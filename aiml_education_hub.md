    - Smooth approximation

  - **Softplus**

  - **Gradient Descent Variants**
    
    - **Batch Gradient Descent**

### 7.5 Transformer Architecture

- **Transformer Fundamentals**
  - Motivation (parallelization, long-range dependencies)
  - "Attention Is All You Need" paper (2017)
  - No recurrence, no convolution
  - Encoder-decoder structure

- **Positional Encoding**
  - Lack of sequential information
  - Sinusoidal positional encoding
  - Learned positional embeddings
  - Absolute vs. relative positional encoding

- **Encoder**
  - Stack of N identical layers (typically N=6)
  - Each layer has:
    - Multi-head self-attention
    - Position-wise feed-forward network
  - Residual connections
  - Layer normalization
  - Sublayer structure

- **Decoder**
  - Stack of N identical layers
  - Each layer has:
    - Masked multi-head self-attention
    - Encoder-decoder attention (cross-attention)
    - Position-wise feed-forward network
  - Residual connections and layer normalization
  - Causal masking (preventing future information)

- **Feed-Forward Networks**
  - Two linear transformations with ReLU/GELU
  - Applied position-wise
  - Hidden dimension (typically 4× model dimension)

- **Layer Normalization**
  - Pre-LN vs. post-LN
  - Impact on training stability

- **Training and Inference**
  - Parallel training (teacher forcing in decoder)
  - Autoregressive inference
  - Beam search decoding
  - Greedy decoding vs. sampling

- **Transformer Variants and Improvements**
  - Sparse attention (Longformer, BigBird)
  - Linear attention
  - Relative positional encoding
  - Adaptive attention span
  - Synthesizer (learned attention patterns)

DiffEq 1.8 The Generative Era

Diffusion Models & SDEs

Generating art by reversing noise.

Stochastic Differential Equations (SDEs)

A standard ODE is deterministic: \(d\mathbf{x} = f(\mathbf{x}, t)dt\). Diffusion models add randomness (Brownian Motion \(d\mathbf{w}\)): \[ d\mathbf{x} = f(\mathbf{x}, t)dt + g(t)d\mathbf{w} \]

The "Forward" process slowly destroys an image by adding noise until it is pure static. The "Reverse" process learns the ODE that removes noise to recreate the image.

2. AI/ML Connection: Stable Diffusion

Langevin Dynamics

To generate an image, we start with random noise and follow the "Score Function" (the gradient of the data distribution). \[ d\mathbf{x} = \nabla_{\mathbf{x}} \log p_{data}(\mathbf{x}) dt + \sqrt{2} d\mathbf{w} \]

This is essentially Gradient Ascent on the probability density of images. The model learns to "push" random pixels towards configurations that look like real photos.

3. Python: 1D Diffusion

diffusion_1d.py
import numpy as np
import matplotlib.pyplot as plt

# Simple 1D "Forward Diffusion": Drift towards 0 + Noise
def diffuse(x0, steps=100, dt=0.1):
    path = [x0]
    x = x0
    for _ in range(steps):
        # dx = -0.5*x*dt + noise
        dx = -0.5 * x * dt + np.random.normal(0, np.sqrt(dt))
        x += dx
        path.append(x)
    return path

# Run multiple particles
for i in range(5):
    plt.plot(diffuse(5.0), alpha=0.6)

plt.axhline(0, color='red', linestyle='--', label="Target Distribution")
plt.title("Forward Diffusion Process (Ornstein-Uhlenbeck)")
plt.xlabel("Time Step")
plt.ylabel("Value")
plt.legend()
plt.show()

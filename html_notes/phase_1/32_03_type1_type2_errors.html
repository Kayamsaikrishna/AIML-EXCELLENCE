03. Type I and Type II Errors

The unavoidable tradeoff of being wrong.

1. Definitions

No statistical test is 100% certain. We always face two types of risks:

  • Type I Error (False Positive): Rejecting $H_0$ when it is actually true. (Convicting an innocent person). The probability of this is $\alpha$.
  • Type II Error (False Negative): Failing to reject $H_0$ when it is actually false. (Letting a guilty person go free). The probability of this is $\beta$.

2. The Balancing Act

You cannot minimize both $\alpha$ and $\beta$ simultaneously without increasing the sample size. If you make it very hard to commit a Type I error (by being extremely strict), you will naturally commit more Type II errors (missing real effects).

3. AI/ML Connection: Recall vs. Precision

The Ethics of Error

In AI, Type I and Type II errors map exactly to **Precision** and **Recall**.

A **Type I Error** is a "False Alarm." In a **Spam Filter**, this is a disaster: an important work email is marked as spam. Here, we prioritize low $\alpha$ (High Precision). A **Type II Error** is a "Missed Signal." In **Cancer Detection AI**, this is a disaster: a patient has a tumor but the AI says they are healthy. Here, we prioritize low $\beta$ (High Recall). AI engineers must use statistical power analysis to decide which error is more "Expensive" for the specific use case. This prevents the building of "One-size-fits-all" models that might be technically accurate but ethically or practically dangerous.

4. Python: Simulating Type I Error

# Experiment: 1000 fair coin tests. 
# How many times do we 'accidentally' reject H0?
trials = 1000
type1_count = 0

for _ in range(trials):
    sample = np.random.binomial(1, 0.5, 100) # True P is 0.5
    p_val = stats.binom_test(np.sum(sample), n=100, p=0.5)
    
    if p_val < 0.05: # Statistical criterion
        type1_count += 1

print(f"Commiting Type I error in {type1_count} out of {trials} trials.")
# Should be close to alpha * trials = 50.

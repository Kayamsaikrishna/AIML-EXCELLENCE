06. Beta Distribution

The distribution of probabilities themselves.

1. Definition

The Beta Distribution is a family of continuous probability distributions defined on the interval $[0, 1]$. It is controlled by two shape parameters, $\alpha$ and $\beta$.

$$ f(x) = \frac{x^{\alpha-1} (1-x)^{\beta-1}}{B(\alpha, \beta)} \quad \text{for } 0 \le x \le 1 $$

Where $B(\alpha, \beta)$ is the Beta function, which ensures the total area is 1.

2. Flexibility

The Beta distribution is incredibly flexible. Depending on $\alpha$ and $\beta$, it can be:

  • **Uniform:** If $\alpha=1, \beta=1$.
  • **U-Shaped:** If $\alpha < 1, \beta < 1$.
  • **Bell-Shaped:** If $\alpha > 1, \beta > 1$.
  • **Symmetric:** If $\alpha = \beta$.

3. AI/ML Connection: Thompson Sampling and A/B Testing

Modeling Success Rates

Because it is restricted to $[0, 1]$, the Beta distribution is used to model Uncertainty about a Probability.

In **Reinforcement Learning**, specifically the **Multi-Armed Bandit** problem, we use **Thompson Sampling**. We maintain a Beta distribution for the "Success Rate" of each action (like clicking an ad). Every time we try an action, we update $\alpha$ (for success) or $\beta$ (for failure). This allows the AI to balance **Exploration** (trying uncertain things) and **Exploitation** (sticking to what works). It is also the standard tool for **Bayesian A/B Testing**, where we compare whether Variant A is better than Variant B by calculating the probability that one Beta distribution is "greater" than the other.

4. Python: Updating a Beta Distribution

from scipy.stats import beta

# Start with a Uniform belief: alpha=1, beta=1
a, b = 1, 1

# Receive data: 8 clicks (successes), 2 skips (failures)
a_new, b_new = a + 8, b + 2

# The new mean success rate
print(f"Post-data Mean: {a_new / (a_new + b_new):.4f}") # 0.81

# Probability that the success rate is > 50%
print(f"P(p > 0.5): {1 - beta.cdf(0.5, a_new, b_new):.4f}") # ~0.99

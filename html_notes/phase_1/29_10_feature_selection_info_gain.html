Feature Selection using Information Gain

Filtering the static. How to mathematically identifies which variables are "Signals" and which are "Noise."

The Overabundance of Data

Adding more data isn't always better. In high-dimensional datasets, irrelevant features (like "Row ID" or "User Name") can hide the true patterns. Information Gain is the filter we use to find the "Gold" in the dirt.

1. The Ranking Process

Information Gain allows us to perform Filter-based Feature Selection. The workflow is as follows:

  1. Calculate Global Entropy of the target variable \(Y\).
  2. For every feature \(X_i\), calculate the Information Gain \(IG(Y, X_i)\).
  3. Rank all features by their IG score.
  4. Keep the top \(k\) features (e.g., SelectKBest).
Feature Ranking Logic: $$ IG_{Ranking} = \{ X_i \mid IG(Y, X_1) \ge IG(Y, X_2) \ge \dots \} $$

2. The "Gain Ratio" Upgrade

Standard IG has a weakness: it inherently prefers features with many distinct values (high cardinality). A feature like "Passport Number" would have perfect IG but zero predictive power for future cases.

$$ GainRatio = \frac{IG(Target, Feature)}{SplitInformation(Feature)} $$

SplitInformation is simply the entropy of the feature itself. If a feature has many branches, its SplitInformation is high, which shrinks the final Ratio—effectively penalizing "noisy" or overly granular features.

3. Python: Feature Importance

from sklearn.feature_selection import mutual_info_classif
import pandas as pd

# Assume X contains features, y contains labels
importance = mutual_info_classif(X, y)

# Create a ranking table
feat_importance = pd.Series(importance, index=X.columns)
print(feat_importance.sort_values(ascending=False))
Note: In scikit-learn, `mutual_info_classif` is the function used to calculate Information Gain for classification tasks. It uses K-Nearest Neighbors to estimate the entropy.
Random Forest Boosting

Gain in Modern Ensembles

  • Gradient Boosting (XGBoost/LightGBM): When these models build trees, they use a "Score" or "Gain" to decide where to cut. This is directly descended from Information Gain principles but modified to handle gradients and second-order derivatives.
  • Dimensionality Reduction: Before running expensive algorithms like SVM or Deep Learning, run an IG filter to drop features with near-zero gain. This reduces training time and prevents overfitting.
  • Interpretability: Unlike "Gini Impurity" (which is more common in Scikit-Learn's default Random Forest), "Information Gain" provides a result in Bits, which is often easier for humans to intuitive'y grasp as "How much information did I actually gain?"

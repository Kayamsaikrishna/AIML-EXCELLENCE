Calculus 1.3 Visualization

Curve Sketching

Seeing the whole elephant, not just the trunk.

The "Check Engine" Light

Plotting a function reveals secrets that raw numbers hide. In AI, "sketching" the loss landscape is how we debug failed training runs.

1. The 7-Step Protocol

  1. Domain: Where does the function die? (Divide by zero, etc.)
  2. Intercepts: Where does it cross zero? (Roots).
  3. Symmetry: Is it Even (mirror) or Odd (rotational)?
  4. Asymptotes: Behavior at infinity (Horizontal) or singularities (Vertical).
  5. Intervals of Increase/Decrease: Use \(f'(x)\).
  6. Extrema: Local Max/Min points.
  7. Concavity: Use \(f''(x)\) for curvature.

2. AI/ML Connection: Loss Landscape Visualization

Why ResNets Train Better

Researchers visualize high-dimensional Neural Networks by taking 2 random direction vectors and plotting the Loss Function on that 2D plane (Isomap/PCA).

  • Plain Networks: Rugged, chaotic landscapes with many local minima.
  • ResNets (Skip Connections): Smooth, convex-like bowls.

This "Curve Sketching" for AI proved mathematically why Skip Connections allow deeper networks to train (they smooth the landscape).

3. Python: The Sketch Artist

auto_sketch.py
import sympy as sp

def analyze_curve(func_str):
    x = sp.Symbol('x')
    f = sp.sympify(func_str)
    
    # 1. Domain (simplified check for denominators)
    # 2. Intercepts (Roots)
    roots = sp.solve(f, x)
    
    # 3. Derivatives
    f1 = sp.diff(f, x)
    f2 = sp.diff(f1, x)
    
    crit_pts = sp.solve(f1, x)
    inflection_pts = sp.solve(f2, x)
    
    print(f"--- Analysis of {f} ---")
    print(f"Roots (y=0): {roots}")
    print(f"Critical Points (f'=0): {crit_pts}")
    print(f"Inflection Points (f''=0): {inflection_pts}")
    
    # Check limit at infinity
    lim_inf = sp.limit(f, x, sp.oo)
    print(f"Limit x->inf: {lim_inf}")

analyze_curve("x**3 - 3*x**2 + 2")

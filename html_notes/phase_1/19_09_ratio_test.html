06. Absolute Convergence & The Ratio Test

Finding the speed of term decay.

1. Absolute Convergence

A series \(\sum a_n\) is Absolutely Convergent if the sum of its absolute values \(\sum |a_n|\) converges. This is strongest form of convergence—if path is absolutely convergent, you can rearrange its terms however you like and the sum won't change.

2. The Ratio Test

The Ratio Test is the most important tool for series containing factorials (\(n!\)) or powers (\(a^n\)). We look at the ratio of consecutive terms:

$$ L = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| $$
  • If \(L < 1\): The series Converges Absolutely.
  • If \(L > 1\): The series Diverges.
  • If \(L = 1\): The test is inconclusive.

3. AI/ML Connection: The Stability of Neural Updates

Convergence Rates

In Deep Learning, we want to know how fast the error decreases. If the ratio of error at step \(t+1\) to the error at step \(t\) is always less than 1, we have Exponential Convergence.

The Ratio Test is essentially the discrete version of checking a "Learning Rate Boundary". If an AI's learning updates grow faster than they shrink (Ratio \(> 1\)), the model will suffer from Exploding Gradients and crash. If the updates shrink consistently (Ratio \(< 1\)), the learning process is stable and the model is likely to reach a high-quality global optimum. This math is the basis for proving which "Optimizers" are safe to use in production.

4. Python: Testing a Factorial Series

# Series n! / n^n
# a_{n+1}/a_n = (n+1)! / (n+1)^(n+1) * n^n / n!
# = (n+1) * n^n / (n+1)^(n+1) = (n / (n+1))^n -> 1/e

import numpy as np
n = 100000
ratio = (n / (n+1))**n
print(f"Ratio limit: {ratio:.6f}")
print(f"Verify (1/e): {1/np.exp(1):.6f}")
# Since 1/e < 1, the series converges!

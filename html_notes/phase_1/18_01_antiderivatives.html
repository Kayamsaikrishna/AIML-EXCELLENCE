01. Antiderivatives

Differentiation in reverse.

1. The Definition

A function \(F\) is called an antiderivative of \(f\) on an interval \(I\) if \(F'(x) = f(x)\) for all \(x\) in \(I\).

For example, if \(f(x) = 2x\), then an antiderivative is \(F(x) = x^2\).

2. The Constant of Integration (\(+C\))

Because the derivative of any constant is zero, there are infinitely many antiderivatives for a single function. We represent this "family" of functions by adding a constant \(C\):

$$ F(x) = x^2 + C $$

Without specific Initial Conditions (e.g., "know that the curve passes through point (1,5)"), we cannot determine the exact value of \(C\).

3. AI/ML Connection: Reconstructing Probabilities

CDF from PDF

In Probability Theory (the backbone of AI), we deal with Probability Density Functions (PDF). If you want to know the "Cumulative" probability (What is the chance that the error is less than 5?), you must find the Antiderivative of the density function.

The Cumulative Distribution Function (CDF) is essentially the antiderivative of the PDF. Many AI models used in risk assessment and stock market prediction rely on these antiderivatives to calculate global confidence bounds.

4. Python: Symbolic Integration with SymPy

import sympy as sp

x = sp.Symbol('x')
f = 3*x**2 + 2*x

# Finding the antiderivative
# SymPy doesn't add +C automatically, but it returns the primary function
F = sp.integrate(f, x)

print(f"Function: {f}")
print(f"Antiderivative (Family): {F} + C") 
# Output: x**3 + x**2 + C

02. The First Derivative Test

Classifying peaks and valleys using signs.

1. The Test

Suppose \(c\) is a critical point of a continuous function \(f\). To determine if \(c\) is a maximum or minimum, we look at the sign of \(f'(x)\) as it passes through \(c\):

  • If \(f'(x)\) changes from positive to negative, \(c\) is a Local Maximum.
  • If \(f'(x)\) changes from negative to positive, \(c\) is a Local Minimum.
  • If \(f'(x)\) does not change sign, \(c\) is neither (it could be a shelf or an inflection point).

2. The "Sign Chart" Method

Usually, we pick test points to the left and right of the critical point. If the slope was climbing (+), hit zero, and started falling (-), you found a peak.

3. AI/ML Connection: Gradient Descent Direction

Oscillating near a Minimum

In Gradient Descent, if our learning rate is too high, we might see the gradient change from positive to negative repeatedly. This is exactly what the First Derivative Test describes: we are jumping across the critical point from one side of the valley to the other.

Knowing that a sign change in the gradient indicates we have "passed" the optimum allows adaptive optimizers to slow down (decay) the learning rate to settle into the actual minimum point.

4. Python: Sign Check Logic

# Function: f(x) = x^2, f'(x) = 2x. Critical point at 0.
def df(x): return 2*x

left_slope = df(-0.1)  # Result: -0.2 (Negative)
right_slope = df(0.1)  # Result: 0.2 (Positive)

if left_slope < 0 and right_slope > 0:
    print("Slope changed from negative to positive. This is a Local Minimum.")

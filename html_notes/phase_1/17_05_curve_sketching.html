05. Curve Sketching

Bringing it all together.

1. The 7-Step Checklist

To visualize the behavior of a function \(f(x)\) from start to finish, we follow this systematic analysis:

  1. Domain: Where is the function allowed to exist?
  2. Intercepts: Where does it hit the x and y axes?
  3. Symmetry: Is it even, odd, or periodic?
  4. Asymptotes: What happens as \(x \to \infty\) or near vertical breaks?
  5. Intervals of Increase/Decrease: Found using \(f'(x)\).
  6. Local Extrema: Maxima and Minima.
  7. Concavity & Inflection: Found using \(f''(x)\).

2. The "Anatomy" of a Curve

By identifying these milestones, we can draw a high-fidelity graph of the function without needing to plot thousands of individual points.

3. AI/ML Connection: Loss Surface Visualization

Debugging Your Model

When an AI model isn't training well, research engineers often "sketch" the loss surface. Does the loss function have multiple local minima? Is there a flat plateau? Are there sharp "cliffs" where the gradient explodes?

Advanced tools like LossLandscape.com use variations of curve sketching techniques to plot the multi-billion-dimensional space of a Neural Network onto a 2D or 3D graph. Understanding the "shape" of your objective function is the first step toward improving optimizer performance.

4. Python: Automated Analysis Utility

import sympy as sp

def analyze_function(expr_string):
    x = sp.Symbol('x')
    f = sp.sympify(expr_string)
    
    analysis = {
        "Intercepts": sp.solve(f, x),
        "Critical Points": sp.solve(sp.diff(f, x), x),
        "Inflection Points": sp.solve(sp.diff(f, x, 2), x)
    }
    return analysis

res = analyze_function("x**3 - 3*x**2")
print(f"Key Graph Points: {res}")

01. Vector Definition & Notation

The fundamental unit of data in modern AI.

1. What is a Vector?

From a Computer Science perspective, a vector is simply an ordered list of numbers. From a Mathematical perspective, it is an element of a Vector Space. From an AI perspective, it represents a single data point or a "Feature" in multi-dimensional space.

$$ \mathbf{v} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix}, \quad \mathbf{v} \in \mathbb{R}^n $$

Notation Standards

  • Column Vectors: Standard in Linear Algebra (\( n \times 1 \)).
  • Row Vectors: Common in Batch Processing (\( 1 \times n \)).
  • Components: \( v_i \) denotes the \( i \)-th element or feature.

2. Vectors as Tensors

Rank & Dimensionality

In libraries like PyTorch or TensorFlow, we call everything a "Tensor". A Vector is specifically a Rank-1 Tensor.

  • Word Embeddings: A vector representing a word (e.g., 512 dimensions).
  • Weights: A vector of parameters in a single neuron.

3. Python: Vector Notation in Numpy

import numpy as np

# Creating a Column Vector
v_col = np.array([[1], [2], [3]])
print(f"Column Vector Shape: {v_col.shape}") # (3, 1)

# Creating a Row Vector (Modern AI standard for layers)
v_row = np.array([1, 2, 3])
print(f"Row Vector Shape: {v_row.shape}")    # (3,)

# Accessing components
print(f"Second component: {v_row[1]}")      # Output: 2

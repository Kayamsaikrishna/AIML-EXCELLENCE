01. Vector Definition & Notation

The fundamental unit of data in modern AI.

1. What is a Vector?

From a Computer Science perspective, a vector is simply an ordered list of numbers. From a Mathematical perspective, it is an element of a Vector Space. From an AI perspective, it represents a single data point or a "Feature" in multi-dimensional space.

$$ \mathbf{v} = \begin{bmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{bmatrix}, \quad \mathbf{v} \in \mathbb{R}^n $$

Notation Standards

  • Column Vectors: Standard in Linear Algebra (\( n \times 1 \)).
  • Row Vectors: Common in Batch Processing (\( 1 \times n \)).
  • Components: \( v_i \) denotes the \( i \)-th element or feature.

2. Vectors as Tensors

Rank & Dimensionality

In libraries like PyTorch or TensorFlow, we call everything a "Tensor". A Vector is specifically a Rank-1 Tensor.

  • Word Embeddings: A vector representing a word (e.g., 512 dimensions).
  • Weights: A vector of parameters in a single neuron.

3. Python: Vector Notation in Numpy

import numpy as np

# Creating a Column Vector
v_col = np.array([[1], [2], [3]])
print(f"Column Vector Shape: {v_col.shape}") # (3, 1)

# Creating a Row Vector (Modern AI standard for layers)
v_row = np.array([1, 2, 3])
print(f"Row Vector Shape: {v_row.shape}")    # (3,)

# Accessing components
print(f"Second component: {v_row[1]}")      # Output: 2

4. Applications in AI/ML Systems

Word Embeddings

Vectors representing semantic meaning of words in high-dimensional space. Words with similar meanings are located close to each other.

$$ \text{similarity}(\vec{w}_{king}, \vec{w}_{queen}) = \cos(\theta) = \frac{\vec{w}_{king} \cdot \vec{w}_{queen}}{||\vec{w}_{king}|| ||\vec{w}_{queen}||} $$

Feature Vectors

Representing data points as vectors in machine learning. Each dimension corresponds to a feature of the data.

$$ \vec{x} = [x_1, x_2, ..., x_n] \text{ where } x_i \text{ represents the } i^{th} \text{ feature} $$

Neural Network Representations

Activations in neural networks are represented as vectors at each layer, transforming input data through learned transformations.

$$ \vec{a}^{(l+1)} = \sigma(W^{(l)}\vec{a}^{(l)} + \vec{b}^{(l)}) $$

5. Problem-Solving Methodologies

Vector Normalization

Techniques to scale vectors to a consistent magnitude while preserving direction.

$$ \hat{v} = \frac{\vec{v}}{||\vec{v}||_2} = \frac{\vec{v}}{\sqrt{\sum_{i=1}^n v_i^2}} $$ 

import numpy as np

def normalize_vector(v):
    norm = np.linalg.norm(v)
    if norm == 0:
        return v
    return v / norm

# Example usage
v = np.array([3, 4])
normalized_v = normalize_vector(v)
print(f'Original: {v}, Normalized: {normalized_v}')
# Output: Original: [3 4], Normalized: [0.6 0.8]

Vector Operations

Fundamental operations for manipulating vector data in machine learning.

\text{Addition: } \vec{a} + \vec{b} = [a_1+b_1, a_2+b_2, ..., a_n+b_n] \\\n \text{Dot Product: } \vec{a} \cdot \vec{b} = \sum_{i=1}^n a_i b_i

Distance Metrics

Different ways to measure similarity or distance between vectors.

\text{Euclidean Distance: } d(\vec{a}, \vec{b}) = ||\vec{a} - \vec{b}||_2 \\\n \text{Cosine Similarity: } \cos(\theta) = \frac{\vec{a} \cdot \vec{b}}{||\vec{a}|| ||\vec{b}||}

6. Industry Use Cases

Recommendation Systems

Representing users and items as vectors in embedding space to find similarities and make recommendations.

  • User vectors based on preferences and behavior
  • Item vectors based on content and user interactions
  • Similarity calculations for personalized recommendations

Computer Vision

Image features extracted as vectors for classification, detection, and similarity matching.

  • Feature extraction using CNNs
  • Face recognition embeddings
  • Image similarity and clustering

Search Engines

Document and query vectors for semantic search and information retrieval.

  • Semantic search using vector similarity
  • Document ranking based on vector distances
  • Question answering systems

7. Step-by-Step Problem Solving

Step 1: Define the Vector Space

Identify the dimensionality and nature of your vector space:

  • Determine the number of features/dimensions
  • Define the data type (real numbers, binary, categorical)
  • Consider normalization requirements

Step 2: Choose Appropriate Operations

Select vector operations based on your problem requirements:

  • Dot product for similarity measures
  • Cross product for perpendicular vectors (3D only)
  • Norms for measuring vector magnitudes

Step 3: Implement Numerical Stability

Apply appropriate techniques to ensure reliable computation:

  • Normalize vectors to prevent magnitude issues
  • Handle zero vectors appropriately
  • Use stable algorithms for distance calculations

Step 4: Optimize for Performance

Implement efficient vector operations for your use case:

  • Use vectorized operations in NumPy/PyTorch
  • Consider approximate nearest neighbor algorithms
  • Apply dimensionality reduction if needed

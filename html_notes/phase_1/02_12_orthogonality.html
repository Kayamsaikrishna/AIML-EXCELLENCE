1. Orthonormal Matrices (Q)

A set of vectors is Orthonormal if:

  1. They are all mutually orthogonal (Dot product = 0).
  2. They are all unit length (Norm = 1).

If we stack them into a matrix \( Q \), explicitly:

$$ Q^T Q = I \implies Q^{-1} = Q^T $$

This property makes inverting matrices free (computationally), which is why we love QR Decomposition.

2. Feature Disentanglement

Ideally, we want our neural network features to be orthogonal. This means changing one feature (e.g., "Hair Color") does not affect another (e.g., "Age").

If features are correlated (angle < 90), the gradient descent path is zig-zaggy and slow. If they are orthogonal, the cost function becomes a perfect bowl (Condition Number=1), and convergence is instant.

3. Checking Orthonormality

Verifying the Identity property.

import numpy as np

# A Rotation Matrix (Always Orthonormal)
theta = np.radians(45)
c, s = np.cos(theta), np.sin(theta)

Q = np.array([
    [c, -s],
    [s,  c]
])

print("Matrix Q:")
print(Q)

# Check Q^T @ Q
QtQ = np.dot(Q.T, Q)

print("\nQ^T . Q (Should be Identity):")
with np.printoptions(suppress=True):
    print(QtQ)

# Check Inverse cost
inv_Q = np.linalg.inv(Q)
print("\nInverse (Same as Transpose?):")
print(np.allclose(inv_Q, Q.T)) # True

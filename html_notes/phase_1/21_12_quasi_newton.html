12. Quasi-Newton Methods (BFGS)

Approximating intelligence for efficiency.

1. The Problem with Newton

Newton's Method is mathematically brilliant but computationally expensive because it requires calculating and inverting the Hessian (\(N^2\) terms). In high dimensions, this is a bottleneck.

2. The Quasi-Newton Solution

Quasi-Newton methods, like BFGS (Broyden–Fletcher–Goldfarb–Shanno), don't calculate the Second Derivative. Instead, they learn an approximation of the Hessian inverse by looking at how the Gradient changes between steps.

  • They use only First-Order information (gradients).
  • They build a "Running Estimate" of the curvature.
  • They are much more efficient than Newton, but faster than Gradient Descent.

3. AI/ML Connection: Scikit-Learn and L-BFGS

The Workhorse of Classical ML

When you run LogisticRegression(solver='lbfgs') in Python, you are using a Limited-memory BFGS algorithm.

It is the favored choice for problems with a medium number of features because it converges much faster than Gradient Descent and doesn't require the massive memory of Newton's Method. It is particularly good for Convex problems where reaching the absolute global minimum is the priority. Many modern "Energy-Based" AI models use L-BFGS in their inner loops to find perfectly stable states. It is the bridge between "Blind Descent" and "Total Information".

4. Python: Using BFGS in SciPy

from scipy.optimize import minimize

def rosenbrock(v):
    return (1 - v[0])**2 + 100 * (v[1] - v[0]**2)**2

# 'BFGS' method calculates the gradient and approximates the Hessian
res = minimize(rosenbrock, [0, 0], method='BFGS')

print(f"Optimal Result: {res.x}")
print(f"Number of Iterations: {res.nit}")

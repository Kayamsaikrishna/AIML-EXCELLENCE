06. Marginal Analysis in Economics

The derivative as "incremental change".

1. Core Concepts

$$ C(x) = \text{Total Cost for x units} $$ $$ R(x) = \text{Total Revenue for x units} $$ $$ P(x) = R(x) - C(x) = \text{Total Profit} $$
  • Marginal Cost: \(C'(x)\). The cost to produce the next unit.
  • Profit Maximization: Occurs when \(P'(x) = 0 \implies R'(x) = C'(x)\).

2. Elasticity of Demand

Measures the sensitivity of quantity demanded (\(q\)) to changes in price (\(p\)):

$$ E = \left| \frac{p}{q} \cdot \frac{dq}{dp} \right| $$

3. AI Connection: Recommender Revenue

Dynamic Pricing Agents

AI models in e-commerce use marginal analysis to set prices in real-time. By estimating the Elasticity of demand for different users, an RL (Reinforcement Learning) agent tries to find the point where Marginal Revenue equals Marginal Cost. Calculus allows the business to scale without manual price changes.

4. Python: Profit Maximization

import sympy as sp

x = sp.Symbol('x')
# Revenue: R(x) = Price * Quantity
R = 50*x - 0.5*x**2
# Cost: C(x) = Fixed + Variable
C = 10*x + 50

# Profit
P = R - C

# Maximize: P' = 0
dP = sp.diff(P, x)
opt_x = sp.solve(dP, x)[0]

print(f"Optimal units for Max Profit: {opt_x}")
print(f"Max Profit: {P.subs(x, opt_x)}")

Infinite Sets & Countability

Comparing the Endless. Proving that not all infinities are created equal and discovering the smallest "size" of infinity that defines the range of digital computers.

The Countability Test

How do you compare two infinite sets? You try to find a Bijection (Perfect Pairing) between them. If you can pair every element of set \(A\) with every element of set \(B\) with none left over, they have the same size (Cardinality), even if one seems "bigger" at first glance.

1. Countably Infinite Sets

A set is Countable if it has the same cardinality as the set of Natural Numbers \(\mathbb{N} = \{1, 2, 3, ...\}\). Its cardinality is denoted by \(\aleph_0\) (Aleph-null).

Hilbert's Hotel

Even if an infinite hotel is full, you can fit more people. If an infinite bus arrives, just move person \(n\) to room \(2n\). This proves the Integers (\(\mathbb{Z}\)) have the same size as Natural Numbers.

The Paradox of Parts

In the infinite world, a proper subset can have the same size as the whole set. Example: The set of even numbers is "just as big" as the set of all integers.

2. Are Fractions Bigger?

Surprisingly, the set of all Rational Numbers (\(\mathbb{Q}\)) is also Countable.

By arranging fractions in a 2D grid and snaking through them diagonally, we can list every single fraction in order (1st, 2nd, 3rd...). If you can list them, they are countable. \(\therefore |\mathbb{Q}| = \aleph_0\).

Computing Precision

Why Infinity matters in CS

  • Computable Numbers: There are only a Countable number of computer programs (since every program is a finite string of bits). This means there are only a countable number of tasks a computer can *ever* perform.
  • The Floating Point Trap: Computers struggle with Real Numbers (\(\mathbb{R}\)) because there are Uncountably many of them. We are forced to use "Floating Point" approximations, which are discrete (countable) subsets of the reals. This is the source of all numerical instability in AI training.
  • Hashing: When we hash infinite potential strings into a finite bit-space (e.g., SHA-256), a "Collision" is mathematically guaranteed. We are mapping an infinite set to a finite one.

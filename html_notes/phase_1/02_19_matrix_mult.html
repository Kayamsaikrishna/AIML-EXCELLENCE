1. Function Composition

If matrix \( B \) rotates a vector, and matrix \( A \) scales a vector:

  • Apply \( B \) first: \( \mathbf{h} = B\mathbf{x} \)
  • Apply \( A \) next: \( \mathbf{y} = A\mathbf{h} = A(B\mathbf{x}) = (AB)\mathbf{x} \)

The product \( AB \) represents the single transformation that does both steps at once. Note that order matters: \( AB \neq BA \) (Rotate then Scale != Scale then Rotate).

2. Stacking Layers

A Deep Neural Network is just a chain of matrix multiplications (interspersed with non-linearities \( \sigma \)).

$$ \hat{y} = W_3 \sigma(W_2 \sigma(W_1 \mathbf{x})) $$

If we removed the non-linearities \( \sigma \), the whole network would collapse into a single matrix \( W_{total} = W_3 W_2 W_1 \), making "Deep" learning pointless. Linear layers alone cannot learn complex patterns.

3. The Dot Product Method

Using NumPy for efficient multiplication.

import numpy as np

# A: Scale Y by 2
A = np.array([
    [1, 0],
    [0, 2]
])

# B: Rotate 90 Deg
B = np.array([
    [0, -1],
    [1, 0]
])

# AB (Rotate THEN Scale)
AB = np.dot(A, B)

# BA (Scale THEN Rotate)
BA = np.dot(B, A)

print("AB (Rotate then Scale):")
print(AB)
# [[ 0, -1]
#  [ 2,  0]]

print("\nBA (Scale then Rotate):")
print(BA)
# [[ 0, -2]
#  [ 1,  0]]

# They are different!

1. Definition

Any matrix \( A \) (even rectangular) can be written as:

$$ A = Q R $$
  • \( Q \): Orthogonal Matrix (\( Q^T Q = I \)). Encodes the "Direction".
  • \( R \): Upper Triangular. Encodes the "Scaling/Shearing".

This is effectively the matrix form of the Gram-Schmidt process.

2. Stable Regression

To solve Least Squares \( A^T A \mathbf{x} = A^T \mathbf{b} \), we typically use QR because it avoids forming \( A^T A \) (which can square the condition number and lose precision).

$$ R \mathbf{x} = Q^T \mathbf{b} $$

Solving this triangular system is fast and stable.

3. Numerical QR

Standard factorization.

import numpy as np

A = np.array([
    [1, 1],
    [1, 0],
    [1, 2]
]) # 3x2, Overdetermined

# Reduced QR (returns Q as 3x2, R as 2x2)
Q, R = np.linalg.qr(A)

print("Q (Orthonormal Columns):")
print(Q.round(3))
print("\nR (Upper Triangular):")
print(R.round(3))

print("\nCheck Orthogonality Q.T @ Q:")
print((Q.T @ Q).round(10)) # Should be Identity

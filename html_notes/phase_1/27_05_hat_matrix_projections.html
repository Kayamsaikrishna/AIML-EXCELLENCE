Stats 1.7 Matrix Algebra

The Hat Matrix (\(\mathbf{H}\))

The linear transformation that maps observed data to our predictions.

The Mathematical Name

We call it the Hat Matrix because it literally "puts a hat" on \(\mathbf{y}\).

$$ \hat{\mathbf{y}} = \mathbf{H} \mathbf{y} $$

1. Definition & Formula

$$ \mathbf{H} = \mathbf{X}(\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T $$

While this looks complex, its geometry is simple: \(\mathbf{H}\) is a Projection Matrix. It takes the raw data vector \(\mathbf{y}\) and smashes it down into the subspace formed by our features \(\mathbf{X}\).

2. Two Critical Properties

1. Idempotency (\(\mathbf{H} \cdot \mathbf{H} = \mathbf{H}\))

If you project a vector onto a plane, and then project the result onto the same plane again, nothing changes. You're already there!

2. Symmetry (\(\mathbf{H} = \mathbf{H}^T\))

This ensures that the projection is Orthogonal (the shortest path to the plane).

3. ML Connection: Leverage & Outliers

Diagnostics Robustness

The Diagonals of H

The diagonal elements of the Hat matrix (\(h_{ii}\)) are called Leverage values.

They tell you how much weight a single data point \(y_i\) has on its own prediction \(\hat{y}_i\). - If \(h_{ii}\) is high, it means that even a small change in that data point will pull the entire regression line towards it.

In ML Production: We use these values to detect Influential Points. If one user's data has a massive leverage value, it might be skewing the whole model (e.g., a "whale" in a spending dataset). We might want to remove them or use Robust Regression to mitigate their power.

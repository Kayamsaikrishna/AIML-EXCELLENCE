16. Wilcoxon Rank-Sum (Mann-Whitney U)

The robust alternative to the t-test.

1. Why go Non-parametric?

The t-test assumes your data is Normal. What if it's not? What if it's heavily skewed, has massive outliers, or consists of **Ordinal Ranks** (like "Bad, Good, Excellent")? In these cases, the t-test's p-values are lies. You must use a Non-parametric test like the Wilcoxon Rank-Sum (also known as Mann-Whitney U).

2. Logic: The Power of Ranks

Instead of using the raw values, this test converts all data points into **Ranks** (1st, 2nd, 3rd...). It then sums the ranks for each group. If one group holds most of the "High" ranks and the other holds the "Low" ranks, the test concludes they are different. Because it uses ranks, it is completely immune to **Outliers**—a value of 1,000,000 is treated the same as a value of 100 if both are the "Highest" in the set.

3. AI/ML Connection: Evaluating Robustness across Domains

Comparing Black-Box Stability

In AI research, the Wilcoxon test is used for Universal Comparison.

In **Reinforcement Learning (RL)**, performance scores across different seeds often follow a "Long Tail" distribution—some runs succeed wildly, others fail completely. A t-test would be destroyed by these "Extreme Wins/Losses." RL researchers use the **Mann-Whitney U** to compare Algorithm A vs. Algorithm B. It answers: "Does A generally rank higher than B?" regardless of the variance. In Search Engine Optimization (SEO), we use it to compare user behavior between different algorithms. Because "Time on Page" is never Normal (some users stay for 1 second, others for an hour), the Wilcoxon test is the only mathematically safe way to prove that your new AI has actually improved engagement.

4. Python: stats.mannwhitneyu

# Skewed results from two RL agents
agent_a = [10, 12, 1000, 15, 11] # One massive outlier
agent_b = [20, 22, 25, 21, 23]

# The t-test would be confused by the '1000'
# but Mann-Whitney is robust.
u_stat, p_val = stats.mannwhitneyu(agent_a, agent_b)

print(f"p-value: {p_val:.4f}")
# p = 0.015. Agent B is significantly 'Higher' than A 
# despite A having the highest single score.

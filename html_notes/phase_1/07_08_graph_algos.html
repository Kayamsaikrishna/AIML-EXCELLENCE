1. Counting Paths

If \( A \) is the definition of "neighbors", then \( A^2 \) is "neighbors of neighbors".

Specifically, the entry \( (A^k)_{ij} \) counts the number of distinct walks of length \( k \) between node \( i \) and node \( j \). This is the foundation of Graph Convolutional Networks (GCNs) which aggregate info from k-hop neighborhoods.

2. The Graph Laplacian

The matrix \( L = D - A \) (Degree matrix - Adjacency) measures the "smoothness" of a signal on the graph.

\( x^T L x = \sum (x_i - x_j)^2 \) sums the differences between connected nodes. Minimizing this (subject to constraints) finds the best way to cut the graph into clusters (Spectral Clustering).

3. Counting Paths

import numpy as np

# Simple Graph: 0-1, 1-2
# 0 -- 1 -- 2
A = np.array([
    [0, 1, 0],
    [1, 0, 1],
    [0, 1, 0]
])

print("Adjacency A:\n", A)

# Paths of length 2
A2 = A @ A
print("\nA^2 (2-hop paths):\n", A2)
# A2[0,0] = 1 (0 -> 1 -> 0)
# A2[0,2] = 1 (0 -> 1 -> 2)

# Paths of length 3
A3 = A2 @ A
print("\nA^3 (3-hop paths):\n", A3)
# A3[0,1] = 2 (0->1->0->1, 0->1->2->1)

Prob 1.4 The Law

Kolmogorov Axioms

Three rules to bind them all.

The Foundation

Probability \(P\) is a function mapping events to real numbers. It must satisfy:

  1. Non-negativity: \(P(E) \ge 0\) for any event \(E\).
  2. Unit Measure: \(P(\Omega) = 1\) (Something must happen).
  3. Additivity: If \(A\) and \(B\) are disjoint (\(A \cap B = \emptyset\)), then \(P(A \cup B) = P(A) + P(B)\).

2. ML Connection: Softmax

Valid Distributions

In Classification, the output layer of determines class probabilities. We usually get "Logits" (scores) \(z_i\) which can be negative or > 1.

The Softmax function enforces Axioms 1 and 2: \[ \sigma(z)_i = \frac{e^{z_i}}{\sum e^{z_j}} \] This ensures all \(p_i \ge 0\) and \(\sum p_i = 1\), making it a valid probability distribution.

3. Python: Verifying Axioms

softmax_check.py
import numpy as np

def softmax(logits):
    exp_z = np.exp(logits)
    return exp_z / np.sum(exp_z)

logits = np.array([2.0, 1.0, 0.1])
probs = softmax(logits)

print(f"Probs: {probs}")
print(f"Axiom 1 (Non-neg): {np.all(probs >= 0)}")
print(f"Axiom 2 (Sum=1): {np.isclose(np.sum(probs), 1.0)}")

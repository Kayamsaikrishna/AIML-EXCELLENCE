22. Rational Graphs & Discontinuities

When math breaks. Holes, Cliffs, and Clipping.

1. Types of Breaks

$$ f(x) = \frac{N(x)}{D(x)} $$

The Two Dangers

  • Hole (Removable): If a factor cancels out (e.g., \(\frac{x-1}{x-1}\)). It's just a missing point.
  • Asymptote (Infinite): If the factor stays in the denominator (e.g., \(\frac{1}{x}\)). The graph shoots to infinity.

2. Gradient Clipping

In Recurrent Neural Networks (RNNs), the loss function can look like a Rational Function with steep cliffs. If you step too close to the edge, the gradient becomes massive (Infinity).

This causes the weights to update by a huge amount, destroying the model's memory.

The Fix: Clipping

We artificially limit the length of the gradient vector.

$$ \text{if } ||g|| > c, \text{then } g = c \cdot \frac{g}{||g||} $$

3. Coding Protection

PyTorch has a built-in utility for this safety measure.

// PyTorch: Gradient Clipping
import torch
import torch.nn as nn

# Simulate a massive gradient (Explosion)
linear = nn.Linear(10, 10)
# Manually setting gradients to be HUGE
linear.weight.grad = torch.full((10, 10), 10000.0)

print(f"Norm before: {linear.weight.grad.norm():.2f}") 
# Output: 100000.00 (Danger!)

# Clip Gradients to max norm of 5.0
nn.utils.clip_grad_norm_(linear.parameters(), max_norm=5.0)

print(f"Norm after: {linear.weight.grad.norm():.2f}") 
# Output: 5.00 (Safe)
# The direction is preserved, but the magnitude is tamed.

1. Types of Breaks

Not all functions are smooth connected lines.

  • Holes (Removable): \( \frac{x^2-1}{x-1} \). Looks fine everywhere except \( x=1 \).
  • Asymptotes (Non-Removable): \( \frac{1}{x} \). The value shoots to infinity. This is the more dangerous one for AI.

2. Safety Rails: Gradient Clipping

When training Recurrent Neural Networks (RNNs), gradients effectively multiply over time: \( g^T \). If \( g > 1 \), this goes to infinity (Exploding Gradient).

To fix this, we artificially "Clip" the gradient norm.

$$ \text{if } \|g\| > C, \text{ then } g \leftarrow g \cdot \frac{C}{\|g\|} $$

This forces the update to stay reasonable, even if the math says "Jump to Infinity".

3. Implementing Clipping

Handling numerical instability.

import numpy as np

# Simulating a dangerous gradient (Explosion)
gradients = np.array([10.0, 500.0, -9999.0])

def clip_gradients(grads, max_norm):
    total_norm = np.linalg.norm(grads)
    if total_norm > max_norm:
        clip_coef = max_norm / (total_norm + 1e-6)
        grads = grads * clip_coef
        print(f"Clipped! New Norm: {max_norm}")
    else:
        print("Gradients are safe.")
    return grads

# Clip to max length of 5.0
safe_grads = clip_gradients(gradients, 5.0)

print(f"Original: {gradients}")
print(f"Safe: {safe_grads}")
# The DIRECTION is preserved, but length is capped.

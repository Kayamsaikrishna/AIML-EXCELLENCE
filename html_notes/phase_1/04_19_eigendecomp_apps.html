1. Mechanical Vibrations

Any oscillating system is governed by \( M \ddot{x} + K x = 0 \).

The solutions are purely sinusoidal \( x(t) = v e^{i \omega t} \) precisely when \( v \) is an eigenvector of \( M^{-1}K \). The fundamental frequencies of the Universe (and guitar strings) are eigenvalues.

2. Spectral Clustering

How do we cluster data that is shaped like a spiral or concentric circles? K-Means fails here.

Spectral Clustering builds a similarity graph, computes the Graph Laplacian \( L = D - A \), and finds the eigenvectors. The data becomes linearly separable in the "Eigen-space" of the Laplacian.

3. Spectral Clustering (Fiedler Vector)

import numpy as np
from sklearn.cluster import SpectralClustering
import matplotlib.pyplot as plt

# Adjacency Matrix of a Line Graph (0-1-2-3)
# Cutting the middle edge separates the graph
adj = np.array([
    [0, 1, 0, 0],
    [1, 0, 1, 0],
    [0, 1, 0, 1],
    [0, 0, 1, 0]
])

# Degree Matrix
D = np.diag(np.sum(adj, axis=1))

# Laplacian
L = D - adj

# Eigen decomp
vals, vecs = np.linalg.eigh(L)

print("Eigenvalues of Laplacian:")
print(vals.round(2))
# First is always 0. Second (Fiedler Value) tells algebraic connectivity.

print("\nFiedler Vector (2nd Eigenvector):")
print(vecs[:, 1].round(2))
# The sign of this vector separates the graph into two clusters

Prob 1.4 Inversion

The Complement Rule

Sometimes it's easier to count what didn't happen.

The "Not" Logic

For any event \(A\), the probability of "Not A" (denoted \(A^c\) or \(A'\)) is: \[ P(A^c) = 1 - P(A) \]

This is useful when calculating \(P(A)\) directly is hard, but calculating "None of the above" is easy. Example: "At least one server fails" = 1 - "All servers work".

2. ML Connection: Dropout

Survival Probability

In Dropout regularization, each neuron has a probability \(p\) of being "dropped" (set to zero). The probability of a neuron surviving (being kept/active) is \(1-p\).

We use this complement probability to scale the activations during testing, ensuring the expected value remains consistent with training.

3. Python: Birthday Problem

birthday_paradox.py
# Prob that in room of N people, at least 2 share a birthday.
# P(Share) = 1 - P(No One Shares)

def p_share(n):
    # P(No Share) = 365/365 * 364/365 * ... 
    p_no_share = 1.0
    for i in range(n):
        p_no_share *= (365 - i) / 365
    return 1 - p_no_share

print(f"Room of 23 people: {p_share(23):.4f}")
# Result is > 0.5!

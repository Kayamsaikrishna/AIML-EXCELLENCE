Prob 1.4 The Strength

Correlation (Pearson's \(r\))

Measuring the strength and direction of linear relationships on a universal scale.

The Normalized Covariance

Correlation is simply Covariance divided by the product of Standard Deviations.

This "normalization" removes the units and constrains the value to exactly between -1 and 1. This makes it a universal yardstick for how closely two variables follow a straight line.

1. The Formula

$$ \rho_{X,Y} = \text{Corr}(X, Y) = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y} $$
  • \(\rho = 1\): Perfect positive linear relationship.
  • \(\rho = -1\): Perfect negative linear relationship.
  • \(\rho = 0\): No linear relationship.

Key Insight: Correlation only measures Linear relationships. Two variables could have a perfect parabolic relationship (\(Y=X^2\)) and still have a correlation of zero!

3. ML Connection: Feature Engineering

EDA Supervised

The Correlation Heatmap

During Exploratory Data Analysis (EDA), we look at the correlation matrix between features and the target variable.

- Predictive Power: High correlation between a feature and the target means the feature is likely very useful for the model.
- Multicollinearity: High correlation between two features suggests redundancy. If Feature A and Feature B are 0.99 correlated, keeping both might hurt the stability of your Linear Regression coefficients.

Feature Selection

Oftentimes, we drop features that have very low correlation with the target to reduce noise and speed up training. However, be careful: some features only become useful in combination with others (interaction effects).

4. Python: The Heatmap

Python: Visualizing Correlations

import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Sample DataFrame
data = pd.DataFrame({
    'Income': [50, 60, 80, 110, 120],
    'Spending': [20, 25, 30, 45, 50],
    'Age': [25, 30, 45, 50, 60]
})

# Compute Correlation Matrix
corr_matrix = data.corr()

# Plot Heatmap
sns.heatmap(corr_matrix, annot=True, cmap='coolwarm')
plt.show()

08. Numerical Integration

Solving the "unsolvable" integrals.

1. The Trapezoidal Rule

Approximate the area using trapezoids instead of rectangles. It's more accurate for curved functions.

$$ \int_a^b f(x) dx \approx \frac{\Delta x}{2} [f(x_0) + 2f(x_1) + ... + f(x_n)] $$

2. Simpson's Rule (Parabolic)

Instead of lines, use quadratic arcs to fit the curve. It requires an even number of sub-intervals (\(n\)).

$$ S = \frac{\Delta x}{3} [f(x_0) + 4f(x_1) + 2f(x_2) + 4f(x_3) ... + f(x_n)] $$

3. AI Connection: Expected Values in Bayesian AI

Log-Likelihood Integration

In Bayesian ML, calculating the Evidence \(p(D)\) requires integrating over the entire parameter space. These integrals are often high-dimensional and impossible to solve on paper. Numerical methods like the Trapezoidal rule (for low dims) or Monte Carlo Integration (for high dims) are the only way AI systems can handle uncertainty in the real world.

4. Python: Scipy Integration

from scipy.integrate import simps, trapezoid
import numpy as np

def f(x): return np.exp(-x**2) # Gaussian (no analytical integral)
x = np.linspace(0, 1, 100)
y = f(x)

# Numerical Int
trap_val = trapezoid(y, x)
simp_val = simps(y, x)

print(f"Trapezoidal: {trap_val:.6f}")
print(f"Simpson's:   {simp_val:.6f}")

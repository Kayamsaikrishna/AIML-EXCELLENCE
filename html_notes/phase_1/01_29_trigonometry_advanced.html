29. Advanced Trigonometry

Identities and The Dot Product. The Measure of Similarity.

The Dot Product

$$ A \cdot B = ||A|| ||B|| \cos(\theta) $$

Geometric Interpretation

The Dot Product measures how much two vectors point in the same direction.

  • If aligned: \(\cos(0) = 1\) (Max Sim).
  • If perpendicular: \(\cos(90^\circ) = 0\) (No correlation).
  • If opposite: \(\cos(180^\circ) = -1\) (Negative correlation).

2. Cosine Similarity

In Search Engines and Recommendation Systems (like Netflix or Google), we represent items as Vectors.

To find "Similar" items, we calculate the Cosine Similarity (just the normalized dot product).

$$ \text{Similarity} = \frac{A \cdot B}{||A|| ||B||} $$

3. Coding Similarity

// Python: Cosine Similarity
import numpy as np
from sklearn.metrics.pairwise import cosine_similarity

# Define Embeddings (e.g., Word Vectors)
#        [Furry, Metal, Alive]
dog   = [[0.9,   0.0,   0.9]] 
cat   = [[0.9,   0.0,   0.8]]
robot = [[0.1,   0.9,   0.0]]

print(f"Dog vs Cat: {cosine_similarity(dog, cat)[0][0]:.4f}") 
# High Score (Very Similar)

print(f"Dog vs Robot: {cosine_similarity(dog, robot)[0][0]:.4f}") 
# Low Score (Different)

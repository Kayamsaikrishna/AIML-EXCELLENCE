Stats 1.5 Group Comparison

Two-Sample T-Test

Comparing the means of two independent groups to see if they come from the same underlying reality.

The Question

"Does Group A behave differently than Group B?"

- Independent: The people in Group A have no relationship with the people in Group B.

1. The Test Statistic (Equal Variance)

$$ t = \frac{\bar{x}_1 - \bar{x}_2}{s_p \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} $$ $$ s_p^2 = \frac{(n_1-1)s_1^2 + (n_2-1)s_2^2}{n_1 + n_2 - 2} $$
  • \(s_p\): Pooled Standard Deviation. We combine the noise of both groups to get a more stable estimate.

2. Welch's T-test (Unequal Variance)

If the groups have very different sample sizes or spreads, we skip "pooling" and use **Welch's T-test**. This is the default in modern software like `scipy.stats` because it is more robust.

3. ML Connection: A/B Testing

Product ML Experimentation

Model A vs. Model B

You have two model versions deployed in an A/B test. - Group A (Control): Users see current recommendations. - Group B (Experiment): Users see Neural-Collaborative Filtering.

The Metric: Average session duration (in seconds). 1. Collect data for 1000 users in each group. 2. Run a Two-Sample T-test.

If the T-test returns a P-value of 0.001, you have scientific proof that the new model has changed user behavior. It's not just a lucky day; the new algorithm is significantly better at keeping users on the app.

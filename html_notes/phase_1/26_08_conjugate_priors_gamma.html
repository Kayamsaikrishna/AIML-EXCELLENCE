Stats 1.6 Rate Estimation

Conjugate Priors: Gamma

Estimating frequencies and arrival rates (Poisson/Exponential) using the highly flexible Gamma distribution.

What is Gamma?

The Gamma Distribution \(\text{Gamma}(\alpha, \beta)\) is the "Mother" of arrival processes.
- \(\alpha\): Shape parameter (number of events). - \(\beta\): Rate parameter (how fast events happen).

1. The Gamma-Poisson Pair

Use this when your data consists of Counts (e.g., number of emails, number of clicks).

Prior: \(\text{Gamma}(\alpha, \beta)\)
Data: \(n\) observations with sum \(\sum x_i\) from Poisson \(\text{Pois}(\lambda)\)
Posterior: \(\text{Gamma}(\alpha + \sum x_i, \beta + n)\)

It's like a scoreboard: You add the "total events" you've seen to \(\alpha\), and the "total time" that passed to \(\beta\).

2. The Gamma-Exponential Pair

Use this when your data consists of Wait Times (e.g., time between server failures).

Prior: \(\text{Gamma}(\alpha, \beta)\)
Data: \(n\) samples from \(\text{Exp}(\lambda)\) with sum \(S\)
Posterior: \(\text{Gamma}(\alpha + n, \beta + S)\)

3. ML Connection: Website Traffic Prediction

Systems Time Series

Bayesian Load Balancing

An AWS server needs to estimate how many requests per second it will receive (\(\lambda\)).

- Prior: Historically, the rate is \(\text{Gamma}(10, 2)\) (approx 5 req/sec). - Data: In the last minute, it received 200 requests. - Update: The posterior immediately shifts to \(\text{Gamma}(210, 62)\).

Because this update is a simple Add (\(10 + 200\) and \(2 + 60\)), the server can update its belief about traffic in microseconds without complex retraining. This allows the system to auto-scale dynamically based on the most recent, statistically-backed posterior.

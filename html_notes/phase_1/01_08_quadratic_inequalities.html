8. Quadratic Inequalities & Margins

Solving \( ax^2 + bx + c > 0 \). Understanding "Safe Zones" in AI.

1. BASICS

1. The "Cut Points" Method

To solve \( x^2 - 5x + 6 > 0 \), we don't just guess numbers. We use the Roots as boundary markers.

  1. Find Roots: Solve \( x^2 - 5x + 6 = 0 \) → \( (x-2)(x-3) = 0 \). Roots are 2 and 3.
  2. Test Regions: The number line is cut into 3 pieces: \( (-\infty, 2) \), \( (2, 3) \), \( (3, \infty) \).
  3. Check Sign: Plug in a test point for each. e.g., \( x=0 \rightarrow 6 > 0 \) (True).
2. AI CONTEXT

2. The Margin Loss

In AI, we often don't just want the "Right Answer" to be bigger than the "Wrong Answer". We want it to be bigger by a specific Margin (a gap).

$$ Score_{correct} - Score_{wrong} > Margin $$

This is an inequality. If the condition is met (True), the Loss is 0. If it is violated (False), the Loss is positive.

AI: Triplet Loss (Face Recognition)

When training Face ID, we want:

  • Distance(Face, Same_Person) < Distance(Face, Different_Person) - Margin
  • \( ||f(A) - f(P)||^2 + \alpha < ||f(A) - f(N)||^2 \)

This is a Quadratic Inequality involving distances (squared norms).

3. CODE IMPLEMENTATION

3. Coding Margin Ranking Loss

PyTorch has this inequality built-in as `nn.MarginRankingLoss`.

// PyTorch: Enforcing Inequalities
import torch
import torch.nn as nn

# Loss Function: max(0, -y * (x1 - x2) + margin)
criterion = nn.MarginRankingLoss(margin=1.0)

# Scores for two items
score_good = torch.tensor([5.0], requires_grad=True) # High Score
score_bad = torch.tensor([4.2], requires_grad=True)  # Slightly lower score

# Target: 1 means score_good SHOULD be > score_bad
target = torch.tensor([1.0])

# Calculate Loss
# Difference is 0.8. Margin is 1.0.
# Inequality Failed! Gap (0.8) is less than Margin (1.0).
loss = criterion(score_good, score_bad, target)

loss.backward()

print(f"Loss: {loss.item()}") 
# Output: 0.2 (The extra amount needed to reach margin)

Why use Margins?

If we just required \( > 0 \), the model might output `5.000001` vs `5.0`. This is technically correct but "fragile". By enforcing a quadratic margin, we ensure the model is Confident and Robust to noise.

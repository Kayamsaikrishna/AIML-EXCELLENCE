1. What is Rank?

The Rank of a matrix is the dimension of its Column Space (which equals the dimension of its Row Space).

$$ \text{rank}(A) \le \min(m, n) $$

If Rank < min(m, n), the matrix is "Rank Deficient" (Singular). It squashes space.

2. Recommender Systems

The Netflix Prize was solved using Matrix Factorization. We assume the "User-Movie" rating matrix is Low Rank.

Why? Because a user's taste isn't random; it depends on just a few latent factors (Action vs Romance, Budget, etc.).

$$ R \approx U \cdot V^T $$

where \( U \) and \( V \) are thin matrices (Rank \( k \)). This fills in the missing ratings!

3. Image Compression (SVD)

Approximating an image with a low-rank matrix.

import numpy as np
import matplotlib.pyplot as plt

# A 4x4 Image (Simple Gradient)
img = np.array([
    [10, 20, 30, 40],
    [10, 20, 30, 40],
    [50, 60, 70, 80],
    [50, 60, 70, 80]
])

# Calculate Rank
rank = np.linalg.matrix_rank(img)
print(f"Original Rank: {rank}")
# Result: 2. (Rows 1&2 are same, Rows 3&4 are same).

# SVD (Singular Value Decomposition)
U, S, Vt = np.linalg.svd(img)

print(f"Singular Values: {S}")
# Only first 2 are non-zero.

# Reconstruct using ONLY Rank 1 (Most info)
img_approx = S[0] * np.outer(U[:, 0], Vt[0, :])

print("\nRank 1 Approximation:")
print(img_approx)
# Captures the main light/dark split but loses detail.

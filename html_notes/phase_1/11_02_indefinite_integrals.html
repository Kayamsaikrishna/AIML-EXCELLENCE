Calculus 1.4 Notation

Indefinite Integrals

The formal language of addition.

The "S" stands for Sum

The integral symbol \(\int\) is literally a stretched-out "S" because integration is fundamentally about summing up infinite tiny pieces to recover the whole.

1. Notation Decomposition

\[ \int f(x) dx = F(x) + C \]

  • \(\int\) Integral Sign: The command to integrate.
  • \(f(x)\) Integrand: The function we are summing/integrating.
  • \(dx\) Differential: Indicates the variable of integration (and represents the tiny width).
  • \(F(x)\) Primitive: The resulting function.
  • \(C\) Constant: The shift parameter.

2. AI/ML Connection: Continuous Expectation

Integrating Probability

In discrete math, the expected value (average) is a sum: \( E[X] = \sum x \cdot P(x) \).

In AI, most variables (weights, activations, pixel values) are treated as continuous. So the sum becomes an Integral: \[ E[X] = \int_{-\infty}^{\infty} x \cdot p(x) dx \]

When Variational Autoencoders (VAEs) calculate the "KL-Divergence" loss, they are evaluating an integral of probability distributions to see how different the generated image is from the real distribution.

3. Python: Solving Integrals

solve_integral.py
import sympy as sp

x = sp.Symbol('x')

# Standard Polynomials
expr1 = x**2 + 5*x + 1
sol1 = sp.integrate(expr1, x)
print(f"Int({expr1}) = {sol1} + C")

# Exponential Functions (Crucial for Softmax/Sigmoid math)
expr2 = sp.exp(2*x)
sol2 = sp.integrate(expr2, x)
print(f"Int({expr2}) = {sol2} + C") 
# Result: exp(2x)/2. Note the division by the inner derivative (Reverse Chain Rule).

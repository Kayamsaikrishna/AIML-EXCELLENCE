1. The Reversal Rule

The most important property to remember is that the transpose of a product reverses the order.

$$ (AB)^T = B^T A^T $$

Think "Shoes and Socks": You put on socks ($A$) then shoes ($B$). To take them off (Transpose/Inverse), you must take off shoes ($B^T$) then socks ($A^T$).

2. Backpropagation

When calculating gradients of a Neural Network layer \( Y = ZW + b \), we need the derivative with respect to $W$.

$$ \frac{\partial L}{\partial W} = Z^T \frac{\partial L}{\partial Y} $$

We systematically use the transpose to match the dimensions so gradients can be subtracted from weights. Without this rule, the shapes wouldn't align!

3. Verification

Proving the rule computationally.

import numpy as np

A = np.random.rand(2, 3)
B = np.random.rand(3, 4)

# LHS: (AB)^T
AB = np.dot(A, B)
LHS = AB.T

# RHS: B^T A^T
RHS = np.dot(B.T, A.T)

print(f"LHS Shape: {LHS.shape}")
print(f"RHS Shape: {RHS.shape}")

are_equal = np.allclose(LHS, RHS)
print(f"\nEquality Hold? {are_equal}")

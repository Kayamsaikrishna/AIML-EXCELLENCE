07. Transpose & Properties

Flipping the grid for cross-dimensional analysis.

1. What is a Transpose?

The transpose of a matrix \( \mathbf{A} \), denoted \( \mathbf{A}^T \), is formed by swapping rows with columns.

$$ (A^T)_{ij} = A_{ji} $$

Key Properties

  • \( (\mathbf{A}^T)^T = \mathbf{A} \).
  • \( (\mathbf{A} + \mathbf{B})^T = \mathbf{A}^T + \mathbf{B}^T \).
  • The Shoe-Sock Rule: \( (\mathbf{AB})^T = \mathbf{B}^T\mathbf{A}^T \). (Order is reversed!)

2. The Backbone of Backpropagation

Weight Updates

During neural network training, to calculate how much to change a weight matrix \( \mathbf{W} \), we multiply the input activations \( \mathbf{X} \) by the error gradient \( \delta \). Because of dimension alignment, we MUST use the transpose:

$$ \Delta \mathbf{W} = \mathbf{X}^T \delta \quad \text{or} \quad \delta \cdot \mathbf{W}^T $$
  • Feature Dot Products: \( \mathbf{X}\mathbf{X}^T \) creates a Covariance matrix (similarity between samples).
  • Gram Matrix: \( \mathbf{A}^T\mathbf{A} \). Used in Style Transfer to capture textures.

3. Python: Numpy Transpose

import numpy as np

A = np.array([[1, 2, 3], [4, 5, 6]]) # 2x3

A_T = A.T # 3x2

print(f"Original:\n{A}")
print(f"Transpose:\n{A_T}")

# Verify Shoe-Sock Rule
B = np.random.rand(3, 2)
left_side = (A @ B).T
right_side = B.T @ A.T
print(f"Equality check: {np.allclose(left_side, right_side)}")

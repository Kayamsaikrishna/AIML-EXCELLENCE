Power Iteration

\( x_{k+1} = A x_k \). How Google finds the most important website in the world.

1. The Algorithm

To find the eigenvector corresponding to the largest eigenvalue \( |\lambda_1| > |\lambda_2| \dots \):

  1. Start with random \( b_0 \).
  2. Iterate: \( b_{k+1} = \frac{A b_k}{||A b_k||} \).
  3. Converges to \( v_1 \).

2. PageRank

The entire web can be modeled as a Markov Chain transition matrix \( M \).

The "Importance" of websites is simply the Principal Eigenvector of \( M \). Since the web has billions of pages, direct diagonalization is impossible. Power Iteration (simulating a random surfer) is the only scalable way to solve it.

3. Implementing PageRank (Toy Example)

import numpy as np

def power_iteration(A, num_simulations=10):
    # Ideally choose a random vector
    # To decrease the chance that it is orthogonal to the eigenvector
    b_k = np.random.rand(A.shape[1])

    for _ in range(num_simulations):
        # calculate the matrix-by-vector product Ab
        b_k1 = np.dot(A, b_k)

        # calculate the norm
        b_k1_norm = np.linalg.norm(b_k1)

        # re normalize the vector
        b_k = b_k1 / b_k1_norm

    # Rayleigh Quotient to find Lambda
    mu = np.dot(b_k.T, np.dot(A, b_k)) / np.dot(b_k.T, b_k)
    return b_k, mu

# Matrix A
A = np.array([
    [0.5, 0.5],
    [0.2, 0.8]
])

eigenvec, eigenval = power_iteration(A, 50)
print(f"Dominant Eigenvalue: {eigenval:.4f}")
print(f"Dominant Eigenvector: {eigenvec.round(4)}")

# Verify with NumPy
vals, vecs = np.linalg.eig(A)
print(f"NumPy Max Val: {np.max(vals)}")

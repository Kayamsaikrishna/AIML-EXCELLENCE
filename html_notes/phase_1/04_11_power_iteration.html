11. Power Iteration Method

The scalable way to find the dominant eigenvector.

1. The Problem: Matrices are too big

For a matrix like the Google Link Graph (billions of nodes), we cannot compute \(\det(\mathbf{A} - \lambda\mathbf{I}) = 0\). Instead, we use an iterative approach that only requires matrix-vector multiplication.

2. The Algorithm

  1. Start with a random vector \(\mathbf{b}_0\).
  2. Repeatedly multiply by \(\mathbf{A}\): \(\mathbf{b}_{k+1} = \frac{\mathbf{A}\mathbf{b}_k}{||\mathbf{A}\mathbf{b}_k||}\).

As \(k \to \infty\), \(\mathbf{b}_k\) converges to the eigenvector associated with the largest eigenvalue (\(\lambda_{max}\)).

$$ \mathbf{b}_k \approx \mathbf{v}_1 $$

3. Why it works

Any random vector can be written as a linear combination of eigenvectors. When we multiply by \(\mathbf{A}\) repeatedly, the component along the largest eigen-direction grows geometrically faster than all other components (\(\lambda_1^k \gg \lambda_2^k\)).

4. Python: Dominant Eigen Discovery

import numpy as np

def power_iteration(A, num_simulations: int):
    # Random initial vector
    b_k = np.random.rand(A.shape[1])

    for _ in range(num_simulations):
        # Calculate the matrix-by-vector product
        b_k1 = np.dot(A, b_k)

        # Re-normalize
        b_k = b_k1 / np.linalg.norm(b_k1)

    return b_k

A = np.array([[0.5, 0.5], [0.2, 0.8]])
v1 = power_iteration(A, 100)

print(f"Largest Eigenvector estimate:\n{v1}")
# Verify with linalg.eig
vals, vecs = np.linalg.eig(A)
print(f"Actual Principal Vector:\n{vecs[:, np.argmax(vals)]}")

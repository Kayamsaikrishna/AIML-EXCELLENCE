Module 01_08

Graphing & Visualization

Visualizing data distributions. Before you model data, you must see it.

19. Linear

19. Graphing Linear Functions

$$ y = mx + b $$

AI: Learning Rates

The slope \(m\) represents the Rate of Change. In Stochastic Gradient Descent (SGD), the rate at which we descend is often linear with respect to the gradient vector.

20. Quadratic

20. Graphing Quadratic Functions (Parabolas)

$$ y = ax^2 + bx + c $$

AI: Convexity

If \(a > 0\), the parabola opens UP (Smile). This is a Convex function. Convex functions are easy to optimize because they have a single global minimum.

If \(a < 0\), the parabola opens DOWN (Frown). This is Concave.

21. Polynomial

21. Graphing Polynomial Functions

$$ y = x^3 - 4x $$

AI: Overfitting

High-degree polynomials wiggle a lot. If you try to fit a 10th-degree polynomial to 5 data points, it will pass through them perfectly but wiggle wildly in between.

This "Wiggle" is High Variance (Overfitting).

22. Rational

22. Graphing Rational Functions

Asymptotes where denominator is zero.

These represent Singularities in the data manifold.

23. Exp/Log

23. Graphing Exponential & Logarithmic Functions

Exponential ($e^x$)

Explodes to infinity. This is why loss values can become "NaN" (Not a Number) if not clipped.

Logarithmic ($\ln x$)

Grows very slowly. We use this to dampen outliers. If you have "Income" data (ranging from $0 to $1B), taking the log compresses the range to something manageable.

Optimization 1.7 Second Order

Newton's Method (Multi-Dim)

Using curvature to accelerate convergence.

The Hessian Update

Gradient Descent is "dumb"—it only knows the slope. Newton's Method is "smart"—it uses the Curvature (Hessian Matrix) to perfectly jump to the minimum of a quadratic bowl in one step.

$$ \mathbf{w}_{t+1} = \mathbf{w}_t - \mathbf{H}^{-1} \nabla f(\mathbf{w}_t) $$

2. AI/ML Connection: The Memory Wall

Why not in Deep Learning?

If Newton's Method is so much better, why don't we use it? Simply put: Calculating the Inverse Hessian is impossible for large networks.

  • If \(N=1,000,000\) weights (a tiny network), \(\mathbf{H}\) has \(10^{12}\) entries.
  • Storing it requires 4000 Terabytes of RAM.
  • Inverting it takes \(O(N^3)\) operations.

This is why we use Quasi-Newton Methods (like L-BFGS) or adaptive gradient methods (like Adam) which approximate the *diagonal* of the Hessian without storing the full matrix.

3. Python: Convergence Test

newton_convergence.py
import numpy as np

# f(x) = x^4 - 2x^2 + 2
# f'(x) = 4x^3 - 4x
# f''(x) = 12x^2 - 4

def newton_opt(start_x, steps=5):
    x = start_x
    for i in range(steps):
        grad = 4*x**3 - 4*x
        hess = 12*x**2 - 4
        
        # Newtons Update
        x = x - grad / hess
        print(f"Step {i}: x={x:.6f}")
    return x

print("Newton starting at 2.0:")
newton_opt(2.0)
# Converges to 1.0 (minimum) in ~4 steps. Extremely fast.

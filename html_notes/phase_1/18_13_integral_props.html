13. Properties of Definite Integrals

Efficient manipulation of area logic.

1. Core Algebraic Properties

  • Lineary: \(\int [kf(x) + lg(x)] dx = k\int f(x) + l\int g(x)\)
  • Order: \(\int_{a}^{b} f(x) dx = -\int_{b}^{a} f(x) dx\)
  • Zero Width: \(\int_{a}^{a} f(x) dx = 0\)

2. Splitting Intervals & Symmetry

Additivity: \(\int_{a}^{c} f(x) dx = \int_{a}^{b} f(x) dx + \int_{b}^{c} f(x) dx\).

Symmetry: If \(f\) is even (\(f(-x) = f(x)\)) on \([-a, a]\), the area is \(2\int_{0}^{a} f(x) dx\). If odd, the total signed area is 0.

3. AI/ML Connection: Distributed Summation

MapReduce & Data Sharding

Large AI models (like Llama-3) are trained on trillions of tokens. No single machine can process this. The Additivity property is used to split the training integral (the total loss over the dataset) into thousands of "shards".

Each machine independently integrates a chunk of the data (\(\int_{a}^{b}, \int_{b}^{c} \dots\)). Because of these calculus properties, we can simply add the results together at the end (a Reduce operation) to get the correct global state. This linearity property is what makes scalable AI training mathematically valid.

4. Python: Properties Verification

import sympy as sp
x = sp.Symbol('x')
f = x**2

# Show that int(0,2) = int(0,1) + int(1,2)
area_0_2 = sp.integrate(f, (x, 0, 2))
area_0_1 = sp.integrate(f, (x, 0, 1))
area_1_2 = sp.integrate(f, (x, 1, 2))

print(f"Full Area (0->2): {area_0_2}")
print(f"Sum of parts: {area_0_1 + area_1_2}")
print(f"Property holds: {area_0_1 + area_1_2 == area_0_2}")

14. Vector-Valued Random Variables

Treating a group of variables as a single mathematical object.

1. Definition

A Random Vector $\mathbf{X}$ is a list whose components are random variables. If $X_1, X_2, \dots, X_n$ are random variables defined on the same sample space, then:

$$ \mathbf{X} = \begin{bmatrix} X_1 \\ X_2 \\ \vdots \\ X_n \end{bmatrix} $$

The **Expected Value** of a random vector is simply the vector of the expected values of its components: $E[\mathbf{X}] = [E[X_1], E[X_2], \dots, E[X_n]]^T$.

2. The Joint View

Working with random vectors allows us to use Linear Algebra to solve probability problems. Transformations that would require pages of integrals for individual variables (like rotating a dataset) can be represented as a simple matrix multiplication: $\mathbf{Y} = \mathbf{A}\mathbf{X} + \mathbf{b}$.

3. AI/ML Connection: Embeddings and Representations

The "Latent" Meaning

In AI, every piece of data is treated as a Sample from a Random Vector.

In **Natural Language Processing**, a word is represented as an Embedding Vector (e.g., in a 768-dimensional space). We treat this embedding as a vector-valued random variable. The AI's job is to learn the joint distribution of these dimensions so it can differentiate "King" from "Queen." In **Deep Learning Layers**, the "Hidden State" is a random vector. By treating them as vectors, we can calculate the Jacobian Matrix of the transformation, which is the foundation of the Backpropagation algorithm. Understanding random vectors is the bridge between "Scalar" probability and the "Matrix" reality of modern AI.

4. Python: Vector Operations

import numpy as np

# A random vector sample (e.g., a 3D embedding)
x_vec = np.random.randn(3, 1)

# Linear transformation (Matrix multiplication)
A = np.array([[1, 2, 0], [0, 1, 1], [1, 0, 1]])
b = np.array([[1], [1], [1]])

y_vec = A @ x_vec + b

print(f"Original Vector:\n{x_vec}")
print(f"Transformed Vector:\n{y_vec}")

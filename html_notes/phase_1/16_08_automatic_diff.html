ML Calc 1.9 The Magic

Automatic Differentiation (Autodiff)

Neither Symbolic nor Numeric. It's Computational.

The Third Way

We know two ways to get derivatives: 1. Symbolic: (Mathematica/SymPy) Manipulate formulas. Gets incredibly messy with loops and branches. 2. Numeric: (Finite Diff) Approximate with \(h\). Slow and inaccurate.

Autodiff is the technique used by PyTorch and TensorFlow. It tracks every operation (add, multiply, sin) performed on a variable and builds a tape. Then, it replays the tape backwards to compute exact gradients using the Chain Rule. It supports if-statements, loops, and recursion natively.

2. ML Connection: Forward vs Reverse Mode

Reverse Mode is King

Forward Mode computes gradients w.r.t one input at a time. Good if Inputs << Outputs. Reverse Mode (Backprop) computes gradients w.r.t all inputs in one go. Good if Inputs >> Outputs.

Since Neural Networks map millions of inputs (pixels/weights) to 1 output (Loss), **Reverse Mode Autodiff** is the only viable option.

3. Python: PyTorch Autodiff

autograd_demo.py
import torch

# Create a tensor and say "Watch this"
x = torch.tensor(3.0, requires_grad=True)
w = torch.tensor(2.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)

# Define computational graph
y = w * x + b
loss = y ** 2

# Calculating gradients is magical
loss.backward()

# dLoss/dw = 2*y * x = 2*(7)*3 = 42
print(f"dL/dw: {w.grad}") 
print(f"dL/db: {b.grad}")
print(f"dL/dx: {x.grad}")
# Exact values, no approximation.

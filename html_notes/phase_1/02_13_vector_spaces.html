1. What Makes a "Space"?

A set of objects is a Vector Space if you can add them and scale them, and the result stays in the set.

  • Closure: If \( u, v \in V \), then \( u+v \in V \).
  • Zero Vector: There must be a "neutral" element \( \mathbf{0} \) (e.g., the function \( f(x)=0 \)).

Example: The set of all continuous functions \( C[0, 1] \) is a vector space. If you add two continuous functions, the result is continuous.

2. Hilbert Spaces (Infinite Dimensions)

In Machine Learning, we often map data into "Infinite Dimensional" spaces (RKHS - Reproducing Kernel Hilbert Spaces).

We treat Functions as vectors. The "Dot Product" becomes an Integral:

$$ \langle f, g \rangle = \int f(x)g(x) dx $$

This allows us to do geometry (angles, distances) on complicated curves.

3. Functions as Vectors

Demonstrating linearity with Python functions.

import numpy as np
import matplotlib.pyplot as plt

# Define "Vector" objects as Python Functions
f = np.sin
g = np.cos
alpha = 2.0
beta = 3.0

# Linear Combination: h(x) = 2sin(x) + 3cos(x)
def h(x):
    return alpha * f(x) + beta * g(x)

# Visualize over a domain (Discretized Vector)
x = np.linspace(0, 2*np.pi, 100)
y = h(x)

# Check a point
x0 = np.pi/4
val = alpha * np.sin(x0) + beta * np.cos(x0) # 2(0.707) + 3(0.707) = 3.535
print(f"h({x0:.2f}) = {h(x0):.4f}")
print(f"Expected: {val:.4f}")

1. Functions as Mappings

A function is a rule that assigns exactly one output to every input.

$$ f: X \rightarrow Y $$

Domain & Codomain in AI

  • Domain (Input): Your data space (e.g., \( \mathbb{R}^{784} \) for MNIST images).
  • Codomain (Output): Your label space (e.g., \( \mathbb{R}^{10} \) probabilities).
  • Range (Image): The actual outputs the model produces.

2. The Manifold Hypothesis

Real-world data (like faces) isn't scattered randomly in high-dimensional space. It lives on a lower-dimensional surface called a Manifold.

The goal of a Deep Neural Network is to function as a Diffeomorphism (a smooth, invertible mapping) that "unfolds" this crumpled manifold so the classes become linearly separable.

3. Functions in Python

Even simple functions can be visualized as warps.

import numpy as np

def relu(x):
    # The most popular AI function
    # Maps negatives to 0, positives stay same
    return np.maximum(0, x)

def linear_transform(x, W, b):
    # Affine Mapping: Rotate/Scale + Shift
    return np.dot(x, W) + b

# Input Vector (2D point)
x = np.array([1.0, 2.0])

# Transformation Matrix (Rotation/Scale)
W = np.array([[2.0, 0.0],  # Scale x by 2
              [0.0, 0.5]]) # Scale y by 0.5

# Bias (Shift)
b = np.array([1.0, 1.0])

y = linear_transform(x, W, b)
z = relu(y)

print(f"Input: {x}")
print(f"After Linear Map: {y}")
print(f"After Activation (ReLU): {z}")

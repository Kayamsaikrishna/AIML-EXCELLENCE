Functions: The Black Boxes

A function is just a machine: inputs go in, outputs come out. Neural Networks are just massive, composite functions.

1. Domain & Range

Domain (Valid Inputs)

The set of all possible \(x\) values. In AI, this is your Input Space (e.g., all valid RGB pixel values [0-255]).

Range (Valid Outputs)

The set of all possible \(y\) values. In AI, this is your Output Space.

Example: A `Sigmoid` activation function squashes the range to \((0, 1)\). A `ReLU` function restricts the range to \([0, \infty)\).

2. Function Composition

$$ (f \circ g)(x) = f(g(x)) $$

Deep Learning IS Composition

Why do we call it "Deep" Learning? Because we compose many functions layers deep.

$$ y = f_3(f_2(f_1(x))) $$

If \(f_1\) detects edges, \(f_2\) detects shapes, and \(f_3\) detects faces, the composition allows us to map Pixels -> Faces.

// PyTorch: nn.Sequential is Function Composition 
# Model = f3( f2( f1(x) ) )
model = nn.Sequential(
    nn.Linear(784, 128),  # f1
    nn.ReLU(),            # g1 (Non-linearity)
    nn.Linear(128, 64),   # f2
    nn.ReLU(),            # g2
    nn.Linear(64, 10)     # f3
)

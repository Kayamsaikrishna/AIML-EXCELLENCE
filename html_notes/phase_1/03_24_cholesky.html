1. Definition

If \( A \) is Symmetric (\( A=A^T \)) and Positive Definite (\( x^T Ax > 0 \)), it has a unique decomposition:

$$ A = L L^T $$

This is often called the "Square Root" of a matrix. It only requires storing \( L \) (half the memory of LU) and is computationally cheaper.

2. Covariance Matrices

Covariance matrices are always Symmetric Positive Semi-Definite.

In Gaussian Processes and Kalman Filters, we use Cholesky to generate correlated random samples. If \( \mathbf{z} \sim N(0, I) \), then \( L \mathbf{z} \sim N(0, \Sigma) \), where \( \Sigma = LL^T \).

3. Sampling Noise

Generating correlated data using Cholesky.

import numpy as np

# A valid Covariance Matrix (Symmetric, Positive Definite)
Sigma = np.array([
    [2.0, 1.0],
    [1.0, 2.0]
])

# Compute Cholesky L
L = np.linalg.cholesky(Sigma)
print("Cholesky L:")
print(L)

# Generate uncorrelated white noise
noise = np.random.randn(2, 5000)

# Transform to correlated noise
correlated = L @ noise

# Check empirical covariance
emp_cov = np.cov(correlated)
print("\nEmpirical Covariance (Should match Sigma):")
print(emp_cov.round(1))

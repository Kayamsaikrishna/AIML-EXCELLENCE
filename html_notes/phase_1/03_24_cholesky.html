24. Cholesky Decomposition

The fastest square root for matrices.

1. The Factorization

If a matrix \( \mathbf{A} \) is Symmetric and Positive-Definite, it can be factored into a lower triangular matrix \( \mathbf{L} \) times its transpose.

$$ \mathbf{A} = \mathbf{LL}^T $$

This is roughly twice as fast as LU decomposition because it exploits the symmetry of the matrix.

2. Sampling from Gaussians

The Kernel of Variational Autoencoders (VAEs)

In Gaussian Processes or VAEs, we need to sample from a Multivariate Normal distribution \( \mathcal{N}(0, \Sigma) \). Computers can only sample from a standard normal \( \mathbf{z} \sim \mathcal{N}(0, \mathbf{I}) \). To make it follow the target covariance \( \Sigma \), we use the Cholesky factor \( \mathbf{L} \):

$$ \mathbf{x} = \mathbf{L}\mathbf{z} $$

Since \( \text{Cov}(\mathbf{Lz}) = \mathbf{L}\mathbf{I}\mathbf{L}^T = \mathbf{LL}^T = \Sigma \). This is the Reparameterization Trick.

3. Python: Multivariate Sampling

import numpy as np

# Covariance Matrix (Must be positive definite)
Sigma = np.array([[2, 1], [1, 2]])

# 1. Cholesky
L = np.linalg.cholesky(Sigma)

# 2. Sample from Standard Normal
z = np.random.randn(2, 5000)

# 3. Transform
x = L @ z

print(f"Empirical Covariance:\n{np.cov(x)}")
print(f"Target Sigma:\n{Sigma}")

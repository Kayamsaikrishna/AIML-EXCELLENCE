22. LU Decomposition

Optimization through triangularization.

1. The Factorization

LU decomposition factors a square matrix \( \mathbf{A} \) into the product of a Lower Triangular matrix \( \mathbf{L} \) and an Upper Triangular matrix \( \mathbf{U} \).

$$ \mathbf{A} = \mathbf{LU} $$

If row swapping is required (for stability), the form is \( \mathbf{PA} = \mathbf{LU} \), where \( \mathbf{P} \) is a permutation matrix.

2. Why LU is faster for AI Inference

Solving AX = B is now trivial

  1. Solve \( \mathbf{Ly} = \mathbf{b} \) using Forward Substitution.
  2. Solve \( \mathbf{Ux} = \mathbf{y} \) using Backward Substitution.

Once \( \mathbf{L} \) and \( \mathbf{U} \) are pre-computed, solving for a new batch \( \mathbf{b} \) takes only \( O(n^2) \) time instead of \( O(n^3) \).

  • Real-time Physics: Deterministic environment solvers in simulators use LU.
  • Determinant Calculation: Just multiply the diagonal of U!

3. Python: LU Solve

import numpy as np
from scipy.linalg import lu_factor, lu_solve

A = np.array([[2, 5, 8], [5, 2, 2], [7, 5, 6]])
b = np.array([1, 1, 1])

# 1. Pre-factorize
lu_piv = lu_factor(A)

# 2. Solve for b
x = lu_solve(lu_piv, b)

print(f"Solution x: {x}")
print(f"Residual: {np.linalg.norm(A @ x - b)}")

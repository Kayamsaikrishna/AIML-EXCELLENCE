10. Polynomial Division & The Residual

Breaking down complexity. From Long Division to ResNets and CRCs.

1. The Algorithm

Division is finding how many times one signal "fits" into another, and what is left over.

$$ \underbrace{P(x)}_{\text{Dividend}} = \underbrace{D(x)}_{\text{Divisor}} \cdot \underbrace{Q(x)}_{\text{Quotient}} + \underbrace{R(x)}_{\text{Remainder}} $$

Engineering Application: CRC Checks

When you download a file, your computer performs Poly Division (over binary fields). The file is a massive polynomial. The "Checksum" is the Remainder.

If the calculated remainder doesn't match the sent remainder, the file is corrupted.

2. The Residual Connection (ResNet)

In Deep Learning, we realized that trying to learn a completely new function \( H(x) \) is hard. Instead, we try to learn the Remainder (Residual).

$$ y = x + F(x) $$

Here, \( F(x) \) is learning "what is missing" from \( x \) to get to the answer. It is effectively learning the remainder function.

Figure 1: A ResNet Block. The skip connection passes \( x \) (like a divisor), and the layers learn to add a "Remainder" \( F(x) \) to refine it.

3. Coding Divisibility

We use Numpy to handle polynomial coefficients.

// Numpy: Polynomial Operations
import numpy as np

# P(x) = x^2 - 5x + 6 (Roots are 2, 3)
# Represented as [1, -5, 6]
P = np.array([1, -5, 6])

# D(x) = x - 2
D = np.array([1, -2])

# Divide P(x) / D(x)
quotient, remainder = np.polydiv(P, D)

print(f"Quotient: {quotient}")  # Output: [1, -3] -> (x - 3)
print(f"Remainder: {remainder}") # Output: [0] -> Evaluates to 0

# If remainder is 0, then D(x) is a Factor of P(x).
# This confirms the Factor Theorem!

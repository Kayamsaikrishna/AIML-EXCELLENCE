1. Grid vs Radar

Instead of walking logical blocks (x then y), we define a point by distance and direction.

$$ x = r \cos \theta, \quad y = r \sin \theta $$

Calculus Shift: \( dx dy \) becomes \( r dr d\theta \). The factor \( r \) (Jacobian) is critical for integrating Gaussians.

2. Radial Basis Functions

In data sets like the "Two Circles" (donals), a linear classifier fails completely. But if we switch to Polar Coordinates \((r, \theta)\), the circles become straight lines!

The RBF Kernel (Gaussian Kernel) in SVMs measures similarity based purely on radial distance:

$$ K(x, y) = \exp(-\gamma \|x - y\|^2) $$

This is a "Polar" way of thinking embedded in high-dimensional space.

3. The Kernel Trick Visualization

Transforming circular data to make it linearly separable.

import numpy as np

# Data: Points on two rings
# Class A: r ~ 5
# Class B: r ~ 10

# Point from Class A
x_cart = np.array([3.0, 4.0]) # r=5

# Transform to Polar
r = np.linalg.norm(x_cart)
theta = np.arctan2(x_cart[1], x_cart[0])

print(f"Cartesian: {x_cart}")
print(f"Polar Feature [r]: {r}")

# Decision Boundary:
if r < 7.5:
    print("Prediction: Inner Circle (Class A)")
else:
    print("Prediction: Outer Circle (Class B)")

# In (x,y) space, the boundary is a circle (x^2+y^2 < 7.5^2).
# In (r) space, the boundary is a simple line (r < 7.5).

Stats 1.7 Binary Classification

Logistic Regression

Predicting the probability of an event happening. The "S-Curve" that powers everything from Spam filters to Ad-clicks.

Regression for Labels

"Regression" is in the name, but it's used for Classification.

Why? Because it first calculates a continuous score (Log-Odds) and then maps it to a probability between 0 and 1 using the Sigmoid Function.

1. The Sigmoid Function

$$ P(Y=1) = \sigma(z) = \frac{1}{1 + e^{-z}} $$ $$ \text{where } z = \beta_0 + \beta_1 X_1 + ... + \beta_p X_p $$
- If \(z\) is very large, \(P\) approaches 1. - If \(z\) is very small (negative), \(P\) approaches 0. - If \(z = 0\), \(P = 0.5\). This is the Decision Boundary.

2. Interpretability: Log-Odds

Intuition

We don't talk about \(P\) directly in the linear part. We talk about Odds: \(\frac{P}{1-P}\).

The Slope (\(\beta_1\))

A 1-unit increase in X increases the Log-Odds by \(\beta_1\). To get the "Odds Ratio", we use \(e^{\beta_1}\).

3. ML Connection: Decision Boundaries

Deep Learning Foundations

The simplest Neural Network

A Logistic Regression is exactly the same thing as a **Perceptron with a Sigmoid activation function and Cross-Entropy loss**.

  • Linear Decision Boundary: In its raw form, Logistic Regression can only separate classes with a straight line (Hyperplane). To handle "moons" or "xor" shapes, you need Polynomial features or Neural Networks.
  • Calibration: Unlike SVMs, Logistic Regression gives you **well-calibrated probabilities**. If the model says 0.8 probability, it actually means 8 out of 10 similar cases will be positive. This is crucial for medical and financial risk modeling.
Engineer's Fact: Logistic Regression doesn't have a closed-form solution like OLS. We use Maximum Likelihood Estimation (MLE) and solve it using Gradient Descent or Newton's Method.

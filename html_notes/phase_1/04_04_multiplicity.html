Alg vs Geo Multiplicity

Not all eigenvalues are created equal. When \( \text{Geo} < \text{Alg} \), things break.

1. Definitions

  • Algebraic Multiplicity (AM): How many times \( \lambda \) appears as a root of the characteristic polynomial. (e.g., \((\lambda - 2)^3 \implies \text{AM}=3\)).
  • Geometric Multiplicity (GM): The dimension of the eigenspace required for that \( \lambda \). How many independent eigenvectors exist.

Rule: \( 1 \leq \text{GM} \leq \text{AM} \). If \( \text{GM} < \text{AM} \), the matrix is Defective.

2. Mode Collapse

In Physics and Data Science, repeated eigenvalues usually imply Symmetry (e.g., a sphere has the same width in x, y, z).

A defective matrix implies a "shear" structure that cannot be purely decoupled. This is rare in random data but common in designed systems (control loops).

3. Spotting the Defect

import numpy as np
from sympy import Matrix

# A defective matrix (Shear)
# [2 1]
# [0 2]
A = Matrix([
    [2, 1],
    [0, 2]
])

eigenvals = A.eigenvals()
print(f"Eigenvalues (Root:Count): {eigenvals}")
# {2: 2} -> Alg Multiplicity is 2

eigenvects = A.eigenvects()
# Returns [(lambda, AlgMult, [vectors])]
root, alg_mult, vectors = eigenvects[0]

geo_mult = len(vectors)

print(f"Algebraic Multiplicity: {alg_mult}")
print(f"Geometric Multiplicity: {geo_mult}")

if geo_mult < alg_mult:
    print("Matrix is DEFECTIVE (Non-diagonalizable)")

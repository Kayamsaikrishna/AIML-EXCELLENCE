ML Calc 1.9 Backprop Core

The Neural Chain Rule

Propagating blame backwards through layers.

Nested Functions

A Neural Network is just a massive composite function: \[ y = f_3(f_2(f_1(x))) \]

To find how the output changes w.r.t input (or weights), we multiply the derivatives of each layer: \[ \frac{dy}{dx} = f_3' \cdot f_2' \cdot f_1' \] This multiplication of gradients is Backpropagation.

2. ML Connection: Vanishing Gradients

Multiplying Small Numbers

If we have a deep network (100 layers), we multiply 100 derivatives. If these derivatives are small (e.g., Sigmoid max deriv is 0.25), then \(0.25^{100} \approx 0\).

The gradient vanishes, and the front layers stop learning. This is why ReLU (deriv = 1) and Residual Connections (addition instead of mult) were invented.

3. Python: Manual Backprop

chain_rule.py
# Simple Chain: z = f(y), y = g(x) -> z = (3x + 1)^2
# x=2
x = 2.0

# Forward
y = 3 * x + 1  # y = 7
z = y ** 2     # z = 49

# Backward
dz_dy = 2 * y      # 14
dy_dx = 3          # 3

dz_dx = dz_dy * dy_dx # 14 * 3 = 42

print(f"Gradient at x=2: {dz_dx}")

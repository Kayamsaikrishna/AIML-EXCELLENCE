03. Partial Derivatives

Wiggling one variables at a time.

1. The Logic of "Holding Constant"

A partial derivative measures how the function changes with respect to one specific variable, while all other variables are treated as constants.

$$ f_x(x, y) = \frac{\partial f}{\partial x} \quad \text{(y is constant)} $$ $$ f_y(x, y) = \frac{\partial f}{\partial y} \quad \text{(x is constant)} $$

Geometrically, a partial derivative represents the slope of a cross-section of the surface.

2. Notation

In AI research, we use the "curly d" (\(\partial\)) to distinguish partial derivatives from the total derivative (\(d\)). We also use subscript notation \(f_i\) where \(i\) is the index of the weight.

3. AI/ML Connection: The Gradient Component

Backpropagation Internals

Training an AI involves millions of weights (\(w_1, w_2, \dots w_n\)). To update them, we need to know how the Loss (\(L\)) changes if we tweak just one weight. This is exactly what a partial derivative tells us:

$$ \text{Update: } w_i \leftarrow w_i - \eta \frac{\partial L}{\partial w_i} $$

The entire field of **Auto-Differentiation** (implemented in PyTorch and TensorFlow) is essentially a massive, optimized system for calculating millions of partial derivatives per second. Every clever "learning" in an AI starts with a single partial derivative.

4. Python: Partial Differentiation with SymPy

import sympy as sp

x, y = sp.symbols('x y')
f = x**2 * y + sp.sin(x*y)

# Differentiate with respect to x (y is constant)
df_dx = sp.diff(f, x)

# Differentiate with respect to y (x is constant)
df_dy = sp.diff(f, y)

print(f"Partial w.r.t x: {df_dx}")
print(f"Partial w.r.t y: {df_dy}")

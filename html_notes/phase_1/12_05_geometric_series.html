Calculus 1.5 Standard Series

Geometric & P-Series

The "Hello World" of Infinite Sums.

The Geometric Series

A series where each term is a constant multiple \(r\) of the previous one. \[ S = a + ar + ar^2 + ar^3 + \dots = \sum_{n=0}^{\infty} ar^n \]

Convergence Rule: It converges if and only if **\(|r| < 1\)**.
Sum Formula: \( S = \frac{a}{1 - r} \)

2. AI/ML Connection: Discount Factors

Why Gamma < 1?

In Reinforcement Learning, we use a discount factor \(\gamma\) (gamma) to value future rewards. The total value is: \[ G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \]

This is a geometric series with ratio \(r = \gamma\). If \(\gamma = 1\), the agent values eternity equally, and the sum might explode (diverge). If \(\gamma < 1\) (e.g., 0.99), the sum is guaranteed to be finite (converge), allowing stable learning. The mathematical necessity of \(|r| < 1\) is why we discount the future in AI.

3. Python: Summing the Series

geometric_sum.py
# Function to calc geometric sum
def geometric_sum(a, r, n_terms):
    return sum([a * (r**i) for i in range(n_terms)])

# RL Example: Reward = 1, Discount = 0.9
a = 1
r = 0.9
true_sum = a / (1 - r) # 1 / 0.1 = 10

computed_sum = geometric_sum(a, r, 100)

print(f"Sum Formula: {true_sum}")
print(f"Computed (100 terms): {computed_sum}")
# Output: 10.0 vs 9.9997...

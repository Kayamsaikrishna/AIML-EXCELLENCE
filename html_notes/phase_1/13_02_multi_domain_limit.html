Calculus 1.6 Topology

Domain & Limits

Boundaries and Continuity in N-Dimensions.

Infinite Approaches

In 1D Calculus, a limit \( \lim_{x \to a} f(x) \) exists if left-approach equals right-approach.

In 2D (or higher), a point \((x, y)\) can approach \((a, b)\) from infinite directions: along the x-axis, y-axis, a spiral, a parabola, etc. For the limit to exist, ALL paths must yield the same value. \[ \lim_{(x,y) \to (a,b)} f(x,y) = L \]

2. AI/ML Connection: Feasible Regions

Constrained Optimization

The Domain of a function corresponds to the Feasible Region in optimization. For example, in a Recommender System, the "probability" that a user likes a movie must be between 0 and 1. The domain is restricted to \([0, 1]\).

Continuity is essential for robustness. If a slight change in input features (e.g., pixel noise) causes a massive jump in the model's output (a discontinuity), the model is brittle and vulnerable to Adversarial Attacks. We mathematically enforce continuity using activation functions like Softmax or ReLU.

3. Python: Path Testing

limit_paths.py
import numpy as np

def f(x, y):
    # Function: (x^2 - y^2) / (x^2 + y^2)
    # Undefined at (0,0)
    if x==0 and y==0: return None
    return (x**2 - y**2) / (x**2 + y**2)

# Path 1: Approach along X-axis (y=0)
lim_x = f(0.0001, 0) # (eps^2 - 0) / (eps^2 + 0) = 1

# Path 2: Approach along Y-axis (x=0)
lim_y = f(0, 0.0001) # (0 - eps^2) / (0 + eps^2) = -1

print(f"Limit along x-axis: {lim_x}")
print(f"Limit along y-axis: {lim_y}")

if lim_x != lim_y:
    print("Conclusion: Limit DOES NOT EXIST.")
else:
    print("More tests needed.")

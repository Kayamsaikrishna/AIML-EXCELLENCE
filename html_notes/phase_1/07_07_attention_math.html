1. The Formula

Self-Attention defines a dynamic weight matrix based on data similarity.

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$
  • \( Q K^T \): Computes "Angle" between every query vector and every key vector (Similarity Matrix).
  • \( \text{softmax} \): Normalizes rows to sum to 1 (Probability distribution).
  • \( \times V \): Computes expected value (weighted average) of Value vectors.

2. Context Windows

The matrix \( A = QK^T \) is size \( T \times T \) (where \( T \) is sequence length). This is why attention is \( O(T^2) \).

Each entry \( A_{ij} \) tells the model "How much should word \( i \) attend to word \( j \)?". It is essentially a dynamic adjacency matrix of a fully connected graph of tokens.

3. Self-Attention Step

import numpy as np
from scipy.special import softmax

# Dimensions
seq_len = 3
d_model = 4
d_k = 4

# Dummy Inputs (Embeddings)
X = np.random.rand(seq_len, d_model)

# Weights (Typically learned)
W_Q = np.eye(d_model)
W_K = np.eye(d_model)
W_V = np.eye(d_model)

# Projections
Q = X @ W_Q
K = X @ W_K
V = X @ W_V

# 1. Similarity Scores (Unnormalized)
scores = Q @ K.T

# 2. Scaling
scores = scores / np.sqrt(d_k)

# 3. Softmax (Row-wise)
attn_weights = softmax(scores, axis=1)

# 4. Output
output = attn_weights @ V

print("Attention Map (LxL):\n", attn_weights.round(2))

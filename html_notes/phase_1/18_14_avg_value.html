14. Average Value of a Function

The representative height of a continuous hill.

1. The Formula

If you have a discrete set of numbers, you add them and divide by \(n\). If you have a continuous function \(f(x)\) on \([a, b]\), the Average Value is:

$$ f_{avg} = \frac{1}{b - a} \int_{a}^{b} f(x) dx $$

This is the "height" of a rectangle that has exactly the same area as the space under the curve.

2. Mean Value Theorem for Integrals

If \(f\) is continuous on \([a, b]\), then there exists a number \(c\) in the range such that \(f(c) = f_{avg}\). That is, the function must cross its own average at least once.

3. AI/ML Connection: Performance Smoothing

Moving Averages and Smoothing

Training logs of AI models are often very "noisy" (zig-zagging). To understand if the model is actually getting better, we use Smoothing. This is effectively calculating the Average Value of the loss over a sliding window.

Metric calculations like mAP (Mean Average Precision) in object detection depend on integrating the precision-recall curve and finding its average value. Without this calculus-based averaging, we wouldn't have a single, stable number to represent how "smart" an AI vision model is.

4. Python: Calculating Average Height

# Calculate avg value of sin(x) from 0 to pi
# Area is 2. Length of interval is pi.
# Expected avg: 2/pi (approx 0.636)

import numpy as np
from scipy.integrate import quad

def f(x): return np.sin(x)

a, b = 0, np.pi
area, error = quad(f, a, b)
avg_val = area / (b - a)

print(f"Average Value of Sin(x) on [0, pi]: {avg_val:.4f}")

05. Limits and Continuity in Multiple Variables

Approaching from all directions.

1. The Challenge of Infinity

In 1D calculus, you can only approach a point from the left or right. In 2D+, there are infinite possible paths (straight lines, parabolas, spirals) to reach a point \((a, b)\). For a limit to exist, the function must approach the same value from every possible path.

$$ \lim_{(x,y) \to (a,b)} f(x, y) = L $$

2. Proving Non-Existence

The easiest way to show a limit doesn't exist is to find two paths that yield different results. Common test paths include:

  • Along the x-axis (\(y=0\))
  • Along the y-axis (\(x=0\))
  • Along the line \(y=mx\)
  • Along the parabola \(y=x^2\)

3. AI/ML Connection: The Continuity of Learning

Gradient Explosions

Most AI algorithms rely on Gradient Descent, which assumes the Loss Function is Continuous and Smooth. If the loss function has a "Jump Discontinuity" (a sudden wall), the gradient becomes infinite, and the AI's weights will "Explode" to NaN (Not a Number).

This is why we prefer ReLU or Sigmoid activations. While ReLU has a "kink" at zero, it is still continuous. If we used a "Step Function" (which has a discontinuity), we couldn't use backpropagation because the limit of the derivative doesn't exist at the step. Multivariable continuity ensures that a small change in weights always leads to a predictable, small change in error.

4. Python: Path Sensitivity

# Function: f(x, y) = (xy) / (x^2 + y^2)
# Does the limit exist at (0, 0)?

def f(x, y):
    if x == 0 and y == 0: return None
    return (x * y) / (x**2 + y**2)

# Path 1: y = 0
print(f"Path y=0: {f(0.1, 0)}") # Result: 0.0

# Path 2: y = x
print(f"Path y=x: {f(0.1, 0.1)}") # Result: (0.1*0.1)/(0.1^2 + 0.1^2) = 0.5

# Since 0.0 != 0.5, the limit DOES NOT EXIST.

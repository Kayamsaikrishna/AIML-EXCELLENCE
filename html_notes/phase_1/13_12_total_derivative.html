Calculus 1.6 Sensitivity

The Total Derivative

Summing up every ripple.

The Differential

The Total Derivative (or Total Differential \( dz \)) answers: "If I change everything slightly, how much does the output change?" \[ dz = \frac{\partial f}{\partial x} dx + \frac{\partial f}{\partial y} dy + \dots \]

Unlike a partial derivative (which holds things constant), the total derivative allows everything to move at once. It essentially defines the Local Linear Approximation of the function: \[ f(x+dx, y+dy) \approx f(x, y) + dz \]

2. AI/ML Connection: Differential Privacy

Robustness & Privacy

In Differential Privacy, we ask: "If I change ONE user's record (a small \( dx \)), how much does the model's output change (\( dz \))?"

If the Total Derivative of the model with respect to the input data is bounded (small), the model is "Stable" and "Private". A large total derivative means the model is "Overfitting" to specific data points (memorizing them). If removing one user causes the model's prediction to swing wildly, that user's privacy is compromised. Techniques like Gradient Clipping essentially put a leash on the total derivative to force stability.

3. Python: Sensitivity Check

total_differential.py
import sympy as sp

x, y = sp.symbols('x y')
# Model: f = 3x^2 + 5y
f = 3*x**2 + 5*y

# Current State
x0, y0 = 10, 2
# Small perturbations (e.g., measurement noise)
dx, dy = 0.01, -0.01

# Calculate Total Differential
df_dx = sp.diff(f, x) # 6x
df_dy = sp.diff(f, y) # 5

total_diff = df_dx * dx + df_dy * dy
sensitivity = total_diff.subs({x: x0, y: y0})

print(f"Predicted Change (dz): {sensitivity:.4f}")

# Compare with actual change
exact = f.subs({x: x0+dx, y: y0+dy}) - f.subs({x: x0, y: y0})
print(f"Actual Change:         {exact:.4f}")

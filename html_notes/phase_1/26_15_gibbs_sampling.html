Stats 1.6 Multivariate Sampling

Gibbs Sampling

A "coordinate descent" version of MCMC where you update one variable at a time while holding the others constant.

The Cheat Code

Most MCMC algorithms are slow because you have to propose a jump and see if it's "Accepted."

Gibbs Sampling is special. It uses Conditional Distributions. Because it always samples exactly from the conditional, every single proposal is 100% Accepted. Zero waste!

1. The Algorithm

To sample a pair \((\theta_1, \theta_2)\):
1. Fix \(\theta_2\). Sample \(\theta_1\) from \(P(\theta_1 | \theta_2, Data)\).
2. Fix the new \(\theta_1\). Sample \(\theta_2\) from \(P(\theta_2 | \theta_1, Data)\).
3. Repeat.
graph TD A["(x0, y0)"] -->|Update x| B["(x1, y0)"] B -->|Update y| C["(x1, y1)"] C -->|Update x| D["(x2, y1)"] D -->|Update y| E["(x2, y2)"]

The sampler moves in an L-shaped "staircase" pattern through the probability space.

2. When to use it

  • Pros: No "tuning" required. High efficiency for conjugate models.
  • Cons: Requires you to actually *know* the conditional distributions (math-heavy). If variables are highly correlated, the staircase becomes very slow.

3. ML Connection: Restricted Boltzmann Machines (RBM)

Deep Learning Energy Models

The Heart of Contrastive Divergence

In an RBM (the building block of Deep Belief Networks), we have Visible units (data) and Hidden units (features).

Because the hidden units are not connected to each other, given the data, the features are independent. 1. Sample Hidden cells given Visible cells. 2. Sample Visible cells given Hidden cells.

This "Gibbs block update" is how RBMs learn to represent images. It's the engine that powers Contrastive Divergence (CD-k), which was the first practical algorithm for training deep neural networks in the mid-2000s.

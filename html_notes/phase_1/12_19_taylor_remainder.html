Calculus 1.5 Error Analysis

Taylor's Remainder Theorem

Exactly how wrong is your approximation?

The Cost of Simplicity

When we replace a function \(f(x)\) with a polynomial \(P_n(x)\), we introduce an error called the Remainder \(R_n(x)\). Lagrange's form of the remainder tells us exactly how big this error might be:

\[ R_n(x) = \frac{f^{(n+1)}(z)}{(n+1)!} (x - a)^{n+1} \]

where \(z\) is some unknown point between \(a\) and \(x\). This formula allows us to calculate the Maximum Error Bound.

2. AI/ML Connection: Safety Guarantees

Certified Robustness

In safety-critical AI (like Autonomous Vehicles or Robotic Surgery), "good enough" isn't enough. We need guarantees.

If an AI controller uses a linear approximation (Taylor degree 1) to predict a car's trajectory for the next 0.5 seconds, we MUST know the worst-case deviation. Using the Remainder Theorem, engineers can prove that the car's actual position will not deviate more than \( \epsilon \) meters from the predicted path. Without this calculus-based guarantee, we cannot legally deploy control algorithms in the real world.

3. Python: Calculating Max Error

error_bound.py
import math

# Approximating sin(0.5) using 3rd degree Maclaurin polynomial
# Remainder R_3 depends on 4th derivative of sin(x), which is sin(x).
# Max value of sin(z) is 1.

x_val = 0.5
n = 3
max_deriv = 1.0 # |sin(z)| <= 1

error_bound = (max_deriv / math.factorial(n + 1)) * (x_val**(n + 1))

print(f"Approximation: {x_val - x_val**3/6:.6f}")
print(f"Actual sin(0.5): {math.sin(0.5):.6f}")
print(f"Max Possible Error: {error_bound:.6f}")
# The actual error is always less than the theoretical bound.

1. The Proof

We want a direction \( u \) (unit vector) such that the projected variance \( u^T \Sigma u \) is maximized.

Using a Lagrange Multiplier to enforce \( u^T u = 1 \):

$$ \mathcal{L} = u^T \Sigma u - \lambda (u^T u - 1) $$

Taking the derivative and setting to zero yields \( \Sigma u = \lambda u \). The optimal direction is an eigenvector!

2. Decorrelation

Before feeding data into simple models (like Naive Bayes or Linear Regression), we often want features to be uncorrelated.

PCA rotates the data so the covariance matrix becomes diagonal. This "Whitening" step is crucial for many classical ML algorithms.

3. Manual PCA

import numpy as np

# 1. Create correlated data
rng = np.random.RandomState(42)
X = np.dot(rng.rand(2, 2), rng.randn(2, 200)).T

# 2. Centralize
X_centered = X - X.mean(axis=0)

# 3. Covariance Matrix
cov_matrix = np.cov(X_centered, rowvar=False)

# 4. Eigendecomposition
eigenvalues, eigenvectors = np.linalg.eigh(cov_matrix)

# 5. Sort (eigh returns ascending)
idx = eigenvalues.argsort()[::-1]
eigenvalues = eigenvalues[idx]
eigenvectors = eigenvectors[:, idx]

print("Top Principal Component:")
print(eigenvectors[:, 0])

# Project data
X_pca = X_centered @ eigenvectors
print("\nNew Covariance (Should be Diagonal):")
print(np.cov(X_pca, rowvar=False).round(2))

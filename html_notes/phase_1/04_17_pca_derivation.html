17. Principal Component Analysis (PCA) Derivation

Finding the axis of maximum variance.

1. The Geometric Goal

Suppose we have data \(\mathbf{X}\) (zero-centered). We want to find a unit vector \(\mathbf{w}\) such that the variance of the data projected onto \(\mathbf{w}\) is maximized.

2. The Mathematical Proof

1. The projection of data \(\mathbf{X}\) onto \(\mathbf{w}\) is \(\mathbf{X}\mathbf{w}\).

2. The variance of this projection is:

$$ \text{Var} = \frac{1}{n-1} (\mathbf{X}\mathbf{w})^T(\mathbf{X}\mathbf{w}) = \mathbf{w}^T \left( \frac{\mathbf{X}^T\mathbf{X}}{n-1} \right) \mathbf{w} $$

3. Calling the term in parentheses the Covariance Matrix \(\mathbf{S}\):

$$ \max_{\mathbf{w}} \mathbf{w}^T\mathbf{S}\mathbf{w} \quad \text{subject to } ||\mathbf{w}|| = 1 $$

4. This is exactly the optimization solved by the Rayleigh Quotient. The solution, by the Spectral Theorem, is the eigenvector of \(\mathbf{S}\) associated with its largest eigenvalue!

3. Multi-Step Procedure

  1. Center the data (\(\mathbf{X} - \mu\)).
  2. Compute Covariance \(\mathbf{S} = \frac{1}{n-1} \mathbf{X}^T\mathbf{X}\).
  3. Compute Eigenpairs of \(\mathbf{S}\).
  4. Sort Eigenvectors by Eigenvalues (decreasing).
  5. Project data into the space formed by top \(k\) vectors.

4. Python: PCA from Scratch

import numpy as np

# Generate synthetic 2D data
X = np.random.randn(100, 2)
X[:, 1] = 0.5 * X[:, 0] + 0.1 * np.random.randn(100) # Correlated data

# 1. Center
X_centered = X - np.mean(X, axis=0)

# 2. Covariance
cov_matrix = np.cov(X_centered.T)

# 3. Eigen
eigenvals, eigenvects = np.linalg.eig(cov_matrix)

# 4. Sort
idx = eigenvals.argsort()[::-1]
eigenvals, eigenvects = eigenvals[idx], eigenvects[:, idx]

print(f"Top PC Direction: {eigenvects[:, 0]}")
print(f"Variance explained by PC1: {eigenvals[0] / np.sum(eigenvals):.2f}")

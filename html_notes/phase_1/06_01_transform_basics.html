1. Definition

A function \( T: V \to W \) is a Linear Transformation if it satisfies two conditions for all vectors \( u, v \) and scalar \( c \):

  1. \( T(u + v) = T(u) + T(v) \) (Preserves Addition)
  2. \( T(cu) = cT(u) \) (Preserves Scaling)

Or combined: \( T(c_1 u + c_2 v) = c_1 T(u) + c_2 T(v) \).

2. Why We Need Non-Linearity

If Neural Networks only consisted of Linear Transformations (matrices), deep networks would collapse into a single linear layer: \( W_2(W_1 x) = (W_2 W_1)x = W_{new} x \).

To learn complex patterns, we introduce Non-Linear activation functions (ReLU, Sigmoid). These violate the linearity properties (e.g., \( \text{ReLU}(-x) \neq -\text{ReLU}(x) \)), allowing the network to fold space in complex ways.

3. Checking Linearity

import numpy as np

def T_linear(v):
    # A rotation matrix (Linear)
    theta = np.pi / 4
    R = np.array([[np.cos(theta), -np.sin(theta)],
                  [np.sin(theta),  np.cos(theta)]])
    return R @ v

def T_nonlinear(v):
    # Adding a constant bias shifts origin (Not Linear!)
    # T(0) != 0
    return v + np.array([1, 1])

# Test Vectors
u = np.array([1, 0])
v = np.array([0, 1])
c = 2

# Check Additivity for T_linear
print(f"Linear Additivity Holds: {np.allclose(T_linear(u+v), T_linear(u)+T_linear(v))}")
# Check Homogeneity for T_linear
print(f"Linear Scaling Holds: {np.allclose(T_linear(c*u), c*T_linear(u))}")

# Check T_nonlinear
print(f"Non-Linear Additivity Holds: {np.allclose(T_nonlinear(u+v), T_nonlinear(u)+T_nonlinear(v))}")
# Fails because (u+v)+b != (u+b) + (v+b) = u+v+2b

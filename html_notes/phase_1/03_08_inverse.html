08. Inverse Matrices & Properties

The reciprocal of a linear transformation.

1. Definition

A square matrix \( \mathbf{A} \) is Invertible (or Non-Singular) if there exists a matrix \( \mathbf{A}^{-1} \) such that:

$$ \mathbf{AA}^{-1} = \mathbf{A}^{-1}\mathbf{A} = \mathbf{I} $$

Key Properties

  • \( (\mathbf{A}^{-1})^{-1} = \mathbf{A} \).
  • \( (\mathbf{AB})^{-1} = \mathbf{B}^{-1}\mathbf{A}^{-1} \). (Order is reversed!)
  • \( (\mathbf{A}^T)^{-1} = (\mathbf{A}^{-1})^T \).

2. The "Closed-Form" Solution in AI

The Normal Equation

In Linear Regression, we want to find weights \( \mathbf{w} \) that minimize error. The exact, non-iterative solution is the Normal Equation:

$$ \mathbf{w} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y} $$

Warning: Calculating a matrix inverse is computationally expensive (\( O(n^3) \)). In deep learning, we almost never calculate it directly; we use optimization (Gradient Descent) instead.

3. Python: Numpy Inverse

import numpy as np

A = np.array([[1, 2], [3, 4]])

# Compute Inverse
A_inv = np.linalg.inv(A)

# Verification
identity = A @ A_inv

print(f"Inverse:\n{A_inv}")
print(f"Check (Identity):\n{np.round(identity)}")

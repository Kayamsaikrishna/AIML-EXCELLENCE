1. The Definition

The inverse of a square matrix \( A \) is a matrix \( A^{-1} \) such that multiplying them yields the Identity.

$$ A A^{-1} = I \quad \text{and} \quad A^{-1} A = I $$

If such a matrix exists, \( A \) is called Invertible (or Non-Singular).

2. Note on Computation

While \( \mathbf{x} = A^{-1} \mathbf{b} \) is the theoretical solution to \( A\mathbf{x} = \mathbf{b} \), we rarely compute \( A^{-1} \) directly in algorithms.

Inverting a matrix is computationally expensive ($O(n^3)$) and numerically unstable. We prefer factorization methods (LU, QR) which "act like" an inverse without explicitly forming the full matrix.

3. NumPy Inversion

Calculating the inverse explicitly.

import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

# Compute Inverse
try:
    A_inv = np.linalg.inv(A)
    print("Inverse of A:")
    print(A_inv)
    
    # Verify: A @ A_inv should be Identity
    I_check = A @ A_inv
    print(f"\nVerification (Should be I):\n{I_check.round(10)}")
    
except np.linalg.LinAlgError:
    print("Matrix is Singular (Not Invertible)!")

# Singular Example
B = np.array([[1, 2], [2, 4]]) # Cols are dependent

3. Natural Numbers (\(\mathbb{N}\))

$$ \mathbb{N} = \{0, 1, 2, 3, ...\} $$

Theoretical Basis: Peano Axioms

Natural numbers are defined rigorously by the Peano Axioms:

  1. 0 is a natural number.
  2. For every natural number \(n\), its successor \(S(n)\) is a natural number.
  3. 0 is not the successor of any natural number.
  4. If \(S(n) = S(m)\), then \(n = m\) (Injection).
  5. Induction: If a set contains 0 and the successor of every element in the set, it contains all Natural Numbers.
AI Insight: Tokenization & Embeddings

In Large Language Models (LLMs), every word is mapped to a unique Natural Number (Token ID). The vocabulary size \( V \) (e.g., 50,000) defines the range of these integers. Embedding layers are essentially lookup tables indexed by \(\mathbb{N}\).

# Concept: Embedding Layer
import torch.nn as nn

vocab_size = 50000 
embedding_dim = 768

# This layer expects integer inputs in range [0, 49999]
embedding_layer = nn.Embedding(vocab_size, embedding_dim)

# Input MUST be Natural Numbers (Long Tensor)
token_ids = torch.tensor([154, 982, 33]) 
vectors = embedding_layer(token_ids)

4. Integers (\(\mathbb{Z}\)) & Rationals (\(\mathbb{Q}\))

Integers (\(\mathbb{Z}\)) extend \(\mathbb{N}\) with additive inverses (negatives). Rationals (\(\mathbb{Q}\)) introduce multiplicative inverses (division).

Quantization: The art of shrinking models

To fit 70B parameter models on consumer hardware, we "quantize" weights from 32-bit Reals to 8-bit or 4-bit Integers.

$$ x_{Q} = \text{round}\left( \frac{x_{F}}{S} + Z \right) $$
  • \(x_Q\): Quantized Integer value (int8)
  • \(x_F\): Original Float value (fp32)
  • \(S\): Scale factor (float)
  • \(Z\): Zero-point (integer)

This allows operations to be performed using integer arithmetic units, which are faster and more energy-efficient than floating-point units.

5. Real Numbers & IEEE 754

Computers typically use Floating Point arithmetic to represent Reals. This is lossy and leads to precision errors that can crash training via NaN (Not a Number).

$$ Value = (-1)^S \times (1 + M) \times 2^{E - Bias} $$

Python Proof: Floating Point Error

def demonstrate_error():
    # The famous 0.1 + 0.2 != 0.3
    val = 0.1 + 0.2
    target = 0.3
    
    print(f"Calculated: {val:.25f}")
    print(f"Target:     {target:.25f}")
    
    # Machine Epsilon (smallest difference)
    import sys
    print(f"Machine Epsilon: {sys.float_info.epsilon}")

    if val != target:
        print("\nMATCH FAILED: IEEE 754 Precision Error detected.")
        print("This is why we use 'tolerance' (atol) in tests.")

6. Complex Numbers (\(\mathbb{C}\)) in AI

Complex numbers (\(z = a + bi\)) are critical in signal processing (Fourier Transforms) and modern positional encodings.

Rotary Positional Embeddings (RoPE)

Models like LLaMA use complex number rotations to encode relative positions of tokens.

$$ f(x, m) = x \cdot e^{i m \theta} $$ $$ \text{where } x = (x_1 + i x_2), \text{ and } m \text{ is position.} $$

Using Euler's formula \( e^{i\theta} = \cos \theta + i \sin \theta \), this rotation can be applied as a matrix multiplication on pairs of embedding dimensions. This property allows the model to generalize to sequence lengths longer than seen during training.

7. Applications and Review

Hyperparameter Tuning

We perform grid searches over number sets. Learning rates are typically Real numbers (e.g., 0.001), while Batch Sizes are purely Natural numbers (e.g., 32, 64).

Loss Functions

Classification targets are Integers (Class 0, 1, 2) which are "One-Hot Encoded" into vectors for Cross-Entropy Loss comparison against Softmax probabilities (Reals).

Calculus 1.6 Circulation

Stokes' Theorem

Boundaries in 3D: Curl matches Circulation.

3D Green's Theorem

Stokes' Theorem is the 3D upgrade of Green's Theorem. It relates the Line Integral around a closed boundary curve \( C \) to the Surface Integral of the Curl over any "cap" surface \( S \) that sits on that curve. \[ \oint_C \vec{F} \cdot d\vec{r} = \iint_S (\nabla \times \vec{F}) \cdot d\vec{S} \]

This means the "Total Swirl" along the edge equals the sum of all the "Micro-Swirls" (Curl) on the inside.

2. AI/ML Connection: Recurrent Neural Networks (RNNs)

Rotational Dynamics

In Recurrent Neural Networks, the hidden state \( h_t \) evolves over time. The dynamics can be viewed as a vector field in the state space. If the vector field has strong Curl (Rotational dynamics), the hidden state can cycle or oscillate, which is useful for tasks like generating music or repetitive patterns.

However, unintended curl can cause instability (exploding gradients). Stokes' Theorem gives us a theoretical tool to analyze the "energy" of these cycles. If we enforce the Curl to be zero (Conservative field), we get "Contractive" RNNs that always converge to a stable fixed point.

3. Python: Verifying Stokes'

stokes_check.py
import sympy as sp

# Field F = < -y, x, 0 > (Vortex in z-plane)
# Surface S: Disk x^2 + y^2 <= 1 on z=0 plane. Normal n=<0,0,1>
# Boundary C: Unit circle x^2 + y^2 = 1.

x, y, z = sp.symbols('x y z')
F = sp.Matrix([-y, x, 0])

# 1. Calculate Curl
curl_F = sp.Matrix([
    sp.diff(F[2], y) - sp.diff(F[1], z),
    sp.diff(F[0], z) - sp.diff(F[2], x),
    sp.diff(F[1], x) - sp.diff(F[0], y)
]) # <0, 0, 1 - (-1)> = <0, 0, 2>

# 2. Surface Integral: Integral(Curl . n) dA
# Curl . <0,0,1> = 2.
# Integral of 2 over unit disk (Area pi) = 2 * pi.

print(f"Curl: {curl_F}")
print(f"Predicted Circulation (Stokes): {2 * sp.pi}")

# 3. Line Integral Check
# r(t) = 
# F(r) = <-sin(t), cos(t), 0>
# dr/dt = <-sin(t), cos(t), 0>
# F . dr = sin^2 + cos^2 = 1
# Integral 1 dt from 0 to 2pi = 2pi.

print("Matches Line Integral: True")

08. Partial Fraction Decomposition (PFD)

Breaking down complex rational ratios.

1. The Goal

PFD is an algebraic method used to split a complex fraction into a sum of simpler fractions. This is primarily done so we can use the Log Rule or Inverse Trig Rule for integration.

$$ \frac{P(x)}{Q(x)} = \frac{A}{x - r} + \frac{B}{x - s} $$

2. The Cases

  • Distinct Linear Factors: \(\frac{A}{x-r} + \frac{B}{x-s}\)
  • Repeated Factors: \(\frac{A}{x-r} + \frac{B}{(x-r)^2}\)
  • Irreducible Quadratic Factors: \(\frac{Ax+B}{x^2+px+q}\)

3. AI/ML Connection: Linear Time-Invariant (LTI) Systems

The Laplace Domain

In Control Theory and Signal Processing AI, we model systems using "Transfer Functions". Often, these functions are complex polynomials. To understand how a robot will react to an input over time, we must perform an "Inverse Laplace Transform", which relies entirely on Partial Fraction Decomposition.

By breaking a complex system into smaller "modes" (the partial fractions), an AI can predict the stability of a feedback loop or the frequency response of a sensor filter. PFD is also used in Gaussian Process regressions when handling complex rational kernels.

4. Python: Symbolic PFD

import sympy as sp

x = sp.Symbol('x')
f = 1 / (x**2 - 5*x + 6)

# Decompose into Partial Fractions
decomposed = sp.apart(f)

print(f"Original: {f}")
print(f"Decomposed: {decomposed}")
# Output: 1/(x-3) - 1/(x-2)

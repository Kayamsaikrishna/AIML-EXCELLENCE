01. Derivative Definition (Limit Definition)

Finding the "Instantaneous" rate of change.

1. The Concept: From Secant to Tangent

The derivative \(f'(x)\) represents the slope of a function at a single point. To find this, we start with a secant line between two points \((x, f(x))\) and \((x+h, f(x+h))\). The slope is:

$$ \frac{\text{Change in } y}{\text{Change in } x} = \frac{f(x+h) - f(x)}{h} $$

As we let the distance \(h\) shrink to zero, the secant line becomes the tangent line.

2. The Formal Definition

The derivative of a function \(f\) at \(x\) is defined as:

$$ f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} $$

Provided this limit exists. If it exists, the function is said to be differentiable at \(x\).

3. AI/ML Connection: Numerical Gradient Estimation

Finite Differences

In AI, we often use complex functions where we don't have a simple formula for the derivative. We can estimate the gradient (derivative) using the Finite Difference Method, which is simply the limit definition with a very small \(h\):

$$ \nabla f(w) \approx \frac{f(w + \epsilon) - f(w)}{\epsilon} $$

This is used to verify that our hand-coded backpropagation (analytical gradients) is correct.

4. Python: Estimating a Derivative

def f(x):
    return x**2

def estimate_derivative(func, x, h=1e-7):
    return (func(x + h) - func(x)) / h

x_val = 5
actual = 2 * x_val # Derivative of x^2 is 2x
estimated = estimate_derivative(f, x_val)

print(f"Estimation at x={x_val}: {estimated:.8f}")
print(f"Actual Value: {actual:.8f}")

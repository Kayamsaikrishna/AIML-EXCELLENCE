04. Limits at Infinity

Predicting the "End Behavior" of a function.

1. Exploring Horizontal Asymptotes

What happens to a function \(f(x)\) as \(x\) grows larger and larger without bound? We denote this as:

$$ \lim_{x \to \infty} f(x) = L \quad \text{or} \quad \lim_{x \to -\infty} f(x) = M $$

If these limits equal a finite number \(L\), the line \(y = L\) is called a Horizontal Asymptote.

2. Common Patterns

  • Rational Functions: If the degree of the denominator is higher than the numerator, the limit is 0. $$\lim_{x \to \infty} \frac{2x + 5}{x^2 - 1} = 0$$
  • Exponential Functions: \(e^{-x}\) approaches 0 as \(x \to \infty\).

3. AI/ML Connection: Activation Saturation

Sigmoid and Tanh Limits

The Sigmoid activation function \(\sigma(x) = \frac{1}{1 + e^{-x}}\) is designed around its limits at infinity:

  • \(\lim_{x \to \infty} \sigma(x) = 1\) (Maximum probability)
  • \(\lim_{x \to -\infty} \sigma(x) = 0\) (Minimum probability)

In Deep Learning, if the values entering these functions are very large, the function "saturates" near its limits. Because the slope (derivative) at these limits is almost 0, gradients stop flowing, leading to the Vanishing Gradient Problem.

4. Python: Simulating Extremes

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# Test extreme values
large_x = [10, 100, 1000]
print("Sigmoid as x -> Infinity:")
for x in large_x:
    print(f"σ({x}) = {sigmoid(x):.10f}")

small_x = [-10, -100, -1000]
print("\nSigmoid as x -> -Infinity:")
for x in small_x:
    print(f"σ({x}) = {sigmoid(x):.10f}")

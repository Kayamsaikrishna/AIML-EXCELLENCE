07. Expected Value (Mean)

The long-term average of a random variable.

1. Definition

The Expected Value $E[X]$, often denoted by $\mu$, is the "center of mass" of a distribution. It is the weighted average of all possible values.

Discrete: $E[X] = \sum_i x_i P(X = x_i)$

Continuous: $E[X] = \int_{-\infty}^{\infty} x f_X(x) \, dx$

2. Fundamental Properties

  • Linearity of Expectation: $E[aX + b] = aE[X] + b$. This holds even if variables are dependent!
  • Expectation of a Function: $E[g(X)] = \sum g(x) P(x)$ or $\int g(x) f(x) \, dx$.

3. AI/ML Connection: Maximizing Reward

Expectation in Optimization

In Machine Learning, we almost never minimize "error on a single point"; we minimize Expected Loss.

When you train an AI, you are effectively finding parameters that minimize the average error over the entire data distribution. In Reinforcement Learning (RL), the AI's goal is to maximize the Expected Reward. Because the environment and actions are uncertain, the AI must reason about the future by weighing every possible outcome by its probability. Furthermore, Generative Models (like VAEs) use the "Evidence Lower Bound" (ELBO), which is entirely formulated using expectations of log-likelihoods. Expected value is the "Goal Post" of AI training.

4. Python: Calculating Expected Value

# For a discrete dice roll: values=[1,2,3,4,5,6], probs=[1/6 for all]
values = np.array([1, 2, 3, 4, 5, 6])
probs = np.ones(6) / 6

expected_value = np.sum(values * probs)
print(f"E[Dice Roll]: {expected_value}") # 3.5

# For continuous (Standard Normal):
from scipy.stats import norm
print(f"E[Normal(0,1)]: {norm.mean(loc=0, scale=1)}")

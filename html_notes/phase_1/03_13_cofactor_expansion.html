13. Cofactor Expansion (Laplace Expansion)

Recursive breakdown of higher-dimensional determinants.

1. Minors and Cofactors

  • Minor (\( M_{ij} \)): The determinant of the sub-matrix formed by deleting the \( i \)-th row and \( j \)-th column.
  • Cofactor (\( C_{ij} \)): The minor adjusted by a sign: \( C_{ij} = (-1)^{i+j}M_{ij} \).

The Laplace Expansion for row \( i \):

$$ \text{det}(\mathbf{A}) = \sum_{j=1}^n a_{ij}C_{ij} $$

2. Computational Complexity & Recursion

The O(n!) Trap

While elegant, using Cofactor Expansion for an \( n \times n \) matrix takes Factorial Time. For a \( 10 \times 10 \) matrix, this is millions of operations. For a \( 100 \times 100 \), it's physically impossible before the death of the universe.

  • AI Practice: Modern libraries (Numpy, PyTorch) use PLU Decomposition to find determinants in \( O(n^3) \).

3. Python: Recursive Determinant (Educational Only)

import numpy as np

def determinant_recursive(matrix):
    n = len(matrix)
    if n == 1: return matrix[0][0]
    if n == 2: return matrix[0][0]*matrix[1][1] - matrix[0][1]*matrix[1][0]
    
    det = 0
    for j in range(n):
        # Create sub-matrix (Minor)
        minor = np.delete(np.delete(matrix, 0, axis=0), j, axis=1)
        det += ((-1)**j) * matrix[0][j] * determinant_recursive(minor)
    return det

A = np.array([[1, 2, 3], [4, 5, 6], [7, 8, 0]])
print(f"Recursive Det: {determinant_recursive(A)}")

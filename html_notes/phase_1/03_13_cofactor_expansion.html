1. Laplace Expansion

We can compute determinants recursively. For a 3x3, we break it into three 2x2s.

$$ \det(A) = \sum_{j=1}^n (-1)^{i+j} a_{ij} \det(M_{ij}) $$
  • \( M_{ij} \): The Minor (matrix with row $i$, col $j$ removed).
  • \( C_{ij} \): The Cofactor (Minor with Sign).

2. Why NOT to use this

This algorithm is \( O(n!) \). For a 20x20 matrix, this would take lifetimes of the universe.

In practice, we use LU Decomposition ($O(n^3)$) to find determinants using the product of the diagonal pivots. We learn Lapace only for theoretical understanding (like Cross Products).

3. Recursive Calculation

Just for fun: Implementing Laplace Expansion.

import numpy as np

def get_minor(matrix, i, j):
    # Remove row i and col j
    return np.delete(np.delete(matrix, i, 0), j, 1)

def laplace_det(matrix):
    n = matrix.shape[0]
    # Base case: 2x2
    if n == 2:
        return matrix[0,0]*matrix[1,1] - matrix[0,1]*matrix[1,0]
    
    det = 0
    # Expand along first row (i=0)
    for j in range(n):
        sign = (-1) ** j
        minor = get_minor(matrix, 0, j)
        det += sign * matrix[0, j] * laplace_det(minor)
        
    return det

A = np.array([
    [1, 2, 3],
    [0, 4, 5],
    [1, 0, 6]
])

print(f"Manual Recursive Det: {laplace_det(A)}")
print(f"NumPy Det: {np.linalg.det(A)}")

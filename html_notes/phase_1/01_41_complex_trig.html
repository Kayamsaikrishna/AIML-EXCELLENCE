1. Introduction

Leonhard Euler discovered that exponential growth in imaginary time is actually circular motion in real space.

$$ e^{i\pi} + 1 = 0 $$

This means multiplying by \( e^{i\theta} \) is the same as Rotating a vector by angle \( \theta \).

2. FFT and RoPE

Because \( e^{ix} \) is easy to multiply (add exponents) but \( \sin(x) \) is hard (trig identities), computers do almost ALL signal processing using Complex Numbers.

RoPE (Rotary Positional Embedding) explicitly defines position as a complex rotation:

$$ f(x, pos) = x \cdot e^{i \cdot pos \cdot \theta} $$

3. Complex Rotation

Rotating a point using complex multiplication.

import numpy as np

# A point at (1, 0) -> Real number 1 + 0j
z = 1.0 + 0.0j

# Rotate by 90 degrees (Pi/2)
theta = np.pi / 2
rotator = np.exp(1j * theta)

# New Position
z_new = z * rotator

print(f"Original: {z}")
print(f"Rotated:  {z_new:.2f}") 
# 0.00 + 1.00j (Pure Imaginary -> Vertical Up)

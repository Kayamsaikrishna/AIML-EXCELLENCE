1. Gauss-Jordan Elimination

To find the inverse, we augment \( A \) with the Identity \( I \): \( [A | I] \).

We then perform Row Operations (swap, scale, add) to turn the left side ($A$) into Identity. The right side automatically transforms into \( A^{-1} \).

If we cannot turn $A$ into $I$, then $A$ is singular.

2. Note on Adjugate Method

For small matrices (2x2, 3x3), we can use the Adjugate Formula:

$$ A^{-1} = \frac{1}{\det(A)} \text{adj}(A) $$

This is useful for theory, but bad for computers ($O(n!)$ complexity!). Gauss-Jordan ($O(n^3)$) is what solvers actually use.

3. Symbolic Inversion

Using SymPy to see exact fractions.

from sympy import Matrix

# Define a matrix with integers
M = Matrix([
    [1, 2],
    [3, 4]
])

# Compute Inverse Symbolic
M_inv = M.inv()

print("M:")
print(M)

print("\nExact Inverse:")
print(M_inv)
# [-2, 1]
# [3/2, -1/2]

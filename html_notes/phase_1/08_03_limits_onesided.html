Calculus 1.3 Discontinuities

One-Sided Limits

Sometimes, truth depends on your perspective. Or at least, the limit depends on the direction of your approach.

Direction Matters

In continuous mathematics, "approaching" 3 usually implies from both sides. But real-world signals (like stock prices opening after a weekend gap, or digital signals switching from 0 to 1) often have different behaviors depending on whether you look at "before" or "after" a specific moment.

1. Notation & Definition

Right-Hand Limit

\[ \lim_{x \to a^+} f(x) = L \]

Approaching \(a\) from values larger than \(a\) (decreasing towards \(a\)).

Left-Hand Limit

\[ \lim_{x \to a^-} f(x) = M \]

Approaching \(a\) from values smaller than \(a\) (increasing towards \(a\)).

Theorem of Existence

The general limit \(\lim_{x \to a} f(x)\) exists if and only if:

\[ \lim_{x \to a^-} f(x) = \lim_{x \to a^+} f(x) = L \]

If they differ, the limit Does Not Exist (DNE).

3. AI/ML Application: ReLU and Indeterminacy

The "Kink" in Deep Learning

The ReLU (Rectified Linear Unit) activation function is defined as:

\[ f(x) = \max(0, x) \]

Is it continuous? Yes. At \(x=0\), Left Limit = 0, Right Limit = 0. So the function value exists and is stable.
Is it smooth? No. Let's look at its derivative (slope):

  • Left Slope (\(x \to 0^-\)): \(d/dx(0) = 0\)
  • Right Slope (\(x \to 0^+\)): \(d/dx(x) = 1\)

Since \(0 \neq 1\), the limit of the difference quotient does not exist at 0. The function is non-differentiable at the origin.

Subgradients to the Rescue

How do we train networks with ReLU if the gradient doesn't exist at 0? We cheat! We define a subgradient, effectively picking the slope to be 0 or 1 arbitrarily (usually 0) at the exact point of the kink. This works because hitting exactly 0.0000000... is numerically rare.

4. Python Implementation: Detecting Jumps

jump_detector.py
import numpy as np

def heaviside_step(x):
    """
    Heaviside Step Function: 0 if x < 0, 1 if x >= 0
    Classic example of a jump discontinuity.
    """
    return np.where(x >= 0, 1.0, 0.0)

def check_limit_existence(func, point, epsilon=1e-5):
    # Approach from left and right
    left_x = point - epsilon
    right_x = point + epsilon
    
    left_val = func(left_x)
    right_val = func(right_x)
    
    print(f"Checking limit at x = {point}")
    print(f"Limit x->{point}- : {left_val}")
    print(f"Limit x->{point}+ : {right_val}")
    
    if np.isclose(left_val, right_val):
        print("=> Conclusion: Limit EXISTS.")
    else:
        print("=> Conclusion: Limit Does Not Exist (JUMP Detected).")

# Test 1: Step Function at 0
print("--- Test 1: Heaviside at 0 ---")
check_limit_existence(heaviside_step, 0)

# Test 2: x^2 at 2 (Continuous)
print("\n--- Test 2: x^2 at 2 ---")
check_limit_existence(lambda x: x**2, 2)

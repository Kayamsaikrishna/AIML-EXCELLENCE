Bayesian Networks Structure

Visualizing high-dimensional probability as a directed story of "Who causes Who."

The Combinatorial Explosion

To define a Joint Distribution of 10 binary variables, you need a table with \(2^{10} = 1024\) entries.

In a Bayesian Network, you only define local relationships. If each node only has 2 parents, you might only need 50 entries! It is the ultimate tool for **Efficient Probability Representation**.

1. What is a Bayesian Network?

A Directed Acyclic Graph (DAG) where: - Nodes represent Random Variables. - Edges represent conditional dependencies (Causality-ish).

graph TD A[Rain] --> C[Wet Grass] B[Sprinkler] --> C C --> D[Slippery Floor]

2. Joint Distribution Factorization

The "Magic" of BN is that the joint probability of the entire world is simply the product of each node given its parents.

$$ P(X_1, \dots, X_n) = \prod_{i=1}^n P(X_i | \text{Parents}(X_i)) $$

3. ML Connection: Root Cause Analysis (RCA)

Monitoring Systems

The "Cloud Outage" Problem

A major e-commerce site goes down. You have 5,000 metrics (CPU, DB latency, Network bandwidth, etc.).

A Bayesian Network can be built to represent the architecture of the app. By observing the "Evidence" (High Latency in Service A), the network uses Bayesian Inference (Belief Propagation) to backtrack and calculate the probability of where the fault lies. It might tell you: "There is an 85% probability the root cause is a Deadlock in Database Cluster B."

Companies like Microsoft and Intel use BNs for hardware troubleshooting and medical software to help doctors find the specific disease (hidden node) that caused a set of symptoms (observed nodes).

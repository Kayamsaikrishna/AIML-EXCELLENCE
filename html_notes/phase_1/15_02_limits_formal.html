02. Formal Definition (ε-δ)

Ensuring mathematical rigor: The Epsilon-Delta definition.

1. The Rigorous Definition

While the intuitive definition ("gets closer to") is useful, we need a way to prove limits. The formal definition states:

Let \(f\) be a function defined on an open interval containing \(a\), except possibly at \(a\) itself. We say that:

$$ \lim_{x \to a} f(x) = L $$

if for every number \(\epsilon > 0\) (epsilon), there exists a number \(\delta > 0\) (delta) such that:

$$ \text{if } 0 < |x - a| < \delta \implies |f(x) - L| < \epsilon $$

2. What does this actually mean?

Think of it as a challenge:

  • The Challenge (\(\epsilon\)): Someone says, "I want the output of the function to be within 0.01 units of \(L\)."
  • The Response (\(\delta\)): You must find a distance around \(a\) such that every \(x\) in that range (except \(a\)) produces an output within that 0.01 units.

3. AI/ML Connection: Convergence Analysis

Is your Optimizer "Converging"?

In AI research, we often prove that an algorithm (like Adam or SGD) converges to an optimal weight \(w^*\). This proof fundamentally relies on the \(\epsilon-\delta\) logic: "Given a target error \(\epsilon\), how many iterations \(n\) (our \(\delta\) in discrete space) are needed to ensure we are that close to the optimum?"

Without this formal framework, we couldn't guarantee that AI models would ever stop learning or settle at a "good" solution.

4. Visualizing with Code

# Checking the definition for f(x) = 2x, as x -> 3, L = 6
def check_delta(epsilon):
    # For f(x) = 2x, |2x - 6| < epsilon => 2|x - 3| < epsilon
    # So |x - 3| < epsilon/2. Thus, delta = epsilon/2
    delta = epsilon / 2
    return delta

eps = 0.5
delta_found = check_delta(eps)
print(f"For epsilon {eps}, delta is {delta_found}")

# Verify: pick x in (3 - delta, 3 + delta)
test_x = 3 + (delta_found * 0.9)
error = abs((2 * test_x) - 6)
print(f"Test x: {test_x}, Output error: {error} (Must be < {eps})")

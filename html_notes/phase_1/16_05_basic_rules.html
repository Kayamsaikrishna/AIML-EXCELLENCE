05. Basic Differentiation Rules

Shortcuts for the most common functions.

1. The Constant Rule

If a function is a constant (a horizontal line), its slope is zero everywhere.

$$ \frac{d}{dx}[c] = 0 $$

2. The Power Rule

For any real number \(n\), the derivative of \(x^n\) is:

$$ \frac{d}{dx}[x^n] = nx^{n-1} $$

Example: The derivative of \(x^3\) is \(3x^2\).

3. The Constant Multiple Rule

A constant multiplying a function just scales the derivative:

$$ \frac{d}{dx}[c \cdot f(x)] = c \cdot f'(x) $$

Example: \(\frac{d}{dx}[5x^2] = 5 \cdot (2x) = 10x\).

4. AI/ML Connection: Linear Models

Gradient of Mean Squared Error (MSE)

In a simple linear regression \(y = wx\), the loss function (MSE) often looks like \((wx - y_{true})^2\). When we expand this and take the derivative with respect to \(w\), we are using the Power Rule. Minimizing this squared error is the heart of how AI models "learn".

5. Python: Automated Differentiation with SymPy

import sympy as sp

x = sp.Symbol('x')
f = 10*x**3 + 7

# SymPy uses the Power Rule and Constant Rule automatically
f_prime = sp.diff(f, x)

print(f"Function: {f}")
print(f"Derivative: {f_prime}") # Output: 30*x**2

1. Definition

An Isomorphism is a linear transformation that is both:

  1. Injective (One-to-One): No info lost.
  2. Surjective (Onto): Covers the whole target.

If such a map exists, \( V \) and \( W \) are "Isomorphic". They are effectively the same space, just labeled differently. (e.g., Polynomials of degree 2 vs \( \mathbb{R}^3 \)).

2. Feature Spaces

In Kernel Methods (SVMs), we map data to a high-dimensional feature space \( \phi(x) \).

We often assume there exists an isomorphism between the pattern in the input space and the pattern in the feature space (preserving the geometry/distances), allowing us to solve the problem more easily there (Linear Separability).

3. Coordinates as Isomorphism

Mapping polynomials \( ax^2 + bx + c \) to vector \( [a, b, c] \) is the classic isomorphism.

import numpy as np

# Map Polynomial 2x^2 + 3x + 5 -> Vector [2, 3, 5]
# T: P2 -> R3

def T_iso(poly_coeffs):
    return np.array(poly_coeffs)

def T_inv(vector):
    return list(vector)

# P = 3x^2 + 0x + 1
p = [3, 0, 1]

# Forward to Vector Space
v = T_iso(p)
print(f"Vector in R3: {v}")

# Operation in R3 (Add vectors)
v2 = np.array([1, 1, 1])
v_sum = v + v2

# Inverse back to Polynomial
p_sum = T_inv(v_sum)
print(f"Sum in Polynomials: {p_sum[0]}x^2 + {p_sum[1]}x + {p_sum[2]}")
# We did algebra in R3 to solve a problem in P2.

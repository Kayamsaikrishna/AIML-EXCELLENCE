16. Metropolis-Hastings Algorithm

The general-purpose sampler for the unknown.

1. The Universal Logic

Metropolis-Hastings (MH) is the most flexible MCMC algorithm. Unlike Gibbs, it doesn't require you to know the conditional distributions. It works by proposing a jump to a new state and "Coin Flipping" to decide whether to go:

  1. Propose: Jump from $\theta_{old}$ to $\theta_{new}$ using a random step.
  2. Compare: Calculate the ratio $R = \frac{P(D|\theta_{new})P(\theta_{new})}{P(D|\theta_{old})P(\theta_{old})}$.
  3. Accept: If $R \ge 1$, move. If $R < 1$, move with probability $R$. Otherwise, stay put.

2. The Mathematical Magic

The beauty of the ratio $R$ is that the **Evidence** $P(D)$ cancels out perfectly! This allows us to sample from distributions where the normalization constant is unknown—which is almost every complex Bayesian problem in AI.

3. AI/ML Connection: Combinatorial Optimization and Protein Folding

Searching in Chaos

In AI, Metropolis-Hastings is used for Structure Discovery.

When searching for the optimal Graph Architecture** or **Neural Network Topology**, there is no "Gradient." You cannot use Backprop. You use MH. You "Propose" a new connection, and the AI evaluates if the model got better. This is also how **DeepMind's AlphaFold** explores the energy landscape of a protein: it proposes a twist or a fold, and the Metropolis-like criterion decides if that fold is energetically stable. It is the core algorithm for any AI that needs to find a "Good" solution in a massive, discrete, or non-differentiable space.

4. Python: The Accept-Reject Step

# Propose a new set of weights
proposal = current_theta + np.random.normal(0, sigma)

# Compute Acceptance Ratio
prob_current = posterior_log_prob(current_theta)
prob_proposal = posterior_log_prob(proposal)

# acceptance_ratio = exp(proposal - current)
ratio = np.exp(prob_proposal - prob_current)

# Decision logic
if np.random.rand() < ratio:
    current_theta = proposal # Acceptance!
else:
    # Stay where we are - keep 'current_theta'
    pass

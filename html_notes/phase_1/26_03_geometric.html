03. Geometric Distribution

Waiting for the first success.

1. Definition

A random variable $X$ follows a Geometric Distribution if it represents the number of Bernoulli trials (each with success probability $p$) needed to get the first success.

$$ P(X=k) = (1-p)^{k-1} p \quad \text{for } k=1, 2, 3, \dots $$

Note: Some definitions count the number of failures before the first success ($k=0, 1, 2, \dots$). In the "number of trials" version, $k \ge 1$.

2. Key Feature: Memorylessness

The Geometric distribution is the only discrete distribution with the Memoryless Property. Given that success has not occurred by trial $n$, the probability that it occurs on trial $n+m$ is the same as the probability that it occurs on trial $m$ starting from the beginning.

$$ P(X > n+m \mid X > n) = P(X > m) $$

3. AI/ML Connection: Survival Analysis and Optimization

Modeling Wait times

Geometric distributions are the foundation of **Survival Analysis** in AI.

When an AI model predicts "Churn" (when a user will stop using a service), it is often modeling a process where each month is a trial with a probability of the user leaving. Geometric distributions also appear in **Iterative Algorithms**. If a process (like a randomized search) has a probability $p$ of encontrar the global minimum at each step, the total number of steps is geometrically distributed. Understanding this allows AI researchers to calculate the Expected Convergence Time of their algorithms.

4. Python: Trials Until Success

from scipy.stats import geom

# Probability of finding an error in a line of code: p=0.05
p = 0.05

# Probability it takes exactly 10 lines to find the first error
print(f"P(X=10): {geom.pmf(10, p):.4f}")

# Expected number of trials (1/p)
print(f"E[X]: {geom.mean(p)}") # 20.0

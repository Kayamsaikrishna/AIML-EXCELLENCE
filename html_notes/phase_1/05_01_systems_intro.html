1. The Form

A system of \( m \) linear equations with \( n \) variables can be written compactly as a matrix multiplication:

$$ A \mathbf{x} = \mathbf{b} $$
  • \( A \): Coefficient Matrix (\( m \times n \)).
  • \( \mathbf{x} \): Vector of unknowns (\( n \times 1 \)).
  • \( \mathbf{b} \): Constant vector (\( m \times 1 \)).

2. The Forward Pass

A single layer of a fully connected Neural Network is essentially a linear system (followed by a non-linearity):

$$ \mathbf{z} = W \mathbf{x} + \mathbf{b} $$

Here, we aren't "solving" for \( x \) (we know the input), but rather computing the linear transformation. However, training the network involves solving for the weights \( W \) that satisfy the data equations.

3. Visualizing Intersections

import numpy as np
import matplotlib.pyplot as plt

# System:
# 1x + 1y = 5
# 2x - 1y = 1

# Matrix Form
A = np.array([[1, 1], [2, -1]])
b = np.array([5, 1])

# Solve
x = np.linalg.solve(A, b)
print(f"Intersection Point: {x}")

# Visualization (Row Picture)
x_vals = np.linspace(0, 5, 100)
# Line 1: y = 5 - x
y1 = 5 - x_vals
# Line 2: y = 2x - 1
y2 = 2 * x_vals - 1

plt.figure(figsize=(6,6))
plt.plot(x_vals, y1, label='x + y = 5')
plt.plot(x_vals, y2, label='2x - y = 1')
plt.scatter(x[0], x[1], color='red', zorder=5, label='Solution')
plt.grid(True)
plt.legend()
plt.title("Row Picture: Intersection of Lines")
plt.show() # In a notebook this would display

1. The Structure

The complete set of solutions to \( Ax = b \) is given by:

$$ \mathbf{x} = \mathbf{x}_p + \mathbf{x}_n $$
  • \( \mathbf{x}_p \): Any single vector that solves \( Ax = b \) (Particular).
  • \( \mathbf{x}_n \): Any vector in the Null Space of \( A \) (Homogeneous).

Geometrically, this is a subspace (the null space) shifted by the vector \( x_p \). It doesn't pass through the origin (unless \( b=0 \)), so it's an Affine Space, not a Subspace.

2. Infinite Solutions in ML

In Deep Learning, we have more parameters than data points (\( n \gg m \)). This is an underdetermined system.

There are infinite solutions (weights) that yield zero training error (perfect \( Ax=b \)). The "Solution Space" is vast. Optimization algorithms (SGD) traverse this space to find a solution that generalizes well (often picking the one with minimum norm implicitly).

3. Least Squares Particular Solution

import numpy as np

# Underdetermined System (1 equation, 3 unknowns)
# x + y + z = 6
A = np.array([[1, 1, 1]])
b = np.array([6])

print("A shape:", A.shape)

# Particular Solution using Pseudo-inverse (gives min-norm solution)
x_p = np.linalg.pinv(A) @ b
print("Particular Solution x_p:", x_p)
# Should be [2, 2, 2]

# Homogeneous Solutions (Null Space)
# Vectors sum to 0
x_n1 = np.array([1, -1, 0])
x_n2 = np.array([1, 0, -1])

# Verify General Solution x = x_p + c*x_n
x_general = x_p + 5 * x_n1
print("General Solution check:", A @ x_general) 
# Should still be [6]

1. Speeding Up

If you know \( \sin(\theta) \), you can calculate \( \sin(2\theta) \) without measuring again.

$$ \sin(2\theta) = 2 \sin(\theta) \cos(\theta) $$ $$ \cos(2\theta) = \cos^2(\theta) - \sin^2(\theta) $$

Geometrically, this squeezes the wave, occurring twice as often in the same interval.

2. The Danger of Downsampling

In Computer Vision (CNNs), we use "Stride 2" or "MaxPooling" to halve the image size. This effectively doubles the spatial frequencies.

If we don't have enough pixels (Nyquist Theorem), high-frequency details (textures) turn into low-frequency noise. This is called Aliasing.

Just like simpler trigonometric identities collapse details, simpler grids collapse reality.

3. Visualizing Aliasing

When sampling is too slow for the signal.

import numpy as np
import matplotlib.pyplot as plt

# High frequency wave (Double Angle effect)
t = np.linspace(0, 1, 1000)
signal = np.sin(2 * np.pi * 50 * t) # 50 Hz

# Bad Sampling Rate (40 Hz - Violates Nyquist)
t_sample = np.linspace(0, 1, 40)
sampled = np.sin(2 * np.pi * 50 * t_sample)

# Result: The sampled points will look like a completely different
# low-frequency wave (10 Hz) that doesn't exist.
print("Aliasing detected: The ghost signal appears due to poor sampling.")

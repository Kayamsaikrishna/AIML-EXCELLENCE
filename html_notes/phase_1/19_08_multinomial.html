Prob 1.4 Many Categories

The Multinomial Distribution

Beyond binary: What if the coin has \(k\) sides?

Generalizing the Binomial

The Binomial distribution handles 2 outcomes (Heads/Tails).
The Multinomial distribution handles \(k\) outcomes (e.g., Rolling a generic die, classifying an image as Cat/Dog/Bird/Car).

1. The Formula

We perform \(n\) independent trials. Each trial results in one of \(k\) categories with probabilities \(p_1, p_2, \dots, p_k\) (where \(\sum p_i = 1\)).

Let \(X_i\) be the count of outcome \(i\). $$ P(X_1=x_1, \dots, X_k=x_k) = \frac{n!}{x_1! x_2! \dots x_k!} p_1^{x_1} p_2^{x_2} \dots p_k^{x_k} $$ where \(\sum x_i = n\).

The term \(\frac{n!}{x_1! \dots x_k!}\) is the Multinomial Coefficient.

2. ML Connection: Softmax & Cross-Entropy

Deep Learning NLP

Categorical Classification

In a Neural Network classifying handwritten digits (0-9), the output layer has 10 neurons. We apply the Softmax function to convert logits into probabilities \(p_1, \dots, p_{10}\).

The target label is a "one-hot" vector (e.g., \([0, 0, 1, 0, \dots]\)). This is essentially a single draw from a Multinomial distribution (\(n=1\)).

The loss function is Categorical Cross-Entropy, which is derived from the negative log-likelihood of the Multinomial distribution.

NLP: Bag of Words

In classic NLP, a document is represented as a count of words from a vocabulary of size \(V\). If we assume words are generated independently (Naive Bayes assumption), the document is modeled as a draw from a Multinomial distribution with parameters \(n\) (doc length) and \(p\) (word probabilities).

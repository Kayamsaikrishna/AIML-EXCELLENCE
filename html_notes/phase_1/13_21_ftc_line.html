Fundamental Theorem for Line Integrals

Only the destination matters.

The Theorem

Just as \( \int_a^b f'(x) dx = f(b) - f(a) \), there is a version for vector fields. If \( \vec{F} = \nabla f \) (Conservative Field), then: \[ \int_C \nabla f \cdot d\vec{r} = f(\vec{r}(b)) - f(\vec{r}(a)) \]

This means if you know the Potential Function \( f \), you don't need to parameterize the messy path \( C \). You can just evaluate the potential at the start and end points.

2. AI/ML Connection: Lyapunov Stability

Guaranteed Convergence

In control theory and AI stability analysis, we look for a Lyapunov Function \( V(x) \). This acts like a "Potential Energy" function for the system.

If we can show that the system always moves "downhill" on this potential surface (\( \dot{V} < 0 \)), the Fundamental Theorem guarantees that the system will eventually settle at a stable equilibrium (End State), regardless of the crazy path (trajectory) it takes to get there. This proves that our robot/AI model won't explode or oscillate forever.

3. Python: Path Independence Demo

lyapunov_path.py
import numpy as np

# Potential Function f(x,y) = x^2 + y^2 (Bowl)
def potential(x, y):
    return x**2 + y**2

# Start (-2, 2), End (0, 0)
start_val = potential(-2, 2) # 4 + 4 = 8
end_val = potential(0, 0)    # 0

# Work done by Gradient Field moving to minimum
work_done = end_val - start_val 
print(f"Change in Potential: {work_done}")
# Result: -8. The system lost 8 units of energy to stabilize.
# This result is TRUE regardless of how wobbly the path was.

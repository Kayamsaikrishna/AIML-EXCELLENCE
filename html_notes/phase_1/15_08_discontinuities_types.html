08. Types of Discontinuities

Identifying when and how functions break.

1. Three Major Categories

1. Removable

The limit exists, but the function value is different or undefined. It's just a tiny "hole".

Example: \(f(x) = \frac{x^2-1}{x-1}\) at \(x=1\).

2. Jump

The left and right limits both exist but are not equal. The function "jumps" from one value to another.

Example: Step functions like Heavyside.

3. Infinite

At least one side of the limit goes to \(\infty\) or \(-\infty\). The graph follows a vertical asymptote.

Example: \(1/x^2\) at \(x=0\).

2. Essential vs. Non-essential

Removable discontinuities are often called "non-essential" because we can fix them by redefining a single point. Jump and Infinite discontinuities are "essential" features of the function's structure.

3. AI/ML Connection: Edge Cases & Anomalies

When Data "Jumps"

In Real-world AI applications like Anomaly Detection, we look for discontinuities in sensor data. A temperature sensor suddenly jumping from 25°C to 100°C in one millisecond is a Jump Discontinuity in time-series data, indicating a sensor fault or an emergency rather than a smooth physical process.

4. Python: Detecting a Jump

# Function with a jump at x=0
def f(x):
    return 1 if x > 0 else -1

epsilon = 1e-6
val_left = f(-epsilon)
val_right = f(epsilon)

if abs(val_left - val_right) > 0.1:
    print(f"Jump Discontinuity detected! Gap size: {abs(val_left - val_right)}")

Prob 1.4 Fourier Domain

Characteristic Functions

Universal fingerprint.

Definition

The Characteristic Function \(\phi_X(t)\) is the MGF assessed at imaginary values \(it\): \[ \phi_X(t) = E[e^{itX}] \] This always exists for any random variable! It is essentially the Fourier Transform of the PDF.

2. ML Connection: CLT Proof

Central Limit Theorem

Why does adding random variables creates a Normal distribution? Using Characteristic Functions, we can prove that: \[ \phi_{\sum X_i} (t) = (\phi_X(t))^n \] As \(n \to \infty\), this product converges to the function \(e^{-t^2/2}\), which is exactly the Characteristic Function of a Gaussian!

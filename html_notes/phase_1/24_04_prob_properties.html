04. Properties of Probability

The logical consequences of the axioms.

1. Derived Rules

From the three Kolmogorov axioms, we can logically derive several rules that make probability calculations easier:

  • Probability of Null Set: \(P(\emptyset) = 0\).
  • Bound Rule: For any event \(A\), \(0 \leq P(A) \leq 1\).
  • Monotonicity: If \(A \subseteq B\), then \(P(A) \leq P(B)\).
  • Inclusion-Exclusion (2 Events): \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\).

2. Importance of the Intersection

The subtraction of \(P(A \cap B)\) is necessary because if you simply add \(P(A)\) and \(P(B)\), you "double-count" the outcomes that belong to both. This rule is fundamental whenever you combine multiple classifications or filters.

3. AI/ML Connection: The Probability Budget

Confidence Calibration

In Anomaly Detection, we use the Bound Rule to decide if a data point is "Out-of-Distribution". If an AI model outputs probabilities that sum to more than 1 (or less than 0), it is "Uncalibrated".

Furthermore, Inclusion-Exclusion is used in complex search queries and recommendation engines. If an AI recommends a product because it is "Cheap" (Event A) OR "Highly Rated" (Event B), it must correctly handle the products that are both. Failing to account for the intersection results in biased recommendations. Understanding these properties ensures that your AI's "Confidence" actually reflects the reality of the data distribution.

4. Python: Inclusion-Exclusion Demo

# S = {1...100}
# P(Multiples of 3 OR Multiples of 5)

p_3 = len([x for x in range(1, 101) if x % 3 == 0]) / 100 # 0.33
p_5 = len([x for x in range(1, 101) if x % 5 == 0]) / 100 # 0.20
p_3_and_5 = len([x for x in range(1, 101) if x % 15 == 0]) / 100 # 0.06

p_union = p_3 + p_5 - p_3_and_5

print(f"P(3 or 5): {p_union:.2f}")

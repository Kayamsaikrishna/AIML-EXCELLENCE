Calculus 1.3 Interactions

The Product Rule

When two dynamic systems interact (multiply), their total rate of change is a weighted sum of their individual changes.

Not Just u'v'

A common mistake is thinking \((uv)' = u'v'\). This is wrong. If a rectangle's length and width both grow, the new area isn't just the corner piece; it's the added strips along both original sides.

1. The Formula

For two differentiable functions \(u(x)\) and \(v(x)\):

\[ \frac{d}{dx}[u(x) \cdot v(x)] = u'(x)v(x) + u(x)v'(x) \]

The derivative sums the two main strips of growth. The tiny corner (du*dv) vanishes.

2. AI/ML Connection: Gating Mechanisms

Backprop Through Gates

In LSTMs (Long Short-Term Memory) and Transformers, we use "Gates" to control information flow. A gate is a multiplication:

\[ h_t = o_t \odot \tanh(c_t) \]

Here, the output gate \(o_t\) multiplies the memory content. When we adjust weights via Backpropagation, gradients must flow through this multiplication. The Product Rule tells us exactly how the error signal splits:

  • Part of the error signal updates the gate ($o_t$).
  • Part updates the memory ($c_t$).

3. Python: Symbolic Verification

product_rule_check.py
import sympy as sp

x = sp.Symbol('x')

# Define u and v
u = x**2
v = sp.sin(x)

# 1. Product Rule Formula: u'v + uv'
u_prime = sp.diff(u, x)
v_prime = sp.diff(v, x)
formula_result = u_prime * v + u * v_prime

# 2. Direct Differentiation using SymPy
direct_result = sp.diff(u * v, x)

print(f"u(x) = {u}, v(x) = {v}")
print(f"Formula (u'v + uv'): {formula_result}")
print(f"Direct Diff:          {direct_result}")

# Check Equality
if sp.simplify(formula_result - direct_result) == 0:
    print("\n✅ Product Rule Vindicated!")
else:
    print("\n❌ Something went wrong.")

11. Parametric Bootstrap

Combining Model Assumptions with Resampling.

1. The Concept

The Parametric Bootstrap differs from the non-parametric version because it assumes the population follows a specific distribution (like Normal, Poisson, or Gamma).

Instead of resampling from the data, we:

  1. Estimate the parameters ($\hat{\theta}$) from the original sample.
  2. Assume the "True" population is exactly that distribution.
  3. Generate new "resamples" by drawing thousands of new values from that theoretical distribution.

2. Why use it?

If you *know* the data is roughly Normal, the Parametric Bootstrap is much more powerful and accurate than the non-parametric version, especially for tiny datasets. It effectively "smooths out" the noise in your sample using the structure of the mathematical model. It serves as a bridge between pure theory and pure data-driven estimation.

3. AI/ML Connection: Generative Modeling and Synthetic Data

The Logic of Simulation

In AI, the Parametric Bootstrap is the heart of Data Augmentation via Simulation.

If you are building an AI for Algorithmic Trading, you only have one "History" of the stock market. You can't just resample with replacement because the time dependency Matters. Instead, you fit a model (like an ARMA or GARCH process) to the data and then use the Parametric Bootstrap to simulate 10,000 "Alternative Histories" of the market. You then train your AI on these synthetic worlds. This is also how Generative Adversarial Networks (GANs) and Variational Autoencoders (VAEs) operate: they learn the "Parameters" of the image space and then "Resample" from that space to create new, synthetic cat pictures. Understanding this theorem tells you that synthetic data is not "Magic"—it is a mathematically valid way to explore the uncertainty of your model's beliefs.

4. Python: Parametric Resampling

# Original Sample (n=20)
data = np.random.normal(50, 5, 20)

# 1. Estimate params
mu_hat = np.mean(data)
sigma_hat = np.std(data, ddof=1)

# 2. Parametric Bootstrap
boot_means = []
for _ in range(5000):
    # Generating from the ESTIMATED distribution, not the raw data
    resample = np.random.normal(mu_hat, sigma_hat, 20)
    boot_means.append(np.mean(resample))

# 95% CI
low, high = np.percentile(boot_means, [2.5, 97.5])
print(f"Parametric Bootstrap CI: [{low:.2f}, {high:.2f}]")

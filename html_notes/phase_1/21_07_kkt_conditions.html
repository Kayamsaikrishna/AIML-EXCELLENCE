07. Karush-Kuhn-Tucker (KKT) Conditions

Solving optimization with inequality constraints.

1. Generalizing Lagrange

Lagrange multipliers handle equality constraints (\(g=k\)). But what if the constraint is an Inequality (\(g(x, y) \leq k\))? In this case, we use the KKT Conditions.

For a point \(\mathbf{x^*}\) to be an optimum, it must satisfy four conditions:

  • Stationarity: \(\nabla f - \sum \mu_i \nabla g_i = 0\)
  • Primal Feasibility: \(g_i(\mathbf{x^*}) \leq 0\)
  • Dual Feasibility: \(\mu_i \geq 0\)
  • Complementary Slackness: \(\mu_i g_i(\mathbf{x^*}) = 0\)

2. Complementary Slackness

This is the most intuitive part: either the multiplier \(\mu_i\) is zero (the constraint isn't "active", meaning the optimum is inside the boundary), OR the constraint \(g_i\) is zero (the optimum is exactly on the boundary).

3. AI/ML Connection: Support Vector Selection

The "Zero Weight" Logic

In Sparse Modeling and SVMs, we want most of our data points to have no influence on the final model to keep it simple.

KKT conditions ensure that only the points that are on the boundary (active constraints) have a non-zero Lagrange multiplier (\(\mu_i > 0\)). These are the "Support Vectors". By looking at the KKT violations during training, AI frameworks (like LIBSVM or Scikit-learn) can identify which data points are "Difficult" and need more attention, while ignoring the easy points that satisfy the classification margin already. KKT is the math of "Filtering for Importance".

4. Python: Inequality via SciPy

# Minimize x^2 + y^2 subject to x + y >= 1.0
from scipy.optimize import minimize

def obj(v): return v[0]**2 + v[1]**2

# fun >= 0
cons = ({'type': 'ineq', 'fun': lambda v: v[0] + v[1] - 1})

# If we start inside the constraint (e.g. at [2, 2]), 
# the solution will roll to the boundary.
res = minimize(obj, [2, 2], constraints=cons)
print(f"Optimal Point: {res.x}") # [0.5, 0.5]

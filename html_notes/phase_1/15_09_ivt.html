09. Intermediate Value Theorem (IVT)

Ensuring no "skipping" of values in a continuous flow.

1. The Theorem

The Intermediate Value Theorem states that if a function \(f\) is continuous on a closed interval \([a, b]\), and \(N\) is any number between \(f(a)\) and \(f(b)\), then there exists at least one number \(c\) in \([a, b]\) such that:

$$ f(c) = N $$

In simple terms: if you start at altitude 10 and end at altitude 20, and the path is continuous, you must cross altitude 15 at some point.

2. Application: Root Finding

One of the most powerful uses of IVT is to prove a function has a root (a zero). If \(f(a)\) is negative and \(f(b)\) is positive, and the function is continuous, there must be some point \(c\) where \(f(c) = 0\).

3. AI/ML Connection: Binary Search & Bisection

Solving for Hyperparameters

When searching for a hyperparameter that results in a target accuracy, we often use the Bisection Method. If a learning rate \(\alpha=0.1\) yields an accuracy of 0.8, and \(\alpha=0.01\) yields 0.9, the IVT guarantees that if the relationship is continuous, there is a learning rate in between that yields exactly 0.85.

This "Existence Proof" is why we are confident that searching within ranges (like in GridSearch or Bayesian Optimization) will eventually hit our target performance.

4. Python: The Bisection Method

# Find the root of f(x) = x^3 - 2 using IVT logic
def f(x):
    return x**3 - 2

# We know f(1) = -1 and f(2) = 6. Continuity ensures a root between 1 and 2.
low, high = 1.0, 2.0
for _ in range(10): # 10 iterations of bisection
    mid = (low + high) / 2
    if f(mid) < 0:
        low = mid # root is in upper half
    else:
        high = mid # root is in lower half

print(f"Approximate Cube Root of 2: {mid:.4f}")

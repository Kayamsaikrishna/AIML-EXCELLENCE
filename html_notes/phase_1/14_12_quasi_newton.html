Optimization 1.7 Smart Approx

Quasi-Newton Methods (BFGS)

Approximating curvature without the heavy lifting.

The Best of Both Worlds

Newton's Method is fast (converges in few steps) but expensive (inverts a huge matrix). Gradient Descent is cheap (linear time) but slow (needs many steps).

Quasi-Newton Methods (like BFGS) bridge the gap. They don't calculate the Hessian directly. Instead, they estimate the inverse Hessian \(\mathbf{H}^{-1}\) iteratively by observing how the gradient changes between steps. It's like building a map of the terrain as you walk.

2. AI/ML Connection: L-BFGS

Limited Memory

Standard BFGS stores an \(N \times N\) matrix approximation. For 1 million params, that's still too big. L-BFGS (Limited-memory BFGS) only stores the last \(m\) updates (e.g., \(m=10\)).

L-BFGS is the default solver for Logistic Regression in Scikit-Learn. It is incredibly efficient for "traditional" ML models (GLMs, SVMs, CRFs) where the parameter count is in the thousands, not billions. In Deep Learning, Adam is preferred because the noise of mini-batches breaks the curvature estimation of L-BFGS.

3. Python: Optimizing Rosenbrock

bfgs_demo.py
from scipy.optimize import minimize
import numpy as np

# The Rosenbrock function (The "Banana" Valley)
# Global minimum at (1,1) inside a long, narrow, curved valley.
# Hard for GD, easy for BFGS.

def rosenbrock(x):
    return (1 - x[0])**2 + 100 * (x[1] - x[0]**2)**2

# Start at (0,0)
x0 = [0, 0]

# 1. Nelder-Mead (Gradient-Free)
res_nm = minimize(rosenbrock, x0, method='Nelder-Mead')
print(f"Nelder-Mead Iterations: {res_nm.nit}")

# 2. BFGS (Quasi-Newton)
res_bfgs = minimize(rosenbrock, x0, method='BFGS')
print(f"BFGS Iterations: {res_bfgs.nit}")
print(f"Optimal X: {res_bfgs.x}")

# BFGS typically solves it in < 50 iters.
# Gradient Descent might take thousands.

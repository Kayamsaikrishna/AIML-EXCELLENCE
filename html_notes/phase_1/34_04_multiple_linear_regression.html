04. Multiple Linear Regression

Controlling for many variables at once.

1. The Multi-Feature Model

In the real world, an outcome $Y$ is almost never caused by just one thing. Multiple Linear Regression (MLR) models $Y$ as a function of multiple independent variables $X_1, X_2, \dots, X_p$:

$$ Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_p X_p + \epsilon $$

Each coefficient $\beta_i$ represents the effect of $X_i$ on $Y$ **while holding all other variables constant**. This is the power of "Control."

2. The Complexity Trap: Collinearity

As we add more features, we risk Multicollinearity: when two features are highly correlated (e.g., 'Height in cm' and 'Height in inches'). This makes the $\beta$ estimates unstable and the matrix hard to invert. This is the first signal that we need **Regularization**.

3. AI/ML Connection: The "Linear Layer" in Deep Learning

The Atomic Unit of Neural Nets

In AI, MLR is the Standard Linear Layer ($Y = WX + b$).

Every "Neuron" in a Neural Network is essentially a Multiple Linear Regression model followed by an activation function. When you train a model, you are performing a massive parallel version of MLR. Understanding the "Control" aspect of coefficients is vital for **Model Explainability (SHAP/LIME)**: we want to know if a feature like 'Credit Score' is truly predictive or if it's just "Stealing the credit" from another correlated feature like 'Annual Income'. By mastering MLR, you understand how AI "allocates" importance across a high-dimensional feature vector.

4. Python: Fitting Multiple Features

# Multiple X columns
X = data[['SqFt', 'Age', 'Bedrooms']]
y = data['Price']

model = LinearRegression().fit(X, y)

# Coefficients for each feature
for feature, coef in zip(X.columns, model.coef_):
    print(f"{feature}: {coef:.2f}")

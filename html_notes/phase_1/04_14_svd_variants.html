1. Definitions

  • Full SVD: The mathematical definition. \( U \) is fully square \( n \times n \). Contains Null Space basis vectors.
  • Compact SVD: Only keeps non-zero singular values. \( U \) is \( n \times r \) where \( r \) is rank. Lossless compression.
  • Truncated SVD: Only keeps the top \( k \) singular values. Lossy compression, but the "optimal" lossy compression (Eckart-Young Theorem).

2. Truncated SVD for NLP

In LSA (Latent Semantic Analysis), we have a Term-Document matrix. We use Truncated SVD to project this sparse, high-dimensional matrix into a dense, low-dimensional "Concept Space".

Synonyms mapping to similar concepts is solved by this truncation.

3. Truncated SVD in Sklearn

import numpy as np
from sklearn.decomposition import TruncatedSVD

# Large matrix
X = np.random.rand(10, 10)

# Keep only top 2 components
# This implicitly computes the k=2 Truncated SVD
svd = TruncatedSVD(n_components=2)
X_reduced = svd.fit_transform(X)

print(f"Original Shape: {X.shape}")
print(f"Reduced Shape: {X_reduced.shape}")

print(f"Explained Variance Ratio: {svd.explained_variance_ratio_}")
# Shows how much info we kept

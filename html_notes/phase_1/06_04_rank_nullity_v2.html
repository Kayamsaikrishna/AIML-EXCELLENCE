1. The Fundamental Theorem

For any linear map \( T: \mathbb{R}^n \to \mathbb{R}^m \):

$$ n = \text{nullity}(T) + \text{rank}(T) $$

This is a conservation law. Input dimensions must either be preserved (landing in the Image) or destroyed (landing in the Kernel). They cannot vanish without a trace.

2. Data Compression

If we matrix multiply a high-dim vector \( x \in \mathbb{R}^{1000} \) by a low-rank matrix \( A \) (Rank 50), the Nullity is necessarily 950.

This means 950 dimensions of information are completely lost (compressed to zero). Whether this is "lossy compression" or "noise removal" depends on whether the signal lived in the Kernel or the Image.

3. Numerical Verification

import numpy as np
from numpy.linalg import matrix_rank

# A 4x4 Singular Matrix
A = np.array([
    [1, 2, 3, 4],
    [2, 4, 6, 8], # Dependent
    [1, 0, 1, 0],
    [0, 1, 0, 1]
])

n = A.shape[1] # Input dimension = 4

# Calculate Rank
rank = matrix_rank(A)

# Calculate Nullity (n - rank)
# Or via scipy.linalg.null_space
from scipy.linalg import null_space
nullity = null_space(A).shape[1]

print(f"Total Dimensions (n): {n}")
print(f"Rank (Preserved):     {rank}")
print(f"Nullity (Lost):       {nullity}")
print(f"Sum: {rank + nullity}")
assert rank + nullity == n

16. Combinations

When order doesn't matter.

1. Selection without Order

A Combination is a selection of items from a larger set where the order of selection does not matter. Choosig $\{A, B\}$ is considered the same as choosing $\{B, A\}$.

2. The Formula ("n choose r")

$$ C(n, r) = \binom{n}{r} = \frac{n!}{r!(n-r)!} $$

This formula essentially takes the total number of permutations $P(n, r)$ and divides by $r!$ to "cancel out" the different orderings of the same set of items.

3. AI/ML Connection: Feature Subset Selection

The Complexity of Choice

In Feature Engineering, we often have hundreds of potential inputs (features) but only want to select a small subset of the best ones.

If you have 100 features and want to pick the best 5 for your model, the Combination Formula tells you there are $\binom{100}{5} = 75,287,520$ possible subsets to evaluate. Because the order of features in a vector doesn't matter to most models, we use combinations. This massive number is why we use AI-driven search (like Forward Selection or LASSO) to find the best subset rather than checking every combination manually. Combinations are the mathematical reason why Feature Selection is a high-compute task.

4. Python: nCr Calculation

from scipy.special import comb

n = 100
r = 5

# Calculation using scipy (handles large numbers efficiently)
total_subsets = comb(n, r, exact=True)

print(f"Selecting {r} items from {n}: {total_subsets:,} ways.")

# Python 3.8+ math.comb
import math
print(f"Confirming with math.comb: {math.comb(n, r):,}")

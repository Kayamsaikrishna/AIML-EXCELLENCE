15. Generalized Linear Models (GLMs) & Link Functions

The unifying framework for all linear modeling.

1. Beyond the Normal Distribution

Standard regression assumes $Y$ is Normal. But what if $Y$ is a count (Poisson) or a probability (Bernoulli)? GLMs generalize linear regression by adding a Link Function** $g(\cdot)$ that connects the linear predictor to the expected value of $Y$.

$$ E[Y|X] = \mu = g^{-1}(X\beta) $$

2. The Three Components

  • Random Component: The probability distribution of $Y$ (e.g., Binomial, Gamma).
  • Systematic Component: The linear predictor $\eta = X\beta$.
  • Link Function: $g(\mu) = \eta$. It squashes the infinite range of $X\beta$ into the appropriate range for $Y$ (e.g., $(0, 1)$ or $(0, \infty)$).

3. AI/ML Connection: The Generalization to Modern Architectures

Linear Algebra meet non-linear range

In AI, GLMs are the blueprint for Every Single Output Layer**.

When you put a Sigmoid on the end of a Neural Network for binary classification, you are technically building a Logistic GLM**. When you use **Softmax** for multi-class, you are building a **Multinomial GLM**. The "Link Function" in statistics is the "Activation Function" in Deep Learning. This connection is vital for **Loss Function design**: the choice of distribution (Random Component) determines your **Cross-Entropy loss**. By mastering GLMs, you understand why we use Log-Loss for probabilities and MSE for continuous values—it's not arbitrary; it's a mathematical requirement of the GLM framework.

4. Python: Fitting a GLM (Poisson)

import statsmodels.api as sm

# Predicting 'Counts' using a Poisson distribution and Log link
model = sm.GLM(y, X, family=sm.families.Poisson())
results = model.fit()

print(results.summary())

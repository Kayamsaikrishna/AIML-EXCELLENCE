05. The Hat Matrix & Projections

The linear algebra machinery of predictions.

1. The Matrix Solution

In matrix form, the OLS prediction is $\hat{Y} = X\beta$. To find the best $\beta$, we solve the Normal Equations:

$$ \hat{\beta} = (X^T X)^{-1} X^T Y $$

Substituting this back into the prediction gives: $\hat{Y} = X(X^T X)^{-1} X^T Y$.

2. Why "Hat" Matrix?

We define $H = X(X^T X)^{-1} X^T$. This is the Hat Matrix because it "Puts a hat on Y" (transforms $Y$ into $\hat{Y}$):

$$ \hat{Y} = H Y $$

Properties: It is Idempotent ($H^2 = H$) and **Symmetric** ($H^T = H$). This confirms it is a valid geometric projection matrix.

3. AI/ML Connection: Attention Mechanisms and Linear Projections

The Math of Focus

In AI, the Hat Matrix logic is the soul of Linear Transformations**.

The core of a Transformer's Attention Mechanism** is a series of projections ($Q, K, V$). By projecting input embeddings into different subspaces, the AI "Attends" to different features. The Hat Matrix also helps in **Anomaly Detection**: the diagonal elements $H_{ii}$ (Leverage) tell the AI how much a specific data point $y_i$ influences its own prediction. If one point has massive leverage, it might be an outlier or a labeling error. Understanding the "Projection" nature of matrices allows AI engineers to optimize **Inference Speed** by using low-rank approximations of these matrices without losing the "Essence" of the data.

4. Python: The Manual Matrix Fit

# The Matrix OLS Solution
# (X'X)^-1 X'y
XtX_inv = np.linalg.inv(X.T @ X)
beta = XtX_inv @ X.T @ y

# The Hat Matrix
H = X @ XtX_inv @ X.T

# Prediction via Hat Matrix
y_hat = H @ y
print(f"Predictions check (SSE): {np.sum((y - y_hat)**2):.4f}")

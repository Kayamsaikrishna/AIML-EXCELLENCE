Calculus 1.3 Change

The Definition of the Derivative

How do we measure change at a single instant? By shrinking the interval of measurement to zero.

The Heart of Machine Learning

Almost all modern AI learning algorithms (Gradient Descent, Backpropagation, Adam) rely on differentiation. The derivative tells us sensitivity: "If I nudge this weight slightly, how much will the error increase?"

1. From Average to Instantaneous

Average Rate of Change

The slope of the Secant Line between points \(x\) and \(x+h\).

\[ m_{sec} = \frac{f(x+h) - f(x)}{h} \]

Instantaneous Rate of Change

The slope of the Tangent Line as \(h\) shrinks to 0.

\[ f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} \]

2. AI/ML Connection: Numerical Gradients

Finite Differences

In deep learning framworks like PyTorch, we compute exact gradients using the Chain Rule (Automatic Differentiation). However, to test if our implementation is correct, we use the definition directly with a tiny \(h\) (e.g., \(1e-7\)). This is called Gradient Checking.

\[ \frac{\partial \mathcal{L}}{\partial w} \approx \frac{\mathcal{L}(w+\epsilon) - \mathcal{L}(w-\epsilon)}{2\epsilon} \]

(We often use the "Two-Sided" or Central Difference formula because it's more accurate than the standard one-sided definition.)

3. Python: Implementing the Definition

gradient_check.py
import numpy as np
import matplotlib.pyplot as plt

def f(x):
    return x**2  # We know analytical derivative is 2x

def analytical_derivative(x):
    return 2*x

def numerical_derivative(func, x, h=1e-5):
    # Definition of Derivative
    return (func(x + h) - func(x)) / h

x_target = 3.0
exact_slope = analytical_derivative(x_target)
approx_slope = numerical_derivative(f, x_target)

print(f"Target Point x: {x_target}")
print(f"Analytical Slope (2x): {exact_slope}")
print(f"Numerical Slope (Lim h->0): {approx_slope:.6f}")
print(f"Error: {abs(exact_slope - approx_slope):.10f}")

# Simulating h -> 0
h_values = [0.1, 0.01, 1e-4, 1e-8]
print("\nConvergence Check:")
for h in h_values:
    est = numerical_derivative(f, x_target, h)
    print(f"h={h:<10} | est={est:.8f} | diff={abs(exact_slope - est):.8f}")

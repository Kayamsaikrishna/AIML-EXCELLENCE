1. The Goal

We want to find a new basis Direction \( \mathbf{u} \) such that when we project the data onto \( \mathbf{u} \), the spread (Variance) is maximized.

$$ \sigma^2_u = \frac{1}{n} \sum (x_i \cdot u)^2 $$

Mathematically, this direction is simply the Eigenvector of the Covariance Matrix corresponding to the largest Eigenvalue.

2. Feature Decorrelation

Raw data features are often correlated (e.g., Height and Weight). This confuses simple classifiers.

PCA rotates the data so that the new features (Principal Components) are strictly uncorrelated (Diagonal Covariance). This makes training faster and more stable, acting as a form of "Whitening".

3. Scikit-Learn PCA

Reducing 2D data to 1D.

import numpy as np
from sklearn.decomposition import PCA

# Correlated Data (y approx x)
X = np.array([
    [1, 1],
    [2, 2.1],
    [3, 2.9],
    [4, 4.1]
])

# Initialize PCA (Keep 1 Axis)
pca = PCA(n_components=1)

# Fit and Transform
X_reduced = pca.fit_transform(X)

print(f"Original Shape: {X.shape}")
print(f"Reduced Shape:  {X_reduced.shape}")

print("\nExplained Variance Ratio:")
print(pca.explained_variance_ratio_) 
# Likely > 99%. Almost all info is along the main diagonal.

print("\nComponents (The new Basis):")
print(pca.components_)
# Should be roughly [0.707, 0.707] (45 degree line)

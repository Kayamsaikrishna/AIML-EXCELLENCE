1. What Can We Reach?

The Column Space \( C(A) \) is simply the Span of the columns of \( A \).

$$ \text{range}(A) = \{ \mathbf{y} \in \mathbb{R}^m \mid \mathbf{y} = A\mathbf{x} \text{ for some } \mathbf{x} \} $$

When we solve \( A\mathbf{x} = \mathbf{b} \), we are asking: "Is \( \mathbf{b} \) a linear combination of the columns of \( A \)?"

2. The Generator's Limits

A GAN Generator takes random noise \( z \) and maps it to an image \( G(z) \). The set of ALL possible images the GAN can ever create is its Range (or Image manifold).

If a real photo lies outside this Column Space, the GAN can never generate it perfectly, no matter what input \( z \) you choose. This is "Mode Collapse" or limited capacity.

3. Checking Solvability

Can we reach the target?

import numpy as np

# A Matrix (Span is a Plane in 3D: z=0)
A = np.array([
    [1, 0],
    [0, 1],
    [0, 0]
])

# Two Targets
b1 = np.array([5, 5, 0])  # Inside Span
b2 = np.array([5, 5, 10]) # Outside Span

# Check Rank consistency (Rouche-Capelli Theorem)
# Rank(A) vs Rank([A|b])

rank_A = np.linalg.matrix_rank(A)

# Augmented Matrix [A|b1]
Aug1 = np.column_stack((A, b1))
rank_Aug1 = np.linalg.matrix_rank(Aug1)

# Augmented Matrix [A|b2]
Aug2 = np.column_stack((A, b2))
rank_Aug2 = np.linalg.matrix_rank(Aug2)

print(f"Rank(A): {rank_A}")
print(f"Rank(A|b1): {rank_Aug1} -> {'Solvable' if rank_A == rank_Aug1 else 'Impossible'}")
print(f"Rank(A|b2): {rank_Aug2} -> {'Solvable' if rank_A == rank_Aug2 else 'Impossible'}")

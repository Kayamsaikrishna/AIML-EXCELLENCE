23. Newton's Method

Using derivatives to find solutions iteratively.

1. The Goal: Root Finding

Newton's Method is an iterative numerical technique for finding the roots (zeros) of a real-valued function \(f(x) = 0\).

2. The Algorithm

We start with a guess \(x_0\). We find the tangent line at \((x_0, f(x_0))\) and see where it hits the x-axis. That x-intercept becomes our new guess \(x_1\). The update formula is:

$$ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} $$

This process is repeated until the change in \(x\) is negligible (convergence).

3. AI/ML Connection: The Newton Optimizer

Second-Order Training

When we apply Newton's Method to find where the derivative (gradient) of a loss function is zero (\(f'(x) = 0\)), we end up with the second-order update rule:

$$ w_{n+1} = w_n - \frac{f'(w_n)}{f''(w_n)} $$

In multivariable AI, this is \(w \leftarrow w - H^{-1} \nabla J\), where \(H\) is the Hessian matrix. While Gradient Descent is like a person walking down a hill, Newton Optimization is like a person who knows exactly where the bottom of the valley is based on the curve. It converges in far fewer steps, but requires calculating complex second-order derivatives.

4. Python: Newton's Method for \(\sqrt{2}\)

# Solving x^2 - 2 = 0
def f(x): return x**2 - 2
def df(x): return 2*x

x_guess = 1.0 # Initial guess

for i in range(5):
    x_guess = x_guess - f(x_guess) / df(x_guess)
    print(f"Iteration {i+1}: {x_guess:.10f}")

print(f"Final Solution: {x_guess:.10f}")

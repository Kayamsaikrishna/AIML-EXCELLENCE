Skewness & Kurtosis

Not everything is a Bell Curve.

Definitions

Skewness (3rd Moment): Measures asymmetry.

  • Positive Skew: Long tail to the RIGHT (e.g., Income distribution).
Kurtosis (4th Moment): Measures "tailedness" (outliers).
  • High Kurtosis (Leptokurtic): Heavy tails. More outliers than Normal.
  • Normal Distribution Kurtosis = 3.

2. ML Connection: Data Transformation

Log Transform

Many ML algorithms (Linear Regression, KNN) assume symmetric data. Real-world data (prices, duration) is often highly positive-skewed. Applying a Log Transform (\(y = \ln(x)\)) compresses the long tail and makes the distribution more Normal (Gaussian), improving model performance.

3. Python: Measuring Shape

skew_kurt.py
from scipy.stats import skew, kurtosis
import numpy as np

# Generate heavy-tailed data (Exponential)
data = np.random.exponential(scale=1.0, size=1000)

print(f"Skewness: {skew(data):.2f}") # Exp dist skew is 2
print(f"Kurtosis: {kurtosis(data):.2f}") # Exp dist xs kurt is 6

# Take Log
log_data = np.log(data)
print(f"Log Skew: {skew(log_data):.2f}") # Much closer to 0 (Left skewed essentially)

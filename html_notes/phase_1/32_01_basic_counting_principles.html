Combinatorics Fundamentals

Basic Counting Principles

Counting without Enumerating. The fundamental rules of Sum and Product that allow us to calculate the size of massive search spaces without ever seeing the individual items.

The Combinatorial Explosion

In AI, we often deal with search spaces so large they exceed the number of atoms in the universe. Understanding the rules of counting allows us to reason about the feasibility of an algorithm before we write a single line of code.

1. The Product Rule (Multiplication Principle)

If a task can be broken down into a sequence of steps, and there are \(n_1\) ways to do step 1, \(n_2\) ways to do step 2, and so on... then the total number of ways to complete the task is the product.

$$ N = n_1 \times n_2 \times ... \times n_k $$

Example: A password consists of 3 lowercase letters followed by 2 digits. How many possibilities?

Steps: L1(26) × L2(26) × L3(26) × D1(10) × D2(10) = \(26^3 \times 10^2 = 1,757,600\).

2. The Sum Rule (Addition Principle)

If a task can be done in either of two ways (that cannot be done at the same time), and there are \(n_1\) ways to do it the first way and \(n_2\) ways to do it the second... the total number of ways is the sum.

$$ N = n_1 + n_2 $$

Example: A student can choose a project from List A (10 topics) OR List B (15 topics). Total choices = \(10 + 15 = 25\).

Deep Learning Architecture

Why Counting matters in AI

  • Parameter Counting: In a Transformer layer, the number of weights in the query projection is (Embedding Dimension) × (Head Dimension) × (Number of Heads). This is the Product Rule in action.
  • Hyperparameter Search: If you have 3 choices for learning rate, 4 choices for batch size, and 2 choices for optimizer... you have \(3 \times 4 \times 2 = 24\) possible configurations to test (Grid Search).
  • State Space Complexity: In games like Chess or Go, the branching factor (number of legal moves) multiplied by the depth of the game defines the "Game Tree Complexity." We use counting to prove that brute-force search is impossible, necessitating techniques like Reinforcement Learning.
  • Data Augmentation: If we apply 5 independent augmentations (Rotate, Flip, Crop, Color, Noise) to an image dataset, we are multiplying our effective dataset size by \(2^5 = 32\).

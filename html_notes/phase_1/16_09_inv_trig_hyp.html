09. Inverse Trig and Hyperbolic Derivatives

Differentiation of the "S" and "H" functions.

1. Inverse Trigonometric Derivatives

$$ \frac{d}{dx} \arcsin x = \frac{1}{\sqrt{1-x^2}} $$ $$ \frac{d}{dx} \arccos x = -\frac{1}{\sqrt{1-x^2}} $$ $$ \frac{d}{dx} \arctan x = \frac{1}{1+x^2} $$

2. Hyperbolic Functions (tanh)

Hyperbolic functions are combinations of exponentials. They are extremely common in Neural Networks.

$$ \sinh x = \frac{e^x - e^{-x}}{2}, \quad \cosh x = \frac{e^x + e^{-x}}{2} $$ $$ \frac{d}{dx} \sinh x = \cosh x, \quad \frac{d}{dx} \cosh x = \sinh x $$

3. AI Connection: The Tanh Activation

The Hyperbolic Tangent (\(\tanh\)) was the standard activation for hidden layers before ReLU became popular. Its derivative is:

$$ \frac{d}{dx} \tanh x = 1 - \tanh^2 x $$

Like Sigmoid, this can be computed using only the function value, saving substantial compute during backpropagation. It maps inputs to \((-1, 1)\), which is often preferred for zero-centered data distributions.

4. Python: tanh and its Gradient

import numpy as np

def tanh(x): return np.tanh(x)
def tanh_grad(x): return 1 - np.tanh(x)**2

x = 0.5
print(f"tanh(0.5): {tanh(x):.4f}")
print(f"gradient: {tanh_grad(x):.4f}")

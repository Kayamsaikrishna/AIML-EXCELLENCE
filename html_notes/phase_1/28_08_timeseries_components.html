Stats 1.8 Forecasting

Time Series Components

Decomposing the past to predict the future. The four pillars that make up any temporal signal.

The Anatomy of Time

A Time Series is not just a bunch of numbers in order. It is a "Layer Cake" of different temporal effects stacked on top of each other.

To forecast accurately, we first have to "unbake" the cake and identify each layer.

1. The Four Pillars

1. Trend (\(T\))

The long-term upward or downward movement (e.g., global population growth). It’s the "Story" the data tells over years.

2. Seasonality (\(S\))

A repeating pattern over a fixed period (e.g., high ice cream sales every July). It’s about the "Calendar".

3. Cyclicity (\(C\))

Long-term fluctuations that are NOT periodic (e.g., economic recessions). They are unpredictable in duration.

4. Irregularity / Noise (\(I\))

Random errors, shocks, or outliers. This is the part we can't explain.

2. Additive vs. Multiplicative

Additive Model

\( Y = T + S + C + I \)

Used when the seasonal variation is constant regardless of the trend. (e.g., Always +100 sales in December).

Multiplicative Model

\( Y = T \times S \times C \times I \)

Used when seasonality grows with the trend. (e.g., Sales grow by 20% every December, so the raw peak gets bigger as the company grows).

3. ML Connection: Feature Extraction

Deep Learning Feature Eng

Turning Time into Features

Classical models (like ARIMA) handle components internally. Modern ML models (like XGBoost or LSTMs) need you to feed them these components as features.

  • Extraction: We create "Date Features" like `is_weekend`, `month_sin`, `day_of_year`. These explicitly tell the model about the Seasonality component.
  • De-trending: Before feeding data into a Neural Network, we often "De-trend" it by subtracting the mean or using differencing. This makes the data Stationary, which is easier for the network to learn.
  • STL Decomposition: `Seasonal-Trend decomposition using LOESS` is a standard pre-processing tool. It splits your data into three separate signals. You can then use a different model to predict each signal (e.g., a Linear model for Trend and a XGBoost for the Residuals).
Pro-Tip: If your time series plot looks like a "Fan" (the squiggles get bigger as you go right), it's Multiplicative. Take the Log of the data to convert it into an Additive model!

04. Negative Binomial Distribution

Generalizing the wait for $r$ successes.

1. Definition

A random variable $X$ follows a Negative Binomial Distribution if it represents the number of Bernoulli trials (success prob $p$) required to achieve exactly $r$ successes.

$$ P(X=k) = \binom{k-1}{r-1} p^r (1-p)^{k-r} \quad \text{for } k=r, r+1, \dots $$

Note: When $r=1$, this simplifies to the Geometric distribution.

2. Overdispersion

One of the most important statistical uses of the Negative Binomial is modeling Count Data where the variance is significantly larger than the mean. While the Poisson distribution requires $Var(X) = E[X]$, the Negative Binomial allows for $Var(X) > E[X]$, making it more flexible for real-world datasets.

3. AI/ML Connection: Topic Modeling and Genomics

Modeling Word Counts

In **Natural Language Processing (NLP)**, the Negative Binomial is used to model word distributions in documents.

Unlike simple models that assume words appear independently (Poisson), real language is "bursty"—once a word appears, it's likely to appear again. The Negative Binomial captures this "burstiness" and overdispersion. It is also the standard distribution for **Genomics AI**, where it models the number of RNA sequence reads for a gene. In **Recommendation Systems**, it can model "engagement counts" (like number of songs played), providing a more robust alternative to Poisson regression when user behavior is highly variable.

4. Python: Count Modeling

from scipy.stats import nbinom

# Wait for r=3 successes, p=0.2
r, p = 3, 0.2

# Probability it takes 15 trials
# (nbinom in scipy counts failures: n = k - r)
print(f"P(X=15): {nbinom.pmf(15-r, r, p):.4f}")

# Stats
print(f"Mean: {r/p}") # 15.0
print(f"Var: {r*(1-p)/(p**2)}") # 60.0 (Var > Mean)

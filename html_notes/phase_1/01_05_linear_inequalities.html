1. Linear Separability & The XOR Problem

A dataset is Linearly Separable if there exists a hyperplane that perfectly divides the two classes.

The First AI Winter (1969)

Minsky and Papert proved that a single layer Perceptron (a linear inequality) cannot learn XOR.

$$ \text{XOR}(0,0) = 0, \quad \text{XOR}(1,1) = 0 $$ $$ \text{XOR}(0,1) = 1, \quad \text{XOR}(1,0) = 1 $$

No straight line can separate these points. This discovery froze AI funding for a decade until Multi-Layer Perceptrons (MLPs) were popularized.

2. Inequalities as Constraints

In Deep Learning, inequalities often appear as constraints on the loss function.

Support Vector Machines (SVM)

We want to maximize the margin subject to ensuring all points are correctly classified:

$$ y_i (w \cdot x_i + b) \ge 1 \quad \forall i $$

Wasserstein GANs (WGAN)

The Critic network must satisfy the Lipschitz Constraint:

$$ || \nabla D(x) || \le 1 $$

We enforce this via "Gradient Penalty" or "Weight Clipping".

3. The Perceptron From Scratch

Implementing the algorithm that updates weights when an inequality is violated.

import numpy as np

class Perceptron:
    def __init__(self, n_features, lr=0.1):
        self.weights = np.zeros(n_features)
        self.bias = 0.0
        self.lr = lr

    def predict(self, x):
        # The Inequality Check: w.x + b >= 0
        linear_output = np.dot(x, self.weights) + self.bias
        return np.where(linear_output >= 0, 1, 0)

    def train(self, X, y, epochs=10):
        for _ in range(epochs):
            for idx, x_i in enumerate(X):
                y_pred = self.predict(x_i)
                # Update rule only triggers on error
                update = self.lr * (y[idx] - y_pred)
                self.weights += update * x_i
                self.bias += update

# Test on AND gate (Linearly Separable)
X = np.array([[0,0], [0,1], [1,0], [1,1]])
y = np.array([0, 0, 0, 1])

p = Perceptron(2)
p.train(X, y)
print(f"Weights: {p.weights}, Bias: {p.bias}")
print(f"Predictions: {p.predict(X)}") # Should be [0 0 0 1]

5. Linear Inequalities & Decision Boundaries

An equation (\(=\)) is a line. An inequality (\(>\)) is a Region. This is how machines classify the world.

1. The Half-Plane

When you solve an equation like \( y = 2x + 1 \), you get a specific set of points on a line. When you solve an inequality like \( y > 2x + 1 \), you get infinite points—an entire "Half-Plane".

Symbols & Syntax

  • \( > \) Greater Than: Everything ABOVE the line (Dashed line).
  • \( < \) Less Than: Everything BELOW the line (Dashed line).
  • \( \ge, \le \) Inclusive: Includes the boundary itself (Solid line).

Engineering Context: Constraints

In Linear Programming (Optimization), we rarely have exact equalities. We have Constraints.

  • "Budget must be less than $1000" (\( B \le 1000 \))
  • "Speed must be above 20mph" (\( S > 20 \))

The solution isn't a single point, but a Feasible Region where all constraints are satisfied.

2. The Decision Boundary

The most fundamental unit of Deep Learning (the Neuron) is essentially a Linear Inequality check.

$$ \underbrace{w \cdot x + b}_{\text{Score}} > 0 $$
Figure 1: A Linear Classifier. The dashed line is the "Decision Boundary". Points on one side are classified as Positive, the others as Negative.

What happens on the line?

If \( w \cdot x + b = 0 \), the model is exactly 50/50 unsure. This is the point of maximum entropy (uncertainty). In practice, we usually default to Class 1 or Class 0, but ideally, the model should output 0.5 probability.

3. Coding a Linear Classifier

How do we check an inequality in Python? It turns into a boolean mask.

// Numpy: Vectorized Inequality Check
import numpy as np

# Weights (w1, w2) and Bias
w = np.array([0.5, -0.5])
b = 0.0

# 3 Data Points (x1, x2)
# P1: (2, 1) -> Score: 0.5*2 - 0.5*1 = 0.5 (>0, Class 1)
# P2: (1, 2) -> Score: 0.5*1 - 0.5*2 = -0.5 (<0, Class 0)
X = np.array([
    [2, 1],
    [1, 2],
    [10, 10] # P3: 5 - 5 = 0 (On Boundary)
])

# 1. Compute Scores (Linear Equation)
scores = np.dot(X, w) + b
# scores = [0.5, -0.5, 0.0]

# 2. Check Inequality (Activation)
predictions = scores > 0

print(f"Scores: {scores}")
print(f"Classes: {predictions.astype(int)}") 
# Output: [1, 0, 0] (False maps to 0)

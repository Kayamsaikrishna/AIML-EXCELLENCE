30. Sparse Matrices in AI

Efficient computing for mostly empty data.

1. What is Sparsity?

A matrix is Sparse if the vast majority of its elements are zero. Storing all those zeros is a massive waste of memory and compute (\( 0 \times x = 0 \) is a redundant calculation).

Storage Formats

  • COO (Coordinate): Stores (row, col, value) tuples. Best for building matrices.
  • CSR (Compressed Sparse Row): Optimized for fast row-access and matrix-vector multiplication.
  • CSC (Compressed Sparse Column): Optimized for column-access and slicing.

2. Large Scale AI Applications

NLP and Graphs

In many real-world domains, data is naturally sparse:

  • TF-IDF / One-Hot Encoding: In a vocabulary of 50k words, a single document only contains a few hundred. 99% of the matrix is zero.
  • Adjacency Matrices: In a social network with 1M users, each person has ~200 friends. The adjacency matrix is 99.98% sparse.
  • Model Pruning: We "prune" small weights in neural networks to make them sparse, allowing them to run on low-power mobile devices.

3. Python: Sparse Computing with Scipy

import numpy as np
from scipy.sparse import csr_matrix

# Create a largely empty matrix
data = np.zeros((1000, 1000))
data[42, 42] = 1.0
data[99, 1] = 5.0

# Convert to CSR (Compress it)
sparse_data = csr_matrix(data)

print(f"Dense size in memory: {data.nbytes} bytes")
print(f"Sparse size (approx): {sparse_data.data.nbytes} bytes")

# Fast multiplication works natively
vector = np.random.rand(1000)
result = sparse_data @ vector # Dramatically faster than dense @

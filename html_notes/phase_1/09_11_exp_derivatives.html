Calculus 1.3 Special Number e

Exponential Derivatives

"I am my own derivative." — The number e.
The only function that describes its own rate of change.

The Natural Rate

The number \(e\) (2.718...) isn't arbitrary. It's the unique base where the slope of the curve \(y=e^x\) is exactly equal to its height \(y\). If you own \(e^x\) dollars, your interest payment is exactly \(e^x\) dollars/year.

1. The Formulae

Natural Exponential:

\[ \frac{d}{dx}[e^x] = e^x \]

With Chain Rule (Common in ML):

\[ \frac{d}{dx}[e^{g(x)}] = e^{g(x)} \cdot g'(x) \]

General Exponential (Base a):

\[ \frac{d}{dx}[a^x] = a^x \ln(a) \]

(Since \(a^x\) grows faster or slower than \(e^x\), we need the scaling factor \(\ln(a)\).)

2. AI/ML Connection: The Sigmoid Shortcut

Vanishing Gradients

The exponential is the core of the Sigmoid activation function \(\sigma(x) = \frac{1}{1+e^{-x}}\). Its derivative has a beautiful property: \[ \sigma'(x) = \sigma(x) \cdot (1 - \sigma(x)) \]

Why this matters: 1. Speed: We don't need to recompute exponentials during backprop; we usually just reuse the forward pass output. 2. Vanishing Gradient: Notice the term \(\sigma(x)(1-\sigma(x))\). The maximum value of this is \(0.25\) (at x=0). This means every time we backprop through a Sigmoid layer, we lose 75% of our error signal. This is why deep networks couldn't be trained until ReLU came along!

3. Python: Visualizing the Gradient Vanish

sigmoid_vanish.py
import numpy as np
import matplotlib.pyplot as plt

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)

x_vals = np.linspace(-10, 10, 200)
y_vals = sigmoid(x_vals)
grad_vals = sigmoid_derivative(x_vals)

print("Sigmoid(0):", sigmoid(0))         # 0.5
print("Derivative(0):", sigmoid_derivative(0)) # 0.25 (Max)

print("Sigmoid(5):", sigmoid(5))         # ~0.99
print("Derivative(5):", sigmoid_derivative(5)) # ~0.006 (Tiny!)

# Note: In a real notebook, we would plot this.
# You would see the bell-shaped derivative curve peaking at 0.25,
# and crushing to zero for large inputs (saturation).

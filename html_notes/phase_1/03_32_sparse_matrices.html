1. Why Sparse?

Most real-world adjacency matrices (Social Graphs, Web Links) are 99.99% zeros.

Storing a 1M x 1M dense matrix requires 8TB RAM. Storing it sparse (with 1B edges) requires only ~12GB.

  • COO (Coordinate): List of (row, col, value). Good for construction.
  • CSR (Compressed Row): Optimized for matrix-vector multiplication.

2. GNNs

Graph Neural Networks rely entirely on sparse matrix operations. The "Message Passing" step is effectively \( A \times H \), where \( A \) is the sparse adjacency matrix.

Without sparse optimization, training GNNs on huge datasets (Reddit, Protein structures) would be impossible.

3. SciPy Sparse

import numpy as np
import scipy.sparse as sp
import sys

N = 10000
density = 0.001

# Create random sparse matrix
A_dense = np.zeros((N, N))
# ... filling this would take too much RAM if N was bigger

# Create CSR directly
nnz = int(N * N * density)
data = np.random.rand(nnz)
rows = np.random.randint(0, N, nnz)
cols = np.random.randint(0, N, nnz)

A_sparse = sp.coo_matrix((data, (rows, cols)), shape=(N, N)).tocsr()

print(f"Matrix Size: {N}x{N}")
print(f"Non-Zeros: {A_sparse.nnz}")
print(f"Memory Usage (MB): {A_sparse.data.nbytes / (1024**2):.2f}")
# A dense 10k x 10k float64 would be 800MB. This is ~1MB.

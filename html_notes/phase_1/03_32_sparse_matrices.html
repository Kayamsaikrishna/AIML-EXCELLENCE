32. Sparse Matrices

Efficient computing for mostly empty data.

1. What is Sparsity?

A matrix is Sparse if the vast majority of its elements are zero. Storing all those zeros is a massive waste of memory and compute.

Storage Formats

  • COO (Coordinate): Stores (row, col, value) tuples. Best for building matrices.
  • CSR (Compressed Sparse Row): Optimized for fast row-access and matrix-vector multiplication.
  • CSC (Compressed Sparse Column): Optimized for column-access and slicing.

2. Large Scale AI Applications

NLP and Graphs

  • TF-IDF: In a vocabulary of 50k words, a single document only contains a few hundred.
  • Adjacency Matrices: In a social network, the friend-matrix is 99.98% sparse.
  • Model Pruning: Removing small weights to make neural networks sparse for edge devices.

3. Python: Sparse Computing

import numpy as np
from scipy.sparse import csr_matrix

# Create a largely empty matrix
data = np.zeros((1000, 1000))
data[1, 5] = 10.0
data[500, 500] = 3.0

# Convert to CSR
sparse_data = csr_matrix(data)

print(f"Full Data: {data.nbytes} bytes")
print(f"Compressed: {sparse_data.data.nbytes} bytes")

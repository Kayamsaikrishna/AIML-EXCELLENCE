Data Whitening

1. Definition

Whitening transforms the data so its covariance matrix becomes the Identity matrix \( I \).

Typically used before training to make gradients flow evenly (Preconditioning). It involves:

$$ X_{white} = X U S^{-1/2} $$

Where \( U, S \) come from the SVD/Eigen decomposition of the covariance.

2. Batch Normalization

Full Whitening is computationally expensive to do at every layer. Batch Normalization is a simplified whitening (only centers and scales variance, ignoring covariance/rotation) applied to each mini-batch.

This approximation speeds up training significantly by stabilizing the distribution of inputs to layers.

3. PCA Whitening Code

import numpy as np

# Random Correlated Data
rng = np.random.default_rng(42)
X = rng.multivariate_normal([0,0], [[1, 0.9], [0.9, 1]], size=500)

# 1. Zero Center
X -= np.mean(X, axis=0)

# 2. Compute Covariance
Sigma = np.cov(X, rowvar=False)

# 3. Eigen Decomposition
D, V = np.linalg.eigh(Sigma)
# D: variances along principal aexs
# V: rotation matrix

# 4. Whiten (Rotate then Scale)
# X_rot = X @ V
# X_white = X_rot / sqrt(D + epsilon)
epsilon = 1e-5
X_white = (X @ V) / np.sqrt(D + epsilon)

# Check new covariance
print("Original Cov:\n", Sigma.round(2))
print("\nWhitened Cov (Should be Identity):\n", np.cov(X_white, rowvar=False).round(2))

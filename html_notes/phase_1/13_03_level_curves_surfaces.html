Calculus 1.6 Visualization

Level Curves & Surfaces

Slicing the mountain to see the path.

Contours of Constant Value

A function \( z = f(x, y) \) describes a surface. If we slice this surface horizontally at height \( k \), the intersection is a cure called a Level Curve. \[ f(x, y) = k \]

The collection of all level curves creates a Contour Map (like a topographic map). - Crowded lines = Steep slope. - Spaced out lines = Flat plain.

2. AI/ML Connection: Decision Boundaries

The Lines That Divide

In a classification problem (e.g., Cat vs. Dog), the model predicts a probability \( P(\text{Cat} | x) \). The Decision Boundary is literally just a specific Level Curve: \[ P(\text{at} | x) = 0.5 \]

Everything on one side of this curve is classified as "Cat", and everything on the other is "Dog". Complex models (Deep Learning) create highly twisted and non-linear level curves to separate difficult data.

3. Python: Isocontours

contours.py
import numpy as np
import matplotlib.pyplot as plt

# Probability function for a 2D logistic regression
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)

# Linear boundary: 2x - 3y
Z = sigmoid(2*X - 3*Y)

plt.figure(figsize=(6, 6))
# Draw the "Decision Boundary" at 0.5
contours = plt.contour(X, Y, Z, levels=[0.1, 0.3, 0.5, 0.7, 0.9], cmap='coolwarm')
plt.clabel(contours, inline=True, fontsize=10)
plt.title("Decision Boundary (Level Curve 0.5)")
plt.xlabel("Feature 1")
plt.ylabel("Feature 2")
plt.grid(True, alpha=0.3)
plt.show()

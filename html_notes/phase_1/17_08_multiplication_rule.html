Multiplication Rule

P(A and B).

Conditioning

To calculate the probability that BOTH \(A\) AND \(B\) occur, we use conditioning: \[ P(A \cap B) = P(A) P(B|A) \] "First A happens, then B happens given that A happened." If \(A\) and \(B\) are Independent, this simplifies to \(P(A)P(B)\).

2. ML Connection: Naive Bayes

The "Naive" Assumption

In a Naive Bayes classifier, we want \(P(x_1, x_2, \dots | Class)\). Applying the multiplication rule generally is hard due to complexities. The "Naive" assumption is that features are independent given the class. \[ P(x_1, \dots | C) \approx P(x_1|C) \cdot P(x_2|C) \dots \] This turns a hard problem into simple multiplication.

3. Python: Chaining

chain_prob.py
# Two cards drawn without replacement
# A: First is Ace
# B: Second is Ace

p_A = 4/52
p_B_given_A = 3/51 # One ace gone, one card gone

p_both = p_A * p_B_given_A
print(f"Prob(Ace then Ace): {p_both:.5f}")

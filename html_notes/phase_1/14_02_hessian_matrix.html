Optimization 1.7 Curvature (2nd Order)

The Hessian Matrix

Measuring the "Sharpness" of the loss landscape.

Definition

The Hessian Matrix \(\mathbf{H}\) contains all second-order partial derivatives of a function. If the Gradient \(\nabla f\) is the vector of slopes, the Hessian is the matrix of curvatures.

$$ \mathbf{H}(f) = \begin{bmatrix} \frac{\partial^2 f}{\partial x_1^2} & \frac{\partial^2 f}{\partial x_1 \partial x_2} & \cdots \\ \frac{\partial^2 f}{\partial x_2 \partial x_1} & \frac{\partial^2 f}{\partial x_2^2} & \cdots \\ \vdots & \vdots & \ddots \end{bmatrix} $$

2. AI/ML Connection: Flat vs. Sharp Minima

Generalization & The Hessian

In Deep Learning, we care about the Eigenvalues of the Hessian at the final solution \(\mathbf{w}^*\).

  • Sharp Minimum (Large Eigenvalues): The loss shoots up if you move slightly. This suggests the model is "brittle" and might not generalize well to unseen data.
  • Flat Minimum (Small Eigenvalues): The loss stays low even if parameters are perturbed. This suggests robust generalization.

Techniques like SAM (Sharpness-Aware Minimization) explicitly try to minimize the trace (or largest eigenvalue) of the Hessian to find flatter solutions.

3. Python: Calculating the Hessian

hessian_calc.py
import torch

# Define a function: f(x,y) = 0.5*x^2 + 2*y^2 + x*y
# This is a quadratic bowl (convex).

def f(w):
    x, y = w[0], w[1]
    return 0.5*x**2 + 2.0*y**2 + 1.0*x*y

w = torch.tensor([1.0, 1.0], requires_grad=True)
loss = f(w)

# 1. First Derivative (Gradient)
grad = torch.autograd.grad(loss, w, create_graph=True)[0]
# grad = [x+y, 4y+x] -> at (1,1): [2, 5]

# 2. Second Derivative (Hessian)
hessian = []
for i in range(len(w)):
    # Calculate grad of the i-th component of the gradient
    row = torch.autograd.grad(grad[i], w, retain_graph=True)[0]
    hessian.append(row)

H = torch.stack(hessian)

print(f"Gradient: {grad}")
print(f"Hessian Matrix:\n{H}")
# Expected H:
# [[1, 1],
#  [1, 4]]

# 3. Eigenvalues
eig = torch.linalg.eigvals(H)
print(f"Eigenvalues: {eig}")
# Both positive -> Definite Minimum.

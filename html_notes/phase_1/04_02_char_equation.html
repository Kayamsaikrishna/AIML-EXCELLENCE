Characteristic Equation

\( \det(A - \lambda I) = 0 \). How we actually find the eigenvalues mathematically.

1. The Logic

If \( (A - \lambda I) \mathbf{x} = \mathbf{0} \) has a non-trivial solution (where \( \mathbf{x} \neq 0 \)), then the matrix \( A - \lambda I \) cannot be invertible.

Non-invertible matrices have a determinant of zero.

$$ \det(A - \lambda I) = 0 $$

This expands into a polynomial of degree \( n \). The roots of this polynomial are the eigenvalues.

2. System Roots

In Control Theory and RNNs, the eigenvalues of the state transition matrix determine if gradients explode or vanish.

If any root \( |\lambda| > 1 \), the system is unstable (explodes). The characteristic equation allows us to analyze stability without simulating the system forever.

3. Symbolic Solution

Using SymPy to find the exact polynomial.

from sympy import Matrix, Symbol, eye

l = Symbol('lambda')
A = Matrix([
    [3, 1],
    [1, 3]
])

# Create (A - lambda*I)
M = A - l * eye(2)

# Compute Determinant (Characteristic Polynomial)
char_poly = M.det()

print(f"Characteristic Poly: {char_poly}")
# Results in lambda^2 - 6*lambda + 8

# Roots
roots = alg_roots = char_poly.nroots()
print(f"Eigenvalues: {roots}")
# Should be 2 and 4

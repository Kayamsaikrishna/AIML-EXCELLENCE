Optimization 1.7 The Dual

Lagrange Multipliers

Converting Hard Constraints into solvable equations.

Geometric Intuition

We want to maximize \(f(x,y)\) subject to \(g(x,y)=c\). Imagine hiking on a mountain (\(f\)) but you must stay on a specific trail (\(g=c\)). The highest point on the trail occurs where the trail runs parallel to the contour lines of the mountain.

Mathematically, this means their Normal Vectors (Gradients) are parallel:

$$ \nabla f = \lambda \nabla g $$
graph TD Primal[Primal Problem: Min f s.t. g=0] -->|Define Lagrangian| L[L = f - λg] L -->|Solve ∇L=0| Critical[Critical Points of L] Critical -->|Find λ| Solution[Optimal x*, λ*] Solution -->|λ measures| Sensitivity[Price of Constraint]

2. AI/ML Connection: Support Vector Machines (SVM)

The Power of the Dual

In SVMs, we want to find the widest street separation between classes. This is a constrained quadratic problem. By forming the Lagrangian and solving the **Dual Problem**, we get a solution that depends only on dot products \(x_i \cdot x_j\).

This "Kernel Trick" allows infinite-dimensional classification efficiently. The Lagrange Multipliers \(\alpha_i\) tell us how important each data point is. If \(\alpha_i > 0\), that point is a Support Vector (holding up the margin). If \(\alpha_i = 0\), the point is irrelevant.

3. Python: Solving with Scipy

lagrange_solve.py
import numpy as np
from scipy.optimize import minimize

# Objective: Minimize x^2 + y^2 (Distance to origin)
# Constraint: x + y = 1

def f(x):
    return x[0]**2 + x[1]**2

# Constraint form: g(x) = 0
def constraint(x):
    return x[0] + x[1] - 1

cons = {'type': 'eq', 'fun': constraint}

# Run Optimizer
res = minimize(f, [2.0, 2.0], constraints=cons)

print(f"Optimal Solution: {res.x}") # Should be [0.5, 0.5]
print(f"Optimal Value: {res.fun}")

# Note: The 'lambda' multiplier is hidden inside the solver's logic.
# Geometrically, at (0.5, 0.5):
# Grad f = [1, 1]
# Grad g = [1, 1]
# They are parallel!

07. Attention & Transformer Math

Linear Algebra behind Large Language Models.

1. The Triple Transformation

In a Transformer, an input embedding \(\mathbf{X}\) is transformed into three different representations using learned matrices \(\mathbf{W}_Q, \mathbf{W}_K, \mathbf{W}_V\):

$$ \mathbf{Q} = \mathbf{X}\mathbf{W}_Q, \quad \mathbf{K} = \mathbf{X}\mathbf{W}_K, \quad \mathbf{V} = \mathbf{X}\mathbf{W}_V $$

This is just Linear Change of Basis to three different specialized latent spaces.

2. Scaled Dot-Product Attention

The "Attention Map" is calculated via Matrix Multiplication and Softmax:

$$ \text{Attention}(\mathbf{Q, K, V}) = \text{softmax}\left(\frac{\mathbf{QK}^T}{\sqrt{d_k}}\right)\mathbf{V} $$
  • \(\mathbf{QK}^T\): A matrix of pairwise similarities (Dot Products).
  • Softmax: Normalization so rows sum to 1.

3. AI Insight: Contextual Vectors

The final output is a Linear Combination of the Value vectors, weighted by how much "Attention" the Query pays to each Key. Linear Algebra allows word vectors to "talk" to each other and update their meaning based on surrounding context.

4. Python: Miniature Attention

import numpy as np

def scaled_dot_product_attention(Q, K, V):
    dk = Q.shape[-1]
    scores = (Q @ K.T) / np.sqrt(dk)
    # Simple Softmax
    weights = np.exp(scores) / np.sum(np.exp(scores), axis=-1, keepdims=True)
    return weights @ V

# 2 words, embedding dim 4
X = np.random.randn(2, 4)
Q = K = V = X # Self-Attention

output = scaled_dot_product_attention(Q, K, V)
print(f"Attention Output:\n{output}")

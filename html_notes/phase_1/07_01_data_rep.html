1. The Design Matrix

The standard format for data in ML is the Design Matrix \( X \in \mathbb{R}^{N \times D} \).

  • \( N \): Number of samples (rows).
  • \( D \): Number of features/dimensions (columns).

Geometric intuition comes from viewing rows as points in \( D \)-dimensional space (cloud), or columns as features spanning the "Feature Space".

2. Embeddings

Unstructured data (words, users, products) doesn't have natural dimensions. We learn a mapping (Embedding) that places these entities into a vector space such that semantic similarity corresponds to geometric proximity (Dot Product).

3. Loading and Viewing Data

import numpy as np
import pandas as pd
from sklearn.datasets import load_iris

# 1. Tabular Data
data = load_iris()
X = data.data
print(f"Iris Design Matrix Shape: {X.shape}")
print("First sample (Features):", X[0])

# 2. Image Data (Flattening)
# 8x8 image
image = np.random.rand(8, 8)
flat_image = image.flatten()
print(f"\nImage Tensor: (8, 8) -> Vector: {flat_image.shape}")

# 3. One-Hot Encoding (Categorical -> Vector)
vocab_size = 5
word_idx = 2 # 3rd word
one_hot = np.zeros(vocab_size)
one_hot[word_idx] = 1
print(f"\nOne-Hot Vector: {one_hot}")

09. The Chain Rule

The engine of Deep Learning.

1. The Concept: Composition

If you have a function inside another function, like \(y = f(g(x))\), the rate of change of \(y\) depends on how \(f\) changes relative to \(g\), and how \(g\) changes relative to \(x\).

$$ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} $$

Where \(u = g(x)\). In function notation:

$$ (f \circ g)'(x) = f'(g(x)) \cdot g'(x) $$

2. The "Outer-Inner" Principle

  1. Differentiate the outer function, keeping the inner part exactly the same.
  2. Multiply by the derivative of the inner function.

Example: \(\frac{d}{dx} [\sin(x^2)]\)

  • Outer: \(\sin(\dots) \to \cos(\dots)\)
  • Inner: \(x^2 \to 2x\)
  • Result: \(\cos(x^2) \cdot 2x\)

3. AI/ML Connection: Backpropagation

The "Learning" Algorithm

A Neural Network is just a massive composition of functions. Each layer is a function, and the final loss is a function of the last layer. To update the weights of the first layer, we must calculate the derivative of the loss with respect to those weights.

The Backpropagation algorithm is simply the recursive application of the Chain Rule from the output back to the input. Without the Chain Rule, we wouldn't be able to "blame" errors in the prediction on specific weights deep inside the network.

4. Python: Chain Rule with Symbolic Math

import sympy as sp

x = sp.Symbol('x')
# Composite function: sqrt(x^2 + 1)
inner = x**2 + 1
outer = sp.sqrt(inner)

# SymPy handles the chain rule automatically
deriv = sp.diff(outer, x)

print(f"Function: {outer}")
print(f"Derivative: {deriv}") 
# Output: x/sqrt(x**2 + 1)

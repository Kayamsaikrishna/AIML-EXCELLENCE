Gauss-Jordan

Going all the way to Identity. The most robust (but expensive) way to solve systems.

1. Gaussian vs Gauss-Jordan

Gaussian

Stops at REF (Upper Triangular).

Requires back-substitution to solve.

Faster ($2/3 n^3$ flops).

Gauss-Jordan

Goes to RREF (Diagonal/Identity).

Solution is immediately visible.

Slower ($n^3$ flops). Used for Inversion.

2. Numerical Stability

Naive Gauss-Jordan is unstable if pivots are very small (division by near-zero).

Real-world solvers use Partial Pivoting: we verify the best pivot (largest absolute value) in the column and Swap rows to bring it to the top before eliminating.

3. SciPy Solver

The standard way to solve.

import numpy as np
import scipy.linalg as la

# A random system
A = np.random.rand(100, 100)
b = np.random.rand(100)

# 1. Using LU (Gaussian under the hood) - The Fast Way
lu, piv = la.lu_factor(A)
x = la.lu_solve((lu, piv), b)

# 2. Using Inverse (Gauss-Jordan) - The Slow Way
# x = inv(A) @ b
# NEVER DO THIS IN PRODUCTION CODE (Unless for theory)

print(f"Solution shape: {x.shape}")
print(f"Check Error: {np.linalg.norm(A @ x - b):.2e}")

19. Gauss-Jordan Elimination

Complete reduction to the identity matrix.

1. The Backward Pass

Gauss-Jordan extends Gaussian elimination by reducing the matrix all the way to Reduced Row Echelon Form (RREF). This means eliminating entries both below and above each pivot.

Visual Transition

$$ [\mathbf{A}] \xrightarrow{\text{Gaussian}} [REF] \xrightarrow{\text{Jordan}} [RREF] $$

2. Applications in Matrix Logic

The Dual Purpose

  • Direct Solving: The solution to \( \mathbf{Ax} = \mathbf{b} \) can be read directly from the augmented column of a RREF matrix.
  • Inverse Calculation: Reducing \( [\mathbf{A} | \mathbf{I}] \) to \( [\mathbf{I} | \mathbf{A}^{-1}] \).

Note: While manual calculation stops here, AI frameworks use Gauss-Jordan logic to implement numerical solvers and find the rank of a matrix reliably.

3. Python: Full Reduction

import numpy as np

def gauss_jordan(A):
    n = A.shape[0]
    # Reduce to RREF
    for i in range(n):
        A[i] = A[i] / A[i, i] # Normalize pivot to 1
        for j in range(n):
            if i != j:
                A[j] -= A[j, i] * A[i]
    return A

A = np.array([[2, 1], [1, 3]], dtype=float)
rref = gauss_jordan(A)
print(f"RREF (Identity for non-singular):\n{rref}")

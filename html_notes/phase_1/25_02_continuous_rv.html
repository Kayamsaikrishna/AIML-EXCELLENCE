02. Continuous Random Variables

Dealing with infinite precision and smooth scales.

1. Definition

A Continuous Random Variable is an RV that can take on any value within an interval (or union of intervals) on the real line. The possible values are uncountable.

Crucially, for a continuous RV, the probability of $X$ taking on any exact single value is zero:

$$ P(X = x) = 0 \quad \text{for any } x \in \mathbb{R} $$

Instead, we measure the probability that $X$ falls within a range $[a, b]$.

2. Density vs. Probability

Since $P(X=x)=0$, we use a Probability Density Function (PDF). The magnitude of the PDF at a point $x$ is not a probability; it represents the "relative likelihood" of the variable being near that point.

3. AI/ML Connection: Signals and Weights

The Continuous World of AI

Most entities in modern Machine Learning are continuous random variables.

Image Pixels are usually treated as continuous values between 0.0 and 1.0 (after normalization). Neural Network Weights are continuous variables defined in a high-dimensional space. In Generative AI, when you ask a model like Midjourney to create an image, the model is essentially sampling from a massive, multi-dimensional continuous distribution. Understanding continuous RVs is vital for Optimization; because the variables are continuous, we can use Calculus (Gradients) to navigate the probability landscape. If the world were purely discrete, we couldn't use Gradient Descent!

4. Python: Sampling Continuous RVs

import numpy as np

# Uniform Continuous RV between 0 and 1
# (e.g., probability of a pixel intensity)
pixel_val = np.random.uniform(0, 1)

# Normal Continuous RV (Gaussian)
# (e.g., initial weight distribution)
weight = np.random.normal(0, 0.01)

print(f"Continuous Pixel: {pixel_val:.4f}")
print(f"Continuous Weight: {weight:.4f}")

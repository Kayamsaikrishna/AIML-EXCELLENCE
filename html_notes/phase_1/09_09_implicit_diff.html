Calculus 1.3 Indirect

Implicit Differentiation

Sometimes you can't isolate \(y\). That doesn't stop calculus.

Tangled Variables

In many physical and geometric systems (like circles, ellipses, or conservation laws), variables are mixed together: \(x^2 + y^2 = 25\). Solving for \(y = \pm\sqrt{25-x^2}\) is messy and loses information (the \(\pm\)). Implicit differentiation lets us work directly on the equation.

1. The Technique

Treat \(y\) as an unknown function of \(x\), i.e., \(y = y(x)\). When you differentiate a term with \(y\), apply the Chain Rule.

\[ \frac{d}{dx}[y^n] = ny^{n-1} \cdot \frac{dy}{dx} \]

After differentiating both sides, solve the resulting algebraic equation for \(\frac{dy}{dx}\).

2. AI/ML Connection: Implicit Layers

Deep Equilibrium Models

Standard Deep Learning is an Explicit function: \(y = f_3(f_2(f_1(x)))\).

However, recent research (Deep Equilibrium Models - DEQ) defines the output \(z\) as the stability point of an equation: \[ z = f(z, x) \] Here, the output \(z\) depends on itself! To train this, we need the gradient \(\frac{\partial z}{\partial x}\). Since \(z\) is defined implicitly, we use the Implicit Function Theorem to calculate gradients without unrolling infinite loops.

\[ \frac{\partial z}{\partial x} = -(I - J_f)^{-1} \frac{\partial f}{\partial x} \]

This allows "infinite depth" networks with constant memory.

3. Python: Implicit Slopes

implicit_diff.py
import sympy as sp

x, y = sp.symbols('x y')

# Define the implicit equation: x^3 + y^3 = 6xy (Folium of Descartes)
eq = x**3 + y**3 - 6*x*y

# Differentiate implicit function
dy_dx = sp.idiff(eq, y, x)

print(f"Equation: {eq} = 0")
print(f"Derivative dy/dx: {dy_dx}")
# Output: (2x - y^2) / (y - 2x) ? (Sympy usually simplifies)

# Check slope at specific point (3, 3)
point_x = 3
point_y = 3
slope_val = dy_dx.subs({x: point_x, y: point_y})

print(f"\nSlope at ({point_x}, {point_y}): {slope_val}")
# At (3,3), 3^3 + 3^3 = 54, 6*3*3 = 54. It lies on curve.
# Slope calculation: (2*3 - 3^3/3?? idiff handles logic)

ML Calc 1.9 Verification

Numerical Differentiation

How to check if your calculus is correct.

Finite Differences

The mathematical definition of a derivative uses a limit: \[ f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} \] Computers can't do limits, but they can pick a very small \(h\) (e.g., \(1e-5\)). This is the Finite Difference Approximation.

Central Difference is more accurate: \[ f'(x) \approx \frac{f(x+h) - f(x-h)}{2h} \]

2. ML Connection: Gradient Checking

The Trust Check

Implementing Backpropagation manually is error-prone. One flipped sign in layer 50 ruins the whole network. Gradient Checking involves calculating the gradient of your network numerically (slow, but robust) and comparing it to your analytic backprop gradient.

If they match to within \(1e-7\), your implementation is correct. If they differ, you have a bug.

3. Python: Grad Check

grad_check.py
import numpy as np

def f(x): return x**2 + 3*x

def analytic_grad(x): return 2*x + 3

def numerical_grad(x, h=1e-5):
    return (f(x+h) - f(x-h)) / (2*h)

x_test = 5.0
ag = analytic_grad(x_test)
ng = numerical_grad(x_test)

print(f"Analytic: {ag}")
print(f"Numeric:  {ng}")
print(f"Diff:     {abs(ag - ng)}")
# Should be extremely small!

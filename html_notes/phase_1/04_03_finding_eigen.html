Finding Eigenvectors

Once you have \( \lambda \), finding \( \mathbf{x} \) is just dealing with the Null Space.

1. The Method

For each eigenvalue \( \lambda \):

  1. Construct the singular matrix \( M = A - \lambda I \).
  2. Solve the homogeneous system \( M \mathbf{x} = \mathbf{0} \).
  3. The solution space (Kernel of M) is the Eigenspace corresponding to \( \lambda \).

2. Basis Finding

Finding eigenvectors is essentially finding the "natural coordinate system" for your data.

In AI, when we move from pixel space to "feature space", we often want axes that decouple the data's variations. This is what solving for eigenvectors does manually.

3. SciPy Null Space

Calculating the kernel for a specific lambda.

import numpy as np
from scipy.linalg import null_space

A = np.array([
    [2, 1],
    [1, 2]
])

# We know lambda = 3 is an eigenvalue.
lambda_val = 3

# Form M = A - 3I
M = A - lambda_val * np.eye(2)
print("A - 3I:")
print(M)
# [[-1, 1], [1, -1]] -> Rows are dependent! Good.

# Find x such that Mx = 0
basis = null_space(M)
print(f"\nEigenvector Basis for lambda={lambda_val}:")
print(basis)
# Should be proportional to [1, 1] normalized

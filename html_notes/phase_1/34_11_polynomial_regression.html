11. Polynomial Regression

Bending lines to fit the curves of reality.

1. Modeling Curves

Sometimes relationships are not straight lines; they curve (e.g., the growth of a virus or the trajectory of a ball). Polynomial Regression models this by adding powers of original features ($X^2, X^3, \dots, X^d$) as new features.

$$ Y = \beta_0 + \beta_1 X + \beta_2 X^2 + \dots + \beta_d X^d + \epsilon $$

Crucially, this is still "Linear Regression" because the model is linear in terms of its Parameters ($\beta$), even if it is non-linear in $X$.

2. The Degree Tradeoff

Choosing the degree $d$ is a balancing act:

  • Degree 1: Too simple (Underfitting).
  • Degree 10: Fits every wiggle/noise (Overfitting).

3. AI/ML Connection: Universal Approximation and Overfitting

Increasing Model Capacity

In AI, Polynomial expansion is the simplest way to increase **Model Capacity**.

A standard Support Vector Machine (SVM)** or **Linear Learner** with a polynomial kernel is doing exactly this math. It "Projects" the data into a higher-dimensional space where it becomes easier to separate. However, this is also the textbook example of the Bias-Variance Tradeoff**. As the degree $d$ increases, the Bias (Underfitting) drops, but the Variance (Sensitivity to small wiggles) explodes. Modern Deep Learning** solves this by using non-linear activation functions (like ReLU) instead of polynomials, but the core principle remains: how much "Complexity" can we afford before we start memorizing the data instead of learning the pattern?

4. Python: Expanding Features

from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline

# Create a degree 3 model
model = make_pipeline(PolynomialFeatures(3), LinearRegression())
model.fit(X, y)

# The model now fits a smooth curve through the points!

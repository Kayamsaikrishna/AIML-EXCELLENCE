Calculus 1.4 Approximation

Definite Integrals & Riemann Sums

How do you measure a cloud? Slice it into blocks.

From Pixel to Picture

A digital image is just a grid of colored rectangles (pixels). If you make the pixels small enough, you get a smooth curve. Riemann Sums are just "Pixelating" a function to measure its area.

1. The Riemann Method

To find the area under \(f(x)\) from \(a\) to \(b\):

  1. Cut the interval into \(n\) slices of width \(\Delta x\).
  2. Measure the height of each slice \(f(x_i)\).
  3. Sum the areas: \( \sum f(x_i) \cdot \Delta x \).
  4. Take the limit \(n \to \infty\).

$$ \int_a^b f(x) dx = \lim_{n \to \infty} \sum_{i=1}^n f(x_i) \Delta x $$

2. AI/ML Connection: Discretization

Numerical Integration in Physics Engines

When training a Reinforcement Learning agent to walk (like in MuJoCo or OpenAI Gym), the physics engine simulates the world. But computers can't handle continuous time. They simulate "frames" (usually 60 per second).

This is a Riemann Sum! \[ Position_{new} = Position_{old} + Velocity \times \Delta t \]

If \(\Delta t\) is too large (low FPS), the approximation fails, the agent explodes, and training crashes. This is why "Time Step" is a critical hyperparameter in RL.

3. Python: Measuring the Area

riemann_sum.py
import numpy as np

def f(x):
    return x**2

# Range [0, 1]
a, b = 0, 1
n = 1000 # Number of pixels/slices
dx = (b - a) / n

# 1. Generate x points
x_points = np.linspace(a, b, n, endpoint=False) # Left Endpoints

# 2. Calculate heights
heights = f(x_points)

# 3. Sum Areas (Height * Width)
# Broadcasting allows us to multiply array by scalar
areas = heights * dx
total_area = np.sum(areas)

print(f"Approx Area (n={n}): {total_area:.5f}")
print(f"Actual Area (1/3):   {1/3:.5f}")
# As n increases, error decreases.

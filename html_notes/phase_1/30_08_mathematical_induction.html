Proofs Recursion

Mathematical Induction

The Domino Effect. Proving that a property holds for an infinite set of integers by showing that the first one is true and that each success guarantees the next.

The Falling Dominos

Imagine an infinite line of dominos. How do you prove they will all fall?

  1. Base Case: Push the first domino.
  2. Inductive Step: Prove that if any domino \(k\) falls, it must knock over its neighbor \(k+1\).

1. The Formal Structure

1. Base Case \(P(1)\)

Verify that the statement is true for the starting value (usually \(n=1\)). This is the foundation.

2. Inductive Hypothesis

Assume that the statement is true for some arbitrary integer \(k\). (Assume \(P(k)\)).

3. Inductive Step

Use the assumption to prove that the statement remains true for \(k+1\). (Show \(P(k) \rightarrow P(k+1)\)).

Example: Prove the sum of first \(n\) integers: \(1 + 2 + ... + n = \frac{n(n+1)}{2}\).

  1. Base Case (n=1): \(1 = \frac{1(2)}{2} = 1\). True.
  2. Hypothesis: Assume \(S_k = \frac{k(k+1)}{2}\).
  3. Step: \(S_{k+1} = S_k + (k+1) = \frac{k(k+1)}{2} + (k+1)\).
  4. Factor out \((k+1)\): \( (k+1) [\frac{k}{2} + 1] = (k+1) \frac{k+2}{2} = \frac{(k+1)(k+2)}{2} \).
  5. This matches the formula for \(n=k+1\). \(\square\)

2. Strong Induction

Sometimes, knowing only that the *previous* step was true isn't enough. In Strong Induction, we assume the statement is true for all values from the base case up to \(k\).

$$ [P(1) \land P(2) \land ... \land P(k)] \rightarrow P(k+1) $$

This is often used in Computer Science for proving things about binary trees or recursive structures where a node depends on all its children.

Recursion Programming

The Logic of Algorithms

  • Loop Invariants: When you write a `while` loop, you are using induction. You ensure the "Loop Invariant" (a property) is true at the start, and that each iteration preserves it. This guarantees the program's correctness when the loop ends.
  • Recursive Complexity: We use induction to prove the time complexity of algorithms like MergeSort. By showing that a list of size \(n\) takes \(O(n \log n)\) based on its halves, we are building an inductive proof.
  • Dynamic Programming: The "State Transition" in DP is essentially an inductive step. You solve the base cases and then define how the solution for a larger state depends on smaller ones.

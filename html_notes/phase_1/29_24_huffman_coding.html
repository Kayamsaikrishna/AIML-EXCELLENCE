Huffman Coding

Optimal Efficiency. The elegant algorithm that builds a bridge between probability and data structure, ensuring that frequent events get the shortest descriptions.

The Language of the Frequent

In common English, 'E' is the most frequent letter. 'Z' is one of the rarest. In a standard computer code (ASCII), both take 8 bits. Huffman coding says: Let's give 'E' 3 bits and 'Z' 12 bits. On average, the whole book becomes much smaller.

1. The Huffman Algorithm

1. Count Frequencies

Start with a list of all symbols and their probabilities (or frequencies).

2. Build the Tree

Repeatedly take the two symbols with the lowest probabilities, merge them into a new node with their sum, and put it back in the list.

3. Assign Bits

Once you have a single root, assign '0' to the left branch and '1' to the right branch. The path from root to leaf is the symbol's code.

2. Implementation (Python)

import heapq
from collections import Counter

def huffman_encode(data):
    # Calculate frequencies
    freq = Counter(data)
    # Create priority queue of (freq, symbol)
    heap = [[f, [s, ""]] for s, f in freq.items()]
    heapq.heapify(heap)

    while len(heap) > 1:
        lo = heapq.heappop(heap)
        hi = heapq.heappop(heap)
        # Add 0 to low frequency branch, 1 to high
        for pair in lo[1:]:
            pair[1] = '0' + pair[1]
        for pair in hi[1:]:
            pair[1] = '1' + pair[1]
        heapq.heappush(heap, [lo[0] + hi[0]] + lo[1:] + hi[1:])

    return sorted(heapq.heappop(heap)[1:], key=lambda p: (len(p[-1]), p))

Efficient AI Deep Compression

Why AI Researchers Love Huffman

Modern LLMs and Vision models are massive (billions of parameters). Keeping them in RAM is a nightmare.

  • Model Weight Compression: In papers like *Deep Compression* (Han et al.), researchers first Prune the weights, then Quantize them into shared values, and finally apply Huffman Coding to the index map. This can shrink a model by 35x-50x with ZERO loss in accuracy.
  • Data Preprocessing: Huffman is a core component of JPEG, MP3, and many other data formats that supply the raw data for AI models.

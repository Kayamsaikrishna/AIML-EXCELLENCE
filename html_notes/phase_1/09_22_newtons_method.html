Calculus 1.3 Optimization

Newton's Method

Why walk blindly downhill when you can calculate the exact location of the bottom?

The Quadratic Speedup

Newton's Method is radically faster than simple guessing or even linear search. It uses the slope to "predict" where the function forces zero. It generally doubles its precision with every step (Quadratic Convergence).

1. Root Finding Formula

To solve \(f(x) = 0\):

\[ x_{new} = x_{old} - \frac{f(x_{old})}{f'(x_{old})} \]

Geometric Idea: Slide down the tangent line from \(x_{old}\) until you hit the x-axis. That intercept is \(x_{new}\).

2. AI/ML Connection: Second-Order Optimization

Newton's Method in Training

In ML, we don't want \(Loss = 0\) (which might be impossible due to noise). We want \(\text{Gradient} = 0\) (the minimum).

Applying Newton's Method to the Gradient function gives: \[ \theta_{new} = \theta_{old} - \frac{J'(\theta)}{J''(\theta)} \]

In vector form (multivariate): \[ \theta_{new} = \theta_{old} - H^{-1} \nabla J \] Where \(H\) is the Hessian Matrix (2nd derivatives).

Pros: Converges instantly on quadratic surfaces.
Cons: Calculating \(H^{-1}\) for a billion-parameter GPT model requires unimaginable memory. That's why we use "Quasi-Newton" methods like BFGS or purely first-order methods like Adam.

3. Python: Convergence Race

convergence_race.py
import numpy as np

# We want to find sqrt(612) iteratively.
# This implies solving x^2 - 612 = 0
target = 612

def f(x): return x**2 - target
def df(x): return 2*x

# Method 1: Newton's Method
x_newton = 10.0 # Bad guess
print("--- Newton's Method ---")
for i in range(6):
    x_newton = x_newton - f(x_newton)/df(x_newton)
    error = abs(x_newton**2 - target)
    print(f"Iter {i+1}: {x_newton:.8f} (Error: {error:.8f})")

# Method 2: Gradient Descent (Finding min of (x^2 - 612)^2)
# Often much slower for root finding without tuning
lr = 0.0001
x_gd = 10.0
print("\n--- Gradient Descent (Naive) ---")
for i in range(6):
    # Loss L = (x^2 - A)^2
    # dL/dx = 2(x^2 - A) * 2x = 4x(x^2 - A)
    grad = 4 * x_gd * (x_gd**2 - target)
    x_gd = x_gd - lr * grad
    error = abs(x_gd**2 - target)
    print(f"Iter {i+1}: {x_gd:.8f} (Error: {error:.8f})")

# Insight: Newton's method solves it in 4-5 steps. GD barely moves.

Stats 1.4 The Playground

Parameter Space (\(\Theta\))

The universe of all possible values that a population parameter can take.

Where Truth Lives

A model is usually defined by a set of parameters (\(\theta\)). The Parameter Space is the geometric space containing every valid combination of those parameters.

"If you are looking for the needle (the truth), the Parameter Space is the haystack."

1. Defining Constraints

$$ \theta \in \Theta $$
  • Normal Distribution: \(\mu \in \mathbb{R}\), \(\sigma^2 \in (0, \infty)\).
  • Bernoulli Distribution: \(p \in [0, 1]\).
  • Poisson Distribution: \(\lambda \in (0, \infty)\).

2. ML Connection: Hypothesis Space

Deep Learning Optimization

Weight Space

In a Neural Network with 1 million weights, the Parameter Space is \(\mathbb{R}^{1,000,000}\). Training a model is effectively a Global Search through this massive parameter space to find the "best" \(\theta\).

Constraints matter: If we use a Sigmoid activation, we are restricting our model's "output space" to \((0, 1)\). If we use Weight Decay (L2), we are effectively "shrinking" the accessible volume of the parameter space to keep weights small.

3. Identifiability

A model is Identifiable if different parameters always lead to different distributions. - If two different values of \(\theta\) produce the exact same data distribution, the model is unidentifiable. - Translation in ML: If your loss surface has a flat "plateau" where different weights give the same error, your parameters are not uniquely identifiable.

08. Convex Sets and Convex Functions

The holy grail of easy optimization.

1. Convex Sets

A set \(S\) is Convex if, for any two points in \(S\), the line segment connecting them also lies entirely within \(S\). Visually, a convex set has no "dents" or "holes".

2. Convex Functions

A function \(f\) is Convex if the line segment between any two points on its graph lies above the graph.

The Second Derivative Test for Convexity: A twice-differentiable function is convex if its Hessian Matrix is Positive Semi-Definite at all points (\(\mathbf{H} \succeq 0\)).

3. AI/ML Connection: Why Convexity is Gold

Local is Global

The most important property of a convex function is that any local minimum is also a global minimum.

In Linear Regression and Logistic Regression, the loss functions are convex. This means no matter where you start your "Gradient Descent", you are mathematically guaranteed to reach the same best answer. In Deep Learning, the loss functions are NOT convex, which is why we spend months tuning learning rates and initializations. Understanding convexity allows AI engineers to know when they can be certain of their results versus when they are just "finding a good enough" solution in a non-convex mess.

4. Python: Jensen's Inequality Demo

# For a convex function f(x) = x^2
# f(avg(x1, x2)) <= avg(f(x1), f(x2))

def f(x): return x**2

x1, x2 = 1, 5
avg_x = (x1 + x2) / 2 # 3

val_of_avg = f(avg_x) # 3^2 = 9
avg_of_vals = (f(x1) + f(x2)) / 2 # (1 + 25) / 2 = 13

print(f"f(avg): {val_of_avg}")
print(f"avg(f): {avg_of_vals}")
print(f"Convexity Check: {val_of_avg <= avg_of_vals}")

Prob 1.4 Common Pitfall

Exclusive vs Independent

They are opposites, not synonyms.

The Difference

Mutually Exclusive: Can't happen together. \(P(A \cap B) = 0\). Example: Coin landing on Heads AND Tails.

Independent: One doesn't affect the other. \(P(A \cap B) = P(A)P(B)\). Example: Coin 1 Heads AND Coin 2 Heads.

If \(P(A) > 0\) and \(P(B) > 0\), Mutually Exclusive events are never independent! Knowing A happened forces B to not happen.

2. ML Connection: Feature Engineering

Feature Construction

When creating features, we often create exclusive categories (Day of Week). But we want our input features to be relatively independent so the model learns diverse signals. Highly correlated (dependent) features cause Multicollinearity, creating unstable gradients in Linear Regression and Neural Nets.

Antiderivatives

To understand the crime, reconstruct the timeline.

Reverse-Engineering Reality

Differentiation breaks a whole function into momentary rates of change. Integration rebuilds the whole from the parts. If differentiating is "analysis", integrating is "synthesis".

1. The Definition

A function \(F\) is an Antiderivative of \(f\) if: \[ F'(x) = f(x) \]

Example: If \(f(x) = 2x\), then \(F(x) = x^2\) is an antiderivative because \(\frac{d}{dx}(x^2) = 2x\).

The Constant of Integration: Since the derivative of a constant is zero, there are infinitely many answers. \(x^2 + 1\), \(x^2 - 1000\), \(x^2 + \pi\)...
We write the General Solution as: \[ F(x) + C \]

2. AI/ML Connection: Reconstructing Generative Data

Deconvolution & Autoencoders

In a Convolutional Neural Network (CNN), we "differentiate" an image to find edges (changes in pixel intensity). This is analysis.

In a GAN (Generative Adversarial Network) or Autoencoder, we do the opposite. We start with a compressed vector (the rate/seed) and "integrate" it back up to produce a full 2D image.

The \(+C\) represents the Latent Space Uncertainty. One seed vector could generate multiple valid variations of a face (with glasses, without glasses) depending on the initial conditions (the \(C\)).

3. Python: Symbolic Reversal

find_antiderivative.py
import sympy as sp

x = sp.Symbol('x')

# Function 1: Power Rule
f1 = 3*x**2
F1 = sp.integrate(f1, x)
print(f"Antiderivative of {f1}: {F1} + C") 
# Output: x**3 + C

# Function 2: Trig
f2 = sp.cos(x)
F2 = sp.integrate(f2, x)
print(f"Antiderivative of {f2}: {F2} + C") 
# Output: sin(x) + C

# Function 3: 1/x (Log Rule)
f3 = 1/x
F3 = sp.integrate(f3, x)
print(f"Antiderivative of {f3}: {F3} + C") 
# Output: log(x) + C

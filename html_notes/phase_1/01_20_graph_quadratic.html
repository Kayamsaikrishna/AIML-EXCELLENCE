1. The Geometry of Squared Error

Most Loss Functions are quadratic-ish because we define error as \( (y_{true} - y_{pred})^2 \).

$$ J(w) = w^2 $$

This creates a U-shaped curve. No matter where you start (except the exact bottom), the gradient (slope) always points towards the minimum.

2. 3D Loss Surfaces

In 2D, we have a line. In 3D (2 weights), we have a Bowl (Paraboloid). In 1 Billion dimensions (GPT-4), we have a Hyper-Bowl.

But beware Saddle Points: Regions where the surface curves up in one direction but down in another (like a Pringles chip or a horse saddle). These are major obstacles for training.

3. Plotting the Bowl of Gradient Descent

Using Matplotlib to visualize a 3D loss surface.

import numpy as np
import matplotlib.pyplot as plt

# Create grid of w1, w2 values
w1 = np.linspace(-10, 10, 50)
w2 = np.linspace(-10, 10, 50)
W1, W2 = np.meshgrid(w1, w2)

# Loss Function: J = w1^2 + w2^2 (Perfect Bowl)
J = W1**2 + W2**2

# Plot not available in text, but concept remains:
print(f"Loss at (0,0): {0**2 + 0**2} (Global Min)")
print(f"Loss at (5,5): {5**2 + 5**2} (High Error)")

# Gradient at (5,5) is [2*5, 2*5] = [10, 10]
# It points AWAY from minimum. We go OPPOSITE.
# New w = w - learning_rate * gradient

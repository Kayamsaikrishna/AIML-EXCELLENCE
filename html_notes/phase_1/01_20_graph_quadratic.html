20. Graphing Quadratic Functions

The Parabola. The "Bowl" of Optimization.

1. The Vertex Form

$$ y = a(x-h)^2 + k $$

Every parabola has a Vertex (the bottom of the bowl) at \( (h, k) \).

Convexity

If \( a > 0 \), the bowl opens UP (Convex). It has a global minimum.

If \( a < 0 \), the bowl opens DOWN (Concave). It has a global maximum.

Optimization Holy Grail: In AI, we want our Loss Function to be Convex, because then we can always find the best solution just by rolling downhill.

2. The Loss Landscape

Training a Neural Network is essentially walking on a high-dimensional surface, looking for the lowest valley.

For Linear Regression, the surface is a perfect Quadratic Bowl (a Paraboloid). You result is guaranteed.

For Deep Networks, the surface is wobbly, with many "Local Minima" and "Saddle Points" (flat areas).

Squared Error (MSE)

The reason we use Mean Squared Error (\(L_2\)) is specifically to create this parabolic shape.

$$ J(w) = \frac{1}{n} \sum (y - \hat{y})^2 $$

Squaring the error ensures the curve is smooth, differentiable, and has a clear bottom.

3. Visualizing the Surface

Let's plot a 3D Loss Surface in Python.

// Python: 3D Optimization Surface
import numpy as np
import matplotlib.pyplot as plt

# Define the "Bowl" function (Paraboloid)
def loss_function(w1, w2):
    return w1**2 + w2**2  # Simple convex surface

# Generate grid
w1 = np.linspace(-10, 10, 50)
w2 = np.linspace(-10, 10, 50)
W1, W2 = np.meshgrid(w1, w2)
Loss = loss_function(W1, W2)

# Plot 3D
fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection='3d')
ax.plot_surface(W1, W2, Loss, cmap='viridis', alpha=0.8)

ax.set_xlabel('Weight 1')
ax.set_ylabel('Weight 2')
ax.set_zlabel('Loss')
plt.title("The Gradient Descent Bowl")
plt.show()

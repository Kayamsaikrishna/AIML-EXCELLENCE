11. Derivatives of Trigonometric Functions

Managing periodic change.

1. The Primary Derivatives

Trigonometric functions change in cycles. Their derivatives reflect this periodicity.

$$ \frac{d}{dx}[\sin x] = \cos x $$ $$ \frac{d}{dx}[\cos x] = -\sin x $$

Note the sign change for \(\cos\). A common mnemonic is that the derivative of any "co" function (\(\cos, \cot, \csc\)) starts with a negative sign.

2. Other Trig Rules

  • \(\frac{d}{dx}[\tan x] = \sec^2 x\)
  • \(\frac{d}{dx}[\cot x] = -\csc^2 x\)
  • \(\frac{d}{dx}[\sec x] = \sec x \tan x\)
  • \(\frac{d}{dx}[\csc x] = -\csc x \cot x\)

3. AI/ML Connection: Signal Processing & Wavelets

Oscillatory Features

In Time Series Analysis and Audio Engineering (AI Music Generation), we often decompose signals into sines and cosines (Fourier Analysis). When we train a model to predict the next value in a signal, we need the derivatives of these trig functions to perform Gradient Descent on the frequencies and phases.

Furthermore, in Positional Encoding (used in Transformers like GPT), sine and cosine functions are used to help the model understand the "position" of a word in a sentence. The smooth derivatives of these functions allow gradients to flow back easily through the attention layers.

4. Python: Trig Derivative Table

import sympy as sp

x = sp.Symbol('x')
trig_fns = [sp.sin(x), sp.cos(x), sp.tan(x)]

for fn in trig_fns:
    print(f"Derivative of {fn} is {sp.diff(fn, x)}")

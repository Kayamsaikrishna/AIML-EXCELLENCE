07. L'Hôpital's Rule

Solving indeterminate limits with derivatives.

1. The Problem

If \(\lim_{x \to a} \frac{f(x)}{g(x)}\) results in \(0/0\) or \(\infty/\infty\), we cannot solve it with basic limit laws.

2. The Rule

Under certain continuity conditions:

$$ \lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)} $$

If the result is still indeterminate, you can apply the rule again!

3. AI Connection: Log-Loss and Divergence

Many information-theoretic metrics like KL Divergence involve limits of the form \(x \ln(x)\) as \(x \to 0\). Using L'Hôpital's rule by rewriting the expression as \(\frac{\ln(x)}{1/x}\), we can prove that \(x\) dominates \(\ln(x)\) and the limit is 0. This proof is crucial for demonstrating that some loss functions remain well-behaved even as probabilities approach zero.

4. Python: Verifying with SymPy

import sympy as sp

x = sp.Symbol('x')
# Limit of (sin x) / x as x -> 0 is 0/0
f = sp.sin(x)
g = x

# Manual L'Hopital: diff(f)/diff(g) = cos(x) / 1
# cos(0) / 1 = 1
result = sp.limit(f/g, x, 0)

print(f"Limit of sin(x)/x as x->0: {result}")

Module 06

Diagonalizability

Not every matrix can be diagonalized. Knowing when is crucial.

Concept Map: The Checklist

1. The Rules

  • Sufficient Condition: If \( A \) has \( n \) distinct eigenvalues, it is guaranteed to be diagonalizable.
  • Necessary & Sufficient Condition: \( A \) is diagonalizable if and only if the sum of geometric multiplicities equals \( n \). (i.e., we can find a basis of \( n \) eigenvectors).

2. Highly Non-Normal Systems

In Training Deep Networks, if weight matrices are "highly non-normal" (far from diagonalizable, or eigenvectors are nearly parallel), signal propagation becomes unstable.

This "Transient Growth" phenomena (where \( ||A^k|| \) grows before decaying) can cause exploding gradients even if all eigenvalues \( |\lambda| < 1 \).

3. Testing Conditions

import numpy as np

# Case 1: Distinct Eigenvalues (Diagonalizable)
A1 = np.array([[1, 2], [3, 4]]) 
# Roots are approx -0.37 and 5.37 (Distinct) -> Diagonalizable

# Case 2: Repeated, but Independent Vectors (Identity - Diagonalizable)
A2 = np.eye(2) 
# Roots are 1, 1. Vectors are [1,0], [0,1]. GM=2=AM. -> Diagonalizable

# Case 3: Repeated, Dependent Vectors (Shear - Defective)
A3 = np.array([[1, 1], [0, 1]])
# Roots are 1, 1. Vector is only [1,0]. GM=1 < AM=2. -> NOT Diagonalizable

print("Analyzing Shear Matrix A3:")
try:
    # NumPy's eig will return dependent vectors or fail to find n independent ones
    vals, vecs = np.linalg.eig(A3)
    print(f"Eigenvalues: {vals}")
    print(f"Eigenvectors:\n{vecs}")
    
    # Check linear independence (Determinant of P)
    det_P = np.linalg.det(vecs)
    if np.isclose(det_P, 0):
        print("Eigenvector matrix is singular! Matrix is defective.")
except Exception as e:
    print(e)

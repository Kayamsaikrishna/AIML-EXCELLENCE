06. Conditions for Diagonalizability

When is a matrix "simple enough"?

1. The Primary Condition

An \(n \times n\) matrix \(\mathbf{A}\) is diagonalizable if and only if it has \(n\) linearly independent eigenvectors.

Sufficient Conditions

  • Distinct Eigenvalues: If \(\mathbf{A}\) has \(n\) distinct eigenvalues, it is guaranteed to be diagonalizable.
  • Symmetric Matrices: Every real symmetric matrix is diagonalizable (by an orthogonal matrix).

2. Multiplicity Revisited

For a matrix with repeated eigenvalues, it is diagonalizable if and only if for every eigenvalue:

$$ \text{Geometric Multiplicity} = \text{Algebraic Multiplicity} $$

If this equality fails for even one eigenvalue, the matrix is Defective (non-diagonalizable).

3. AI Implications: Numerical Stability

Close to Defective?

In practice, matrices in AI are rarely perfectly defective, but they can be nearly defective. This causes the eigenvector matrix \(\mathbf{P}\) to be ill-conditioned, leading to numerical instability in algorithms like Eigendecomposition-based ODE solvers.

4. Python: Checking Diagonalizability

import numpy as np

def is_diagonalizable(A):
    eigenvals, eigenvects = np.linalg.eig(A)
    # Check if number of LI eigenvectors matches size
    return np.linalg.matrix_rank(eigenvects) == A.shape[0]

A_good = np.array([[1, 0], [0, 1]])
A_bad = np.array([[1, 1], [0, 1]])

print(f"Identity: {is_diagonalizable(A_good)}")
print(f"Shear Matrix: {is_diagonalizable(A_bad)}")

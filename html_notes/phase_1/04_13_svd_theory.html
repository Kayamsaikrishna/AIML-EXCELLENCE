13. Singular Value Decomposition (SVD)

The universal factorization for every matrix.

1. Beyond Square Matrices

Eigendecomposition requires a matrix to be square and (often) symmetric. SVD is the ultimate generalization that works for any \(m \times n\) matrix.

$$ \mathbf{A} = \mathbf{U}\Sigma\mathbf{V}^T $$
  • \(\mathbf{U}\) (\(m \times m\)): Left Singular Vectors. Orthogonal basis for the output space.
  • \(\Sigma\) (\(m \times n\)): Singular Values. Diagonal matrix indicating importance/scaling.
  • \(\mathbf{V}^T\) (\(n \times n\)): Right Singular Vectors. Orthogonal basis for the input space.

2. The Geometric Story

Every linear transformation can be decomposed into three simple steps:

  1. Rotation in the input space (\(\mathbf{V}^T\)).
  2. Scaling along the axes (\(\Sigma\)).
  3. Rotation in the output space (\(\mathbf{U}\)).

3. Why SVD is the "Soul" of AI

  • Pseudo-Inverse: Solving non-square systems (Least Squares).
  • Dimensionality Reduction: Dropping small singular values to compress data (Truncated SVD).
  • Latent Semantic Analysis: Discovering hidden themes in text documents.

4. Python: Manual Verification

import numpy as np

A = np.array([[1, 2, 3], [4, 5, 6]]) # Non-square

U, s, Vt = np.linalg.svd(A)
Sigma = np.zeros(A.shape)
Sigma[:len(s), :len(s)] = np.diag(s)

# Reconstruct
A_new = U @ Sigma @ Vt

print(f"Original Shape: {A.shape}")
print(f"Singular Values: {s}")
print(f"Reconstruction Error: {np.linalg.norm(A - A_new)}")

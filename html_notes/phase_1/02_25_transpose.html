1. Turning Columns into Rows

The Transpose \( A^T \) flips the matrix over its main diagonal.

$$ (AB)^T = B^T A^T $$

The Dot Product Trick: The dot product of two vectors \( \mathbf{u}, \mathbf{v} \) can be written as matrix multiplication: \( \mathbf{u} \cdot \mathbf{v} = \mathbf{u}^T \mathbf{v} \).

2. The Covariance Matrix

In Data Science, if we have a dataset matrix \( X \) (rows=samples, cols=features), the matrix \( X^T X \) is the Covariance Matrix (up to a scaling factor).

  • It is always Square (n x n).
  • It is always Symmetric.
  • It tells us how features correlate with each other.

In Neural Style Transfer, the "Gram Matrix" (which captures style/texture) is just \( G = F^T F \), where \( F \) are the feature maps.

3. Calculating Style (Gram Matrix)

A simple implementation of a Style Matrix.

import numpy as np

# Feature Maps (e.g. 3 channels, flattened to 4 pixels each)
# Shape: (Channels, Pixels)
F = np.array([
    [1, 2, 0, 1], # Channel R
    [0, 1, 1, 2], # Channel G
    [1, 0, 2, 0]  # Channel B
])

print(f"Features Shape: {F.shape}")

# Gram Matrix: F * F^T (Correlations between channels)
gram = np.dot(F, F.T)

print("\nGram Matrix (Style):")
print(gram)
# The Diagonal tells us the "Intensity" of each channel.
# Off-diagonals tell us if channels "fire together".

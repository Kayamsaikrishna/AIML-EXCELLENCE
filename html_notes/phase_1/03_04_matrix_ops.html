1. The Trace

The Trace of a square matrix is the sum of its diagonal elements.

$$ \text{Tr}(A) = \sum_{i} a_{ii} $$

Amazing Property: The trace is the sum of the Eigenvalues! \( \text{Tr}(A) = \sum \lambda_i \). It is invariant under change of basis.

2. Broadcasting

In Math, \( A + \mathbf{v} \) is undefined (Size Mismatch). In Python/NumPy/PyTorch, it is valid!

The vector \( \mathbf{v} \) is "Broadcast" (copied/stretched) across all rows of the matrix. This is used everywhere, e.g., adding bias vectors to neural network layers.

3. Broadcasting in Action

Adding a bias vector to a batch of data.

import numpy as np

# Batch of 3 Linear Outputs (e.g., Logits for 3 classes)
# 2 Samples (Rows)
Mat = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

# Bias Vector (1 per class)
bias = np.array([10, 20, 30])

# Broadcasting Addition
# bias is added to EACH ROW automatically
Result = Mat + bias

print(f"Original:\n{Mat}")
print(f"Bias:\n{bias}")
print(f"\nResult (Broadcasted):\n{Result}")

# Trace
tr = np.trace(Mat) # 1+5 = 6 (Only main diagonal elements exist)
# Note: np.trace on non-square takes diagonal starting at (0,0)
print(f"\nTrace: {tr}")

09. Global vs Local Optima

Ensuring you've found the best possible answer.

1. Absolute Extrema

A Global (Absolute) Minimum is the single point in the entire domain where the function has its lowest value. A Local Minimum is the lowest point in just a small neighborhood.

The Extreme Value Theorem (EVT) for multi-variables states: If \(f\) is continuous on a closed, bounded set \(D\), then \(f\) attains an absolute maximum and absolute minimum at least once.

2. The Checklist for Global Minima

To find the global maximum/minimum on a closed set \(D\):

  • 1. Find the values of \(f\) at every critical point inside \(D\).
  • 2. Find the extreme values of \(f\) on the boundary of \(D\).
  • 3. The largest of these is the global max; the smallest is the global min.

3. AI/ML Connection: The Optimization Trap

Escaping Local Minima

Most AI models (Neural Networks) have "Non-Convex" loss landscapes with many Local Minima. If your model gets stuck in a local minimum, its accuracy won't be as good as the best possible (global) configuration.

This is why we use techniques like Stochastic Gradient Descent (SGD) with high Initial Learning Rates or Annealing. The "Noise" or "Heat" in these algorithms helps the model "jump" out of local minima in hopes of falling into a deeper, more global valley. Understanding the difference between local and global prevents AI practitioners from settling for mediocre models when a better one exists.

4. Python: Absolute Extrema Example

# Function: f(x) = x^3 - 3x on interval [-2, 3]
# Critical points: 3x^2 - 3 = 0 -> x = 1, -1

f = lambda x: x**3 - 3*x
points = [-1, 1, -2, 3] # Crit points + Boundaries
results = {p: f(p) for p in points}

print(f"Values: {results}")
print(f"Global Max: {max(results.values())} at x={max(results, key=results.get)}")
print(f"Global Min: {min(results.values())} at x={min(results, key=results.get)}")

Randomized Algorithms in AI

Strategic Uncertainty. Exploring the specialized algorithms that use randomness to handle massive-scale data where deterministic methods fail.

Complexity via Chaos

When dealing with billions of vectors (like in LLM embeddings) or trillions of tokens, we cannot afford to index them perfectly. Randomized Algorithms provide a way to compress high-dimensional info into low-dimensional "sketches" that retain essential properties.

1. Locality Sensitive Hashing (LSH)

A hashing technique where similar inputs produce similar hash values (the opposite of standard cryptographic hashing). This reduces a global search problem from $O(N)$ to almost $O(1)$.

$$ P(H(x) = H(y)) = \text{sim}(x, y) $$

MinHash

Used for Jaccard similarity between sets of words (e.g., detecting duplicate articles in a massive training corpus).

Random Projections

Mapping high-dimensional vectors to a lower-dimensional space while preserving distances (Johnson-Lindenstrauss Lemma).

2. Streaming & Sketching

Count-Min Sketch

A probabilistic data structure used to estimate frequencies in data streams. Used in AI to track "Top N" features or labels in real-time pipelines.

Reservoir Sampling

Selecting a random sample of $k$ items from a stream of unknown size. Vital for selecting diverse examples for "Instruction Tuning" or "Active Learning."

The Hashing Trick

Using a hash function to map features directly to indices in a fixed-size vector. This eliminates the need for a memory-intensive dictionary (Vocabulary).

NLP Search

Randomization in Action

  • Deduplication: AI datasets (like Common Crawl) are trillions of tokens. We use LSH to find and remove near-duplicate documents at scale.
  • ANN Search: Databases like Pinecone or Weaviate use randomized graph algorithms (HNSW) to provide sub-second retrieval for billion-vector embeddings.
  • Reformer Transformer: Uses LSH to group keys and values into "buckets," reducing the complexity of self-attention from $O(L^2)$ to $O(L \log L)$.
  • Data Augmentation: Randomly cropping images or perturbing speech is a randomized algorithm to artificially increase dataset size and improve model robustness.

10. Multicollinearity & VIF

When your features are echoing each other.

1. What is Multicollinearity?

Multicollinearity occurs when features in a regression model are highly correlated with each other. This is a problem because the model can no longer distinguish the individual effect of each variable. It's like having two people shouting the same thing—you can't tell who is more important.

2. VIF (Variance Inflation Factor)

VIF measures how much the variance of a coefficient is inflated due to multicollinearity. For a feature $X_j$:

$$ VIF_j = \frac{1}{1 - R_j^2} $$

where $R_j^2$ is the R-squared obtained by regressing $X_j$ against all other features.

  • VIF = 1: No correlation.
  • VIF > 5 or 10: High multicollinearity. The feature is redundant.

3. AI/ML Connection: Feature Selection and Stability

Numerical Stability in Large Models

In AI, Multicollinearity is the enemy of Model Generalization**.

If features are redundant, the matrix $(X^T X)$ becomes almost singular (un-invertible). This leads to **Exploding Gradients** and unstable weights. In AutoML Pipelines**, VIF is used to automatically drop redundant variables before training. It saves computational power and prevents the AI from "Over-reliance" on specific feature groups. It is also critical in Model Explainability (XAI)**: if VIF is high, your SHAP values will be misleading because the importance is split randomly between redundant features. Dropping high-VIF features results in a **Sparse, Robust Model** that is easier for humans to trust and cheaper to run in production.

4. Python: Calculating VIF

from statsmodels.stats.outliers_influence import variance_inflation_factor

# Calculate VIF for each feature
vif_data = pd.DataFrame()
vif_data["feature"] = X.columns
vif_data["VIF"] = [variance_inflation_factor(X.values, i) 
                   for i in range(len(X.columns))]

print(vif_data)
# If any VIF > 10, consider dropping that feature!

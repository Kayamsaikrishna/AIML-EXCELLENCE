1. Poles and Zeros

$$ R(x) = \frac{P(x)}{Q(x)} = k \frac{(x-z_1)\dots}{(x-p_1)\dots} $$
  • Zeros (\(z_i\)): Where numerator is 0. Function value is 0.
  • Poles (\(p_i\)): Where denominator is 0. Function goes to \( \pm \infty \).

AI Relevance: Gradient Explosion

If your loss function involves division (e.g., standardizing by variance \( \sigma^2 \)), calculating gradients near \( \sigma \approx 0 \) causes a "Pole" in the gradient landscape. We add \( \epsilon \) (epsilon) to avoid this singularity.

$$ \text{BatchNorm}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} $$

2. Padé Approximant

Often better than Taylor Series.

A Taylor Series uses a polynomial to approximate a function. A Padé Approximant uses a Rational Function. This allows it to model poles and singularities that Taylor Series cannot.

3. Visualizing a Pole

Plotting \( 1/x \) to see the explosion.

import numpy as np
import matplotlib.pyplot as plt

# Avoid 0 to prevent true math error, but get close
x = np.linspace(-2, 2, 100)
# Add epsilon
epsilon = 1e-5
y = 1 / (x + epsilon) 

print("At x=0, value explodes to:", 1/epsilon)
# This mimics 'Gradient Explosion' in RNNs/Training

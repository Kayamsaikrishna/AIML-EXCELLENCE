12. Rational Expressions & Asymptotes

Division is dangerous. Handling infinite explosions in math and code.

1. The DenominatorTrap

$$ f(x) = \frac{P(x)}{Q(x)} $$

The domain of a rational function excludes any \( x \) where \( Q(x) = 0 \). At these points, the function creates a Vertical Asymptote (it shoots to \( \infty \)).

Engineering Context

In Control Systems, poles (zeros of the denominator) determine stability. If a pole lies in the Right Half Plane, the system explodes (unstable oscillation).

2. Numerical Stability & Epsilon

In Deep Learning, we divide frequently: Batch Normalization, Softmax, standardizing images.

If the denominator (variance) is zero, the gradient becomes NaN (Not a Number), and the training crashes.

The Solution: Epsilon (\( \epsilon \))

We add a tiny constant (usually `1e-5` or `1e-8`) to safe-guard the division.

$$ \hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} $$

This prevents the asymptote. It turns the "infinite explosion" into a "large but finite number".

3. Coding Numerical Stability

Demonstrating the crash and the fix.

// Numpy: Handling Division by Zero
import numpy as np

# Scenario: Image variances. One pixel is completely black (variance=0).
variance = np.array([0.5, 1.2, 0.0, 0.9])

# FAILED Normalization
try:
    inv_std = 1.0 / np.sqrt(variance)
    print(f"Unsafe: {inv_std}")
except Exception as e:
    print("Crash!") 
# Numpy actually returns [1.41, 0.91, Inf, 1.05]
# 'Inf' will turn into 'NaN' as soon as you multiply it by 0.

# SAFE Normalization (Batch Norm style)
epsilon = 1e-5
safe_inv_std = 1.0 / np.sqrt(variance + epsilon)

print(f"Safe: {safe_inv_std}")
# Output: [1.414, 0.912, 316.22, 1.054]
# Index 2 is now 316 (large) instead of Infinity. Manageable.

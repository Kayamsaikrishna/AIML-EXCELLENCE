15. Exponential Models

The math of viral explosions and radioactive decay. Learning Rate Annealing.

1. The Formula of Change

$$ A(t) = P \cdot e^{rt} $$

Variables

  • P (Principal): The starting amount.
  • r (Rate): If \( r > 0 \), Growth. If \( r < 0 \), Decay.
  • t (Time): The independent variable.

2. Learning Rate Annealing

Training a neural network is like landing a plane. You start fast (high speed) to cover distance, but you must slow down (decay speed) as you approach the runway (minimum loss) to land smoothly.

Exponential Decay Schedule

$$ LR_{epoch} = LR_{initial} \cdot \gamma^{epoch} $$

We reduce the Learning Rate by a factor (e.g., 0.9) every epoch. This allows "Fine-Tuning".

3. Coding Decay

PyTorch handles this via `lr_scheduler`.

// PyTorch: Scheduling
import torch
import torch.nn as nn
import torch.optim as optim

model = nn.Linear(10, 1)
optimizer = optim.SGD(model.parameters(), lr=0.1)

# Decay LR by multiplying by 0.9 every step
scheduler = optim.lr_scheduler.ExponentialLR(optimizer, gamma=0.9)

print(f"Start LR: {optimizer.param_groups[0]['lr']}")

for epoch in range(3):
    optimizer.step()
    scheduler.step()
    current_lr = optimizer.param_groups[0]['lr']
    print(f"Epoch {epoch+1} LR: {current_lr:.4f}")

# Output:
# Start LR: 0.1
# Epoch 1 LR: 0.0900
# Epoch 2 LR: 0.0810
# Epoch 3 LR: 0.0729

06. Geometric Interpretation of Dot Product

Angle, Projection, and Similarity.

1. The Cosine Formula

While the algebraic definition is for computation, the geometric definition provides intuition. The dot product measures how much one vector points in the direction of another.

$$ \mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\| \|\mathbf{v}\| \cos \theta $$

2. Cosine Similarity in AI

Similarity Mapping

In Recommendation Systems or Semantic Search, we often don't care about the length (magnitude) of the vector, only the angle. This is Cosine Similarity.

  • Value = 1: Vectors are perfectly aligned (θ = 0°).
  • Value = 0: Vectors are orthogonal (θ = 90°), no similarity.
  • Value = -1: Vectors point in opposite directions (θ = 180°).

3. Python: Cosine Similarity

import numpy as np

def cosine_similarity(a, b):
    dot = np.dot(a, b)
    norm_a = np.linalg.norm(a)
    norm_b = np.linalg.norm(b)
    return dot / (norm_a * norm_b)

v1 = np.array([1, 2, 3])
v2 = np.array([1, 2, 2.8]) # Very similar

score = cosine_similarity(v1, v2)
print(f"Similarity Score: {score:.4f}") # Output: 0.99...

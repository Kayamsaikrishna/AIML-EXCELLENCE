Calculus 1.3 Foundations

Intuitive Understanding of Limits

The mathematical microscope that allows us to study the behavior of functions at the edge of the undefined, forming the bedrock of differentiation and training AI models.

The "Nearness" Concept

In deep learning, we constantly deal with continuous changes—adjusting weights by "tiny" amounts to reduce mistake. But what is "tiny"? A Limit formalizes the idea of approaching a specific state without necessarily reaching it. It answers the question: "Where is the function going, regardless of whether it actually gets there?"

1. The Limit Notation

\[ \lim_{x \to a} f(x) = L \]

This is read as: "The limit of \(f(x)\) as \(x\) approaches \(a\) is \(L\)."

Flow of Convergence: Typically, x never touches a, but f(x) gets arbitrarily close to L.

2. The "Hole" in the Graph

The most classic motivation for a limit is a function that is undefined at a specific point, creating a "hole". Consider the function:

\[ f(x) = \frac{x^2 - 1}{x - 1} \]

If we try to evaluate \(f(1)\), we get \(\frac{0}{0}\), which is indeterminate. We cannot compute it directly. However, we can simplify algebraically for \(x \neq 1\):

\[ \frac{x^2 - 1}{x - 1} = \frac{(x-1)(x+1)}{x-1} = x + 1 \]

So, the graph looks exactly like the line \(y = x + 1\), except for a hole at \(x = 1\). As \(x \to 1\), the value \(x+1 \to 2\).

3. AI/ML Application: The Gradient Definition

Why Limits Enable Learning

The core of training a Neural Network is Backpropagation, which relies on gradients (derivatives). The standard definition of a derivative is purely a limit:

\[ \frac{d\mathcal{L}}{dw} = \lim_{h \to 0} \frac{\mathcal{L}(w + h) - \mathcal{L}(w)}{h} \]

Here, \(\mathcal{L}\) differs slightly from a simple function like \(x^2\); it's a high-dimensional loss landscape.

Without the limit concept: We could never define "instantaneous slope" or "direction of steepest descent" because we can't literally set \(h=0\) (division by zero). The limit bridges the gap between discrete steps and continuous smooth optimization.

  • Numerical Gradient Checking: In practice, when debugging AI models, we approximate this limit by choosing a very small \(h\) (e.g., \(1e-7\)) to verify our analytic derivatives.

4. Python Implementation: Numerical Limits

We can simulate the limit process computationally to see convergence.

approaching_limit.py
import numpy as np
import pandas as pd

def f(x):
    # Function with a hole at x=2
    # f(x) = (x^2 - 4) / (x - 2) which simplifies to x + 2
    return (x**2 - 4) / (x - 2)

target_x = 2.0
deltas = [0.1, 0.01, 0.001, 0.0001, 1e-5]

print(f"{'Delta':<10} | {'x_left':<10} | {'f(x_left)':<10} | {'x_right':<10} | {'f(x_right)':<10}")
print("-" * 65)

for delta in deltas:
    # Approach from left
    x_left = target_x - delta
    y_left = f(x_left)
    
    # Approach from right
    x_right = target_x + delta
    y_right = f(x_right)
    
    print(f"{delta:<10} | {x_left:<10.5f} | {y_left:<10.5f} | {x_right:<10.5f} | {y_right:<10.5f}")

# Expected Limit: 4.0
# Notice both sides converge to 4.00000

Prob 1.4 Disjoint

Addition Rule (Mutually Exclusive)

Summing probabilities of separate paths.

Or Logic

Two events \(A\) and \(B\) are Mutually Exclusive (Disjoint) if they cannot happen at the same time (\(A \cap B = \emptyset\)). In this case: \[ P(A \text{ or } B) = P(A \cup B) = P(A) + P(B) \]

2. ML Connection: One-Hot Encoding

Categorical Distributions

In multi-class classification (e.g., ImageNet), classes are typically treated as mutually exclusive. An image is EITHER a "Cat" OR a "Dog" (not both). The probabilities output by Softmax sum to 1. \( P(\text{Object}) = P(\text{Cat}) + P(\text{Dog}) + \dots \)

3. Python: Disjoint Sum

disjoint_check.py
# Rolling a Die
# A = {1, 2}, B = {3, 4}
# A and B share no elements. They are Disjoint.

P_A = 2/6
P_B = 2/6

P_A_or_B = P_A + P_B
print(f"P(1, 2, 3, or 4): {P_A_or_B:.4f}")
# 4/6 = 0.6667

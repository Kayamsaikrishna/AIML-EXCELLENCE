27. Block & Partitioned Matrices

Treating sub-grids as single entities.

1. Anatomy of Partitioning

A large matrix can be partitioned into smaller blocks. This notation is essential for expressing complex neural architectural units.

$$ \mathbf{M} = \begin{bmatrix} \mathbf{A} & \mathbf{B} \\ \mathbf{C} & \mathbf{D} \end{bmatrix} $$

Matrix multiplication can be performed on these blocks as if they were scalars, provided their dimensions are compatible.

2. Hardware & AI Performance

Cache-Aware Computing

CPUs and GPUs don't multiply whole matrices at once. They use Tiled Matrix Multiplication, breaking matrices into "blocks" that fit into L1/L2 Cache or GPU Shared Memory. This reduces the "Memory Wall" bottleneck.

  • STRASSEN Algorithm: A recursive block-multiplication method that is faster than the standard \( O(n^3) \) for very large matrices.
  • Architecture Design: Multi-head attention in Transformers is computed by partitioning a hidden state matrix into smaller "head" blocks.

3. Python: Stacking and Partitioning

import numpy as np

A = np.ones((2, 2))
B = np.zeros((2, 2))
C = np.zeros((2, 2))
D = np.eye(2)

# Create a Block Matrix
M = np.block([
    [A, B],
    [C, D]
])

print(f"Block Matrix M:\n{M}")

# Slice (Partition)
block_top_left = M[:2, :2]

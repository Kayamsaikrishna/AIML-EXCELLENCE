1. Block Multiplication

If partitions act compatibly (dimensions match), we can multiply block matrices exactly like 2x2 scalars:

$$ \begin{bmatrix} A & B \\ C & D \end{bmatrix} \begin{bmatrix} X \\ Y \end{bmatrix} = \begin{bmatrix} AX + BY \\ CX + DY \end{bmatrix} $$

This allows parallel processing of huge matrices.

2. Multi-Head Attention

In Transformers, the weight matrices are huge. We process "Heads" separately.

This is effectively Block Diagonal multiplication. We compute \( Q_i K_i^T \) for each head \( i \) independently, which is mathematically partitioning the large embedding space into blocks.

3. Block Construction

Using NumPy to build block matrices directly.

import numpy as np

# Define small blocks
A = np.ones((2, 2))
B = np.zeros((2, 2))
C = np.eye(2)
D = np.full((2, 2), 7)

# Assemble Block Matrix
# [[A, B],
#  [C, D]]
Block = np.block([
    [A, B],
    [C, D]
])

print("Block Matrix (4x4):")
print(Block)

# Schur Complement Example S = D - C A^-1 B
# Since B is zero, S = D
print("\nSchur Complement (should be 7s):")
S = D - C @ np.linalg.inv(A) @ B
print(S)

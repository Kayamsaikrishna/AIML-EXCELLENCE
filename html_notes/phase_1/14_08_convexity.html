Optimization 1.7 The Safe Zone

Convex Sets & Functions

Why linear regression works every time, but neural networks don't.

The Definition

A function \(f\) is Convex if the line segment connecting any two points on the graph lies above the graph. Intuitively, it means the function is bowl-shaped everywhere.

$$ f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y) $$

If \(f\) is convex, then every local minimum is a Global Minimum.

2. AI/ML Connection: The Optimization Gap

Convex vs. Non-Convex

Linear Regression, Logistic Regression, and SVMs have Convex loss functions. This is why we blindly run optimizers on them; we know they will find the perfect answer.

Deep Neural Networks are highly Non-Convex. They have hills, valleys, and saddle points. However, modern research (like ResNets with skip connections) shows that adding certain architectural features "smooths" the landscape, making it behave *almost* like a convex function locally, which allows SGD to succeed.

3. Python: Checking Convexity

convexity_check.py
import numpy as np
import matplotlib.pyplot as plt

# Check Jensen's Inequality: f(E[x]) <= E[f(x)]
# Let f(x) = x^2 (Convex)

x = np.random.uniform(-5, 5, 1000)
f_x = x**2

E_x = np.mean(x)
val_of_mean = E_x**2

mean_of_vals = np.mean(f_x)

print(f"f(E[x]): {val_of_mean:.4f}")
print(f"E[f(x)]: {mean_of_vals:.4f}")

if val_of_mean <= mean_of_vals:
    print("Jensen's Inequality Holds (Likely Convex)")
else:
    print("Function is Non-Convex")

# This inequality is fundamental in Variational Autoencoders (ELBO).
# The 'Evidence Lower Bound' comes directly from Jensen's Inequality.

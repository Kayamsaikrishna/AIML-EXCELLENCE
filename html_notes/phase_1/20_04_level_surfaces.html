04. Level Surfaces

Finding boundaries in higher dimensions.

1. Expanding the Concept

If a function has three variables, \(f(x, y, z)\), its graph would exist in 4D space (which we cannot see). However, we can visualize the function by setting its value to a constant \(k\). This creates a 3D surface in 3D space, called a Level Surface.

$$ S_k = \{ (x, y, z) \mid f(x, y, z) = k \} $$

2. Example: The Sphere

The function \(f(x, y, z) = x^2 + y^2 + z^2\) has level surfaces that are Spheres centered at the origin. For \(k=4\), the level surface is a sphere of radius 2. As \(k\) increases, the "shells" grow larger.

3. AI/ML Connection: Decision Boundaries

Classification in 3D

In Binary Classification, we often have a model that outputs a probability \(p = \sigma(f(x_1, x_2, x_3))\). We decide that a point belongs to "Class A" if \(p \geq 0.5\).

The mathematical boundary between Class A and Class B is the Level Surface where \(f(x, y, z) = 0\) (or whatever value results in \(p=0.5\)). If \(f\) is linear, this surface is a Plane. If \(f\) is a Neural Network, this surface is a complex, warped Manifold that separates cats from dogs in the feature space. Understanding level surfaces allows AI engineers to reason about how "Curvy" or "Smooth" the model's logic is.

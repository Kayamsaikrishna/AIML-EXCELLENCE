Calculus 1.3 Time Dynamics

Related Rates

If A pulls B, and B pulls C, how fast is C moving when A starts running?

The Ripple Effect

In a connected system, you can't change one variable without affecting all the others that depend on it. Related Rates is simply Implicit Differentiation with respect to Time (\(t\)).

1. The Strategy

  1. Equation: Find the static relationship (e.g., \(x^2 + y^2 = z^2\)).
  2. Differentiate w.r.t Time: Apply \(d/dt\) to both sides. Remember Chain Rule: \( \frac{d}{dt}(x^2) = 2x \frac{dx}{dt} \).
  3. Substitute: Plug in the "snapshot" values (current x, y) and known rates.
  4. Solve: Isolate the unknown rate.

2. AI/ML Connection: Recurrent Neural Networks (RNNs)

Backpropagation Through Time (BPTT)

RNNs process data over time steps \(t=1, 2, 3...\). The hidden state \(h_t\) depends on the previous state \(h_{t-1}\) and current input \(x_t\).

When we train an RNN, we face a Related Rates problem: "How does the Loss \(L\) change with respect to the weights \(W\)?"

Because \(L\) depends on \(h_T\), which depends on \(h_{T-1}\), which depends on \(W\), we must chain the rates backward through time: \[ \frac{dL}{dW} = \sum_{t} \frac{dL}{dh_t} \cdot \frac{dh_t}{dW} \]

This is literally tracking how a small nudge to the weights at \(t=0\) ripples forward to affect the error at \(t=100\).

3. Python: The Ripple Simulation

related_rates_sim.py
import numpy as np

# Scenario: A balloon is being inflated.
# Volume V = (4/3) * pi * r^3
# We know dV/dt (pump rate) = 100 cm^3/s
# Question: How fast is radius growing (dr/dt) when r = 25 cm?

def calculate_dr_dt(r, dv_dt):
    # Differentiating V = (4/3)pi*r^3 w.r.t t:
    # dV/dt = 4 * pi * r^2 * dr/dt
    # Therefore: dr/dt = (dV/dt) / (4 * pi * r^2)
    return dv_dt / (4 * np.pi * r**2)

dv_dt = 100 # constant pump rate

radii_to_check = [5, 10, 25, 50]

print(f"Pump Rate dV/dt: {dv_dt} cm^3/s")
print("-" * 40)
print(f"{'Radius (cm)':<15} | {'Growth Rate dr/dt (cm/s)':<25}")
print("-" * 40)

for r in radii_to_check:
    rate = calculate_dr_dt(r, dv_dt)
    print(f"{r:<15} | {rate:.6f}")

print("-" * 40)
print("Insight: As the balloon gets bigger, the radius grows SLOWER for the same air input.")
# This is analogous to 'Vanishing Gradients' in a way - the effect dilutes over volume.

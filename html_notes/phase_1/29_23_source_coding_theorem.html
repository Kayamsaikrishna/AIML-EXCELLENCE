Compression Limits

Source Coding Theorem

The Ultimate Squeeze. Shannon's First Theorem proves that Entropy is the physical floor for how small we can compress any piece of information without losing it.

The Hard Floor of Reality

Can you compress a movie into a single bit? No. But why? Shannon proved that every source of information has a "density" called Entropy (\(H\)). If you try to represent a source using fewer than \(H\) bits per symbol, you are guaranteed to lose information.

1. The Fundamental Limit

The Theorem Statement

For any discrete memoryless source with entropy \(H(X)\), there exists a coding scheme that can represent the source with an average length \(L\), such that:

$$ H(X) \le L < H(X) + \epsilon $$

where \(\epsilon\) can be made arbitrarily small by encoding larger blocks of symbols.

Lossless vs. Lossy

This theorem applies to Lossless compression (like ZIP files). It tells us the theoretical limit of perfection. If you want to compress more, you must move to Lossy compression (JPEG, MP3), where you intentionally throw away entropy.

2. Redundancy: The Enemy of Efficiency

Most data we interact with is highly redundant. English text is about 4.7 bits per character if we assume letters are independent, but its true entropy (considering context and grammar) is closer to 1 bit per character.

Coding in Modern AI

The Source Coding Theorem is the invisible hand behind how AI "perceives" the world:

  • Byte Pair Encoding (BPE): Sub-word tokenizers used in models like GPT-4 are essentially source coders. They identify frequent patterns (merges) to represent common strings with single tokens, reducing the "description length" of the text and staying close to the entropy limit.
  • Model Compression: When we Prune or Quantize a neural network, we are trying to find a more efficient code for the model's weights. We are essentially saying: "The original 32-bit floats have too much redundancy; we can reach the same 'intelligence' using only 4 bits."
  • Autoencoders: The bottleneck layer in an autoencoder is a physical manifestation of source coding. It forces the network to find the "entropy-minimal" representation of the input data.

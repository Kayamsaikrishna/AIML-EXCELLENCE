01. Discrete Random Variables

Assigning numbers to uncertain outcomes.

1. Definition

A Random Variable (RV) is a function that maps outcomes of a random experiment to real numbers. A Discrete Random Variable is an RV whose possible values form a finite or countably infinite set.

$$ X: S \to \{x_1, x_2, \dots\} $$

For example, if we flip a coin three times and $X$ is the number of heads, $X \in \{0, 1, 2, 3\}$.

2. Key Properties

  • Range: The set of all possible values the RV can take.
  • Countability: Unlike height or weight (continuous), discrete variables jump between distinct values (like "number of clicks" or "category ID").

3. AI/ML Connection: Classification and Counts

Categorical Predictions

Discrete Random Variables are the foundation of Classification.

When an AI predicts whether an image is a "Cat" (0), "Dog" (1), or "Bird" (2), the output is a realization of a discrete random variable. In Natural Language Processing (NLP), every word in a vocabulary is mapped to an integer index—this is effectively treating the "Next Word" prediction as a categorical discrete RV. Even simple features like "Number of bedrooms" in a house price predictor or "User Rating" (1-5 stars) are discrete RVs. Understanding the distribution of these variables allows us to choose the right loss functions (like Cross-Entropy) for training.

4. Python: Simulating a Discrete RV

import numpy as np

# Simulate a Die Roll (Discrete RV with Range {1, 2, 3, 4, 5, 6})
def roll_die(n=10):
    return np.random.randint(1, 7, size=n)

outcomes = roll_die(20)
print(f"Discrete Outcomes: {outcomes}")
print(f"Unique values: {np.unique(outcomes)}")

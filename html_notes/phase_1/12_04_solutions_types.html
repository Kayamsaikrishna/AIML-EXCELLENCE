04. Particular vs General Solutions

Describing the entire infinite set.

1. The Decomposition

Every solution \(\mathbf{x}\) to \(\mathbf{Ax} = \mathbf{b}\) can be split into two parts:

$$ \mathbf{x} = \mathbf{x}_p + \mathbf{x}_h $$
  • \(\mathbf{x}_p\) (Particular Solution): Any single vector that satisfies \(\mathbf{Ax}_p = \mathbf{b}\).
  • \(\mathbf{x}_h\) (Homogeneous Solution): Any vector in the Null Space (\(\mathbf{Ax}_h = \mathbf{0}\)).

2. The Gaussian Workflow

  1. Transform the augmented matrix \([\mathbf{A}|\mathbf{b}]\) to RREF.
  2. Identify pivot variables and free variables.
  3. Solve for pivot variables in terms of free variables.
  4. Write \(\mathbf{x}\) as a linear combination of vectors multiplied by the free variable scalars.

3. AI Engineering Application

Unconstrained Optimization

When finding the minimum of a quadratic loss function, if the Hessian matrix is singular, there isn't one unique "best" set of weights. There is a whole manifold (the general solution) of optimal parameters. Regularization techniques (like L2) "pick" a specific particular solution—usually the one with the smallest norm.

4. Python: Symbolically Solving

import sympy as sp

# Define variables
x1, x2, x3 = sp.symbols('x1 x2 x3')

# System: x1 + x2 + x3 = 6
#         2x1 + x2 + 2x3 = 10
A = sp.Matrix([[1, 1, 1], [2, 1, 2]])
b = sp.Matrix([6, 10])

# Solve
sol = sp.solve_linear_system(A.row_join(b), x1, x2, x3)

print(f"Solution: {sol}")
# output: {x1: 4 - x3, x2: 2} 
# x3 is the free variable!

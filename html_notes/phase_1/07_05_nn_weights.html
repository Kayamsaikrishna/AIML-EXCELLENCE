1. Interpretation

If we view a layer computation as \( z = Wx \):

  • Rows of W: Each row is a "template" or "filter". The dot product measures how much the input \( x \) matches that template.
  • Columns of W: Basis vectors for the output space. \( x \) is the coordinate vector in this new basis.

2. Initialization Matters

If \( W \) is initialized to zeros, gradients die (Symmetry breaking fails). If initialized too large, activations saturate.

Xavier/He Initialization sets the random variance of \( W \) based on the size of the matrix (Fan-in/Fan-out) to keep signal magnitude stable across layers (keeping Spectral Radius close to 1).

3. Visualizing Weights (MNIST)

import numpy as np
import matplotlib.pyplot as plt

# Simulate a trained Weight Matrix for MNIST (784 inputs -> 10 outputs)
# 10 rows (digits), 784 cols (pixels)
# In reality, we learn these. Here we simulate random patterns.
W = np.random.randn(10, 784)

# Visualize the weights for digit '0'
weight_image = W[0].reshape(28, 28)

plt.imshow(weight_image, cmap='seismic')
plt.title("What Neuron 0 looks for (Weights)")
plt.colorbar()
# Positive regions (Red) : "Ink here implies Digit 0"
# Negative regions (Blue): "Ink here implies NOT Digit 0"
plt.show()

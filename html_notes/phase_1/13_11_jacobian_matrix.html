Calculus 1.6 Linearization

The Jacobian Matrix

How to stretch space locally.

The "Derivative" of a Vector Field

A single derivative \( f'(x) \) works for \( f: \mathbb{R} \to \mathbb{R} \). The Gradient \( \nabla f \) works for \( f: \mathbb{R}^n \to \mathbb{R} \). What if we have multiple inputs mapping to multiple outputs? \( f: \mathbb{R}^n \to \mathbb{R}^m \) (e.g., Robot arm velocity).

The derivative is a Matrix of all possible partials, called the Jacobian: \[ \mathbf{J} = \begin{bmatrix} \frac{\partial f_1}{\partial x_1} & \cdots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \cdots & \frac{\partial f_m}{\partial x_n} \end{bmatrix} \]

2. AI/ML Connection: Generative Flows

Normalizing Flows

In Generative Modeling, we often want to map a simple distribution (Gaussian noise) to a complex one (Images of faces). If we transform a probability distribution using a function \( f \), the density changes. To compute the new probability, we Must divide by the absolute value of the **Determinant of the Jacobian** (\( |\det(J)| \)).

This determinant tells us how much the function "stretches" or "squishes" space at that point. If the Jacobian determinant is 2, the function expands volume by 2x, so the probability density must drop by half to integrate to 1. Normalizing Flows (like Glow or RealNVP) are architected specifically so that this Jacobian determinant is easy to compute.

3. Python: Symbolic Jacobian

jacobian_calc.py
import sympy as sp

# Define variables for Polar Coordinates
r, theta = sp.symbols('r theta')

# Transformation: x = r cos(theta), y = r sin(theta)
x = r * sp.cos(theta)
y = r * sp.sin(theta)

# Define vector function F = [x, y]
F = sp.Matrix([x, y])
vars = sp.Matrix([r, theta])

# Compute Jacobian Matrix
J = F.jacobian(vars)

print("Jacobian Matrix:")
sp.pprint(J)

# Compute Determinant
det_J = sp.simplify(J.det())
print(f"\nDeterminant: {det_J}")
# Expected: r (Since dx dy = r dr dtheta)

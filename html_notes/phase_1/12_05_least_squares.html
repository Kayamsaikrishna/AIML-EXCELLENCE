05. Least Squares Solutions

Solving the unsolvable.

1. The Normal Equation

If \(\mathbf{Ax} = \mathbf{b}\) has no solution (inconsistent), we find the best approximation \(\hat{\mathbf{x}}\) by minimizing the residual \(\|\mathbf{b} - \mathbf{A}\mathbf{x}\|^2\). This is achieved by solving the Normal Equation:

$$ \mathbf{A}^T\mathbf{A}\hat{\mathbf{x}} = \mathbf{A}^T\mathbf{b} $$

Geometrically, we are projecting the vector \(\mathbf{b}\) onto the Column Space of \(\mathbf{A}\).

2. AI Connection: Linear Regression

Optimal Weights

In Linear Regression, \(\mathbf{A}\) is the feature matrix and \(\mathbf{b}\) is the target values. The closed-form solution for the weights is:

$$ \mathbf{w} = (\mathbf{A}^T\mathbf{A})^{-1}\mathbf{A}^T\mathbf{b} $$

3. Numerical Stability Warning

While the Normal Equation is elegant, computing \((\mathbf{A}^T\mathbf{A})^{-1}\) is often numerically unstable if \(\mathbf{A}\) is ill-conditioned. In production AI libraries (like Scikit-Learn or PyTorch), we use QR Decomposition or SVD to solve the least squares problem instead.

4. Python: Manual vs Library

import numpy as np

# Data: points (0,1), (1,2), (2,2)
A = np.array([[1, 0], [1, 1], [1, 2]])
b = np.array([1, 2, 2])

# 1. Normal Equation Approach
w_normal = np.linalg.inv(A.T @ A) @ A.T @ b

# 2. Recommended NumPy approach (Uses SVD)
w_lstsq, residuals, rank, s = np.linalg.lstsq(A, b, rcond=None)

print(f"Normal Eq result: {w_normal}")
print(f"LSTSQ result:    {w_lstsq}")

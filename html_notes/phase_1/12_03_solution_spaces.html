03. Solution Spaces

The geometry of possible answers.

1. Geometry of Ax=0

The solution set of \(\mathbf{Ax} = \mathbf{0}\) is a Subspace. This means if \(\mathbf{x}_1\) and \(\mathbf{x}_2\) are solutions, then \(\mathbf{x}_1 + \mathbf{x}_2\) is also a solution.

$$ \text{Dimension of Solution Space} = n - \text{rank}(\mathbf{A}) $$

2. Geometry of Ax=b

The solution set of \(\mathbf{Ax} = \mathbf{b}\) (where \(\mathbf{b} \neq 0\)) is NOT a subspace. It is an Affine Space—a subspace shifted away from the origin by a vector \(\mathbf{x}_p\).

3. AI Analogy

Overfitting

If your model has too many parameters (high-dimensional solution space for \(\mathbf{Ax}=\mathbf{0}\)), it means there are many different combinations of weights that result in the same output. This "slack" is what allows for overfitting.

4. Python: Representing General Solutions

Solutions are usually expressed as: \(\mathbf{x} = \mathbf{x}_p + c_1\mathbf{v}_1 + c_2\mathbf{v}_2\dots\)

import numpy as np

A = np.array([[1, 1, 1], [1, 1, 1]])
b = np.array([5, 5])

# One particular solution (p)
xp = np.array([5, 0, 0])

# Basis for Null Space (v)
v1 = np.array([-1, 1, 0])
v2 = np.array([-1, 0, 1])

# Any combination is valid
c1, c2 = 2.5, -1.2
x_general = xp + c1*v1 + c2*v2

print(f"General solution point: {x_general}")
print(f"Verify Ax=b: {A @ x_general}")

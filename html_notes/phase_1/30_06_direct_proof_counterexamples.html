Direct Proof & Counterexamples

Connecting the Dots. The simplest yet most profound way to build a bridge of truth, and the surgical tool for tearing down false claims with a single strike.

The Bridge of Reason

A Direct Proof is a flow of logical steps starting from a known fact (the Hypothesis) and arriving at a target (the Conclusion) using only definitions, axioms, and previously proven theorems. It's the "straight line" of mathematics.

1. Structure of a Direct Proof

1. State the Hypothesis

Say exactly what you are assuming. \(P\).

2. Expand Definitions

Turn words into math. If \(x\) is even, then \(x = 2k\) for some integer \(k\).

3. Apply Inference

Use algebra or previously known theorems to transform the statement.

4. Reach Conclusion

Show that the result matches the goal. \(\therefore Q\).

Example: Prove that if \(n\) is even, then \(n^2\) is even.

1. Assume \(n = 2k\).

2. Then \(n^2 = (2k)^2 = 4k^2 = 2(2k^2)\).

3. Let \(m = 2k^2\). Then \(n^2 = 2m\), which is the definition of an even number. \(\square\)

2. Disproving: The Counterexample

To prove a universal statement (\(\forall x P(x)\)) is true, you must prove it for all cases. To prove it is false, you only need to find one case where it fails. This is a Counterexample.

Claim: All prime numbers are odd.

Counterexample: 2 is a prime number, but it is even. \(\therefore\) The claim is false.

Verification Debugging

Proofs in Engineering

  • Unit Testing: A unit test is essentially searching for a Counterexample. One failing test case disproves the claim "My code works for all inputs."
  • Formal Verification: In mission-critical systems (like autonomous car brakes), engineers use "Model Checkers" to Directly Prove that under the given axioms (physics rules), the system will never enter an unsafe state (\(\forall t, \text{Safety}(t) = \text{True}\)).
  • Edge Case Discovery: Robust AI development involves adversarial testing — finding the one "adversarial image" (Counterexample) that makes the model think a stop sign is a speed limit sign.

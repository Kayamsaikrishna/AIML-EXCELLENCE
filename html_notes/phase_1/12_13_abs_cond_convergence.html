Calculus 1.5 Stability

Absolute vs Conditional Convergence

Does the order of ingredients matter?

The Gold Standard

  • Absolute Convergence: The series converges even if you make every term positive (\(\sum |a_n|\)). This is "Robust Convergence".
  • Conditional Convergence: The series converges only because of the cancelling signs. If you took absolute values, it would explode.

Riemann's Rearrangement Theorem: If a series is only conditionally convergent, you can rearrange the terms to make it sum to any number you want! Absolute convergence guarantees the sum is unique regardless of order.

2. AI/ML Connection: Permutation Invariance

Set-Based Learning

In modern AI architectures like Transformers or PointNets (for 3D data), the input is often a set of items where order shouldn't matter (e.g., a bag of words). We want the model to be Permutation Invariant.

This maps mathematically to Absolute Convergence. If our aggregation functions (like Sum Pooling) relied on Conditional Convergence, then shuffling the input data would change the output result entirely, making the model unstable and useless. We design neural aggregators to be absolutely convergent (usually by using symmetric functions) to ensure consistency.

3. Python: Breaking Math by Reordering

rearrangement_chaos.py
import numpy as np

# The Alternating Harmonic series is Conditionally Convergent.
# Standard Order: 1 - 1/2 + 1/3 - 1/4 ... -> ln(2)
# Rearranged Order: 1 + 1/3 - 1/2 + 1/5 + 1/7 - 1/4 ... -> 1.5 * ln(2)

def standard_sum(n):
    return sum(((-1)**(i+1))/i for i in range(1, n+1))

def rearranged_sum(n):
    # Pattern: Positive, Positive, Negative
    # Roughly simulates the rearrangement logic
    val = 0
    pos_idx = 1
    neg_idx = 2
    for _ in range(n // 3):
        val += 1/pos_idx + 1/(pos_idx+2) - 1/neg_idx
        pos_idx += 4
        neg_idx += 2
    return val

print(f"Standard Sum: {standard_sum(10000):.4f} (Target: {np.log(2):.4f})")
print(f"Rearranged Sum: {rearranged_sum(10000):.4f} (Target: {1.5*np.log(2):.4f})")

# The sum CHANGED just by reordering!
# This proves Conditional Convergence is fragile.

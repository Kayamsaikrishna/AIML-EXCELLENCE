03. Modeling and Optimization

Turning constraints into coordinates.

1. The Workflow

  1. Objective Function: Define what you want to maximize/minimize.
  2. Constraints: Relate the variables using problem rules.
  3. Elimination: Substitute constraints to get a single-variable function.
  4. Solution: Find critical points and test with the 2nd derivative.

2. Classic Example: Max Area

You have 100m of fence for a rectangular field against a wall. Maximize Area \(A = x \cdot y\).

  • Constraint: \(x + 2y = 100 \implies x = 100 - 2y\)
  • Objective: \(A = (100-2y)y = 100y - 2y^2\)
  • Optimize: \(A' = 100 - 4y = 0 \implies y = 25m\).

3. AI Connection: Hyperparameter Optimization

Optimization in AI isn't just about training weights. We also optimize **Hyperparameters** (like the learning rate, number of layers, or regularization strength). While we often use "Black Box" optimizers like Bayesian Search, the goal is identical: define a surrogate model of the accuracy function and find its peak using derivatives.

4. Python: Numerical Optimization

from scipy.optimize import minimize_scalar

# We want to minimize f(x) = (x-3)^2 + 4
def objective(x):
    return (x-3)**2 + 4

res = minimize_scalar(objective)

print(f"Optimal x: {res.x:.4f}")
print(f"Minimum Value: {res.fun:.4f}")

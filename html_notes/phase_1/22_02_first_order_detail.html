02. First-Order Differential Equations

Solving the simplest building blocks of change.

1. Separable Equations

A first-order ODE is Separable if it can be written as \( \frac{dy}{dx} = g(x)h(y) \). We solve these by grouping all \(y\) terms with \(dy\) and all \(x\) terms with \(dx\), then integrating both sides.

$$ \int \frac{1}{h(y)} dy = \int g(x) dx $$

2. Linear Equations & Integrating Factor

For equations of the form \( y' + P(x)y = Q(x) \), we use a magic multiplier called the Integrating Factor (\(I\)):

$$ I(x) = e^{\int P(x) dx} $$

Multiplying the whole equation by \(I(x)\) makes the left side a perfect Product Rule derivative, allowing for a direct solution.

3. AI/ML Connection: Learning Rate Scheduling

Decay Dynamics

When training an AI, we often want the Learning Rate (\(\eta\)) to decrease over time so the model settles into a perfect minimum.

A common "Exponential Decay" schedule is defined by a simple first-order ODE: \( \frac{d\eta}{dt} = -k\eta \). The solution is \(\eta(t) = \eta_0 e^{-kt}\). By understanding how to solve this ODE, AI engineers can predict exactly when the learning rate will become too small to make progress, allowing them to optimize the training "Compute Budget" effectively.

4. Python: Solving Linear ODEs

# Solving dy/dx + 2y = exp(-x)
# P(x) = 2, Q(x) = exp(-x)
# Integrating factor = exp(2x)

import sympy as sp

x = sp.symbols('x')
y = sp.Function('y')

ode = sp.Eq(y(x).diff(x) + 2*y(x), sp.exp(-x))
sol = sp.dsolve(ode, y(x))

print(f"Solution: {sol}")
# Result: y(x) = (C1 + exp(x)) * exp(-2x)

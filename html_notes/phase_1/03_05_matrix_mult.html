1. The Standard View

The element \( c_{ij} \) is the dot product of the \( i \)-th row of \( A \) and the \( j \)-th column of \( B \).

$$ c_{ij} = \text{row}_i(A) \cdot \text{col}_j(B) $$

For this to work, the "inner dimensions" must match: \( (m \times \mathbf{k}) \times (\mathbf{k} \times n) \to (m \times n) \).

2. Neural Layers

A Fully Connected Layer involves: \( Y = X W^T + b \).

  • \( X \): The input batch.
  • \( W \): The weights matrix.

This single operation transforms the entire batch of inputs into outputs in parallel. GPUs are optimized specifically to do this one operation blazingly fast.

3. The @ Operator

The modern way to multiply matrices.

import numpy as np

# A: 2x3
A = np.array([
    [1, 2, 0],
    [3, 1, 4]
])

# B: 3x2
B = np.array([
    [4, 1],
    [2, 2],
    [1, 0]
])

# Result C: 2x2
# Op 1: matmul
C1 = np.matmul(A, B)

# Op 2: @ operator (Preferred)
C2 = A @ B

print(f"A Shape: {A.shape}, B Shape: {B.shape}")
print(f"Result Shape: {C2.shape}")
print(f"\nResult C:\n{C2}")

# Element (0,0): 1*4 + 2*2 + 0*1 = 8
# Element (0,1): 1*1 + 2*2 + 0*0 = 5

05. Matrix Multiplication (Dot Product Rule)

The dynamic engine of AI inference.

1. The Fundamental Rule

To multiply \( \mathbf{A} \) (\( m \times n \)) and \( \mathbf{B} \) (\( n \times p \)), the columns of A must match the rows of B. The result is a matrix of size \( m \times p \).

$$ c_{ij} = \sum_{k=1}^n a_{ik}b_{kj} $$

Each element \( c_{ij} \) is the Dot Product of the \( i \)-th row of A and the \( j \)-th column of B.

2. Visualizing Parallel Processing

Linear Layers (Dense Layers)

In a Neural Network, calculating the hidden state is a matrix multiplication: \( \mathbf{H} = \sigma(\mathbf{X} \mathbf{W}) \).

  • X: Input batch matrix.
  • W: Weight matrix where each column is one neuron.
  • Scaling: Since compute cost is \( O(m \cdot n \cdot p) \), optimizing matrix multiplication is the primary goal of AI hardware designers (Tensor Cores).

3. Python: Efficient Multiplication

import numpy as np

A = np.random.rand(128, 512) # 128 samples, 512 features
W = np.random.rand(512, 1024) # 512 inputs, 1024 neurons

# Standard Matrix Mult (The @ operator)
C = A @ W 

print(f"Result shape: {C.shape}") # (128, 1024)

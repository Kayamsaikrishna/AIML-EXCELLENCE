33. Band Matrices & Vectorization

Structured sparsity for ultra-fast solvers.

1. Defining Band Matrices

A Band Matrix is a sparse matrix whose non-zero entries are confined to a diagonal band. Common types include:

  • Tridiagonal: Non-zeros only on the main, super, and sub-diagonals.
  • Pentadiagonal: Five non-zero diagonals.
$$ \begin{bmatrix} a_1 & b_1 & 0 \\ c_1 & a_2 & b_2 \\ 0 & c_2 & a_3 \end{bmatrix} $$

2. Vectorization: Thinking in Batches

SIMD and Parallelism

Throughout this Matrices section, the recurring theme is Vectorization. Instead of a for loop traversing elements, we use Single Instruction, Multiple Data (SIMD). Modern CPUs (AVX/AMX) and GPUs (Tensor Cores) are built specifically to do this for Band and Dense matrices.

  • Toeplitz Matrices: Constant diagonal band matrices used to represent convolutions.
  • Computation Cost: For a tridiagonal matrix, solving \( \mathbf{Ax} = \mathbf{b} \) is \( O(n) \), whereas for a general matrix it's \( O(n^3) \).

3. Python: Banded Solvers

import numpy as np
from scipy.linalg import solve_banded

# Solving a tridiagonal system Ax = b
# A is stored in a compact format (l, u)
# Top row is padding + super-diagonal
# Middle row is main diagonal
# Bottom row is sub-diagonal + padding
ab = np.array([
    [0, 1, 1], # Super-diag
    [2, 2, 2], # Main-diag
    [1, 1, 0]  # Sub-diag
])

b = np.array([1, 1, 1])

x = solve_banded((1, 1), ab, b)
print(f"Banded Solution: {x}")

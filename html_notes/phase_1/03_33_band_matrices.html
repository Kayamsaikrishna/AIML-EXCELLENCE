1. Definition

A Band Matrix has non-zero entries only within a "band" around the main diagonal.

  • Tridiagonal: Bandwidth 1. Common in 1D Physics simulation.
  • Pentadiagonal: Bandwidth 2.

Solving \( Ax=b \) for tridiagonal systems takes \( O(n) \) time, compared to \( O(n^3) \) for general matrices.

2. 1D Convolutions

A 1D Convolution with kernel size 3 is precisely matrix multiplication by a constant Toeplitz Tridiagonal Matrix.

$$ \begin{bmatrix} w_1 & w_2 & 0 & 0 \\ w_0 & w_1 & w_2 & 0 \\ 0 & w_0 & w_1 & w_2 \\ 0 & 0 & w_0 & w_1 \end{bmatrix} $$

The "Band" structure reflects the "Local Receptive Field".

3. SciPy Banded Solver

Solving efficiently.

import numpy as np
import scipy.linalg as la

# Tridiagonal System
#   2x1 + 1x2 = 8
#   1x1 + 2x2 + 1x3 = 12
#   1x2 + 2x3 = 10

# Banded storage format (3 rows x N cols)
# Row 0: Super-diagonal
# Row 1: Diagonal
# Row 2: Sub-diagonal
ab = np.array([
    [0, 1, 1],
    [2, 2, 2],
    [1, 1, 0]
])
b = np.array([8, 12, 10])

# Solve using specialized solver
x = la.solve_banded((1, 1), ab, b)
print(f"Solution: {x}")

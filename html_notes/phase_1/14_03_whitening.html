03. Whitening Transformations

Removing feature redundancy via Eigendecomposition.

1. What is Whitening?

Whitening (or Sphering) is a linear transformation that transforms a vector of random variables with a known covariance matrix \(\mathbf{\Sigma}\) into a new vector whose covariance is the Identity Matrix \(\mathbf{I}\).

$$ \mathbf{x}_{white} = \mathbf{\Sigma}^{-1/2} (\mathbf{x} - \mu) $$

Results: All features have unit variance and are uncorrelated.

2. The Math behind the "Undo"

We use Eigendecomposition \(\mathbf{\Sigma} = \mathbf{V}\mathbf{\Lambda}\mathbf{V}^T\):

$$ \mathbf{\Sigma}^{-1/2} = \mathbf{V} \mathbf{\Lambda}^{-1/2} \mathbf{V}^T $$

This "unsquashes" the data from its elliptical distribution back into a perfect sphere.

3. AI Connection: Batch Norm & Vision

Stable Learning

Neural networks often struggle with "Internal Covariate Shift". Batch Normalization is a lightweight version of whitening. In vision, ZCA Whitening is used as a preprocessing step to remove low-frequency redundancy (like flat background colors) and emphasize edges.

4. Python: ZCA Whitening

import numpy as np

def zca_whitening(X):
    # X shape: (samples, features)
    X_centered = X - np.mean(X, axis=0)
    sigma = np.cov(X_centered, rowvar=False)
    
    # Eigendecomposition
    vals, vecs = np.linalg.eigh(sigma)
    
    # Whitening matrix: V * L^-0.5 * V^T
    zca_matrix = vecs @ np.diag(1.0 / np.sqrt(vals + 1e-5)) @ vecs.T
    
    return X_centered @ zca_matrix

# Test
X = np.random.multivariate_normal([0, 0], [[1, 0.9], [0.9, 1]], 1000)
X_white = zca_whitening(X)

print(f"New Covariance:\n{np.round(np.cov(X_white, rowvar=False), 2)}")

Prob 1.4 Advanced Sets

Inclusion-Exclusion Principle

Correcting the overcounting for N sets.

The Alternating Sum

For \(n\) sets, the probability of their union is: \[ P(\cup A_i) = \sum P(A_i) - \sum P(A_i \cap A_j) + \sum P(A_i \cap A_j \cap A_k) - \dots \] Add singles, subtract pairs, add triples, subtract quads...

2. ML Connection: Derangements

Matching Problems

If we randomly permute a dataset of \(N\) labels, what is the probability that *at least one* label remains in its original correct position (a Fixed Point)? Using Incl-Excl, as \(N \to \infty\), this probability approaches \(1 - 1/e \approx 0.632\). This appears in Bootstrap Aggregating (Bagging): Each bagged tree uses only ~63.2% of the unique training examples!

1. Definition

An eigenvector (\( x \)) of a square matrix \( A \) is a non-zero vector such that multiplication by \( A \) alters only its scale, not its direction.

$$ A \mathbf{x} = \lambda \mathbf{x} $$
  • \( \mathbf{x} \): The Eigenvector (The "Axis").
  • \( \lambda \): The Eigenvalue (The "Stretch Amount").

2. Principal Component Analysis

In Data Science, we look for the "Principal Components" of a dataset.

These components are simply the eigenvectors of the Covariance Matrix. They point in the directions of maximum variance (information). If you want to compress an image, you keep the eigenvectors with large \( \lambda \) and discard the small ones.

3. NumPy Check

Verifying the equality.

import numpy as np

A = np.array([
    [4, 1],
    [2, 3]
])

# Compute Eigenvalues and Eigenvectors
vals, vecs = np.linalg.eig(A)

# Check the first pair
lambda_1 = vals[0]
v_1 = vecs[:, 0]

print(f"Eigenvalue: {lambda_1}")
print(f"Eigenvector: {v_1}")

# A @ x
Ax = A @ v_1

# lambda * x
Lx = lambda_1 * v_1

print("\nCheck A @ x == lambda * x:")
print(f"Ax: {Ax}")
print(f"Lx: {Lx}")
# Matches exactly

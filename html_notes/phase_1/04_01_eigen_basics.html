01. Eigenvalues & Eigenvectors

Finding the axes that don't rotate.

1. The Intuition: Stretching without Turning

Usually, when you multiply a matrix \(\mathbf{A}\) by a vector \(\mathbf{v}\), the vector is both stretched and rotated. However, for every square matrix, there exist special vectors that are only stretched.

$$ \mathbf{A}\mathbf{v} = \lambda\mathbf{v} $$
  • Eigenvector (\(\mathbf{v}\)): The direction that remains unchanged by the transformation.
  • Eigenvalue (\(\lambda\)): The factor by which that direction is scaled (stretched or squashed).

Note: \(\mathbf{v}\) must be non-zero (\(\mathbf{v} \neq 0\)).

2. Visualizing Eigen-space

In an Eigen-direction, the output is just a scalar multiple of the input.

3. Real World AI Application

Steady State Distributions

In PageRank (the algorithm that built Google), the importance of a web page is determined by the "Steady State" of a random surfer. This steady state is exactly the principal eigenvector of the web's transition matrix where \(\lambda = 1\).

4. Python: Quick Eigen Check

import numpy as np

A = np.array([[3, 1], [0, 2]])

# Compute eigenvalues and eigenvectors
eigenvalues, eigenvectors = np.linalg.eig(A)

print(f"Eigenvalues: {eigenvalues}")
print(f"Eigenvectors:\n{eigenvectors}")

# Verify Av = lambda * v for the first pair
v1 = eigenvectors[:, 0]
l1 = eigenvalues[0]

lhs = A @ v1
rhs = l1 * v1

print(f"Is Av == lambda*v? {np.allclose(lhs, rhs)}")

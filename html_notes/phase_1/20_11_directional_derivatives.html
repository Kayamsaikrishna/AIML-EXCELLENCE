06. Directional Derivatives

Finding the slope in any direction.

1. The Limitation of Partial Derivatives

Partial derivatives \(f_x\) and \(f_y\) only tell you the slope if you move exactly along the x or y axes. But what if you want to walk "North-East" or at any arbitrary angle \(\theta\)? This is where the Directional Derivative comes in.

2. The Formula

The directional derivative of \(f\) in the direction of a unit vector \(\vec{u} = \langle a, b \rangle\) is:

$$ D_u f(x, y) = f_x(x, y)a + f_y(x, y)b = \nabla f \cdot \vec{u} $$

It is the dot product of the gradient vector and the direction vector.

3. AI/ML Connection: Exploring "What If" Directions

Sensitivity Analysis

In AI, we often want to know: "How much will the model prediction change if we increase weight \(w_1\) AND decrease weight \(w_2\) simultaneously?" This is a directional derivative.

It is used in Adversarial Robustness testing. An attacker looks for the directional derivative that results in the greatest increase in error. If an AI model has very high directional derivatives in certain directions, it is considered "brittle" to small perturbations in the input (like adding tiny, specific noises to an image to make it look like a cat to a human but a toaster to the AI).

4. Python: Calculating Slope in a Custom Direction

import numpy as np

# f(x, y) = x^2 + y^2. At (1, 1).
# Gradient grad_f = <2x, 2y> = <2, 2>
# Direction: North-East (45 degrees) -> u = <1/sqrt(2), 1/sqrt(2)>

grad_f = np.array([2, 2])
u = np.array([1, 1]) / np.sqrt(2) # Normalize to unit vector

directional_deriv = np.dot(grad_f, u)

print(f"Slope in the NE direction: {directional_deriv:.4f}")

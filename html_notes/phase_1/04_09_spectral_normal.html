1. Definition

A matrix \( A \) is Normal if it commutes with its conjugate transpose:

$$ A A^H = A^H A $$

If \( A \) is Normal, it has a complete set of orthonormal eigenvectors, even if the eigenvalues are complex.

2. Orthogonal Initialization

Unitary (or Orthogonal) matrices are Normal.

Initializing RNN weights with Orthogonal matrices preserves the gradient norm over time (because \( |\lambda|=1 \)), preventing both explosion and vanishing gradients during early training.

3. Checking Normality

import numpy as np

# A Skew-Symmetric Matrix (Normal, but not Symmetric)
A = np.array([
    [0, -1],
    [1, 0]
])

AH = A.conjugate().T

# Check Commutativity
commutator = A @ AH - AH @ A
is_normal = np.allclose(commutator, 0)
print(f"Is Normal? {is_normal}")
print(f"Norm of Commutator: {np.linalg.norm(commutator)}")

# Eigen decomposition
# Results will be complex (+- i), but vectors will be orthogonal
vals, vecs = np.linalg.eig(A)

print(f"\nEigenvalues: {vals}")
# [0+1j, 0-1j]

# Check orthogonality of eigenvectors
dot = np.vdot(vecs[:,0], vecs[:,1]) # Use vdot for complex vectors!
print(f"Dot Product: {dot:.2e}")

03. Basic Integration Rules

Shortcuts for polynomial reconstruction.

1. The Power Rule for Integration

To integrate \(x^n\), you reverse the differentiation rule: add 1 to the power and divide by the new power.

$$ \int x^n dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1) $$

Note: If \(n = -1\), the result is \(\ln|x| + C\).

2. Table of Basic Rules

  • Constant Rule: \(\int k dx = kx + C\)
  • Sum Rule: \(\int [f(x) + g(x)] dx = \int f(x)dx + \int g(x)dx\)
  • Exponential: \(\int e^x dx = e^x + C\)
  • Sine: \(\int \sin x dx = -\cos x + C\)

3. AI/ML Connection: Feature Transformation Integration

Normalizing "Cumulative" Features

In data preprocessing, we often have features that are "Rates" (e.g., number of clicks per hour). If we want to transform this feature into a "Total" (e.g., total clicks since start), we are essentially integrating the rate.

Simple integration rules allow our pre-processing pipelines (like those in Spark or Pandas) to convert rate-based data into magnitude-based data, which is often more stable for linear models and standard regression algorithms.

4. Python: Bulk Integration Verification

import sympy as sp

x = sp.Symbol('x')
expressions = [x**4, 1/x, sp.exp(x), sp.cos(x)]

for expr in expressions:
    print(f"Integral of {expr}: {sp.integrate(expr, x)}")

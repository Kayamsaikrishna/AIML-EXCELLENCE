Making it Square

\( A = QR \). Turning a messy basis into a clean, orthonormal one. The "Marie Kondo" of Algebra.

1. The Algorithm

Given any basis \( \{ \mathbf{v}_1, \dots, \mathbf{v}_n \} \), Gram-Schmidt produces an orthogonal basis \( \{ \mathbf{u}_1, \dots, \mathbf{u}_n \} \) by iteratively subtracting the projection on previous vectors.

$$ \mathbf{u}_k = \mathbf{v}_k - \sum_{j=1}^{k-1} \text{proj}_{\mathbf{u}_j}(\mathbf{v}_k) $$

Normalizing them gives an Orthonormal basis \( \{ \mathbf{q}_1, \dots, \mathbf{q}_n \} \).

2. QR Factorization

This process gives us the famous QR Decomposition: \( A = QR \).

  • \( Q \): Orthogonal Matrix (The clean basis).
  • \( R \): Upper Triangular Matrix (The "mess" we removed).

Use Case: Solving Linear Least Squares problems (Regression) with extreme numerical stability compared to the Normal Equations.

3. QR in Action

Solving Ax=b using QR.

import numpy as np

# A Matrix (Messy)
A = np.array([
    [1, 1],
    [1, 2]
])

# Compute QR
Q, R = np.linalg.qr(A)

print("Q (Orthonormal):")
print(Q)
print(f"Check Q.T @ Q (Identity):\n{np.dot(Q.T, Q).round(2)}")

print("\nR (Upper Triangular):")
print(R)

# Solve Ax = b -> QRx = b -> Rx = Q.T b
b = np.array([3, 5])
y = np.dot(Q.T, b)
x = np.linalg.solve(R, y) # Easy back-substitution

print(f"\nSolution x: {x}")
# Expected: [1, 2] since 1*1+1*2=3, 1*1+2*2=5

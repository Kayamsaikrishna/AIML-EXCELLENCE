23. Gram-Schmidt Process

Turning chaotic vectors into a perfect basis.

1. The Algorithm

The Gram-Schmidt process takes a set of linearly independent vectors and produces an Orthonormal Basis by iteratively subtracting projections.

$$ \mathbf{u}_1 = \mathbf{v}_1 $$ $$ \mathbf{u}_2 = \mathbf{v}_2 - \text{proj}_{u_1} \mathbf{v}_2 $$ $$ \mathbf{u}_3 = \mathbf{v}_3 - \text{proj}_{u_1} \mathbf{v}_3 - \text{proj}_{u_2} \mathbf{v}_3 $$

Then, normalize each \(\mathbf{u}_i\) to get the final basis vectors \(\mathbf{e}_i\).

2. QR Decomposition & Numerical Stability

Solving Linear Systems

Gram-Schmidt is the engine behind QR Decomposition (\( A = QR \)), where \(Q\) is orthogonal. This is much more numerically stable for solving linear systems than calculating an explicit matrix inverse.

  • Stability: Modern AI frameworks use "Modified Gram-Schmidt" to prevent rounding errors from destroying orthogonality in high dimensions.
  • Orthogonal Layers: Some specialized neural network architectures force hidden layers to be orthonormal via Gram-Schmidt to maintain signal flow.

3. Python: Step-by-Step Gram-Schmidt

import numpy as np

def gram_schmidt(V):
    U = np.zeros(V.shape)
    for i in range(V.shape[1]):
        U[:, i] = V[:, i]
        for j in range(i):
            proj = (np.dot(V[:, i], U[:, j]) / np.dot(U[:, j], U[:, j])) * U[:, j]
            U[:, i] -= proj
    # Normalize
    for i in range(U.shape[1]):
        U[:, i] /= np.linalg.norm(U[:, i])
    return U

V = np.array([[1, 1], [0, 1]], dtype=float).T
Q = gram_schmidt(V)

print(f"Orthonormal Basis Q:\n{Q}")

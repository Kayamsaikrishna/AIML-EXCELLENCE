Calculus 1.3 Zero Slope

Rolle's Theorem

If what goes up must come down, there must be a moment where it freezes in mid-air.

The "Turnaround" point

Rolle's Theorem is common sense wrapped in rigor. If you throw a ball and catch it at the same height, at some point its vertical velocity was exactly zero.

1. The Theorem

If \(f\) is continuous on \([a,b]\), differentiable on \((a,b)\), and \(f(a) = f(b)\), then there exists at least one \(c\) where:

\[ f'(c) = 0 \]

This \(c\) is a Critical Point (candidate for local max/min).

2. AI/ML Connection: Loss Landscape Symmetry

Finding Valleys between Mountains

In deep learning, our loss landscapes are often non-convex and have symmetries. Imagine we have two different sets of weights \(W_1\) and \(W_2\) that yield the exact same loss value (e.g., due to permuting neurons).

Rolle's Theorem (or its multidimensional version) implies that on any smooth path connecting \(W_1\) and \(W_2\), there must be a point where the gradient is zero.

This usually implies the existence of a Saddle Point between two minima. AI researchers use this to study "Mode Connectivity"—how we can travel from one good solution to another without the loss spiking up too high.

3. Python: Rolle's Check

rolles_check.py
import numpy as np

# Function: f(x) = x^2 - 4x + 3
# Roots at x=1 and x=3 -> f(1)=0, f(3)=0
def f(x):
    return x**2 - 4*x + 3

def df(x):
    return 2*x - 4

a, b = 1, 3
print(f"f({a}) = {f(a)}")
print(f"f({b}) = {f(b)}")
print("Rolle's Condition Met: f(a) == f(b)")

# Solve 2x - 4 = 0 -> x = 2
c = 2
print(f"\nTurning Point c: {c}")
print(f"Is c in ({a}, {b})? {a < c < b}")
print(f"Derivative at c: {df(c)}")

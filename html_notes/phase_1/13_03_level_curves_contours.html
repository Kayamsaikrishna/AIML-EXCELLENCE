03. Level Curves and Contour Plots

Flattening the 3D world into 2D maps.

1. What are Level Curves?

A Level Curve of a function \(f(x, y)\) is the set of all points \((x, y)\) where the function has a constant value \(k\).

$$ L_k = \{ (x, y) \mid f(x, y) = k \} $$

If you think of \(f(x, y)\) as mountain elevation, a level curve is a "constant altitude" path. A collection of level curves for several values of \(k\) is called a Contour Plot.

2. Interpretation: Slopes and Valleys

When level curves are close together, it means the function's value is changing rapidly (steep slope). When they are far apart, the surface is relatively flat. This visual intuition is vital for understanding optimization.

3. AI/ML Connection: Loss Landscapes

Visualizing Why Training Fails

An AI model's "Loss Function" is often a function of thousands of variables. While we can't see the full 1000D surface, we can use Dimensionality Reduction and Contour Plots to visualize a 2D slice of the loss landscape.

If the level curves are highly Elliptical (stretched out), it means the model is "harder to train" because the gradients in one direction are much stronger than the other. This visual feedback tells AI researchers that they need Batch Normalization or a different Optimizer (like Adam) to "round out" the contours and make the path to the minimum smoother and faster.

4. Python: Creating Contour Plots

import numpy as np
import matplotlib.pyplot as plt

# A simple "Bowl" function: f(x, y) = x^2 + 2y^2
x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)
Z = X**2 + 2*Y**2

plt.figure(figsize=(8, 6))
cp = plt.contour(X, Y, Z, levels=15, colors='blue')
plt.clabel(cp, inline=True, fontsize=10)
plt.title('Loss Contours (Bowl Shape)')
plt.xlabel('x (Weight 1)')
plt.ylabel('y (Weight 2)')
plt.show()

Stats 1.5 Practical Impact

Effect Size (Cohen's d)

Measuring the "bigness" of a discovery. Significance tells you if it's real; effect size tells you if it's worth it.

The P-value Trap

With enough data (e.g., \(n = 1,000,000\)), almost any tiny difference becomes "Statistically Significant" (\(P < 0.05\)). But is a 0.0001% increase in revenue worth a 50% increase in GPU cost?

Effect Size helps you answer that.

1. Cohen's d Formula

$$ d = \frac{\bar{x}_1 - \bar{x}_2}{s_p} $$

It measures how many Standard Deviations the two groups are apart.

graph LR A["d = 0.2"] --> B["Small Effect (Hard to see)"] C["d = 0.5"] --> D["Medium Effect"] E["d = 0.8"] --> F["Large Effect (Obvious)"]

2. Significance vs. Effect Size

Scenario Statistical Significance (P) Effect Size (d) Interpretation
Large \(n\), Tiny diff YES NO "Technically real, but useless."
Small \(n\), Large diff NO YES "Promising, but need more data."
Large \(n\), Large diff YES YES "The Holy Grail of discovery."

3. ML Connection: Feature Importance

Supervised Product

Practical Significance in A/B Tests

A company tests a new recommender system. - P-value: 0.004 (Extremely Significant). - Effect Size (Cohen's d): 0.02 (Extremely Tiny).

The product manager decides NOT to deploy. Why? Because the difference, while "real," is so small that the extra maintenance cost of the new model outweighs the tiny lift in performance.

In your ML reports, always include Cohen's d or R-squared alongside P-values to avoid building models that solve "statistically real" but "practically invisible" problems.

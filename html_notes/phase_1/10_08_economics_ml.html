Calculus 1.3 Economics

Marginal Analysis & Cost Functions

"Marginal" is just economist-speak for "Derivative".

The Cost of One More

In economics, we care about the cost to produce the next unit. In ML, we care about the error contributed by the next sample. The math is identical.

1. Definitions

  • Cost Function \(C(x)\): Total cost to produce \(x\) units.
  • Marginal Cost \(C'(x) \approx C(x+1) - C(x)\): Cost of the next unit.
  • Revenue \(R(x)\): Income from \(x\) units.
  • Marginal Revenue \(MR = R'(x)\): Income from next unit.
  • Profit Max Rule: Profit is maxed when \(MR = MC\) (Marginal Revenue = Marginal Cost).

2. AI/ML Connection: Gradient Boosting

Fitting the Residuals

In Gradient Boosting Machines (XGBoost, LightGBM), we train models sequentially.

The first tree makes predictions. The second tree doesn't predict the target; it predicts the Gradient of the Loss Function (the "Marginal Error") left over by the first tree.

Consider the Loss \(L(y, \hat{y})\). The "Marginal Cost" of adding a new tree \(f_2\) is how much it reduces \(L\). We explicitly train \(f_2\) to follow the negative gradient \( - \frac{\partial L}{\partial \hat{y}} \). This is Marginal Analysis applied to function approximation!

3. Python: Profit Maximization

profit_max.py
import sympy as sp

x = sp.Symbol('x') # Units produced

# Cost: Fixed $1000 + $10 per unit + complexity cost x^2/100
C = 1000 + 10*x + 0.01*x**2

# Price: Demand curve p(x) = 50 - 0.1x (Price drops as supply increases)
p = 50 - 0.1*x
# Revenue = Price * Quantity
R = p * x

# Profit = R - C
P = R - C

# Marginal Analysis
MC = sp.diff(C, x)
MR = sp.diff(R, x)

print(f"Marginal Cost: {MC}")
print(f"Marginal Revenue: {MR}")

# Solve MR = MC
optimal_x = sp.solve(MR - MC, x)[0]
max_profit = P.subs(x, optimal_x)

print(f"Optimal Production: {optimal_x:.2f} units")
print(f"Max Profit: ${max_profit:.2f}")

# Verify 2nd Derivative for max
P_double_prime = sp.diff(P, x, 2)
print(f"Concavity: {P_double_prime} (<0 means Max)")

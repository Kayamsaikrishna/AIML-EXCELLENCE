Calculus 1.3 Singularities

Infinite Limits

When functions explode: Understanding behavior near vertical asymptotes and avoiding numerical instability in AI.

The "NaN" Nightmare

In your Python console, seeing NaN (Not a Number) or inf usually means you hit an infinite limit. This happens when your model is too confident (probability ≈ 0 or 1) inside a logarithm, or when you divide by variance ≈ 0.

1. Vertical Asymptotes

\[ \lim_{x \to a} f(x) = \infty \quad \text{or} \quad \lim_{x \to a} f(x) = -\infty \]

This defines a Vertical Asymptote at \(x=a\). The function value grows without bound as inputs get closer to \(a\).

2. AI/ML Application: Cross-Entropy Loss

Why we use `epsilon`

The most common loss function for classification is Binary Cross-Entropy:

\[ \mathcal{L} = -y \log(\hat{y}) - (1-y) \log(1-\hat{y}) \]

Consider a case where the true label \(y=1\), but your model predicts \(\hat{y} = 0\) (completely wrong). The term becomes \(-\log(0)\).

\[ \lim_{x \to 0^+} \ln(x) = -\infty \]

So your loss becomes \(+\infty\). The gradient (derivative) will also be infinite. The weights update by an infinite amount, destroying the model ("Exploding Gradient").

The Implementation Fix

We strictly avoid 0 inputs to logs. We use a "numerical stabilizer" \(\epsilon\):

loss = -log(y_pred + 1e-7)

This clips the infinite limit to a finite (though large) number.

3. Python: Handling Singularities

stable_log.py
import numpy as np

def unsafe_log_loss(y_true, y_pred):
    # This will crash or return inf if y_pred is 0
    return -y_true * np.log(y_pred)

def safe_log_loss(y_true, y_pred, epsilon=1e-15):
    # Clip predictions to range [epsilon, 1-epsilon]
    y_pred_clipped = np.clip(y_pred, epsilon, 1 - epsilon)
    return -y_true * np.log(y_pred_clipped)

y_true = 1
bad_prediction = 0.0

print(f"{'Method':<20} | {'Input':<10} | {'Result':<15}")
print("-" * 50)

# Unsafe
with np.errstate(divide='ignore'): # Suppress warning for demo
    loss = unsafe_log_loss(y_true, bad_prediction)
    print(f"{'Unsafe Log':<20} | {bad_prediction:<10} | {loss}")

# Safe
loss_safe = safe_log_loss(y_true, bad_prediction)
print(f"{'Safe Log (Clipped)':<20} | {bad_prediction:<10} | {loss_safe:.4f}")

# Notice: 'inf' became ~34.5 (finite!)

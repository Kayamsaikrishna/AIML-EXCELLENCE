02. Events and Event Spaces

Slicing the sample space into meaningful groups.

1. What is an Event?

An Event is any subset of the Sample Space \(S\). It is a collection of one or more outcomes that share a specific property.

  • Simple Event: An event containing only one outcome.
  • Compound Event: An event combining multiple outcomes (e.g., "rolling an even number").
  • Impossible Event (\(\emptyset\)): An event with zero outcomes.
  • Certain Event (\(S\)): The entire sample space.

2. The Operation of Events

Because events are sets, we use set theory to manipulate them:

  • Union (\(A \cup B\)): Event A OR Event B occurs.
  • Intersection (\(A \cap B\)): Event A AND Event B occur.
  • Complement (\(A^c\)): Event A does NOT occur.

3. AI/ML Connection: Classification Labels

Slicing the Data

In Classification, our goal is to determine which "Event" a specific data point belongs to.

If our sample space is "Images of Animals", the event \(A\) could be "Images containing a Cat". When an AI model predicts a class, it is essentially estimating the probability that the sample belongs to that specific subset of the feature space. Understanding Intersections is critical for Multi-Label Classification (e.g., an image being both a "Beach" and a "Sunny Day"). Every label in your dataset is mathematically defined as an event in a high-dimensional probability space.

4. Python: Event Filtering

# Sample Space: Rolling a 10-sided die
S = set(range(1, 11))

# Event A: Outcome is even
event_A = {x for x in S if x % 2 == 0}

# Event B: Outcome is greater than 7
event_B = {x for x in S if x > 7}

print(f"Event A (Even): {event_A}")
print(f"Event B (>7): {event_B}")

# Set operations
print(f"A AND B: {event_A.intersection(event_B)}")
print(f"A OR B: {event_A.union(event_B)}")

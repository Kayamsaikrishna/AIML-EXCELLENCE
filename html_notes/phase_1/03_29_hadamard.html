29. Hadamard Product (Element-wise)

Scaling features without spatial interaction.

1. The Definition

The Hadamard Product \( \mathbf{A} \odot \mathbf{B} \) is simply the element-wise multiplication of two matrices of the same dimension.

$$ (\mathbf{A} \odot \mathbf{B})_{ij} = a_{ij}b_{ij} $$

Unlike standard matrix multiplication, the Hadamard product is Commutative: \( \mathbf{A} \odot \mathbf{B} = \mathbf{B} \odot \mathbf{A} \).

2. Critical Uses in Deep Learning

Activation Gating & Attention Scaling

  • LSTMs/GRUs: The "Gating" mechanism (Forget Gate, Input Gate) uses Hadamard products to decide which information to pass through or block.
  • Dropout: We multiply the layer outputs by a binary mask matrix (Hadamard product) to randomly deactivate neurons.
  • Attention Mechanism: When we apply a mask to prevent a model from "looking into the future" in a Transformer, we use a Hadamard product with a masking matrix.

3. Python: Element-wise vs Matrix Mult

import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

# Hadamard Product (The * operator in Numpy)
hadamard = A * B

# Standard Matrix Product (The @ operator)
standard = A @ B

print(f"Hadamard:\n{hadamard}")
print(f"Standard:\n{standard}")

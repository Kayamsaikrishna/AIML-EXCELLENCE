Hadamard Product

\( A \odot B \). Point-to-point multiplication. The primary op in Neural Nets.

1. Definition

The Hadamard Product (also Schur product) is simply multiplying corresponding elements.

$$ (A \odot B)_{ij} = A_{ij} B_{ij} $$

The dimensions of A and B must match exactly (unless broadcasting implies expansion).

2. Gating Mechanisms

In LSTMs and GRUs, we have "Forget Gates" \( f_t = \sigma(W x_t) \).

The cell state update is \( C_t = f_t \odot C_{t-1} \). This element-wise multiplication allows the network to selectively "zero out" (forget) specific dimensions of the state vector while keeping others.

3. Python Operator

Using `*` vs `@`.

import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [2, 0],
    [0, 2]
])

Hadamard = A * B
# [1*2, 2*0]
# [3*0, 4*2]
# = [2, 0], [0, 8]

MatMul = A @ B
# [1*2+2*0, ...]
# = [2, 4], [6, 8] (Doubles every value)

print("Hadamard (A * B):")
print(Hadamard)

print("\nMatMul (A @ B):")
print(MatMul)

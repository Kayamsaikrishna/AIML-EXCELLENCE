22. Linear Approximation & Differentials

Making complex functions simple (local flat Earth theory).

1. The Linearization

If a function \(f\) is differentiable at \(a\), the equation of its tangent line is the best linear estimate of the function near \(a\). We call this the linearization \(L(x)\):

$$ L(x) = f(a) + f'(a)(x - a) $$

For values of \(x\) very close to \(a\), \(f(x) \approx L(x)\).

2. Differentials

Differentials \(dx\) and \(dy\) allow us to estimate the "error" or "change" in current output based on a small change in input:

$$ dy = f'(x) dx $$

This is the fundamental idea behind approximation: "How much will \(y\) wiggle if \(x\) wiggles by \(0.001\)?"

3. AI/ML Connection: The Learning Rate Intuition

The "Small Step" Assumption

In Gradient Descent, we update our weights using \(\Delta w = -\eta \nabla J\). This update rule is entirely based on Linear Approximation. We assume that if we take a "small enough" step (\(\eta\)), the loss function \(J\) behaves like a flat line with slope \(\nabla J\).

If we take a step that is too large, the linear approximation breaks down (because the real function is curvy), and our model "explodes" or diverges. Choosing the right Learning Rate is essentially choosing a range where the Linear Approximation is still valid.

4. Python: Approximating a Square Root

# Approx sqrt(4.1) using linearization at a=4
# f(x) = sqrt(x), f'(x) = 1/(2*sqrt(x))
# f(4) = 2, f'(4) = 1/4 = 0.25

a = 4
x = 4.1
approx = 2 + 0.25 * (x - a)

print(f"Linearized Approximation: {approx}")
print(f"Actual Value: {4.1**0.5:.6f}") # Very close!

12. Derivatives of Exponential Functions

Functions that grow in proportion to themselves.

1. The Natural Exponential Rule

The function \(e^x\) is unique in all of mathematics. Its derivative is exactly equal to itself. Every point on the graph has a slope equal to its height.

$$ \frac{d}{dx}[e^x] = e^x $$

With the Chain Rule, this becomes even more powerful:

$$ \frac{d}{dx}[e^{u(x)}] = e^{u(x)} \cdot u'(x) $$

2. General Exponential Rule

For any positive base \(a\):

$$ \frac{d}{dx}[a^x] = a^x \ln a $$

3. AI/ML Connection: The Sigmoid Gradient

Backprop through Sigmoid

The Sigmoid Activation Function is defined as: \(\sigma(x) = \frac{1}{1 + e^{-x}}\).

Because of the beautiful derivative property of \(e^x\), the derivative of the Sigmoid function can be calculated using only the output of the function itself:

$$ \sigma'(x) = \sigma(x)(1 - \sigma(x)) $$

This "computational shortcut" makes neural networks significantly faster to train, as we don't need to re-compute expensive exponentials during the backpropagation phase—we just reuse the value we already calculated during the forward pass.

4. Python: Verifying the shortcut

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_grad(x):
    s = sigmoid(x)
    return s * (1 - s)

x_val = 0.5
print(f"Sigmoid at {x_val}: {sigmoid(x_val):.4f}")
print(f"Gradient at {x_val}: {sigmoid_grad(x_val):.4f}")

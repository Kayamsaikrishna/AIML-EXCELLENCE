1. Derivatives with Matrices

To minimize \( J(w) = ||y - Xw||^2 \), we take the derivative with respect to vector \( w \):

$$ \nabla_w J = -2 X^T (y - Xw) $$

Setting this to zero gives the Normal Equation \( X^T X w = X^T y \). Learning to differentiate matrix expressions is crucial for deriving backpropagation.

2. Stochastic Gradient Descent (SGD)

Inverting matrices is \( O(n^3) \). When \( n \) is large (Big Data), the analytical solution is too slow.

Instead, we use iterative methods: update \( w \) using the gradient computed on a small batch of data. This avoids big matrix inversions and allows us to train on datasets larger than RAM.

3. Gradient Descent from Scratch

import numpy as np

# Synthetic Data
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X + np.random.randn(100, 1)

# Add bias term (column of 1s)
X_b = np.c_[np.ones((100, 1)), X]

# Init weights
w = np.random.randn(2, 1)
learning_rate = 0.1
n_iterations = 50

# Gradient Descent Loop
for iteration in range(n_iterations):
    # Compute Gradient
    gradients = 2/100 * X_b.T @ (X_b @ w - y)
    
    # Update
    w = w - learning_rate * gradients

print("Learned Intercept & Slope:", w.flatten())
print("Expected approx: [4.0, 3.0]")

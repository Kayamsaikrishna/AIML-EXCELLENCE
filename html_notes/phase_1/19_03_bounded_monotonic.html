03. Bounded & Monotonic Sequences

Ensuring stability: The Monotone Convergence Theorem.

1. Definitions

  • Monotonic: A sequence that either only increases (\(a_n \leq a_{n+1}\)) or only decreases (\(a_n \geq a_{n+1}\)).
  • Bounded: There exists a number \(M\) such that \(|a_n| \leq M\) for all \(n\).

2. The Monotone Convergence Theorem

Every bounded and monotonic sequence is convergent. This is a fundamental guarantee in mathematical analysis: if a sequence is restricted (bounded) and headed in one direction (monotonic), it must hit a limit.

3. AI/ML Connection: The Loss Floor

Gradient Descent Stability

When training an AI, the "Loss" is ideally a Monotonic Decreasing sequence. Since the loss of a model can never be less than zero (it is Bounded Below), the Monotone Convergence Theorem guarantees that the training must eventually settle on a minimum value.

If your training loss is not monotonic (it keeps jumping up and down), it indicates that your Learning Rate is too high, causing the sequence to oscillate instead of converging. Stability in AI is about forcing the math to behave like a bounded monotonic sequence.

4. Python: Checking Monotonicity

# Sequence: a_n = n / (n + 1)
def a_n(n):
    return n / (n + 1)

values = [a_n(i) for i in range(1, 11)]

# Check if increasing
is_increasing = all(x < y for x, y in zip(values, values[1:]))
# Check if bounded by 1.0
is_bounded = all(x <= 1.0 for x in values)

print(f"Values: {[round(v, 3) for v in values]}")
print(f"Is Monotonic Increasing? {is_increasing}")
print(f"Is Bounded Above by 1.0? {is_bounded}")
print("Therefore, by MCT, it MUST converge (Limit is 1).")

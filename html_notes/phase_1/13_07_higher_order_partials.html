04. Higher-Order Partial Derivatives

Exploring curvature in multiple directions.

1. Iterative Differentiation

Just as in single-variable calculus, we can take the derivative of a derivative. In two variables, there are four possible second-order partial derivatives:

  • \(f_{xx} = \frac{\partial^2 f}{\partial x^2}\)
  • \(f_{yy} = \frac{\partial^2 f}{\partial y^2}\)
  • \(f_{xy} = \frac{\partial^2 f}{\partial y \partial x}\) (Mixed Partial)
  • \(f_{yx} = \frac{\partial^2 f}{\partial x \partial y}\) (Mixed Partial)

2. Clairaut's Theorem

This theorem states that for most well-behaved (smooth) functions, the order of differentiation does not matter for mixed partials:

$$ f_{xy} = f_{yx} $$

This symmetry is a foundational property used to speed up calculations in numerical software.

3. AI/ML Connection: The Hessian Matrix

The Shape of the Loss Landscape

In AI, the second-order partial derivatives are organized into a square matrix called the Hessian Matrix (\(H\)). While the 1st derivative (gradient) tells you the direction of the hill, the Hessian tells you about its Curvature.

If \(f_{xx}\) is positive, the loss function is "curving up" in the \(x\) direction. If the mixed partial \(f_{xy}\) is large, it means the features \(x\) and \(y\) are highly inter-dependent. Using the Hessian allows for "Second-Order" optimizers that can identify sharp cliffs and safely navigate around them, or identify saddle points which 1st-order methods would fail to escape.

4. Python: Calculating the Hessian

import sympy as sp

w1, w2 = sp.symbols('w1 w2')
loss = w1**2 + 5*w1*w2 + w2**2

# Calculate all 2nd order partials
hessian = sp.hessian(loss, (w1, w2))

print(f"Hessian Matrix:\n{hessian}")
# Output: Matrix([[2, 5], [5, 2]])

04. Independence of Random Variables

When one variable tells you nothing about another.

1. Definition

Two random variables $X$ and $Y$ are Independent if knowing the value of one provides no information about the value of the other. Mathematically, the joint PDF (or PMF) is simply the product of their marginals:

$$ f(x,y) = f_X(x) f_Y(y) \quad \text{for all } x, y $$

Similarly, for independence, the conditional distribution equals the marginal: $f(x \mid y) = f_X(x)$.

2. Extension to $n$ Variables

A set of random variables $X_1, X_2, \dots, X_n$ is **mutually independent** if their joint distribution factors into the product of all their individual marginals. This is accurately known as the **Factorization Property**.

3. AI/ML Connection: Naive Bayes and Feature Decoupling

The "Naive" Simplification

Independence is the most common (and most violated) Simplifying Assumption in AI.

In **Naive Bayes**, we assume that all features (words in an email) are independent given the class (Spam or Not Spam). While technically "Naive" (because words like "Bank" and "Account" are highly correlated), this assumption allows the AI to calculate the joint probability by simply multiplying individual probabilities, making it incredibly fast and efficient even for millions of features. In **PCA (Principal Component Analysis)** and **ICA (Independent Component Analysis)**, the goal is to transform "tangled" correlated data into a new set of independent variables, making the underlying structure of the data easier for an AI to learn.

4. Python: Checking for Independence

# If independent: Joint Prob = P(X) * P(Y)
p_x = np.array([0.5, 0.5])
p_y = np.array([0.2, 0.8])

# Predicted Joint PMF under independence
independence_joint = np.outer(p_x, p_y)

print(f"Independent Joint Table:\n{independence_joint}")
# [[0.1, 0.4],
#  [0.1, 0.4]]

# If our actual joint data is different, variables are correlated!

Calculus 1.3 The Goal

Applied Optimization

Maximize gain, minimize cost. The universal algorithm of existence.

Constraint Satisfaction

In the real world, you never just "Maximize Profit". You "Maximize Profit *subject to* Budget, Time, and Physics".

1. The Workflow

  1. Objective Function ($J$): What do you want to optimize? (e.g., Area, Cost).
  2. Constraints ($g$): What limits you? (e.g., Perimeter=100).
  3. Reduction: Use Constraint to eliminate variables in Objective.
  4. Differentiate: Find critical points of the new single-variable function.
  5. Verify: Check endpoints and 2nd derivative.

2. AI/ML Connection: Constrained Optimization

Regularization is a Constraint

Why do we add "L2 Regularization" (Weight Decay) to our loss function? \[ Loss = MSE + \lambda ||W||^2 \]

This is actually a Lagrange Multiplier formulation of a constrained optimization problem: "Minimize Error subject to the Weights remaining small (within a sphere of radius \(C\))."

By optimizing this combined function, we find a "sweet spot" model that fits the data well but isn't too complex (preventing overfitting).

3. Python: Parameter Optimization

optimize_box.py
import sympy as sp

# Problem: Minimize Surface Area of an OPEN box with Volume = 500 cm^3
# Dimensions: x (square base), h (height)
# Volume V = x^2 * h = 500 -> h = 500/x^2
# Surface Area S = x^2 (base) + 4xh (sides)

x = sp.Symbol('x')
S = x**2 + 4 * x * (500 / x**2)
# Simplify: S = x^2 + 2000/x

# 1. Differentiate
dS = sp.diff(S, x)
print(f"Objective Function S(x): {S}")
print(f"Derivative dS/dx: {dS}")

# 2. Solve dS/dx = 0
crit_pt = sp.solve(dS, x)[0] # Taking the real solution
# x^3 = 1000 -> x=10

print(f"Optimal Base Width x: {crit_pt}")
print(f"Optimal Height h: {500 / crit_pt**2}")
print(f"Min Surface Area: {S.subs(x, crit_pt)}")

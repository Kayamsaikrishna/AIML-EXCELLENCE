ML Calc 1.9 Approximation

Taylor Optimization in ML

Approximating the loss landscape.

Local Approximations

We can approximate the loss function \(L(\mathbf{w})\) around a point \(\mathbf{w}_0\) using Taylor Series:

$$ L(\mathbf{w}) \approx L(\mathbf{w}_0) + (\mathbf{w}-\mathbf{w}_0)^T \mathbf{g} + \frac{1}{2}(\mathbf{w}-\mathbf{w}_0)^T \mathbf{H} (\mathbf{w}-\mathbf{w}_0) $$

Gradient Descent only uses the first term (Linear Approximation). Newton's Method uses the second term (Quadratic Approximation) to find the bottom of the "parabola".

2. ML Connection: K-FAC

Natural Gradients

Standard Gradient Descent assumes the geometry of parameter space is Euclidean (Isotropic). It isn't. Changing one weight might drastically change the output probability distribution, while changing another does nothing.

Natural Gradient Descent uses the Fisher Information Matrix (related to the Hessian) to correct for this curvature. Methods like K-FAC (Kronecker-Factored Approximate Curvature) approximate this term to speed up training of very deep networks.

3. Python: 2nd Order approx

taylor_approx.py
import numpy as np

# Approx f(x) = e^x near x=0
# Taylor: 1 + x + x^2/2

def taylor_exp(x):
    return 1 + x + (x**2)/2

print(f"e^0.1 real: {np.exp(0.1):.6f}")
print(f"e^0.1 approx: {taylor_exp(0.1):.6f}")
# Matches closely! 

# In ML, this tells us how far we can trust the gradient step.
# If the "Trust Region" is small, we must take small steps.

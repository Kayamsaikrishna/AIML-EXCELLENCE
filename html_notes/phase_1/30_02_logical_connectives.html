Operations Syntax

Logical Connectives

The Joints of Reason. Combining atomic propositions into compound statements using operators that mimic human language and digital circuits.

The Connective Principle

In arithmetic, we use \(+, -, \times\) to build complex numbers. In logic, we use Connectives to build complex truth values. These are the "chemical bonds" that hold molecules of thought together.

1. The Primary Operators

Negation (\(\neg\))

NOT: Flips the truth value. If \(p\) is true, \(\neg p\) is false.

\(\neg p\)

Conjunction (\(\land\))

AND: True only if both propositions are true. Like a series circuit.

\(p \land q\)

Disjunction (\(\lor\))

OR: True if at least one is true (inclusive). Like a parallel circuit.

\(p \lor q\)

Exclusive OR (\(\oplus\))

XOR: True if exactly one is true. Used in hardware and parity checks.

\(p \oplus q\)

2. The Conditional Operators

Implication (\(\rightarrow\))

If \(p\), then \(q\): Only false if the hypothesis (\(p\)) is true and the conclusion (\(q\)) is false.

\(p \rightarrow q\)

Note: If \(p\) is false, the whole statement is true (vacuously true).

Biconditional (\(\leftrightarrow\))

If and only if: True only if both have the same truth value (both true or both false).

\(p \leftrightarrow q\)
Neural Nets Programming

Logic in Implementation

  • Revitilizing Perceptrons: An early single-layer perceptron could easily represent AND, OR, and NOT gates. However, the XOR gate became the "crisis" of early AI because a single linear neuron could not separate it (it required a multi-layer network).
  • Short-circuit Evaluation: In languages like Python, `if p or q:` won't even evaluate `q` if `p` is already true. This is an optimization based on the definition of the Disjunction operator.
  • Masking: In LLM transformers, we use "Causal Masking" (an AND operation between the attention scores and a triangular matrix) to ensure tokens don't "see" the future.

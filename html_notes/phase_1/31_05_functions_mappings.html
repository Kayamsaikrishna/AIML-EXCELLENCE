Functions & Mappings

Input to Output. Thinking of functions not just as formulas, but as specific, restricted relations between sets that preserve the integrity of a computation.

The Functional Constraint

A Function \(f: A \to B\) is a relation that assigns exactly one element of \(B\) to each element of \(A\). You can think of it as a machine where every button pulse (input) is guaranteed to produce one specific light (output).

1. Domain, Codomain, and Range

Domain (\(A\))

The set of all possible inputs. Every element here must have an assignment.

Codomain (\(B\))

The "target" set. The pool of potential outputs.

Range (Image)

The subset of the Codomain that is actually reached by the function. \(f(A) = \{f(x) \mid x \in A\}\).

2. Types of Mappings

Injective (One-to-One)

Different inputs always produce different outputs. No two elements in \(A\) map to the same element in \(B\).

\( f(x_1) = f(x_2) \rightarrow x_1 = x_2 \)

Surjective (Onto)

Every element in the Codomain is covered. The Range equals the Codomain.

\( \forall y \in B, \exists x \in A \text{ s.t. } f(x) = y \)

Bijective (One-to-One Correspondence)

Both Injective and Surjective. This creates a perfect pairing, which means the function is Invertible.

Neural Nets Loss Functions

Why Mappings matter in AI

  • Neural Networks as Universal Approximators: A neural network is just a giant compound function. We want it to be a mapping from a high-dimensional input set (Images) to a low-dimensional output set (Labels).
  • Feature Mapping: In Kernel methods (like SVMs), we map data into a higher-dimensional space (the "Feature Space") using a function \(\phi(x)\). If this mapping is injective, we preserve all information while making it easier to separate.
  • Dimensionality Reduction: Techniques like PCA or Autoencoders use "Surjective" (many-to-one) mappings to compress the data, discarding noise while keeping the essential structure.
  • Normalizing Flows: In Generative AI, we look for Bijective (invertible) mappings between a simple distribution (Gaussian noise) and a complex one (Images). This allows us to both generate images and calculate the exact probability of an image.

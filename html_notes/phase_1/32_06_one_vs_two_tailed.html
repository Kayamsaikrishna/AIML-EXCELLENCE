06. One-tailed vs Two-tailed Tests

Choosing the direction of suspicion.

1. The Difference in Focus

  • Two-tailed Test: We test if the parameter is **Different** (Higher OR Lower) than the null. $H_1: \mu \ne \mu_0$. The 5% alpha is split (2.5% each side). This is the default "Neutral" stance.
  • One-tailed Test: We test in a specific direction. $H_1: \mu > \mu_0$ (Right-tailed) or $H_1: \mu < \mu_0$ (Left-tailed). The entire 5% alpha is on one side, making it easier to find an effect in that direction, but impossible to detect an effect in the other.

2. When to use One-tailed?

ONLY when an effect in the opposite direction is physically impossible or completely irrelevant to your decision. If you think the new drug is better, but you *also* need to know if it's worse (toxic), you **MUST** use a two-tailed test.

3. AI/ML Connection: A/B Testing and Safe Rollouts

The Ethics of Bias

In AI, the tails of the test determine your **Standard of Proof**.

In A/B Testing** of a new UI, we usually use **Two-tailed tests. We want to know if the new design improves conversion, but we critically need to know if it *hurts* conversion. However, in Safety Testing**, we might use a **One-tailed test. If our goal is to prove that a new model's latency is "Less than 20ms," we don't care if it's 1ms or 10ms—we only care if it's *higher* than the limit. Using a one-tailed test gives the model more "statistical slack," but it requires absolute certainty that the "Good" direction is the only one that matters. Choosing the wrong tail can lead to p-hacking**, where a researcher picks the one-tailed test just to get a significant result—a practice that lead to model failure in production.

4. Python: Comparison of p-values

# Let's say Z-obs = 1.7
z = 1.7

# Two-tailed p-value
p_two = 2 * (1 - stats.norm.cdf(abs(z))) # ~0.089

# One-tailed (Right) p-value
p_one = 1 - stats.norm.cdf(z) # ~0.045

# Surprise! With the SAME data, the one-tailed test is "Significant" 
# while the two-tailed is not. 
# This illustrates why tail selection must happen BEFORE seeing the data.

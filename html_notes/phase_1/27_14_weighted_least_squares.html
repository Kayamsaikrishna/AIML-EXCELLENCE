Stats 1.7 Heteroscedasticity

Weighted Least Squares (WLS)

Not all data points are created equal. WLS lets you prioritize the points you trust more.

The Precision Priority

In standard OLS, we assume every data point has the same amount of noise (Homoscedasticity).

But what if some measurements come from a high-precision sensor and others from an old, shaky one? WLS gives higher weights (\(w_i\)) to the precise data and lower weights to the noisy data.

1. The Objective Function

$$ RSS_{weighted} = \sum_{i=1}^n w_i (y_i - \hat{y}_i)^2 $$

Where: - \(w_i = \frac{1}{\sigma_i^2}\) (Inverse of the variance). - High variance points have small weights and don't influence the line much.

2. Why use WLS?

Solving Heteroscedasticity

If your error variance grows with the input (The "Fan" shape), WLS down-weights the points in the "fat" part of the fan where the model is uncertain.

Averaged Data

If some data points are averages of 1,000 observations and others are just 1 observation, you should weight them by the sample size.

3. ML Connection: Class Weights

Loss Functions Imbalanced Data

Weighting in modern AI

The spirit of WLS lives on in almost every ML framework (PyTorch, TensorFlow, Scikit-learn):

  • Imbalanced Classification: If you have 99% "Normal" transactions and 1% "Fraud", you can set `class_weight='balanced'`. This is mathematically equivalent to WLS—it tells the model to penalize errors on Fraud cases much more heavily.
  • Sample Weights: In many competitions (Kaggle), some test samples are more important than others. You pass a `sample_weight` vector to the `fit()` function of an XGBoost or CatBoost model.
  • Locally Weighted Regression (LOWESS): Used in data visualization to create smooth curves. It weights points near the "current X" more heavily than distant points.
Pro-Tip: WLS is the bridge to Iteratively Reweighted Least Squares (IRLS), which is the actual algorithm used to solve Logistic Regression and GLMs.

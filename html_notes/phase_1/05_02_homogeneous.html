1. Definition

A system is homogeneous if the right-hand side is the zero vector: \( A \mathbf{x} = \mathbf{0} \).

  • Trivial Solution: \( \mathbf{x} = \mathbf{0} \) always works. (Since \( A \cdot 0 = 0 \)).
  • Non-Trivial Solution: Exists ONLY if columns of \( A \) are linearly dependent (i.e., \( A \) is singular).

2. Finding Eigenvectors

To find eigenvectors for a known eigenvalue \( \lambda \), we solve the homogeneous system:

$$ (A - \lambda I)\mathbf{x} = \mathbf{0} $$

The solution space of this homogeneous system is the Eigenspace.

3. Null Space Basis

import numpy as np
from scipy.linalg import null_space

# Case 1: Invertible Matrix (Only Trivial Solution)
A_inv = np.array([[1, 2], [3, 4]])
ns_inv = null_space(A_inv)
print("Null Space of Invertible Matrix (Should be empty):")
print(ns_inv) 

# Case 2: Singular Matrix (Non-Trivial Solution Exists)
# Row 2 is 2x Row 1
A_sing = np.array([[1, 2], [2, 4]])
ns_sing = null_space(A_sing)

print("\nNull Space Basis of Singular Matrix:")
print(ns_sing)
# Returns a vector like [[-0.89], [0.44]].
# Any multiple of this vector maps to 0.

1. What is a Subspace?

A subspace is a smaller vector space inside a larger one. It must satisfy three rules:

  1. Contains Zero: It must pass through the origin. (A plane floating above the origin is NOT a subspace).
  2. Closed under Addition: If you add two vectors in the subspace, you stay in the subspace.
  3. Closed under Scaling: If you stretch a vector, it stays in the subspace (infinite extent).

2. The Data Manifold

We assume real-world data (images of faces) lies on a low-dimensional Subspace (or Manifold) inside the high-dimensional pixel space.

If we have 1000 pictures of faces, the Span of these vectors defines the "Face Space". Anything outside this span is noise or "not a face".

3. Checking the Span

Does a target vector lie within the span of our basis?

import numpy as np

# Basis Vectors (The Span)
v1 = np.array([1, 0, 0])
v2 = np.array([0, 1, 0]) # Standard XY Plane

# Quantifying the Matrix
A = np.column_stack((v1, v2))

# Target Vector (Is this in the span?)
b_in = np.array([2, 3, 0]) # Yes (z=0)
b_out = np.array([2, 3, 5]) # No (z=5)

# We solve Ax = b. If solution exists, b is in Span.
try:
    # Use Least Squares to check residual
    x, residuals, rank, s = np.linalg.lstsq(A, b_in, rcond=None)
    print(f"Residual for b_in: {residuals}") # Should be empty or near zero
    
    x, residuals, rank, s = np.linalg.lstsq(A, b_out, rcond=None)
    print(f"Residual for b_out: {residuals}") # Should be > 0 (Squared Error = 25)
except:
    print("Error in calculation")

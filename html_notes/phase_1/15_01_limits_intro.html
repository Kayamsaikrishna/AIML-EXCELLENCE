01. Intuition of Limits

The gateway to continuous mathematics.

1. What is a Limit?

A Limit describes the behavior of a function \(f(x)\) as \(x\) gets arbitrarily close to a specific value \(a\), without necessarily reaching it. We write this as:

$$ \lim_{x \to a} f(x) = L $$

This means: "As \(x\) approaches \(a\), the value of \(f(x)\) approaches \(L\)."

2. The Problem of "Zero"

Calculus exists because we often need to divide by something that is almost zero. Consider the slope of a line between two points \((x, f(x))\) and \((x+h, f(x+h))\):

$$ \text{Slope} = \frac{f(x+h) - f(x)}{h} $$

If \(h=0\), the math breaks. But if \(h \to 0\), the limit reveals the Instantaneous Slope (the Derivative).

3. AI/ML Connection: Numerical Stability

Vanishing and Exploding Gradients

In Deep Learning, we compute gradients (limits) over many layers. If the "limit" of the weight updates approaches 0, the network stops learning (Vanishing Gradient). If it approaches \(\infty\), the network breaks (Exploding Gradient). Understanding limits helps us design Activation Functions like ReLU, which avoid these "dead zones".

4. Python: Approximating a Limit

import numpy as np

# Function: f(x) = (sin x) / x
# Value at x=0 is undefined (0/0)
def f(x):
    return np.sin(x) / x

# Let's approach 0 from the right
steps = [0.1, 0.01, 0.001, 0.0001, 0.00001]
for h in steps:
    print(f"As x -> {h}, f(x) -> {f(h):.6f}")

# The limit is 1.0!

1. Principal Axes Theorem

Any quadratic form \( x^T A x \) containing "cross terms" (like \( x_1 x_2 \)) can be transformed into a pure sum of squares \( \lambda_1 y_1^2 + \lambda_2 y_2^2 + \dots \) by changing to the eigenvector basis.

This rotates the coordinate system to align with the axes of the ellipsoid.

2. Anomaly Detection

Euclidean distance assumes space is isotropic (circles). Real data is often stretched (ellipses) due to correlation.

The Mahalanobis Distance uses the inverse covariance matrix \( \Sigma^{-1} \) as the "metric" in the Quadratic Form:

$$ d(x, y) = \sqrt{(x-y)^T \Sigma^{-1} (x-y)} $$

This effectively "whitens" the distance measurement, allowing us to detect outliers properly in correlated data distributions.

3. Plotting the Contour

import numpy as np
import matplotlib.pyplot as plt

# Define Quadratic Form Matrix A (Symmetric)
# 5x^2 + 4xy + 5y^2
A = np.array([
    [5, 2],
    [2, 5]
])

# Grid
x = np.linspace(-3, 3, 100)
y = np.linspace(-3, 3, 100)
X, Y = np.meshgrid(x, y)

# Compute Q(x,y)
Z = A[0,0]*X**2 + (A[0,1]+A[1,0])*X*Y + A[1,1]*Y**2

# Plot
plt.contour(X, Y, Z, levels=[5, 10, 20])
plt.axis('equal')
plt.title("Level Sets of Quadratic Form (Ellipses)")
print("Eigenvalues:", np.linalg.eigvals(A))
# Eigenvalues [3, 7] determine the axes lengths

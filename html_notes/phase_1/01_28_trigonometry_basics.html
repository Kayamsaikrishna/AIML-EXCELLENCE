28. Trigonometry Basics

Circles, Triangles, and the shape of Repetition.

The Unit Circle

$$ \sin^2(\theta) + \cos^2(\theta) = 1 $$

SOH CAH TOA

  • Sine (Sin): Opposite / Hypotenuse (Vertical Component).
  • Cosine (Cos): Adjacent / Hypotenuse (Horizontal Component).
  • Tangent (Tan): Opposite / Adjacent (Slope).

2. Cycles and Embeddings

Trigonometry is essential for anything that repeats (Audio, Cycles, Time).

Positional Embeddings (again): We use Sin/Cos in Transformers to give the model a sense of "Position" because Sin/Cos are continuous, bounded, and deterministic.

3. Coding Cycles

// Python: Sine Wave
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 4 * np.pi, 200) # 2 Cycles
y = np.sin(x)

plt.plot(x, y)
plt.title("The Wave of Learning")
plt.axhline(0, color='black')
plt.grid(True)
plt.show()

09. Spearman's Rank Correlation

Capturing non-linear monotonic relationships.

1. Definition

Spearman's Rank Correlation ($r_s$ or $\rho$) is a non-parametric measure of rank correlation. It assesses how well the relationship between two variables can be described using a monotonic function.

To calculate it, you convert both $X$ and $Y$ values into **Ranks** (1st, 2nd, 3rd...) and then calculate the standard Pearson correlation on those ranks.

2. Monotonicity

A relationship is **Monotonic** if, as one variable increases, the other either only increases or only decreases (even if not at a constant rate). Spearman is perfect for curves like $y = x^3$ or $y = \log(x)$, where Pearson would struggle.

3. AI/ML Connection: Robustness to Outliers

The Honest Evaluator

Spearman's correlation is the go-to metric for **Evaluating Rankers** and **Handling Outliers**.

In **Search Engines** or **Recommendation AI**, we care more about the order of results than the raw scores. If an AI predicts that Document A is "more relevant" than B, and the human user agrees, that's a success—even if the raw relevance numbers differ. Spearman captures this better than Pearson. In **Noisy Datasets**, extreme outliers can "drag" a Pearson correlation toward zero even if a strong relationship exists. Because Spearman only cares about ranks, it is largely **Immune to Outliers**. If a value is the "Largest," it doesn't matter if it's 100 or 1,000,000—its rank is still the same. This makes it an essential tool for **Sturdy Feature Selection**.

4. Python: Pearson vs Spearman

from scipy.stats import spearmanr, pearsonr

# Non-linear monotonic relationship
x = np.arange(1, 11)
y = np.exp(x)

p_corr, _ = pearsonr(x, y)
s_corr, _ = spearmanr(x, y)

print(f"Pearson (Linear): {p_corr:.4f}") # (Low, around 0.6-0.7)
print(f"Spearman (Rank): {s_corr:.4f}")   # (Perfect 1.0)

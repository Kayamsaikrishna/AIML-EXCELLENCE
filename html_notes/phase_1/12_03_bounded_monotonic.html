Calculus 1.5 Analysis

Bounded & Monotonic Sequences

Guarantees of stability.

The Framework for Convergence

Sometimes we don't know the exact limit, but we want to know if a limit exists. Two properties determine this:

  • Monotonic: The sequence moves in only one direction (always increasing or always decreasing).
  • Bounded: The sequence is trapped between two numbers (it has a ceiling and a floor).

1. Monotone Convergence Theorem (MCT)

Theorem: Every bounded monotonic sequence is convergent.

Intuition: If you keep walking north (monotonic) but there is a giant wall you cannot cross (bounded), you must eventually stop or approach the wall infinitely closely. You cannot wander forever.

2. AI/ML Connection: Loss Function Guarantees

Why Gradient Descent Works

When we train a model using Gradient Descent with a sufficiently small learning rate, we aim for the Loss Sequence \(L_0, L_1, L_2 \dots\) to be Monotonic Decreasing (\(L_{n+1} \leq L_n\)).

Since Loss is usually defined as a square error or cross-entropy, it is always non-negative (\(L \geq 0\)). Thus, it is Bounded Below by 0.

By MCT, if the loss is decreasing and bounded below, the training must converge to some value. This is the mathematical guarantee that our AI won't run in circles (provided the learning rate isn't too high).

3. Python: Verifying Monotonicity

check_monotonic.py
# Sequence: a_n = n / (n + 1) -> 1/2, 2/3, 3/4...
# This is Increasing and Bounded above by 1.

def get_sequence(limit):
    return [n / (n + 1) for n in range(1, limit)]

vals = get_sequence(11)

is_increasing = all(vals[i] <= vals[i+1] for i in range(len(vals)-1))
is_bounded = all(v < 1.0 for v in vals)

print(f"Sequence: {[round(x, 2) for x in vals]}")
print(f"Monotonic Increasing: {is_increasing}")
print(f"Bounded by 1.0: {is_bounded}")
print("Conclusion: Must Converge.")

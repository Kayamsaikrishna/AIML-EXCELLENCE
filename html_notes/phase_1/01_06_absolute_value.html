1. The Non-Differentiability Problem

The function \( f(x) = |x| \) is continuous everywhere, but not differentiable at \( x=0 \). This is a "kink" in the optimization landscape.

$$ \frac{d}{dx}|x| = \text{sign}(x) = \begin{cases} 1 & x > 0 \\ -1 & x < 0 \\ \text{undefined} & x=0 \end{cases} $$

The Solution: Subgradients

In Convex Optimization, when the gradient is undefined, we use a Subgradient. At \( x=0 \), any value in the interval \( [-1, 1] \) is a valid subgradient. AI optimizers often just arbitrarily choose 0.

2. Norm Theory: Measuring Vectors

In high dimensions, "size" depends on how you measure it. Generically, the \( L_p \) norm is:

$$ ||x||_p = \left( \sum |x_i|^p \right)^{1/p} $$
Norm Formula Nickname AI Behavior
\( L_1 \) \( \sum |x_i| \) Manhattan Prone to Sparsity (sets weights to exactly 0).
\( L_2 \) \( \sqrt{\sum x_i^2} \) Euclidean Prone to diffuse small weights (Weight Decay).

3. Why L1 Induces Sparsity (Lasso)

This is a critical concept in Model Compression. Why does adding \( \lambda ||w||_1 \) to the loss function define feature selection?

The Geometry of Constraints

Imagine the error surface is an ellipse. The L1 constraint area is a Diamond (rotated square). The L2 constraint area is a Circle.

When the ellipse expands to touch the constraint:

  • It hits the Circle (L2) at a random non-zero point.
  • It hits the Diamond (L1) at a vertex (corner), which lies exactly on an axis (where other weights are 0).

4. Proving L1 Sparsity in Python

Let's force a model to learn a sparse vector.

import torch
import torch.nn as nn
import torch.optim as optim

# True vector has only 1 non-zero element
true_weights = torch.tensor([0.0, 5.0, 0.0, 0.0, 0.0])
inputs = torch.randn(100, 5)
targets = inputs @ true_weights

# Model initiated with random noise
model = nn.Linear(5, 1, bias=False)

# Optimizer with L1 Regularization is tricky in PyTorch
# Usually we add it manually to loss
optimizer = optim.SGD(model.parameters(), lr=0.1)

print("Training with L1 Penalty...")
for _ in range(100):
    optimizer.zero_grad()
    preds = model(inputs).squeeze()
    mse_loss = nn.MSELoss()(preds, targets)
    
    # L1 Penalty term
    l1_lambda = 0.1
    l1_norm = sum(p.abs().sum() for p in model.parameters())
    
    loss = mse_loss + l1_lambda * l1_norm
    loss.backward()
    optimizer.step()

# Result: Weights should be pushed towards 0, except index 1
print(f"Learned Weights: {model.weight.data}")

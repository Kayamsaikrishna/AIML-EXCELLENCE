6. Absolute Value & Loss Functions

Distance cannot be negative. The mathematics of Error and Sparsity.

1. The Definition of Distance

$$ |x| = \begin{cases} x & \text{if } x \ge 0 \\ -x & \text{if } x < 0 \end{cases} $$

Why it Matters

In the physical world and engineering, "Negative Distance" doesn't exist. If a robot is -5 meters from the target, the Error magnitude is 5 meters. We optimize systems to minimize this magnitude.

AI Context: MAE vs MSE

When training a Regression model (e.g., predicting house prices), we measure error.

  • Mean Absolute Error (L1): \( \frac{1}{n} \sum |y_{pred} - y_{true}| \).
  • Mean Squared Error (L2): \( \frac{1}{n} \sum (y_{pred} - y_{true})^2 \).

L1 (Absolute Value) is Robust: It doesn't overreact to outliers. If one house is priced crazily high, L1 treats it linearly. L2 squares the error, forcing the model to skew massively to fix that one mistake.

2. The "V" vs The "U"

The shape of the function determines how the Gradient flows.

The Engineering Trade-off: Sparsity

Because the L1 gradient is constant (it doesn't get smaller as you get closer to 0), it pushes weights Exactly to Zero.

This is called L1 Regularization (Lasso). It is used for "Feature Selection"—the model automatically kills off useless features by setting their weights to exactly 0.

L2 (Ridge), on the other hand, just makes weights "small" but rarely zero.

3. Coding L1 Regularization

Let's see how we manually add L1 regularization to a PyTorch loss function.

// PyTorch: Adding L1 Penalty
import torch
import torch.nn as nn

model = nn.Linear(10, 1) # simple linear model
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# Training Loop
def train_step(data, target):
    optimizer.zero_grad()
    output = model(data)
    
    # 1. Standard Loss (MSE)
    mse_loss = nn.MSELoss()(output, target)
    
    # 2. L1 Regularization Term
    l1_lambda = 0.01
    l1_norm = sum(p.abs().sum() for p in model.parameters())
    
    # 3. Total Loss
    loss = mse_loss + (l1_lambda * l1_norm)
    
    loss.backward() # Gradients calculated for both Error and Magnitude
    optimizer.step()
    
    return loss.item()

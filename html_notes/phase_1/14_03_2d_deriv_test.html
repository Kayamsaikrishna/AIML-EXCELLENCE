Optimization 1.7 Classification

The Second Derivative Test

Using the Hessian determinant to distinguish peaks from valleys.

The Discriminant (D)

To classify a critical point \((a, b)\), we compute the Determinant of the Hessian Matrix, called the Discriminant \(D\):

$$ D = \det(\mathbf{H}) = f_{xx} f_{yy} - (f_{xy})^2 $$

Think of \(D\) as the product of the two eigenvalues ("curvatures").

2. AI/ML Connection: The Trust Region

Avoiding Fake Minima

In Newton's Mean, we approximate the function locally as a quadratic bowl using the Hessian and jump to the bottom. However, if the Hessian is Indefinite (\(D < 0\)), "jumping to the bottom" actually sends us towards the saddle point or infinity!

Advanced optimizers check the curvature. If \(D < 0\), they switch strategies (e.g., Levenberg-Marquardt) to avoid taking a bad step. This is equivalent to checking if the "Trust Region" is valid.

3. Python: Classification Logic

classify_optima.py
import sympy as sp

x, y = sp.symbols('x y')
# f(x,y) = x^4 + y^4 - 4xy + 1
f = x**4 + y**4 - 4*x*y + 1

# 1. Gradients
fx = sp.diff(f, x)
fy = sp.diff(f, y)
critical_pts = sp.solve([fx, fy], (x, y))
print(f"Critical Points: {critical_pts}")
# Expected: (0,0), (1,1), (-1,-1)

# 2. Hessian Components
fxx = sp.diff(f, x, x)
fyy = sp.diff(f, y, y)
fxy = sp.diff(f, x, y)

def classify(pt):
    subs_dict = {x: pt[0], y: pt[1]}
    D = (fxx * fyy - fxy**2).subs(subs_dict)
    val_fxx = fxx.subs(subs_dict)
    
    if D > 0 and val_fxx > 0: return "Local Minimum"
    if D > 0 and val_fxx < 0: return "Local Maximum"
    if D < 0: return "Saddle Point"
    return "Inconclusive"

for pt in critical_pts:
    print(f"Point {pt}: {classify(pt)}")

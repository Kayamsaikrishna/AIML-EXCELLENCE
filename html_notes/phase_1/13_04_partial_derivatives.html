Calculus 1.6 Core Mechanic

Partial Derivatives

Changing one thing at a time.

Hold Everything Else Constant

A regular derivative \( \frac{dy}{dx} \) assumes \(y\) depends only on \(x\). In multivariable calculus, \( z = f(x, y) \) depends on both. To find how \(z\) changes when we nudge \(x\), we pretend \(y\) is a constant (like the number 5).

Notation: \( \frac{\partial f}{\partial x} \) or \( f_x \). \[ \frac{\partial}{\partial x} (x^2 y) = 2xy \quad \text{(y treated as constant)} \] \[ \frac{\partial}{\partial y} (x^2 y) = x^2 \quad \text{(x treated as constant)} \]

2. AI/ML Connection: Adjusting Weights

The Essence of Learning

When a Neural Network creates an error, we need to know: "Who is responsible?" If the network has 1 million weights, we calculate the Partial Derivative of the error with respect to *each individual weight*.

\( \frac{\partial Error}{\partial w_{500}} \) tells us: "If we increase weight #500 slightly, how much will the error go up or down?" We then update that weight in the opposite direction. We do this for all 1 million weights simultaneously. This is Backpropagation.

3. Python: Symbolic Differentiation

partial_diff.py
import sympy as sp

x, y = sp.symbols('x y')
f = x**2 * sp.sin(y) + y**3

# Calculate partial derivative with respect to x
# Treat y as constant: derivative of (x^2 * const + const^3) -> 2x * const
df_dx = sp.diff(f, x)

# Calculate partial derivative with respect to y
# Treat x as constant: derivative of (const * sin(y) + y^3) -> const * cos(y) + 3y^2
df_dy = sp.diff(f, y)

print(f"Function: {f}")
print(f"df/dx: {df_dx}") # 2*x*sin(y)
print(f"df/dy: {df_dy}") # x**2*cos(y) + 3*y**2

# Evaluate at (1, pi/2)
print(f"df/dx evaluated at (1, pi/2): {df_dx.subs({x:1, y:sp.pi/2})}")

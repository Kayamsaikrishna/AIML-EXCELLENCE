1. The Three Possibilities

  • No Solution (Inconsistent): Parallel lines/planes that never meet. \( \text{rank}(A) < \text{rank}([A|b]) \).
  • Unique Solution: Independent columns, full rank. \( \text{rank}(A) = \text{rank}([A|b]) = n \).
  • Infinite Solutions: Dependent columns (free variables exist). \( \text{rank}(A) = \text{rank}([A|b]) < n \).

2. Linear Separability

In a Support Vector Machine (SVM), we look for a hyperplane \( w^T x + b = 0 \) that separates classes.

If classes overlap perfectly (same point with different labels), there is No Solution (Inconsistent). We must add a "slack variable" (error tolerance) to make it solvable, effectively moving from \( Ax=b \) to a Least Squares / Optimization approach.

3. Detecting Cases via Rank

import numpy as np

def analyze_system(A, b):
    # Augmented Matrix [A|b]
    augmented = np.column_stack((A, b))
    
    rank_A = np.linalg.matrix_rank(A)
    rank_Aug = np.linalg.matrix_rank(augmented)
    n = A.shape[1]
    
    print(f"Rank(A): {rank_A}, Rank(Aug): {rank_Aug}, Vars: {n}")
    
    if rank_A < rank_Aug:
        print(">> Inconsistent (No Solution)")
    elif rank_A == rank_Aug:
        if rank_A == n:
            print(">> Consistent (Unique Solution)")
        else:
            print(">> Consistent (Infinite Solutions)")

# Examples
A1 = np.array([[1, 1], [2, 2]])
b1 = np.array([5, 6]) # Parallel lines, different intercept
print("Case 1:")
analyze_system(A1, b1)

A2 = np.array([[1, 1], [0, 1]])
b2 = np.array([5, 2])
print("\nCase 2:")
analyze_system(A2, b2)

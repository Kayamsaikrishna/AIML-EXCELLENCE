01. Introduction to Differential Equations

Describing how systems evolve over time.

1. What is an ODE?

An Ordinary Differential Equation (ODE) is an equation that relates an unknown function \(y(x)\) to its derivatives. It describes the rate of change of a system.

$$ \frac{dy}{dx} = f(x, y) $$

The Order of an ODE is the highest derivative present in the equation.

2. General vs. Particular Solutions

A General Solution contains an arbitrary constant \(C\) because integration introduces an unknown starting point. A Particular Solution is found when we are given an Initial Value problem (IVP), such as \(y(0) = 5\).

3. AI/ML Connection: Dynamic Systems

Neural ODEs

In traditional Deep Learning, we think of a model as a series of "Discrete Steps" (layers). Neural ODEs change this paradigm. Instead of \(h_{t+1} = h_t + f(h_t, \theta)\), we treat the hidden states as a continuous flow defined by an ODE:

$$ \frac{dh(t)}{dt} = f(h(t), t, \theta) $$

This allows the AI to consume data at Any Timestamp (not just fixed steps) and is particularly powerful for medicine (heart monitors) and finance (stock market flows). By using the math of ODEs, we can build models that are more memory-efficient and physically consistent with how the real world changes.

4. Python: Symbolic ODE Check

import sympy as sp

x = sp.symbols('x')
y = sp.Function('y')

# Define ODE: y' = y
ode = sp.Eq(y(x).diff(x), y(x))

# Solve ODE
solution = sp.dsolve(ode)
print(f"General Solution: {solution}")
# Result: y(x) = C1 * exp(x)

Backpropagation Math

The "Error Signal" passing protocol.

The Backward Pass

We define the "Error Signal" (or adjoint) at layer \(l\) as: \[ \delta^l = \frac{\partial L}{\partial z^l} \] Backpropagation is a recursive algorithm to compute \(\delta^l\) from \(\delta^{l+1}\): \[ \delta^l = (\mathbf{W}^{l+1})^T \delta^{l+1} \odot \sigma'(z^l) \]

Once we have the error signal \(\delta^l\), the gradient for the weights is simply the outer product: \[ \frac{\partial L}{\partial \mathbf{W}^l} = \delta^l (\mathbf{a}^{l-1})^T \]

2. ML Connection: Efficiency

Why Backprop?

If we used finite differences (perturbing each weight one by one), calculating gradients for 1 billion weights would take 1 billion forward passes.

Backpropagation computes ALL gradients in just ONE forward pass + ONE backward pass. It is O(1) relative to the number of parameters per pass. This efficiency is the only reason Deep Learning is possible.

3. Python: Numpy Backprop

numpy_backprop.py
import numpy as np

# A simple 2-layer network backpass
# y = W2 * ReLU(W1 * x)

N, Din, H, Dout = 64, 1000, 100, 10
x = np.random.randn(N, Din)
y = np.random.randn(N, Dout)
w1 = np.random.randn(Din, H)
w2 = np.random.randn(H, Dout)

# Forward
h = x.dot(w1)
h_relu = np.maximum(h, 0)
y_pred = h_relu.dot(w2)
loss = np.square(y_pred - y).sum()

# Backward
grad_y_pred = 2.0 * (y_pred - y)
grad_w2 = h_relu.T.dot(grad_y_pred)
grad_h_relu = grad_y_pred.dot(w2.T)
grad_h = grad_h_relu.copy()
grad_h[h < 0] = 0 # Derivative of ReLU
grad_w1 = x.T.dot(grad_h)

print(" Gradients Computed!")

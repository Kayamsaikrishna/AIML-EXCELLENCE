15. Derivatives of Hyperbolic Functions

The derivatives of the S-shaped functions.

1. Primary Rules

Hyperbolic functions (\(\sinh, \cosh\)) behave similarly to trig functions but without the complicated sign changes in their primary derivatives.

$$ \frac{d}{dx}[\sinh x] = \cosh x $$ $$ \frac{d}{dx}[\cosh x] = \sinh x $$ $$ \frac{d}{dx}[\tanh x] = \text{sech}^2 x $$

2. The Tanh Derivative Identity

Just like the sigmoid function, the derivative of \(\tanh\) has a very efficient computational form:

$$ \frac{d}{dx}[\tanh x] = 1 - \tanh^2 x $$

3. AI/ML Connection: The Tanh Activation Function

Vanishing Gradients

The Tanh function is a popular activation function in RNNs and standard MLPs because it maps any input to the range \([-1, 1]\).

However, notice its derivative: \(1 - \text{tanh}^2 x\). As the input \(x\) gets very large (positive or negative), \(\tanh(x)\) approaches \(1\) or \(-1\). This means the derivative \((1 - \text{tanh}^2 x)\) approaches Zero.

This is the mathematical root of the Vanishing Gradient Problem. If the derivative is zero, the model stops learning because there is no gradient signal to tell it how to update the weights. This is why ReLU (Rectified Linear Unit) has largely replaced Tanh in deep networks.

4. Python: Tanh Derivative Visualization

import numpy as np

def tanh(x):
    return np.tanh(x)

def tanh_grad(x):
    # D/dx [tanh] = 1 - tanh^2
    return 1 - np.tanh(x)**2

x_points = np.linspace(-5, 5, 10)
for x in x_points:
    print(f"x={x:5.2f} | Tanh={tanh(x):5.2f} | Grad={tanh_grad(x):5.2f}")

# Notice how grad goes to 0 as |x| increases!

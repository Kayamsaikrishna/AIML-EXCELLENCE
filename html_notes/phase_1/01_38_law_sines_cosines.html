1. Generalized Pythagoras

For ANY triangle, not just right triangles:

$$ c^2 = a^2 + b^2 - 2ab \cos(C) $$

Insight: If \( C = 90^\circ \), then \( \cos(90) = 0 \), and we get back \( c^2 = a^2 + b^2 \).

The term \( -2ab \cos(C) \) is the "Correction factor" for how much the angle deviates from orthogonality.

2. Triangle Inequality

For any distance metric \( d(x, y) \), the Law of Cosines implies the Triangle Inequality:

$$ d(A, C) \le d(A, B) + d(B, C) $$

This is crucial for Metric Learning (Siamese Networks). If the distance doesn't obey this rule (e.g., KL Divergence), the space is not a "Metric Space", and many algorithms (like K-Means or Nearest Neighbors) break down.

3. Calculating Distance

Computing the side of a generalized triangle.

import numpy as np

# Two vectors (Sides a and b)
a = 5.0
b = 8.0
angle_deg = 60.0 # Angle C
angle_rad = np.radians(angle_deg)

# Law of Cosines to find side c
c_squared = a**2 + b**2 - 2*a*b*np.cos(angle_rad)
c = np.sqrt(c_squared)

print(f"Side c: {c:.4f}") 
# 5^2 + 8^2 - 2(5)(8)(0.5) = 25 + 64 - 40 = 49. sqrt(49) = 7.
# Yes, a 5-8-7 triangle works with 60 degrees!

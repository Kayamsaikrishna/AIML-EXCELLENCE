1. The Dot Product: Measuring Alignment

The Dot Product is the single most important operation in Deep Learning. It measures how much two vectors "agree" with each other.

$$ \mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^n a_i b_i = ||\mathbf{a}|| ||\mathbf{b}|| \cos \theta $$

Geometric Interpretation

  • If \( \mathbf{a} \cdot \mathbf{b} > 0 \): They point in a similar direction (Acute angle).
  • If \( \mathbf{a} \cdot \mathbf{b} = 0 \): They are Orthogonal (90°). No correlation.
  • If \( \mathbf{a} \cdot \mathbf{b} < 0 \): They point in opposite directions (Obtuse angle).

2. Cosine Similarity in AI

In RAG (Retrieval-Augmented Generation), we search for documents similar to a query. We use Cosine Similarity, which is just the normalized Dot Product.

Why Normalize?

If we just use the raw dot product, longer documents (vectors with large Magnitude) might dominate just because they have more words. Dividing by the magnitude focuses purely on Direction (Meaning).

$$ \text{Sim}(\mathbf{A}, \mathbf{B}) = \frac{\mathbf{A} \cdot \mathbf{B}}{||\mathbf{A}|| ||\mathbf{B}||} = \cos \theta $$

3. The Hadamard Product (Element-wise)

Denoted \( \mathbf{A} \odot \mathbf{B} \), this just multiplies corresponding elements. It is used in Gating Mechanisms (LSTMs, GRUs) to filter information.

$$ \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix} \odot \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix} = \begin{bmatrix} 0 \\ 2 \\ 0 \end{bmatrix} $$

Here, the second vector acts as a "binary mask", passing the middle value and killing the others.

4. Python Implementation

Beware: The `*` operator in Python/Numpy often defaults to Hadamard, not Dot Product!

import numpy as np
import torch

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

# 1. Hadamard (Element-wise)
print(f"a * b: {a * b}") # [4, 10, 18]

# 2. Dot Product (Standard)
print(f"np.dot(a, b): {np.dot(a, b)}") # 4+10+18 = 32

# 3. Cosine Similarity in PyTorch
t_a = torch.tensor([1.0, 0.0, 0.0])
t_b = torch.tensor([0.707, 0.707, 0.0])

# Using functional API
cos_sim = torch.nn.functional.cosine_similarity(t_a, t_b, dim=0)
print(f"Cosine Sim: {cos_sim:.4f}") # Should be ~0.707 (cos 45 deg)

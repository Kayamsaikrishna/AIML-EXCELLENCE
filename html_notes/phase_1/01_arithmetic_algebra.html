1.1 Arithmetic & Algebra

The fundamental building blocks of mathematical logic. While often overlooked, these concepts form the basis for data representation, loss functions, and model complexity.

Number Systems

Definitions

  • Natural Numbers (\(\mathbb{N}\)): Counting numbers {1, 2, 3...}. Used for indices and epochs.
  • Integers (\(\mathbb{Z}\)): Whole numbers including negative {..., -2, -1, 0, 1, 2...}. Used for discrete labels.
  • Rational Numbers (\(\mathbb{Q}\)): Fractions p/q.
  • Real Numbers (\(\mathbb{R}\)): Include irrationals (pi, e). Represents continuous data (weights, gradients).
  • Complex Numbers (\(\mathbb{C}\)): a + bi. Used in Fourier Transforms and signal processing.
\(\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}\)

AI/ML Application: Data Types & Tensors

In Machine Learning frameworks like PyTorch or TensorFlow, choosing the right number system is critical for memory and precision.

  • Integers (int8, int64): Used for classification labels (0 = Cat, 1 = Dog).
  • Real Numbers (float32, float16): Used for Neural Network weights. "Float16" (half-precision) is heavily used in Large Language Models (LLMs) to reduce memory usage without losing significant accuracy.

Linear Equations & Inequalities

Linear Equations

An equation of the form \(y = mx + b\).

  • Slope (m): Rate of change.
  • Intercept (b): Value when x is 0.

Inequalities & Absolute Value

Absolute value \(|x|\) measures distance from zero. Inequalities describe regions.

AI/ML Application: Linear Regression & SVMs

Linear Regression: The simplest ML model is literally fitting a linear equation \(y = w \cdot x + b\) to data to find the best slope (weight) and intercept (bias).

Constraints: Inequalities are used in optimization constraints (e.g., \( \sum p_i = 1 \) for probabilities).

L1 Regularization: Uses the absolute value of weights (\(|w|\)) to force some feature weights to become exactly zero, effectively doing feature selection.

Exponentials & Logarithms

Concepts

Exponential Growth (\(e^x\)): Rate of growth proportional to current value.

Logarithms (\(\log_b x\)): The inverse of exponentiation. "To what power must b be raised to get x?"

\(\ln(e^x) = x\)
\(\log(ab) = \log a + \log b\) (Turns multiplication into addition)

AI/ML Application: Log-Likelihood & Cross-Entropy

Log-Likelihood: Probabilities are often tiny numbers (e.g., 0.00001). Multiplying many tiny probabilities causes "numerical underflow" (computer rounds to 0). By taking the Log, we turn multiplication into addition, keeping numbers manageable.

Softmax & Cross-Entropy: Deep learning classification losses heavily rely on \(-\sum y \cdot \log(\hat{y})\).

Functions

Definitions

A mapping from a Domain (inputs) to a Range (outputs). \(f(x) \rightarrow y\).

  • Composition: \(f(g(x))\) - chaining functions.
  • Inverse: \(f^{-1}(y) = x\) - undoing a function.

AI/ML Application: Neural Networks as Universal Function Approximators

Composition: A Deep Neural Network is essentially a giant composite function: \( y = f_3(f_2(f_1(x))) \), where each layer is a function.

Activation Functions: Non-linear functions (ReLU, Sigmoid) applied to outputs to allow the network to learn complex patterns.

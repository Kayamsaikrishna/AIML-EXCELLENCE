Prob 1.4 Scale

Standard Deviation

Back to the original units.

Definition

Variance is in "squared units" (e.g., \(meters^2\)), which is hard to interpret. Standard Deviation is the square root of Variance: \[ \sigma = \sqrt{Var(X)} \] It measures spread in the same units as the data.

2. ML Connection: Feature Scaling

Normalization

Neural Networks and Gradient Descent converge faster if all inputs have similar scale (mean 0, std 1). We perform Z-Score Normalization: \[ x' = \frac{x - \mu}{\sigma} \] This ensures gradients flow smoothly across all dimensions.

3. Python: Z-Score

normalize.py
import numpy as np

data = np.array([2.0, 5.0, 10.0, 100.0]) # 100 is an outlier

mean = np.mean(data)
std = np.std(data)

z_scores = (data - mean) / std

print(f"Data: {data}")
print(f"Z-Scores: {z_scores}")
# Large positive Z-score indicates outlier.

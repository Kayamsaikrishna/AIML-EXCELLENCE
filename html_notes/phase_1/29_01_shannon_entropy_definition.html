Info Theory Foundations

Shannon Entropy Definition

Measuring Uncertainty. How Claude Shannon quantified the "Information" contained in a message before it is even sent.

The Intuition of Surprise

Information is directly proportional to Surprise.

If I tell you "It will rain in the Sahara Desert today," that is high information because it's rare (high surprise). If I tell you "The sun will rise," that is zero information because you already knew it was 100% likely.

1. Self-Information: The Unit of Surprise

Before we define Entropy for a whole system, we must define it for a single event \(x\). We call this Surprise or Self-Information:

$$ I(x) = \log_b \left( \frac{1}{P(x)} \right) = -\log_b P(x) $$
  • If \(b=2\), the unit is Bits (Binary Digits).
  • If \(b=e\), the unit is Nats (Natural Units).
  • If \(b=10\), the unit is Hartleys.

2. Shannon Entropy: The Average Surprise

Entropy \(H(X)\) is the Expected Value of the self-information over all possible outcomes in a distribution \(X\).

$$ H(X) = E[I(X)] = \sum_{x \in \mathcal{X}} P(x) \log_b \left( \frac{1}{P(x)} \right) $$

Or more commonly written as:

$$ H(X) = - \sum_{i=1}^{n} p_i \log_b p_i $$
graph TD A[Source Distribution X] --> B{Calculate P_i} B --> C[Calculate -log P_i] C --> D[Weight by P_i] D --> E[Sum = H_X] E --> F[High H = High Uncertainty] E --> G[Low H = High Predictability]

3. Properties of Entropy

1. Non-negativity

\(H(X) \ge 0\). You can't have "negative" uncertainty. It only reaches zero when one outcome is certain (\(P=1\)).

2. Extremality

For a discrete set of \(n\) outcomes, Entropy is maximized when every outcome is equally likely (Uniform Distribution). \(H_{max} = \log n\).

Deep Learning Decision Trees

Why AI Engineers care about Entropy

In Machine Learning, Entropy is the primary tool for measuring "Purity" and "Distance".

  • Decision Trees (ID3/C4.5): We choose splits that maximize Information Gain, which is just the reduction in Entropy of the labels.
  • Cross-Entropy Loss: When training a classifier (like Softmax), we minimize the Cross-Entropy between the predicted distribution and the true label. This effectively forces the model to remove uncertainty from its predictions.
  • Bit-Level Compression: Large Language Models (LLMs) are evaluated using Perplexity, which is mathematically \(2^{H}\). A model with lower entropy is a more "knowledgeable" model.

4. Python Implementation

import numpy as np

def shannon_entropy(probabilities):
    # Filter out zero probabilities to avoid log(0)
    probabilities = probabilities[probabilities > 0]
    return -np.sum(probabilities * np.log2(probabilities))

# Example: Fair Coin
fair_coin = np.array([0.5, 0.5])
print(f"Fair Coin Entropy: {shannon_entropy(fair_coin)} bits") # Output: 1.0

# Example: Biased Coin
biased_coin = np.array([0.9, 0.1])
print(f"Biased Coin Entropy: {shannon_entropy(biased_coin):.4f} bits") # Output: 0.4690

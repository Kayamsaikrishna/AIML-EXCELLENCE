Set Notation & Operations

The Language of Belonging. Defining the fundamental structures of mathematics where everything is either in or out, providing the basis for probability, database theory, and data architecture.

What is a Set?

A Set is an unordered collection of distinct objects (elements). In the world of sets, \( \{1, 2, 3\} \) is the same as \( \{3, 1, 2\} \), and duplicates don't exist. This binary "Belongs To" (\(\in\)) or "Does Not Belong To" (\(\notin\)) logic is the bedrock of information grouping.

1. Core Notation

Roster vs. Set-Builder

  • Roster: \( A = \{2, 4, 6\} \) (Listing elements)
  • Set-Builder: \( A = \{x \in \mathbb{Z} \mid x \text{ is even and } 0 < x < 8\} \) (Defining properties)

Special Sets

  • \(\varnothing\): The Empty Set (Null set).
  • \(\mathbb{N, Z, Q, R}\): Natural, Integers, Rationals, Reals.
  • \(U\): The Universal Set (Everything under consideration).

2. Fundamental Operations

Union (\(\cup\))

OR: Everything in \(A\) OR \(B\).

\( A \cup B = \{x \mid x \in A \lor x \in B\} \)

Intersection (\(\cap\))

AND: Only things in BOTH \(A\) AND \(B\).

\( A \cap B = \{x \mid x \in A \land x \in B\} \)

Difference (\(-\))

EXCLUDE: Things in \(A\) that are NOT in \(B\).

\( A - B = \{x \mid x \in A \land x \notin B\} \)

Complement (\(A^c\))

NOT: Everything in the universe \(U\) that is not in \(A\).

\( A^c = \{x \in U \mid x \notin A\} \)
Data Engineering Probability

Sets in the Real World

  • SQL Joins: A `LEFT JOIN` is essentially the Union of an Intersection and a Set Difference. Databases are built entirely on set theory (Relational Algebra).
  • Python Sets: The `{}` syntax in Python implements these operations at high speed. `set1 | set2` (Union), `set1 & set2` (Intersection).
  • Probability Spaces: The "Sample Space" is a set \(\Omega\). An "Event" is a subset \(E \subseteq \Omega\). Finding the probability of \(A\) and \(B\) happening is finding the "size" of the intersection.
  • Recommendation Engines: Finding "User-User Similarity" often involves calculating the Jaccard Index, which is the ratio of the intersection to the union of two users' liked items: \( J(A, B) = \frac{|A \cap B|}{|A \cup B|} \).

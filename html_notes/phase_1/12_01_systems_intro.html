01. Consistent & Inconsistent Systems

Does a solution even exist?

1. The Fundamental Question

For a system \(\mathbf{Ax} = \mathbf{b}\), we have three possibilities:

  • Consistent (Unique): Exactly one intersection.
  • Consistent (Infinite): Lines/Planes overlap (linearly dependent).
  • Inconsistent: Parallel lines/planes that never meet.

3. AI/ML Connection

Linear Regression

Most real-world data systems are Inconsistent and Overdetermined (more equations than unknowns). We don't find a perfect solution; we find the Least Squares solution that minimizes the error \(\|\mathbf{Ax} - \mathbf{b}\|^2\).

4. Python: Checking Consistency

import numpy as np

def check_system(A, b):
    # Augment A with b
    augmented = np.column_stack((A, b))
    
    rank_A = np.linalg.matrix_rank(A)
    rank_aug = np.linalg.matrix_rank(augmented)
    
    if rank_A == rank_aug:
        if rank_A == A.shape[1]:
            return "Consistent (Unique)"
        else:
            return "Consistent (Infinite)"
    else:
        return "Inconsistent"

A = np.array([[1, 2], [1, 2]])
b_inc = np.array([3, 5]) # Parallel
b_con = np.array([3, 3]) # Overlapping

print(f"System 1: {check_system(A, b_inc)}")
print(f"System 2: {check_system(A, b_con)}")

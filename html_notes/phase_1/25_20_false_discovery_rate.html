False Discovery Rate (FDR)

A modern, smarter way to handle multiple tests by controlling the *proportion* of errors rather than banning them entirely.

The Pragmatic View

Bonferroni is so strict that it often "throws the baby out with the bathwater."

FDR says: "I know some of my discoveries will be mistakes. I just want to ensure that only 5% of my significant findings are mistakes."

1. The Benjamini-Hochberg (BH) Procedure

1. Sort all P-values from smallest to largest (\(P_{(1)}, P_{(2)}, \dots, P_{(m)}\)). 2. For each P-value, calculate the threshold: \( \frac{i}{m} \times Q \). 3. Find the largest \(i\) such that \(P_{(i)} \le \frac{i}{m} Q \). 4. Reject all hypotheses from 1 to \(i\).

(\(Q\) is your target FDR, usually 0.05).

2. FDR vs. Bonferroni

Feature Bonferroni FDR (BH)
Goal Zero False Positives Allowed. Keep False Positives to 5% of "Selected" items.
Power Low (Very conservative). High (Finds more real effects).
Best For Critical trials (Medicine). Exploratory Big Data (ML features).

3. ML Connection: Modern Feature Selection

Supervised Big Data

High-Dimensional Discovery

In many ML tasks, you have 10,000 features. - If you use Alpha=0.05, you get 500 noise features. - If you use Bonferroni, you get 0 features (too strict).

FDR is the balance. If you select 100 features using FDR, you can be reasonably sure that ~95 of them are truly related to the target, and only 5 are accidental noise. This is the standard in Omics, Marketing propensity models, and Econometrics.

Model-Based FDR

Techniques like the Knockoff Filter extend FDR to complex neural networks, allowing us to prove which inputs the model is "actually" using while controlling the false discovery rate.

1. Geometric Interpretation

The determinant is the signed volume scaling factor of the linear transformation.

  • If \( \det(A) = 2 \): The transformation doubles the volume of any region.
  • If \( \det(A) = 0 \): The transformation flattens space (Volume -> 0).
  • If \( \det(A) = -1 \): The transformation acts like a mirror (Flip).

2. Normalizing Flows

In Generative AI (Normalizing Flows), we transform a simple distribution (Gaussian) into a complex one (Image).

To compute the probability density, we MUST track how the volume changes. This requires computing \( \log |\det(J)| \), where \( J \) is the Jacobian matrix.

3. Calculating Scale

Singular vs Non-Singular transforms.

import numpy as np

# A Shear Matrix (Preserves Volume)
Shear = np.array([
    [1, 1],
    [0, 1]
])

print(f"Shear Det: {np.linalg.det(Shear)}")
# Exact 1.0. Shearing pushes the box but keeps area same.

# A Scaling Matrix (Doubles x, Triples y)
Scale = np.array([
    [2, 0],
    [0, 3]
])

print(f"Scale Det: {np.linalg.det(Scale)}")
# 2*3 = 6.0. Area increases 6-fold.

# A Singular Matrix (Projection)
Proj = np.array([
    [1, 0],
    [0, 0]
])

print(f"Proj Det: {np.linalg.det(Proj)}")
# 0.0. Squashed 2D space onto 1D x-axis. Volume is lost.

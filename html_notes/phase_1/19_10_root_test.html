07. The Root Test

Finding the limit of the n-th magnitude.

1. The Test

The Root Test is ideal for series where the terms are raised to the \(n\)-th power (\(a_n^n\)). We look at the \(n\)-th root of the absolute value:

$$ L = \lim_{n \to \infty} \sqrt[n]{|a_n|} $$
  • If \(L < 1\): The series Converges Absolutely.
  • If \(L > 1\): The series Diverges.
  • If \(L = 1\): Inconclusive.

2. Geometry

Intuitively, the Root Test compares the series to a Geometric Series. If \(L < 1\), it means that for very large \(n\), the terms are decaying faster than some geometric series \(\sum r^n\) where \(r < 1\).

3. AI/ML Connection: Spectral Radius & RNNs

Recurrent Dependencies

In Recurrent Neural Networks (RNNs), a weight matrix \(W\) is applied repeatedly to the hidden state over time steps. If the "Average Magnitude" of these weights is greater than 1, the signal will grow exponentially and explode.

The Root Test logic is used to calculate the Spectral Radius of the weight matrix. If the spectral radius (\(L\)) is less than 1, we are guaranteed that the information "Converges" and doesn't explode. This is why we use techniques like Weight Normalization—to force the \(n\)-th root of our model's transformation to stay within the safe "Convergence Zone" (less than 1).

4. Python: Root Test Simulation

# Series: ( (n+1)/3n )^n
# Root: (n+1)/3n -> 1/3
import numpy as np

n = 1000000
an = ((n + 1) / (3 * n))**n
root_val = an**(1/n)

print(f"n-th root limit: {root_val:.6f}")
print("Limit 1/3 < 1 -> Series Converges!")

Calculus 1.3 Dynamics

Velocity, Acceleration & Jerk

Position is a state. Motion is a derivative.

The Hierarchy of Change

Calculus was invented largely to understand planetary motion. The relationship between where you are, how fast you're going, and what force is pushing you is purely differential.

1. The Ladder of Derivatives

  • \(s(t)\) Position: Location at time \(t\).
  • \(v(t) = s'(t)\) Velocity: Rate of change of position.
  • \(a(t) = v'(t) = s''(t)\) Acceleration: Rate of change of velocity. (F=ma).
  • \(j(t) = a'(t) = s'''(t)\) Jerk: Rate of change of acceleration. (Whiplash).

2. AI/ML Connection: Trajectory Planning

Minimizing Jerk

In Robotics and Autonomous Driving, we plan paths from A to B.

If we just minimize time, the robot might accelerate instantly (Infinite Force -> Impossible). If we just minimize acceleration, the motion is smooth but spiky.

We actually minimize Jerk (the 3rd derivative). High jerk causes wear and tear on motors and makes passengers sick. The cost function often looks like: \( J = \int (s'''(t))^2 dt \).

3. Python: Kalman Filter Logic

motion_simulation.py
import sympy as sp
import numpy as np

t = sp.Symbol('t')
# A particle moves according to a cubic function (smooth jerk)
# s(t) = t^3 - 6t^2 + 9t
position = t**3 - 6*t**2 + 9*t

velocity = sp.diff(position, t)
acceleration = sp.diff(velocity, t)
jerk = sp.diff(acceleration, t)

print(f"Pos: {position}")
print(f"Vel: {velocity}") # 3t^2 - 12t + 9
print(f"Acc: {acceleration}") # 6t - 12
print(f"Jrk: {jerk}") # 6 (Constant Jerk)

# Find when particle stops (v=0)
stops = sp.solve(velocity, t)
print(f"Particle stops at t={stops}")

# Calculate total distance in first 5 seconds
# We must integrate speed |v(t)| or sum absolute displacements
times = [0] + sorted([float(x) for x in stops if 0 < x < 5]) + [5]
total_dist = 0
for i in range(len(times)-1):
    t1, t2 = times[i], times[i+1]
    p1 = position.subs(t, t1)
    p2 = position.subs(t, t2)
    total_dist += abs(float(p2 - p1))

print(f"Total Distance Traveled (0 to 5s): {total_dist}")

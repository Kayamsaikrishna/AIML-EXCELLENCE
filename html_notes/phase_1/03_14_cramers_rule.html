14. Cramer's Rule

Solving linear systems using determinants.

1. The Analytical Formula

For a system \( \mathbf{Ax} = \mathbf{b} \), Cramer's rule allows you to solve for each variable independently using determinants.

$$ x_i = \frac{\text{det}(\mathbf{A}_i)}{\text{det}(\mathbf{A})} $$

Where \( \mathbf{A}_i \) is the matrix \( \mathbf{A} \) but with the \( i \)-th column replaced by the vector \( \mathbf{b} \).

2. The "Stability" Consideration

Theoretical vs. Physical AI

Cramer's rule is beautiful theoretically but dangerous numerically. Because it relies on Dividing by the determinant, if the matrix is "almost singular" (determinant close to 0), the result will explode or be highly inaccurate due to float precision errors.

  • Condition Number: Related to Cramer's Rule, it measures how much the output changes for a small change in input.
  • Better Alternatives: LU Decomposition or iterative solvers like Conjugate Gradient are preferred in real-time AI.

3. Python: Cramer's Implementation

import numpy as np

def cramer_solve(A, b):
    det_A = np.linalg.det(A)
    if np.isclose(det_A, 0): return None
    
    n = len(b)
    result = []
    for i in range(n):
        Ai = A.copy()
        Ai[:, i] = b
        result.append(np.linalg.det(Ai) / det_A)
    return np.array(result)

A = np.array([[2, 1], [1, 3]])
b = np.array([5, 10])

x = cramer_solve(A, b)
print(f"Solution: {x}") # [1, 3] approx

Cramer's Rule

\( x_i = \det(A_i) / \det(A) \). Elegant theory, computationally expensive.

1. The Formula

If \( \det(A) \neq 0 \), determining the unknowns \( x_1, x_2, \dots \) can be done explicitly:

$$ x_i = \frac{\det(A_i)}{\det(A)} $$

where \( A_i \) is the matrix obtained by replacing the \( i \)-th column of \( A \) with the vector \( b \).

2. Utility

Because calculating determinants is slow, Cramer's Rule is useless for large AI systems.

However, it is useful in Control Theory or theoretical derivations where we want to express the solution as an explicit algebraic function of the parameters.

3. Cramer's Implementation

Solving Ax=b using pure determinants.

import numpy as np

A = np.array([[2, 1], [1, -1]])
b = np.array([4, 1])

det_A = np.linalg.det(A)
print(f"Det(A): {det_A}")

# Solve for x1 (Replace col 0 with b)
A1 = A.copy()
A1[:, 0] = b
x1 = np.linalg.det(A1) / det_A

# Solve for x2 (Replace col 1 with b)
A2 = A.copy()
A2[:, 1] = b
x2 = np.linalg.det(A2) / det_A

print(f"Solution: x = [{x1:.2f}, {x2:.2f}]")

# Check using solver
print(f"NumPy Solve: {np.linalg.solve(A, b)}")

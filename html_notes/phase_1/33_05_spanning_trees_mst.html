Spanning Trees & MST

Minimal Connectivity. Extracting the most efficient skeleton from a complex network to connect all nodes with minimum total edge weight.

The Spanning Concept

A Spanning Tree of a graph \(G\) is a subgraph that includes all vertices and is a tree. A graph can have many spanning trees, but in a Weighted Graph, we are often looking for the Minimum Spanning Tree (MST) — the one with the smallest sum of edge weights.

1. MST Algorithms

Kruskal's Algorithm

A Greedy approach: Sort all edges by weight and add them to the MST as long as they don't create a cycle (using Disjoint Set Union).

Prim's Algorithm

Starts from a single node and grows the tree by adding the cheapest edge that connects a node in the tree to one outside of it.

2. Cayley's Formula

How many spanning trees exist in a complete graph \(K_n\)?

$$ T(K_n) = n^{n-2} $$

Example: For \(n=4\), there are \(4^{4-2} = 16\) unique spanning trees. This explosive growth shows why greedy optimization is necessary.

Unsupervised Learning NLP

MST in AI

  • Single Linkage Clustering: When performing Hierarchical Clustering, the sequence of merges is exactly the order of edges added in Kruskal's MST algorithm.
  • Image Segmentation: Treating pixels as nodes and spectral differences as edge weights, MST algorithms are used to find "natural" boundaries and regions in an image.
  • Taxonomy Generation: In NLP, given a set of concepts and their semantic distances, an MST can discover the most "efficient" logical hierarchy between them.
  • Communication Efficiency: In Distributed ML (Federated Learning), gradients are often aggregated along an MST of the nodes to minimize network latency and bandwidth.

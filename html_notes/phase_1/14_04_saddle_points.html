Optimization 1.7 The Trap

Saddle Points in High Dimensions

Why optimizers get stuck in the flatlands, and how to escape.

The Geometry

A Saddle Point is a critical point that curvature "up" in some directions and "down" in others. The classic example is the Monkey Saddle: \(z = x^3 - 3xy^2\).

In 2D, they are rare. In 1,000,000 dimensions (Deep Learning), they are everywhere. Probability suggests that if you have 1B random directions, ~500M will curve up and ~500M will curve down. Finding a pure local minimum (where ALL directions curve up) is extremely unlikely until you are very close to the true solution.

2. AI/ML Connection: Escaping Saddles

Why SGD Works

If you are exactly at a saddle point, the gradient is 0. A deterministic optimizer stays there forever. However, Stochastic Gradient Descent (SGD) uses random mini-batches, which adds Noise to the gradient.

This noise kicks the ball sideways. Since a saddle point curves *down* in at least one direction, that random kick will causing the ball to "fall off" the saddle and continue optimizing. This is why small batch sizes often generalize better—they provide more "kicking".

3. Python: Visualization

saddle_viz.py
import numpy as np
import matplotlib.pyplot as plt

# Monkey Saddle
def monkey_saddle(x, y):
    return x**3 - 3*x*y**2

x = np.linspace(-2, 2, 50)
y = np.linspace(-2, 2, 50)
X, Y = np.meshgrid(x, y)
Z = monkey_saddle(X, Y)

fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')
ax.plot_surface(X, Y, Z, cmap='plasma', alpha=0.9)
ax.set_title("Monkey Saddle (Degenerate)")

# Note: Hessian at (0,0) is all zeros!

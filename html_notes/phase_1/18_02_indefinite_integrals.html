02. Indefinite Integrals

The operator symbol for reconstruction.

1. Notation & Vocabulary

The notation \(\int f(x) dx\) is used to denote the set of all antiderivatives of \(f(x)\). It is called an indefinite integral.

  • \(\int\): The integral sign (a stretched "S" for Sum).
  • \(f(x)\): The integrand (the function being integrated).
  • \(dx\): The differential (indicating the variable of integration).
  • \(F(x) + C\): The result.

2. The Identity Relationship

Integration and Differentiation are inverse operations. If you integrate a function and then differentiate the result, you get the original function back:

$$ \frac{d}{dx} \left[ \int f(x) dx \right] = f(x) $$

3. AI/ML Connection: Continuous Expected Value

Integrating for Averages

In classical statistics, the "Average" (Expectation) of a discrete set of numbers is a sum. But for continuous variables (like "Height" or "Stock Price"), the expected value is an integral:

$$ E[X] = \int x \cdot p(x) dx $$

Where \(p(x)\) is the probability density. To calculate the most likely prediction for a model that outputs continuous values, AI libraries must perform this integration either symbolically or numerically.

4. Python: Evaluating Indefinite Integrals

import sympy as sp

x = sp.Symbol('x')
integrand = sp.sin(x) + x**2

# Compute integral
ind_integral = sp.integrate(integrand, x)

print(f"Integral of {integrand} is: {ind_integral} + C")
# Output: -cos(x) + x**3/3 + C

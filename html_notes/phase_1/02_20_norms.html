1. The Formula

The general \( L_p \) norm is defined as:

$$ ||\mathbf{x}||_p = \left( \sum_{i=1}^n |x_i|^p \right)^{1/p} $$
  • L1 (Taxicab): Sum of absolute values. \( |x| + |y| \).
  • L2 (Euclidean): Straight line distance. \( \sqrt{x^2 + y^2} \).
  • L0 (Pseudo-norm): Count of non-zero elements.

2. Sparsity vs Decay

In Machine Learning loss functions:

$$ L = Error + \lambda ||\mathbf{w}|| $$

If we use L1 Regularization (Lasso), the "Diamond" shape of the unit ball forces coefficients to hit exactly zero. This performs Feature Selection (Sparsity).

If we use L2 Regularization (Ridge), the "Circle" shape just shrinks weights small but rarely zero.

3. Calculating Norms

Using NumPy to measure vectors.

import numpy as np

v = np.array([3, -4])

# L1 Norm: |3| + |-4| = 7
l1 = np.linalg.norm(v, 1)
print(f"L1 Norm: {l1}")

# L2 Norm: sqrt(9 + 16) = 5
l2 = np.linalg.norm(v, 2)
print(f"L2 Norm: {l2}")

# L-Infinity: max(|3|, |-4|) = 4
linf = np.linalg.norm(v, np.inf)
print(f"L-Inf Norm: {linf}")

# Custom L0
l0 = np.count_nonzero(v)
print(f"L0 Norm: {l0}")

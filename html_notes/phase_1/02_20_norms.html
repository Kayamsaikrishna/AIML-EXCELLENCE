20. Norms (L1, L2, p-norms)

Defining "Size" and "Distance".

1. Common p-Norms

A norm is a function that assigns a strictly positive length or size to all vectors.

$$ L_p \text{ Norm: } \|\mathbf{v}\|_p = \left( \sum_{i=1}^n |v_i|^p \right)^{1/p} $$
  • L1 Norm (Manhattan): \( \sum |v_i| \). Encourages Sparsity.
  • L2 Norm (Euclidean): \( \sqrt{\sum v_i^2} \). The standard "as-the-crow-flies" distance.
  • L-infinity Norm: \( \max |v_i| \). Used in Chebyshev distance and adversarial robustness.

2. AI Regularization (Lasso vs. Ridge)

Shape of the Constraint

In Weight Regularization, we add the norm of the weights to the loss function to prevent over-fitting.

  • L1 Regularization (Lasso): The "diamond" shape forces some weights to be exactly zero, effectively performing Feature Selection.
  • L2 Regularization (Ridge): The "circle" shape makes weights small but usually non-zero.

3. Python: Vector Norms with Numpy

import numpy as np

v = np.array([3, -4])

# L1 Norm (3 + 4)
norm_l1 = np.linalg.norm(v, ord=1) 

# L2 Norm (sqrt(9 + 16))
norm_l2 = np.linalg.norm(v, ord=2)

# Max Norm (4)
norm_inf = np.linalg.norm(v, ord=np.inf)

print(f"L1: {norm_l1}, L2: {norm_l2}, Inf: {norm_inf}")

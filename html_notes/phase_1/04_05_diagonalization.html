05. Diagonalization

Decoupling a matrix into its prime components.

1. The Factorization

A matrix \(\mathbf{A}\) is Diagonalizable if it can be written as:

$$ \mathbf{A} = \mathbf{PDP}^{-1} $$

Where:

  • \(\mathbf{P}\): A matrix whose columns are the eigenvectors of \(\mathbf{A}\).
  • \(\mathbf{D}\): A diagonal matrix whose entries are the corresponding eigenvalues.

2. Why AI engineers love Diagonalization

Decoupling Features

Imagine a system where variables depend on each other (e.g., height depends on age). Diagonalization changes our coordinate system to a "Latent Space" where all variables are independent. This is the mathematical core of Principal Component Analysis (PCA).

Computing Powers

Calculating \(\mathbf{A}^{100}\) is hard. But:

$$ \mathbf{A}^{100} = (\mathbf{PDP}^{-1})^{100} = \mathbf{P}\mathbf{D}^{100}\mathbf{P}^{-1} $$

Raising a diagonal matrix to a power just means raising its individual diagonal elements! This makes iterative AI processes (like infinite Markov Chains) solvable instantly.

3. Python: Performing Diagonalization

import numpy as np

A = np.array([[1, 2], [2, 1]])

# Get Eigenvalues (D) and Eigenvectors (P)
D_vals, P = np.linalg.eig(A)
D = np.diag(D_vals)

# Reconstruct A
A_reconstructed = P @ D @ np.linalg.inv(P)

print(f"Original A:\n{A}")
print(f"Reconstructed A:\n{A_reconstructed}")
print(f"All close? {np.allclose(A, A_reconstructed)}")

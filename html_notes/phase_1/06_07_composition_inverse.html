1. Composition

Composing two linear transformations \( T \) and \( S \) corresponds to multiplying their matrices.

$$ (S \circ T)(x) = S(T(x)) \iff (BA)x $$

Order matters! \( BA \neq AB \) (usually). Applying rotation then shear is different from shear then rotation.

2. The Chain Rule

A Deep Neural Network is just a composition of many functions: \( f(x) = f_L(... f_2(f_1(x))...) \).

When computing gradients (Backpropagation), we use the chain rule for derivatives, which involves multiplying the Jacobians (matrices of partial derivatives) of each layer in reverse order. This is directly analogous to \( (BA)^{-1} = A^{-1} B^{-1} \).

3. Matrix multiplication as Composition

import numpy as np

# T1: Scale by 2 (Matrix A)
A = np.diag([2, 2])

# T2: Rotate 90 deg (Matrix B)
B = np.array([[0, -1], [1, 0]])

# Composition T2(T1(x)) -> B(Ax) -> (BA)x
BA = B @ A
AB = A @ B

print("BA (Scale then Rotate):\n", BA)
print("AB (Rotate then Scale):\n", AB)
# In this specific case (diagonal scaling + rotation), they commute
# only because the scaling is uniform (scalar matrix).

# Invert
BA_inv = np.linalg.inv(BA)
# Check Identity
print("\nIdentity Check:", (BA_inv @ BA).round(1))

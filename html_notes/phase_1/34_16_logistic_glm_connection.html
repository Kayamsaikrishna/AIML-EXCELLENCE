16. Logistic Regression as a GLM

The bridge between regression and classification.

1. Predicting 0 or 1

Standard regression for a binary outcome ($Y \in \{0, 1\}$) fails because it can predict impossible values (e.g., -0.5 or 1.2). Logistic Regression** solves this by using the **Logit Link Function** ($g(p) = \ln(\frac{p}{1-p})$).

2. The Probability Squash

The inverse of the logit link is the Sigmoid Function:

$$ P(Y=1|X) = \frac{1}{1 + e^{-X\beta}} $$

This ensures that no matter how large the input $X\beta$ gets, the output stays between 0 and 1. We model the **Log-Odds** as a linear function of $X$.

3. AI/ML Connection: The Logistic Neuron

The Binary Gate

In AI, the Logistic GLM is the Most Widely Used Classifier in History**.

From **Credit Scoring** to **Disease Screening**, Logistic units provide the "Probability of success." In Natural Language Processing (NLP)**, the final layer of a sentiment analyzer is typically a Logistic GLM. It also explains the "Internal Logic" of Logistic Units in LSTMs/GRUs**: by using a Sigmoid gate, the AI decides how much of the previous memory to "Forget" (0.1) or "Keep" (0.9). Understanding Logistic Regression as a GLM is the key to jumping from continuous estimation to discrete decision-making. It is the fundamental building block of **Probabilistic ML**.

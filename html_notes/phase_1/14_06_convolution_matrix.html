06. Convolution as Matrix Multiplication

The hidden linear structure of CNNs.

1. The Sliding Window Problem

Convolution involves sliding a kernel \(\mathbf{K}\) over an image \(\mathbf{I}\). While programmatically implemented as nested loops (or vectorized slices), mathematically it is a Linear Transformation.

2. Toeplitz Matrices

For a 1D convolution, the kernel can be rearranged into a Toeplitz Matrix \(\mathbf{C}\). The convolution output is then simply \(\mathbf{y} = \mathbf{C}\mathbf{x}\).

$$ \begin{bmatrix} y_1 \\ y_2 \\ y_3 \end{bmatrix} = \begin{bmatrix} w_1 & w_0 & 0 \\ w_2 & w_1 & w_0 \\ 0 & w_2 & w_1 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} $$

In 2D (Images), this becomes a Doubly Block Toeplitz matrix.

3. AI Insight: Efficiency

Why don't we use Toeplitz matrices in code? Sparsity. A Toeplitz matrix for a \(224\times 224\) image would be astronomical in size. CNNs are efficient because they exploit the fact that this matrix is mostly zeros and has highly repetitive structure (Weight Sharing).

4. Python: im2col Transformation

Modern libraries use the `im2col` trick to turn convolution into a dense GEMM (General Matrix Multiply). 

import numpy as np

def convolution_as_matrix(input_vec, kernel):
    # Simple 1D Example
    n = len(input_vec)
    k = len(kernel)
    # Construct Toeplitz
    from scipy.linalg import toeplitz
    # Pad kernel with zeros to match dimension
    padding = np.zeros(n - k)
    c = np.concatenate([kernel, padding])
    r = np.zeros(n)
    r[0] = kernel[0]
    
    C = toeplitz(c, r)
    return C @ input_vec

x = np.array([1, 2, 3, 4])
k = np.array([1, -1]) # Edge detector

print(f"Convolution Output:\n{convolution_as_matrix(x, k)}")

Graph Theory Topology

Graph Definitions & Types

Modeling Relationships. A mathematical structure consisting of vertices and edges, bridging the gap between discrete objects and complex networks.

The Language of Networks

A Graph \(G = (V, E)\) is a collection of Vertices (nodes) and Edges (connections). While sets define *what* we have, and combinatorics defines *how many ways* we can arrange them, Graph Theory defines the *interaction* between them.

1. Formal Definition

$$ G = (V, E) $$
  • \(V\): A non-empty set of vertices (nodes).
  • \(E\): A set of edges (links) connecting pairs of vertices.

Order & Size

The Order of a graph is the number of vertices \(|V|\). The Size is the number of edges \(|E|\).

Degree \(d(v)\)

The number of edges connected to a vertex \(v\). The sum of all degrees is \(2|E|\) (Handshaking Lemma).

2. Common Graph Types

Simple Graph

No loops (an edge from \(v\) to \(v\)) and no multiple edges between the same two nodes.

Directed Graph (Digraph)

Edges have a direction (\(u \to v\) is different from \(v \to u\)). Essential for causality and flow.

Weighted Graph

Every edge has a numerical weight (cost, distance, strength). Foundation for neural network weights.

Complete Graph (\(K_n\))

Every vertex is connected to every other vertex. Order \(n\) has \(\binom{n}{2}\) edges.

Deep Learning NLP

The Graph Paradigm in AI

  • Knowledge Graphs: Representing facts and entities (Entities as Nodes, PREDICATES as Edges). Used by Google Search and LLMs to ground knowledge.
  • Neural Network Architecture: A Feedforward Neural Network is a **Directed Acyclic Graph (DAG)** of operations. Backpropagation calculates gradients along the edges of this graph.
  • Graph Neural Networks (GNNs): Models that operate directly on graph-structured data (molecules, social networks, recommendation systems) by passing "messages" along edges.
  • Markov Chains: A probabilistic model represented as a directed graph where edges are transition probabilities.

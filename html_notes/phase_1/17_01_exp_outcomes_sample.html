Prob 1.4 The Universe

Outcomes & Sample Spaces

Defining the set of all possibilities.

The Experiment

In Probability, an Experiment is any process with an uncertain result (e.g., rolling a die, training a model).

The Sample Space (\(\Omega\)) is the set of all possible outcomes.

  • Discrete: Coin flip \(\Omega = \{H, T\}\).
  • Continuous: Temperature \(\Omega = \mathbb{R}\).

2. ML Connection: The Latent Space

High-Dimensional Spaces

In Generative AI (GANs, VAEs), the sample space \(\Omega\) is the "Latent Space" (usually a high-dimensional box or sphere). Every point \(z \in \Omega\) corresponds to a possible image the model can generate.

Sampling from this space effectively means picking a random "possibility" from the universe of all images.

3. Python: Sampling

sample_space.py
import numpy as np

# Discrete Sample Space (Die Roll)
omega_discrete = [1, 2, 3, 4, 5, 6]
outcome = np.random.choice(omega_discrete)
print(f"Discrete Outcome: {outcome}")

# Continuous Sample Space (Uniform [0, 1])
# Omega = All real numbers between 0 and 1
omega_continuous = np.random.uniform(0, 1)
print(f"Continuous Outcome: {omega_continuous:.4f}")

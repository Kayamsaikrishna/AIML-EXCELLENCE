15. SVD Applications

The Swiss-Army Knife of Numeric AI.

1. Collaborative Filtering (Recommender Systems)

Imagine a User-Movie rating matrix. It's mostly empty (Sparse). SVD can decompose this into "User Features" and "Movie Features" (Latent Space). By multiplying them back, we predict the missing ratings.

$$ \text{Rating}_{ij} \approx \text{Profile}_i \cdot \text{Features}_j $$

This was the winning strategy for the original Netflix Prize.

2. Image Denoising

A natural image has a structure that is captured by the first few singular values. Experimental noise is random and distributed across all singular values. By reconstructing the image using only the top \(k\) values, the noise is mathematically removed.

3. Stability in Control Systems

In Robotics, the Condition Number (ratio of max to min singular values) tells us if a robotic arm is near a "Singularity" where it might behave uncontrollably. SVD is the primary tool for this health check.

4. Python: Singular Value Decay

Visualizing why truncation works (The "Elite 20%" rule):

import numpy as np
import matplotlib.pyplot as plt

# Simulate rank-deficient data with some noise
A = np.dot(np.random.rand(100, 5), np.random.rand(5, 100)) + 0.1*np.random.rand(100, 100)

U, s, Vt = np.linalg.svd(A)

# Observe the decay
# You will see the first 5 values are much larger than the noise
print(f"Top 10 Singular Values: {np.round(s[:10], 2)}")

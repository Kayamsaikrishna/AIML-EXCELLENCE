1. Image Compression

An image is a matrix of pixels. We can compute its SVD and keep only the top \( k \) singular values.

Instead of storing \( n \times n \) pixels, we store \( k(2n+1) \) numbers. For large \( n \) and small \( k \), this is massive savings.

2. Netflix Prize

The famous solution to the Netflix Prize involved SVD-like Matrix Factorization.

Users and Movies are projected into a latent "Taste Space". If User vector aligns with Movie vector (high dot product), they will likely enjoy it.

3. Image Compression Code

import numpy as np
import matplotlib.pyplot as plt

# Create a synthetic image (gradients)
img = np.zeros((100, 100))
for i in range(100):
    for j in range(100):
        img[i, j] = np.sin(i/10) + np.cos(j/20)

# Compute SVD
U, S, Vt = np.linalg.svd(img)

# Reconstruct using top 5 components
k = 5
Recon = U[:, :k] @ np.diag(S[:k]) @ Vt[:k, :]

correlation = np.corrcoef(img.flat, Recon.flat)[0, 1]
print(f"Original Rank: 100")
print(f"Compressed Rank: {k}")
print(f"Correlation: {correlation:.4f}")
# High correlation despite 95% data reduction (in rank terms)

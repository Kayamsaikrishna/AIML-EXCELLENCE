25. Series (Summing to Infinity)

When does an infinite list equal a finite number? The magic of Convergence.

1. Geometric Series

$$ S = \sum_{k=0}^{\infty} ar^k = \frac{a}{1-r} \quad \text{if } |r| < 1 $$

Interpretation

If you keep adding smaller and smaller pieces, you eventually stop moving forward essentially. You hit a limit.

2. Reinforcement Learning

In RL (like training an AI to play Chess), we care about the "Total Future Reward".

The Problem: The game might go on forever. The sum would be infinity.

The Fix: We multiply future rewards by a discount factor \( \gamma \) (usually 0.99). This turns the problem into a convergent Geometric Series.

$$ G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \dots $$

3. Calculating Returns

Computing the discounted return for an episode.

// Python: Discounted Return Calculation
import numpy as np

def calculate_return(rewards, gamma=0.99):
    """
    Computes G_t for a single time step t=0.
    """
    G = 0
    power_of_gamma = 1.0
    
    for r in rewards:
        G += r * power_of_gamma
        power_of_gamma *= gamma
        
    return G

# Example: AI gets +1 reward for 100 steps
rewards = [1] * 100 
finite_return = calculate_return(rewards)

print(f"Total Undiscounted: {sum(rewards)}") # 100
print(f"Total Discounted (γ=0.99): {finite_return:.2f}") 
# Output: ~63.4 (Even if calculating to infinity, it would cap at 1/(1-0.99) = 100)

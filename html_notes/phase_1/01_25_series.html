1. Convergence vs Divergence

A Series is the sum of a Sequence. \( S = \sum a_n \).

  • Convergent: Sums to a finite number (e.g., \( 1 + 1/2 + 1/4 + \dots = 2 \)).
  • Divergent: Sums to infinity (e.g., \( 1 + 1 + 1 + \dots \)).

In AI, we need our Loss Function to Converge to 0 (or a minimum). If it Diverges (Exploding Loss), training fails.

2. Taylor Series: The Engine of Calculus

Any smooth function can be rewritten as an infinite polynomial.

$$ f(x) \approx f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 $$

Optimization Insight

Gradient Descent is basically approximating the Loss Landscape as a flat plane (First Order Taylor Series) and taking a step downhill.

3. Approximating e^x

Computing exponential growth using simple addition/multiplication.

import math

def taylor_exp(x, terms=10):
    # e^x = 1 + x + x^2/2! + x^3/3! + ...
    sum_val = 0
    for n in range(terms):
        term = (x ** n) / math.factorial(n)
        sum_val += term
    return sum_val

x_val = 1.0
approx = taylor_exp(x_val, 10)
true_val = math.exp(x_val)

print(f"Approximation (10 terms): {approx}")
print(f"True Value: {true_val}")
# They are nearly identical!

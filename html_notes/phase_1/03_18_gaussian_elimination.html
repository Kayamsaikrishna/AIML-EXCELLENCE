18. Gaussian Elimination

The algorithm for systematic problem solving.

1. The Forward Pass

Gaussian elimination converts a matrix into Row Echelon Form (REF) using three elementary operations:

  • Swap: Interchange two rows.
  • Scale: Multiply a row by a non-zero constant.
  • Add: Add a multiple of one row to another.

Once in REF, we use Back Substitution to find the solution to \( \mathbf{Ax} = \mathbf{b} \).

2. Hardware & AI Performance

Numerical Stability: Pivoting

When computers do Gaussian elimination, if a pivot is very small, rounding errors become massive. AI libraries use Partial Pivoting—swapping rows to make sure the largest possible number is used as the pivot.

  • Complexity: \( O(n^3) \). Too slow for giant networks, but the backbone of numerical solvers.

3. Python: Step-by-Step Elimination

import numpy as np

def gaussian_elimination(A, b):
    n = len(b)
    # Augmented Matrix
    Ab = np.hstack([A, b.reshape(-1, 1)]).astype(float)
    
    for i in range(n):
        # Pivoting (Find max in column)
        max_row = i + np.argmax(np.abs(Ab[i:, i]))
        Ab[[i, max_row]] = Ab[[max_row, i]]
        
        # Eliminate below
        for j in range(i + 1, n):
            factor = Ab[j, i] / Ab[i, i]
            Ab[j, i:] -= factor * Ab[i, i:]
            
    return Ab

A = np.array([[3, 2], [1, 2]])
b = np.array([1, 8])
ref = gaussian_elimination(A, b)
print(f"Augmented REF:\n{ref}")

1. Elementary Row Operations

Gaussian Elimination uses three "Legal Moves" that do not change the solution set:

  1. Swap: Interchange two rows.
  2. Scale: Multiply a row by a non-zero constant.
  3. Add: Add a multiple of one row to another.

2. It's just LU

If we keep track of the multipliers we used to eliminate rows, we get the Lower Triangular Matrix \( L \).

The final Upper Triangular result is \( U \).

Thus, Gaussian Elimination is simply: \( A = LU \).

3. Manual Elimination

Step-by-step reduction.

import numpy as np

A = np.array([
    [2.0, 1.0, 1.0],
    [4.0, -6.0, 0.0],
    [-2.0, 7.0, 2.0]
])
# Augmented with b? No, let's just do A -> U

# Step 1: Eliminate Col 0 below Pivot A[0,0]
# Row 1 = Row 1 - (4/2)*Row 0
A[1] = A[1] - (A[1,0]/A[0,0]) * A[0]
# Row 2 = Row 2 - (-2/2)*Row 0
A[2] = A[2] - (A[2,0]/A[0,0]) * A[0]

print("After Step 1:")
print(A)

# Step 2: Eliminate Col 1 below Pivot A[1,1]
# Row 2 = Row 2 - (8/-8)*Row 1 (Assuming A[1,1] became -8)
factor = A[2,1]/A[1,1]
A[2] = A[2] - factor * A[1]

print("\nAfter Step 2 (Upper Triangular U):")
print(A)

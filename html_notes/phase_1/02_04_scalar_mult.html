04. Scalar Multiplication

Stretching and shrinking the feature space.

1. Definition

Multiplying a vector \(\mathbf{v}\) by a scalar \(c\) changes its magnitude but usually maintains (or reverses) its direction.

$$ c \mathbf{v} = \begin{bmatrix} c v_1 \\ c v_2 \end{bmatrix} $$

2. Optimization & Learning Rates

Scaling the Gradient

In Gradient Descent, we calculate the gradient vector \(\nabla L\), but we don't take a full step in that direction. We multiply it by a Learning Rate (\(\eta\)).

  • Scalar Multiplication: The update step is \(\Delta w = \eta \cdot \nabla L\).
  • Gradient Clipping: If the magnitude is too large, we use a scalar \(c < 1\) to shrink the vector and prevent "Exploding Gradients" .

3. Python: Feature Scaling

import numpy as np

features = np.array([45000, 3, 22]) # [Salary, Age, Experience]

# Scaling down by a factor to normalize
scale_factor = 1/features.max()
normalized_features = features * scale_factor

print(f"Original: {features}")
print(f"Normalized: {normalized_features}")

18. The Link: PCA vs SVD

Two paths to the same latent space.

1. The Mathematical Link

Why do all professional libraries (like Scikit-Learn) use SVD to compute PCA instead of the Covariance matrix method?

Recall the SVD of \(\mathbf{X}\): \(\mathbf{X} = \mathbf{U}\Sigma\mathbf{V}^T\).

The Covariance Matrix \(\mathbf{S}\) is:

$$ \mathbf{S} = \frac{\mathbf{X}^T\mathbf{X}}{n-1} = \frac{(\mathbf{U}\Sigma\mathbf{V}^T)^T(\mathbf{U}\Sigma\mathbf{V}^T)}{n-1} = \frac{\mathbf{V}\Sigma^T\mathbf{U}^T\mathbf{U}\Sigma\mathbf{V}^T}{n-1} $$ $$ \mathbf{S} = \mathbf{V} \left( \frac{\Sigma^2}{n-1} \right) \mathbf{V}^T $$

Comparing this to the Eigendecomposition of \(\mathbf{S}\) (\(\mathbf{S} = \mathbf{P}\Lambda\mathbf{P}^T\)):

  • Principal Components: Are the columns of \(\mathbf{V}\) (Right singular vectors).
  • Eigenvalues: Are related to Singular values by \(\lambda_i = \frac{\sigma_i^2}{n-1}\).

2. Why SVD is Superior

Avoid the Square

Computing \(\mathbf{X}^T\mathbf{X}\) squares the Condition Number of the data. If your data is poorly conditioned, \(\mathbf{X}^T\mathbf{X}\) becomes extremely sensitive to precision errors. SVD works directly on \(\mathbf{X}\), preserving numeric precision.

3. Python: Proving the Link

import numpy as np

X = np.random.randn(50, 5) # 50 samples, 5 features
X_centered = X - np.mean(X, axis=0)

# Method 1: Covariance
S = np.dot(X_centered.T, X_centered) / (50 - 1)
eigenvals, eigenvects = np.linalg.eigh(S)

# Method 2: SVD
U, s, Vt = np.linalg.svd(X_centered)

# Compare Singular vectors vs Eigenvectors
# (Note: directions might be inverted, so take absolute)
print(f"Match PC directions? {np.allclose(np.abs(Vt.T), np.abs(eigenvects[:, ::-1]))}")

# Compare eigenvalues vs singular values^2 / (n-1)
print(f"Match Spectrum? {np.allclose(eigenvals[::-1], (s**2)/(50-1))}")

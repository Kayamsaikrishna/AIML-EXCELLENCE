PCA on Data Matrix

Don't compute the Covariance Matrix. Use SVD directly on X.

1. The Connection

If we apply SVD to the centered data \( X = U \Sigma V^T \):

$$ X^T X = (V \Sigma U^T) (U \Sigma V^T) = V \Sigma^2 V^T $$

This shows that the Right Singular Vectors \( V \) of \( X \) are identically the Eigenvectors of the covariance matrix \( X^T X \).

2. Why SVD?

Computing \( X^T X \) squares the condition number, effectively destroying numerical precision. SVD works directly on \( X \), maintaining higher precision.

Furthermore, standard libraries (like Scikit-Learn's PCA) implementation use randomized SVD to solve this efficiently.

3. Sklearn's Secret

import numpy as np

# Centered Data X
X = np.array([
    [-1, -1],
    [-2, -1],
    [-3, -2],
    [1, 1],
    [2, 1],
    [3, 2]
])

# Method 1: Eigen of Covariance
cov = np.cov(X.T)
val, vec = np.linalg.eig(cov)
# Note: eig doesn't sort by default

# Method 2: SVD of X
U, S, Vt = np.linalg.svd(X)

print(f"Eigenvectors from Cov (Column 0):\n{vec[:,0]}")
print(f"Singular Vectors from SVD (Row 0 of Vt):\n{Vt[0,:]}")

# Check magnitude
print(f"\nEigenvalue[0]: {val[0]:.4f}")
print(f"SingularValue[0]^2 / (N-1): {S[0]**2 / (X.shape[0]-1):.4f}")
# Matches exactly!

Subsets, Power Sets & Cardinality

Worlds within Worlds. Understanding the hierarchical structure of collections and how the size of a set dictates the complexity of its internal relationships.

The Container Logic

A set isn't just a list; it's a boundary. Subsets define smaller boundaries within that set. Power Sets build a universe out of those boundaries. Cardinality tells us how crowded that universe is.

1. Subsets (\(\subseteq\))

\(A\) is a subset of \(B\) if every element of \(A\) is also in \(B\).

\( A \subseteq B \iff \forall x (x \in A \rightarrow x \in B) \)

Proper Subset (\(\subset\))

\(A\) is inside \(B\), but \(A\) is not equal to \(B\). There's at least one element in \(B\) that isn't in \(A\).

Identity

Every set is a subset of itself. The Empty set \(\varnothing\) is a subset of every set.

2. Cardinality (\(|A|\))

The "size" or number of elements in a set. For a finite set, it is a non-negative integer.

$$ A = \{a, b, c, d\} \rightarrow |A| = 4 $$ $$ |\varnothing| = 0 $$

3. The Power Set (\(\mathcal{P}(A)\))

The set of all possible subsets of \(A\). This is the key to understanding complexity and combinations.

$$ A = \{1, 2\} \rightarrow \mathcal{P}(A) = \{\varnothing, \{1\}, \{2\}, \{1, 2\}\} $$

The \(2^n\) Rule

If \(|A| = n\), then the number of elements in the Power Set is \(2^n\).

Intuition: For every element, you have 2 choices: Include it or Exclude it.

Feature Engineering Complexity

Why Power Sets matter in ML

  • Feature Selection (Wrapper Methods): If you have \(n\) features and you want to find the "best" subset, you are searching through the Power Set of features. Since there are \(2^n\) subsets, this is why greedy algorithms like "Forward Selection" are needed (searching the whole power set is impossible for \(n > 30\)).
  • Market Basket Analysis: Retailers look for "Frequent Itemsets." They are essentially searching the power set of all products in the store to find combinations that appear together often.
  • Model Complexity: The VC-Dimension (a measure of model capacity) is related to how many subsets of a point cloud the model can "shatter" (separate). A model that can shatter all \(2^n\) subsets has very high capacity.

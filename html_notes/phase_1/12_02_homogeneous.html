02. Homogeneous Systems

Solving systems set to zero.

1. The Definition

A system is Homogeneous if it can be written as:

$$ \mathbf{Ax} = \mathbf{0} $$

A system is Non-homogeneous if the right side is non-zero: \(\mathbf{Ax} = \mathbf{b}\).

2. The Trivial Solution

Homogeneous systems are always consistent because \(\mathbf{x} = \mathbf{0}\) is always a solution (the Trivial Solution).

The system has Non-trivial solutions if and only if \(\mathbf{A}\) has Free Variables (i.e., \(\mathbf{A}\) is singular/not full rank).

3. AI Connection: PCA and Null Space

The Kernel

The set of all solutions to \(\mathbf{Ax} = \mathbf{0}\) is the Null Space of \(\mathbf{A}\). In dimensionality reduction, vectors in the null space represent information that is completely discarded by the transformation \(\mathbf{A}\).

4. Python: Finding the Null Space

import numpy as np
from scipy.linalg import null_space

A = np.array([[1, 2, 3], [2, 4, 6]]) # Linearly dependent rows

# Find basis for the null space
ns = null_space(A)

print(f"Null Space Basis:\n{ns}")
# Verify: A @ x should be ~ 0
print(f"Verification:\n{np.round(A @ ns, 10)}")

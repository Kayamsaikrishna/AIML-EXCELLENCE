01. Power, Sum, and Difference Rules

The foundational mechanics of differentiation.

1. The Power Rule

For any real number \(n\):

$$ \frac{d}{dx} x^n = nx^{n-1} $$

This simple rule allows us to differentiate any polynomial instantly.

2. Linearity of the Derivative

The derivative is a Linear Operator. This means it respects addition and scalar multiplication:

  • Sum/Diff Rule: \(\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)\)
  • Constant Multiplier: \(\frac{d}{dx}[c \cdot f(x)] = c \cdot f'(x)\)

3. AI Connection: Gradient Descent in Linear Models

In Simple Linear Regression with MSE loss \(L(w) = (y - wx)^2\), we expand this to \(y^2 - 2ywx + w^2x^2\). Applying the Power Rule and Linearity: $$ \frac{\partial L}{\partial w} = 0 - 2yx + 2wx^2 = -2x(y - wx) $$ This derivative tells the model how to adjust the weight \(w\). Basic rules are the "engine" under the hood of every optimization step.

4. Python: Numerical vs Symbolic Diff

import sympy as sp

x = sp.Symbol('x')
f = 4*x**3 + 2*x**2 - 5*x + 10

# Symbolic derivative
df = sp.diff(f, x)
print(f"f(x)  = {f}")
print(f"f'(x) = {df}")

# Numerical approximation at x=1
def f_num(x): return 4*x**3 + 2*x**2 - 5*x + 10
h = 1e-7
df_num = (f_num(1 + h) - f_num(1)) / h
print(f"Numerical f'(1) ≈ {df_num:.4f}")

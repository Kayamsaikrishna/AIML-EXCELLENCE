06. Over & Underdetermined Systems

Constraint counting in higher dimensions.

1. Overdetermined Systems

When you have more equations than unknowns (\(m > n\)).

  • Typical state: Inconsistent (No perfect solution).
  • Strategy: Least Squares (find the "best fit").
  • AI Example: Training a model with 1,000,000 data points but only 10,000 parameters.

2. Underdetermined Systems

When you have fewer equations than unknowns (\(m < n\)).

  • Typical state: Infinite solutions.
  • Strategy: Min-norm solution (find the "simplest" solution).
  • AI Example: Modern Deep Learning where number of parameters \(>>\) number of data points.

3. Determinacy Table

Type Shape Solutions (Typical) ML Context
Determined Square (\(m=n\)) 1 Unique Exact Interpolation
Overdetermined Tall (\(m>n\)) 0 (Inconsistent) Compression/Regression
Underdetermined Wide (\(m \(\infty\) Solutions Over-parameterized Models

4. Python: Min-Norm Solution

For underdetermined systems, we often want the solution with the smallest length \(\|\mathbf{x}\|_2\). 

import numpy as np

# System: x + y + z = 10 (1 equation, 3 unknowns)
A = np.array([[1, 1, 1]])
b = np.array([10])

# Using Pseudoinverse gives the min-norm solution
x_min_norm = np.linalg.pinv(A) @ b

print(f"Min-norm solution: {x_min_norm}")
# Result ensures equal distribution [3.33, 3.33, 3.33]

03. Backpropagation Derivation

Assigning blame for error through the layers.

1. What is Backpropagation?

Backpropagation is the algorithm used to calculate the gradient of a loss function with respect to the weights of a neural network. It is simply an efficient implementation of the Multivariable Chain Rule.

2. The Core Derivation

For a weight \(w_{jk}^l\) connecting node \(k\) in layer \(l-1\) to node \(j\) in layer \(l\), the gradient is:

$$ \frac{\partial L}{\partial w_{jk}^l} = \frac{\partial L}{\partial a_j^l} \cdot \frac{\partial a_j^l}{\partial z_j^l} \cdot \frac{\partial z_j^l}{\partial w_{jk}^l} $$

Where:

  • \(L\) is the Loss.
  • \(z_j^l\) is the weighted input.
  • \(a_j^l = \sigma(z_j^l)\) is the activation.

3. AI/ML Connection: Blame Assignment

Gradient Flow

The "Blame Assignment" problem asks: "If the model got an answer wrong, which weight is most responsible?"

Calculus answers this through partial derivatives. Backpropagation starts at the output, calculates the error, and "propagates" it backward. A weight with a high partial derivative is a weight that, if nudged slightly, would significantly change the loss. The AI uses this mathematical "signal" to prioritize which weights to update most aggressively. Backpropagation is the reason neural networks can learn from complex data; it provides a mathematically rigorous way to update millions of parameters simultaneously based on a single error signal.

4. Python: Manual Backprop Step

# Simple Forward: z = w*x + b, a = sigmoid(z)
# Loss: L = (a - y)^2

# 1. dL/da = 2 * (a - y)
# 2. da/dz = a * (1 - a)
# 3. dz/dw = x

delta = dL_da * da_dz
grad_w = delta * dz_dw
grad_b = delta # because dz/db = 1

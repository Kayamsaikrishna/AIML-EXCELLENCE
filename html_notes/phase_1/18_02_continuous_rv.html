Continuous Random Variables

Measuring, not counting.

The Continuum

A Continuous Random Variable takes values from an interval of numbers (e.g., height, time, temperature). \(P(X=x) = 0\) for any specific point \(x\). Instead, we measure the probability of \(X\) falling within a range: \(P(a < X < b)\).

2. ML Connection: Weights and Biases

Model Parameters

The weights \(\theta\) in a Neural Network are continuous variables. In Bayesian Neural Networks, we treat these weights as distributions (usually Gaussian). Since they are continuous, we optimize them using gradients (Calculus). Discrete variables (like Tree nodes) are much harder to optimize because gradients don't exist.

3. Python: Floating Point

continuous_dist.py
import numpy as np
import matplotlib.pyplot as plt

# Generate continuous data (Height in cm)
# Mean=170, Std=10
heights = np.random.normal(170, 10, 1000)

# Probability of exact match is basically 0
exact_170 = np.sum(heights == 170.0)
print(f"Count exactly 170.0: {exact_170}")

# Probability of range [169, 171]
in_range = np.sum((heights > 169) & (heights < 171))
print(f"Count in range: {in_range} ({in_range/1000:.1%})")

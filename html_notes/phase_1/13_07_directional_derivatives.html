Calculus 1.6 Slopes

Directional Derivatives

Slope in any direction.

Beyond X and Y

Partial derivatives (\( f_x, f_y \)) only tell you the slope if you move strictly East or North. What if you want to walk North-East (45°)? The Directional Derivative \( D_{\mathbf{u}}f \) gives the rate of change in the direction of any unit vector \( \mathbf{u} \).

It is simply the dot product of the Gradient and the Direction: \[ D_{\mathbf{u}}f = \nabla f \cdot \mathbf{u} = |\nabla f| |\mathbf{u}| \cos \theta \] Since \( \mathbf{u} \) is a unit vector, this is maximized when \( \cos \theta = 1 \) (moving in gradient direction) and zero when \( \cos \theta = 0 \) (moving along level curve).

2. AI/ML Connection: Adversarial Attacks

Finding the Weakest Spot

In Adversarial Machine Learning, we want to trick a neural network into misclassifying an image (e.g., calling a Panda a Gibbon) by changing the pixels as little as possible.

The attacker calculates the Directional Derivative of the Loss Function with respect to the input pixels. They look for the direction where the error *increases the fastest* (the gradient of the input). By adding a tiny amount of noise in this specific direction (Fast Gradient Sign Method), we can push the image across the decision boundary.

3. Python: Calculating Arbitrary Slopes

directional_slope.py
import numpy as np

# Function: f(x, y) = x^2 * y
# Gradient: <2xy, x^2>
def grad_f(x, y):
    return np.array([2*x*y, x**2])

# Point of interest
x0, y0 = 1, 2

# Direction: vector <3, 4>
v = np.array([3, 4])
# MUST normalize to unit vector u!
u = v / np.linalg.norm(v)

gradient = grad_f(x0, y0) # <4, 1>
slope = np.dot(gradient, u)

print(f"Gradient at (1,2): {gradient}")
print(f"Unit Direction u: {u}")
print(f"Slope (Directional Deriv): {slope}")
# Expected: <4, 1> dot <0.6, 0.8> = 2.4 + 0.8 = 3.2

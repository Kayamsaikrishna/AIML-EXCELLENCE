Calculus 1.3 Rigor

The Formal Definition (ε-δ)

Moving from "hand-wavy" intuition to the rock-solid logical foundation of Calculus via the Epsilon-Delta definition.

Rigorous Bounds in ML

In Machine Learning Theory, we often need guarantees. For example, PAC Learning (Probably Approximately Correct) uses logic remarkably similar to epsilon-delta: "With probability \(1-\delta\), the error is less than \(\epsilon\)." Mastering this logic is the first step toward understanding theoretical guarantees in AI.

1. The Definition

\[ \lim_{x \to a} f(x) = L \]

Means that for every \(\epsilon > 0\) (no matter how small), there exists a \(\delta > 0\) such that:

\[ 0 < |x - a| < \delta \implies |f(x) - L| < \epsilon \]

Decoding the Inequalities

Recall that \(|A - B|\) represents the distance between A and B.

  • \(|f(x) - L| < \epsilon\): The output \(f(x)\) is within distance \(\epsilon\) of the target \(L\). This is the "Challenge".
  • \(|x - a| < \delta\): The input \(x\) is within distance \(\delta\) of the point \(a\). This is the "Response".
  • \(0 < |x - a|\): We specifically ignore the point \(x = a\) itself (where the "hole" might be).

2. Visualizing "The Game"

Limit proofs can be thought of as a game between a Skeptic (Challenger) and You (Prover).

3. A Concrete Proof Example

Prove that \(\lim_{x \to 3} (2x - 1) = 5\)

Step 1: Scratch Work (Finding the relationship)
We want \(|(2x - 1) - 5| < \epsilon\).
Simplify: \(|2x - 6| < \epsilon\)
Factor out 2: \(2|x - 3| < \epsilon\)
Divide by 2: \(|x - 3| < \epsilon/2\)
This looks exactly like \(|x - a| < \delta\) if we choose \(\delta=\epsilon/2\).

Step 2: Formal Proof
Given any \(\epsilon > 0\), choose \(\delta = \epsilon/2\).
Assume \(0 < |x - 3| < \delta\).
Substitute \(\delta\): \(\implies |x - 3| < \epsilon/2\)
Multiply by 2: \(\implies 2|x - 3| < \epsilon\)
Bring 2 inside: \(\implies |2x - 6| < \epsilon\)
Rewrite inside: \(\implies |(2x - 1) - 5| < \epsilon\)
Therefore, \(|f(x) - L| < \epsilon\). Q.E.D.

4. Python: Verifying the Delta

epsilon_delta_check.py
def linear_proof_check(epsilon):
    # For f(x) = 2x - 1, limit at 3 is 5
    # Our proof said delta = epsilon / 2
    delta = epsilon / 2
    return delta

# Let's play the game
epsilons = [1.0, 0.1, 0.01, 0.00001, 1e-9]

print(f"{'Appointed Epsilon':<20} | {'Required Delta':<20} | {'Test Result'}")
print("-" * 65)

for eps in epsilons:
    delta = linear_proof_check(eps)
    
    # VERIFICATION: Pick the 'worst case' x at the very edge of delta
    # If proof is correct, error must be EXACTLY epsilon (or less)
    
    # Test point slightly inside the boundary (99.9% of delta)
    x_test = 3 + (delta * 0.999) 
    f_x = 2 * x_test - 1
    
    actual_error = abs(f_x - 5)
    
    status = "PASS" if actual_error < eps else "FAIL"
    print(f"{eps:<20} | {delta:<20} | Error: {actual_error:.10f} ({status})")

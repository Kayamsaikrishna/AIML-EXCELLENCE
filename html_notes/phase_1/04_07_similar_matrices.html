07. Similar Matrices

Same transformation, different perspective.

1. The Definition

Two matrices \(\mathbf{A}\) and \(\mathbf{B}\) are Similar if there exists an invertible matrix \(\mathbf{P}\) such that:

$$ \mathbf{B} = \mathbf{P}^{-1}\mathbf{A}\mathbf{P} $$

Similar matrices represent the same linear transformation under different coordinate bases.

2. Invariant Properties

No matter which basis you choose, these properties of a linear transformation remain exactly the same:

  • Eigenvalues: Have the same values and multiplicities.
  • Trace: The sum of diagonal elements is invariant.
  • Determinant: The product of eigenvalues is invariant.
  • Rank & Nullity: The dimension of the span/null space is invariant.

3. AI Context: Latent Space Similarity

Linear Probing

In Representation Learning, the hidden states of two different models might look different as matrices, but if they are similar, they contain the same "knowledge" (features) just rotated or scaled. Techniques like Canonical Correlation Analysis (CCA) search for such similarities.

4. Python: Verifying Invariants

import numpy as np

A = np.array([[1, 2], [3, 4]])
P = np.array([[1, 1], [0, 1]]) # Random invertible matrix
P_inv = np.linalg.inv(P)

# B is similar to A
B = P_inv @ A @ P

print(f"Det(A): {np.linalg.det(A):.2f}, Det(B): {np.linalg.det(B):.2f}")
print(f"Trace(A): {np.trace(A)}, Trace(B): {np.trace(B)}")
print(f"Eigenvals A: {np.linalg.eigvals(A)}")
print(f"Eigenvals B: {np.linalg.eigvals(B)}")

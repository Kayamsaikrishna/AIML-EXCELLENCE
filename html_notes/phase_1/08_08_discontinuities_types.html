Calculus 1.3 Break-Points

Types of Discontinuities

Not all breaks are created equal. Classifying the different ways functions can fail to be continuous allows us to predict algorithm behavior.

Why it matters in ML

Different discontinuities require different fixes. A "Removable" discontinuity can be patched (e.g., 0/0). A "Jump" discontinuity (like in Decision Trees or Classification) fundamentally changes the state. An "Infinite" discontinuity (like exploding loss) crashes the system.

1. The Classification

1. Removable (Hole)

The limit exists, but the function value is wrong or missing. We can "plug the hole".

\[\lim_{x \to a^-} f = \lim_{x \to a^+} f \neq f(a)\]

2. Jump

Left and Right limits both exist but are different. The graph "skips".

\[\lim_{x \to a^-} f \neq \lim_{x \to a^+} f\]

3. Infinite

At least one side shoots to \(\pm \infty\). A vertical asymptote (The "Wall").

\[\lim_{x \to a} f = \pm \infty\]

3. AI/ML Connection: Decision Boundaries

Classification is a Discontinuity

In a binary classification problem (e.g., Cat vs. Dog), the output is discrete: Yes (1) or No (0). The perfect decision boundary is a Jump Discontinuity.

However, training a model with jumps is hard (gradients are zero almost everywhere and undefined at the jump). We replace the hard jump (Step function) with a smooth Sigmoid curve.

\[ \text{Step}(x) \approx \frac{1}{1 + e^{-kx}} \]

By increasing \(k\), the sigmoid becomes steeper, approaching the jump discontinuity while remaining continuous and differentiable everywhere. This is the "Relaxation" technique in optimization.

4. Python: Discontinuity Detector

detect_breaks.py
import numpy as np

def classify_discontinuity(func, point, epsilon=1e-5):
    left_val = func(point - epsilon)
    right_val = func(point + epsilon)
    
    print(f"Analyzing at x={point}...")
    print(f"Left Limit: {left_val:.2f}, Right Limit: {right_val:.2f}")

    # Check for Infinite (Overflow or huge number)
    if abs(left_val) > 1e6 or abs(right_val) > 1e6:
        print("=> Type: INFINITE Discontinuity ⚠️")
        return

    # Check for Jump
    if not np.isclose(left_val, right_val, atol=0.1):
        print("=> Type: JUMP Discontinuity 🦘")
        return

    # If limits match, check value at point
    try:
        val_at = func(point)
        if not np.isclose(val_at, left_val, atol=0.1):
             print(f"=> Type: REMOVABLE Discontinuity (Hole) 🕳️. Point is {val_at}, Limit is {left_val:.2f}")
        else:
             print("=> Type: None (Continuous) ✅")
    except:
        print("=> Type: REMOVABLE Discontinuity (Undefined Point) 🕳️")

# Test 1: Step Function
step = lambda x: 1 if x > 0 else 0
classify_discontinuity(step, 0)

# Test 2: 1/x^2
inv_sq = lambda x: 1/(x**2)
classify_discontinuity(inv_sq, 0)

# Test 3: Hole (x^2-1)/(x-1)
hole = lambda x: (x**2-1)/(x-1) if x != 1 else 10 # Incorrect value at 1
classify_discontinuity(hole, 1)

25. Vector Space Symmetry

Rotations, Reflections, and Invariance.

1. Transformations that Preserve Structure

A transformation is a Symmetry if it preserves a certain property (like length or angle) of the vectors in the space. The set of these transformations forms a Group.

  • Rotations (SO(n)): Preserve both length and orientation.
  • Reflections: Preserve length but flip orientation.
  • Invariance: A property \( P \) is invariant if \( P(\mathbf{v}) = P(T \mathbf{v}) \).

2. Geometric Deep Learning

Equivariance in CNNs

A Convolutional Neural Network (CNN) is powerful because it is Translation Invariant. It doesn't matter if a cat is in the top-left or bottom-right; the features are the same.

  • Data Augmentation: We artificially create symmetry by rotating and flipping images, teaching the AI to be invariant to these transformations.
  • Geometric AI: Modern models for molecule discovery (Graph Neural Networks) must be 3D-rotation invariant.

3. Python: Rotation Symmetry

import numpy as np

def rotate_2d(v, theta_deg):
    theta = np.radians(theta_deg)
    # Rotation Matrix
    R = np.array([
        [np.cos(theta), -np.sin(theta)],
        [np.sin(theta),  np.cos(theta)]
    ])
    return R @ v

v = np.array([1, 0])
v_rot = rotate_2d(v, 90)

# Symmetry: Magnitude is preserved
print(f"Original Mag: {np.linalg.norm(v)}")
print(f"Rotated Mag: {np.linalg.norm(v_rot)}") # Should be 1.0

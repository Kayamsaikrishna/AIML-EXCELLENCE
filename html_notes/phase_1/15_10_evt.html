10. Extreme Value Theorem (EVT)

Guarantees that a maximum and minimum exist.

1. The Theorem

The Extreme Value Theorem states that if a function \(f\) is continuous on a closed interval \([a, b]\), then \(f\) attains both an absolute maximum and an absolute minimum value on that interval.

There exist numbers \(c\) and \(d\) in \([a, b]\) such that:

$$ f(c) \leq f(x) \leq f(d) \quad \text{for all } x \in [a, b] $$

Where \(f(c)\) is the minimum and \(f(d)\) is the maximum.

2. Why "Closed Interval" matters?

If the interval is open (e.g., \((0, 1)\)), the function might approach a value but never reach it. For example, \(f(x) = 1/x\) on \((0, 1)\) has no maximum because it goes to \(\infty\). The EVT requires the boundaries to be included.

3. AI/ML Connection: The Quest for the Global Minimum

Absolute Minima in Loss Functions

In Machine Learning, we are always trying to find the global minimum of a loss function. The EVT gives us the mathematical confidence that if our loss function is continuous and we are searching within a bounded (closed) space of weights, an Absolute Minimum actually exists.

Without the EVT, we might be searching for a "best" model that theoretically doesn't exist, leading to algorithms that never stop or oscillate forever.

4. Python: Brute Force Search for Extrema

import numpy as np

# Function: f(x) = sin(x) + x on [-5, 5]
def f(x):
    return np.sin(x) + x

x_range = np.linspace(-5, 5, 1000)
y_values = f(x_range)

abs_min = np.min(y_values)
abs_max = np.max(y_values)

print(f"On [-5, 5]:")
print(f"Absolute Minimum: {abs_min:.4f}")
print(f"Absolute Maximum: {abs_max:.4f}")

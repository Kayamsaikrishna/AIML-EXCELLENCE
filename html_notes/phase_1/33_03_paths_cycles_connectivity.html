Graph Theory Navigation

Paths, Cycles & Connectivity

Traversing the Network. Defining how nodes interact over distances and determining if a graph is a unified structure or a collection of isolated islands.

The Walk vs. The Path

In a graph, moving from A to B can happen in many ways. A Walk is any sequence of edges. A Path is a walk where no vertex is repeated. A Cycle is a path that starts and ends at the same node. These definitions are crucial for detecting loops in software and dependencies in AI pipelines.

1. Connectivity Definitions

Connected Graph

A graph where there is a path between *every* pair of vertices. No node is left behind.

Components

Isolated "islands" of nodes within a non-connected graph. Each component is itself a connected sub-graph.

Strongly vs. Weakly Connected

In Digraphs: Strongly means you can go from A to B AND B to A. Weakly means they are connected only if we ignore edge directions.

2. Cycle Detection

Cycles represent feedback loops or circular dependencies. In many AI tasks, we explicitly try to avoid them by working with DAGs (Directed Acyclic Graphs).

Bridges & Articulation Points: A bridge is an edge whose removal increases the number of connected components. In a network, these are "Single Points of Failure."

NLP Recommendation Systems

Connectivity in AI

  • Recommender Systems: "Users who bought X also bought Y." We find paths between users (nodes) and items (nodes). Connectivity helps determine "collaborative filtering" clusters.
  • Dependency Parsing: In NLP, a sentence is parsed into a dependency tree (a specific type of connected graph). Cycles in a parse usually indicate an error.
  • Gradient Flow: In deep neural networks, a skip-connection (like in ResNets) creates a shortcut Path for gradients to flow without vanishing, effectively enhancing the "connectivity" of the gradient network.
  • Social Network Analysis: Using Connectivity to find the "Six Degrees of Separation" (the average shortest path length) between people.

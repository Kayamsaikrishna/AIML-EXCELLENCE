1. Finding Coordinates

If you know your distance/angle to two known points, you can calculate your exact coordinates.

In Computer Vision, this is how we reconstruct 3D scenes from 2D images (Stereo Vision). The disparity between the left and right eye (parallax) gives depth via trigonometry.

2. Simultaneous Localization and Mapping (SLAM)

Self-driving cars use Lidar angles to build a map. The core math problem is:

$$ \text{Given } Z_t \text{ (measurements), find } X_t \text{ (position)} $$

This is solved using the Law of Sines/Cosines inside a Kalman Filter or Graph Optimization loop.

3. Simple 2D Localization

Determining position from distance to two beacons.

import numpy as np

# Beacon Locations
beacon_A = np.array([0, 0])
beacon_B = np.array([10, 0])

# Measured Distances (from Robot)
d_A = 6.0
d_B = 5.0

# Using Law of Cosines to find angle at Beacon A
# d_B^2 = d_A^2 + dist_AB^2 - 2*d_A*dist_AB*cos(theta)
dist_AB = 10.0
# 25 = 36 + 100 - 120*cos(theta)
# 120*cos(theta) = 111
cos_theta = 111 / 120
theta = np.arccos(cos_theta)

# Robot Position
x = d_A * np.cos(theta)
y = d_A * np.sin(theta)

print(f"Robot Position: ({x:.2f}, {y:.2f})")

39. Engineering & AI Applications

Where Trigonometry powers the physical and digital worlds.

1. Physics: The Simple Harmonic Motion

Every oscillation—from a bridge vibrating to an electron spinning—is described by the general wave equation:

$$ y(t) = A \sin(\omega t + \phi) $$
  • \(A\) = Amplitude (Volume / Intensity)
  • \(\omega\) = Angular Frequency (Pitch)
  • \(\phi\) = Phase Shift (Horizontal displacement)

2. LiDAR & Computer Vision sensing

Scanning the World

Autonomous vehicles use LiDAR (Light Detection and Ranging). The sensor rotates and shoots laser beams. By measuring the "Time of Flight" and the precise Angle (\(\theta, \phi\)) of the laser, the AI uses trig to convert the polar data into a 3D point cloud \((x, y, z)\).

  • Ray-Tracing: In photorealistic AI rendering (like NeRFs), we trace rays of light through pixels using trigonometry to calculate lighting, shadows, and reflections.
  • Drones: Flight stabilization (gimbals) uses real-time inverse trig to keep cameras level regardless of the drone's tilt.

3. Python: Simulating a Wave

import numpy as np
import matplotlib.pyplot as plt

def generate_wave(amp, freq, phase, t):
    return amp * np.sin(2 * np.pi * freq * t + phase)

time = np.linspace(0, 1, 1000)
wave1 = generate_wave(1.0, 5, 0, time)      # Pure Tone
wave2 = generate_wave(0.5, 10, np.pi/2, time) # Octave Shifted

# Constructing a complex "Sound"
complex_wave = wave1 + wave2

plt.plot(time, complex_wave)
plt.title("Synthesis of a Complex Signal")
plt.show()

07. Velocity and Acceleration (Applied)

The calculus of motion.

1. The Motion Chain

Calculus allows us to move between levels of physical description through differentiation.

  1. Position \(s(t)\): Where the object is.
  2. Velocity \(v(t) = s'(t)\): How fast its position is changing (speed + direction).
  3. Acceleration \(a(t) = v'(t) = s''(t)\): How fast its velocity is changing.
  4. Jerk \(j(t) = a'(t)\): How quickly its acceleration changes (crucial for comfort in self-driving cars).

2. Speed vs. Velocity

Remember that Velocity is a vector (has direction). Speed is the absolute value of velocity: \(\text{Speed} = |v(t)|\). A particle is moving faster when its speed is increasing, which happens when velocity and acceleration have the same sign.

3. AI/ML Connection: Robotics & Trajectory Prediction

The Kalman Filter

In Robotics and Drone Control, we use AI to predict where a moving object will be in the next 100 milliseconds. Models like the Kalman Filter rely on these derivatives. By knowing the current position, velocity, and acceleration, the AI can "extrapolate" the path even if the sensors are temporarily blocked by noise.

Furthermore, in Self-Driving Cars, we optimize the "Jerk" (the 3rd derivative). A path that is mathematically optimal but has high jerk would be extremely uncomfortable for human passengers, making higher-order calculus essential for human-centric AI design.

4. Python: Simulating Gravity

# s(t) = -4.9t^2 + 20t + 5
# Ground hit: solve s(t) = 0
# Velocity at hit: v(t_hit)

import sympy as sp

t = sp.Symbol('t')
s = -4.9*t**2 + 20*t + 5
v = sp.diff(s, t)

t_hit = sp.solve(s, t)[1] # Get the positive time value
impact_v = v.subs(t, t_hit)

print(f"Time of impact: {t_hit:.2f} s")
print(f"Impact Velocity: {impact_v:.2f} m/s")

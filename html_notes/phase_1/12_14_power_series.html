Calculus 1.5 Approximation

Power Series

Infinite polynomials that build the world.

The Universal Lego Brick

A Power Series is a function represented as an infinite sum of polynomial terms: \[ f(x) = \sum_{n=0}^{\infty} c_n (x-a)^n = c_0 + c_1(x-a) + c_2(x-a)^2 \dots \]

This is incredibly powerful because while computers struggle with \(\sin(x)\) or \(e^x\), they are excessively fast at adding and multiplying (polynomials).

2. AI/ML Connection: Activation Function Approximation

Hardware Acceleration

In deep learning, we use activation functions like Sigmoid (\(\sigma(x) = 1/(1+e^{-x})\)) or Tanh. Computing these exact exponentials on thousands of GPU cores is expensive.

Hardware designers (like at NVIDIA or Google TPU teams) often implement these functions using Truncated Power Series (Polynomial Approximation). Instead of calculating \(e^x\), the chip calculates \(1 + x + x^2/2 + x^3/6\). This is 100x faster and "accurate enough" for neural network training, provided the inputs \(x\) stay within a certain range.

3. Python: Approximating Sigmoid

sigmoid_approx.py
import numpy as np
import matplotlib.pyplot as plt

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# Approx near x=0 (Maclaurin-ish, first few terms)
# Sigmoid approx: 0.5 + 0.25x - 0.02x^3 ...
def sigmoid_poly(x):
    return 0.5 + 0.25*x - (1/48)*x**3

x_vals = np.linspace(-2, 2, 100)
true_vals = sigmoid(x_vals)
approx_vals = sigmoid_poly(x_vals)

print(f"True(1.0): {sigmoid(1.0):.4f}")
print(f"Poly(1.0): {sigmoid_poly(1.0):.4f}")
# Close match near 0! Becomes simpler math for the CPU.

06. Covariance

Measuring joint variability.

1. Definition

Covariance is a measure of the joint variability of two random variables. If the greater values of one variable mainly correspond with the greater values of the other, the covariance is positive.

$$ Cov(X, Y) = E[(X - E[X])(Y - E[Y])] $$

A simpler computational formula is:

$$ Cov(X, Y) = E[XY] - E[X]E[Y] $$

2. Properties

  • $Cov(X, X) = Var(X)$
  • $Cov(X, Y) = Cov(Y, X)$
  • If $X$ and $Y$ are independent, $Cov(X, Y) = 0$. (Note: The reverse is not always true!)
  • $Var(X+Y) = Var(X) + Var(Y) + 2Cov(X, Y)$

3. AI/ML Connection: Redundancy and Dimensionality

Eliminating Wasted Effort

Covariance tells an AI which features are Redundant.

In **Data Preprocessing**, if two features (like "Temperature in Celsius" and "Temperature in Fahrenheit") have high covariance, they are providing essentially the same information. An AI engineer can remove one of them to reduce "Noise" and speed up training. This is the heart of **PCA (Principal Component Analysis)**, which calculates the Covariance Matrix of the entire dataset and compresses it into a smaller set of features that capture the most variance while having zero covariance with each other. Understanding covariance allows you to design models that focus on unique information rather than repeating the same patterns.

4. Python: Calculating Covariance Matrix

import numpy as np

# Height (cm) and Weight (kg)
height = [160, 170, 180, 150, 165]
weight = [60, 75, 85, 50, 68]

# Compute covariance matrix
cov_matrix = np.cov(height, weight)

print(f"Covariance(Height, Weight): {cov_matrix[0, 1]:.2f}")
print(f"Full Matrix:\n{cov_matrix}")

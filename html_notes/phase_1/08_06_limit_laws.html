Calculus 1.3 Algebra

Limit Laws & Properties

Why solve hard limits from scratch when you can break them into easier pieces? The algebraic toolkit for limit evaluation.

Modular Mathematics

In Computer Science, we break complex functions into subroutines. In Math, Limit Laws allow us to do the same. If we know the limit of \(f(x)\) and \(g(x)\), we instantly know the limit of \(f(x) + g(x)\), \(f(x)/g(x)\), or \(\sqrt{f(x)}\) without re-doing the epsilon-delta proof.

1. The Big Six Laws

Assume \(\lim_{x \to a} f(x) = L\) and \(\lim_{x \to a} g(x) = M\) (both are finite).

1. Sum/Difference

\[ \lim(f \pm g) = L \pm M \]

2. Product

\[ \lim(f \cdot g) = L \cdot M \]

3. Constant Multiple

\[ \lim(c \cdot f) = c \cdot L \]

4. Quotient

\[ \lim\left(\frac{f}{g}\right) = \frac{L}{M} \quad (M \neq 0) \]

5. Power

\[ \lim[f(x)]^n = L^n \]

6. Root

\[ \lim\sqrt[n]{f(x)} = \sqrt[n]{L} \]

2. Direct Substitution

For "nice" functions (polynomials, rational functions strictly inside their domain), limit evaluation simplifies to just plugging in the number.

The Substitution Property

If \(f(x)\) is continuous at \(x=a\), then:

\[ \lim_{x \to a} f(x) = f(a) \]

Example

$$ \lim_{x \to 2} (3x^2 + 5x - 1) = 3(2)^2 + 5(2) - 1 = 12 + 10 - 1 = 21 $$

3. AI/ML Application: Computational Graphs

Backpropagation is Limit Laws in Action

Modern AI frameworks (PyTorch, TensorFlow) view models as Computational Graphs. We care about the derivative of the loss \( \mathcal{L} \). The derivative is a limit.

graph TD X[Input x] --> Node1(f_x) X --> Node2(g_x) Node1 --> Sum((+)) Node2 --> Sum Sum --> Out[Output y] style Sum fill:#f6e05e,stroke:#d69e2e
Graph for y = f(x) + g(x).

Since differentiation is a linear operator (derived from the Sum and Constant limit laws): \[ \frac{d}{dx}(f(x) + g(x)) = \frac{df}{dx} + \frac{dg}{dx} \] The framework computes gradients for each node independently and sums them up. Without the Sum Law of Limits, we couldn't modularize backpropagation; we'd have to solve the limit for the entire massive network at once.

4. Python: Symbolic Limit Solving

While numerical methods approximate, libraries like SymPy use algebraic rules to find exact/analytical limits.

symbolic_limits.py
from sympy import Symbol, limit, sin, oo

x = Symbol('x')

# Case 1: Complex Rational Function (Direct Substitution fails due to 0/0)
# f(x) = (x^2 + 3x + 2) / (x + 1)
# Factor numerator: (x+1)(x+2). The (x+1) cancels.
f = (x**2 + 3*x + 2) / (x + 1)

lim_val = limit(f, x, -1)
print(f"Limit of ({f}) as x -> -1 is: {lim_val}")
# SymPy uses algebraic simplification rules internally to find this.

# Case 2: Trigonometric Limit (Squeeze Theorem logic needed)
# f(x) = sin(x)/x as x -> 0 (Should be 1)
g = sin(x)/x
lim_trig = limit(g, x, 0)
print(f"Limit of sin(x)/x as x -> 0 is: {lim_trig}")

# Case 3: Limits at Infinity
h = (2*x**2 + 5)/(3*x**2 + 1)
lim_inf = limit(h, x, oo)
print(f"Limit of rational function at infinity: {lim_inf}")

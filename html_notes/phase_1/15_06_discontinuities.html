06. Types of Discontinuities

Where the line breaks.

1. Removable Discontinuity ("Holes")

Occurs when the limit exists but does not equal the function value (or the value is undefined).

$$ f(x) = \frac{x^2 - 1}{x - 1} $$

At \(x=1\), there is a hole. We can "remove" it by defining \(f(1) = 2\).

2. Jump Discontinuity

Occurs when the left-hand and right-hand limits exist but are different.

Example: The Step Function (used in early Perceptrons).

3. Infinite Discontinuity

Occurs when at least one of the one-sided limits is \(\pm \infty\). (Vertical Asymptote).

4. AI Insight: Why we hate Jumps

The Relu activation \(max(0, x)\) is continuous BUT has a "kink" at 0 (discontinuous derivative). However, jump discontinuities (like the Step function) are far worse because the gradient is Zero everywhere except at the jump, where it is undefined. This "zero-gradient problem" effectively kills backpropagation.

5. Finding Discontinuities with Python

import sympy as sp

x = sp.Symbol('x')
f = (x**2 - 1) / (x - 1)

# Find where denominator is zero
problem_pts = sp.solve(sp.denom(f), x)

for pt in problem_pts:
    lim = sp.limit(f, x, pt)
    print(f"At x={pt}, Limit={lim} -> Removable Hole!")

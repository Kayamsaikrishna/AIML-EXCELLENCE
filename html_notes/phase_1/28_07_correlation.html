07. Correlation (Pearson)

Normalized relationship: Scale-invariant connection.

1. Definition

Pearson Correlation Coefficient ($\rho$) is the covariance of two variables divided by the product of their standard deviations. It normalizes the relationship to a scale of -1 to +1.

$$ \rho_{X, Y} = \text{Corr}(X, Y) = \frac{Cov(X, Y)}{\sigma_X \sigma_Y} $$

2. The Correlation Scale

  • **+1:** Perfect positive linear relationship.
  • **-1:** Perfect negative linear relationship.
  • **0:** No linear relationship.

3. AI/ML Connection: Feature Selection and Collinearity

The Heatmap of Insight

Correlation is the primary tool for **Exploratory Data Analysis (EDA)**.

In **Predictive Modeling**, we use **Correlation Heatmaps** to visualize how input features relate to the target variable. A high correlation (e.g., 0.8) suggests a strong predictive signal. However, if two input features have a correlation near 1.0, it indicates **Multicollinearity**. This is problematic for models like Linear Regression because it makes the coefficient estimates unstable. In **Neural Networks**, we often use **Batch Normalization** to ensure that neurons aren't too highly correlated, which helps the model learn more diverse and robust features. Understanding correlation ensures you don't over-rely on redundant signals.

4. Python: Correlation Heatmap Logic

import pandas as pd

# Creating a small dataset
df = pd.DataFrame({
    'Feature_A': [1, 2, 3, 4, 5],
    'Feature_B': [2, 4, 6, 8, 10],   # Perfect correlation with A
    'Feature_C': [5, 4, 3, 2, 1],   # Negative correlation with A
    'Random': [3, 1, 4, 2, 5]        # Low correlation
})

corr_matrix = df.corr()
print(corr_matrix.round(2))

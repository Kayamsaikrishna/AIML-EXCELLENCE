12. The QR Algorithm

Efficiently finding the whole spectrum of eigenvalues.

1. Iterative Diagonalization

While Power Iteration only finds the ONE largest eigenvalue, the QR Algorithm finds ALL of them by repeatedly "pushing" a matrix toward its Schur (Triangular) form.

The Recursive Step

  1. Start with \(\mathbf{A}_0 = \mathbf{A}\).
  2. Decompose \(\mathbf{A}_k = \mathbf{Q}_k\mathbf{R}_k\).
  3. Re-multiply in reverse: \(\mathbf{A}_{k+1} = \mathbf{R}_k\mathbf{Q}_k\).

Remarkably, after several iterations, \(\mathbf{A}_k\) converges to an Upper Triangular matrix where the diagonal elements are the eigenvalues!

2. Why this is efficient

Every step \(\mathbf{A}_{k+1} = \mathbf{Q}_k^T\mathbf{A}_k\mathbf{Q}_k\) is a similarity transformation. This means the eigenvalues never change, but the off-diagonal entries slowly converge to zero. This is the implementation used under the hood in libraries like numpy.linalg.eig.

3. Python: Implementing QR Iteration

import numpy as np

def qr_algorithm(A, iterations=100):
    A_k = np.copy(A)
    for _ in range(iterations):
        Q, R = np.linalg.qr(A_k)
        A_k = R @ Q
    return A_k

A = np.array([[4, 1], [2, 3]])
final_matrix = qr_algorithm(A)

print(f"Matrix after 100 QR iterations:\n{np.round(final_matrix, 2)}")
print(f"Diagonal contains Eigenvalues: {np.diag(final_matrix)}")

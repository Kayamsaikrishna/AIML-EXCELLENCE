1. What Makes a Function Invertible?

Not all functions have inverses. \( f(x) = x^2 \) destroys information (you can't know if input was -2 or +2). It is not Injective (One-to-One).

$$ f(f^{-1}(x)) = x $$

AI Application: Autoencoders

An Autoencoder tries to learn an identity mapping: \( \text{Decoder}(\text{Encoder}(x)) \approx x \). If the Encoder destroys information, the Decoder produces blurry images.

2. Invertible Neural Networks (Flows)

Normalizing Flows (e.g., RealNVP, Glow) consist of special layers that are mathematically guaranteed to be invertible.

Why Invertibility?

It allows us to compute exact likelihoods and generate data cheaply. If we know \( f(x) \), we can easily compute \( P(x) \) using the Change of Variables formula:

$$ \log P(x) = \log P(z) + \log |\det(J)| $$

3. Inverting a Transform

The inverse of scaling is un-scaling. The inverse of shifting is un-shifting.

import numpy as np

# 1. Forward Transform (Standardization)
def transform(x, mean, std):
    return (x - mean) / std

# 2. Inverse Transform (Reconstruction)
def inverse_transform(z, mean, std):
    return (z * std) + mean

# Data
data = np.array([10.0, 20.0, 30.0])
mu = np.mean(data)
sigma = np.std(data)

# Forward
z_scores = transform(data, mu, sigma)
print(f"Z-Scores: {z_scores}")

# Backward
reconstructed = inverse_transform(z_scores, mu, sigma)
print(f"Reconstructed: {reconstructed}") 
# Matches original exactly

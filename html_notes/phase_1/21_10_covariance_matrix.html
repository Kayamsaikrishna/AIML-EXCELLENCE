Prob 1.4 Multivariate Spread

The Covariance Matrix (\(\Sigma\))

Organizing all pairwise relationships in a high-dimensional dataset.

The Map of Dependency

When we have a random vector \(\mathbf{X} = [X_1, X_2, \dots, X_n]^\top\), we need a way to describe how every variable interacts with every other variable.

The Covariance Matrix is a square table where:
- Diagonals are the Variances of each feature.
- Off-diagonals are the Covariances between pairs.

1. Definition

$$ \Sigma = E[(\mathbf{X} - \mu)(\mathbf{X} - \mu)^\top] $$ For two variables \(X\) and \(Y\): $$ \Sigma = \begin{bmatrix} \text{Var}(X) & \text{Cov}(X, Y) \\ \text{Cov}(Y, X) & \text{Var}(Y) \end{bmatrix} $$

2. Mathematical Properties

  • Symmetric: \(\Sigma_{ij} = \Sigma_{ji}\) because covariance is symmetric.
  • Positive Semi-definite (PSD): For any vector \(\mathbf{v}\), \(\mathbf{v}^\top \Sigma \mathbf{v} \ge 0\).
    Intuition: This is the matrix version of saying "variance can't be negative". You can't have a "spread" in any direction that is less than zero.

3. ML Connection: Mahalanobis Distance

Anomaly Detection Clustering

Mahalanobis Distance

Standard Euclidean distance assumes features are independent and have the same variance (hyper-spheres). But real data is often multi-dimensional "ellipsoids" because of correlation.

The Mahalanobis distance uses the inverse of the covariance matrix to "normalize" the space, accounting for the spread and rotation of the data: $$ D_M(\mathbf{x}) = \sqrt{(\mathbf{x} - \mu)^\top \Sigma^{-1} (\mathbf{x} - \mu)} $$ This is essential for identifying Outliers that might look "close" in raw units but are actually very far from the data distribution when correlation is considered.

4. The Geometry of $\Sigma$

The Eigenvectors of the covariance matrix point in the directions of maximum variance (the principal axes of the data ellipsoid).
The Eigenvalues represent the amount of variance (the stretch) along those axes.

This is the theoretical bedrock of PCA (Principal Component Analysis).

03. The Integral Test

Turning sums into areas to prove convergence.

1. The Test

If \(f(n) = a_n\) is a continuous, positive, and decreasing function, then the infinite series \(\sum a_n\) and the improper integral \(\int_{1}^{\infty} f(x) dx\) either both converge or both diverge.

$$ \int_{1}^{\infty} f(x) dx \leq \sum_{n=1}^{\infty} a_n \leq a_1 + \int_{1}^{\infty} f(x) dx $$

2. The p-series

Using the integral test, we can prove the p-series test: \(\sum \frac{1}{n^p}\) converges if \(p > 1\) and diverges if \(p \leq 1\).

3. AI/ML Connection: Bounding Approximations

Infinite Data Streams

In Online Learning, an AI receives a stream of infinite data points. To ensure the "Accumulated Regret" (total mistakes) doesn't grow to infinity, we represent the mistakes as a series.

By using the Integral Test, researchers can prove that as long as the learning rate decreases at a certain rate (like \(1/\sqrt{n}\)), the total "Mistake Series" will have a finite bound. This mathematical guarantee is what allows companies to deploy AI in Stock Trading or Ad-Click Prediction with confidence that the model won't suddenly "explode" in error over time.

4. Python: Comparing Sums and Integrals

import numpy as np
from scipy.integrate import quad

# Series 1/n^2. Expected: Sum is pi^2 / 6 approx 1.644
# Integral: int(1/x^2 dx) from 1 to inf = [-1/x] = 1.0

def series_sum(limit):
    return sum(1/(n**2) for n in range(1, limit))

integral, _ = quad(lambda x: 1/(x**2), 1, np.inf)

print(f"Partial Sum (1000 terms): {series_sum(1000):.6f}")
print(f"Improper Integral: {integral:.6f}")
print("Both are finite -> Series Converges!")

Calculus 1.3 Classification

The First Derivative Test

Is it a Hill or a Valley? Ask the slopes around it.

Reading the Signs

A zero derivative just means "flat". To know if you're at the top or bottom, check the path you just walked (left) and the path ahead (right).

1. The Test Logic

Let \(c\) be a critical point. Check signs of \(f'(x)\):

Left of c Right of c Conclusion Shape
Positive (+) Negative (-) Local Maximum Up then Down (Peak)
Negative (-) Positive (+) Local Minimum Down then Up (Valley)
Same Sign Same Sign Neither Shelf (Inflection)

2. AI/ML Connection: Momentum

Overshooting the Minimum

In SGD with Momentum, the optimizer "remembers" the previous gradients. When approaching a minimum:

  • On the left, the gradient is negative (pushing right).
  • After crossing the minimum, the gradient becomes positive (pushing left).

This "sign flip" is the signal to the optimizer that it has overshot the target. Advanced optimizers use this information to dampen velocity. The First Derivative Test explains why gradients flip signs at the optimal point.

3. Python: The Sign Chart

sign_chart_check.py
import numpy as np

def f_prime(x):
    # Derivative of x^3 - 3x is 3x^2 - 3
    # Critical points at x = 1, -1
    return 3*x**2 - 3

crit_points = [-1, 1]
epsilon = 0.1

print(f"{'Point':<10} | {'Left Slope':<12} | {'Right Slope':<12} | {'Result'}")
print("-" * 50)

for c in crit_points:
    left_sign = np.sign(f_prime(c - epsilon))
    right_sign = np.sign(f_prime(c + epsilon))
    
    if left_sign > 0 and right_sign < 0:
        res = "MAX (Peak)"
    elif left_sign < 0 and right_sign > 0:
        res = "MIN (Valley)"
    else:
        res = "Inflection"
        
    print(f"{c:<10} | {left_sign:<12} | {right_sign:<12} | {res}")

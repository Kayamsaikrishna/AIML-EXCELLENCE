05. Neural Network Weights & Layers

Deep learning as nested linear maps.

1. The Dense Layer

A "Fully Connected" layer with \(n_{in}\) inputs and \(n_{out}\) neurons is simply a dimension change via matrix multiplication:

$$ \mathbf{y} = \sigma(\mathbf{W} \mathbf{x} + \mathbf{b}) $$
  • \(\mathbf{x}\): Input vector \((n_{in} \times 1)\).
  • \(\mathbf{W}\): Weight matrix \((n_{out} \times n_{in})\).
  • \(\mathbf{b}\): Bias vector \((n_{out} \times 1)\).

2. Visualizing Connectivity

Every line represents a single weight \(w_{ij}\) in our matrix.

3. Weight Initialization

If we initialize \(\mathbf{W}\) to all zeros, every neuron in a layer will learn the exact same thing (Symmetry). We use Xavier/Glorot or He initialization, which chooses values based on the matrix dimensions to keep the Variance of activations stable across layers.

4. Python: Simple Forward Pass

import numpy as np

# Layer 1: 3 features -> 2 neurons
W = np.random.randn(2, 3) 
b = np.zeros((2, 1))
x = np.random.randn(3, 1)

# Linear combo
z = W @ x + b

# Non-linear activation (ReLU)
y = np.maximum(0, z)

print(f"Output Activations:\n{y}")

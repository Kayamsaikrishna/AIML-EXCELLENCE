Stats 1.7 Multivariate

Multiple Linear Regression (MLR)

Predicting Y using multiple predictors, while "holding other factors constant."

The Partial Effect

In SLR (\(Y = \beta_0 + \beta_1 X\)), \(\beta_1\) is the total effect.

In MLR (\(Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2\)), \(\beta_1\) is the Ceteris Paribus effect: The change in Y when \(X_1\) increases by 1, assuming \(X_2\) DOES NOT MOVE.

1. The Matrix Form

$$ \mathbf{y} = \mathbf{X}\beta + \epsilon $$

Where \(\mathbf{X}\) is an \(n \times (p+1)\) matrix (the first column is all ones for the intercept).

$$ \hat{\beta} = (\mathbf{X}^T \mathbf{X})^{-1} \mathbf{X}^T \mathbf{y} $$

This is the famous Normal Equation. It calculates all weights simultaneously.

2. ML Connection: Feature Engineering

ML Engineering Supervised

Why More is not always Better

In Multiple Regression, every feature you add takes away one Degree of Freedom.

- Overfitting: If you have 10 data points and 10 features, you can get a "Perfect" (\(R^2 = 1\)) fit that means absolutely nothing. This is why we use Regularization (Ridge/Lasso) or Akaike Information Criterion (AIC) to judge if a feature is actually worth its weight. - Syks Effect: Adding a feature that is highly correlated with an existing feature (Like having "Height in cm" and "Height in inches") makes the matrix \((\mathbf{X}^T \mathbf{X})\) non-invertible. The model breaks. This is why we check for Multicollinearity.

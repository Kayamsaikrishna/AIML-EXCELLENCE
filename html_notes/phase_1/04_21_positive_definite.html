21. Positive Definite Matrices

The multi-dimensional version of "Positive Numbers".

1. The Definition

A real symmetric matrix \(\mathbf{A}\) is Positive Definite (PD) if for every non-zero vector \(\mathbf{x}\):

$$ \mathbf{x}^T\mathbf{A}\mathbf{x} > 0 $$

Equivalently, \(\mathbf{A}\) is PD if all its eigenvalues are positive (\(\lambda_i > 0\)).

2. Why AI Engineers care

Convexity and Gradients

In optimization, the **Hessian** (matrix of second derivatives) tells us if a point is a minimum, maximum, or saddle point. If the Hessian is Positive Definite at a critical point, the function is "cupped upwards" like a bowl, ensuring we have found a Local Minimum.

3. Tests for Positive Definiteness

  • Eigenvalue Test: All \(\lambda_i > 0\).
  • Cholesky Test: If a Cholesky decomposition \(\mathbf{A} = \mathbf{LL}^T\) exists with positive diagonal entries.
  • Sylvester’s Criterion: All leading principal minors have positive determinants.

4. Python: PD Verification

import numpy as np

def is_pd(A):
    try:
        np.linalg.cholesky(A)
        return True
    except np.linalg.LinAlgError:
        return False

A = np.array([[2, -1], [-1, 2]]) # PD
B = np.array([[1, 2], [2, 1]])   # Explodes (Not PD)

print(f"Is A Positive Definite? {is_pd(A)}")
print(f"Is B Positive Definite? {is_pd(B)}")

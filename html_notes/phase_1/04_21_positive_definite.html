1. Definition

A symmetric matrix \( A \) is Positive Definite (SPD) if for every non-zero vector \( x \):

$$ x^T A x > 0 $$

Equivalent properties:

  • All eigenvalues are strictly positive.
  • It has a unique Cholesky Decomposition \( A = LL^T \).

2. Convexity

In Optimization, a function is strictly convex if its Hessian matrix (second derivatives) is Positive Definite everywhere.

This guarantees that any local minimum is the unique Global Minimum. This is why Least Squares problems (where \( A^T A \) is SPD) are so easy to solve compared to Neural Networks.

3. The Cholesky Test

The fastest way to check SPD status numerically.

import numpy as np

# A SPD Matrix
A = np.array([
    [4, 1],
    [1, 3]
])

try:
    L = np.linalg.cholesky(A)
    print("Matrix is Positive Definite!")
    print("Cholesky Factor L:\n", L)
    print("Eigenvalues:", np.linalg.eigvals(A))
except np.linalg.LinAlgError:
    print("Matrix is NOT Positive Definite.")

# A Indefinite Matrix
B = np.array([
    [1, 2],
    [2, 1]
])
# x^T B x can be negative (saddle point)

try:
    L_B = np.linalg.cholesky(B)
except np.linalg.LinAlgError:
    print("\nMatrix B is NOT Positive Definite (Eigenvalues mixed).")
    print("Eigenvalues:", np.linalg.eigvals(B))

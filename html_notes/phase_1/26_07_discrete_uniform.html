07. Discrete Uniform Distribution

Equal probability for all outcomes.

1. Definition

A random variable $X$ follows a Discrete Uniform Distribution if every value in its finite range $\{a, a+1, \dots, b\}$ is equally likely. If there are $n$ possible values, the probability of any single value is $1/n$.

$$ P(X=x) = \frac{1}{n} = \frac{1}{b - a + 1} $$

2. Statistical Properties

  • Mean (Expected Value): $E[X] = \frac{a+b}{2}$
  • Variance: $Var(X) = \frac{(b-a+1)^2 - 1}{12}$

3. AI/ML Connection: Randomization and Initialization

The Initial State of Knowledge

The Discrete Uniform distribution represents a state of Maximum Entropy (most uncertainty) when possible outcomes are finite.

In **Random Sampling**, when you split your data into "Train" and "Test" sets, you are assigning each data point an index from a discrete uniform distribution to ensure the split is unbiased. In **Hyperparameter Tuning**, **Random Search** often samples integers (like "Number of Layers" or "Batch Size") from a discrete uniform range. Furthermore, in **Model Initialization**, while we often use Normal distributions, some architectures use **Uniform Initialization** to ensure that neurons start with a "Fair" and diverse set of weights, preventing the model from becoming biased towards a specific feature before training even begins.

4. Python: Uniform Sampling

import numpy as np

# Sample an integer between 1 and 100 (Inclusive)
# np.random.randint is [low, high) - so high=101
val = np.random.randint(1, 101)

# Sampling a batch for training
indices = np.random.randint(0, 10000, size=32)
print(f"Batch Indices: {indices}")

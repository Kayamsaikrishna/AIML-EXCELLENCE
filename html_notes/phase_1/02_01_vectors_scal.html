Vectors, Scalars & Feature Spaces

They aren't just arrows. In AI, Vectors are the language of meaning, representing everything from pixels to semantic concepts in high-dimensional space.

1. The Three Perspectives

Depending on who you ask, a vector is:

  • Physics: An arrow in space. Properties: Length and Direction. Invariant to coordinate systems.
  • Computer Science: An ordered list of numbers. [1.5, 3.2, -0.9].
  • Machine Learning: A Feature Vector. Each dimension represents a distinct attribute of an entity.
$$ \mathbf{x} = \begin{bmatrix} x_1 \\ x_2 \\ \vdots \\ x_n \end{bmatrix} \in \mathbb{R}^n $$

The Scalar

A Scalar is a single number value that "scales" a vector. In AI, loss values and learning rates are scalars.

2. High-Dimensional Feature Spaces

We rarely work in 2D or 3D. We work in \(\mathbb{R}^{d}\) where \(d\) can be thousands.

Case Study: The "House" Vector

Imagine a house represented as a vector in \(\mathbb{R}^4\):

$$ \mathbf{x}_{house} = \begin{bmatrix} 2500 \text{ (sq ft)} \\ 4 \text{ (bedrooms)} \\ 2010 \text{ (year)} \\ 1 \text{ (has pool?)} \end{bmatrix} $$

This house is a single point in a 4-dimensional space. "Similar" houses are points that are close together in this space.

3. Word Embeddings (NLP)

The most famous vectors in AI are Word Embeddings (e.g., Word2Vec, GloVe, GPT activations).

These vectors capture semantic meaning. The famous arithmetic holds:

$$ \vec{v}_{King} - \vec{v}_{Man} + \vec{v}_{Woman} \approx \vec{v}_{Queen} $$

4. Vectors in Python (NumPy & PyTorch)

Numpy arrays are the standard implementation of vectors.

import numpy as np
import torch
import matplotlib.pyplot as plt

# 1. Defining Vectors
v_row = np.array([1, 2, 3])          # Shape (3,)
v_col = np.array([[1], [2], [3]])    # Shape (3, 1)

print(f"Row Vector Shape: {v_row.shape}")
print(f"Col Vector Shape: {v_col.shape}")

# 2. Scaling (Scalar Multiplication)
alpha = 0.5
v_scaled = alpha * v_row 
print(f"Scaled: {v_scaled}") # [0.5, 1.0, 1.5]

# 3. AI Example: Random Embedding
# A random vector of dimension 512 (like in GPT-2 small)
gpt_vector = torch.randn(512)
print(f"Embedding Norm (Length): {torch.norm(gpt_vector):.4f}")

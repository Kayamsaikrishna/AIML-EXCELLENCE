Prob 1.4 Adam's Law

The Law of Iterated Expectations

Simplifying complex averages by breaking them into nested stages.

The Average of Averages

Suppose you want to find the average height of a person in the world. You could:
1. Calculate the average height in each country.
2. Take the weighted average of those country-wide averages.

The result is exactly the same as if you measured every person individually. This is **Adam's Law**: The expectation of a conditional expectation is the global expectation.

1. The Formula (The Tower Property)

$$ E[X] = E[ \, E[X|Y] \, ] $$

Calculation Steps: 1. Find \(E[X|Y=y]\) (this is a function of \(y\)). 2. Take the expectation of that function with respect to the distribution of \(Y\).

2. Why is this useful?

Oftentimes, \(X\) is very complex, but it becomes simple if we know some "state" \(Y\).
Example: Finding the expected number of clicks on an ad. - If user is "Interested" (\(Y=1\)), \(E[X|Y=1] = 0.5\). - If user is "Not Interested" (\(Y=0\)), \(E[X|Y=0] = 0.01\). - Global Average = (Prob Interested \(\times\) 0.5) + (Prob Not Interested \(\times\) 0.01).

3. ML Connection: Hierarchical Models

Bayesian ML Ensembles

Boosting and Aggregation

In Hierarchical Bayesian Models, we assume parameters \(\theta\) themselves are random variables drawn from a hyper-distribution.

To find the expected performance of a model across all possible datasets, we often use the Law of Iterated Expectations to average over the datasets first, then over the hyper-parameters.

Stochastic Processes

In Reinforcement Learning, the Bellman Equation is an application of iterated expectations. The value of a state is the expected reward plus the expected value of the next state, conditional on the action taken.

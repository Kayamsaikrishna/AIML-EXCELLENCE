1. The Identity Matrix

The Identity Matrix \( I_n \) is the "1" of Linear Algebra. It has 1s on the main diagonal and 0s everywhere else.

$$ I_3 = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} $$

Property: \( AI = A \) and \( IA = A \).

2. Sparsity

In Recommender Systems (e.g., Netflix), the User-Item matrix is huge (Millions x Millions) but Sparse (mostly 0s, because a user rates very few movies).

We do not store all the zeros. We only store values like `(row, col, value)`. This saves terabytes of RAM.

3. Creating Primitives

Generating base matrices.

import numpy as np
from scipy.sparse import csr_matrix

# Identity
I = np.eye(3)
print(f"Identity:\n{I}")

# Diagonal
D = np.diag([10, 20, 30])
print(f"\nDiagonal:\n{D}")

# Sparse Matrix (Compressed Sparse Row)
# Imagine a 1000x1000 matrix with only 2 non-zeros
large_dense = np.zeros((1000, 1000))
large_dense[0, 5] = 1
large_dense[999, 999] = 1

sparse_mat = csr_matrix(large_dense)

print(f"\nDense Bytes: {large_dense.nbytes} bytes")
print(f"Sparse Bytes: {sparse_mat.data.nbytes + sparse_mat.indices.nbytes + sparse_mat.indptr.nbytes} bytes")
# Massive savings!

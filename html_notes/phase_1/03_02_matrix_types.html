02. Basic Matrix Types

The building blocks of linear transformations.

1. Classification by Shape

  • Square Matrix: Rows = Columns (\( n \times n \)). Essential for determinants and inverses.
  • Rectangular Matrix: Rows \(\neq\) Columns (\( m \times n \)). Common for datasets.
  • Row Matrix: A single row (\( 1 \times n \)). Effectively a row vector.
  • Column Matrix: A single column (\( m \times 1 \)). Effectively a column vector.

2. Specific Purpose Matrices

The Identity Matrix (\( \mathbf{I} \))

The "Number 1" of matrices. Multiplying any matrix by \( \mathbf{I} \) leaves it unchanged.

$$ \mathbf{I} = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} $$

AI Use: Residual connections can be viewed as adding an Identity mapping to the learned features.

The Zero Matrix (\( \mathbf{0} \))

All elements are zero. Represents "Dead" weights or the absence of a signal.

3. Python: Initializing Special Matrices

import numpy as np

# 3x3 Identity Matrix
I = np.eye(3)

# 2x4 Zero Matrix
Z = np.zeros((2, 4))

# 3x3 Matrix of Ones (Useful for Bias Initialization)
O = np.ones((3, 3))

print(f"Identity:\n{I}")
print(f"Zeros:\n{Z}")

22. Angle between Vectors

From raw numbers to geometric orientation.

1. The Formula

Using the dot product geometric definition, we can solve for the angle \(\theta\).

$$ \theta = \cos^{-1} \left( \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|} \right) $$

Intuition

  • θ = 0°: Parallel, maximum correlation.
  • θ = 90°: Orthogonal, zero correlation.
  • θ = 180°: Opposite, maximum negative correlation.

2. Document Embeddings & NLP

The "King - Man + Woman = Queen" Logic

In Word2Vec and Transformer embeddings, semantic relationships are often captured as angles. If the angle between "Paris" and "France" is similar to the angle between "Berlin" and "Germany", the model has effectively learned the concept of "Capital of".

  • Attention Scores: Softmax over dot products (angles) decides which words are "seeing" each other.
  • Query-Key Alignment: High attention occurs when the query vector and key vector have a small angle.

3. Python: Calculating the Angle

import numpy as np

u = np.array([1, 0])
v = np.array([1, 1])

cosine_theta = np.dot(u, v) / (np.linalg.norm(u) * np.linalg.norm(v))
theta_rad = np.arccos(np.clip(cosine_theta, -1.0, 1.0))
theta_deg = np.degrees(theta_rad)

print(f"Angle: {theta_deg:.2f}°") # Output: 45.00°

Prob 1.4 Inference

Bayes' Theorem

Prior + Likelihood = Posterior.

Flipping Conditional Probabilities

Bayes' Theorem allows us to reverse the condition: if we know \(P(B|A)\), how do we find \(P(A|B)\)? \[ P(A|B) = \frac{P(B|A) P(A)}{P(B)} \]

  • \(P(A)\) Prior: Belief before seeing data.
  • \(P(B|A)\) Likelihood: How probable is evidence \(B\) if \(A\) is true?
  • \(P(B)\) Evidence: Total probability of observing \(B\).
  • \(P(A|B)\) Posterior: Belief after seeing data.

2. ML Connection: Bayesian Inference

Parameter Estimation

In Machine Learning, we want \(P(\text{Model} | \text{Data})\). We calculate it by: \[ P(\theta | X) \propto P(X | \theta) P(\theta) \] This combines the Fit (Likelihood) with Regularization (Prior). L2 Regularization (Weight Decay) is mathematically equivalent to a Gaussian Prior on the weights!

3. Python: Medical Test

bayes_solver.py
# Disease Rate (Prior) P(D) = 0.01
# Test Accuracy (Likelihood):
# P(Pos | D) = 0.99 (True Positive)
# P(Pos | No D) = 0.05 (False Positive)

# Question: If Test is Positive, what is prob of Disease? P(D | Pos)

p_d = 0.01
p_nod = 0.99
p_pos_given_d = 0.99
p_pos_given_nod = 0.05

# Law of Total Prob for Evidence P(Pos)
p_pos = (p_pos_given_d * p_d) + (p_pos_given_nod * p_nod)

# Bayes
p_d_given_pos = (p_pos_given_d * p_d) / p_pos

print(f"Prob of Disease given Positive Test: {p_d_given_pos:.4f}")
# Result is only ~16%! (Base rate fallacy)

06. Applied Optimization

Finding the "Best" solution under constraints.

1. The Goal

Optimization is the process of finding the maximum or minimum value of a function that represents a real-world quantity (cost, profit, distance, time).

2. The Workflow

  1. Define the Objective Function (the thing you want to maximize/minimize).
  2. Identify the Constraints (rules that limit your variables).
  3. Substitute constraints into the objective function to reduce it to one variable.
  4. Find the critical points and verify using the 1st or 2nd derivative test.

3. AI/ML Connection: Hyperparameter Tuning

Minimizing the Meta-Loss

In AutoML and Neural Architecture Search (NAS), we don't just optimize weights—we optimize the model itself. For example, "What is the optimal number of layers that maximizes accuracy while staying under 1GB of GPU memory?"

This is a classical applied optimization problem. We have an objective (Accuracy) and a constraint (Memory). Using calculus-based optimization (or its discrete equivalents in Bayesian Optimization), AI systems can automatically "tune" themselves to find the best possible configuration for a given hardware limit.

4. Python: Maximize Area with Fixed Perimeter

# Perimeter P = 2w + 2h = 100
# Find dimensions to maximize Area A = w * h
# Constraint: h = 50 - w
# Objective: A = w * (50 - w) = 50w - w^2

import sympy as sp

w = sp.Symbol('w')
A = 50*w - w**2
A_prime = sp.diff(A, w)

# Solve A' = 0
width = sp.solve(A_prime, w)[0]
height = 50 - width

print(f"Optimal Dimensions: {width} x {height}")
print(f"Max Area: {width * height}")

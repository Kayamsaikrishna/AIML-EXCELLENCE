Stats 1.7 Generalization

Generalized Linear Models (GLM)

Breaking the chains of Normality. How to do regression when your data is binary, counts, or strictly positive.

The Problem with OLS

Standard OLS assumes your errors are Normal (\(-\infty\) to \(+\infty\)). But what if you're predicting "Number of Website Visits"? You can't have -5 visits. What if you're predicting "Customer Churn"? You can't be 1.5 "churned".

GLMs solve this by using a Link Function to map the linear model's output to a valid space.

1. The Three Components of a GLM

1. Random Component

The probability distribution of the target (e.g., Bernoulli for Binary, Poisson for Counts).

2. Systematic Component

The linear predictor: \(\eta = \beta_0 + \beta_1 X_1 + ... + \beta_p X_p\).

3. Link Function (\(g\))

The math that connects the linear predictor to the mean of the distribution: \(g(\mu) = \eta\).

2. Common Link Functions

Distribution Link Function Predicts...
Normal (Gaussian) Identity (\(\mu = \eta\)) Continuous values (OLS)
Bernoulli / Binomial Logit (\(\ln(\frac{\mu}{1-\mu}) = \eta\)) Probabilities (0 to 1)
Poisson Log (\(\ln(\mu) = \eta\)) Counts (0 to \(\infty\))
Gamma Inverse (\(\frac{1}{\mu} = \eta\)) Waiting times, Insurance claims

3. ML Connection: Neural Network Activations

Deep Learning Architectures

Link Functions are Activations

Every modern Neural Network is essentially a "Chain of GLMs".

  • Sigmoid Activation: This is literally the Inverse Logit link function. It squeezes values into (0, 1) for classification.
  • Softmax Activation: The multi-class version of the logit link.
  • Exponential Activation: Used in the output layer of networks predicting strictly positive values (Counts/Demand).
In Insurance Tech (InsurTech), GLMs are still the regulated standard. You cannot use a "Black Box" to set premiums; you must show the GLM link and the coefficients.

System Determinacy

Over, Under, or Well-Determined. The shape of A matters.

1. Definitions

  • Overdetermined (\( m > n \)): Too much info. Usually inconsistent. Solution is an approximation (Least Squares).
  • Underdetermined (\( m < n \)): Not enough info. Infinite solutions. Solution requires an extra condition (e.g., "Find smallest \( x \)").
  • Well-Determined (\( m = n \)): Just enough. Unique solution if non-singular.

2. Overfitting & Regularization

Underdetermined systems are like Neural Networks (millions of weights, thousands of examples). They can memorize data perfectly (overfitting).

To fix this, we impose constraints (L1/L2 Regularization), effectively changing the problem from "Solve \( Ax=b \)" to "Solve \( Ax=b \) AND keep \( x \) small". This makes the solution unique and stable.

3. Regularized Solution (Ridge)

import numpy as np
from sklearn.linear_model import Ridge

# Underdetermined: 1 sample, 2 features
# x1 + x2 = 10
X = np.array([[1.0, 1.0]])
y = np.array([10.0])

# Infinite solutions: (5,5), (0,10), (10,0)...

# Ridge Regression imposes L2 penalty: min ||y - Xw||^2 + alpha * ||w||^2
# This favors the solution with smallest norm (5, 5)
ridge = Ridge(alpha=1.0, fit_intercept=False)
ridge.fit(X, y)

print(f"Details: Coeffs: {ridge.coef_}")
# Expect close to [5, 5] (balanced)

# Analytical Solution: w = (X^T X + alpha I)^-1 X^T y
alpha = 1.0
I = np.eye(2)
w_analytic = np.linalg.inv(X.T @ X + alpha * I) @ X.T @ y
print(f"Analytical: {w_analytic}")

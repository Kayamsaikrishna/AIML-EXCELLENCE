02. Functions of Several Variables

Mappings from vector space to scalar space.

1. What is a Multivariable Function?

Instead of a function \(y = f(x)\) taking one input, a multivariable function \(z = f(x, y)\) takes two (or more) independent inputs to produce one output.

  • Domain: A region in the \(xy\)-plane.
  • Range: A set of values on the \(z\)-axis.
  • Level Curves: Slices of the surface at a constant height (\(f(x, y) = k\)).

2. Visualizing with Level Curves

Level curves are like Topographic Maps of a mountain. If the curves are close together, the mountain is steep. In AI, these are called Contour Plots.

3. AI/ML Connection: Loss Isocontours

Visualizing Gradient Descent

When training a model with two weights (\(w_1, w_2\)), we visualize the error as a contour plot. Gradient Descent always moves perpendicular to these level curves.

If the level curves are "elongated" (elliptical), it means the model is much more sensitive to one weight than the other—leading to zig-zagging training paths. Understanding the shape of these level curves allows researchers to design better Normalization techniques (like Batch Norm) that "circle out" the contours, making optimization smoother and faster.

4. Python: Contour Plotting

import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(-2, 2, 100)
y = np.linspace(-2, 2, 100)
X, Y = np.meshgrid(x, y)
Z = X**2 + Y**2 # Sphere/Paraboloid contours

plt.contour(X, Y, Z, levels=20)
plt.title("Level Curves of z = x^2 + y^2")
plt.xlabel("w1")
plt.ylabel("w2")
plt.show()

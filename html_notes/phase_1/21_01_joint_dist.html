Prob 1.4 The Big Picture

Joint Distributions

Understanding how multiple random variables behave together.

Beyond One Dimension

In the previous modules, we looked at variables in isolation (e.g., just height or just weight). But in Machine Learning, we deal with Feature Vectors.

A data point is rarely a single number; it's a combination of features that are often related. The Joint Distribution captures the probability of all these variables occurring simultaneously.

1. Discrete Joint PMF

For discrete RVs \(X\) and \(Y\), the Joint Probability Mass Function is: $$ p(x, y) = P(X = x, Y = y) $$ Properties:
  • \(0 \le p(x, y) \le 1\)
  • \(\sum_x \sum_y p(x, y) = 1\) (The total mass in the grid must sum to 1).

Visualization: Think of a 2D table where rows are \(X\) values and columns are \(Y\) values. Each cell contains the probability of that specific pair.

2. Continuous Joint PDF

For continuous RVs \(X\) and \(Y\), the Joint Probability Density Function is \(f(x, y)\): $$ P(a \le X \le b, c \le Y \le d) = \int_c^d \int_a^b f(x, y) \, dx \, dy $$ Properties:
  • \(f(x, y) \ge 0\)
  • \(\int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f(x, y) \, dx \, dy = 1\) (Volume under the surface equals 1).

Visualization: Instead of a 1D curve, you have a 2D Surface (like a mountain or a bowl) over the \(XY\) plane. The height of the surface at \((x, y)\) is the density.

3. The Joint CDF

The Cumulative Distribution Function for multiple variables: $$ F(x, y) = P(X \le x, Y \le y) $$

This asks: "What is the probability that \(X\) is below a threshold AND \(Y\) is below a threshold?" Geometrically, this is the mass/volume in the bottom-left quadrant starting from \((x, y)\).

4. ML Connection: Input Distributions

Deep Learning Generative Models

Modeling $P(X)$

In Generative AI (VAEs, GANs, Diffusion), our goal is often to learn the Joint Distribution of pixels in an image.

Pixels are not independent. If pixel \((i, j)\) is part of a blue sky, its neighbor \((i+1, j)\) is very likely blue as well. Understanding these joint dependencies is what allows AI to generate coherent patterns rather than random noise.

Feature Interaction

In structured data (like a housing dataset), 'Square Footage' and 'Number of Bedrooms' have a strong joint relationship. A model that understands their joint behavior can better predict the 'Price' than one that looks at them independently.

5. Python: Visualizing Joint Density

Python: 2D Density Plot

import seaborn as sns
import matplotlib.pyplot as plt
import numpy as np

# Generate correlated data
mean = [0, 0]
cov = [[1, 0.8], [0.8, 1]]
x, y = np.random.multivariate_normal(mean, cov, 5000).T

# Create a Joint Plot
sns.jointplot(x=x, y=y, kind="kde", color="teal")
plt.show()

# Observe how the "mountain" is stretched along the diagonal.

Graph Theory Data Structures

Graph Representations

From Topology to Bitmaps. How we store and manipulate graphs in computer memory — balancing space complexity with lookup speed.

Matrix vs. List

A graph is a mathematical ideal. In a computer, it must be a data structure. The choice between a Matrix (dense) and a List (sparse) defines the efficiency of every algorithm from PageRank to Pathfinding.

1. Adjacency Matrix (\(A\))

An \(n \times n\) matrix where \(A_{ij} = 1\) if there is an edge between \(i\) and \(j\), and \(0\) otherwise.

$$ A = \begin{bmatrix} 0 & 1 & 0 \\ 1 & 0 & 1 \\ 0 & 1 & 0 \end{bmatrix} $$

Symmetry

For undirected graphs, the Adjacency Matrix is always symmetric (\(A = A^T\)).

Pros & Cons

Pros: \(O(1)\) edge lookup. Cons: \(O(V^2)\) space — wasteful for sparse graphs.

2. Adjacency List

An array of lists. Index \(i\) contains a list of all neighbors of vertex \(i\).

# Example List representation
graph = {
    'A': ['B'],
    'B': ['A', 'C'],
    'C': ['B']
}

Space Complexity

\(O(V + E)\). This is the gold standard for real-world networks (like the internet or social media) where most people are only connected to a tiny fraction of the whole.

Deep Learning Optimization

Representations in AI

  • Adjacency Matrix Powers: In Graph Neural Networks, calculating the matrix power \(A^k\) tells us about the connectivity of nodes \(k\) hops away. This is the heart of "Message Passing" mechanisms.
  • Sparse Tensors: Modern deep learning libraries (PyTorch Geometric, DGL) use sparse matrix formats (COO, CSR) for Adjacency Lists to perform high-speed tensor operations on giant graphs.
  • Attention Matrices: In Transformers, the Self-Attention matrix is essentially a *weighted complete graph* Adjacency Matrix, where every token (node) has a connection to every other token.
  • Laplacian Matrix (\(L = D - A\)): Used in Spectral Clustering and Graph Signal Processing to identify clusters and smooth features across a graph.

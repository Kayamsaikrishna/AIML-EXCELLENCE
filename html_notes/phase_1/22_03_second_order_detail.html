03. Second-Order Linear Differential Equations

Oscillations, vibration, and balanced systems.

1. The General Form

A second-order linear ODE with constant coefficients looks like this:

$$ ay'' + by' + cy = 0 $$

To solve it, we assume a solution of the form \(y = e^{rx}\), which leads to the Characteristic Equation:

$$ ar^2 + br + c = 0 $$

2. The Three Solution Cases

  • Distinct Real Roots: \(y = C_1 e^{r_1 x} + C_2 e^{r_2 x}\)
  • Repeated Real Roots: \(y = (C_1 + C_2 x) e^{rx}\)
  • Complex Roots (\(\alpha \pm \beta i\)): \(y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)\)

3. AI/ML Connection: Momentum and Convergence

The Heavy-Ball Algorithm

When we add Momentum to Gradient Descent (to help it roll through flat regions), the optimization path changes from a first-order flow to a Second-Order Dynamical System.

Specifically, the "Momentum" term behaves like the "Damping" coefficient (\(b\)) in a mass-spring system. If we pick the wrong coefficients, the AI might **Oscillate** wildly (Complex Roots) around the target or take forever to settle (Over-damped). Understanding second-order ODEs allows researchers to tune Optimizer Hyperparameters (like \(\gamma\) in Adam) to ensure the model settles into the minimum smoothly without bouncing away.

4. Python: Characteristic Solver

# For y'' - 5y' + 6y = 0
# Eq: r^2 - 5r + 6 = 0 -> (r-2)(r-3) = 0

import numpy as np

roots = np.roots([1, -5, 6])
print(f"Roots: {roots}")

if roots[0] != roots[1]:
    print(f"Solution: C1*exp({roots[0]}x) + C2*exp({roots[1]}x)")

03. The Second Derivative Test

Using curvature to identify extrema.

1. The Test

If \(c\) is a critical point where \(f'(c) = 0\), we can use the second derivative \(f''(c)\) to classify it:

  • If \(f''(c) > 0\), the function is concave up (smiling) \(\to\) Local Minimum.
  • If \(f''(c) < 0\), the function is concave down (frowning) \(\to\) Local Maximum.
  • If \(f''(c) = 0\), the test is inconclusive (use the First Derivative Test).

2. Advantages

Unlike the First Derivative Test, which requires checking two points (left and right), the Second Derivative Test only requires checking the critical point itself. This makes it much faster for computers to calculate if the function is mathematically well-defined.

3. AI/ML Connection: Avoiding Saddle Points

The Curvature Constraint

In high-dimensional AI, we often run into Saddle Points. These are points where the gradient is zero, but it's a minimum in one direction and a maximum in another.

Simple 1st-order gradient descent can get "stuck" at a saddle point because it thinks it has found a minimum. By calculating the second derivatives (the Hessian Eigenvalues), we can check if the curvature is positive in all directions. If it's not, we know we are at a saddle point and need to keep searching. This is why second-order information is so valuable for complex loss landscapes.

4. Python: Automated Point Classification

import sympy as sp

x = sp.Symbol('x')
f = x**3 - 3*x + 5
f1 = sp.diff(f, x)
f2 = sp.diff(f1, x)

crit_points = sp.solve(f1, x)

for c in crit_points:
    val = f2.subs(x, c)
    if val > 0:
        print(f"Point {c} is a Local Minimum (Concave Up)")
    elif val < 0:
        print(f"Point {c} is a Local Maximum (Concave Down)")

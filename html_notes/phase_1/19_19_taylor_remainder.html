19. Taylor's Remainder Theorem

Exactly how wrong is our approximation?

1. The Formula

If we approximate a function \(f(x)\) using a Taylor polynomial \(P_n(x)\) of degree \(n\), the error (or remainder) \(R_n(x)\) is given by Lagrange's Form:

$$ R_n(x) = \frac{f^{(n+1)}(z)}{(n+1)!} (x - a)^{n+1} $$

Where \(z\) is some unknown number between \(a\) and \(x\). While we don't know \(z\), we can often find the maximum possible value of the \((n+1)\)-th derivative to find the Error Bound.

2. Convergent Approximation

A Taylor series only equals the function if the limit of the remainder goes to zero as \(n\) goes to infinity. If \(\lim R_n(x) = 0\), the approximation is perfect.

3. AI/ML Connection: Safety Bounds

Worst-Case Error Guaruntees

In Autonomous Driving or Robotic Surgery, "Approximately Correct" isn't enough. If an AI uses a Taylor series to predict the movement of a car, we must know the Maximum Possible Error.

By using the Remainder Theorem, engineers can calculate that even if the AI is "wrong", it will never be wrong by more than, say, 2 centimeters. This "Safe Offset" is added to the robot's collision avoidance logic. If we can't bound the Taylor Remainder, we can't get safety certification for AI in the real world. Calculus literally provides the "Safety Net" for intelligent systems.

4. Python: Calculating Error Bounds

# Approximating sin(0.5) with 3 terms
# Remainder R_3 depends on 4th derivative (sin(x) -> cos -> -sin -> -cos -> sin)
# Max value of sin(z) is 1.0.

def error_bound(x, n):
    import math
    # Bound = M / (n+1)! * |x-a|^(n+1) where M is max of (n+1)th deriv
    m = 1.0 # max of sin/cos derivatives
    return m / math.factorial(n+1) * (x**(n+1))

x_val = 0.5
print(f"Max Error for 3 terms at x=0.5: {error_bound(x_val, 3):.8f}")

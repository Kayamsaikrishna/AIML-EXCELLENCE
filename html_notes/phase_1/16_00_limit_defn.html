00. Limit Definition of the Derivative

The instantaneous rate of change.

1. The Difference Quotient

The average slope between two points \((x, f(x))\) and \((x+h, f(x+h))\) is:

$$ m_{sec} = \frac{f(x+h) - f(x)}{h} $$

As \(h\) shrinks to zero, the secant line becomes the Tangent Line.

2. The Formal Definition

$$ f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} $$

This is the core identity of all Calculus. If this limit exists, we say \(f\) is Differentiable at \(x\).

3. AI Connection: Numerical Gradients

When we test if a complex Neural Network's "Auto-Grad" system is working correctly, we perform a Gradient Check. We calculate the slope using this limit definition with a tiny \(h\) (e.g., \(10^{-7}\)) and compare it to the analytical derivative. This is the ultimate "Ground Truth" for optimization.

4. Python: Deriving from Definition

import sympy as sp

x, h = sp.symbols('x h')
f = x**2

# Apply definition: lim_{h->0} (f(x+h) - f(x)) / h
diff_quotient = (f.subs(x, x + h) - f) / h
derivative = sp.limit(diff_quotient, h, 0)

print(f"Function: {f}")
print(f"Derivative via Definition: {derivative}")

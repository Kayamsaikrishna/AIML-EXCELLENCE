1. Vertical & Horizontal Shifts

Functions can be moved around:

  • \( f(x) + k \): Shift Up
  • \( f(x-h) \): Shift Right (Counter-intuitive!)

AI: Normalization (Z-Score)

We shift data to center it at 0 and scale it to variance 1. This helps Gradient Descent converge faster.

$$ x_{norm} = \frac{x - \mu}{\sigma} $$

2. Transformations as Data Augmentation

In Computer Vision, we artificially expand the dataset by applying random transformations.

  • Rotation: Rotate image by \(\theta\).
  • Flip: Reflection across axis.
  • Shear: Slanting the image.

This forces the model to learn Invariant Features (e.g., a cat is still a cat even if tilted).

3. Implementing Transforms

Using Affine Matrices to rotate points.

import numpy as np
import matplotlib.pyplot as plt

def rotate_point(point, angle_degrees):
    theta = np.radians(angle_degrees)
    # Rotation Matrix
    R = np.array([
        [np.cos(theta), -np.sin(theta)],
        [np.sin(theta),  np.cos(theta)]
    ])
    return np.dot(R, point)

x = np.array([1, 0]) # Point on X axis
x_rot = rotate_point(x, 90)

print(f"Original: {x}")
print(f"Rotated 90 deg: {x_rot}") 
# Should be close to [0, 1] (allowing for float error)

# Normalization Logic
data = np.array([10, 20, 30, 40, 50])
norm_data = (data - np.mean(data)) / np.std(data)
print(f"Normalized Mean: {np.mean(norm_data):.2f}") # Should be 0.00

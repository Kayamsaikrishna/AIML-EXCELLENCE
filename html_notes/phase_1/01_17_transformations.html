17. Transformations & Augmentation

Shifting, Scaling, and Flipping. Teaching AI Invariance.

1. The Logic of Movement

$$ g(x) = A \cdot f(B(x - C)) + D $$

The Components

  • C (Horizontal Shift): Moves graph Left/Right.
  • D (Vertical Shift): Moves graph Up/Down. (Bias in NN).
  • A (Vertical Scaling): Amplitude. (Weight in NN).
  • B (Horizontal Scaling): Frequency/Speed.

2. Data Augmentation

If we want an AI to recognize a "Cat", it should recognize the cat whether it's in the center, the corner, or zoomed in.

We Transformation the training data randomly so the model learns Translational Invariance.

Mathematical Invariance

We want the Neural Network Function \( N(x) \) to satisfy:

$$ N(\text{Shift}(x)) \approx N(x) $$

Convolutional Neural Networks (CNNs) have this built-in for small shifts via Pooling Layers.

3. Coding Augmentations

PyTorch's `torchvision.transforms` is a library of mathematical functions applied to images.

// PyTorch: Augmentation Pipeline
import torch
from torchvision import transforms

# Define a pipeline of transformations
# 1. Flip Horizontally (Reflection over Y-axis)
# 2. Random Rotation (Coordinate Rotation matrix)
# 3. Convert to Tensor (Normalization)
transform = transforms.Compose([
    transforms.RandomHorizontalFlip(p=0.5), # f(-x)
    transforms.RandomRotation(degrees=15),  # Rotation Matrix R
    transforms.ToTensor()
])

print("Pipeline Ready. This teaches the model 'Invariance'.")

The Undo Button

\( A^{-1} \). Reversing space. Why we rarely compute it explicitly in AI.

1. Definition

The inverse \( A^{-1} \) is the unique matrix that, when multiplied by \( A \), returns the Identity matrix.

$$ A^{-1}A = I \quad \text{and} \quad AA^{-1} = I $$

This allows us to solve \( A\mathbf{x} = \mathbf{b} \) by simply multiplying: \( \mathbf{x} = A^{-1}\mathbf{b} \).

2. The Condition Number

In practice (Deep Learning), we almost NEVER calculate \( A^{-1} \) explicitly.

  • Computational Cost: \( O(n^3) \). Too slow for big matrices.
  • Stability: If \( A \) is "almost" singular (Condition Number is high), dividing by small numbers causes massive exploding errors.

Instead, we use solvers like Gaussian Elimination or LU Decomposition.

3. The Inverse vs Solver

Comparing explicit inversion vs efficient solving.

import numpy as np
import time

# Large Matrix
N = 1000
A = np.random.rand(N, N)
# Ensure it's invertible by adding Identity (Diagonally dominant)
A = A + np.eye(N) * N 
x_true = np.random.rand(N)
b = np.dot(A, x_true)

# Method 1: Explicit Inverse (Slow & Less Precise)
t0 = time.time()
A_inv = np.linalg.inv(A)
x_inv = np.dot(A_inv, b)
t1 = time.time()
print(f"Inverse Time: {t1-t0:.4f}s")

# Method 2: Solver (Fast & Stable)
t0 = time.time()
x_solve = np.linalg.solve(A, b)
t1 = time.time()
print(f"Solver Time:  {t1-t0:.4f}s")

# Check Errors
err_inv = np.linalg.norm(x_true - x_inv)
err_solve = np.linalg.norm(x_true - x_solve)

print(f"Error (Inv):   {err_inv:.4e}")
print(f"Error (Solve): {err_solve:.4e}")

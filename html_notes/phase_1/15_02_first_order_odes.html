DiffEq 1.8 Fundamentals

First-Order ODEs

Modeling rates of change in simple systems.

Separation & Integration

A first-order ODE involves \(y' = \frac{dy}{dt}\) and \(y\). The simplest method to solve them is Separable Equations: \[ \frac{dy}{dt} = g(t)h(y) \Rightarrow \int \frac{1}{h(y)} dy = \int g(t) dt \]

For linear first-order equations \(y' + p(t)y = g(t)\), we use an Integrating Factor \(I(t) = e^{\int p(t) dt}\) to turn the LHS into a product rule derivative.

2. AI/ML Connection: Optimization Flow

Gradient Flow

Gradient Descent with an infinitely small learning rate is actually a First-Order ODE known as Gradient Flow: \[ \frac{d\mathbf{w}}{dt} = - \nabla L(\mathbf{w}) \]

By studying the behavior of this differential equation, we can prove convergence properties of Neural Networks even in non-convex settings (like the "Neural Tangent Kernel" regime).

3. Python: Vector Fields

vector_field_plot.py
import numpy as np
import matplotlib.pyplot as plt

# ODE: y' = y - t
# Defines a "slope" at every point (t, y)

t = np.linspace(-2, 2, 20)
y = np.linspace(-2, 2, 20)
T, Y = np.meshgrid(t, y)

dT = np.ones(T.shape) # Move 1 unit in time
dY = Y - T           # Change in y

# Normalize arrows
N = np.sqrt(dT**2 + dY**2)
dT, dY = dT/N, dY/N

plt.figure(figsize=(8, 6))
plt.quiver(T, Y, dT, dY, color='#4fd1c5')
plt.title("Slope Field for y' = y - t")
plt.xlabel("t")
plt.ylabel("y")
plt.grid(True, alpha=0.3)
# To solve the ODE is to "follow the arrows"
plt.show()

Calculus 1.3 Ratios

The Quotient Rule

How to differentiate a competition between two forces (Numerator vs Denominator).

The "Lo-D-Hi" Mnemonic

This rule is notoriously hard to remember because order matters (subtraction). Memorize this chant:
"Low D-High minus High D-Low, over the square of what's below."

1. The Formula

For two differentiable functions \(u(x)\) (High) and \(v(x)\) (Low):

\[ \frac{d}{dx} \left[ \frac{u(x)}{v(x)} \right] = \frac{v(x)u'(x) - u(x)v'(x)}{[v(x)]^2} \]

2. AI/ML Connection: Softmax Gradient

Why Softmax is Hard

The Softmax activation function turns logits into probabilities: \[ p_i = \frac{e^{z_i}}{\sum e^{z_j}} \]

When we maximize the probability of the correct class (via Log-Likelihood), we need the gradient of this ratio.

  • If \(i = j\): The term \(e^{z_i}\) is in both numerator and denominator.
  • If \(i \ne j\): The term \(e^{z_j}\) is only in the denominator.

The Quotient Rule derived the famous Jacobian matrix for Softmax: \[ \frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j) \] This clean result comes purely from applying "Lo-D-Hi" and simplifying.

3. Python: Symbolic Quotient Logic

quotient_rule_check.py
import sympy as sp

x = sp.Symbol('x')

# Define u (High) and v (Low) for the Sigmoid function
# Sigmoid = 1 / (1 + e^-x)
u = 1
v = 1 + sp.exp(-x)

# 1. Quotient Rule Formula
# (v * u' - u * v') / v^2
u_prime = sp.diff(u, x) # 0
v_prime = sp.diff(v, x) # -e^-x
formula_res = (v * u_prime - u * v_prime) / v**2

# 2. Direct Differentiation
direct_res = sp.diff(u/v, x)

print(f"Sigmoid Derivative (Formula): {sp.simplify(formula_res)}")
print(f"Sigmoid Derivative (Direct):  {sp.simplify(direct_res)}")

# Show that Sigmoid derivative is s(1-s)
sigmoid = u/v
magic_property = sigmoid * (1 - sigmoid)
print(f"Sigmoid Property s(1-s):      {sp.simplify(magic_property)}")

if sp.simplify(direct_res - magic_property) == 0:
    print("\n✅ Verified: The Quotient Rule confirms the Sigmoid derivative property.")

16. Moore-Penrose Pseudoinverse

Inverting the un-invertible.

1. The Problem: Rectangular Systems

In Linear Regression, we often have \(\mathbf{y} = \mathbf{Xw}\) where \(\mathbf{X}\) is \(m \times n\) (more data than features). There is no standard inverse if \(m \neq n\). We need a "best fit" inverse.

2. The SVD Solution

The pseudoinverse \(\mathbf{A}^+\) is elegantly defined using the components of SVD:

$$ \mathbf{A}^+ = \mathbf{V}\Sigma^+\mathbf{U}^T $$

Where \(\Sigma^+\) is obtained by taking the reciprocal of every non-zero entry on the diagonal of \(\Sigma\) and then transposing the matrix.

Numerical Stability

In practice, we only take the reciprocal of singular values that are larger than a small epsilon (\(\text{rel\_tol}\)). Small singular values are usually noise; reciprocating them would blow up the inverse and cause massive numerical errors.

3. AI Application: Least Squares

The closed-form solution to the Normal Equation in Linear Regression is:

$$ \mathbf{w} = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y} $$

Numerically, we prefer using the Pseudoinverse directly: \(\mathbf{w} = \mathbf{X}^+\mathbf{y}\). This is more robust to redundant (linearly dependent) features.

4. Python: Comparing Inverses

import numpy as np

# A non-square matrix (Rank deficient)
A = np.array([[1, 2], [2, 4]]) # Col 2 is exactly 2*Col 1

# Standard inverse fails
try:
    np.linalg.inv(A)
except np.linalg.LinAlgError:
    print("Standard inverse failed (Singular matrix)")

# Pseudoinverse succeeds
A_pinv = np.linalg.pinv(A)
print(f"Pseudoinverse:\n{A_pinv}")

# Property: A @ A_pinv @ A should be A
print(f"A_pinv property check: {np.allclose(A @ A_pinv @ A, A)}")

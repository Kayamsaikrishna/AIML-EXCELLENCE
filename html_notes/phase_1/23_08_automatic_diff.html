08. Automatic Differentiation (Autodiff)

The engine that makes deep learning possible.

1. Not Symbolic, Not Numerical

Automatic Differentiation (AD) is a set of techniques to programmatically evaluate the derivative of a function. It differs from Symbolic Differentiation (which is complex to automate) and Numerical Differentiation (which has precision errors). AD uses the exact calculus rules but applies them to numerical values at runtime.

2. Forward vs. Reverse Mode

  • Forward Mode: Calculates derivatives alongside the primal values. Efficient for finding the derivative of many outputs with respect to a single input.
  • Reverse Mode: The foundation of deep learning. It calculates the derivative of a single output (The Loss) with respect to millions of inputs (The Weights). It requires a "Forward Pass" to store intermediate values and a "Backward Pass" to apply the chain rule.

3. AI/ML Connection: The Secret Sauce

PyTorch and TensorFlow

When you call `loss.backward()` in PyTorch, you are triggering Reverse Mode Automatic Differentiation.

The library builds a mathematical graph of every operation your data went through. Each operation (like addition, multiplication, or a ReLU) has a predefined "Derivative Rule" stored in the framework. By traversing the graph backward and multiplying these rules (Chain Rule), the AI calculates the exact gradient for every single weight in seconds. Without Automatic Differentiation, we would still be limited to very shallow models; it is the single most important mathematical optimization in computer science history for AI.

4. Python: Simplified Autograd Node

class Node:
    def __init__(self, value, grad=0.0):
        self.value = value
        self.grad = grad
        self.backward = lambda: None

def add(a, b):
    result = Node(a.value + b.value)
    def backward():
        a.grad += result.grad
        b.grad += result.grad
        a.backward()
        b.backward()
    result.backward = backward
    return result

# AD handles the chain rule automatically by stacking these backward functions.

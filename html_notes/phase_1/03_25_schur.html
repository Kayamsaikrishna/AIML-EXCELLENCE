25. Schur Decomposition

Unitary transformations for stability analysis.

1. The Theorem

Every square matrix \( \mathbf{A} \) (with potentially complex eigenvalues) can be factored as:

$$ \mathbf{A} = \mathbf{QTQ}^H $$

Where \( \mathbf{Q} \) is a Unitary Matrix (\( \mathbf{Q}^H\mathbf{Q} = \mathbf{I} \)) and \( \mathbf{T} \) is an Upper Triangular Matrix (Schur Form).

2. Importance in Control & Stability

Theoretical Cornerstone

Unlike Eigendecomposition (which requires the matrix to be diagonalizable), Schur Decomposition always exists for any square matrix. This makes it a primary tool for numerical stability proofs in control systems and recurrent neural networks (RNNs).

  • Stability: The diagonal elements of \( \mathbf{T} \) are the eigenvalues of \( \mathbf{A} \). If any \( \text{Re}(\lambda) > 0 \), the system is unstable (Exploding Gradients).
  • Base for other Decompositions: Most computer algorithms first reduce a matrix to Schur form before finding SVD or Eigendecomposition.

3. Python: Real Schur Form

import numpy as np
from scipy.linalg import schur

A = np.array([[0, 2, 2], [0, 1, 2], [1, 0, 1]])

# T is the (quasi) upper triangular schur form
T, Q = schur(A)

print(f"Schur Form T:\n{np.round(T, 2)}")
print(f"Eigenvalues: {np.diag(T)}")

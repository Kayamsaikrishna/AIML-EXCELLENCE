Calculus 1.5 Sequences

Sequence Convergence

Predicting the destination of an infinite journey.

The Limit of a List

A sequence is simply an ordered list of numbers: \(a_1, a_2, a_3, \dots\). We ask one fundamental question: As \(n\) gets infinitely large, does \(a_n\) settle on a single value? If yes, it Converges. If no (it oscillates or goes to infinity), it Diverges.

1. Formal Definition

A sequence \(\{a_n\}\) converges to limit \(L\) if for every target precision \(\epsilon > 0\), there is a cutoff point \(N\) such that all future terms are within \(\epsilon\) of \(L\). \[ \lim_{n \to \infty} a_n = L \]

2. AI/ML Connection: Optimization & Time Series

Training Dynamics

In Deep Learning, the Weights of a neural network over time are a sequence: \(W_0, W_1, W_2, \dots\). We want this sequence to converge to an optimal set of weights \(W^*\).

Similarly, in Recurrent Neural Networks (RNNs), we process sequences of data (like words in a sentence or stock prices). If the gradients in an RNN sequence explode (diverge) or vanish (converge to 0 too fast), learning fails. This is known as the Exploding/Vanishing Gradient Problem.

3. Python: Simulating Convergence

check_convergence.py
import numpy as np
import matplotlib.pyplot as plt

# Sequence: a_n = (n + 1) / n
# As n -> inf, 1 + 1/n -> 1

def sequence_term(n):
    return (n + 1) / n

n_values = [1, 10, 100, 1000, 10000]
terms = [sequence_term(n) for n in n_values]

print(f"{'n':<10} | {'a_n':<10}")
print("-" * 25)
for n, val in zip(n_values, terms):
    print(f"{n:<10} | {val:<10.6f}")

# Output shows values approaching 1.000000

02. Binomial Distribution

Counting successes in multiple independent trials.

1. Definition

A random variable $X$ follows a Binomial Distribution, denoted $X \sim B(n, p)$, if it represents the number of successes in $n$ independent Bernoulli trials, each with success probability $p$.

$$ P(X=k) = \binom{n}{k} p^k (1-p)^{n-k} $$

Where $\binom{n}{k} = \frac{n!}{k!(n-k)!}$ is the binomial coefficient.

2. Statistical Properties

  • Mean (Expected Value): $E[X] = np$
  • Variance: $Var(X) = np(1-p)$
  • MGF: $M_X(t) = ((1-p) + pe^t)^n$

3. AI/ML Connection: Voting and Classifiers

The Power of Ensembles

The Binomial distribution is why **Ensemble Learning** (like Random Forests) works so well.

Imagine you have 10 independent classifiers, each with a 70% accuracy ($p=0.7$). If you take a "Majority Vote," the aggregate classifier succeeds if $k \ge 6$ members are correct. Using the binomial formula, the probability of the ensemble being correct is much higher than any individual member. Furthermore, the Binomial distribution is used to calculate Error Bounds. When you test a model on a test set of size $n$, the number of errors it makes is a binomial random variable. This allows you to say: "Our accuracy is 92%, plus or minus 2%, with 95% confidence."

4. Python: Binomial PMF and Sampling

from scipy.stats import binom

# n=10 trials, p=0.5 (Fair coin)
n, p = 10, 0.5

# Probability of exactly 5 successes
print(f"P(X=5): {binom.pmf(5, n, p):.4f}")

# Simulate 1000 experiments
outcomes = binom.rvs(n, p, size=1000)
print(f"Average successes: {outcomes.mean()}") # Should be ~5.0

1. Toeplitz Matrices

Discrete convolution \( y = x * k \) can be written as \( y = C x \), where \( C \) is a Toeplitz Matrix. A Toeplitz matrix has constant diagonals.

$$ \begin{bmatrix} k_1 & 0 & 0 \\ k_2 & k_1 & 0 \\ k_3 & k_2 & k_1 \end{bmatrix} $$

This allows us to analyze stability using eigenvalues and implement convolutions on hardware optimized for GEMM (General Matrix Multiply).

2. Transpose Convolution

In GANs or Autoencoders, we need to upsample (Go from small to large). This is often called "Deconvolution", but mathematically it is the Transpose of the Convolution Matrix \( C^T \).

If \( C \) downsamples (stride > 1), \( C^T \) upsamples. It spreads pixels out rather than gathering them.

3. Building the Matrix

import numpy as np
from scipy.linalg import toeplitz

# Input signal
x = np.array([1, 2, 3, 4, 5])
# Kernel representing "Running Average"
k = np.array([0.5, 0.5])

# 1. Standard Convolution
conv_result = np.convolve(x, k, mode='same')
print("Function Result:", conv_result)

# 2. Toeplitz Construction
# Padding required for full/same modes
padding = len(k) - 1
first_col = np.r_[k[0], np.zeros(len(x)-1)]
first_row = np.zeros(len(x))
C = toeplitz(first_col, first_row)

# Note: Generic Toeplitz doesn't perfectly match 'same' mode logic simply
# without careful padding. This is a simplified causal filter example.

print("Convolution Matrix C:\n", C)
# Matrix vector multiply
# y = C @ x

02. Limits of Sequences

Where does an infinite list of numbers eventually go?

1. Formal Definition

A sequence \(\{a_n\}\) has the limit \(L\) if for every \(\epsilon > 0\), there exists an integer \(N\) such that if \(n > N\), then \(|a_n - L| < \epsilon\).

2. Limit Laws

Limits of sequences behave exactly like limits of functions. If \(\lim a_n = A\) and \(\lim b_n = B\):

  • \(\lim (a_n \pm b_n) = A \pm B\)
  • \(\lim (a_n \cdot b_n) = A \cdot B\)
  • \(\lim \frac{a_n}{b_n} = \frac{A}{B}\) (if \(B \neq 0\))

3. AI/ML Connection: The Stop Criterion

Convergence Monitoring

In Machine Learning, we don't train forever. We look at the sequence of "Validation Errors" after each epoch. If the limit of this sequence is approaching a constant value (meaning the error is no longer dropping), the model has Converged.

Engineers use a "Patience" parameter (the \(N\) in our limit definition) to decide when to stop. If the error doesn't change by more than \(\epsilon\) for \(N\) steps, we assume we've reached the limit of what the model can learn and stop the training process to save time and power.

4. Python: Simulating Sequence Limits

# Sequence: a_n = (4n^2 + 1) / (2n^2)
# Theoretical limit: 4/2 = 2.0

def a_n(n):
    return (4*n**2 + 1) / (2*n**2)

for i in [1, 10, 100, 1000, 10000]:
    print(f"n={i: <6} | Value: {a_n(i):.8f}")

# As n grows, the result gets closer and closer to 2.0

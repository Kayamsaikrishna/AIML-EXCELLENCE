1. Turning Points (Wiggles)

A polynomial of degree \( n \) can have up to \( n-1 \) turning points (hills and valleys).

AI Lesson: Overfitting

If you have \( N \) data points, a polynomial of degree \( N-1 \) can pass through every single one perfectly.

But between those points, it will swing wildly toward \( \pm \infty \). This is why we prefer simpler models (Occam's Razor) or use Regularization to dampen the wild swings.

2. Runge's Phenomenon

A classic counter-intuitive example. If you try to fit equidistant points with a high-degree polynomial, the error at the edges explodes.

$$ \lim_{n \to \infty} (\max|f(x) - P_n(x)|) = \infty $$

This proves that "More Complexity" != "Better Model".

3. Seeing the Wiggle

Fitting a Degree-15 polynomial to 10 points.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

# Generate noisy sin wave data
X = np.linspace(0, 10, 10)[:, np.newaxis]
y = np.sin(X).ravel() + np.random.normal(0, 0.1, 10)

# Fit HIGHER degree than points (Degree 15)
model = make_pipeline(PolynomialFeatures(15), LinearRegression())
model.fit(X, y)

# Predict on dense grid
x_plot = np.linspace(0, 10, 100)[:, np.newaxis]
y_plot = model.predict(x_plot)

# Result: y_plot will have massive spikes between data points.
print("Training Score: 1.0 (Perfect)")
print("Real World Score: -10000.0 (Terrible)")

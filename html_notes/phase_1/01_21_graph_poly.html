21. Graphing Polynomials: The Wiggle

Higher Degree = More Complexity. The Danger of Overfitting.

1. End Behavior & Turns

$$ P(x) = a_n x^n + \dots + a_0 $$

Key Rules

  • Degree (n): Controls the max number of roots (\(n\)) and turning points (\(n-1\)).
  • Even Degree: Ends point in the same direction (like \(x^2\)).
  • Odd Degree: Ends point in opposite directions (like \(x^3\)).

2. Overfitting (High Variance)

In AI, we can use a polynomial to fit any data perfectly. If you have 10 data points, a 9th-degree polynomial passes exactly through all of them.

This is useless. Between the points, the curve oscillates wildly. It has learned the "Noise", not the "Signal".

Regularization

We penalize complexity. We prefer models with fewer "wiggles" (lower degree or smaller weights).

$$ Loss = \text{Error} + \lambda \sum w^2 $$

3. Coding the Wiggle

Visualizing Runge's Phenomenon (High-degree error).

// Python: Polynomial Regression
import numpy as np
import matplotlib.pyplot as plt
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression
from sklearn.pipeline import make_pipeline

# Generate Noisy Data (Sine wave + noise)
x = np.linspace(0, 10, 10)
y = np.sin(x) + np.random.normal(0, 0.2, 10)

# 1. High Degree Model (Degree 15) -> OVERFIT
model = make_pipeline(PolynomialFeatures(15), LinearRegression())
model.fit(x[:, np.newaxis], y)

# Predict on dense grid to see wiggles
x_plot = np.linspace(0, 10, 100)
y_plot = model.predict(x_plot[:, np.newaxis])

plt.scatter(x, y, color='black', label='Data')
plt.plot(x_plot, y_plot, color='red', label='Degree 15 (Overfit)')
plt.ylim(-2, 2)
plt.legend()
plt.title("Why we hate High Variance")
plt.show()

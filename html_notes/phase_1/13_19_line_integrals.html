Calculus 1.6 Vectors

Line Integrals & Vector Fields

Work along a path.

Accumulation along a Curve

A standard integral accumulates area along a straight line (the x-axis). A Line Integral accumulates values along a curvy path \( C \) through a specific "Field" \( \vec{F}(x, y) \).

The most common form is calculating Work: \[ W = \int_C \vec{F} \cdot d\vec{r} = \int_{a}^{b} \vec{F}(\vec{r}(t)) \cdot \vec{r}'(t) \, dt \] This sums up the dot product of the Field Vector and your Direction Vector at every step. It measures how much the field "pushes" or "pulls" you along your journey.

2. AI/ML Connection: Training Trajectories

Path to Convergence

Training a Neural Network is literally moving a point (the weights \( \vec{w} \)) through a high-dimensional landscape defined by the Gradient Field of the Loss Function.

We calculate the Path Integral (sum of gradients) along the training trajectory to measure "Effective Learning". In Reinforcement Learning, Policy Gradients are vector fields. A crucial question is: "Is the policy improvement path-dependent?" If we update weights in order A vs order B, do we end up at the same policy? Line integrals help analyze this stability (Policy Drift).

3. Python: Work Done by a Field

line_integral_work.py
import sympy as sp

t = sp.Symbol('t')

# Vector Field F(x, y) = < -y, x > (Rotation/Vortex)
# Path r(t) = < cos(t), sin(t) > (Unit Circle) from 0 to pi/2
x = sp.cos(t)
y = sp.sin(t)

F = sp.Matrix([-y, x]) # <-sin(t), cos(t)>
dr = sp.Matrix([sp.diff(x, t), sp.diff(y, t)]) # <-sin(t), cos(t)>

# Dot product F . dr
dot_prod = F.dot(dr) # (-sin)(-sin) + (cos)(cos) = sin^2 + cos^2 = 1

# Integrate from 0 to pi/2
work = sp.integrate(dot_prod, (t, 0, sp.pi/2))

print(f"Dot Product simplifies to: {sp.simplify(dot_prod)}")
print(f"Work Done: {work}")
# Result: pi/2. You are walking WITH the wind the whole time.

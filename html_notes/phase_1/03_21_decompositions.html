1. The Philosophy

Most of Linear Algebra is about finding the right Decomposition (Factorization) for the job.

  • LU? For solving systems efficiently.
  • QR? For Least Squares and Gram-Schmidt.
  • Eig/SVD? For understanding the geometry and data compression.
  • Cholesky? For speed on Symmetric Positive Definite matrices.

2. Compute Once, Solve Many

If we have to solve \( Ax = b_i \) for many different \( b \) vectors (e.g., rendering different frames), we don't want to run elimination every time.

We decompose \( A \) once (expensive), then use the factors to solve for each \( b \) (cheap).

3. Timing Test

Solve vs Decompose+Solve.

import numpy as np
import time
from scipy.linalg import lu_factor, lu_solve

N = 1000
A = np.random.rand(N, N)
b = np.random.rand(N)

# Method 1: Naive Solve (computes decomposition internally every time)
start = time.time()
for _ in range(10):
    x = np.linalg.solve(A, b)
end = time.time()
print(f"Naive Solve (10x): {end - start:.4f}s")

# Method 2: Pre-compute LU
start = time.time()
lu, piv = lu_factor(A)
prep_time = time.time() - start

start = time.time()
for _ in range(10):
    x = lu_solve((lu, piv), b)
solve_time = time.time() - start

print(f"Pre-compute Time: {prep_time:.4f}s")
print(f"Fast Solve (10x): {solve_time:.4f}s")
# Fast Solve should be much faster than Naive

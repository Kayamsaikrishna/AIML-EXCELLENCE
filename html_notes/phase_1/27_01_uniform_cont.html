01. Continuous Uniform Distribution

Constant probability density over a specific range.

1. Definition

A random variable $X$ follows a Continuous Uniform Distribution on the interval $[a, b]$, denoted $X \sim U(a, b)$, if its PDF is constant between $a$ and $b$ and zero elsewhere.

$$ f(x) = \begin{cases} \frac{1}{b-a} & \text{if } a \le x \le b \\ 0 & \text{otherwise} \end{cases} $$

2. Statistical Properties

  • Mean: $E[X] = \frac{a+b}{2}$
  • Variance: $Var(X) = \frac{(b-a)^2}{12}$
  • CDF: $F(x) = \frac{x-a}{b-a}$ for $x \in [a, b]$.

3. AI/ML Connection: Data Augmentation and Privacy

The "Blank Slate" Distribution

The continuous uniform distribution is the tool for adding Unbiased Noise to a system.

In **Data Augmentation**, when an AI "jitters" an image by slightly shifting coordinates or adjusting brightness, it often samples the shift value from a uniform distribution (e.g., $-\epsilon$ to $+\epsilon$). In **Differential Privacy**, adding uniform noise is a basic way to hide individual records while preserving aggregate statistics. Furthermore, in **Neural Architecture Search (NAS)**, when an AI explores different layer sizes or learning rates, it often uses Uniform Sampling across the space of possible values to ensure all options are explored equally before any bias towards "good" values is developed.

4. Python: Uniform PDF and Sampling

import numpy as np
from scipy.stats import uniform

# Range [a, b] = [0, 10]
# scipy uses (loc=a, scale=b-a)
dist = uniform(loc=0, scale=10)

# Simulate 5 random numbers
samples = dist.rvs(size=5)
print(f"Uniform Samples: {samples}")

# PDF at x=5
print(f"Density at 5: {dist.pdf(5)}") # Should be 1/10 = 0.1

15. Linear Combinations

The basic operation of all Neural Networks.

1. Algebraic Definition

A linear combination is a result of scaling vectors and adding them together.

$$ \mathbf{w} = c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \dots + c_n \mathbf{v}_n $$

2. The "Linear" in Neural Networks

Weighted Summing

Every single neuron in a network performs a Linear Combination of its inputs before applying a non-linear activation. The "weights" of the target model \(W\) are the scalars \(c_i\).

  • Inference: Calculating the output is just taking a linear combination.
  • Training: Adjusting the scalars \(c_i\) to minimize error.

3. Python: Manual Linear Combination

import numpy as np

# Basis Vectors
v1 = np.array([1, 0])
v2 = np.array([0, 1])

# Scalars (Weights)
c1, c2 = 2.5, -1.2

# Linear Combination
w = c1*v1 + c2*v2 

print(f"Resultant Vector: {w}") # Output: [2.5, -1.2]

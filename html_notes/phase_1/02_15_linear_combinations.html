1. The Recipe

A linear combination is formed by multiplying vectors by scalars and adding them up.

$$ \mathbf{v} = c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \dots + c_n \mathbf{v}_n $$

If you can reach a vector \( \mathbf{v} \) using vectors \( \{\mathbf{v}_i\} \), we say \( \mathbf{v} \) is "Linearly Dependent" on them.

2. The Fully Connected Layer

A "Dense" layer in a neural network is nothing more than calculating \( m \) different linear combinations of the \( n \) inputs at once.

$$ \mathbf{y} = W \mathbf{x} + \mathbf{b} $$

Here, the matrix \( W \) contains rows of weights, where each row acts as the scalars \( c_i \) for a specific output neuron.

3. Mixing Colors (RGB)

Colors are linear combinations of Red, Green, and Blue basis vectors.

import numpy as np

# Basis Vectors (Primary Colors)
Red = np.array([255, 0, 0])
Green = np.array([0, 255, 0])
Blue = np.array([0, 0, 255])

# Weights
w_r, w_g, w_b = 0.5, 0.5, 0.0 # 50% Red, 50% Green

# Linear Combination
yellow_mix = w_r * Red + w_g * Green + w_b * Blue

print(f"Resulting Color: {yellow_mix}") 
# [127.5, 127.5, 0.0] -> Dark Yellow (Olive)

# In AI, we learn these weights to produce the desired output.

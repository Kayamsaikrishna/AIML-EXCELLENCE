1. The Trap of Inverses

Since sine loops forever, it fails the "Horizontal Line Test" (not one-to-one). It has no true inverse.

To define \( \arcsin(x) \), we must restrict the domain to \( [-\pi/2, \pi/2] \).

$$ y = \arcsin(x) \iff \sin(y) = x \text{ AND } y \in [-\frac{\pi}{2}, \frac{\pi}{2}] $$

2. Cosine Similarity to Angle

Cosine Similarity gives us a score between -1 and 1. Sometimes we want the actual angle in degrees or radians.

$$ \theta = \arccos(\frac{A \cdot B}{\|A\|\|B\|}) $$

This "Angular Distance" is a valid metric (satisfies triangle inequality), whereas Cosine Similarity itself is not a true distance metric.

3. Recovering the Angle

Using Arccos to find the angle between document vectors.

import numpy as np

# Two normalized vectors (Embeddings)
v1 = np.array([1, 0])      # "King"
v2 = np.array([0.5, 0.866]) # "Queen" (60 deg away)

# Dot product (Cosine Sim)
dot = np.dot(v1, v2)
print(f"Cosine Sim: {dot:.4f}") # 0.5000

# Recover Angle (Arccos)
angle_rad = np.arccos(dot)
angle_deg = np.degrees(angle_rad)

print(f"Angle: {angle_deg:.2f} degrees")

01. Simple Linear Regression

Finding the straight-line relationship between variables.

1. The Model

Simple Linear Regression (SLR) is the attempt to model the relationship between a single independent variable $X$ and a dependent variable $Y$ using a straight line:

$$ Y = \beta_0 + \beta_1 X + \epsilon $$
  • $\beta_0$ (Intercept): The value of $Y$ when $X=0$.
  • $\beta_1$ (Slope): The change in $Y$ for a 1-unit change in $X$.
  • $\epsilon$ (Error/Residual): The random noise that the model cannot explain.

2. The "LINE" Assumptions

For SLR to be "Best Linear Unbiased Estimator" (BLUE), we assume:

  • Linearity: The relationship is actually a straight line.
  • Independence: Observations are independent.
  • Normality: Residuals follow a Normal distribution.
  • Equal Variance: Homoscedasticity (constant noise).

3. AI/ML Connection: The Foundation of Interpretable Weights

Linearity as a Feature

In AI, SLR is the **World's Most Important Baseline**.

Before you build a 100-layer Transformer, you check the Linear Regression score. In Feature Engineering**, $\beta_1$ tells the AI which features have the strongest correlation with the target. If you are predicting **House Prices**, $\beta_1$ for 'Square Footage' represents the 'Price per sq ft'. This makes Linear Regression the gold standard for Interpretability**. Unlike a Neural Network, you can point to $\beta_1$ and explain to a business stakeholder exactly *why* the prediction is what it is. It is the core of **Regularized Linear Models** (Lasso/Ridge) used in high-dimensional biological data.

4. Python: A Basic Fit

from sklearn.linear_model import LinearRegression

# X must be a 2D array for sklearn
model = LinearRegression()
model.fit(X.reshape(-1, 1), y)

print(f"Intercept: {model.intercept_}")
print(f"Slope (Weight): {model.coef_[0]}")

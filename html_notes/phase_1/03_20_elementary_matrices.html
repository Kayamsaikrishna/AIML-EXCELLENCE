20. Elementary Matrices & Row Operations

Row operations as matrix multiplication.

1. What is an Elementary Matrix?

An elementary matrix \( \mathbf{E} \) is obtained by performing a single elementary row operation on the identity matrix \( \mathbf{I} \).

Left-Multiplication Principle

Multiplying a matrix \( \mathbf{A} \) on the left by an elementary matrix \( \mathbf{E} \) is exactly equivalent to performing that same row operation on \( \mathbf{A} \).

$$ \mathbf{E}_k \dots \mathbf{E}_2 \mathbf{E}_1 \mathbf{A} = \mathbf{A}_{RREF} $$

2. Inverses and Products

  • Elementary matrices are always invertible.
  • The inverse of an elementary matrix is another elementary matrix that "undoes" the operation.

AI Theory: This is a precursor to LU Decomposition. The matrix \( \mathbf{L} \) is essentially the product of the inverses of the elementary matrices used for Gaussian elimination.

3. Python: Building an Elementary Matrix

import numpy as np

# A 3x3 Identity
E = np.eye(3)

# Row Op: Add -2 * Row 0 to Row 1
E[1, 0] = -2

A = np.array([[1, 1, 1], [2, 5, 5], [0, 0, 1]])

# Result of Matrix Mult
result = E @ A

print(f"Elementary Matrix E:\n{E}")
print(f"Result (Should have 0 at index [1,0]):\n{result}")

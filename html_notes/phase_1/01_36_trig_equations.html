36. Trigonometric Equations

Finding the precise alignment of cycles.

1. Types of Solutions

Unlike linear equations, trig equations have multiple solutions due to their periodic nature.

$$ \sin \theta = \frac{1}{2} \implies \theta = \frac{\pi}{6} + 2k\pi, \frac{5\pi}{6} + 2k\pi $$

We typically find solutions within the Principal Interval \([0, 2\pi)\) or the General Solution.

2. Frequency Alignment in AI

Multi-Head Attention Phase Shift

In Transformers, different "Attention Heads" might look for patterns at different frequencies. Aligning these heads is conceptually similar to solving trig equations: we need to find the specific phase offset (\(\phi\)) that maximizes the dot product between Key and Query vectors.

  • Optimization Goal: We solve for parameters that satisfy \( \nabla_{\theta} L = 0 \). If our weights are modeled as oscillations, this involves solving transcendental trig equations.
  • Active Noise Cancellation: AI models in earphones solve trig equations in real-time to generate a wave that is exactly \( 180^\circ \) out of phase with ambient noise.

3. Python: Solving Trig Equations

from scipy.optimize import fsolve
import numpy as np

# Let's solve: cos(x) - x = 0
def func(x):
    return np.cos(x) - x

# fsolve uses numerical methods to find the intersection
root = fsolve(func, 0.5) 

print(f"The solution is x = {root[0]:.4f}")
# Output: x = 0.7391 (The Dottie Number)

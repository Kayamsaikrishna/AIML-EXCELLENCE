1. Periodicity

Because waves repeat, their equations have infinite solutions.

$$ \sin(x) = a \implies x = \arcsin(a) + 2\pi n $$

In AI, this "repeating structure" corresponds to Symmetry in the weight space. There are many permutations of neurons that yield the exact same function.

2. Finding Zero Gradient

Training an AI model means solving the equation:

$$ \nabla \text{Loss}(\theta) = 0 $$

Just like \( \sin(x)=0 \), this equation has many solutions. Some are good (Global Minima), some are okay (Local Minima), and some are traps (Saddle Points).

3. Numerical Root Finding

Using Newton's Method to find a specific solution.

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import fsolve

# Define function: sin(x) - 0.5 = 0
def func(x):
    return np.sin(x) - 0.5

# Find root near 0
root1 = fsolve(func, 0) # Should be pi/6 (0.523)

# Find root near pi
root2 = fsolve(func, 3) # Should be 5pi/6 (2.618)

print(f"Root 1 (near 0): {root1[0]:.4f}")
print(f"Root 2 (near 3): {root2[0]:.4f}")
print("Multiple distinct solutions for the same target value.")

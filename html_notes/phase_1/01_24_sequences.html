1. Order Matters

A Set \(\{1, 2\}\) is the same as \(\{2, 1\}\). A Sequence \((1, 2)\) is NOT the same as \((2, 1)\).

Explicit Formula: \( a_n = f(n) \). (Direct access, like an Array).

Recursive Formula: \( a_n = f(a_{n-1}) \). (Dependent on history, like a Linked List or RNN).

AI Application: Language Modeling

Sentences are sequences of words. "The cat sat on the..." implies "mat". The order defines the meaning.

2. Hidden States (Recursion)

An RNN processes a sequence by maintaining a "Hidden State" \( h_t \).

$$ h_t = \tanh(W \cdot h_{t-1} + U \cdot x_t) $$

This is a Recursive Definition. The current memory \( h_t \) depends on the previous memory \( h_{t-1} \).

3. A Simple RNN Structure

Implementing a sequence processor from scratch.

import numpy as np

# 1. Define a Sequence (Inputs)
# "Hello" -> [1, 0, 1, 1, 0] (Dummy vectors)
inputs = [np.array([1]), np.array([0]), np.array([1])]

# 2. Weights (The Brain)
W_h = 0.5 # Memory Weight
W_x = 0.8 # Input Weight
bias = 0.1

# 3. Process Sequence (Recurrence)
h_t = 0 # Initial hidden state (Empty mind)

print("Reading Sequence...")
for x in inputs:
    # recursion: h_new = f(h_old, x)
    h_t = np.tanh(W_h * h_t + W_x * x + bias)
    print(f"Input: {x[0]}, Memory State: {h_t:.4f}")

# The final h_t contains a 'summary' of the whole sequence.

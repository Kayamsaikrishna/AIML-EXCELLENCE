24. Sequences (Order Matters)

Lists, Time Steps, and the flow of Data.

1. Arithmetic & Geometric

$$ a_n = f(n) $$

Arithmetic (+d)

Add a constant each step. \( 2, 4, 6, 8 \dots \) (Linear Growth).

Geometric (*r)

Multiply by a constant. \( 2, 4, 8, 16 \dots \) (Exponential Growth).

2. Positional Encodings

Transformers (like GPT) process all words at once (Parallel). They have no concept of "Order" unless we force it.

We inject a fixed Sequence of Sines and Cosines into the embeddings so the model knows that "dog" is at position 5.

The Formula

$$ PE(pos, 2i) = \sin(pos / 10000^{2i/d}) $$

This creates a unique geometric signature for every position.

3. Coding Order

Generating Positional Encodings in Python.

// Python: Positional Encoding (Simplified)
import numpy as np
import matplotlib.pyplot as plt

def get_positional_encoding(max_seq_len, d_model):
    pe = np.zeros((max_seq_len, d_model))
    for pos in range(max_seq_len):
        for i in range(0, d_model, 2):
            div_term = 10000 ** (2 * i / d_model)
            pe[pos, i] = np.sin(pos / div_term)
            if i + 1 < d_model:
                pe[pos, i + 1] = np.cos(pos / div_term)
    return pe

# Visualize
d_model = 64
max_seq_len = 50
pe = get_positional_encoding(max_seq_len, d_model)

plt.imshow(pe, cmap='RdBu', aspect='auto')
plt.title("Transformer Positional Encodings")
plt.xlabel("Embedding Dimension")
plt.ylabel("Sequence Position")
plt.colorbar()
plt.show()

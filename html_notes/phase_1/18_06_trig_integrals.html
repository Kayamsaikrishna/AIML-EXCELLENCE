06. Trigonometric Integrals

Integrating powers and products of sines and cosines.

1. The Strategy

Trig integrals often involve finding a way to use Pythagorean Identities to set up a U-Substitution.

$$ \sin^2 x + \cos^2 x = 1 $$ $$ \tan^2 x + 1 = \sec^2 x $$

If you have \(\int \sin^m x \cos^n x dx\), look for the term with the odd power. Save one factor for the \(du\) and convert the rest using identities.

2. Half-Angle Identities

When all powers are even, you cannot use substitution directly. Instead, you must lower the powers using these identities:

$$ \sin^2 x = \frac{1 - \cos 2x}{2} $$ $$ \cos^2 x = \frac{1 + \cos 2x}{2} $$

3. AI/ML Connection: Spectral Energy

Orthogonality in Signal Processing

In Digital Signal Processing (DSP) and Speech Recognition AI, we use the property that sines and cosines of different frequencies are "orthogonal". This is proven using trig integrals like \(\int \sin(ax)\sin(bx) dx = 0\) when \(a \neq b\).

Because these integrals result in zero, an AI model can perfectly separate different voices or frequencies from a single noisy audio stream. Trig integration is the "filtering" mechanism that allows models to focus on the information that matters.

4. Python: Complex Trig Integration

import sympy as sp

x = sp.Symbol('x')
f = sp.sin(x)**3 * sp.cos(x)**2

# Resulting in setting u = cos(x), du = -sin(x) dx
result = sp.integrate(f, x)

print(f"Integral is: {result}") 
# Output: cos(x)**5/5 - cos(x)**3/3

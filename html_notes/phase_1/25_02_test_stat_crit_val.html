Stats 1.5 The Bar

Test Statistics & Critical Values

Converting raw data into a standardized score and comparing it against a threshold of "doubt."

The Standardized Score

A Test Statistic aggregates your sample data into a single number that measures how far your observation deviates from the Null Hypothesis.

Common formats: \(Z\)-score (large \(n\)), \(T\)-score (small \(n\)), \(\chi^2\)-score (categorical).

1. The Critical Value (\(z^*\), \(t^*\))

The Critical Value is the "line in the sand." It is the threshold that defines the **Rejection Region**. - If your Test Statistic > Critical Value, you reject the Null. - It is determined by your chosen Significance Level (\(\alpha\)).

$$ \text{Test Statistic} = \frac{\text{Observed} - \text{Expected}}{\text{Standard Error}} $$

3. ML Connection: Thresholding

Anomaly Detection Cybersecurity

Detecting Intrusion

In Network Security ML, we define a "Null Hypothesis" that user traffic is normal.
- Test Statistic: The distance of a current packet from the cluster of normal behavior (e.g., Mahalanobis distance). - Critical Value: The "Alert Threshold."

If a specific request's distance exceeds the Critical Value, the system "Rejects the Null" and flags the request as a potential hack. Choosing the right Critical Value is the difference between a secure system and one that constantly gives annoying false alarms.

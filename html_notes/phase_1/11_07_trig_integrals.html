Calculus 1.4 Periodic

Trigonometric Integrals

Powers of sine and cosine. The harmonics of math.

The Pythagorean Key

Almost every strategy here boils down to \(\sin^2 x + \cos^2 x = 1\). We use this to convert "Bad" even powers into "Good" odd powers that allow U-Substitution.

1. Strategies

  • Odd Power of Sin/Cos: Peel off one factor. Use \(u=\text{other one}\). Use \(\sin^2+\cos^2=1\).
  • Both Even Powers: Use Half-Angle Identities to lower the degree. \[ \sin^2 x = \frac{1 - \cos 2x}{2}, \quad \cos^2 x = \frac{1 + \cos 2x}{2} \]

2. AI/ML Connection: Orthogonality & Fourier

Signal Processing

Trig integrals are the engine of Fourier Transforms.

The reason we can separate a flute sound from a drum sound in an audio file is because of Orthogonality: \[ \int_{-\pi}^{\pi} \sin(nx) \cos(mx) dx = 0 \] The "Correlation" (integral product) of different frequencies is zero. This property allows Convolutional Neural Networks (1D CNNs) to learn frequency-domain features efficiently.

3. Python: Orthogonality Check

verify_orthogonality.py
import sympy as sp

x = sp.Symbol('x')

# Orthogonality Proof
# Integral of sin(x) * sin(2x) over one period [0, 2pi]
n = 1
m = 2
f = sp.sin(n*x) * sp.sin(m*x)

result = sp.integrate(f, (x, 0, 2*sp.pi))
print(f"Inner Product of freq {n} and {m}: {result}")
# Output: 0 (They are orthogonal)

# Same frequency
n = 1
m = 1
f_same = sp.sin(n*x) * sp.sin(m*x)
result_same = sp.integrate(f_same, (x, 0, 2*sp.pi))
print(f"Inner Product of freq {n} and {m}: {result_same}")
# Output: pi (Non-zero energy)

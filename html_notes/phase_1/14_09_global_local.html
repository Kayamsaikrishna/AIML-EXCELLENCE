Optimization 1.7 The Goal

Global vs. Local Optima

Distinguishing the best possible solution from a merely "good" one.

Absolute Extrema

A Global Minimum is the point \(\mathbf{x}^*\) where \(f(\mathbf{x}^*) \le f(\mathbf{x})\) for ALL \(\mathbf{x}\). A Local Minimum is only the lowest point in a small neighborhood.

The Extreme Value Theorem guarantees that if \(f\) is continuous on a closed, bounded set, it MUST have a global max and min. But finding it is the hardest problem in Computer Science (NP-Hard for general non-convex functions).

2. AI/ML Connection: The Optimization Trap

Are Local Minima Bad?

Historically, researchers feared that Neural Networks would get stuck in bad Local Minima. However, empirical evidence suggests that in high dimensions, most local minima are actually quite good (close to the global minimum in value).

The real enemy is usually Saddle Points, not bad local minima. Modern techniques like Simulated Annealing or SGD with Noise help the model jump out of shallow valleys to find deeper, better valleys.

3. Python: Brute Force Grid Search

grid_search.py
import numpy as np

# Function with many local minima: f(x) = x^2 - cos(4x)
def f(x):
    return x**2 - np.cos(4*x)

# 1. Gradient Descent (Greedy)
def naive_gd(start_x, lr=0.1, steps=20):
    x = start_x
    for _ in range(steps):
        grad = 2*x + 4*np.sin(4*x)
        x -= lr * grad
    return x

# 2. Grid Search (Global)
grid = np.linspace(-5, 5, 1000)
best_x_global = grid[np.argmin(f(grid))]

# Comparison
local_sol = naive_gd(start_x=4.0) # Starts far away
print(f"Local Solution (GD): {local_sol:.4f}, Value: {f(local_sol):.4f}")
print(f"Global Solution: {best_x_global:.4f}, Value: {f(best_x_global):.4f}")

The Root Test

Evaluating n-th power complexity.

The Fundamental Rate

The Root Test is ideal for series with powers of \(n\), like \( (a_n)^n \). It strips away the power to see the base behavior.

\[ L = \lim_{n \to \infty} \sqrt[n]{|a_n|} \]

  • \(L < 1\): Converges.
  • \(L > 1\): Diverges.

2. AI/ML Connection: Spectral Radius

Spectral Norms

The Root Test is closely related to the Spectral Radius (\(\rho(A)\)) of a matrix in Linear Algebra. Ideally, for a recurrent system \(h_{t+1} = W h_t\) to be stable, we need \(\rho(W) < 1\).

This is the matrix equivalent of the Root Test condition \(L < 1\). If the largest eigenvalue (root) is \(< 1\), the signal decays. If \(> 1\), it explodes. Spectral Normalization (used in GANs) explicitly scales weights to satisfy this property.

3. Python: Root Test Check

root_test.py
import math

# Series: ((n+1)/2n)^n
# Base limit: (n+1)/2n -> 1/2
# Root Limit L = 1/2 < 1 -> Converges

def get_root_val(n):
    term = ((n + 1) / (2 * n))**n
    return term**(1/n) # The n-th root

print(f"{'n':<10} | {'Root Value':<15}")
print("-" * 30)

for n in [10, 100, 1000, 10000]:
    print(f"{n:<10} | {get_root_val(n):<15.6f}")

# It approaches 0.5

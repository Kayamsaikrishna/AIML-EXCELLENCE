1. The Rule

Unlike real numbers ($3 \times 5 = 5 \times 3$), for matrices, the order of multiplication changes the result.

$$ AB \neq BA $$

This is because matrices represent Functions (transformations). Composition of functions is generally not commutative ($f(g(x)) \neq g(f(x))$).

2. Quantum Mechanics & AI

The Heisenberg Uncertainty Principle arises directly from matrix non-commutativity: \( [x, p] = xp - px \neq 0 \).

In Deep Learning, the order of layers matters entirely. A `ReLU` followed by a `Linear` layer is completely different from a `Linear` followed by `ReLU`.

3. Pauli Matrices Check

Famous matrices in Quantum Computing that anti-commute.

import numpy as np

# Pauli Matrices
SigmaX = np.array([[0, 1], [1, 0]])
SigmaY = np.array([[0, -1j], [1j, 0]])

# Order 1: XY
XY = SigmaX @ SigmaY

# Order 2: YX
YX = SigmaY @ SigmaX

print("XY:")
print(XY)
# [[i, 0], [0, -i]]

print("\nYX:")
print(YX)
# [[-i, 0], [0, i]]

print(f"\nCommutator [X, Y]:\n{XY - YX}")
# Not Zero!

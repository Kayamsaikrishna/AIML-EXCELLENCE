DiffEq 1.8 Continuous Depth

Differential Equations & Neural ODEs

What if a Neural Network had infinite layers?

The Limit of ResNets

A Residual Network (ResNet) updates its state like this: \[ \mathbf{h}_{t+1} = \mathbf{h}_t + f(\mathbf{h}_t, \theta_t) \] This looks exactly like Euler's Method for solving a differential equation! \[ \frac{d\mathbf{h}}{dt} = f(\mathbf{h}(t), t, \theta) \]

Neural ODEs treat the "depth" of the network as a continuous time variable \(t\). Instead of distinct layers, we have a continuous flow governed by an ODE, which we solve using a black-box ODE solver.

2. AI/ML Connection: Continuous Depth

Why does this matter?

1. Parameter Efficiency: The function \(f\) (the dynamics) is shared across all "time". A 1000-layer equivalent network might use the same parameters as a 1-layer network, just integrated longer.

2. Adaptive Computation: We can trade precision for speed. If we just want a rough answer, the ODE solver takes fewer steps. For high precision, it takes more.

3. Reversibility: ODEs can be solved backwards in time. This allows for constant-memory backpropagation (no need to store activations!).

3. Python: Euler's Method (The Basic ResNet)

neural_ode_dummy.py
import numpy as np
import matplotlib.pyplot as plt

# A simple dynamic system: dh/dt = -0.5 * h
# True solution: h(t) = h0 * e^(-0.5t)

def dynamics(h):
    return -0.5 * h

def solve_ode(h0, steps, dt):
    trajectory = [h0]
    h = h0
    for _ in range(steps):
        # Update rule: h_{t+1} = h_t + dt * f(h_t)
        dh = dynamics(h)
        h = h + dt * dh
        trajectory.append(h)
    return trajectory

# "Forward Pass"
path = solve_ode(h0=10.0, steps=20, dt=0.5)

print(f"Final State: {path[-1]:.4f}")
print("This discrete path is exactly what a ResNet computes!")

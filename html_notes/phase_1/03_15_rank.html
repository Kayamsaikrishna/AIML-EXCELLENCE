1. The Fundamental Theorem of Linear Algebra (Part 1)

The number of linearly independent rows ALWAYS equals the number of linearly independent columns.

This single number is the Rank. It represents the dimension of the image of the transformation.

2. Low Rank is Good

In Compression (SVD) and Recommender Systems, we want low rank matrices.

A rank-50 approximation of a 10,000x10,000 matrix captures 99% of the information (patterns) but uses 0.1% of the storage. The noise is usually high-rank, so lowering rank filters noise.

3. Numerical Rank

Using SVD to determine effective rank.

import numpy as np

# A Rank-1 Matrix (All rows are multiples of [1, 2, 3])
u = np.array([[1, 2, 3]])
v = np.array([[2], [4], [6]])
A = u.T @ v.T # 3x3

print(f"Matrix A:\n{A}")
print(f"Calculated Rank: {np.linalg.matrix_rank(A)}")

# Add slight noise (Technically Full Rank now)
A_noisy = A + 1e-10 * np.random.rand(3, 3)

# Default tolerance handles tiny noise
print(f"Rank with tiny noise: {np.linalg.matrix_rank(A_noisy)}")

# But if we check singular values
s = np.linalg.svd(A_noisy, compute_uv=False)
print(f"Singular Values: {s}")
# 1 big one, 2 tiny ones. Effectively Rank 1.

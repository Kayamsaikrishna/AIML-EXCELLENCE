15. Rank of a Matrix

The measure of non-redundant information.

1. Definition & Properties

The Rank of a matrix \( \mathbf{A} \) is the maximum number of linearly independent column vectors (or row vectors) in the matrix.

  • Full Rank: If \( \text{rank}(\mathbf{A}) = \min(m, n) \), the matrix contains no redundant information.
  • Rank-Deficient: If the rank is lower than the dimensions, some features can be perfectly predicted by others.
  • Property: \( \text{rank}(\mathbf{A}) = \text{rank}(\mathbf{A}^T) \).

2. LoRA: Fine-Tuning Giant Models

Low-Rank Adaptation

When fine-tuning huge LLMs like GPT-4, updating all 175B parameters is impossible. Researchers found that the change in weights (\( \Delta \mathbf{W} \)) often has a very Low Rank. Instead of learning a giant matrix, we learn two tiny matrices \( \mathbf{A} \) and \( \mathbf{B} \):

$$ \Delta \mathbf{W} \approx \mathbf{A}_{d \times r} \cdot \mathbf{B}_{r \times k} $$

Where \( r \ll d, k \). This reduces parameter counts by \( 99.9\% \)!

3. Python: Rank Detection

import numpy as np

# Redundant features matrix
X = np.array([
    [1, 2, 1],
    [2, 4, 1], # Row 2 is basically Row 1 * 2 (except 3rd col)
    [3, 6, 1]
])

rank = np.linalg.matrix_rank(X)

print(f"Matrix Dimensions: {X.shape}")
print(f"Detected Rank: {rank}") # Output: 2

if rank < X.shape[1]:
    print("This dataset has multi-collinearity!")

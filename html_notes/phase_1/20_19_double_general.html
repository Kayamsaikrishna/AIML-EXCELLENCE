02. Iterated Integrals & Fubini’s Theorem

Solving multi-layer integrals one layer at a time.

1. The Iterated Approach

To evaluate a double integral, we treat it as two nested single integrals. We integrate with respect to one variable (treating the other as constant) and then integrate the result with respect to the second variable.

$$ \iint_{R} f(x, y) dA = \int_{a}^{b} \left[ \int_{c}^{d} f(x, y) dy \right] dx $$

2. Fubini’s Theorem

If \(f\) is continuous on the rectangle \(R\), then the order of integration does not matter:

$$ \int_{a}^{b} \int_{c}^{d} f(x, y) dy dx = \int_{c}^{d} \int_{a}^{b} f(x, y) dx dy $$

Swapping the order is a powerful trick for solving integrals that are "impossible" in one direction but easy in the other.

3. AI/ML Connection: Marginalization

Eliminating Nuisance Variables

Suppose an AI has a joint model of (Age, Salary, Purchase). If we want to know the probability of a "Purchase" regardless of "Age", we must "integrate out" the Age variable. This is called Marginalization.

$$ P(\text{Salary}) = \int P(\text{Age, Salary}) d\text{Age} $$

Fubini's Theorem guarantees that we can marginalize variables in any order and get the same final probability. This is what allows Expectation-Maximization (EM) algorithms to work efficiently in unsupervised learning like Clustering.

4. Python: Swapping Integration Order

import sympy as sp

x, y = sp.symbols('x y')
f = x**2 * y

# Order 1: Integral w.r.t y then x
res1 = sp.integrate(sp.integrate(f, (y, 0, 1)), (x, 0, 1))

# Order 2: Integral w.r.t x then y
res2 = sp.integrate(sp.integrate(f, (x, 0, 1)), (y, 0, 1))

print(f"Result 1: {res1}")
print(f"Result 2: {res2}")
# Verify res1 == res2

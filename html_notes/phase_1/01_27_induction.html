27. Mathematical Induction

The Domino Effect. Proving things for infinity.

1. The Logic

Two Steps

  • Base Case: Prove it works for the first domino (\(n=1\)).
  • Inductive Step: Prove that IF it works for any domino \(k\), THEN it must work for the next domino \(k+1\).

2. Recursion & DP

Induction is the mathematical foundation of Recursive Algorithms and Dynamic Programming.

In the Bellman Equation (Reinforcement Learning), we solve the optimal path by assuming we know the optimal path from the next step. We work backwards, just like induction works forwards.

3. Coding Induction (Recursion)

Using recursion to solve a problem, with Memoization (DP) to make it fast.

// Python: Fibonacci with Memoization
# The "Inductive Step" in code:
# F(n) = F(n-1) + F(n-2)

memo = {}

def fib(n):
    # Base Cases
    if n == 0: return 0
    if n == 1: return 1
    
    # Check Memo (The "Dynamic Programming" part)
    if n in memo: return memo[n]
    
    # Recursive Step
    result = fib(n-1) + fib(n-2)
    memo[n] = result
    return result

print(f"Fib(50): {fib(50)}") 
# Computes instantly due to Memoization

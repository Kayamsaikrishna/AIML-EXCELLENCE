Induction & Generalization

1. The Two Steps

To prove a statement \( P(n) \) is true for all integers \( n \ge 1 \):

  1. Base Case: Show \( P(1) \) is true.
  2. Inductive Step: Assume \( P(k) \) is true. Show this implies \( P(k+1) \) is true.

AI "Induction"

In Machine Learning, we don't have a formal proof. We have Empirical Risk Minimization. We assume that if the model works on \( k \) training examples (drawn from distribution \( \mathcal{D} \)), it will work on the \( k+1 \)-th example from \( \mathcal{D} \). This is the leap of faith called Generalization.

2. Induction is Recursion

Induction is just Recursion running backwards.

  • Recursion: Solve \( n \) by breaking it down to \( n-1 \).
  • Induction: Build up from \( 1 \) to prove \( n \).

Dynamic Programming (like the Bellman Equation in RL) relies entirely on this principle.

3. Recursive Proofs in Code

Calculating Factorials: Determining truth by stepping down to the Base Case.

def factorial(n):
    # Base Case (Dominos stop falling here)
    if n == 1:
        return 1
    
    # Inductive Step (Relationship between k and k-1)
    # n! = n * (n-1)!
    return n * factorial(n - 1)

print(f"5! = {factorial(5)}") 
# 120. It works because it chained back to 1.

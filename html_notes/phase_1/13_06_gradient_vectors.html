Calculus 1.6 Optimization

The Gradient Vector

Points to the steepest ascent.

The Direction of Greatest Change

The Gradient \(\nabla f\) is a vector that packages all partial derivatives: \[ \nabla f(x,y) = \langle f_x, f_y \rangle = \frac{\partial f}{\partial x}\mathbf{i} + \frac{\partial f}{\partial y}\mathbf{j} \]

It has two critical geometric properties: 1. Direction: It points in the direction of steepest increase in function value. 2. Magnitude: The length \( ||\nabla f|| \) represents *how fast* the function is increasing. 3. Orthogonality: It is always perpendicular to Level Curves.

2. AI/ML Connection: The Engine of AI

Why "Descent"?

If the gradient \(\nabla L\) points UP the hill (increasing Loss), then negative gradient \(-\nabla L\) points DOWN the hill (decreasing Loss).

This is the update rule for Gradient Descent: \[ w_{new} = w_{old} - \eta \cdot \nabla L(w_{old}) \] Where \(\eta\) (eta) is the learning rate. We compute this vector for millions of parameters, take a small step in the opposite direction, and repeat until the model is "smart" (error is minimized).

3. Python: Visualizing Vector Fields

gradient_field.py
import numpy as np
import matplotlib.pyplot as plt

# Function: f(x,y) = x^2 + y^2 (Bowl)
# Gradient: <2x, 2y>

x, y = np.meshgrid(np.linspace(-2, 2, 10), np.linspace(-2, 2, 10))
u = 2 * x # x-component of gradient
v = 2 * y # y-component of gradient

plt.figure(figsize=(7, 7))
plt.quiver(x, y, u, v, color='teal')
plt.title("Gradient Vector Field (Arrows point OUT/UP)")
plt.xlabel("x")
plt.ylabel("y")
plt.grid(True, alpha=0.3)
plt.show()

print("Notice: Arrows get longer further from the center (steeper slope).")

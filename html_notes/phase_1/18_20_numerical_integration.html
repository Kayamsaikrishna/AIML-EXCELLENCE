20. Numerical Integration

When an analytical answer doesn't exist.

1. Why Numerical?

Most real-world integrals (like the bell curve \(\int e^{-x^2} dx\)) cannot be solved with basic antiderivative rules. In these cases, we use algorithms to estimate the area with high precision.

2. The Standard Algorithms

  • Trapezoidal Rule: Approximates the function with straight lines (trapezoids). Faster than Riemann sums for the same number of points.
  • Simpson's Rule: Approximates the function with parabolas (quadratic segments). Extremely accurate for smooth functions and usually the default in scientific computing libraries.

3. AI/ML Connection: Monte Carlo & Estimation

Bayesian Inference

In Bayesian AI, to find the "Most Likely" prediction, we must calculate the "Evidence" term, which is a massive integral over the entire parameter space of the model. For Neural Networks, this is an integral in billions of dimensions.

Because these cannot be solved analytically (or even with Simpson's rule due to the "Curse of Dimensionality"), AI researchers use Monte Carlo Integration. This is a "randomized" version of numerical integration—we sample points randomly and take their weighted average. This is the only way that modern AI systems can reason about uncertainty and confidence.

4. Python: Trapezoid vs Simpson

import numpy as np
from scipy.integrate import trapezoid, simpson

x = np.linspace(0, np.pi, 100)
y = np.sin(x)

# Theoretical area is 2
trapz_res = trapezoid(y, x)
simp_res = simpson(y, x)

print(f"Trapezoidal Result: {trapz_res:.6f}")
print(f"Simpson Result:     {simp_res:.6f}")

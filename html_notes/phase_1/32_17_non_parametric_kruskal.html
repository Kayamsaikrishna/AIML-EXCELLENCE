17. Kruskal-Wallis Test

ANOVA for non-normal data.

1. The Concept

The Kruskal-Wallis Test is to ANOVA what the Wilcoxon test is to the t-test. It is a non-parametric method for testing whether three or more independent samples come from the same distribution. Like the Wilcoxon test, it is based on **Ranks** rather than raw values.

2. Assumptions & Application

While ANOVA assumes Normality and Homoscedasticity, Kruskal-Wallis only assumes that the distributions of the groups have similar shapes. It is the "Defensive" choice when you have multiple groups with very small or very messy datasets where you cannot trust the variance-matching assumptions of ANOVA.

3. AI/ML Connection: Comparing Diverse Loss Landscapes

Multi-Architecture Tournament logic

In AI, Kruskal-Wallis is used for Universal Model Benchmarking.

When comparing 5 different **Initialization Strategies** for a Deep Brain network, the results might be extremely "Bipyramidal"—some work, some fail, and the distribution is nowhere near Gaussian. You use **Kruskal-Wallis** to rank the medians of these 5 strategies. If the H-statistic is significant, you follow up with **Dunn's Post-hoc Test** to find which specific strategy is the "Rank Leader." This is the standard procedure in **Hyperparameter Sensitivity analysis**, ensuring that your choices are robust against the "Luck of the Seed" that often plagues high-dimensional optimization.

4. Python: stats.kruskal

# Model scores for 3 different architectures (A, B, C)
a = [0.1, 0.2, 0.1, 0.9] # Very inconsistent
b = [0.4, 0.5, 0.4, 0.5] # Stable
c = [0.3, 0.3, 0.4, 0.2] # Stable but lower

h_stat, p_val = stats.kruskal(a, b, c)

print(f"H-statistic: {h_stat:.2f}, p-value: {p_val:.4f}")
# If p < 0.05, there is a significant 'Rank' difference between the models.

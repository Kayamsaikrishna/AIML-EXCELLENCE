The Ratio Test

Measuring the speed of decay.

Exponential Behavior

The Ratio Test compares a series to a geometric series by checking the ratio of consecutive terms:

\[ L = \lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| \]

  • \(L < 1\): Converges Absolutely (Terms shrink fast).
  • \(L > 1\): Diverges (Terms grow).
  • \(L = 1\): Inconclusive.

2. AI/ML Connection: Exploding Gradients

Multiplicative Updates

In deep networks (like RNNs), gradients are multiplied at each layer (Backpropagation through time). If the "Ratio" of the gradient magnitude from one layer to the next is \(> 1\), the gradient Explodes exponentially. If the ratio is \(< 1\), it **Vanishes**.

We want the learning dynamics to be stable. Techniques like Gradient Clipping ensure that the effective ratio stays \( \leq 1 \) to prevent divergence.

3. Python: Ratio Test Logic

ratio_test.py
# Series: n! / 10^n
# a_n = n! / 10^n
# a_{n+1} = (n+1)! / 10^(n+1)
# Ratio = a_{n+1} / a_n = (n+1) / 10

# Limit as n -> inf is Infinity (> 1).
# Therefore, Series Diverges.

def check_ratio(n):
    return (n + 1) / 10

print(f"n=5: Ratio {check_ratio(5)}")   # 0.6 (< 1, seems convergent locally)
print(f"n=9: Ratio {check_ratio(9)}")   # 1.0 (Critical point)
print(f"n=15: Ratio {check_ratio(15)}") # 1.6 (> 1, Divergent!)

# Factorials eventually beat Exponentials.

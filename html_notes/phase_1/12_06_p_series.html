Calculus 1.5 Standard Series

The P-Series & Harmonic Series

The slow march to infinity.

The Power Law Series

A p-series is a sum of the form: \[ \sum_{n=1}^{\infty} \frac{1}{n^p} = 1 + \frac{1}{2^p} + \frac{1}{3^p} + \dots \]

Convergence Rule:

  • If \(p > 1\): Converges (Terms shrink fast enough).
  • If \(p \leq 1\): Diverges (Terms shrink too slowly).

The case \(p=1\) is the Harmonic Series (\(1 + 1/2 + 1/3 \dots\)). It diverges, but very slowly.

2. AI/ML Connection: Zipf's Law & Vocabulary

The Long Tail of Language

In Natural Language Processing (NLP), word frequencies follow Zipf's Law: the frequency of the \(n\)-th most common word is proportional to \(1/n^s\) (where \(s \approx 1\)).

This is a p-series with \(p \approx 1\). Since \(p=1\) diverges, it means the "total probability mass" of the long tail (rare words) is infinite if the vocabulary is unbounded.

This mathematical reality forces LLMs (like GPT) to use a Fixed Vocabulary (e.g., 50k tokens). If we tried to learn every word, the model complexity would explode because the distribution tails are "heavy" (they don't decay fast enough).

3. Python: Harmonic Divergence

harmonic_growth.py
import numpy as np
import matplotlib.pyplot as plt

# Compare Harmonic (p=1) vs Geometric (p=2) partial sums

n_values = range(1, 1000)
harmonic_sums = []
convergent_sums = []

h_sum = 0
c_sum = 0

for n in n_values:
    h_sum += 1/n
    c_sum += 1/(n**2)
    harmonic_sums.append(h_sum)
    convergent_sums.append(c_sum)

print(f"Harmonic Sum (n=1000): {h_sum:.2f}")
print(f"Convergent Sum (n=1000): {c_sum:.2f}")
# Harmonic keeps growing (logarithmically)
# Convergent flattens out

ML Calc 1.9 The Objective

Loss Optimization

Defining what "Learning" actually means mathematically.

The Error Landscape

In Machine Learning, we define a "Loss Function" \(J(\theta)\) (or \(L(\mathbf{w})\)) that measures how bad our model is. Optimization is simply the process of finding the parameters \(\theta\) that minimize this loss: \[ \theta^* = \arg\min_{\theta} J(\theta) \]

This turns a vague problem ("make a good AI") into a pure calculus problem ("find the minimum of this high-dimensional surface").

2. ML Connection: Common Loss Functions

Regression vs Classification

  • MSE (Mean Squared Error): Convex. Used for Regression. \( (y - \hat{y})^2 \). Like a bowl.
  • Cross-Entropy (Log Loss): Convex (for Logistic Regression) but Non-Convex for Neural Nets. Used for Classification. \( -y \log(\hat{y}) \).

Understanding the geometry of these functions helps us choose the right optimizer. MSE is sensitive to outliers (squaring makes big errors huge), while MAE (Absolute Error) is more robust.

3. Python: Visualizing MSE vs MAE

loss_viz.py
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-3, 3, 100)
mse = x**2
mae = np.abs(x)

plt.figure(figsize=(8, 5))
plt.plot(x, mse, label="MSE (Quadratic)", linewidth=2)
plt.plot(x, mae, label="MAE (Absolute)", linewidth=2, linestyle="--")
plt.title("Impact of Errors")
plt.xlabel("Error (Residual)")
plt.ylabel("Loss Penalty")
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

# Notice how MSE punishes large errors much more severely than MAE.

Calculus 1.3 Core Mechanics

Constant, Power, and Multiple Rules

90% of Machine Learning calculus involves differentiating polynomials (or sums of them).

The "Look and Solve" Era

Using the limit definition is tedious. We instead build a "Catalog of Shortcuts." Once you memorize these, finding the gradient of even complex neural networks becomes a matter of pattern matching.

1. The Big Three Rules

1. The Constant Rule

If \(f(x) = c\), it never changes. Its slope is zero.

\[ \frac{d}{dx}[c] = 0 \]

2. The Power Rule (The MVP)

For any real number \(n\):

\[ \frac{d}{dx}[x^n] = n x^{n-1} \]

Example: \(\frac{d}{dx}[x^3] = 3x^2\), \(\frac{d}{dx}[\sqrt{x}] = \frac{1}{2}x^{-1/2} = \frac{1}{2\sqrt{x}}\)

3. The Constant Multiple Rule

Scalars just come along for the ride. They scale the slope.

\[ \frac{d}{dx}[c \cdot f(x)] = c \cdot f'(x) \]

Example: \(\frac{d}{dx}[5x^4] = 5 \cdot (4x^3) = 20x^3\)

2. AI/ML Connection: Polynomial Regression

Gradient of MSE

Consider a simple loss function for linear regression using Mean Squared Error (MSE):

\[ J(w) = (wx - y)^2 = w^2x^2 - 2wxy + y^2 \]

To find the minimum, we compute the derivative with respect to \(w\) (treating \(x\) and \(y\) as constants).

  • Term 1 (\(w^2 \cdot x^2\)): Use Power Rule -> \(2w \cdot x^2\)
  • Term 2 (\(-2wxy\)): Use Power Rule on \(w^1\) -> \(-2xy\)
  • Term 3 (\(y^2\)): Constant -> 0

Result: \(J'(w) = 2x^2w - 2xy = 2x(wx - y)\). This is exactly the gradient update rule used in ML libraries.

3. Python: Symbolic Differentiation

sympy_power_rule.py
import sympy as sp

# Define variables
x = sp.Symbol('x')
w = sp.Symbol('w')

# 1. Simple Polynomial
f = 3*x**4 - 2*x**2 + 5
df = sp.diff(f, x)

print(f"Function: {f}")
print(f"Derivative: {df}") 
# Output: 12*x**3 - 4*x

# 2. ML Loss Function Example
y_true = sp.Symbol('y_true')
x_input = sp.Symbol('x_input')

# Loss = (w * x_input - y_true)^2
loss = (w * x_input - y_true)**2
gradient = sp.diff(loss, w)

print(f"\nLoss Function: {loss}")
print(f"Gradient wrt w: {gradient}")
# Output: 2*x_input*(w*x_input - y_true) -> Matches manual math!

# 3. Fractional Powers (Square Roots)
g = sp.sqrt(x) # x^(1/2)
dg = sp.diff(g, x)
print(f"\nFunction: {g}")
print(f"Derivative: {dg}")

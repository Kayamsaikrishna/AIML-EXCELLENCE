Calculus 1.6 Fubini

General Regions & Fubini's Theorem

Order matters (but sometimes it doesn't).

Non-Rectangular Bounds

Real-world regions aren't always squares. Often, the limits of integration for \( y \) depend on \( x \). \[ \int_a^b \int_{g_1(x)}^{g_2(x)} f(x, y) \, dy \, dx \] This describes "Type I" regions (bounded by vertical lines). We can also have "Type II" regions (bounded by horizontal lines).

Fubini's Theorem states: If the function is continuous, you can swap the order of integration ($dx dy$ vs $dy dx$), PROVIDED you correctly update the boundary equations. This "Order Swap" is a powerful trick to solve impossible integrals.

2. AI/ML Connection: Marginalization

Integrating Out Variables

In probabilistic graphical models (Bayesian Networks), calculating the Marginal Probability \( P(x) \) requires integrating the joint distribution \( P(x, y) \) over all possible values of \( y \) (often called "integrating out" the nuisance variable).

\[ p(x) = \int_{-\infty}^{\infty} p(x, y) \, dy \]

In variational inference (VAEs), efficient marginalization is crucial. The ability to swap integration orders (Fubini) allows us to rearrange expectations and verify ELBO (Evidence Lower Bound) derivations.

3. Python: Symbolic Iterated Integral

iterated_integral.py
import sympy as sp

x, y = sp.symbols('x y')
f = x * y

# Region: Triangle bounded by x=0, y=0, y=1-x
# Form 1: dy first. y goes from 0 to 1-x. x goes from 0 to 1.
integral_1 = sp.integrate(sp.integrate(f, (y, 0, 1-x)), (x, 0, 1))

# Form 2: dx first. x goes from 0 to 1-y. y goes from 0 to 1.
integral_2 = sp.integrate(sp.integrate(f, (x, 0, 1-y)), (y, 0, 1))

print(f"Order dy dx: {integral_1}")
print(f"Order dx dy: {integral_2}")
# Both should be 1/24

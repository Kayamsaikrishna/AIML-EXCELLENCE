Calculus 1.3 Guarantee

The Mean Value Theorem (MVT)

If you drive 60 miles in 1 hour, at some specific instant your speedometer MUST have read exactly 60 mph.

The "Existence" Proof

The MVT connects the global behavior (average slope) to the local behavior (instantaneous slope). It guarantees that somewhere, the derivative equals the average rate of change.

1. The Theorem

If \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\), there exists at least one \(c \in (a,b)\) such that:

\[ f'(c) = \frac{f(b) - f(a)}{b - a} \]

Equivalently: \( f(b) - f(a) = f'(c)(b - a) \).

2. AI/ML Connection: Lipschitz Continuity

Bounding the Change

In Wasserstein GANs (WGAN), we need to enforce a constraint that the Critic network (Discriminator) does not change 'too fast'. This property is called Lipschitz Continuity.

Using MVT, we know: \[ |f(b) - f(a)| = |f'(c)| \cdot |b - a| \]

If we bound the gradient so that \(|f'(c)| \le K\) always, then we guarantee: \[ |f(b) - f(a)| \le K |b - a| \] This "Gradient Penalty" or "Spectral Normalization" prevents the Discriminator from memorizing the training data perfectly, forcing it to learn meaningful features instead.

3. Python: Finding 'c'

find_mvt_point.py
import numpy as np

def f(x):
    return x**3 - x

def df(x):
    return 3*x**2 - 1

a, b = 0, 2

# 1. Calculate Average Slope (Secant)
avg_slope = (f(b) - f(a)) / (b - a)
# f(2) = 8-2 = 6; f(0) = 0
# Slope = (6 - 0) / (2 - 0) = 3.0

print(f"Interval: [{a}, {b}]")
print(f"Average Slope: {avg_slope}")

# 2. Solve for c where f'(c) = avg_slope
# 3c^2 - 1 = 3
# 3c^2 = 4 -> c^2 = 4/3 -> c = sqrt(4/3)

c_vals = [np.sqrt(4/3), -np.sqrt(4/3)]
valid_c = [c for c in c_vals if a < c < b]

print(f"Calculated c points: {c_vals}")
print(f"Valid c in interval (a,b): {valid_c}")

for c in valid_c:
    print(f"Checking f'({c:.4f}) = {df(c):.4f} (Matches avg slope?)")

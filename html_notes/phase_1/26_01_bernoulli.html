01. Bernoulli Distribution

The simplest discrete distribution: success or failure.

1. Definition

A random variable $X$ follows a Bernoulli Distribution if it has only two possible outcomes: 1 (success) with probability $p$, and 0 (failure) with probability $q = 1-p$.

$$ P(X=x) = \begin{cases} p & \text{if } x=1 \\ 1-p & \text{if } x=0 \end{cases} $$

More compactly: $P(X=x) = p^x (1-p)^{1-x}$ for $x \in \{0, 1\}$.

2. Statistical Properties

  • Mean (Expected Value): $E[X] = p$
  • Variance: $Var(X) = p(1-p)$
  • MGF: $M_X(t) = (1-p) + pe^t$

3. AI/ML Connection: Binary Classification

The Foundation of Logistic Regression

The Bernoulli distribution is the mathematical model behind every Binary Classification task in Machine Learning.

When you train a **Logistic Regression** model or a Neural Network with a single output node (and a Sigmoid activation), the model is predicting the parameter $p$ of a Bernoulli distribution. The output "0.85" means the model estimates $p=0.85$ for the current input. The training objective, **Binary Cross-Entropy (BCE) Loss**, is directly derived from the Negative Log-Likelihood of the Bernoulli distribution. If the labels are $\{0, 1\}$, BCE measures how well your predicted $p$ matches the actual realization of the Bernoulli variable.

4. Python: Bernoulli Trial

import numpy as np
from scipy.stats import bernoulli

# Probability of success (e.g., probability of a click)
p = 0.3

# Simulate a single Bernoulli trial
trial = bernoulli.rvs(p)
print(f"Trial Outcome: {trial}")

# Probability Mass at k=1
print(f"P(X=1): {bernoulli.pmf(1, p)}")

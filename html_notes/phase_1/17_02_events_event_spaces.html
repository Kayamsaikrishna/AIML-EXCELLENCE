Prob 1.4 Sigma Algebra

Events & Event Spaces

Structuring the chaos of randomness.

Events

An Event \(E\) is a subset of the sample space \(\Omega\). Example: Rolling an even number \(E = \{2, 4, 6\}\).

The Event Space (\(\mathcal{F}\), or Sigma-Algebra) is the collection of all possible events we can assign probabilities to. It must be closed under complements and countable unions.

2. ML Connection: Classification

Class Boundaries

In a binary classification problem (Cat vs Dog), the input space is \(\Omega\) (all pixel combinations). The "Cat Event" \(E_{cat}\) is the subset of pixel combinations that look like a cat.

The Neural Network tries to learn the boundary of this event set \(E_{cat}\) so it can say \(P(x \in E_{cat})\).

3. Python: Sets

set_ops.py
# Omega = {1..10}
omega = set(range(1, 11))

# Event A: Evens
A = {x for x in omega if x % 2 == 0}

# Event B: Primes
B = {2, 3, 5, 7}

# Intersection (A AND B)
print(f"Intersection: {A & B}") # {2}

# Union (A OR B)
print(f"Union: {A | B}")

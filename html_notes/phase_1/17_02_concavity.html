02. Concavity and Inflection Points

Mapping the curvature of the loss surface.

1. Concavity Rules

$$ f''(x) > 0 \implies \text{Concave Up (∪)} $$ $$ f''(x) < 0 \implies \text{Concave Down (∩)} $$

If \(f''(x)\) changes sign at point \(c\), then \(c\) is an Inflection Point. This is where the function flip-flops its curvature.

2. Importance of Convexity

A function that is Concave Up everywhere is called a Convex Function. Convex functions are the "gold standard" in AI because any local minimum is guaranteed to be the Global Minimum. Linear Regression and Logistic Regression have convex loss surfaces; Deep Neural Networks do not.

3. AI Connection: Learning Rate Scheduling

The "sharpness" of the concavity (the magnitude of \(f''(x)\)) tells us how fast the gradient is changing. In "sharp" valleys (high concavity), a large learning rate will cause the optimizer to over-shoot and diverge. In "flat" regions (low concavity), we need large learning rates to make progress. Second-order optimizers automate this by dividing the gradient by the curvature.

4. Python: Plotting Concavity

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-2, 2, 100)
y = x**4 - 2*x**2 # Double well potential

dy2 = 12*x**2 - 4 # Second derivative

plt.plot(x, y, label='f(x)')
plt.plot(x, dy2, label="f''(x) (Curvature)")
plt.axhline(0, color='black', lw=1)
plt.fill_between(x, -5, 5, where=dy2>0, alpha=0.1, color='green', label='Convex')
plt.fill_between(x, -5, 5, where=dy2<0, alpha=0.1, color='red', label='Concave')
plt.legend()
plt.show()

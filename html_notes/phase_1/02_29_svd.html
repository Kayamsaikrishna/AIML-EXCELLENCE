1. The Formula

Every matrix \( A \) (square or rectangular) can be broken down into:

$$ A = U \Sigma V^T $$
  • \( U \): Orthogonal matrix (Left Singular vectors).
  • \( \Sigma \): Diagonal matrix (Singular Values \( \sigma \ge 0 \)). sorted large to small.
  • \( V^T \): Orthogonal matrix (Right Singular vectors).

2. Eckart-Young Theorem

If we want to approximate a complex matrix \( A \) with a simpler matrix \( A_k \) of rank \( k \), the Best Possible approximation (in terms of L2 error) is keeping the top \( k \) singular values.

This is why SVD is used for Image Compression, Latent Semantic Analysis (NLP), and Denoising. We throw away the small \( \sigma \)'s as "noise".

3. Image Compression

Reconstructing a face using only 10 singular values.

import numpy as np
import matplotlib.pyplot as plt

# Create a synthetic 100x100 image (Gradient + Noise)
x = np.linspace(0, 1, 100)
y = np.linspace(0, 1, 100)
X, Y = np.meshgrid(x, y)
img = np.sin(X*10) + np.cos(Y*5) + np.random.normal(0, 0.1, (100, 100))

# Compute SVD
U, S, Vt = np.linalg.svd(img, full_matrices=False)

print(f"Top 5 Singular Values: {S[:5]}")
# Notice how fast they drop off!

# Reconstruct with Rank 10
k = 10
img_k = np.dot(U[:, :k] * S[:k], Vt[:k, :])

print(f"Original Rank: {np.linalg.matrix_rank(img)}") # 100
print(f"Approx Rank: {np.linalg.matrix_rank(img_k)}") # 10

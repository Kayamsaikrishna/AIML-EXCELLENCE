01. Intuitive Understanding of Limits

Exploring the behavior of functions as they approach a "point of interest".

1. What is a Limit conceptually?

A Limit is the fundamental concept that allows us to discuss what a function "wants" to be at a certain point, even if the function is not defined there or behaves strangely. It is the study of behavior in the neighborhood of a value.

$$ \lim_{x \to a} f(x) = L $$

This notation tells us that as the input \(x\) gets closer and closer to \(a\) (from both sides), the output \(f(x)\) gets closer and closer to a single real number \(L\).

2. The "Hole" in the Graph

Consider the function \(f(x) = \frac{x^2 - 1}{x - 1}\). At \(x = 1\), the function is \(0/0\), which is undefined. However, as we approach 1:

x f(x)
0.9 1.9
0.99 1.99
1.01 2.01
1.1 2.1

Intuitively, we can see that \(\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = 2\). The "hole" is at 2.

3. AI/ML Connection: Local Linearity

Why limits matter in Gradient Descent?

Gradient Descent relies on the instantaneous rate of change. Conceptually, we move weights by a tiny step \(\eta\). We are essentially calculating:

$$\text{Weight Update} \approx \lim_{\Delta w \to 0} \frac{\text{Loss}(w + \Delta w) - \text{Loss}(w)}{\Delta w}$$

Without the concept of a limit, the idea of a "slope at a single point" is mathematically impossible because the denominator would be zero.

4. Python: Observing the Approach

import numpy as np

def f(x):
    # Function with a hole at x=2
    return (x**2 - 4) / (x - 2)

# Value at exactly 2
try:
    print(f(2))
except ZeroDivisionError:
    print("f(2) is Undefined!")

# Approaching from 2.1 down to 2.000001
approaches = np.linspace(2.1, 2.000001, 5)
for val in approaches:
    print(f"x = {val:.6f} -> f(x) = {f(val):.6f}")

# It's heading straight for 4.0!

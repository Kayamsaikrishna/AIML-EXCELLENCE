1. Efficiency

A Basis is the most efficient way to describe a space. It is a set of vectors that:

  1. Are Linearly Independent (No waste).
  2. Span the entire space (Enough coverage).

The Dimension is simply the number of vectors in a basis.

$$ \text{Standard Basis for } \mathbb{R}^2: \mathbf{e}_1 = \begin{bmatrix}1\\0\end{bmatrix}, \mathbf{e}_2 = \begin{bmatrix}0\\1\end{bmatrix} $$

2. The Curse of Dimensionality

In AI, we deal with high dimensions (e.g. 1024-dim text embeddings). However, the "True" intrinsic dimension is often lower.

Autoencoders try to find a lower-dimensional Basis (Latent Space) that captures the essence of the data, discarding the redundant dimensions (compression).

3. Change of Basis

Representing the same vector in a new coordinate system.

import numpy as np

# Standard Coordinates of P
p_std = np.array([3, 4])

# New Basis (Rotated/Scaled)
B = np.array([
    [2, 1],
    [1, 2]
])
# Note: Columns of B are the new basis vectors

# Find coordinates of P in system B
# B * p_new = p_std  =>  p_new = B_inv * p_std
p_new = np.linalg.solve(B, p_std)

print(f"Standard Coords: {p_std}")
print(f"Basis B Coords:  {p_new}")

# Verify
reconstructed = np.dot(B, p_new)
print(f"Reconstructed:   {reconstructed}")

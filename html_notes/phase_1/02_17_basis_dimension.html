17. Basis and Dimension

Defining the minimum necessary information.

1. What is a Basis?

A set of vectors \( B \) is a Basis for a vector space \( V \) if:

  • \( B \) is Linearly Independent.
  • \( B \) Spans \( V \).

The number of vectors in any basis for \( V \) is called the Dimension of the space.

2. Latent Dimensions (The Secret Sauce of AI)

Autoencoders & Bottlenecks

In Generative AI (VAEs, GANs), we take an image (Dimension = 1,000,000 pixels) and force it through a "Bottleneck" (Dimension = 128 latent factors). The model must find a new Basis for the data that captures only the essential features.

  • Sparse Coding: Representing data using a basis where most coefficients are zero.
  • Low-Dimensional Manifolds: Why a 3D object's surface can be described using a 2D basis.

3. Python: Space Dimensionality

import numpy as np

# A space spanned by 3 vectors in 3D
v1 = np.array([1, 0, 0])
v2 = np.array([0, 1, 0])
v3 = np.array([1, 1, 0]) # Linear combination of v1 and v2

# Calculate dimension
matrix = np.array([v1, v2, v3])
dimension = np.linalg.matrix_rank(matrix)

print(f"Dimension of the space: {dimension}") # Output: 2 (A plane)

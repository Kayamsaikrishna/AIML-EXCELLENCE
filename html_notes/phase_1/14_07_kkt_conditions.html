Optimization 1.7 The General Solvers

KKT Conditions

The definitive rules for finding optimality under any constraint.

Generalizing Lagrange to Inequalities

When we have inequality constraints \(g_i(\mathbf{x}) \le 0\), the optimum might be ON the boundary (\(g=0\)) or INSIDE it (\(g < 0\)). We don't know in advance. The **Karush-Kuhn-Tucker (KKT)** conditions handle both cases automatically.

The most famous condition is Complementary Slackness: \[ \mu_i \cdot g_i(\mathbf{x}^*) = 0 \] This means either the constraint is satisfied with equality (\(g=0\)), or the multiplier is zero (\(\mu=0\), i.e., we ignore the constraint).

2. AI/ML Connection: Sparse Vectors

Why Sparsity Matters

In Support Vector Machines (SVMs), the "Dual Variables" \(\mu_i\) correspond to training examples. Complementary slackness tells us that for most training points (easy ones inside the correct class region), \(\mu_i = 0\). Only the difficult points right on the margin have \(\mu_i > 0\).

This is why SVMs are "Sparse". You can throw away 90% of your training data (the easy ones) and the model remains exactly the same. This is a property guaranteed by KKT.

3. Python: Solving Inequality Constraints

kkt_solve.py
from scipy.optimize import minimize
import numpy as np

# Problem: Minimize x^2 + y^2
# Subject to: x + y >= 1  (or 1 - x - y <= 0)

def objective(x):
    return x[0]**2 + x[1]**2

# Constraint: x[0] + x[1] - 1 >= 0
cons = {'type': 'ineq', 'fun': lambda x: x[0] + x[1] - 1}

# Start at (2, 2) [Inside the valid region]
res = minimize(objective, [2.0, 2.0], constraints=cons)

print(f"Optimal Solution: {res.x}")
# Expected: [0.5, 0.5] (On the boundary)

# If we change the constraint to x + y >= -10
# The unconstrained minimum (0,0) satisfies it!
cons2 = {'type': 'ineq', 'fun': lambda x: x[0] + x[1] + 10}
res2 = minimize(objective, [2.0, 2.0], constraints=cons2)

print(f"Optimal Solution 2: {res2.x}")
# Expected: [0.0, 0.0] (Constraint Inactive)
# Here, μ would be 0.

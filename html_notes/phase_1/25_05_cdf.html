05. Cumulative Distribution Function (CDF)

Answering the question: "What is the probability that $X \le x$?"

1. Definition

The Cumulative Distribution Function (CDF), denoted $F_X(x)$, is defined for any random variable (discrete or continuous) as:

$$ F_X(x) = P(X \le x) $$

For discrete variables, it is a running sum of the PMF. For continuous variables, it is the integral of the PDF from $-\infty$ to $x$.

2. Importance of the CDF

While the PDF/PMF tells you about probabilities at a point (or density), the CDF is often easier to work with when computing probabilities for ranges. For example:

$$ P(a < X \le b)=F_X(b) - F_X(a) $$

3. AI/ML Connection: Percentiles and Confidence

Interpreting Model Uncertainty

The CDF is the primary tool for calculating **Percentiles** and **Quantiles**.

In AI, when we talk about a 95% **Confidence Interval**, we are using the CDF. If an AI predicts a house price and gives a probability distribution, the CDF allows us to say: "There is a 90% chance the house price is below \$500k." In **Deep Learning Optimization**, certain adaptive learning rate algorithms (like **AdaGrad**) use CDF-like accumulators to track the distribution of past gradients. Furthermore, the **GELU activation function**, used in many Transformer models (like BERT and GPT), is defined based on the CDF of the standard normal distribution. Understanding the CDF allows you to move from point-predictions to full probabilistic range predictions, which is essential for "Safer" AI systems.

4. Python: Using the CDF for Range Probability

from scipy.stats import norm

# Standard Normal Distribution (mean=0, std=1)
# Calculate probability that X <= 1.96
p_95 = norm.cdf(1.96)
print(f"P(X <= 1.96): {p_95:.4f}") # Approximately 0.975

# Probability that X is between -1 and 1
p_between = norm.cdf(1) - norm.cdf(-1)
print(f"P(-1 <= X <= 1): {p_between:.4f}") # ~0.6827

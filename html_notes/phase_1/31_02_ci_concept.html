02. Confidence Intervals: The Concept

Moving from a single "Guess" to a "Range" of certainty.

1. Definition

A Confidence Interval (CI) is a range of values, derived from sample data, that is likely to contain the value of an unknown population parameter. Instead of providing a single number (a Point Estimate), we provide an interval $[Lower, Upper]$ accompanied by a **Confidence Level** (usually 95%).

2. The True Meaning of "95% Confidence"

It is a common mistake to say "There is a 95% chance the parameter is in this specific interval." In Frequentist statistics, the parameter is a fixed constant. **95% Confidence** means that if we repeated our experiment 100 times and calculated 100 different intervals, we would expect 95 of those intervals to successfully "capture" the true parameter. The interval is what's random, not the parameter.

3. AI/ML Connection: Model Confidence and Error Tolerance

Communicating Uncertainty

In AI, Point Estimates are often insufficient for Critical Decision Making.

If an medical AI predicts a patient's blood pressure is 120 (Point Estimate), that's one thing. But if the **95% Confidence Interval** is $[80, 160]$, a doctor knows the model is actually very uncertain. In **A/B Testing** for product features, we use CIs to determine if a change in user engagement is "Significant." If the CI for the difference in engagement includes zero, we cannot say if the new feature is better or just noise. By using CIs, AI systems move from being "Black Boxes that give a single answer" to being **Statistical Systems** that communicate their own level of doubt. This is essential for Safety-Critical AI (Self-driving cars, medical diagnosis) where knowing how much you don't know is as important as the prediction itself.

4. Python: Simulating 100 Intervals

# Population mean = 50. Let's see how many intervals capture it.
true_mu = 50
captured_count = 0

for _ in range(100):
    sample = np.random.normal(true_mu, 5, 30)
    mu_hat = np.mean(sample)
    se = 5 / np.sqrt(30)
    # 95% CI calculation (approximated)
    low, high = mu_hat - 1.96*se, mu_hat + 1.96*se
    
    if low <= true_mu <= high:
        captured_count += 1

print(f"Intervals that captured the truth: {captured_count}/100")

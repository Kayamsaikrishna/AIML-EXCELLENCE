Module 17_01

01. Critical Points and Extrema

Finding the peaks and valleys.

1. Critical Points

A point \(c\) in the domain of \(f\) is a Critical Point if:

$$ f'(c) = 0 \quad \text{or} \quad f'(c) \text{ is undefined} $$

These are the only candidates for where a function might reach a maximum or minimum.

2. First and Second Derivative Tests

  • First Derivative Test: If \(f'(x)\) changes from positive to negative at \(c\), it's a Relative Max.
  • Second Derivative Test: If \(f'(c)=0\) and \(f''(c) > 0\), it's a Relative Min (Bottom of a bowl).

3. AI Connection: The Loss Surface

Global vs Local Minima

In Machine Learning, we want to find the Global Minimum of a Loss function. However, Loss surfaces in Deep Learning have millions of dimensions and are riddled with Local Minima and Saddle Points. Gradient Descent searches for critical points (\(f'(x)=0\)) blindly; understanding these tests helps us design better optimizers (like Adam or RMSprop) that can escape "trap" critical points.

4. Python: Symbolic Extrema Search

import sympy as sp

x = sp.Symbol('x')
f = x**3 - 3*x**2 + 2

# 1. Find Critical Points
df = sp.diff(f, x)
crit_pts = sp.solve(df, x)

print(f"Critical Points: {crit_pts}")

# 2. Test each point with f''(x)
d2f = sp.diff(df, x)
for pt in crit_pts:
    val = d2f.subs(x, pt)
    status = "Max" if val < 0 else "Min" if val > 0 else "Saddle/Inconclusive"
    print(f"At x={pt}: f''(x)={val} -> {status}")

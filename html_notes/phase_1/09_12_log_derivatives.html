Calculus 1.3 Information

Logarithmic Derivatives

Why does multiplying loss by 'log' make training easier? Because it turns products into sums.

The Reciprocal

The derivative of the natural logarithm is simply \(1/x\). This is beautiful and dangerous. It means as \(x\) gets smaller (closer to zero), the change gets drastically larger.

1. The Formulae

Natural Log:

\[ \frac{d}{dx}[\ln x] = \frac{1}{x} \]

Chain Rule Version (Crucial for ML):

\[ \frac{d}{dx}[\ln(u)] = \frac{u'}{u} \]

(The derivative is "u prime over u".)

2. AI/ML Connection: Cross-Entropy & Maximum Likelihood

Why we use Log-Loss

In classification, we want to maximize the probability of the correct class \(p\). Instead of maximizing \(p\), we minimize \(-\ln(p)\) (Negative Log Likelihood). Why?

Look at the gradient: \[ \frac{d}{dp}[-\ln p] = -\frac{1}{p} \]

If the model assigns \(p=0.01\) (wrongly confident) to the correct class, the gradient is \(-100\). This creates a massive "correction force" that slams the weights back in the right direction. If we used just \(1-p\) (MSE) as loss, the gradient would be small (constant 1), and learning would be slow.

3. Python: The "Brakes" of Gradient Descent

log_gradient_magnitude.py
import numpy as np

def log_loss_gradient(p_predicted):
    # Gradient of -ln(p) is -1/p
    return -1.0 / p_predicted

print("Scenario: True Class is 1.")

# Case 1: Model is confident and correct (p=0.9)
p1 = 0.9
g1 = log_loss_gradient(p1)
print(f"Prediction: {p1} | Gradient: {g1:.2f} (Small adjustment)")

# Case 2: Model is unsure (p=0.5)
p2 = 0.5
g2 = log_loss_gradient(p2)
print(f"Prediction: {p2} | Gradient: {g2:.2f} (Medium adjustment)")

# Case 3: Model is confident and WRONG (p=0.01)
p3 = 0.01
g3 = log_loss_gradient(p3)
print(f"Prediction: {p3} | Gradient: {g3:.2f} (HUGE adjustment!)")

# This geometric explosion forces the model to fix bad predictions immediately.

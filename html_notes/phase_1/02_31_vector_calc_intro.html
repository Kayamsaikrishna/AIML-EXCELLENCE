1. The Definition

The Gradient is a vector containing all the partial derivatives of a function. It points in the direction of greatest increase.

$$ \nabla f(x) = \begin{bmatrix} \frac{\partial f}{\partial x_1} \\ \vdots \\ \frac{\partial f}{\partial x_n} \end{bmatrix} $$

This generalizes the concept of "slope" to n-dimensions.

2. The Jacobian Matrix

If we have a function that outputs a vector (like a layer in a neural net \( f: \mathbb{R}^n \to \mathbb{R}^m \)), the derivative is no longer a vector, but a Matrix.

$$ J_{ij} = \frac{\partial y_i}{\partial x_j} $$

This Matrix tells us how every output variable changes with respect to every input variable. Backpropagation is just multiplying Jacobians (Chain Rule).

3. Computing Gradients

Numerical gradient estimation (Finite Differences).

import numpy as np

# A simple scalar function: f(x, y) = x^2 + y^2
def f(v):
    return v[0]**2 + v[1]**2

# Point to evaluate
p = np.array([3.0, 4.0])

# Analytical Gradient: [2x, 2y] -> [6, 8]
grad_analytical = np.array([2*p[0], 2*p[1]])

print(f"Analytical Gradient: {grad_analytical}")

# Numerical Gradient (Finite Difference)
h = 1e-5
grad_num = np.zeros_like(p)

for i in range(len(p)):
    # Perturb dimension i
    p_plus = p.copy()
    p_plus[i] += h
    
    # Calculate slope
    grad_num[i] = (f(p_plus) - f(p)) / h

print(f"Numerical Gradient:  {grad_num}")
# Matches closely!

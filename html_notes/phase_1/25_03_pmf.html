03. Probability Mass Function (PMF)

The distribution of discrete probability.

1. What is a PMF?

For a discrete random variable $X$, the Probability Mass Function (PMF), denoted as $p_X(x)$, provides the probability that $X$ takes exactly the value $x$.

$$ p_X(x) = P(X = x) $$

2. Fundamental Properties

Any valid PMF must satisfy two criteria:

  • Non-negativity: $p_X(x) \ge 0$ for all $x$.
  • Normalization: The sum of probabilities over all possible values must equal 1:
$$ \sum_{x \in \text{Range}(X)} p_X(x) = 1 $$

3. AI/ML Connection: Softmax and Class Probabilities

Interpreting AI Confidence

The Softmax function in Deep Learning is the most direct application of a PMF.

When a Neural Network processes an image and outputs $[0.1, 0.8, 0.1]$ for classes {Cat, Dog, Bird}, it is defining a PMF. The numbers are non-negative and sum to 1.0. The training objective (Cross-Entropy Loss) works by comparing the Empirical PMF (from your data labels) to the Predicted PMF (from the model). Lowering the distance between these two mass functions is how the AI "learns" to distinguish objects. Understanding PMF properties ensures that your model's outputs are mathematically valid probabilities, not just random numbers.

4. Python: Defining a Custom PMF

# Example: A biased coin (Heads=1, Tails=0)
# P(H) = 0.7, P(T) = 0.3
pmf = {1: 0.7, 0: 0.3}

def get_prob(x):
    return pmf.get(x, 0.0)

print(f"P(X=1): {get_prob(1)}")
print(f"P(X=5): {get_prob(5)}") # Not in range
print(f"Sum checks out: {sum(pmf.values()) == 1.0}")

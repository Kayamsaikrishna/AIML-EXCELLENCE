05. Continuity Definition

Where limits meet values.

1. The Three Checklist Conditions

A function \(f(x)\) is Continuous at point \(a\) if and only if:

  1. \(f(a)\) is defined (The point exists).
  2. \(\lim_{x \to a} f(x)\) exists (The approach is consistent).
  3. \(\lim_{x \to a} f(x) = f(a)\) (The approach lands exactly on the point).

If a function is continuous at every point in an interval, we say it is a Continuous Function (usually denoted as \(C^0\)).

2. Global Continuity of Common Functions

Most functions in your AI toolkit are continuous across their domains:

  • Polynomials: Continuous everywhere.
  • Exp/Log: Continuous where defined (\(x>0\) for Log).
  • Trig (sin/cos): Continuous everywhere.

3. AI Connection: Gradient Descent Requirement

Differentiability depends on Continuity

For an optimizer to work, the loss surface must be (mostly) continuous. If the loss function has a "jump" or a "hole", the derivative (the limit) doesn't exist at that point, and the optimizer doesn't know which way is "down". This is why we prefer Smooth activations over step functions.

4. Python: Numerical Continuity Checking

import numpy as np

def is_continuous_at(f, a, eps=1e-7):
    # Check if limit from left/right matches value
    val = f(a)
    left_lim = f(a - eps)
    right_lim = f(a + eps)
    
    return np.allclose(val, left_lim, atol=1e-5) and \
           np.allclose(val, right_lim, atol=1e-5)

# Test 1: f(x) = x^2 (Continuous)
print(f"x^2 at 0: {is_continuous_at(lambda x: x**2, 0)}")

# Test 2: Heaviside Step Function (Discontinuous)
heaviside = lambda x: 1 if x >= 0 else 0
print(f"Step at 0:  {is_continuous_at(heaviside, 0)}")

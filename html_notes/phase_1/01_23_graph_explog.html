23. Graphing Exp & Log Functions

The Hockey Stick and the Plateau. Activation Functions.

1. The Two Shapes

Exponential ($e^x$)

Starts flat, then explodes up. Used in Softmax to emphasize high scores.

Logarithmic ($\ln x$)

Starts vertical, then plateaus. Used to dampen large numbers (e.g. magnitudes of earthquake).

2. Vanishing Gradients

The Sigmoid function \( \sigma(x) = \frac{1}{1+e^{-x}} \) squashes numbers between 0 and 1.

The Trap: At the far ends (very positive or very negative inputs), the curve is flat. A flat curve has a Slope of Zero.

Since Backpropagation multiplies gradients, multiplying by zero kills the learning signal. The network stops learning.

The Fix: ReLU

Rectified Linear Unit (ReLU) is \( \max(0, x) \). For positive numbers, the slope is always 1 (Constant). It never vanishes!

3. Coding Activations

Comparing Derivatives.

// Python: Plotting Gradients
import numpy as np
import matplotlib.pyplot as plt

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)

x = np.linspace(-10, 10, 100)
grad = sigmoid_derivative(x)

plt.plot(x, grad, label="Sigmoid Gradient", color='red')
plt.title("The Vanishing Problem")
plt.xlabel("Input Value")
plt.ylabel("Gradient Strength")
plt.axhline(0, color='black', linestyle='--')
plt.legend()
plt.show()

# Notice: Gradient is only non-zero near 0. 
# Everywhere else, it's dead.

1. The "S" Curves

$$ \sigma(x) = \frac{1}{1+e^{-x}} $$

Use Case: Probability output (Logistic Regression).

The Flaw: Look at the graph. For very large or very small \( x \), the curve is flat. Flat curve = Zero Slope = Zero Gradient. The network stops learning. This is the Vanishing Gradient Problem.

2. Rectified Linear Unit (ReLU)

$$ \text{ReLU}(x) = \max(0, x) $$

It looks like a hockey stick. It solved Deep Learning because the gradient for \( x > 0 \) is always 1. It never vanishes!

Risk: "Dead ReLU". If inputs are always negative, gradient is always 0. The neuron dies.

3. Visualizing Activations

Plotting the curves that power LLMs.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-5, 5, 100)

# Functions
sigmoid = 1 / (1 + np.exp(-x))
tanh = np.tanh(x)
relu = np.maximum(0, x)

# Derivatives (Gradients)
sig_grad = sigmoid * (1 - sigmoid) # Max is 0.25 (Tiny!)
relu_grad = (x > 0).astype(float) # Max is 1.0 (Strong!)

print(f"Max Sigmoid Gradient: {np.max(sig_grad)}")
print("This explains why Deep Sigmoid networks couldn't allow... ")
print("...gradients to flow back to early layers.")

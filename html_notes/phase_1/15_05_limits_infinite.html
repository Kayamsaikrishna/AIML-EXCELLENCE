05. Infinite Limits

When the output "blows up" to infinity.

1. Vertical Asymptotes

An Infinite Limit occurs when the values of \(f(x)\) increase or decrease without bound as \(x\) approaches some number \(a\). We write:

$$ \lim_{x \to a} f(x) = \infty \quad \text{or} \quad \lim_{x \to a} f(x) = -\infty $$

If this occurs, the line \(x = a\) is a Vertical Asymptote.

2. The classic Case: 1/x

Consider \(f(x) = \frac{1}{x}\) as \(x\) approaches 0:

  • From the right (\(x \to 0^+\)): \(1/0.1=10, 1/0.01=100\)... Limit is \(\infty\).
  • From the left (\(x \to 0^-\)): \(1/-0.1=-10, 1/-0.01=-100\)... Limit is \(-\infty\).

3. AI/ML Connection: Exploding Gradients & NaN

When Loss goes to Infinity

In Deep Learning, Exploding Gradients occur when the updates to weights become incredibly large. This often happens if the loss function has a vertical asymptote. For example, the Cross-Entropy Loss:

$$L = -\log(y_{pred})$$

If the model predicts exactly 0 (\(y_{pred} \to 0\)) for a class that should be 1, the loss calculation involves \(\lim_{x \to 0^+} \log(x) = -\infty\), resulting in a loss of \(+\infty\). This is why code often clips predictions to a small value like \(10^{-7}\) to avoid producing NaN (Not a Number) errors.

4. Python: Observing Divergence

import numpy as np

def cross_entropy(y_pred):
    # Cross-entropy loss for target=1
    return -np.log(y_pred)

# Approaching 0
preds = [0.1, 0.01, 1e-5, 1e-10]
for p in preds:
    print(f"Prediction: {p:12} -> Loss: {cross_entropy(p):.4f}")

# Near zero, loss 'blows up'
try:
    print(f"Prediction: 0.0 -> Loss: {cross_entropy(0)}")
except:
    print("Log(0) Error!")

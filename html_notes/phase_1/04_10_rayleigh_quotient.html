1. Definition

For a symmetric matrix \( A \), the Rayleigh Quotient for a vector \( x \) is:

$$ R(A, x) = \frac{x^T A x}{x^T x} $$

The Min-Max Theorem states that the maximum value of \( R(x) \) is the largest eigenvalue, and the minimum is the smallest.

2. Principal Components

PCA (Principal Component Analysis) can be framed as an optimization problem: Find the direction \( u \) that maximizes the variance.

$$ \max_u \frac{u^T \Sigma u}{u^T u} $$

By the Rayleigh theorem, the solution is exactly the eigenvector corresponding to the largest eigenvalue of the Covariance matrix \( \Sigma \).

3. Numerical Bounds

import numpy as np

# Symmetric Matrix
A = np.array([
    [3, 1],
    [1, 2]
])

vals = np.linalg.eigvals(A)
min_lambda = np.min(vals)
max_lambda = np.max(vals)

print(f"True Eigenvalues: {min_lambda:.4f}, {max_lambda:.4f}")

# Test Random Vectors
radii = []
for _ in range(100):
    x = np.random.randn(2)
    R = (x.T @ A @ x) / (x.T @ x)
    radii.append(R)

print(f"Random R Min: {min(radii):.4f}")
print(f"Random R Max: {max(radii):.4f}")
# Notice the random values never exceed the eigenvalue bounds

10. Rayleigh Quotient

Turning Linear Algebra into an Optimization problem.

1. The Definition

For a real symmetric matrix \(\mathbf{A}\), the Rayleigh Quotient \(R(\mathbf{A}, \mathbf{x})\) is defined for a non-zero vector \(\mathbf{x}\) as:

$$ R(\mathbf{A}, \mathbf{x}) = \frac{\mathbf{x}^T\mathbf{A}\mathbf{x}}{\mathbf{x}^T\mathbf{x}} $$

If \(\mathbf{x}\) is an eigenvector with eigenvalue \(\lambda\), then \(R(\mathbf{A}, \mathbf{x}) = \lambda\).

2. The Min-Max Property

Energy Bounds

Crucially, the Rayleigh Quotient is bounded by the smallest and largest eigenvalues:

$$ \lambda_{min} \leq \frac{\mathbf{x}^T\mathbf{A}\mathbf{x}}{\mathbf{x}^T\mathbf{x}} \leq \lambda_{max} $$

To find the "Principal Direction" of data, we simply pick the \(\mathbf{x}\) that **maximizes** this quotient. To find the "Bottleneck," we minimize it.

3. AI Application: LDA & Fisher's Criterion

Linear Discriminant Analysis (LDA)

In classification, we want to find a direction that maximizes the distance between class means while minimizing the variance within classes. This "separability" is expressed exactly as a Generalized Rayleigh Quotient:

$$ J(\mathbf{w}) = \frac{\mathbf{w}^T\mathbf{S}_B\mathbf{w}}{\mathbf{w}^T\mathbf{S}_W\mathbf{w}} $$

4. Python: Estimating Max Eigenvalue

import numpy as np

A = np.array([[5, 1], [1, 5]])

# Start with a random vector
x = np.random.rand(2)

# Compute Rayleigh Quotient
def rayleigh_quotient(A, x):
    return (x.T @ A @ x) / (x.T @ x)

# Iteratively improve x (Simplistic Power Method)
for _ in range(10):
    x = A @ x
    x = x / np.linalg.norm(x)

estimated_lambda = rayleigh_quotient(A, x)
actual_lambda = max(np.linalg.eigvals(A))

print(f"Estimated: {estimated_lambda:.4f}")
print(f"Actual: {actual_lambda:.4f}")

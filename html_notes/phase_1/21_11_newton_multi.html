11. Newton's Method in Multiple Dimensions

Higher-order acceleration for optimization.

1. The Matrix Update Rule

While Gradient Descent only uses the first derivative, Newton's Method uses the second derivative (the Hessian) to take more "intelligent" steps. By approximating the function as a parabola locally, Newton's method can reach the minimum in far fewer steps.

$$ \mathbf{w}_{t+1} = \mathbf{w}_t - \mathbf{H}_f(\mathbf{w}_t)^{-1} \nabla f(\mathbf{w}_t) $$

Instead of just moving "Downhill", the Hessian inverse \(\mathbf{H}^{-1}\) scales the step based on the Curvature. It moves faster in flat directions and slower in steep directions.

2. Convergence Speed

Newton's Method has Quadratic Convergence near the optimum. If you are close, it doubles the number of correct digits with every step. In contrast, Gradient Descent is only linear.

3. AI/ML Connection: Why don't we use it in Deep Learning?

The Computational Wall

If Newton's Method is so much faster, why do we use SGD instead?

The problem is the Hessian Inverse. If a Neural Network has 1 million weights, the Hessian is a \(1M \times 1M\) matrix. Calculating and inverting such a matrix would take trillions of operations and petabytes of RAM.

However, Newton's Method is the gold standard for Scikit-Learn models (like Logistic Regression or GLMs) where the number of features is small (e.g., < 10,000). It is also the basis for Second-Order Optimizers like L-BFGS, which try to approximate the Hessian's effect without actually building the full matrix. Newton's Method is the "Limit" of how fast math can solve a problem if computation was infinite.

4. Python: Newton vs. Gradient Descent

import numpy as np

# f = x^2 + 10y^2 (A narrow valley)
def grad(v): return np.array([2*v[0], 20*v[1]])
def hess_inv(v): return np.diag([1/2, 1/20])

v = np.array([10.0, 10.0])

# Newton's Step
v_next = v - hess_inv(v) @ grad(v)
print(f"Newton's result after 1 step: {v_next}") 
# Result: [0, 0] (Exact min in one jump for quadratics!)

# Gradient Descent with lr=0.1
v_gd = v - 0.1 * grad(v)
print(f"GD result after 1 step: {v_gd}") # [8, -10] (Overshot Y!)

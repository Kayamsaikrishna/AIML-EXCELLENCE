1. What "Dies"?

The Null Space (or Kernel) of a matrix \( A \) consists of all vectors \( \mathbf{x} \) such that:

$$ A\mathbf{x} = \mathbf{0} $$

If the Null Space contains only the zero vector (\( \mathbf{x}=0 \)), the matrix is Invertible (it preserves all information). If it contains non-zero vectors, the matrix destroys dimensions (flattening 3D to 2D, etc.).

2. Reconstruction Loss

In GANs or Autoencoders, we want to map data to a latent space and back. If the mapping matrix has a large Null Space, we lose critical information that can never be recovered.

Singular matrices (Determinant 0) have non-trivial Null Spaces. This is why adding a small "jitter" (Regularization) helps keep matrices invertible.

3. Determining the Kernel

Finding the vectors that map to zero using SVD or Scipy.

import numpy as np
from scipy.linalg import null_space

# A singular matrix (Rank 1, not 2)
# Both rows are identical scales of [1, 2]
A = np.array([
    [1, 2],
    [2, 4]
])

# Find Null Space Basis
ns = null_space(A)

print("Null Space Basis Vector:")
print(ns)
# Expected: roughly [-0.89, 0.44]
# (Any multiple of [-2, 1] works because 1(-2) + 2(1) = 0)

# Verify
x = ns[:, 0]
result = np.dot(A, x)

print(f"\nAx (Should be near 0):")
print(result) # [0. 0.]

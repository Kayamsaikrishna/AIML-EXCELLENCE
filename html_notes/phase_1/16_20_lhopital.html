20. L'Hôpital's Rule

Resolving "Indeterminate" limits.

1. Indeterminate Forms

Sometimes when calculating a limit, you end up with nonsensical forms like \(\frac{0}{0}\) or \(\frac{\infty}{\infty}\). These are called indeterminate forms because the result isn't necessarily zero or infinity—it depends on which function is "winning" the race.

2. The Rule

If \(\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{0}{0}\) or \(\frac{\infty}{\infty}\), then:

$$ \lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} \frac{f'(x)}{g'(x)} $$

Provided the second limit exists. You can apply the rule multiple times! Note: This is not the quotient rule—you differentiate the top and bottom separately.

3. AI/ML Connection: Numerical Stability

Limits in Loss Functions

Calculus models often involve terms like \(\frac{1 - e^{-x}}{x}\). If you try to evaluate this at \(x=0\) in code, you get NaN (Not a Number) because of division by zero.

However, by using L'Hôpital's Rule, we know that as \(x \to 0\), the value limit is \(\frac{e^{-x}}{1} = 1\). This "theoretical value" is used to create stable numerical implementations (like numpy.sinc or scipy.special.log1p) that avoid crashing when a training process hits a zero-state.

4. Python: Symbolic Limit Resolution

import sympy as sp

x = sp.Symbol('x')
f = sp.sin(x)
g = x

# Evaluates to 0/0 if evaluated directly at 0
limit_val = sp.limit(f/g, x, 0)

print(f"Limit of sin(x)/x as x->0 : {limit_val}") 
# Result: 1 (via L'Hopital's)

07. Numerical Differentiation

Estimating slopes without symbolic algebra.

1. Finite Differences

Numerical Differentiation is the process of estimating the derivative of a function using discrete values. The most common method is the Symmetric Difference Quotient derived from the definition of the derivative:

$$ f'(x) \approx \frac{f(x + h) - f(x - h)}{2h} $$

As $h \to 0$, the approximation becomes exact. However, in computers, $h$ cannot be too small due to floating-point precision errors.

2. Precision vs. Stability

If $h$ is too large, we get a Truncation Error (the formula is wrong). If $h$ is too small, we get a Round-off Error (the computer can't tell the difference between $x$ and $x+h$). Finding the "magic" $h$ (usually around $10^{-7}$ for double precision) is a classic problem in numerical calculus.

3. AI/ML Connection: Gradient Checking

Verifying the Math

In the early days of AI, researchers had to manually code the derivatives for backpropagation. A single typo in a partial derivative could ruin a model.

Gradient Checking is an AI dev-tool that uses Numerical Differentiation to verify an analytical derivative. The system calculates the slope using the complex backprop code, and then calculates it again using the simple Finite Difference formula. If the two match to 6 decimal places, the calculus is correct. Although we rarely use numerical diff for training (it's too slow), it remains the "Golden Standard" for debugging the mathematical heart of AI software.

4. Python: Gradient Checker

def f(x): return x**2
def df_analytical(x): return 2*x

def df_numerical(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

x_val = 5.0
ana = df_analytical(x_val)
num = df_numerical(f, x_val)

print(f"Analytical: {ana}")
print(f"Numerical: {num}")
print(f"Difference: {abs(ana - num)}")

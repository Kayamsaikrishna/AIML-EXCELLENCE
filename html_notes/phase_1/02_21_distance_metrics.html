1. Euclidean vs Cosine

Euclidean (\( L_2 \))

How far apart two points are in space. Good for physical data (GPS).

$$ d = || \mathbf{u} - \mathbf{v} ||_2 $$

Cosine Similarity

The angle between vectors. Ignores magnitude (length). Good for Text/NLP.

$$ \cos \theta = \frac{\mathbf{u} \cdot \mathbf{v}}{||\mathbf{u}|| ||\mathbf{v}||} $$

2. Why Cosine for AI?

In high dimensions (e.g., 768-dim BERT embeddings), Euclidean distance fails. All points tend to become equidistant ("Curse of Dimensionality").

However, the Direction (Angle) remains meaningful. Two documents about "Physics" will point in the same direction, even if one is 100 words and the other is 10,000 words.

3. Comparing Metrics

Euclidean vs Cosine on Text Embeddings.

import numpy as np
from scipy.spatial.distance import euclidean, cosine

# Embeddings (Simplified)
# Doc A: "AI is great" (Short)
# Doc B: "AI is great and very useful" (Long, same topic)
# Doc C: "I like Pizza" (Different topic)

v_A = np.array([1, 1, 0])
v_B = np.array([2, 2, 0]) # Just a scaled version of A
v_C = np.array([0, 0, 1])

print(f"Euclidean(A, B): {euclidean(v_A, v_B):.2f}") 
# ~1.41 (Far apart physically!)

print(f"Cosine Dist(A, B): {cosine(v_A, v_B):.2f}") 
# 0.00 (Identical meaning!)

print(f"Cosine Dist(A, C): {cosine(v_A, v_C):.2f}")
# 1.00 (Opposite/Orthogonal)

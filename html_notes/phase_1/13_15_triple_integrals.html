Calculus 1.6 Volumes

Triple Integrals

Thinking in 3D voxels.

Adding up Volumetric Density

A Triple Integral \( \iiint_E f(x, y, z) \, dV \) sums up a quantity over a 3D solid region \( E \). If \( f(x, y, z) = 1 \), it simply calculates the Volume of the region. If \( f \) represents density (mass per unit volume), it calculates Total Mass.

The bounds of integration can be complex, requiring careful definition of surfaces: \[ \int_{x=a}^b \int_{y=g_1(x)}^{g_2(x)} \int_{z=u_1(x,y)}^{u_2(x,y)} f(x,y,z) \, dz \, dy \, dx \]

2. AI/ML Connection: Volumetric Rendering (NeRF)

Neural Radiance Fields

NeRF (Neural Radiance Fields) technology reconstructs 3D scenes from 2D images. To render a pixel, the AI shoots a "ray" into the 3D scene. Along this ray, it queries a neural network for the density \( \sigma \) and color \( c \) at every point.

The final pixel color is calculated by a Volume Integral (approximate triple integral) along the ray: \[ C(r) = \int_{t_n}^{t_f} T(t) \sigma(r(t)) c(r(t), d) \, dt \] This is essentially summing up the light emitted by particles along the ray, accounting for occlusion (transmittance \( T \)). Understanding triple integrals is key to understanding how these 3D neural networks "see" the world.

3. Python: Computing Box Volume

triple_int.py
from scipy.integrate import tplquad

# Integrate f(x, y, z) = x*y*z over the unit cube [0,1]^3
f = lambda z, y, x: x * y * z

# tplquad arguments: f, x_min, x_max, y_min_func, y_max_func, z_min_func, z_max_func
val, err = tplquad(f, 
                   0, 1, 
                   lambda x: 0, lambda x: 1, 
                   lambda x,y: 0, lambda x,y: 1)

print(f"Integral Result: {val:.4f}")
print(f"Error Estimate:  {err:.4e}")

# Manual verification:
# Int(x) from 0-1 = 1/2
# Int(y) from 0-1 = 1/2
# Int(z) from 0-1 = 1/2
# Total = 1/8 = 0.1250

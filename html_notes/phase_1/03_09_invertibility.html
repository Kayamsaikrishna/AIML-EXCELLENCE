09. Conditions for Invertibility

When can we undo a transformation?

1. The Non-Singular Threshold

A matrix \( \mathbf{A} \) is invertible if and only if it satisfies the following equivalent conditions:

  • Determinant: \( \text{det}(\mathbf{A}) \neq 0 \). (The transformation doesn't collapse the space).
  • Rank: It is Full Rank (\( \text{rank}(\mathbf{A}) = n \)).
  • Independence: All columns (and rows) are linearly independent.
  • Null Space: The only vector \( \mathbf{x} \) such that \( \mathbf{Ax} = 0 \) is the zero vector \( \mathbf{x} = 0 \).

2. Singularity in Data Science

Multi-Collinearity and Redundant Features

If you have a dataset where one feature is a linear combination of others (e.g., "Weight in kg" and "Weight in lbs"), the resulting matrix \( \mathbf{X}^T\mathbf{X} \) becomes Singular (determinant = 0).

  • Model Failure: The computer cannot calculate \( (\mathbf{X}^T\mathbf{X})^{-1} \), throwing a "Singular Matrix" error.
  • Low-Rank Approximation: Sometimes we intentionally make matrices non-invertible to compress data (PCA).

3. Python: Checking for Singularity

import numpy as np

# Singular Matrix (Rows are dependent)
A = np.array([[1, 2], [2, 4]]) 

det = np.linalg.det(A)
rank = np.linalg.matrix_rank(A)

print(f"Determinant: {det}") # Output: 0
print(f"Rank: {rank}")       # Output: 1 (Not Full Rank)

if det == 0:
    print("Matrix is Singular (Not Invertible)")

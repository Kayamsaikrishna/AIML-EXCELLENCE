1. The Big Theorem

All the following statements are equivalent. If one is true, they are all true:

  • \( A \) is invertible.
  • \( A \) is row-equivalent to \( I \) (Full Rank).
  • \( A\mathbf{x} = \mathbf{0} \) has only the trivial solution.
  • The determinant \( \det(A) \neq 0 \).
  • The columns of \( A \) form a basis for \( \mathbb{R}^n \).

2. Condition Number

In AI, exact singularity is rare (due to noise). But "near singularity" is common and dangerous.

The Condition Number \( \kappa(A) = ||A|| \cdot ||A^{-1}|| \) tells us how close we are to singularity.

  • Small \( \kappa \): Stable.
  • Large \( \kappa \): Ill-conditioned. Small input errors explode (Ex: Exploding Gradients).

3. Testing Solvability

Checking Rank and Condition Number.

import numpy as np

# A Nearly Singular Matrix (Cols are almost parallel)
A = np.array([
    [1, 1],
    [1, 1.00000001]
])

det = np.linalg.det(A)
rank = np.linalg.matrix_rank(A)
cond = np.linalg.cond(A)

print(f"Determinant: {det:.10f}") # Non-zero, technically invertible
print(f"Rank: {rank}")
print(f"Condition Number: {cond:.2e}") 
# ~2e8! Huge. This system is numerically unstable.

# If we try to solve Ax = b, errors will be massive.
b = np.array([2, 2])
x = np.linalg.solve(A, b)
print(f"Solution: {x}")

ML Calc 1.9 Evolution

Gradient Descent Variants

From Vanilla SGD to Adam.

The Zoo of Optimizers

SGD (Stochastic Gradient Descent): Updates using one sample at a time. Noisy but fast. \[ \mathbf{w} \leftarrow \mathbf{w} - \eta \nabla L_i(\mathbf{w}) \]

Momentum: Adds a "velocity" term to dampen oscillations and power through ravines.

Adam (Adaptive Moment Estimation): The current gold standard. It adapts the learning rate for *each parameter* individually based on statistics of the gradients (First and Second moments).

2. ML Connection: Why Adam Wins

Parameter Scale

In a deep net, some weights might have huge gradients (early layers) and some tiny (later layers). A global learning rate \(\eta\) cannot satisfy both. Adam divides the step size by the running average of the gradient's magnitude, effectively normalizing the update for every single neuron.

3. Python: Optimizers in Torch

optimizer_compare.py
import torch
import torch.nn as nn

# Dummy model
model = nn.Linear(10, 1)

# 1. Vanilla SGD
opt_sgd = torch.optim.SGD(model.parameters(), lr=0.01)

# 2. SGD with Momentum
opt_mom = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# 3. Adam
opt_adam = torch.optim.Adam(model.parameters(), lr=0.001)

print("Optimizers initialized.")

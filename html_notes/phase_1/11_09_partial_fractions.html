Calculus 1.4 Decomposition

Partial Fraction Decomposition

Breaking big problems into small, solvable ones.

Factor and Conquer

Integration is linear: \(\int (A+B) = \int A + \int B\). We use PFD to turn a complicated rational function \(\frac{P(x)}{Q(x)}\) (which is hard to integrate) into a sum of simple terms like \(\frac{A}{x-r}\) (which integrate easily to logs).

1. The Formula

If the denominator \(Q(x)\) factors into \((x-r)(x-s)\), we write: \[ \frac{1}{(x-r)(x-s)} = \frac{A}{x-r} + \frac{B}{x-s} \]

The Solution Strategy:

  1. Factor the denominator completely.
  2. Set up the decomposition with unknown constants \(A, B, C...\).
  3. Multiply by the denominator to clear fractions.
  4. Solve for constants by plugging in roots or equating coefficients.

2. AI/ML Connection: Control & Lapalce

Linear Time-Invariant Systems

In Robotics and Control Theory, we analyze stability in the "Laplace Domain". A robot arm's movement is described by a transfer function \(H(s) = \frac{N(s)}{D(s)}\).

To find out how the arm moves over time (Inverse Laplace Transform), we MUST use Partial Fraction Decomposition. Each term \(\frac{A}{s-p}\) corresponds to a decaying exponential \(e^{pt}\). PFD tells us exactly which "poles" (eigenvalues) are driving the system's behavior—whether it will stabilize or oscillate uncontrollably.

3. Python: Symbolic Decomposition

pfd_solver.py
import sympy as sp

x = sp.Symbol('x')
# Complex rational function
rational_func = 1 / (x**2 - 5*x + 6)

# 1. Decompose (Algebraic Step)
# This splits it into A/(x-3) + B/(x-2)
decomposed = sp.apart(rational_func)
print(f"Decomposed: {decomposed}")
# Output: 1/(x-3) - 1/(x-2)

# 2. Integrate
integral = sp.integrate(decomposed, x)
print(f"Integral: {integral}")
# Output: log(x-3) - log(x-2)

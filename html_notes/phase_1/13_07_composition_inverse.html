07. Composition and Inverses

Chaining transformations and hitting "Undo".

1. Composition (Chaining)

Performing transformation \(S\) then transformation \(T\) is written as \(T \circ S\). The matrix for this combined action is the Product of their matrices:

$$ [T \circ S] = \mathbf{T} \cdot \mathbf{S} $$

Crucial Order: Composition is read right-to-left. \(S\) happens first!

2. Inverses (Hitting Undo)

If \(T\) is an isomorphism, it has an inverse \(T^{-1}\) that "undoes" the mapping. The matrix of \(T^{-1}\) is simply the Matrix Inverse \(\mathbf{A}^{-1}\).

$$ T^{-1}(T(\mathbf{v})) = \mathbf{v} \implies \mathbf{A}^{-1}\mathbf{A} = \mathbf{I} $$

3. AI Architectures: The MLP

Multi-Layer Perceptron (MLP)

A deep neural network is just a giant Composition of functions. If we ignore non-linearity for a moment, an \(L\)-layer network is just: \(\mathbf{y} = \mathbf{W}_L \mathbf{W}_{L-1} \dots \mathbf{W}_1 \mathbf{x}\). From a math perspective, any number of linear layers can be collapsed into a single linear layer. This is why non-linearities are mandatory for deep networks to be "deep".

4. Python: Function Composition

import numpy as np

W1 = np.array([[1, 2], [3, 4]])
W2 = np.array([[0, 1], [-1, 0]])

# Manual chaining
x = np.array([1, 1])
y = W2 @ (W1 @ x)

# Composed matrix
W_composed = W2 @ W1
y_comp = W_composed @ x

print(f"Match? {np.allclose(y, y_comp)}")

Calculus 1.3 Simplicity

Linear Approximation

Locally, the world is flat. This simple lie allows Gradient Descent to work.

The Tangent Line Estimate

Complex curves are hard. Straight lines are easy. Differentiation allows us to replace a complicated function \(f(x)\) with a simple linear function \(L(x)\) as long as we don't move too far from our starting point.

1. The Formula

The Linearization \(L(x)\) of \(f\) at \(a\) is:

\[ L(x) = f(a) + f'(a)(x - a) \]

The Differential Form:

Let \(dx\) be a small change in input. The approximate change in output \(dy\) is:

\[ dy = f'(x) dx \]

This \(dy\) is the rise of the tangent line, while \(\Delta y\) is the rise of the actual curve.

2. AI/ML Connection: Why Gradient Descent works

The "Trust Region"

Gradient Descent Update: \( \theta_{new} = \theta_{old} - \alpha \nabla J(\theta) \)

This formula is derived by minimizing the Linear Approximation of the Loss Function. We assume: \[ J(\theta_{new}) \approx J(\theta_{old}) + \nabla J \cdot (\theta_{new} - \theta_{old}) \]

The Learning Rate (\(\alpha\)): This controls how far we trust this linear approximation.

  • Too small: We trust it, but move painfully slow.
  • Too large: We step outside the region where the curve looks like a line. The approximation fails, and loss actually increases (divergence).

3. Python: Breaking the Approximation

linear_breakdown.py
import numpy as np

def f(x):
    return x**2 # A simple curve

def L(x, a):
    # L(x) = f(a) + f'(a)(x-a)
    slope = 2*a
    return f(a) + slope * (x - a)

a = 2.0 # Approximation point
print(f"Approximating x^2 at a={a}")
print("-" * 50)
print(f"{'Step Size dx':<15} | {'Actual f(a+dx)':<18} | {'Linear L(a+dx)':<18} | {'Error'}")
print("-" * 50)

steps = [0.01, 0.1, 1.0, 5.0]

for dx in steps:
    x_new = a + dx
    actual = f(x_new)
    pred = L(x_new, a)
    error = abs(actual - pred)
    print(f"{dx:<15} | {actual:.4f}             | {pred:.4f}             | {error:.4f}")

print("-" * 50)
print("Notice how error explodes as step size increases. This is why high learning rates kill training.")

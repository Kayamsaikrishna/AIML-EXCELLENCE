Congruences & Linear Equations

Solving for X in a Finite World. How to find unknowns when the rules of equality wrap around like a clock face.

The Modular Equation

A linear congruence is an equation of the form $ax \equiv b \pmod n$. It asks: "Is there an integer $x$ such that multiplying it by $a$ and dividing by $n$ leaves a remainder of $b$?" This is the core logic behind cryptographic key exchange.

1. Solvability Condition

The congruence $ax \equiv b \pmod n$ has a solution if and only if:

$$ d | b \quad \text{where } d = gcd(a, n) $$

If $d$ divides $b$, there are exactly $d$ distinct solutions modulo $n$. If $d=1$ (coprime), there is exactly one unique solution.

2. Solving the Equation

To solve, we multiply both sides by the modular inverse of $a$ modulo $n$.

$$ x \equiv a^{-1} b \pmod n $$

The inverse $a^{-1}$ exists only if $gcd(a, n) = 1$. We find it using the Extended Euclidean Algorithm.

Randomness Simulation

Linear Congruential Generators (LCG)

Almost all basic random number generators in AI (like older versions of Python's `random`) use a recurrence relation based on a linear congruence:

$$ X_{n+1} = (aX_n + c) \pmod m $$
  • Choice of Parameters: The values of $a, c, m$ determine the "period" (how long before the sequence repeats). Number theory tells us how to pick them to maximize the period.
  • Predictability: Because LCGs differ from true randomness (they are deterministic), they are fast but unsuitable for crypto. However, they are perfect for Stochastic Gradient Descent (SGD) shuffling where speed is key.

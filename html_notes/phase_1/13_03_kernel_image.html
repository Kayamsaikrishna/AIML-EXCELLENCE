03. Kernel and Image (Range)

Where vectors go to die, and where they land.

1. The Kernel (Null Space)

The Kernel of \(T\) is the set of vectors that map to zero:

$$ \text{ker}(T) = \{ \mathbf{v} \in V \mid T(\mathbf{v}) = \mathbf{0} \} $$

Property: \(T\) is injective (one-to-one) if and only if \(\text{ker}(T) = \{ \mathbf{0} \}\).

2. The Image (Range)

The Image of \(T\) is the set of all possible outputs:

$$ \text{im}(T) = \{ \mathbf{w} \in W \mid \mathbf{w} = T(\mathbf{v}) \text{ for some } \mathbf{v} \in V \} $$

Property: This is exactly the Column Space of the transformation's matrix.

4. AI Insight: Information Bottlenecks

If the dimension of the **Image** is smaller than the **Domain** (rank deficiency), information is permanently lost. This is useful for removing noise (denoising) or discovering latent features, but harmful if the network collapses (e.g., Mode Collapse in GANs).

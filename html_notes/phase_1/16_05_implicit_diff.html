05. Implicit Differentiation

Differentiation without an explicit function.

1. Why Implicit?

Most functions are Explicit (\(y = f(x)\)). But what about curves defined by equations where \(y\) cannot be isolated, like a circle: \(x^2 + y^2 = 25\)?

We differentiate both sides with respect to \(x\), treating \(y\) as an unknown function of \(x\), and then use the Chain Rule for every \(y\) term.

2. The Process

For \(x^2 + y^2 = 25\):

  1. Differentiate: \(2x + 2y \cdot \frac{dy}{dx} = 0\)
  2. Rearrange for \(\frac{dy}{dx}\): \(2y \cdot \frac{dy}{dx} = -2x\)
  3. Solution: \(\frac{dy}{dx} = -\frac{x}{y}\)

3. AI Connection: Level Sets & Classification

Decision Boundaries

In classification, the boundary where a model is neutral (e.g., \(P(class=1) = 0.5\)) is a Level Set of the probability function. We often need to find the slope of this boundary to understand the model's sensitivity. Implicit differentiation allows us to find the gradient of the boundary directly from the neural network's weights.

4. Python: Symbolic Implicit Solves

import sympy as sp

x, y = sp.symbols('x y')
# Equation: x^2 + y^2 - 25 = 0
expr = x**2 + y**2 - 25

# Implicit derivative dy/dx
# Rule: dy/dx = - (df/dx) / (df/dy)
result = -sp.diff(expr, x) / sp.diff(expr, y)

print(f"Implicit Derivative dy/dx: {result}")

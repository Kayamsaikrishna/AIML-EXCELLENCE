1. The Factorization

If a matrix has enough independent eigenvectors, we can factorize it into:

$$ A = PDP^{-1} $$
  • \( P \): Matrix with Eigenvectors as columns.
  • \( D \): Diagonal Matrix with Eigenvalues on the diagonal.

This "Diagonalizes" the matrix. In the Eigen-basis, the transformation is purely stretching (no rotating/shearing).

2. Powers of Matrices

If we want to compute \( A^{100} \) (e.g. 100 steps of a Markov Chain or Recurrent Net), doing 100 multiplications is slow.

With diagonalization:

$$ A^k = (PDP^{-1})^k = P D^k P^{-1} $$

Computing \( D^k \) is trivial (just power the diagonal elements). This makes analyzing long-term behavior (stability) of AI systems possible.

3. Fibonacci via Matrix Power

Calculating the 1000th Fibonacci number instantly.

import numpy as np

# Fibonacci Matrix
# [ F_n+1 ] = [ 1 1 ] [ F_n   ]
# [ F_n   ]   [ 1 0 ] [ F_n-1 ]
A = np.array([
    [1, 1],
    [1, 0]
])

# Diagonalize
vals, P = np.linalg.eig(A)
D = np.diag(vals)
P_inv = np.linalg.inv(P)

# Calculate A^10
k = 10
D_k = np.power(D, k)
A_k = P @ D_k @ P_inv

print(f"Matrix A^{k}:")
print(A_k)

# Check F_10 (Should be 55)
# Initial state [F1, F0] = [1, 0]
start = np.array([1, 0])
result = np.dot(A_k, start)
print(f"\nF_{k+1}: {result[0]:.2f}") # F_11
print(f"F_{k}:   {result[1]:.2f}") # F_10 = 55

Prob 1.4 Uncorrelated

Independence

When knowing one thing tells you nothing about the other.

Definition

Two events \(A\) and \(B\) are Independent if: \[ P(A \cap B) = P(A)P(B) \] Equivalently: \(P(A|B) = P(A)\).

WARNING: Disjoint events are NOT independent. If \(A\) and \(B\) are disjoint, knowing \(A\) happened tells me definitely \(B\) did NOT happen (maximal dependence).

2. ML Connection: I.I.D Assumption

Independent and Identically Distributed

Almost all ML theory rests on the I.I.D. Assumption. We assume each data point \((x_i, y_i)\) is drawn independently from the same underlying distribution. \[ P(D) = \prod_{i=1}^N P(x_i, y_i) \]

If data is not independent (e.g., Time Series, Video), standard algorithms fail, and we need RNNs or Transformers.

3. Python: Covariance Check

independence_check.py
import numpy as np

# Simulate independent coin flips
flips1 = np.random.randint(0, 2, 1000)
flips2 = np.random.randint(0, 2, 1000)

# Joint probability P(H, H) should be 0.25
joint_heads = np.mean((flips1 == 1) & (flips2 == 1))
print(f"Joint Prob P(H,H): {joint_heads:.3f}")

# Product of marginals P(H)*P(H) = 0.5 * 0.5 = 0.25
prod_marginals = np.mean(flips1==1) * np.mean(flips2==1)
print(f"Product Prob:      {prod_marginals:.3f}")

# Correlation should be near 0
corr = np.corrcoef(flips1, flips2)[0,1]
print(f"Correlation: {corr:.4f}")

11. Riemann Sums & Definite Integrals

Approximating area with rectangles.

1. The Riemann Definition

A Definite Integral \(\int_{a}^{b} f(x) dx\) represents the signed area under a curve. We define it as the limit of a Riemann Sum as the number of sub-intervals (\(n\)) goes to infinity:

$$ \int_{a}^{b} f(x) dx = \lim_{n \to \infty} \sum_{i=1}^{n} f(x_i) \Delta x $$

Where \(\Delta x = \frac{b-a}{n}\) is the width of each strip.

2. Over and Under Estimates

  • Left Riemann Sum: Uses the left endpoint of each strip.
  • Right Riemann Sum: Uses the right endpoint.
  • Midpoint Rule: Often the most accurate simple approximation.

3. AI/ML Connection: Numerical Integration & Histograms

Discrete Real-World Data

Computers cannot truly perform "limits to infinity". When an AI processes data from a sensor (like a heart rate monitor), it receives discrete samples. Calculating the "Total energy" or "Area" of that signal is essentially a Riemann Sum.

Furthermore, and most importantly, Histograms are physical Riemann Sums. If you normalize a histogram so its total area is 1, you have created a discrete probability distribution. Understanding Riemann sums allows AI researchers to convert real-world "binned" data into smooth mathematical functions using Kernel Density Estimation (KDE).

4. Python: Manual Riemann Sum Implementation

def riemann_sum(f, a, b, n):
    dx = (b - a) / n
    total_area = 0
    for i in range(n):
        x_i = a + i * dx # Left endpoint
        total_area += f(x_i) * dx
    return total_area

# Approx area under x^2 from 0 to 1
# Analytical solution is 1/3 = 0.333
ans = riemann_sum(lambda x: x**2, 0, 1, 1000)
print(f"Approx Area (1000 rectangles): {ans:.6f}")

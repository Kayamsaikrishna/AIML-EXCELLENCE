Calculus 1.3 Cyclic Rates

Trigonometric Derivatives

Analyzing periodic systems where change repeats itself forever.

The Cycle of Derivatives

Trig functions are unique: diferentiating them keeps you in the trig family. This provides infinite smoothness, which is why sine waves are nature's building blocks (Fourier Series).

1. The Core Rules

Sine

\( \frac{d}{dx}\sin x = \cos x \)

Cosine

\( \frac{d}{dx}\cos x = -\sin x \)

Tangent

\( \frac{d}{dx}\tan x = \sec^2 x \)

Negative "Co"-functions

Derivative of any Co function (Cos, Cot, Csc) is always Negative.

2. AI/ML Connection: Positional Encodings

Transformers & Sequence Position

In Transformer models (like GPT-4), the network processes all words in parallel. To give it a sense of "order" (Word A comes before Word B), we inject Positional Encodings made of sine and cosine waves of different frequencies.

\[ PE_{(pos, 2i)} = \sin(pos / 10000^{2i/d_{model}}) \]

When we train the model, gradients flow back through these embeddings. The smooth, bounded derivatives of sine and cosine (\([-1, 1]\)) ensure that these position signals don't explode or vanish during backpropagation, allowing the model to learn relationships across long distances.

3. Python: Visualizing Phase Shift

trig_phase_shift.py
import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 4*np.pi, 200)

# Function and Derivative
y = np.sin(x)
dy = np.cos(x) # Derivative

print("Sine Value at 0:     ", np.sin(0))      # 0
print("Cosine Value at 0:   ", np.cos(0))      # 1 (Max slope of sin is at 0)

print("Sine Value at pi/2:  ", np.sin(np.pi/2)) # 1 (Peak)
print("Cosine Value at pi/2:", np.cos(np.pi/2)) # 0 (Slope at peak is 0)

# We can see that Cosine is just Sine shifted by 90 degrees (pi/2)
# cos(x) = sin(x + pi/2)
# This confirms the "slope" intuition:
# Where Sine is rising fastest (0), Cosine is Max (1).
# Where Sine is flat (pi/2), Cosine is Zero (0).

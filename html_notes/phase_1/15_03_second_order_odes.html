DiffEq 1.8 Momentum

Second-Order ODEs

Acceleration, Oscillations, and Heavy Balls.

The Spring-Mass System

A second-order linear ODE typically looks like: \[ ay'' + by' + cy = 0 \] This models a mass on a spring with damping. \(a\) is mass (inertia), \(b\) is friction (damping), and \(c\) is the spring constant.

It defines how systems oscillate and settle. The solution depends on the characteristic equation \(ar^2 + br + c = 0\).

2. AI/ML Connection: Momentum Optimization

The Heavy Ball Method

Standard Gradient Descent is a massless particle sliding down a hill (First Order). SGD with Momentum adds "Mass" to the particle using a Second Order ODE:

$$ m \frac{d^2\mathbf{w}}{dt^2} + \gamma \frac{d\mathbf{w}}{dt} = - \nabla L(\mathbf{w}) $$

The "inertia" helps the optimizer plow through small bumps (noise) and travel faster along flat directions (ravines), solving the "Zero Gradient" problem of saddle points.

3. Python: Simulating Damping

momentum_sim.py
import numpy as np
import matplotlib.pyplot as plt

# Simulate a ball in a harmonic well: L(x) = x^2
# Force = -Grad = -2x

def optimize_momentum(start_x, friction, lr, steps=50):
    x = start_x
    velocity = 0
    path = []
    
    for _ in range(steps):
        grad = 2 * x
        
        # Physics Update
        # velocity_{t+1} = friction * velocity_t - lr * grad
        velocity = friction * velocity - lr * grad
        
        # Position Update
        x = x + velocity
        path.append(x)
        
    return path

# High Friction (Standard GD behavior)
path_gd = optimize_momentum(10.0, friction=0.0, lr=0.1)

# Low Friction (Momentum - Oscillates!)
path_mom = optimize_momentum(10.0, friction=0.9, lr=0.1)

print(f"GD Final: {path_gd[-1]:.4f}")
print(f"Momentum Final: {path_mom[-1]:.4f}")
# Momentum reaches closer to 0 faster but might overshoot.

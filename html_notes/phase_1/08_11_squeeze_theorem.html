Calculus 1.3 Bounding

The Squeeze (Sandwich) Theorem

If you are stuck between a rock and a hard place, and both move to zero, you have no choice but to go to zero too.

Bounding the Unknown

Sometimes a function behaves wildly (e.g., oscillating infinitely fast). Calculating its limit directly is impossible. The Squeeze Theorem lets us ignore the complexity by trapping the function between two simple, predictable curves.

1. The Theorem

If \(g(x) \le f(x) \le h(x)\) for all \(x\) near \(a\) (essentially, \(f\) is sandwiched), and:

\[ \lim_{x \to a} g(x) = \lim_{x \to a} h(x) = L \]

Then:

\[ \lim_{x \to a} f(x) = L \]

f(x) has nowhere else to go.

2. The Classic: Dampened Oscillation

Evaluate \(\lim_{x \to 0} x^2 \sin(\frac{1}{x})\).

Direct sub gives \(0 \cdot \sin(\infty)\), which is undefined. The sine term oscillates crazily.

However:

  • \(-1 \le \sin(1/x) \le 1\)
  • Multiply by \(x^2\): \(-x^2 \le x^2 \sin(1/x) \le x^2\)

Now take limits of the outer guards:

  • Maximize: \(\lim_{x \to 0} x^2 = 0\)
  • Minimize: \(\lim_{x \to 0} -x^2 = 0\)

Therefore, the middle term must be 0.

3. AI/ML Connection: Proof of Convergence

Evidence Lower Bound (ELBO)

In Variational Autoencoders (VAEs) and Bayesian Inference, calculating the true probability \(P(X)\) (the evidence) is often intractable (computationally impossible).

Instead of calculating \(P(X)\) directly, we optimize a lower bound function called the ELBO.

\[ \mathcal{L}(\theta, \phi; x) \le \log P(x) \]

By pushing this lower bound UP as high as possible (squeezing it against the true value), we implicitly maximize the true likelihood. The Squeeze Theorem's logic—trapping a value to control it—is the heart of variational inference.

4. Python: Visualizing Constraint

squeeze_check.py
import numpy as np

def g(x): return -x**2 # Lower
def h(x): return x**2  # Upper
def f(x): return x**2 * np.sin(1/x) # Target

# Points getting closer to 0
x_vals = [0.1, 0.01, 0.001, 0.0001, 1e-10]

print(f"{'Input x':<15} | {'Lower g(x)':<15} | {'Target f(x)':<15} | {'Upper h(x)':<15}")
print("-" * 75)

for x in x_vals:
    low = g(x)
    high = h(x)
    val = f(x)
    
    # Check if squeezed
    is_squeezed = low <= val <= high
    mark = "✅" if is_squeezed else "❌"
    
    print(f"{x:<15} | {low:<15.8f} | {val:<15.8f} {mark}| {high:<15.8f}")
    
# Notice that as x -> 0, all three values become indistinguishable from 0.00000000

1. Definition

The Spectral Radius \( \rho(A) \) is the maximum absolute value of the eigenvalues of \( A \).

$$ \rho(A) = \max_i | \lambda_i | $$

Gelfand's Formula: \( \rho(A) = \lim_{k \to \infty} ||A^k||^{1/k} \). It dictates the long-term behavior of matrix powers.

2. RNN Stability

In Recurrent Neural Networks, gradients typically involve terms like \( W^T W^T \dots W^T \) (backprop through time).

If \( \rho(W) > 1 \), gradients grow exponentially (Exploding Gradients). If \( \rho(W) < 1 \), they shrink exponentially (Vanishing Gradients). "Echo State Networks" explicitly force \( \rho(W) < 1 \) to ensure memory stability.

3. Testing Stability

import numpy as np

# Unstable Matrix
A_unstable = np.array([
    [1.1, 0],
    [0, 0.9]
])
rho = np.max(np.abs(np.linalg.eigvals(A_unstable)))
print(f"Spectral Radius A: {rho}")

# Simulate
x = np.array([1.0, 1.0])
for i in range(20):
    x = A_unstable @ x
print(f"State after 20 steps (Unstable): {x.round(2)}")
# x[0] grows, x[1] shrinks

# Scaled Stable Matrix
A_stable = A_unstable / (rho + 0.1) # Force rho < 1
rho_stable = np.max(np.abs(np.linalg.eigvals(A_stable)))
print(f"\nScaled Spectral Radius: {rho_stable:.2f}")

x = np.array([1.0, 1.0])
for i in range(20):
    x = A_stable @ x
print(f"State after 20 steps (Stable): {x.round(2)}")

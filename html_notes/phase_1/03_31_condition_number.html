31. Condition Number (\( \kappa \))

The measure of numerical sensitivity.

1. Definition

The Condition Number of an invertible matrix \( \mathbf{A} \) measures how much the output \( \mathbf{x} \) changes for a small change in the input \( \mathbf{b} \) in the system \( \mathbf{Ax} = \mathbf{b} \).

$$ \kappa(\mathbf{A}) = ||\mathbf{A}|| \cdot ||\mathbf{A}^{-1}|| = \frac{\sigma_{max}}{\sigma_{min}} $$

A matrix with a small condition number (near 1) is Well-Conditioned. A matrix with a very large condition number is Ill-Conditioned.

2. Vanishing & Exploding Gradients

Stability in Transformation Chains

In Deep Neural Networks, the Jacobian of the whole chain is the product of individual layer Jacobians. If the condition numbers are high, small perturbations (rounding errors or noise) in early layers become massive errors in the final output.

  • Batch Normalization: Helps keep the condition number of the data matrix low, ensuring stable gradient flow.
  • Double Precision: When dealing with ill-conditioned robotics control systems, we often switch from 32-bit (float) to 64-bit (double) to survive the sensitivity.

3. Python: Computing Condition Number

import numpy as np

# A well-conditioned matrix
A_well = np.eye(3)

# An ill-conditioned matrix (almost singular)
A_ill = np.array([[1, 1], [1, 1.000000001]])

cond_well = np.linalg.cond(A_well)
cond_ill = np.linalg.cond(A_ill)

print(f"Well-conditioned Kappa: {cond_well}") # Output: 1.0
print(f"Ill-conditioned Kappa: {cond_ill:.2e}") # Output: e.g. 2e9

1. Definition

The Condition Number is the ratio of the maximum stretch to the minimum stretch (squash).

$$ \kappa(A) = ||A|| \cdot ||A^{-1}|| = \frac{\sigma_{\max}}{\sigma_{\min}} $$
  • \( \kappa = 1 \): Perfect (Orthogonal Matrix). Errors are preserved, not grown.
  • \( \kappa = \infty \): Singular Matrix. Inversion is impossible.
  • \( \kappa = 10^6 \): Dangerous. You lose 6 digits of precision.

2. Robustness

If a Neural Network (represented locally by its Jacobian matrix) has a high condition number, a tiny, undetectable perturbation to the input (adversarial noise) can result in a massive change in the output (wrong classification).

Training for robustness often involves minimizing the condition number of the weight matrices.

3. Seeing the Explosion

import numpy as np

# A Hilbert Matrix is notoriously ill-conditioned
from scipy.linalg import hilbert

n = 10
H = hilbert(n)
b = np.ones(n)

print(f"Condition Number: {np.linalg.cond(H):.2e}")
# Likely ~1e13. We are losing 13 digits of accuracy!

# Exact Solution
x_exact = np.linalg.solve(H, b)

# Add tiny noise to b (1e-10)
b_noisy = b.copy()
b_noisy[0] += 1e-10

x_noisy = np.linalg.solve(H, b_noisy)

# Calculating Relative Error
error = np.linalg.norm(x_noisy - x_exact) / np.linalg.norm(x_exact)
print(f"Input Perturbation: 1e-10")
print(f"Output Variation: {error:.4f}")
# Output varies by huge amount compared to input!

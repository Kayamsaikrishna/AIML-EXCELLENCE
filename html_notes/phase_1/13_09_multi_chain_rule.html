Calculus 1.6 Dependencies

Multivariable Chain Rule

Propagating signals through the web.

Multiplying Paths

If \( z \) depends on \( x \) and \( y \), and both depend on \( t \), how does \( z \) change with \( t \)? We must account for both paths of influence: \[ \frac{dz}{dt} = \frac{\partial z}{\partial x} \frac{dx}{dt} + \frac{\partial z}{\partial y} \frac{dy}{dt} \]

Rule of Thumb: Multiply along branches, Add separate branches together.

2. AI/ML Connection: The Backbone of Backprop

Computational Graphs

Deep Learning frameworks (PyTorch, TensorFlow) view models as **Directed Acyclic Graphs (DAGs)**. When we call `.backward()`, the engine automatically constructs the chain rule derivative.

If a layer's output splits into three different branches (e.g., in a ResNet block or Attention Head), the error gradients from all three branches flow back, get multiplied by their respective weigh changes, and then Sum Up at the junction. This summation is the literal implementation of the "Plus" in the Chain Rule formula above.

3. Python: Auto-Differentiation

chain_rule_jax.py
import jax.numpy as jnp
from jax import grad

# Define composite function z = f(g(t), h(t))
# x = sin(t), y = cos(t), z = x*y = sin(t)cos(t)

def f(t):
    x = jnp.sin(t)
    y = jnp.cos(t)
    z = x * y
    return z

# JAX computes chain rule automatically
dz_dt = grad(f)

t_val = 1.0
print(f"Gradient at t=1.0: {dz_dt(t_val)}")

# Manual verification:
# z = 0.5 * sin(2t) -> z' = cos(2t)
print(f"Manual check:      {jnp.cos(2 * t_val)}")

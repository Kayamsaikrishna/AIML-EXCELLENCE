17. Influence, Leverage & Cook's Distance

Identifying the "Power Players" in your dataset.

1. Not all points are equal

Some data points significantly change the "Shape" of the model, while others have no effect. We measure this using three metrics:

  • Leverage ($h_i$): Measures how far an observation's $X$-value is from other $X$-values. A high-leverage point is an "Outlier in X".
  • Influence: A point is influential if removing it substantially changes the coefficients ($\beta$).
  • Cook's Distance ($D_i$): Combines Leverage and Residual. It measures the overall shift in the model's predictions when point $i$ is removed.

2. The Threshold

Typically, if $D_i > 1$ or $D_i > 4/n$, the point is considered an "Outlier with high influence" that you should investigate.

3. AI/ML Connection: Dataset Cleaning and Anomaly Detection

The Math of Dataset Integrity

In AI, Influence metrics are the Dataset Sanitization Engine**.

When training a **Large Scale AI**, one mistyped decimal place in the training set can ruin the model (the "Garbage In, Garbage Out" rule). By calculating **Cook's Distance**, the AI performs Automated Data Cleaning**: it identifies points that are "Yanking" the model in the wrong direction. This is the foundation of **Data-Centric AI**. It is also used in Adversarial AI Defense**: hackers try to "Poison" the training data with high-influence malicious points. Influence analysis detects these "Trojan Horse" points and prunes them before they can compromise the system's security. It is the mathematical shield of modern machine learning.

4. Python: Calculating Cook's Distance

import statsmodels.api as sm

# Fit an OLS model
model = sm.OLS(y, X).fit()

# Get influence results
influence = model.get_influence()
(cooks, pvals) = influence.cooks_distance

# Find the 'troublemakers'
high_dist = np.where(cooks > 1)[0]
print(f"Indices of highly influential points: {high_dist}")

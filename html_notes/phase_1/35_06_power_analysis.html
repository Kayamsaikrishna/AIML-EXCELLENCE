06. Power Analysis & Sample Size

Knowing how much data is "Enough".

1. The Four Pillars

Power Analysis connects four statistical concepts. If you know three, you can calculate the fourth:

  • Significance ($\alpha$): Probability of a false alarm (usually 0.05).
  • Power ($1-\beta$): Probability of correctly finding an effect (usually 0.80).
  • Effect Size: How much of a change we are looking for (e.g., 5% lift).
  • Sample Size ($n$): How many people we need to test.

2. The "Peeking" Problem

Without a pre-calculated sample size, researchers often "Peak" at the data and stop when the p-value looks good. This is **p-hacking** and leads to fake results. Power analysis locks in the sample size *before* the test starts, ensuring scientific integrity.

3. AI/ML Connection: Resource Optimization and Budgeting

Saving Money and Time

In AI, Power Analysis is the **Budget Planner**.

When training an AI model on a **Pay-per-token API (like GPT-4)** or using expensive **GPU clusters**, we use power analysis to decide the minimum amount of data we need to prove the model is better than the baseline. In Clinical AI**, where collecting a single data point might cost $1,000, power analysis is the difference between a successful project and a bankrupt one. It is also used in Dataset Curation**: if adding 1 million more rows only increases power by 0.001%, we stop collecting. It ensures that the AI team is working on the most "Signal-rich" tasks rather than wasting resources on marginal gains.

4. Python: Calculating Required N

from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()
# How many users to detect a medium effect (0.5) 
# with 80% power and 5% alpha?
result = analysis.solve_power(effect_size=0.5, power=0.8, 
                             alpha=0.05, ratio=1.0)

print(f"Required Sample Size: {result:.1f}")

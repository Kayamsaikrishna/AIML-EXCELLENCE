Arithmetic & Algebra

The structural rules of mathematics. From basic order of operations to the polynomial landscapes of high-dimensional optimization.

1. OPERATIONS & BASICS

1. Foundations of Operations

Before optimizing neural networks, we must master the rules that govern how numbers interact. These properties—Associativity, Commutativity, and Distributivity—are the reasons why matrix multiplication behaves the way it does.

Core Properties

  • Associative: \( (a+b)+c = a+(b+c) \)
    Crucial for parallel computing (MapReduce).
  • Commutative: \( a+b = b+a \)
    Matrix Multiplication is NOT commutative (\(AB \neq BA\)), a vital distinction in Deep Learning.
  • Distributive: \( a(b+c) = ab + ac \)
    The basis for tensor factorization.
PEMDAS & Computational Graphs

Order of Operations (PEMDAS/BODMAS) isn't just for school. It defines the Computational Graph in frameworks like PyTorch.

When you write `loss = (y_pred - y) ** 2`, PyTorch builds a Directed Acyclic Graph (DAG) respecting these priorities to perform backpropagation. Misunderstanding precedence leads to silent bugs in loss functions.

2. EQUATIONS & INEQUALITIES

2. Equations & Inequalities

Solving for \(x\) is the "Hello World" of AI. Training a model is literally solving a massive system of equations to find the optimal weights.

Linear Equations

Form: \( ax + b = 0 \). In AI, this scales to \( \mathbf{W}x + \mathbf{b} = \mathbf{y} \), the foundation of the Perceptron.

Absolute Value (\( |x| \))

Measures "magnitude" or distance from zero. \( |x| \geq 0 \).

L1 Regularization (Lasso)

We add \( \lambda \sum |w| \) to our loss function to force weights to zero. This creates Sparse Models (Feature Selection), because the gradient of \(|x|\) is constant (unlike \(x^2\)), pushing small values all the way to 0.

3. POLYNOMIALS

3. Polynomials & Quadratics

Functions of the form \( f(x) = a_n x^n + ... + a_1 x + a_0 \).

Quadratic Equations (\(ax^2 + bx + c = 0\))

Parabolas are everywhere. The most common Loss Function, Mean Squared Error (MSE), is a parabola in high dimensions.

$$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$

Why do we love Quadratics? (Convexity)

A specific type of polynomial—the Quadratic—has a magical property: Convexity.

If a function is convex (bowl-shaped), Gradient Descent is guaranteed to find the global minimum. This is why Least Squares Regression always works perfectly. Deep Neural Networks, however, are non-convex (wavy landscapes), making optimization much harder.

4. EXPONENTIALS & LOGS

4. Exponentials & Logarithms

The language of growth, decay, and information.

Exponentials (\(e^x\))

Used in Softmax to convert logits into probabilities. \(e^x\) ensures all outputs are positive and amplifies differences between large values.

Logarithms (\(\ln x\))

The undo button for exponentials. Used in Cross-Entropy Loss (`-sum(y * log(p))`). Logarithms turn multiplication into addition (\(\log(ab) = \log a + \log b\)), which prevents numerical underflow when multiplying many small probabilities.

5. FUNCTIONS & GRAPHS

5. Functions: Domain, Range, & Graphs

A function maps an input \(x\) (Domain) to an output \(y\) (Range). In AI, we approximate a function \( f(x) \) maps input data to labels.

Composition of Functions

\( (f \circ g)(x) = f(g(x)) \).

Deep Learning is simply function composition repeated many times: \[ y = f_3(f_2(f_1(x))) \] where each \(f\) is a layer. The Chain Rule allows us to differentiate through this nested structure.

Inverse Functions

Functions that "undo" each other. \( f^{-1}(f(x)) = x \). Generative Flows (Normalizing Flows) rely on invertible neural networks to map complex data distributions back to a simple Gaussian.

6. SEQUENCES & SERIES

6. Sequences & Series

Ordered lists of numbers and their sums. Vital for Recurrent Neural Networks (RNNs) and Time Series analysis.

Vanishing Gradients & Geometric Series

When training RNNs, gradients are multiplied repeatedly (a Geometric Sequence with ratio \(r < 1\)).

If the sequence converges to 0, the model stops learning early layers. This is the Vanishing Gradient Problem. LSTMs were invented specifically to break this geometric decay.

7. Applications in AI/ML Systems

Linear Algebra in Neural Networks

Neural network operations are fundamentally matrix and vector operations.

$$ \mathbf{y} = \sigma(\mathbf{Wx} + \mathbf{b}) $$

Where \(\mathbf{W}\) is the weight matrix, \(\mathbf{x}\) is the input vector, \(\mathbf{b}\) is the bias vector, and \(\sigma\) is the activation function.

Optimization in Loss Functions

Training neural networks involves solving optimization problems using algebraic techniques.

$$ \min_\theta \frac{1}{n} \sum_{i=1}^n L(f_\theta(x_i), y_i) $$

Regularization Techniques

Algebraic methods to prevent overfitting by adding penalty terms to loss functions.

$$ L_{reg} = L_{original} + \lambda \sum_{i} |w_i| \text{ (L1 regularization)}$$ $$ L_{reg} = L_{original} + \lambda \sum_{i} w_i^2 \text{ (L2 regularization)}$$

8. Problem-Solving Methodologies

Symbolic Computation

Using algebraic manipulation to derive closed-form solutions when possible.


from sympy import symbols, solve, expand, factor

# Define symbolic variables
x, y = symbols('x y')

# Solve equations
expr = x**2 - 5*x + 6
equation_solution = solve(expr, x)
print(f'Solutions to x^2 - 5x + 6 = 0: {equation_solution}')

# Expand expressions
expanded_expr = expand((x + 2)*(x - 3))
print(f'Expanded form: {expanded_expr}')

Numerical Methods

When symbolic solutions are intractable, numerical methods provide approximations.

\text{Newton's Method: } x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}

Algorithmic Approaches

Systematic procedures for solving classes of algebraic problems.

  • Gaussian elimination for linear systems
  • Polynomial factoring algorithms
  • Root finding methods

9. Industry Use Cases

Computer Vision

Image processing and feature extraction using algebraic operations.

  • Convolution as matrix operations
  • Principal Component Analysis (PCA) for dimensionality reduction
  • Image filtering using kernel operations

Natural Language Processing

Transforming text into algebraic representations for processing.

  • Word embeddings as high-dimensional vectors
  • Attention mechanisms using dot products
  • Transformer architectures based on linear algebra

Recommendation Systems

Matrix factorization techniques for collaborative filtering.

  • Singular Value Decomposition (SVD)
  • Alternating Least Squares (ALS)
  • Matrix completion algorithms

10. Step-by-Step Problem Solving

Step 1: Identify the Problem Type

Classify the algebraic problem to select appropriate solution strategies:

  • Linear vs. nonlinear equations
  • Single vs. systems of equations
  • Exact vs. approximate solutions needed

Step 2: Simplify the Expression

Apply algebraic rules to make the problem more manageable:

  • Combine like terms
  • Factor polynomials
  • Rationalize denominators

Step 3: Apply Solution Technique

Choose and implement the most suitable method:

  • Quadratic formula for quadratic equations
  • Substitution for systems of equations
  • Factoring for polynomial equations

Step 4: Verify the Solution

Confirm the solution satisfies the original equation:

  • Substitute back into original equation
  • Check domain restrictions
  • Validate against problem constraints

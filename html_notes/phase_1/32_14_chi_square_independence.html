14. Chi-Square Test for Independence

Finding hidden strings between categorical labels.

1. The Categorical Challenge

How do you test if two categories are related? For example, is "Search Engine Brand" independent of "User Age Group"? You can't use a t-test because there are no averages. You must use the Chi-Square ($\chi^2$) Test.

2. Observed vs. Expected

We create a **Contingency Table** of frequencies. The test asks: "If these two categories were truly independent, what frequencies should we see? And how far away are our REAL observations from those theoretical numbers?".

$$ \chi^2 = \sum \frac{(O_i - E_i)^2}{E_i} $$

If the $\chi^2$ value is large, the "Observed" and "Expected" are polar opposites—meaning the variables are **Dependent**.

3. AI/ML Connection: Feature Selection and Collinearity

The Pruning Tool

In AI, the Chi-Square test is the primary tool for Feature Selection in Tabular Models.

If you are building a **Churn Prediction AI** for a telecom company, you have 50 categorical features (State, Plan Type, Device Type, etc.). You don't want to use all of them—that leads to overfitting. You run a **Chi-Square test** between every feature and the "Churn (Yes/No)" label. If a feature has a high p-value (meaning it's independent of Churn), you drop it. Furthermore, it helps find **Redundant Features**. If "Zip Code" and "Neighborhood" are 100% dependent according to Chi-Square, you only need one of them for your model. This ensures a "Lean" AI that trains faster and generalizes better to new markets.

4. Python: scipy.stats.chi2_contingency

# Rows: Age Group (Young, Old)
# Columns: Model Choice (A, B)
table = [[10, 20], [30, 15]]

stat, p, dof, expected = stats.chi2_contingency(table)

print(f"Chi-Square Stat: {stat:.2f}, p-value: {p:.4f}")
# If p < 0.05, Age Group and Model Choice are DEPENDENT. 
# Meaning the model needs to account for age to be accurate.

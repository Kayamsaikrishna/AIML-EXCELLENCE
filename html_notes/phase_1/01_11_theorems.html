1. The Fundamental Theorem of Algebra (FTA)

Statement: Every non-zero, single-variable, degree \(n\) polynomial with complex coefficients has at least one complex root.

Corollary: It has exactly \(n\) roots (counting multiplicity).

$$ P(z) = a_n(z-r_1)(z-r_2)\dots(z-r_n) $$

Why this matters for AI

The "Characteristic Equation" of a matrix is a polynomial: \( \det(A - \lambda I) = 0 \).

Because of FTA, we know that an \( n \times n \) matrix is guaranteed to have \( n \) Eigenvalues (possibly complex). If FTA weren't true, Spectral Theory (and thus PCA, Google PageRank) would fall apart.

2. Factor & Remainder Theorems

  • Remainder Theorem: \( P(a) \) is the remainder when dividing by \( (x-a) \).
  • Factor Theorem: \( (x-a) \) is a factor if and only if \( P(a) = 0 \).

3. Numerical Root Finding

Computers solve \( P(x)=0 \) by turning it into an Eigenvalue problem (Companion Matrix algorithm). 

import numpy as np

# P(x) = x^2 + 1
# Roots should be +i and -i (No real roots)
coeffs = [1, 0, 1]

roots = np.roots(coeffs)
print(f"Roots: {roots}")
# Output: [0.+1.j, 0.-1.j] -> Correct!

# P(x) = x^5 - 32
# Should have 5 roots (1 Real, 4 Complex)
roots_5 = np.roots([1, 0, 0, 0, 0, -32])
print(f"5th Roots of 32:\n{roots_5}")

11. Remainder & Factor Theorems

If \( P(c) = 0 \), then \( c \) is a factor. This simple rule powers Recommender Systems.

1. The Two Pillars

Remainder Theorem

If you divide a polynomial \( P(x) \) by \( (x - c) \), the remainder is simply \( P(c) \).

Interpretation: The "Value" of a function at a point is equivalent to the "Leftover" after division.

Factor Theorem

If \( P(c) = 0 \), then \( (x - c) \) is a factor of \( P(x) \).

Interpretation: Roots are Factors. If we find where the system is zero (stable), we have found a fundamental component of the system.

2. Latent Factors (Matrix Factorization)

In AI, we generalize the Factor Theorem to Matrices. A massive logical system (User-Movie Rating Matrix) can be broken down into simpler "Factors".

$$ Rating \approx UserFactor \cdot MovieFactor $$

AI: Recommender Systems

Netflix doesn't store a rating for every movie. It stores:

  • User Factors: [Likes Action, Hates Romance, Likes 90s]
  • Movie Factors: [Is Action, Is Romance, Is 90s]

The prediction is the dot product (multiplication) of these factors. We discovered these factors by "solving used roots" (SVD/NMF) of the data matrix.

3. Coding Matrix Factorization

Let's use NMF (Non-negative Matrix Factorization) to extract latent topics.

// Sklearn: Finding Latent Factors
from sklearn.decomposition import NMF
import numpy as np

# Data: 3 Users, 4 Movies (0 to 5 Star Ratings)
X = np.array([
    [5, 4, 1, 1],
    [1, 1, 5, 4],
    [5, 5, 1, 1] 
])

# Factorize into 2 Components (Action vs Romance)
model = NMF(n_components=2, init='random', random_state=0)

W = model.fit_transform(X) # User Factors
H = model.components_      # Movie Factors

print("User Factors (Taste Profile):")
print(W.round(2))

print("\nMovie Factors (Genre Profile):")
print(H.round(2))

# Reconstruct Original Matrix
approx = np.dot(W, H)
print("\nReconstructed (Predicted Ratings):")
print(approx.round(2))

03. Mutual Information (MI)

The measure of non-linear dependency.

1. Beyond Correlation

Standard Correlation only measures *Linear* relationships. If $Y = X^2$, correlation might be zero. Mutual Information $I(X; Y)$ measures how much information $X$ tells you about $Y$ (and vice versa) regardless of the shape of the relationship.

$$ I(X; Y) = H(X) - H(X|Y) $$

If $X$ and $Y$ are independent, $I(X; Y) = 0$.

2. The Information Bottleneck

MI is a measure of the "Communication Channel" between two variables. If a feature has zero mutual information with the target, it is literally useless—it carries no signal, only noise.

3. AI/ML Connection: Feature Selection and Disentanglement

The Signal Detector

In AI, MI is the gold standard for Feature Selection Methods (mRMR)**.

Instead of testing every feature with a model, we calculate their **Mutual Information with the Target**. This is extremely powerful for Genomic AI** or **Financial High-frequency data** where we have 10,000+ features but only 10 are useful. Furthermore, InfoGANs (Generative Adversarial Networks)** use MI to learn **Disentangled Representations**: by maximizing the mutual information between a latent code and the generated image, the AI learns specific "Levers" (e.g., one lever changes the rotation of a face, another changes the lighting). It is the math of "Meaningful representation."

4. Python: MI Score

from sklearn.feature_selection import mutual_info_regression

# Calculate MI between all features in X and target y
mi_scores = mutual_info_regression(X, y)

# Higher score = more 'information' provided by the feature
for name, score in zip(feature_names, mi_scores):
    print(f"Feature '{name}' MI: {score:.4f}")

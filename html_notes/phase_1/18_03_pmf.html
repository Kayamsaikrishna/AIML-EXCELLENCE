Prob 1.4 Mass

Probability Mass Function (PMF)

Assigning probability chunks.

Definition

For a discrete random variable \(X\), the PMF gives the probability that \(X\) is exactly equal to some value \(x\). \[ p_X(x) = P(X=x) \] Properties:

  1. \(0 \le p_X(x) \le 1\)
  2. \(\sum_x p_X(x) = 1\)

2. ML Connection: Class Probabilities

Categorical Output

A Softmax output layer produces a PMF over the \(K\) classes. If softmax outputs `[0.1, 0.7, 0.2]`, this says: \(P(Y=0)=0.1\), \(P(Y=1)=0.7\), \(P(Y=2)=0.2\). The Cross-Entropy Loss essentially tries to make this predicted PMF match the true PMF (One-hot vector).

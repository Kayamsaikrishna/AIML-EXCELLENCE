Calculus 1.3 Composition

The Chain Rule

If A drives B, and B drives C, how does A drive C? The single most important rule in Artificial Intelligence.

The Backbone of Backprop

"Backpropagation" is just a fancy name for the recursive application of the Chain Rule. It allows us to calculate how much a single pixel in an input image contributed to an error in the final classification.

1. The Formula

For a composite function \(y = f(g(x))\), let \(u = g(x)\). Then:

\[ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx} \]

In Lagrange notation: \( [f(g(x))]' = f'(g(x)) \cdot g'(x) \).

2. AI/ML Connection: The Computation Graph

Node-by-Node Differentiation

In libraries like TensorFlow or PyTorch, we view a function as a graph. Consider \(L(w) = \text{ReLU}(w \cdot x + b)\).

  1. Forward Pass: Compute \(z = wx+b\), then \(a = \text{ReLU}(z)\).
  2. Backward Pass: We want \(\frac{\partial L}{\partial w}\).
\[ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial a} \cdot \frac{\partial a}{\partial z} \cdot \frac{\partial z}{\partial w} \]

This "upstream gradient times local gradient" pattern is how we train networks with 100+ layers without losing our minds.

3. Python: Deep Composition

chain_rule_deep.py
import sympy as sp

x = sp.Symbol('x')

# A Deep Neural Network style function (3 layers)
# Loss = log( sin( x^2 ) )
# Inner most (Layer 1): u = x^2
# Middle (Layer 2):     v = sin(u)
# Outer (Loss):         L = log(v)

f = sp.log(sp.sin(x**2))

# 1. Manual Chain Rule
# dL/dv * dv/du * du/dx
# L = log(v) -> dL/dv = 1/v = 1/sin(x^2)
# v = sin(u) -> dv/du = cos(u) = cos(x^2)
# u = x^2    -> du/dx = 2x

manual_deriv = (1/sp.sin(x**2)) * sp.cos(x**2) * (2*x)

# 2. Automated Chain Rule
auto_deriv = sp.diff(f, x)

print(f"Function: {f}")
print(f"Manual Chain Rule: {manual_deriv}")
print(f"Auto Derivative:   {auto_deriv}")

# Verify they are identical
if sp.simplify(manual_deriv - auto_deriv) == 0:
    print("\n✅ Chain Rule Verified. Complexity collapse successful.")

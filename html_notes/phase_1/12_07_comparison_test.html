Calculus 1.5 Tests

Direct Comparison Test

Using a known truth to prove an unknown.

The "Sandwich" Logic

If we have a messy series \(\sum a_n\) and we want to know if it sum up to a finite number, we can compare it to a simpler series \(\sum b_n\) that we already know.

  • Convergence: If \(0 \leq a_n \leq b_n\) and \(\sum b_n\) converges (is finite), then \(\sum a_n\) is "trapped" below it and must also converge.
  • Divergence: If \(a_n \geq b_n \geq 0\) and \(\sum b_n\) diverges (is infinite), then \(\sum a_n\) is "pushed up" and must also diverge.

2. AI/ML Connection: Bounding Errors

Generalization Bounds

In Computational Learning Theory, we often cannot calculate the exact "True Error" of a complex neural network on unseen data. Instead, we find an Upper Bound (a simpler formula) for the error.

\[ \text{True Error} \leq \text{Training Error} + \text{Complexity Penalty} \]

If we can prove that the "Upper Bound" decreases (converges) as we add more data, then by the Comparison Test, the "True Error" must also decrease. This logic is fundamental to PAC Learning (Probably Approximately Correct), assuring us that models become safer with more data.

3. Python: Visualizing the Bound

comparison_visual.py
import numpy as np

# Series A: 1 / (n^2 + 10)  (Hard to sum directly)
# Series B: 1 / n^2         (Known convergent p-series)

def series_a(n): return 1 / (n**2 + 10)
def series_b(n): return 1 / (n**2)

print(f"{'n':<5} | {'A_n':<10} | {'B_n':<10} | {'A < B?'}")
print("-" * 40)

for n in [1, 2, 3, 10, 100]:
    val_a = series_a(n)
    val_b = series_b(n)
    print(f"{n:<5} | {val_a:<10.6f} | {val_b:<10.6f} | {val_a < val_b}")

# Since A is always smaller than B, and Sum(B) is finite, Sum(A) is finite.

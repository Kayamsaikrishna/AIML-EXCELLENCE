07. Intermediate Value Theorem (IVT)

The "no skipping" guarantee.

1. The Theorem

If \(f(x)\) is continuous on a closed interval \([a, b]\), and \(K\) is any number between \(f(a)\) and \(f(b)\), then there exists at least one number \(c\) in \((a, b)\) such that:

$$ f(c) = K $$

Key Insight: **Continuous functions can't "jump" over values.**

2. Finding Roots (Application)

If \(f(a)\) is negative and \(f(b)\) is positive, and \(f\) is continuous, then IVT guarantees there is at least one Root (where \(f(c)=0\)) between them. This is the mathematical basis for the Bisection Method.

3. AI Analogy: Data Manifolds

In GANs (Generative Adversarial Networks), we assume that the mapping from latent noise to images is a continuous function. IVT implies that between any two generated images (e.g., a cat and a dog), there must exist an image that is an "intermediate" interpolation of the two. This is what makes **Latent Space Interpolation** possible.

4. Python: Bisection Root Finding

def f(x): return x**3 - x - 2 # Roots between 1 and 2

def bisection(a, b, iter=20):
    if f(a) * f(b) > 0: return "IVT doesn't guarantee root"
    
    for _ in range(iter):
        mid = (a + b) / 2
        if f(mid) == 0: return mid
        if f(a) * f(mid) < 0: b = mid
        else: a = mid
    return (a + b) / 2

root = bisection(1, 2)
print(f"Approximate root: {root:.6f}")
print(f"Verification f(root): {f(root):.6f}")

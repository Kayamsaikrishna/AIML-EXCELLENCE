01. Planes and surfaces in 3D

Moving beyond the flat line.

1. Entering the Third Dimension

Single-variable calculus lives on the 2D plane (\(x, y\)). Multivariable calculus lives in 3D space (\(x, y, z\)). Instead of lines, we now deal with Surfaces.

  • Plane: The 3D version of a line (\(ax + by + cz = d\)).
  • Quadric Surfaces: Paradoxical names like Paraboloids, Ellipsoids, and Hyperboloids.

2. The Coordinate System

We use the Right-Hand Rule to define the orientation of axes. In AI, these axes often represent independent features (e.g., \(x\) = square footage, \(y\) = number of bedrooms, \(z\) = price).

3. AI/ML Connection: The Feature Space

High-Dimensional Topology

AI models rarely deal with just one input. Even a simple image recognition model deals with thousands of dimensions (one for each pixel). The Loss Landscape of a Neural Network is a "Surface" in a multi-thousand-dimensional space.

Understanding 3D surfaces is the fundamental building block for understanding how AI "navigates" through complex data structures. When we talk about "Linear Separability" in Support Vector Machines (SVM), we are talking about finding a Hyper-plane in feature space that separates different categories of data.

4. Python: Visualizing a 3D Surface

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(-5, 5, 100)
y = np.linspace(-5, 5, 100)
X, Y = np.meshgrid(x, y)
Z = X**2 + Y**2 # A Paraboloid (Shape of many loss functions)

fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')
ax.plot_surface(X, Y, Z, cmap='viridis')
plt.show()

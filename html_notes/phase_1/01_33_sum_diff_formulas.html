1. Mixing Angles

We cannot just say \( \sin(A+B) = \sin(A)+\sin(B) \). That is linear thinking, but waves are non-linear.

$$ \sin(A+B) = \sin(A)\cos(B) + \cos(A)\sin(B) $$

This formula tells us how to compute the state of a wave at a new position \( A+B \) using only information from \( A \) and \( B \).

2. Relative Positional Encoding

In LLaMA's RoPE, we want the attention score between token \( m \) and token \( n \) to depend only on their relative distance \( m-n \).

The Sum/Diff formulas allow us to define a rotation matrix \( R_{n} \) such that \( R_m^T R_n = R_{m-n} \).

This is the magic sauce that lets LLMs handle long contexts. The math proves that absolute position doesn't matter, only the relative gap.

3. Destructive Interference

Canceling out a signal (Noise Cancellation Logic).

import numpy as np

# Original Angle A
A = np.pi / 4 # 45 degrees

# Shift B (Out of Phase by 180 degrees / Pi radians)
B = np.pi 

# Formula: sin(A+B)
# Should be sin(A + Pi) = -sin(A) [Total Inversion]
val_formula = np.sin(A)*np.cos(B) + np.cos(A)*np.sin(B)
val_direct = np.sin(A + B)

print(f"Original sin(A): {np.sin(A):.4f}") # 0.7071
print(f"Shifted sin(A+B): {val_direct:.4f}") # -0.7071
print(f"Calculated:       {val_formula:.4f}")

# Adding them creates silence: 0.707 - 0.707 = 0

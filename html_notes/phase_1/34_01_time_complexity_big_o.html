Time Complexity & Big O Notation

Measuring Efficiency. Defining the mathematical bounds on how an algorithm's runtime scales as input size approaches infinity.

The Scalability Wall

An algorithm that works on 100 images might fail on 100 billion. Complexity Theory provides the tools to predict this failure before it happens. It focuses on the *rate of growth* rather than the exact number of seconds.

1. Formal Definition of Big O

We say \(f(n) = O(g(n))\) if there exist constants \(c > 0\) and \(n_0 \geq 0\) such that:

$$ |f(n)| \leq c \cdot |g(n)| \quad \text{for all } n \geq n_0 $$

In simple terms, Big O provides an upper bound on the worst-case growth. For AI, this defines the maximum "compute budget" needed for a model.

2. Common Time Complexities

Constant: \(O(1)\)

Time does not change with input size. Example: Accessing an element in a Hash Map or checking a boolean flag.

Logarithmic: \(O(\log n)\)

Time grows very slowly. Example: Binary search in a sorted array or traversing a balanced Decision Tree.

Linear: \(O(n)\)

Time scales 1:1 with input. Example: A single pass through a dataset to calculate mean or variance.

Quadratic: \(O(n^2)\)

Time scales with the square of input. Example: Nested loops used in simple matrix multiplication or basic Self-Attention (without optimizations).

Deep Learning Ops

The Complexity of AI

  • Transformer Self-Attention: Standard Attention has a complexity of **\(O(L^2 \cdot d)\)** where \(L\) is the sequence length. This quadratic scaling is why LLMs have "context window" limits.
  • Layer Weights: Calculating a single forward pass in a Fully Connected layer with \(N\) inputs and \(M\) outputs is \(O(N \cdot M)\).
  • K-Nearest Neighbors (KNN): A naive search for the nearest neighbor in a dataset of size \(N\) is \(O(N \cdot D)\). This is why "Approximate Nearest Neighbor" (ANN) algorithms are used for large vector databases.
  • Viterbi Decoding: For an HMM with \(S\) states and sequence length \(T\), the complexity is \(O(S^2 \cdot T)\).

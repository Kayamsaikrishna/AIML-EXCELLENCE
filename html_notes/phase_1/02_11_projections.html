1. Projections onto Spaces

Previously we projected vectors onto vectors. Now we project vectors onto Planes or Hyperplanes (Subspaces).

If \( \mathbf{A} \) contains the basis vectors of the subspace, the projection matrix \( P \) is:

$$ P = A(A^T A)^{-1}A^T $$

Applying \( P \) to any vector \( \mathbf{b} \) snaps it onto the closest point in the subspace.

2. Linear Regression

If we want to solve \( A\mathbf{x} = \mathbf{b} \) but \( \mathbf{b} \) is not in the column space of \( A \) (no solution), we settle for the "closest" solution.

We project \( \mathbf{b} \) onto the column space to get \( \mathbf{p} \), then solve \( A\hat{x} = \mathbf{p} \). This minimizes the squared error \( ||\mathbf{b} - \mathbf{p}||^2 \).

3. Calculating the Hat Matrix

Implementing the projection from scratch.

import numpy as np

# A Subspace defined by 2 basis vectors (Plane in 3D)
A = np.array([
    [1, 0],
    [0, 1],
    [0, 0]
]) # The XY plane

# A point NOT on the plane (z=5)
b = np.array([2, 3, 5])

# Calculate Projection Matrix P = A(A^T A)^-1 A^T
At = A.T
AtA = np.dot(At, A)
AtA_inv = np.linalg.inv(AtA)
P = np.dot(A, np.dot(AtA_inv, At))

print("Projection Matrix P:")
print(P)
# Should be Identity for x,y and 0 for z

# Project b
p = np.dot(P, b)

print(f"\nOriginal: {b}")
print(f"Projected: {p}") 
# Should be [2, 3, 0] (Dropped the z component)

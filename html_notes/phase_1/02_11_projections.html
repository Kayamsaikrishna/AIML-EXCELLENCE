11. Vector Projections & Components

Finding shadows in high dimensions.

1. Scalar and Vector Projection

Projection is the act of mapping a vector \(\mathbf{v}\) onto a line defined by another vector \(\mathbf{u}\).

$$ \text{Scalar Projection (comp}_u v) = \frac{\mathbf{v} \cdot \mathbf{u}}{\|\mathbf{u}\|} $$ $$ \text{Vector Projection (proj}_u v) = \left( \frac{\mathbf{v} \cdot \mathbf{u}}{\|\mathbf{u}\|^2} \right) \mathbf{u} $$

2. Dimensionality Reduction (PCA)

Compressing Data

In Principal Component Analysis (PCA), we project high-dimensional data points onto a lower-dimensional subspace. The goal is to choose the vector \(\mathbf{u}\) that preserves the most variance.

  • Shadows of Data: PCA is essentially finding the "best" shadows of our data to store it compactly.
  • Linear Regression: Fitting a line involves projecting the target vector \(y\) onto the column space of the feature matrix \(X\).

3. Python: Implementing Projections

import numpy as np

def project(v, u):
    # (v dot u) / (u dot u) * u
    return (np.dot(v, u) / np.dot(u, u)) * u

v = np.array([3, 4])
u = np.array([1, 0]) # Projection onto x-axis

p = project(v, u)
print(f"Projection: {p}") # Output: [3, 0]

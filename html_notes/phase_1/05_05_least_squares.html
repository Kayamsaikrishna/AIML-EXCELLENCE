Least Squares

When \( Ax = b \) fails, solve \( A^T A \hat{x} = A^T b \).

1. The Derivation

If \( b \) is not in the column space of \( A \), we cannot solve \( Ax=b \). Instead, we minimize the error \( ||Ax - b||^2 \).

Calculus (or Geometry) tells us the error vector must be orthogonal to the columns of \( A \):

$$ A^T (b - A\hat{x}) = 0 \implies A^T A \hat{x} = A^T b $$

This "Normal Equation" is always solvable.

2. Linear Regression

Linear Regression is exactly Least Squares.

  • \( A \): Design matrix (rows are data points, cols are features).
  • \( \hat{x} \): The learned weights/parameters.
  • \( b \): The target labels.

While we use Gradient Descent for large nets, the closed-form Normal Equation is optimal for small linear problems.

3. Solving Overdetermined Systems

import numpy as np
import matplotlib.pyplot as plt

# Data points roughly on y = 2x
x_data = np.array([1, 2, 3, 4])
y_data = np.array([2.1, 3.9, 6.2, 8.1])

# Form Matrix A (n x 1)
A = x_data.reshape(-1, 1)
# Typically we add a bias column of 1s, but keeping it simple

# Normal Equation: (A.T A) x = A.T y
lhs = A.T @ A
rhs = A.T @ y_data
slope = np.linalg.solve(lhs, rhs)

print(f"Estimated Slope: {slope[0]:.4f}")

# Verify with numpy.linalg.lstsq
slope_np, res, rank, s = np.linalg.lstsq(A, y_data, rcond=None)
print(f"NumPy lstsq Slope: {slope_np[0]:.4f}")

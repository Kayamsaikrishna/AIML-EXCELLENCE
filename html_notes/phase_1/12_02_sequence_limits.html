Calculus 1.5 Limits

Sequence Limits

Rules for finding the destination.

Algebra of Limits

Just like functions, sequence limits follow standard algebraic rules. If \(\lim a_n = A\) and \(\lim b_n = B\):

  • Sum: \(\lim (a_n + b_n) = A + B\)
  • Product: \(\lim (a_n \cdot b_n) = A \cdot B\)
  • Quotient: \(\lim (a_n / b_n) = A / B\) (if \(B \neq 0\))

1. L'Hôpital's Rule for Sequences

To find \(\lim_{n \to \infty} f(n)\), we can define a continuous function \(f(x)\) such that \(f(n) = a_n\). If \(\lim_{x \to \infty} f(x) = L\), then \(\lim_{n \to \infty} a_n = L\).

This allows us to use L'Hôpital's Rule on sequences by treating \(n\) as a continuous variable \(x\).

2. AI/ML Connection: Patience & Early Stopping

The "Patience" Parameter

In Model Training, we monitor the Validation Loss sequence \(L_1, L_2, L_3 \dots\). We want the limit to be minimum. However, in practice, the loss fluctuates (it's noisy).

We define a Convergence Criterion (like \(\epsilon\) in real analysis). If the loss does not improve by at least \(\epsilon\) for \(P\) steps (Patience), we say the sequence has "Converged" (or stalled) and we stop training. This prevents overfitting and saves compute.

3. Python: Implementing Early Stopping

early_stopping.py
# Simulating a noisy loss sequence
loss_sequence = [5.0, 4.5, 4.1, 4.0, 3.95, 3.94, 3.96, 3.95, 3.95]

best_loss = float('inf')
patience = 2
counter = 0
min_delta = 0.05

for epoch, loss in enumerate(loss_sequence):
    print(f"Epoch {epoch}: Loss {loss}")
    
    if loss < best_loss - min_delta:
        best_loss = loss
        counter = 0 # Reset patience
    else:
        counter += 1
        print(f"  No improvement. Patience: {counter}/{patience}")
        
    if counter >= patience:
        print("  STOPPING: Model has converged.")
        break

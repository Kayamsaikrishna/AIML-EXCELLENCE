20. Applications of Taylor Series

The swiss-army knife of high-performance math.

1. Solving Impossible Limits

If a limit results in an indeterminate form like \(0/0\), and L'Hôpital's rule is too messy, we can replace the functions with their Taylor series.

$$ \lim_{x \to 0} \frac{e^x - 1 - x}{x^2} = \lim_{x \to 0} \frac{(1 + x + x^2/2!) - 1 - x}{x^2} = \frac{1}{2} $$

2. Non-Elementary Integration

Some functions, like \(e^{-x^2}\) (the Gaussian curve), have no "neat" antiderivative. To integrate them, we integrate their Taylor series term-by-term. This is how Standard Normal Distribution tables were originally created!

3. AI/ML Connection: Kernel Expansion

The RBF Kernel

The Radial Basis Function (RBF) kernel used in SVMs is defined as \(K(x, y) = e^{-\gamma \|x-y\|^2}\). To compute this efficiently, we can't always work with the full exponential.

By expanding the RBF kernel into its Taylor Series, we can approximate the "Similarity" between two data points as a weighted sum of their polynomial features. This allows AI models to learn "Non-Linear" boundaries while using "Linear" optimization math. Taylor series is the bridge that allows modern AI to handle complex, curvy data using simple, fast arithmetic.

4. Python: Series Integration

# Error Function (erf) is the integral of e^(-t^2)
# Taylor of e^(-t^2) = 1 - t^2 + t^4/2 - t^6/6 ...
# Integral = t - t^3/3 + t^5/10 - t^7/42 ...

def erf_approx(x, terms=3):
    total = 0
    # Integral of (-1)^n * t^(2n) / n! from 0 to x
    # = (-1)^n * x^(2n+1) / (n! * (2n+1))
    import math
    for n in range(terms):
        term = ((-1)**n * x**(2*n+1)) / (math.factorial(n) * (2*n+1))
        total += term
    return (2/math.sqrt(math.pi)) * total

print(f"erf(0.5) approx: {erf_approx(0.5):.6f}")
from scipy.special import erf
print(f"Actual erf(0.5): {erf(0.5):.6f}")

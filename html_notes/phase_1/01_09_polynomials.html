Polynomials & Rational Functions

Modeling complexity. When a straight line ($x$) and a curve ($x^2$) aren't enough, we combine them into complex features.

1. Polynomial Basics

A polynomial is a sum of terms in the form \( a_n x^n \).

$$ P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0 $$

AI Application: Polynomial Regression & Feature Crossing

Sometimes your data is complex. A simple linear model \( w_1 x_1 + w_2 x_2 \) fails.

We can "engineer" complexity by creating polynomial features:

  • Inputs: Height (\(x_1\)), Weight (\(x_2\)).
  • Polynomial Features: \( x_1^2 \) (Squared Height), \( x_1 \cdot x_2 \) (Interaction term).

This allows a simple Linear Regressor to fit curved data! This is the basis of Kernel Methods in SVMs.

// Sklearn: Generating Polynomial Features
from sklearn.preprocessing import PolynomialFeatures
import numpy as np

# Input: [a, b]
X = np.array([[2, 3]])

# Create features up to degree 2
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(X)

print(X_poly)
# Output: [1, 2, 3, 4, 6, 9]
# Corresponds to: [1, a, b, a^2, a*b, b^2]
# We created "a*b" (interaction) from thin air!

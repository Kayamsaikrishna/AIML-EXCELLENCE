1. What is a Polynomial?

A sum of variables raised to non-negative integer powers.

$$ P(x) = a_n x^n + \dots + a_2 x^2 + a_1 x + a_0 $$

Degree & Behavior

  • Degree 1 (Linear): \( mx+b \). Constant rate of change.
  • Degree 2 (Quadratic): \( ax^2+bx+c \). Acceleration (Gravity).
  • Degree 3 (Cubic): Inflection points. S-curves.

2. Polynomial Regression as Linear Regression

Wait, isn't Linear Regression only for lines? Yes, but observe:

$$ y = w_1 x + w_2 x^2 + b $$

If we treat \( x^2 \) as just another feature \( z \), then \( y = w_1 x + w_2 z + b \). This is Linear in the weights \( w \)!

The "Kernel Trick"

In SVMs, we project data into infinite-dimensional polynomial space using the Kernel function without ever computing the coordinates explicitly.

$$ K(x, y) = (x \cdot y + c)^d $$

3. Feature Engineering in Scikit-Learn

Generating polynomial features automatically.

import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

# 1. Dummy Data: Area of House
X = np.array([[10], [20], [30]]) # 1 Feature: Length

# 2. Upgrade to Quadratic Features
# converts [x] -> [1, x, x^2]
poly = PolynomialFeatures(degree=2)
X_poly = poly.fit_transform(X)

print(f"Original X:\n{X}")
print(f"Expanded Features:\n{X_poly}")
# [[  1.  10. 100.]
#  [  1.  20. 400.]
#  [  1.  30. 900.]]

# 3. Fit Linear Model on Expanded Features
model = LinearRegression()
model.fit(X_poly, np.array([100, 400, 900])) # Perfect y=x^2 relationship
print(f"Coefficients: {model.coef_}") # Should learn [0, 0, 1]

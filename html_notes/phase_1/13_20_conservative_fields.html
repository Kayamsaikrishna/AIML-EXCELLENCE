Calculus 1.6 Potentials

Conservative Vector Fields

Path independence.

The "Gradient" Test

Some vector fields are special. If a field \( \vec{F} \) is simply the gradient of a scalar function \( f \) (i.e., \( \vec{F} = \nabla f \)), it is called Conservative.

Conservative fields have a magical property: The work done moving between two points **does not depend on the path taken**. Test for 2D field \( F = \langle P, Q \rangle \): It is conservative if \[ \frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y} \] " The curl is zero."

2. AI/ML Connection: Consistent Gradients

Avoiding Cycle Loops

In SGD (Optimization), we WANT the gradient field to be conservative (derived from a Loss function). This guarantees there are no "Energy Loops" where the AI could cycle forever without improving.

However, in Game Theory (GANs), the vector field of updates for the Generator and Discriminator is NOT always conservative. It often has "Rotational" components (non-zero Curl). This is why GANs often oscillate forever instead of converging. Researchers analyze the Symplectic Gradient Adjustment to force the field to behave more "Conservatively" and converge to a Nash Equilibrium.

3. Python: The Curl Test

check_conservative.py
import sympy as sp

x, y = sp.symbols('x y')

# Field F = < 2xy, x^2 >
# P = 2xy, Q = x^2
P = 2*x*y
Q = x**2

# Check Curl condition: dQ/dx == dP/dy
dQ_dx = sp.diff(Q, x) # 2x
dP_dy = sp.diff(P, y) # 2x

print(f"dQ/dx: {dQ_dx}")
print(f"dP/dy: {dP_dy}")

if dQ_dx == dP_dy:
    print("Field is Conservative! Finding Potential Function...")
    # Integrate P wrt x
    f = sp.integrate(P, x) # x^2*y
    print(f"Potential Function f(x,y): {f}")
else:
    print("Field is NOT Conservative.")

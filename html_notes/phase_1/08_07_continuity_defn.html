Calculus 1.3 Stability

Definition of Continuity

Mathematically defining "unbroken" paths, a prerequisite for almost every optimization algorithm in Machine Learning.

The "Don't Lift Your Pencil" Rule

Intuitively, a function is continuous if you can draw its graph without lifting your pen. In Machine Learning, we need loss surfaces to be continuous (and preferably smooth) so that we can "slide" down them like a ball rolling down a hill to find the minimum error.

1. The 3-Step Checklist

A function \(f(x)\) is continuous at a point \(x = a\) if and only if:

  1. \(f(a)\) is Defined: The point exists (no hole, no asymptote).
  2. \(\lim_{x \to a} f(x)\) Exists: The function approaches a specific value from both sides.
  3. They Match: \(\lim_{x \to a} f(x) = f(a)\). The path leads exactly to where the point is.

2. AI/ML Connection: Loss Landscapes

Why Gradient Descent Fails on Discontinuities

Imagine training a neural network. You are essentially an optimizer standing on a foggy mountain (the Loss Landscape), trying to walk downhill.

  • Continuous Landscape: You take small steps. If you are at point A, point B (nearby) is at a similar height. You can trust your local slope.
  • Discontinuous Landscape: You take a step and suddenly fall off a cliff or hit a wall. Your gradient calculation (slope) becomes undefined or misleading.

Lipschitz Continuity

In Generative Adversarial Networks (GANs), we often enforce a stricter form of continuity called Lipschitz Continuity. It limits how fast the function can change: \[ |f(x_1) - f(x_2)| \le K |x_1 - x_2| \] This prevents the "Critic" network from having exploding gradients, stabilizing the training of Wasserstein GANs.

3. Python: Continuity Checker

check_continuity.py
import numpy as np

def check_continuity(func, point, epsilon=1e-5):
    print(f"Checking continuity at x = {point}...")
    
    # 1. Check if defined
    try:
        val_at_point = func(point)
        print(f"1. f({point}) = {val_at_point}")
    except:
        print(f"1. f({point}) is Undefined! -> Discontinuous")
        return False

    # 2. Check if limit exists (numerically)
    left_lim = func(point - epsilon)
    right_lim = func(point + epsilon)
    
    # We check if left/right are close
    if not np.isclose(left_lim, right_lim, atol=1e-3):
        print(f"2. Limit DNE! Left: {left_lim:.4f}, Right: {right_lim:.4f} -> Discontinuous")
        return False
    
    limit_val = (left_lim + right_lim) / 2
    print(f"2. Limit exists approx {limit_val:.4f}")

    # 3. Check if they match
    if np.isclose(limit_val, val_at_point, atol=1e-3):
        print("3. Limit == Value -> CONTINUOUS ✅")
        return True
    else:
        print(f"3. Limit ({limit_val}) != Value ({val_at_point}) -> Discontinuous ❌")
        return False

# Test Cases
print("--- Case A: Absolute Value |x| at 0 ---")
check_continuity(abs, 0)

print("\n--- Case B: Step Function at 0 ---")
func_step = lambda x: 1 if x >= 0 else 0
check_continuity(func_step, 0)

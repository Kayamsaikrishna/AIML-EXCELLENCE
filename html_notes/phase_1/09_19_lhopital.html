Calculus 1.3 Tension

L'Hôpital's Rule

When zero fights zero, who wins? The one with the steeper slope.

The Indeterminate Forms

In math, \(\frac{0}{0}\) or \(\frac{\infty}{\infty}\) isn't "undefined"—it's a battle. If the top goes to zero faster, the ratio is 0. If the bottom goes faster, it's infinity. If they go at the same rate, it's a constant. L'Hôpital says: "Look at the derivatives."

1. The Rule

If \(\lim_{x \to c} \frac{f(x)}{g(x)} = \frac{0}{0}\) or \(\frac{\infty}{\infty}\), then:

\[ \lim_{x \to c} \frac{f(x)}{g(x)} = \lim_{x \to c} \frac{f'(x)}{g'(x)} \]

WARNING: This is NOT the Quotient Rule. You differentiate the top and bottom separately!

2. AI/ML Connection: Numerical Stability

Avoiding NaN (Not a Number)

In deep learning implementations (like TensorFlow/PyTorch), we often encounter functions that look dangerous at \(x=0\). Consider the function used in some attention mechanisms: \(\frac{\sin x}{x}\).

  • At \(x=0\), computer sees \(\frac{0}{0}\) -> NaN. This kills training.

Using L'Hôpital: \(\lim_{x\to 0} \frac{\cos x}{1} = 1\).

So in our code, we write a "stable" branch:
if abs(x) < 1e-6: return 1.0; else: return sin(x)/x.
Without L'Hôpital, we wouldn't know what value to plug in!

3. Python: Symbolic Rescue

lhopital_rescue.py
import sympy as sp
import numpy as np

x = sp.Symbol('x')
f = sp.sin(x)
g = x

# 1. Naive limit attempt
print(f"Direct Evaluation at 0: {np.sin(0)/0 if 0 != 0 else 'Undefined (0/0)'}")

# 2. Symbolic Limit (Uses L'Hopital internally)
limit_val = sp.limit(f/g, x, 0)
print(f"Limit via L'Hôpital: {limit_val}")

# 3. Another Example: (e^x - 1) / x
h = sp.exp(x) - 1
limit_exp = sp.limit(h/g, x, 0)
print(f"Limit of (e^x - 1)/x as x->0: {limit_exp}")
# Proof: d/dx(e^x -1) = e^x -> e^0 = 1. d/dx(x) = 1. Ratio = 1/1 = 1.

# Practical Code Pattern (Softplus Stability)
def safe_softplus(x):
    # log(1 + e^x). For large x, e^x explodes.
    # We use approximation x for large x.
    # L'Hopital connects the regimes smoothly.
    return np.log1p(np.exp(x)) if x < 50 else x

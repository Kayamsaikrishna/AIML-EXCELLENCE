Rank-Nullity

\( \text{Rank} + \text{Nullity} = n \). The "Law of Conservation of Dimension".

1. The Conservation Law

For any matrix \( A \) with \( n \) columns (input variables):

$$ \dim(\text{Col}(A)) + \dim(\text{Null}(A)) = n $$

Every dimension of the input space either goes to the Output (Rank) or gets flattened to Zero (Nullity). None disappear.

2. Information Flow

If we have a Neural Network layer with 1000 inputs and 50 nodes, the maximum Rank is 50.

This means the Nullity is at least 950! Massive amounts of information must be destroyed (mapped to zero). This is "Feature Extraction" - keeping the signal (Rank), discarding the noise (Nullity).

3. Verifying the Law

Checking Rank + Nullity = n.

import numpy as np
from scipy.linalg import null_space

# Random 3x5 Matrix
# n = 5 (columns/inputs)
# m = 3 (rows/outputs)
# Max Rank = 3
A = np.random.rand(3, 5)

rank = np.linalg.matrix_rank(A)
null_basis = null_space(A)
nullity = null_basis.shape[1]

n = A.shape[1]

print(f"Inputs (n): {n}")
print(f"Rank (r): {rank}")
print(f"Nullity (k): {nullity}")
print(f"Check: {rank} + {nullity} = {rank + nullity}")
# Should match n exactly

16. Nullity and Rank-Nullity Theorem

The balance between information kept and information lost.

1. Defining Null Space

The Null Space (or Kernel) of a matrix \( \mathbf{A} \) is the set of all vectors \( \mathbf{x} \) that are mapped to zero: \( \mathbf{Ax} = 0 \).

The Nullity is the dimension of this null space.

2. The Rank-Nullity Theorem

For any \( m \times n \) matrix \( \mathbf{A} \), the sum of its rank and nullity must equal the number of columns (\( n \)).

$$ \text{rank}(\mathbf{A}) + \text{nullity}(\mathbf{A}) = n $$

The Data Bottleneck Intuition

Think of \( n \) as the total number of features in your input. When you pass it through a linear layer with weight matrix \( \mathbf{W} \):

  • Rank: The meaningful features that are preserved.
  • Nullity: The "dead features" or noise that are filtered out (information loss).

3. Python: Calculating Nullity

import numpy as np
from scipy.linalg import null_space

A = np.array([[1, 2, 3], [2, 4, 6], [1, 1, 1]])

# Rank
rank = np.linalg.matrix_rank(A)

# Null Space Vectors
ns = null_space(A)
nullity = ns.shape[1]

# Theorem Verification (n=3 columns)
print(f"Rank: {rank}, Nullity: {nullity}")
print(f"Sum: {rank + nullity} (Should be 3)")

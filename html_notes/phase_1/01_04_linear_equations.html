Linear Equations & Inequalities

The humble line is the most important shape in the universe. If you understand \(y = mx + b\), you understand 80% of Machine Learning.

1. The Fundamental Unit: \(y = mx + b\)

Every complex Deep Learning model is just billions of these little lines stacked on top of each other.

Anatomy of the "Neuron"

  • m (Slope): Ideally, this is "Weight" (\(w\)). It tells the AI how important the input is. High slope = strong reaction.
  • x (Input): The data point (e.g., pixel brightness).
  • b (y-intercept): Ideally, this is "Bias". It allows the neuron to fire even if input is zero.

Visualizing Weight (Angle) vs Bias (Shift)

// PyTorch: The Linear Layer is just mx + b
import torch.nn as nn

# In Math:   y = m * x + b
# In Code:   Linear(in_features, out_features, bias=True)

# Create a single "neuron" (1 input, 1 output)
neuron = nn.Linear(in_features=1, out_features=1)

# Inspect the parameters
print(f"Slope (Weight): {neuron.weight.item()}")
print(f"Intercept (Bias): {neuron.bias.item()}")

# This is literally just slope-intercept form!

2. Systems of Equations: Intersection = Solution

Solving a system of equations means finding the point where two truths exist simultaneously.

$$ y = 2x + 1 $$ $$ y = -x + 4 $$

AI Insight: "Training" is just solving a Massive System

Imagine you have 10,000 data points (images of cats). You want ONE line (classifier) that satisfies all of them correctly.

Usually, no such single line exists for complex data. So, instead of an "Exact Solution" (Algebra), we find the "Best Approximate Solution" (Optimization/Calculus).

Overdetermined Systems

In Algebra, if you have 2 variables ($x, y$) and 3 equations, the system is Overdetermined (likely no solution).

In AI, we have 100 variables (weights) and 1,000,000 equations (images). We are massively overdetermined. We use Least Squares Regression to find the line that minimizes the total error distance.

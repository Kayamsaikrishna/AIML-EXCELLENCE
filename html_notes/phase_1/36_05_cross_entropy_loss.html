05. Cross-Entropy Loss

The engine that trains 99% of classification models.

1. The Decomposition

Cross-Entropy $H(P, Q)$ is the total information content required if we use distribution $Q$ (the model) to describe distribution $P$ (the truth). It is simply the sum of the Entropy of the truth + the KL divergence:

$$ H(P, Q) = H(P) + D_{KL}(P || Q) $$

Since the entropy of our data $H(P)$ is constant, minimizing Cross-Entropy is mathematically identical to minimizing KL Divergence.

2. Why not Mean Squared Error (MSE)?

For classification, MSE (calculating the squared distance between labels) has "Flat" gradients when the model is very wrong. Cross-Entropy** has steep gradients when predictions are far from the truth, allowing the AI to learn dramatically faster.

3. AI/ML Connection: The Softmax-CrossEntropy Duo

Probabilistic Alignment

In AI, Cross-Entropy is the standard loss used in **PyTorch (`nn.CrossEntropyLoss`)** and **TensorFlow**.

When you train a **Neural Network** to recognize cats vs dogs, the final layer outputs "Logits." We squash these into a probability distribution using **Softmax**. We then compare this distribution to the Ground Truth (e.g., $[1, 0]$ for cat) using Cross-Entropy. The model's "Goal" is to reach 0 Cross-Entropy. In Multi-label Classification**, we use Binary Cross-Entropy (BCE). In Knowledge Distillation**, a "Student" model tries to minimize the cross-entropy between its outputs and a "Teacher" model's outputs. It is the language that tells the AI: "Be more certain about the right answer."

4. Python: Binary Cross-Entropy (BCE)

import torch
import torch.nn as nn

# Target: [1] (e.g., Cat)
target = torch.tensor([1.0])
# Prediction: 0.8 probability of 'Cat'
pred = torch.tensor([0.8])

# BCE Loss
criterion = nn.BCELoss()
loss = criterion(pred, target)

print(f"BCE Loss: {loss.item():.4f}")
# As pred moves to 1.0, loss moves to 0.0

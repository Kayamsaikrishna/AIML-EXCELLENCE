17. Arc Length

Measuring the distance traveled along a wavy path.

1. The Formula

If you were to "straighten" a piece of a curve and measure it with a ruler, how long would it be? For a smooth function \(f(x)\) on \([a, b]\), the length \(L\) is:

$$ L = \int_{a}^{b} \sqrt{1 + [f'(x)]^2} dx $$

This is derived by applying the Pythagorean Theorem to infinitely small segments of the curve (\(ds = \sqrt{dx^2 + dy^2}\)).

2. Why is this hard?

Arc length integrals are notoriously difficult to solve by hand because of the square root. Most real-world arc lengths (like the length of an ellipse) do not have a "simple" answer and must be calculated using Numerical Integration.

3. AI/ML Connection: Regularization Paths

Path Length as Complexity

In Explainable AI (XAI), we often look at "Regularization Paths". This is a curve showing how your model weights change as you increase the penalty (like Lasso/L1 or Ridge/L2).

An AI model that is "stable" should have a short arc length for its regularization path. If the path is long and winding, it means a tiny change in the penalty causes massive, unpredictable shifts in the weights—indicating a model that might be brittle or noisy. By measuring the arc length of the training trajectory, engineers can quantify the "effort" or "path efficiency" of an optimizer.

4. Python: Measuring the Length of a Parabola

# Length of y = x^2 from 0 to 1
# f'(x) = 2x
# Integral of sqrt(1 + 4x^2)

import numpy as np
from scipy.integrate import quad

def integrand(x):
    return np.sqrt(1 + (2*x)**2)

length, error = quad(integrand, 0, 1)

print(f"Arc Length (0->1): {length:.4f}") 
# Result: ~1.4789

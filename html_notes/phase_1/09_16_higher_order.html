Calculus 1.3 Curvature

Higher Order Derivatives

Velocity tells you where you're going. Acceleration tells you how hard it is to stop.

Beyond the Slope

The First Derivative measures Slope (Rate of Change). The Second Derivative measures Curvature (Rate of Change of the Slope). In ML, curvature tells us if a minimum is a sharp narrow valley (unstable) or a wide flat basin (stable, generalizes well).

1. The Hierarchy

  • First Derivative \(f'(x)\): Velocity. In ML, this is the Gradient Gradient vector \(\nabla\).
  • Second Derivative \(f''(x)\): Acceleration/Concavity. In ML, this is the Hessian Matrix \(H\).
  • Third Derivative \(f'''(x)\): Jerk. Rarely used in ML, but critical in robotics for smooth motion planning.
\[ f''(x) = \frac{d}{dx}\left( \frac{df}{dx} \right) = \frac{d^2f}{dx^2} \]

2. AI/ML Connection: The Hessian Matrix

Second-Order Optimization

Standard Gradient Descent takes small steps downhill. But how big should the step be?

  • If curvature is high (steep valley), big steps will overshoot.
  • If curvature is low (flat plateau), small steps take forever.

Newton's Method uses the Hessian (2nd derivative) to perfectly scale the step size: \[ \theta_{new} = \theta_{old} - H^{-1} \nabla \] In Deep Learning, calculating the full Hessian for 10M parameters is too expensive (memory-wise), so we approximate it (using Adam, RMSprop) or use diagonal approximations.

3. Python: Computing the Hessian

hessian_matrix.py
import sympy as sp

x, y = sp.symbols('x y')

# A simplified Loss Landscape (Bowl shape)
loss = x**2 + 2*y**2 + x*y

# 1. Gradient (First Derivatives)
grad_x = sp.diff(loss, x) # 2x + y
grad_y = sp.diff(loss, y) # 4y + x

# 2. Hessian (Second Derivatives Matrix)
# [ d2/dx2   d2/dxdy ]
# [ d2/dydx  d2/dy2  ]

hessian = [[sp.diff(loss, x, x), sp.diff(loss, x, y)],
           [sp.diff(loss, y, x), sp.diff(loss, y, y)]]

print(f"Loss Function: {loss}")
print(f"Gradient Vector: [{grad_x}, {grad_y}]")
print("Hessian Matrix:")
for row in hessian:
    print(row)
    
# Output Hessian: [[2, 1], [1, 4]]
# The eigenvalues of this matrix determine if we are in a valley, a peak, or a saddle point.

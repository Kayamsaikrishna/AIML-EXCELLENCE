04. A/B Testing Foundations

The engine of data-driven decision making.

1. What is an A/B Test?

An A/B Test is a randomized experiment with two variants, A and B. It is frequently used in web development and marketing to compare things like headline text, button colors, or user interfaces.

  • Variant A (Control): The current version.
  • Variant B (Treatment): The modified version.

2. The Checklist

  • Metric: What are we measuring? (e.g., Click-through rate, Revenue).
  • Randomization: Ensure users are assigned to A or B truly at random.
  • Sample Size: How many users do we need to be 95% sure of the result?
  • Duration: How long will the test run? (Avoid "Peeking").

3. AI/ML Connection: The Validation of Intelligence

The "Offline" vs. "Online" Reality

In AI, A/B testing is the final step in the Model Deployment Pipeline**.

Even if an AI model has a 99% accuracy in "Offline" testing (on old data), it might fail in the real world because of "Data Drift" or user behavior changes. A/B tests provide the **Online Validation**. In Content Recommendation (YouTube/TikTok)**, every major model change is A/B tested to ensure it actually increases "Watch Time." This prevents "Metric Cannibalization"—where a model looks better on one metric but causes a massive drop in another. By mastering A/B testing, AI engineers bridge the gap between "Math on a laptop" and "Impact in the world."

4. Python: Simulating a Test Result

from statsmodels.stats.proportion import proportions_ztest

# Successes (clicks) and total trials (users)
count = np.array([450, 500]) # A had 450, B had 500 clicks
nobs = np.array([10000, 10000]) # 10k users each

stat, pval = proportions_ztest(count, nobs)

print(f"P-value: {pval:.4f}")
# If p-value < 0.05, we switch to Variant B!

05. The Fundamental Theorem of Calculus

The bridge between slope and area.

1. Part 1: The Accumulation Function

If \(g(x) = \int_a^x f(t) dt\), then \(g'(x) = f(x)\).

$$ \frac{d}{dx} \left[ \int_a^x f(t) dt \right] = f(x) $$

Interpretation: The rate at which area accumulates is equal to the value of the function.

2. Part 2: The Evaluation Theorem

$$ \int_a^b f(x) dx = F(b) - F(a) $$

Where \(F\) is any antiderivative of \(f\). This allows us to find exact areas without summing infinite rectangles.

3. AI Connection: Cumulative Distribution Functions (CDF)

Probability Accumulation

In Statistics, a CDF \(\Phi(x)\) gives the probability that \(X \le x\). As an AI researcher, if you have the PDF (Probability Density Function) \(p(x)\), FTC tells you that: $$ \Phi(x) = \int_{-\infty}^x p(t) dt $$ And more importantly, the density is the derivative of the accumulation: \(p(x) = \Phi'(x)\). This identity is used every time an AI samples from a distribution using Inverse Transform Sampling.

4. Python: Verifying FTC

import sympy as sp

x = sp.Symbol('x')
f = sp.sin(x)

# 1. Antiderivative
F = sp.integrate(f, x) # -cos(x)

# 2. Definite Integral from 0 to pi
area = sp.integrate(f, (x, 0, sp.pi))

# 3. FTC Check: F(pi) - F(0)
check = F.subs(x, sp.pi) - F.subs(x, 0)

print(f"Area via integration tool: {area}")
print(f"Area via F(b) - F(a):      {check}")

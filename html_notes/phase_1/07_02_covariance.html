1. Definition

The Covariance Matrix \( \Sigma \) (or \( S \)) is a symmetric matrix where:

  • Diagonal \( \sigma_{ii}^2 \): Variance of feature \( i \).
  • Off-Diagonal \( \sigma_{ij} \): Covariance between \( i \) and \( j \). (How they move together).
$$ \Sigma = \frac{1}{N-1} (X - \mu)^T (X - \mu) $$

2. Multivariate Gaussian

The Normal Distribution in higher dimensions is strictly defined by \( \mathcal{N}(\mu, \Sigma) \).

In Gaussian Mixture Models (GMMs) or Naive Bayes, learning the structure involves estimating this \( \Sigma \). A diagonal \( \Sigma \) implies independent features (Naive assumption).

3. Computing Covariance

import numpy as np

# 3 Samples, 2 Features
X = np.array([
    [1, 2],
    [2, 3],
    [3, 5]
])

# Mean Centering
X_centered = X - np.mean(X, axis=0)

# 1. Manual Calculation (N-1 for sample cov)
N = X.shape[0]
Cov_manual = (X_centered.T @ X_centered) / (N - 1)

# 2. NumPy Calculation (Rowvar=False means rows are samples)
Cov_np = np.cov(X, rowvar=False)

print("Manual Covariance:\n", Cov_manual)
print("NumPy Covariance:\n", Cov_np)

# Correlation (Normalized)
corr = np.corrcoef(X, rowvar=False)
print("\nCorrelation:\n", corr)

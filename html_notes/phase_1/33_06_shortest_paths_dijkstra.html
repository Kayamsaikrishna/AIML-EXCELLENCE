Shortest Path Algorithms

Finding the Optimal Route. Solving the fundamental problem of navigating weighted graphs to find the minimum distance between two points.

Beyond Geometry

In a graph, the "shortest" path isn't necessarily a straight line. It's the path where the sum of edge weights is minimized. These weights can represent time, fuel, cost, or the probability of an error in an AI sequence.

1. Core Algorithms

Dijkstra's Algorithm

Finds shortest paths from a source to all other nodes. Constraint: Edge weights must be non-negative. Uses a Priority Queue for optimization (\(O(E \log V)\)).

Bellman-Ford Algorithm

Handles graphs with negative edge weights. It can also detect Negative Cycles (infinite distance reduction loops).

A* (A-Star) Search

Dijkstra with a Heuristic (\(f = g + h\)). It uses domain knowledge (like Euclidean distance) to "guide" the search toward the target.

2. All-Pairs Shortest Path

When you need the shortest path between every pair of nodes in the graph.

Floyd-Warshall Algorithm: Uses dynamic programming to update distances through intermediate nodes. Complexity: \(O(V^3)\).
NLP Reinforcement Learning

Routing in AI

  • Viterbi Algorithm: In Hidden Markov Models (HMMs) and NLP (Part-of-Speech tagging), Viterbi is essentially a shortest-path algorithm on a "Trellis Graph" to find the most likely sequence of states.
  • Beam Search: Used in LLMs and translation models to explore the most likely paths in the vocabulary graph while keeping memory usage under control.
  • Game AI Pathfinding: A* is the industry standard for autonomous agents in video games and robotics to navigate complex environments.
  • Optimal Policy in RL: Finding the optimal path through a State-Action graph is the core of Reinforcement Learning. Bellman-Ford's logic directly inspires the Bellman Equations used in Q-Learning.

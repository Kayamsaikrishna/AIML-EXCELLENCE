DiffEq 1.8 Forcing Functions

Homogeneous vs Non-Homogeneous

Natural responses vs. Externally driven systems.

The Driver

Homogeneous ODE: \(ay'' + by' + cy = 0\). This represents the system's "Natural" behavior (e.g., a bell ringing after being struck).

Non-Homogeneous ODE: \(ay'' + by' + cy = F(t)\). Here \(F(t)\) is an external "Forcing Function" (e.g., continually pushing a swing). The solution is \(y(t) = y_{homogeneous}(t) + y_{particular}(t)\).

2. AI/ML Connection: Control & Robotics

Driven Systems

In Reinforcement Learning (Robotics), the robot is the system (defined by Homogeneous Dynamics like mass/inertia). The "Action" or "Motor Torque" applied by the Neural Network Policy is the Forcing Function \(F(t)\).

The goal of the RL agent is to find a function \(F(t)\) (the control policy) that forces the system into a desired state (e.g., standing upright).

3. Python: Superposition

forcing_func.py
import numpy as np
import matplotlib.pyplot as plt

# System: y' = -y + sin(t)
# Homogeneous part: y' = -y -> Decay e^-t
# Particular part: sin(t) driver

t = np.linspace(0, 10, 100)
forcing = np.sin(t)
y_homo = np.exp(-t) # Natural decay

plt.plot(t, forcing, label="Forcing (Input)", alpha=0.5)
plt.plot(t, y_homo, label="Homogeneous (Natural)", alpha=0.5)
plt.plot(t, forcing + y_homo, label="Total Response", linewidth=2)
plt.title("System Response = Natural + Forced")
plt.legend()
plt.show()

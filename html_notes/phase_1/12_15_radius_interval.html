Calculus 1.5 The Safe Zone

Interval of Convergence

Finding where the proxy logic holds true.

The Radius (R)

A Power Series doesn't always work for every \(x\). There is a specific domain where it is valid. We find this "Safe Zone" using the Ratio Test.

\[ \lim_{n \to \infty} \left| \frac{c_{n+1} (x-a)^{n+1}}{c_n (x-a)^n} \right| < 1 \]

This inequality solves for \( |x-a| < R \). This \(R\) is the **Radius of Convergence**. Inside this radius, the series is a perfect copy of the function. Outside, it is nonsense.

2. AI/ML Connection: Kernel Methods & Infinite Features

The Kernel Trick

In Support Vector Machines (SVMs), we use the "Kernel Trick" to map data into infinite dimensions: \[ K(x,y) = e^{-\gamma ||x-y||^2} \quad \text{(RBF Kernel)} \]

We can view this kernel as a Power Series expansion (dot products of infinite feature vectors). The convergence of this series is crucial. Because the exponential function has an **Infinite Radius of Convergence** (\(R = \infty\)), the RBF Kernel works for ANY data input, no matter how far from the origin. If we used a kernel based on a function with a finite radius (like a geometric series), the model would fail for outliers.

3. Python: Finding the Radius

radius_check.py
import sympy as sp

# Series: x^n / n (Logarithmic series approximation)
# Ratio Test limit: |x| < 1 implies R=1.

x, n = sp.symbols('x n')
term = x**n / n
next_term = x**(n+1) / (n+1)

ratio = sp.Abs(next_term / term)
limit_ratio = sp.limit(ratio, n, sp.oo)

print(f"Ratio Limit: {limit_ratio}")
# Output: |x|
# Condition: |x| < 1 -> Interval (-1, 1)

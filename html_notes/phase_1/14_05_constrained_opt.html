Optimization 1.7 The Fence

Constrained Optimization

Maximizing success within the boundaries of reality.

The General Problem

Most optimization problems are not free-roaming. We want to find the best parameters \(\mathbf{x}\) subject to limits.

$$ \begin{aligned} &\text{minimize} && f(\mathbf{x}) \\ &\text{subject to} && g_i(\mathbf{x}) = 0 \quad \text{(Equality Constraints)} \\ & && h_j(\mathbf{x}) \le 0 \quad \text{(Inequality Constraints)} \end{aligned} $$

2. AI/ML Connection: Regularization

Hard vs. Soft Constraints

In deep learning, we rarely use "Hard" constraints (like \(|\mathbf{w}| < 1\)) directly because they are hard to differentiate through. Instead, we turn them into "Soft" constraints by adding a penalty term to the loss function.

For example, L2 Regularization (Weight Decay) is actually a solution to:
"Minimize Loss subject to ||w||² < C".
By using Lagrange Multipliers, this becomes:
"Minimize Loss + λ||w||²".

3. Python: Parameter Clipping

projected_gradient.py
import numpy as np

# A simple way to enforce constraints is "Projected Gradient Descent".
# After every update step, we "clip" the parameters to stay inside the box.

def projected_gradient_descent(start_x, learning_rate, steps):
    x = start_x
    path = [x]
    
    for _ in range(steps):
        # 1. Gradient Step (Minimize x^2)
        grad = 2 * x
        x = x - learning_rate * grad
        
        # 2. Projection Step (Constraint: -1 <= x <= 1)
        x = np.clip(x, -1, 1)
        
        path.append(x)
    return path

# Start far outside the box
start = 5.0
path = projected_gradient_descent(start, 0.5, 5)

print(f"Path: {path}")
# Notice it quickly hits 1.0 and stays there. 
# The constraint 'activates'.

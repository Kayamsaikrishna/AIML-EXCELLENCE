Area Between Curves

Measuring the Gap.

The Difference Integral

To find the area between two functions \(f(x)\) (top) and \(g(x)\) (bottom), we simply integrate the difference in their heights. \[ A = \int_a^b (High - Low) dx \]

1. The Process

  1. Identify the Top and Bottom: Graph or test a point to see which function is larger.
  2. Find Intersections: Solve \(f(x) = g(x)\) to find the start (\(a\)) and end (\(b\)) of the region.
  3. Integrate: Compute \(\int_a^b [f(x) - g(x)] dx\).

Note: If the curves switch places (cross each other), split the integral into two parts.

2. AI/ML Connection: AUC and Model Comparison

ROC Curves

In Classification, we use the ROC Curve (Receiver Operating Characteristic) to visualize performance. The metric we care about is AUC (Area Under the Curve).

If we are comparing two models (Model A vs Model B), the "Area Between the Curves" represents the Performance Gap. If we integrate \(\int (ROC_A - ROC_B) dx\), we get a scalar value representing exactly how much better Model A is across all possible thresholds.

3. Python: Calculating the Gap

area_between.py
import sympy as sp

x = sp.Symbol('x')

# Function 1: Line y = x
f1 = x
# Function 2: Parabola y = x^2
f2 = x**2

# 1. Find Intersections (x = x^2)
roots = sp.solve(f1 - f2, x)
print(f"Intersections: {roots}") # [0, 1]

# 2. Integrate (Top - Bottom)
# Between 0 and 1, x > x^2 (e.g., 0.5 > 0.25)
area = sp.integrate(f1 - f2, (x, 0, 1))

print(f"Area Between Curves: {area}")
# Output: 1/6

10. Mean Value Theorem (MVT) and Rolle's Theorem

The existence of instantaneous average change.

1. Rolle's Theorem

If \(f\) is continuous on \([a, b]\) and differentiable on \((a, b)\), and \(f(a) = f(b)\), then there exists at least one \(c\) in \((a, b)\) such that:

$$ f'(c) = 0 $$

Interpretation: If a plane returns to the same altitude, it must have been level at least once.

2. The Mean Value Theorem (MVT)

This is the generalization of Rolle's. It states there is at least one point where the Instantaneous Slope matches the Average Slope:

$$ f'(c) = \frac{f(b) - f(a)}{b - a} $$

3. AI Connection: Gradient Lipschitz Continuity

In Optimization proof theory, we use MVT to bound the change in the gradient. If we know the second derivative is bounded (Lipschitz constant), MVT allows us to prove that Gradient Descent will always make progress if the learning rate is small enough. It "bridges" the discrete steps of the optimizer to the continuous math of the error surface.

4. Python: Verifying MVT

import numpy as np

def f(x): return x**2
a, b = 1, 3

# Average slope
avg_slope = (f(b) - f(a)) / (b - a) # (9 - 1) / 2 = 4

# Solve f'(c) = 2c = 4
c = avg_slope / 2 # c = 2

print(f"Average slope on [1, 3]: {avg_slope}")
print(f"MVT guarantees point c exists. Here c = {c}")

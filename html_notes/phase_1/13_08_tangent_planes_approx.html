Calculus 1.6 Approximation

Tangent Planes & Linearization

Flat earth theory (locally).

The Best Flat Approximation

In 1D, the tangent line approximates a curve. In 2D, the Tangent Plane approximates a surface. Instead of \( y - y_0 = m(x - x_0) \), we have: \[ z - z_0 = f_x(x - x_0) + f_y(y - y_0) \]

This is the Linearization of \( f(x, y) \). For points close to \( (x_0, y_0) \), the curved surface looks indistinguishable from this flat plane.

2. AI/ML Connection: Local Linearity

Why Gradients Work

Gradient Descent relies entirely on the assumption that the loss function is Locally Linear. It assumes that if we step in the direction of the specific tangent plane slope, the function value will decrease linearly.

If the learning rate is too high, we step "off" the valid region of the tangent plane approximation and might overshoot into a region where the curvature (Hessian) dominates, causing the loss to explode. This is why Adaptive Learning Rates (Adam, RMSProp) are crucial—they adjust the step size based on how trustworthy the linear approximation is.

3. Python: Tangent Plane Construction

tangent_plane.py
import numpy as np
import matplotlib.pyplot as plt

def f(x, y):
    return x**2 + y**2

# Point of tangency (1, 1, 2)
x0, y0 = 1, 1
z0 = f(x0, y0)

# Partials at (1, 1)
fx = 2 * x0 # 2
fy = 2 * y0 # 2

# Tangent Plane Equation: z = z0 + fx(x-x0) + fy(y-y0)
# z = 2 + 2(x-1) + 2(y-1) => z = 2x + 2y - 2

x = np.linspace(0, 2, 20)
y = np.linspace(0, 2, 20)
X, Y = np.meshgrid(x, y)
Z_surface = f(X, Y)
Z_plane = 2*X + 2*Y - 2

fig = plt.figure()
ax = fig.add_subplot(111, projection='3d')
ax.plot_surface(X, Y, Z_surface, alpha=0.5, color='blue')
ax.plot_surface(X, Y, Z_plane, alpha=0.5, color='orange')
plt.title("Surface vs Tangent Plane")
plt.show()

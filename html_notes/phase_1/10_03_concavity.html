Calculus 1.3 Curvature

Concavity & Inflection Points

Is the glass half full or half empty? It depends on the curvature.

The "Bend" of Data

The First Derivative tells you direction (up/down). The Second Derivative tells you curvature (smiling/frowning). This distinction separates exponential growth ("accelerating") from logarithmic growth ("saturating").

1. Definition

  • Concave UP (Convex): \(f''(x) > 0\). Slope is increasing. Holds water like a cup.
  • Concave DOWN (Concave): \(f''(x) < 0\). Slope is decreasing. Spills water like an umbrella.
  • Inflection Point: Where \(f''(x) = 0\) AND changes sign. The curve switches from cup to umbrella.

2. AI/ML Connection: The Elbow Method (K-Means)

Law of Diminishing Returns

When tuning hyperparameters (like \(K\) in K-Means clustering), we plot Error vs \(K\). The error drops rapidly at first, then flattens out.

The "Elbow Point" is where the Curvature (second derivative) is maximum (most sharp bend). This inflection point represents the optimal trade-off: getting maximum benefit before the "saturating" behavior (concave up nature) dominates.

Also: Convex Optimization relies entirely on functions being Concave Up everywhere (bowl shaped), guaranteeing a single Global Optimum.

3. Python: Detecting the Bend

inflection_detection.py
import sympy as sp

x = sp.Symbol('x')
# A Logistic-like S-curve: f(x) = 1 / (1 + e^-x) - simplified version
# Let's use polynomial x^3 which also has inflection at 0
f = x**3 - 3*x**2 + 2

f1 = sp.diff(f, x)
f2 = sp.diff(f1, x)

print(f"Function: {f}")
print(f"1st Deriv: {f1}")
print(f"2nd Deriv: {f2}") # 6x - 6

# Find Inflection: f''(x) = 0
inflection_pts = sp.solve(f2, x)
print(f"Candidate Inflection Point: {inflection_pts}")

# Test Concavity around x=1
for pt in [0, 2]:
    curvature = f2.subs(x, pt)
    shape = "Concave UP" if curvature > 0 else "Concave DOWN"
    print(f"At x={pt}: f''={curvature} -> {shape}")

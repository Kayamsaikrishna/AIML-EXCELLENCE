Stats 1.4 Comparative Stats

CI for Difference in Means

Answering the question: "Is the difference between these two groups real, or just noise?"

The Delta (\(\Delta\))

In ML, we rarely care about a single model in isolation. We care if Model B is better than Model A. By building a confidence interval for the difference \(\mu_1 - \mu_2\), we can prove if one genuinely outperforms the other.

1. Independent Samples

$$ (\bar{x}_1 - \bar{x}_2) \pm t^* \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}} $$

Used when the two groups are unrelated (e.g., users in New York vs. users in London).

2. The "Does it contain Zero?" Test

The Golden Rule

If the Confidence Interval for the difference contains zero (e.g., \([-1.5, 3.2]\)), we conclude there is No Significant Difference. - It's possible for \(\bar{x}_1\) to be slightly larger than \(\bar{x}_2\), but the range shows the true difference could easily be zero.

3. ML Connection: A/B Testing

Product A/B Testing

The Multi-Armed Bandit Start

Most modern recommendation systems start with an A/B test. - Group A: Control (Old Model). - Group B: Treatment (New Model).

If the 95% CI for the difference in Click-Through Rate (CTR) is [0.02, 0.05], we are 95% confident that the new model causes at least a 2% increase in clicks. Because the entire interval is above zero, we "Push to Production".

Paired T-Tests (Model Comparison)

If you run Model A and Model B on the exact same validation set, the samples are not independent—they are "Paired". This allows for a much tighter confidence interval because it cancels out the shared difficulty of specific examples.

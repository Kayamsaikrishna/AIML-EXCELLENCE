Prob 1.4 Center of Mass

Expected Value

The long-run average.

Definition

The Expected Value \(E[X]\) (or Mean \(\mu\)) is the weighted average of all possible values.

  • Discrete: \(E[X] = \sum x p(x)\)
  • Continuous: \(E[X] = \int x f(x) dx\)
Linearity of Expectation: \(E[aX + bY] = aE[X] + bE[Y]\). (CRUCIAL!)

2. ML Connection: The Risk Function

Minimizing Expected Loss

In Supervised Learning, our goal is to minimize the Expected Loss (Risk) over the data distribution: \[ R(\theta) = E_{(x,y) \sim P_{data}} [ L(f(x; \theta), y) ] \] Since we don't know the true \(P_{data}\), we approximate this expectation using the **Empirical Mean** of our training set (Empirical Risk Minimization).

3. Python: Expectation

expectation.py
import numpy as np

# Dice Roll (Discrete Uniform 1..6)
values = np.array([1, 2, 3, 4, 5, 6])
probs = np.full(6, 1/6)

# Expected Value = Sum(x * p(x))
expected_val = np.sum(values * probs)
print(f"E[Dice]: {expected_val:.2f}") # 3.50

# Empirical Check (Law of Large Numbers)
rolls = np.random.randint(1, 7, 100000)
print(f"Empirical Mean: {np.mean(rolls):.2f}")

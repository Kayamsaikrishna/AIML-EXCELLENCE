Quadratic Equations & Optimization

The Parabola (\(x^2\)) is the shape of "Loss". Finding its bottom is the primary goal of training a Neural Network.

1. The Quadratic Equation

A quadratic equation introduces curvature. It is a polynomial of degree 2.

$$ ax^2 + bx + c = 0 $$

Factoring: Finding the Roots

Solving for \(x\) means finding where the curve hits the floor ($y=0$).

Example: \(x^2 - 5x + 6 = 0\)

We look for two numbers that multiply to 6 and add to -5.

$$ (x - 2)(x - 3) = 0 $$

Roots: \(x = 2, x = 3\).

AI Context: Zero Loss

If the quadratic represents your Error Function, finding the roots means finding the state where Error = 0 (Perfect Prediction).

In reality, noise prevents Error from ever hitting exactly 0, but we try to get as close as possible.

2. Completing the Square: finding the Minimum

This is arguably the most important algebraic manipulation for Machine Learning intuition. It transforms standard form into Vertex Form.

$$ y = a(x - h)^2 + k $$

Why "Completing the Square" matters for Optimization

The term \((x-h)^2\) is always positive. The smallest it can ever be is 0 (when \(x=h\)).

Therefore, the minimum value of \(y\) is just \(k\).

This is the goal of Gradient Descent: To find the input \(h\) (weights) that minimizes the function value \(k\) (Loss). We want to slide down the sides of the bowl to sit in the vertex.

// PyTorch: MSE Loss looks just like (x-h)^2

import torch.nn as nn
import torch

# Mean Squared Error Loss
loss_fn = nn.MSELoss()

prediction = torch.tensor([5.0], requires_grad=True)
target = torch.tensor([2.0]) # The "h" (correct answer)

# Loss = (5 - 2)^2 = 3^2 = 9
loss = loss_fn(prediction, target) 

print(f"Loss: {loss.item()}") 
# Output: 9.0

# If we shift prediction closer to 2...
prediction = torch.tensor([2.1])
loss = loss_fn(prediction, target)
print(f"New Loss: {loss.item()}")
# Output: 0.0100 (Much smaller!)

3. The Quadratic Formula

When factoring is too hard, we use the brute force tool of the universe.

$$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$

The Discriminant: \( \Delta = b^2 - 4ac \)

  • \(\Delta > 0\): Two real roots. (The Loss curve crosses zero twice).
  • \(\Delta = 0\): One real root. (The Loss curve just touches zero perfectly—Ideal state).
  • \(\Delta < 0\): No real roots. Complex roots. (The Loss curve floats above zero—The model can never reach 0 error).

1. The Geometry of Squared Error

The standard quadratic equation is \( ax^2 + bx + c = 0 \). In AI, we care about the function \( f(x) = ax^2 + bx + c \).

Why do we love squares?

We use Mean Squared Error (MSE) because it is Strictly Convex (if used on linear models). It guarantees a single global minimum, meaning Gradient Descent will find the answer.

$$ \text{Loss}(\theta) = (\theta x - y)^2 $$

Since this is a square, the error surface is a parabola opening upwards.

2. Finding the Minimum: Analytical vs. Iterative

For a simple parabola, we can find the minimum analytically using the Vertex Formula or Calculus.

$$ x_{min} = -\frac{b}{2a} \quad \text{(Vertex Formula)} $$ $$ \frac{df}{dx} = 2ax + b = 0 \implies x = -b/2a \quad \text{(Calculus)} $$

The Hessian Matrix

In high dimensions, how do we know if we are at a minimum, maximum, or saddle point?

We look at the Hessian Matrix (matrix of second derivatives). If the Hessian is Positive Definite (all eigenvalues > 0), the function is locally convex (a bowl), and we are at a stable minimum.

3. Gradient Descent on a Quadratic

Gradient Descent effectively mimics a ball rolling down the parabola.

$$ \theta_{new} = \theta_{old} - \eta \nabla L(\theta) $$

If the learning rate \( \eta \) is too high, the ball bounces out of the bowl (Divergence). If too low, it takes forever.

4. Visualizing the Loss Landscape

Let's plot the MSE loss surface for a simple 1-parameter model.

import numpy as np
import matplotlib.pyplot as plt

# Generate synthetic data
# y = 3x
x_data = np.array([1, 2, 3, 4])
y_data = np.array([3, 6, 9, 12])

# Define Weight space (The parameter we are tuning)
w_space = np.linspace(0, 6, 100) # Check weights from 0 to 6
losses = []

for w in w_space:
    # Model: y_pred = w * x
    preds = w * x_data
    # MSE Loss formula
    mse = np.mean((preds - y_data)**2)
    losses.append(mse)

# This would produce a perfect Parabola with minimum at w=3
# Use libraries to plot if needed, but the array proves the values.
min_loss = min(losses)
best_w = w_space[np.argmin(losses)]

print(f"Minimum Loss: {min_loss:.4f} at Weight: {best_w:.2f}")

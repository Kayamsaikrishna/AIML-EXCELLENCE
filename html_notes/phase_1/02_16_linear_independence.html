16. Linear Independence & Dependence

Ensuring every feature adds unique value.

1. Formal Definition

A set of vectors \( \{ \mathbf{v}_1, \mathbf{v}_2, \dots, \mathbf{v}_n \} \) is Linearly Independent if the only way to satisfy the equation \( c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \dots + c_n \mathbf{v}_n = \mathbf{0} \) is by setting all scalars \( c_i = 0 \).

$$ c_1 \mathbf{v}_1 + c_2 \mathbf{v}_2 + \dots + c_n \mathbf{v}_n = \mathbf{0} \implies c_1 = c_2 = \dots = c_n = 0 $$

If any vector can be written as a combination of the others, the set is Linearly Dependent.

2. Multi-Collinearity & Feature Redundancy

The Data Scientist's Nightmare

In Linear Regression, if two features (e.g., "Height in cm" and "Height in inches") are linearly dependent, the model becomes unstable. This is called Multi-Collinearity.

  • Rank: The rank of a matrix is the number of linearly independent rows (or columns). A full-rank matrix is essential for invertible ML operations.
  • Feature Selection: We often use algorithms to remove linearly dependent features to speed up training and prevent over-fitting.

3. Python: Detecting Dependence

import numpy as np

# Dependent Set
v1 = np.array([1, 2, 3])
v2 = np.array([2, 4, 6]) # v2 = 2 * v1

matrix = np.array([v1, v2])
rank = np.linalg.matrix_rank(matrix)

if rank < min(matrix.shape):
    print("The vectors are Linearly Dependent.")
else:
    print("The vectors are Linearly Independent.")

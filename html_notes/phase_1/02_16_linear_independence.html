1. No Free Lunch

Vectors are Linearly Independent if no vector in the set can be built from the others.

Formal Test: The only way to combine them to get the Zero Vector is by multiplying them all by zero.

$$ \sum c_i \mathbf{v}_i = \mathbf{0} \iff c_1 = c_2 = \dots = 0 $$

If there is ANY other way (e.g. \( 2\mathbf{v}_1 - \mathbf{v}_2 = 0 \)), then they are Dependent (Redundant).

2. The Dummy Variable Trap

In Machine Learning, when we One-Hot Encode categories (Monday..Sunday), we create 7 columns. But the 7th column is redundant because if it's not Mon-Sat, it MUST be Sunday.

This creates Multicollinearity (Linear Dependence). The weights become unstable because there are infinite solutions to \( Wx + b \). We solve this by dropping one column (n-1 encoding).

3. Matrix Rank

Using Rank to count independent rows.

import numpy as np

# 3 Dependent Vectors (Row 3 = Row 1 + Row 2)
A = np.array([
    [1, 2, 3],
    [4, 5, 6],
    [5, 7, 9]  # 1+4, 2+5, 3+6
])

# Calculate Rank
rank = np.linalg.matrix_rank(A)

print("Matrix A:")
print(A)
print(f"Rank: {rank}") 
# Should be 2 (Loss of dimensionality)

# Determinant check
det = np.linalg.det(A)
print(f"Determinant: {det:.10f}") 
# Should be 0 (Volume is zero)

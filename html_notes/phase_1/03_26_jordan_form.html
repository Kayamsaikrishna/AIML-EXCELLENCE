1. Definition

If a matrix \( A \) does not have enough eigenvectors to be diagonalized, it is similar to a block diagonal matrix \( J \):

$$ A = M J M^{-1} $$

Each block \( J_i \) (Jordan Block) has the eigenvalue \( \lambda_i \) on the diagonal and \( 1 \)'s on the super-diagonal.

2. System Stability

In analyzing Recurrent Neural Networks (RNNs) or dynamical systems \( x_{t+1} = A x_t \), the Jordan form determines stability.

The "1"s in the Jordan blocks cause polynomial growth ($t \lambda^t$) alongside the exponential growth ($\lambda^t$), which can affect convergence rates in non-normal networks.

3. SymPy Calculation

Jordan form is numerically unstable (tiny perturbations break the "1"s), so we use symbolic math.

from sympy import Matrix

# A defective matrix (Repeated eigenvalue 5, only 1 eigenvector)
A = Matrix([
    [5, 4],
    [-1, 1]
]) # Leads to char eq (lambda-3)^2 = 0 ? No let's trust SymPy

P, J = A.jordan_form()

print("Jordan Form J:")
print(J)
# Should see [3, 1], [0, 3] or similar structure

print("\nTransformation P (Generalized Eigenvectors):")
print(P)

print("\nCheck A = P J P^-1:")
print(P * J * P.inv() == A)

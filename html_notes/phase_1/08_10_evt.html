Calculus 1.3 Optimization

Extreme Value Theorem (EVT)

Does a "best" solution actually exist? The EVT gives us the guarantee that we aren't chasing ghosts.

The Foundation of Optimization

Machine Learning is essentially finding the minimum of a function (Loss). But can we be sure a minimum exists? What if the loss keeps getting smaller forever (like \(1/x\) approaches 0)? The EVT provides the conditions under which a minimum must exist.

1. The Theorem Statement

If \(f\) is continuous on a closed interval \([a, b]\), then \(f\) attains both an absolute maximum and an absolute minimum on that interval.

\[ \exists c, d \in [a, b] \text{ such that } f(c) \le f(x) \le f(d) \quad \forall x \in [a, b] \]

2. Why the Conditions Matter

Condition 1: Continuous

If the function has a hole or asymptote, it might never reach the max/min.

Ex: \(1/x\) on \([-1, 1]\) explodes to \(\infty\) at 0.

Condition 2: Closed Interval

If the interval is open \((0, 1)\), the function limits to the edge but never touches it.

Ex: \(f(x)=x\) on \((0, 1)\) has no max. It gets arbitrarily close to 1 (0.9, 0.99...) but never reaches it.

3. AI/ML Connection: Regularization & Weights

Why we bound Weights

The EVT is crucial for understanding Regularization. We usually minimize Loss \(L(w)\) over the entire real line \( (-\infty, \infty) \). This is an open interval, so a minimum isn't guaranteed (the weights could explode to infinity to drive loss to 0).

Weight Decay (L2 Regularization) effectively constrains the weights to a "ball" of finite radius (Closed Interval). \[ ||w||^2 \le C \] Because the search space is now closed and bounded (a "compact set" in multivariable calculus terminology), and the Loss function is continuous, the EVT guarantees that a specific, optimal set of weights \(w^*\) exists. This is why regularized models are more stable.

4. Python: Searching for Extremes

find_extrema.py
import numpy as np

def analyze_function_on_interval(func, a, b, num_points=10000):
    # Create the closed interval grid
    x = np.linspace(a, b, num_points)
    y = func(x)
    
    # Simple Brute Force search (EVT guarantees these exist!)
    min_idx = np.argmin(y)
    max_idx = np.argmax(y)
    
    min_val = y[min_idx]
    max_val = y[max_idx]
    
    print(f"Stats for f(x) on [{a}, {b}]:")
    print(f"  Absolute Minimum: {min_val:.4f} at x = {x[min_idx]:.4f}")
    print(f"  Absolute Maximum: {max_val:.4f} at x = {x[max_idx]:.4f}")

# Example 1: Complex polynomial
# f(x) = x^4 - 3x^3 + 2 on [-1, 3]
f1 = lambda x: x**4 - 3*x**3 + 2
analyze_function_on_interval(f1, -1, 3)

# Example 2: Non-closed interval simulation?
# f(x) = x on (0, 1) -> effectively [0.0001, 0.9999] numerically
# The code will find distinct min/max, but mathematically they don't exist in (0,1).
f2 = lambda x: x
analyze_function_on_interval(f2, 0.0001, 0.9999)

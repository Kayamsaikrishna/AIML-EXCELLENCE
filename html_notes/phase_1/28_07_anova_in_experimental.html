Stats 1.8 Group Testing

ANOVA (Analysis of Variance)

Comparing multiple versions at once. Why you shouldn't just run ten T-Tests in a row.

The Multi-Comparison Problem

If you have 5 different website designs (A, B, C, D, E) and you compare them two-at-a-time using T-Tests, your chance of making a False Positive error (Type I) explodes.

ANOVA solves this by checking if ANY group is different from the others in a single "Omnibus" test.

1. The Logic of Variance

Within-Group Variance (\(SS_W\))

How much people within the SAME group vary (The "Noise").

Between-Group Variance (\(SS_B\))

How much the MEANS of the groups vary (The "Signal").

$$ F = \frac{\text{Between-Group Variance}}{\text{Within-Group Variance}} $$

- If \(F\) is large, it means the groups are genuinely different. - If \(F\) is close to 1, it means the group differences are just random noise.

2. ML Connection: Feature Selection

Pre-processing Dimensionality

The ANOVA F-Classifier

In scikit-learn, `SelectKBest(f_classif)` uses ANOVA to find which features are actually useful.

  • Feature Utility: If you have a categorical feature (like "Country") and a continuous target (like "Revenue"), ANOVA checks if the revenue means are different between countries. If they are all the same, the "Country" feature is useless noise and can be deleted.
  • Explainability: In a Random Forest, we often use "Feature Importance." But ANOVA provides a different, statistically rigorous view of which inputs strictly separate the output classes.
  • Factorial ANOVA: When we have multiple treatments (e.g., Change Button Color AND Change Price), ANOVA allows us to calculate the Interaction Effect between these two changes.
Engineer's Fact: ANOVA only tells you that "At least one group is different." It doesn't tell you *which* one. To find the winner, you must follow up with a Post-hoc Test (like Tukey’s HSD) which adjusts the p-values to keep your error rate safe.

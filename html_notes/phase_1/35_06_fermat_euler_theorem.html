Fermat's & Euler's Theorems

The Power of Powers. The fundamental theorems that describe the cyclic structure of modular exponentiation, forming the mathematical bedrock of RSA encryption.

Fermat's Little Theorem

If $p$ is a prime number and $a$ is an integer not divisible by $p$, then:

$$ a^{p-1} \equiv 1 \pmod p $$

Intuition: Raising numbers to the power of "prime minus one" resets them to 1. This is a specific case of Euler's Theorem.

1. Euler's Totient Function $\phi(n)$

To generalize Fermat's theorem to composite numbers, we need to count how many integers are coprime to $n$.

$$ \phi(n) = | \{ k \in \{1,\dots,n\} : gcd(k, n) = 1 \} | $$
  • If $p$ is prime: $\phi(p) = p - 1$.
  • If $n = p \times q$ (product of distinct primes): $\phi(n) = (p-1)(q-1)$.
  • This multiplicative property is what allows us to compute $\phi(N)$ easily if we know the factors, but makes it impossible if we don't.

2. Euler's Totient Theorem

For any integers $a$ and $n$ such that $gcd(a, n) = 1$:

$$ a^{\phi(n)} \equiv 1 \pmod n $$

This theorem implies that exponents work "modulo $\phi(n)$". If we want to compute $a^x \pmod n$, we can reduce the exponent: $x \equiv x' \pmod{\phi(n)}$.

Cryptography Key Generation

Application: RSA Key Generation

RSA relies entirely on Euler's Theorem. Here is the logic:

  1. Choose Primes: Pick large primes $p, q$. Compute $N = pq$.
  2. Compute Totient: $\phi(N) = (p-1)(q-1)$.
  3. Public Key ($e$): Choose $e$ coprime to $\phi(N)$ (often 65537).
  4. Private Key ($d$): Solve $ed \equiv 1 \pmod{\phi(N)}$.

Effect: Encryption is $c = m^e$. Decryption is $c^d = (m^e)^d = m^{ed}$. Since $ed = 1 + k\phi(N)$, by Euler's Theorem:

$m^{ed} = m^{1 + k\phi(N)} = m^1 \cdot (m^{\phi(N)})^k \equiv m \cdot 1^k \equiv m \pmod N$.

The Fermat Primality Test. If the equality fails, the number is definitely composite. If it holds, it is likely prime (though "Carmichael numbers" are rare exceptions). This is the basis for the Miller-Rabin test used in standard libraries.

Calculus 1.5 Continuous Logic

The Integral Test

Approximating steps with a smooth curve.

Summation via Integration

Sometimes summing a series \(\sum a_n\) is hard, but integrating the function \(f(x)\) is easy. If \(f(x)\) is continuous, positive, and decreasing, then:

\[ \int_{1}^{\infty} f(x) dx \quad \text{and} \quad \sum_{n=1}^{\infty} a_n \]

...either both converge or both diverge. They share the same destiny because the integral represents the "area under the curve" which bounds the sum of the rectangles (the series terms).

2. AI/ML Connection: Online Learning Regret

Bounding the Mistakes

In Online Learning, an AI processes an infinite stream of data. We want to bound its "Regret" (the total accumulated error over time). If the error at step \(t\) is \(r_t\), we want \(\sum r_t\) to be small (sub-linear).

Researchers use the Integral Test to prove convergence bounds. If we choose a learning rate of \(\eta_t = 1/\sqrt{t}\), we can prove that the total regret grows at most like \(\int \frac{1}{\sqrt{t}} dt\). This ensures that the AI's performance stabilizes over time, crucial for **High-Frequency Trading** algorithms that run forever.

3. Python: Sum vs Integral

integral_test.py
import numpy as np
from scipy.integrate import quad

# Series: 1/n^2 (Converges)
# Integral: 1/x^2 -> [-1/x] -> 1.0

def f(x):
    return 1 / (x**2)

# Specific partial sum
limit = 1000
partial_sum = sum(f(n) for n in range(1, limit))

# Improper Integral
integral_val, error = quad(f, 1, np.inf)

print(f"Sum (n={limit}): {partial_sum:.6f} (Approaches pi^2/6 approx 1.645)")
print(f"Integral (1 to inf): {integral_val:.6f}")
print("Both are finite. Convergence Confirmed.")

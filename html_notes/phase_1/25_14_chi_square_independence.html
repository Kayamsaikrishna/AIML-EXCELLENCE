Stats 1.5 Categorical

Chi-Square (\(\chi^2\)) Test for Independence

Testing if two categorical variables are related or if they occur independently of each other.

The Count Test

Unlike T-tests which use "Means," Chi-square uses Counts. - Null Hypothesis (\(H_0\)): The two variables are independent. - Alternative (\(H_a\)): The two variables are associated.

1. The Test Statistic

$$ \chi^2 = \sum \frac{(O - E)^2}{E} $$ $$ df = (\text{rows} - 1)(\text{cols} - 1) $$
  • \(O\): Observed Frequency (Actual counts in your table).
  • \(E\): Expected Frequency (Counts expected if the variables were independent).

2. Expected Frequency Calculation

$$ E = \frac{(\text{Row Total}) \times (\text{Column Total})}{\text{Grand Total}} $$

If the gap between Observed and Expected (\(O - E\)) is large, it means the categories aren't mixing randomly—they are influencing each other!

3. ML Connection: Feature Selection (Categorical)

Supervised Data Science

Is this feature useful?

You are building a churn prediction model. You have a categorical feature: Device Type (iOS, Android, Web) and your target: Churned (Yes, No).

The Chi-Square Test: 1. Create a contingency table (3 rows for devices, 2 columns for churn). 2. Calculate \(\chi^2\).

If the P-value is 0.85, Device Type is independent of Churn. It carries no predictive signal! You should drop this feature from your Random Forest or XGBoost model to reduce complexity.

Standard libraries like `sklearn.feature_selection.chi2` do exactly this to rank features.

04. Differentiation of Transcendental Functions

The calculus of e, log, and trig.

1. Exponential and Logarithmic

These functions are unique because they are "Self-Similar" under differentiation:

$$ \frac{d}{dx} e^x = e^x, \quad \frac{d}{dx} \ln(x) = \frac{1}{x} $$

For any base \(a\): \(\frac{d}{dx} a^x = a^x \ln(a) \).

2. Trigonometric Derivatives

  • \(\frac{d}{dx} \sin x = \cos x\)
  • \(\frac{d}{dx} \cos x = -\sin x\)
  • \(\frac{d}{dx} \tan x = \sec^2 x\)

3. AI Connection: The Sigmoid Property

The **Sigmoid Activation** \(\sigma(x) = \frac{1}{1 + e^{-x}}\) has a beautiful derivative property using these rules:

$$ \sigma'(x) = \sigma(x) (1 - \sigma(x)) $$

This means we can calculate the gradient using only the Output of the neuron, without re-calculating the expensive exponential. This is a massive speed-up in training hardware.

4. Python: Verifying Sigmoid Gradient

import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_grad(x):
    s = sigmoid(x)
    return s * (1 - s)

# Numerical test
h = 1e-7
x_val = 2.0
numerical_grad = (sigmoid(x_val + h) - sigmoid(x_val)) / h

print(f"Formula Grad:   {sigmoid_grad(x_val):.8f}")
print(f"Numerical Grad: {numerical_grad:.8f}")

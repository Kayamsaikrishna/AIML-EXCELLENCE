Calculus 1.6 High Dimensions

Functions of Several Variables

Welcome to the Hyperspace.

Beyond the Number Line

In single-variable calculus, a function \( f(x) \) maps one number to another: \( \mathbb{R} \to \mathbb{R} \). In Multivariable Calculus, a function maps a vector of inputs to an output: \[ f: \mathbb{R}^n \to \mathbb{R} \] or even to another vector: \[ f: \mathbb{R}^n \to \mathbb{R}^m \]

Understanding these mappings is crucial because modern datasets are never just single numbers; they are rows of data with dozens or thousands of columns (features).

2. AI/ML Connection: The Loss Landscape

The Billion-Dimensional Function

A Neural Network is essentially a massive multivariable function: \[ \mathcal{L}(w_1, w_2, \dots, w_n) \]

Here, the inputs aren't \(x\) and \(y\), but the weights of the network. If GPT-4 has 1.76 trillion parameters, then its Loss Function is a surface in 1.76 trillion-dimensional space. Training the AI means finding the lowest point (valley) on this unimaginably complex surface.

3. Python: Visualizing 3D Landscapes

plot_surface.py
import numpy as np
import matplotlib.pyplot as plt

# Define a function of two variables: z = x^2 + y^2 - cos(x*y*5)
# This creates a "bumpy bowl" shape, similar to non-convex loss functions
def f(x, y):
    return 0.5 * (x**2 + y**2) - 0.5 * np.cos(5 * x * y)

x = np.linspace(-2, 2, 100)
y = np.linspace(-2, 2, 100)
X, Y = np.meshgrid(x, y)
Z = f(X, Y)

fig = plt.figure(figsize=(10, 6))
ax = fig.add_subplot(111, projection='3d')
ax.plot_surface(X, Y, Z, cmap='plasma', alpha=0.8)
ax.set_title("Visualizing a Non-Convex Loss Surface")
plt.show()

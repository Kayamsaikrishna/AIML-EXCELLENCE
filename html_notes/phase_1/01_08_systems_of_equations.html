1. The Matrix Form: \( Ax = b \)

Solving equations one by one is for humans. Machines solve them all at once using matrices.

$$ \begin{cases} 3x + 2y = 10 \\ 4x - 5y = -3 \end{cases} \implies \begin{bmatrix} 3 & 2 \\ 4 & -5 \end{bmatrix} \begin{bmatrix} x \\ y \end{bmatrix} = \begin{bmatrix} 10 \\ -3 \end{bmatrix} $$

AI Insight: Batch Processing

In Deep Learning, we don't pass one image at a time. We pass a "Batch" (e.g., 32 images). This is essentially setting up a System of Equations where \( A \) is our batch of inputs.

2. When There Is No Solution (Overdetermined)

Real-world data is messy. You might have 1,000 data points (equations) but your line only has 2 parameters (slope and intercept). 1,000 equations for 2 unknowns is impossible to satisfy perfectly.

The Normal Equation (Linear Regression)

Since we can't solve \( Ax = b \), we find the \( x \) that minimizes the error \( ||Ax - b||^2 \).

$$ x = (A^T A)^{-1} A^T b $$

This formula instantly finds the "Line of Best Fit" without any training loops. It is the closed-form solution to Linear Regression.

3. Solving Systems in Python

Using NumPy to differentiate between exact solutions and least squares approximations.

import numpy as np

# 1. EXACT SOLUTION
# 2x + y = 5
# x - 3y = -1
A = np.array([[2, 1], [1, -3]])
b = np.array([5, -1])

try:
    x_exact = np.linalg.solve(A, b)
    print(f"Exact Solution: {x_exact}") # [2. 1.]
except np.linalg.LinAlgError:
    print("Matrix is Singular (No unique solution)")

# 2. LEAST SQUARES (Approximate)
# Suppose we have 3 points for a line (Overdetermined)
A_over = np.array([[1, 1], [2, 1], [3, 1]]) # x values + bias column
b_over = np.array([2, 2.8, 3.6]) # y values

# linalg.solve would CRASH here. We use lstsq
x_approx, residuals, rank, s = np.linalg.lstsq(A_over, b_over, rcond=None)
print(f"Best fit slope/bias: {x_approx}")
print(f"Error (Residuals): {residuals}")

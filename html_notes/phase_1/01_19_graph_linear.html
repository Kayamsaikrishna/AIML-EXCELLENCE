19. Graphing Linear Functions

The Geometry of Constant Change. The Tangent Line.

1. Slope-Intercept Form

$$ y = mx + b $$

Meaning of M and B

  • m (Slope): Rate of Change. Rise over Run. The "Gradient".
  • b (Intercept): Starting Value when \( x=0 \). The "Bias".

2. The Tangent Approximation

Most of Calculus (and Deep Learning) is based on the idea that if you zoom in close enough, everything looks like a line.

We calculate the "Gradient" (Slope) at a single point to know which way is "Down". This allows us to minimize error even on complex, curvy loss landscapes.

Stochastic Gradient Descent (SGD)

SGD updates weights using the linear slope:

$$ w_{new} = w_{old} - \text{learning\_rate} \cdot \text{slope} $$

3. Coding Slopes

Visualizing a line and its parameters using Matplotlib.

// Python: Plotting Linear Functions
import matplotlib.pyplot as plt
import numpy as np

# Define Line Parameters
m = -0.5  # Negative Slope (Going Down)
b = 3.0   # Intercept (Start at 3)

# Generate X values
x = np.linspace(-10, 10, 100)

# Calculate Y
y = m * x + b

# Plot
plt.figure(figsize=(6, 4))
plt.plot(x, y, label=f'y = {m}x + {b}', color='blue')
plt.axhline(0, color='black', linewidth=1)
plt.axvline(0, color='black', linewidth=1)
plt.grid(True, which='both')
plt.legend()
plt.title("Linear Function (The Tangent)")
plt.show()

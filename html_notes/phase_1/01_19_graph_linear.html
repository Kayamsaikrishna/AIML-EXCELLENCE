1. Slope: The First Derivative

The slope \( m \) tells you how sensitive \( y \) is to changes in \( x \).

$$ m = \frac{\Delta y}{\Delta x} = \text{Gradient} $$

In AI:

If the weight \( w \) (slope) is large, a tiny change in input features causes a huge change in output prediction. This can lead to instability (Gradient Explosion).

2. Why We Need Bias

Without the y-intercept \( b \), every line must pass through the origin \( (0,0) \).

In Classification, if we didn't have a Bias term, our Decision Boundary hyperplane would be forced to go through the origin, severely limiting what the model can learn.

3. Plotting Decision Boundaries

Visualizing how a linear model splits 2D space.

import numpy as np
import matplotlib.pyplot as plt

# Define a Linear Decision Boundary: 2x1 - x2 + 1 = 0
# x2 = 2x1 + 1 (m=2, b=1)

x1 = np.linspace(-5, 5, 100)
x2 = 2 * x1 + 1

# Points above line are Class A, below are Class B
# Let's check a random point (2, 2)
# 2(2) - 2 + 1 = 3 (>0), so Class A.

print("Constraint: 2*x1 - x2 + 1 > 0")
print(f" slope (m): 2 (Weight Ratio)")
print(f" intercept (b): 1 (Bias scaled)")

# This line cuts the plane in half.

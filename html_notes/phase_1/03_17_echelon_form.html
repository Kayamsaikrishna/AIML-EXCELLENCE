17. Row Echelon Form (REF) & Reduced (RREF)

Standardizing matrices for easy solving.

1. What is Echelon Form?

Row Echelon Form (REF)

  • All non-zero rows are above any zero rows.
  • The first non-zero entry in a row (Pivot) is to the right of the pivot in the row above.
  • Visualized as a "staircase" of zeros.

Reduced Row Echelon Form (RREF)

  • Satisfies REF criteria.
  • Every pivot is a 1.
  • Every pivot is the only non-zero entry in its column.

2. Canonical Representations in AI

Identifying Dependency

When you reduce a data matrix to RREF, you can immediately see which variables are dependent. If a row becomes all zeros, that sample was a linear combination of others. If a column doesn't have a pivot, that feature is redundant.

  • Basis Finding: The non-zero rows of an REF matrix form a basis for the row space.
  • Uniqueness: While REF is not unique, the RREF of a matrix is Guaranteed Unique.

3. Python: Computing RREF

import sympy as sp

# Sympy has a direct RREF method (Numpy does not!)
M = sp.Matrix([[1, 2, 3], [2, 4, 6], [1, 1, 1]])

# rref() returns (rref_matrix, pivot_tuple)
m_rref, pivots = M.rref()

print(f"RREF Matrix:\n{m_rref}")
print(f"Pivot Columns: {pivots}")

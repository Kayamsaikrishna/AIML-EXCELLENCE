1. Definitions

Row Echelon Form (REF)

  • All non-zero rows are above zero rows.
  • Leading coefficient (Pivot) is to the right of the row above.
  • Use: Solving systems via Back-Substitution.

Reduced REF (RREF)

  • All pivots are 1.
  • Pivots are the ONLY non-zero entry in their columns.
  • Use: Finding Null Space, Inverse, and Rank definitively.

2. Calculating RREF

Using SymPy (Symbolic Python) because floating point arithmetic makes exact RREF messy (0.0000001 != 0).

from sympy import Matrix

M = Matrix([
    [1, 2, 3],
    [2, 4, 6],
    [2, 5, 7]
])

# RREF calculation returns (Matrix, Pivot Indices)
rref_matrix, pivots = M.rref()

print("Original:")
print(M)
print("\nRREF:")
print(rref_matrix)
print(f"Pivots: {pivots}")
# Notice row 2 became 0s because row 2 was 2*row 1.

1. The Definition

The Unit Circle is the set of points \( (x, y) \) such that \( x^2 + y^2 = 1 \).

It links Algebra and Geometry perfectly. Every point is defined by:

$$ x = \cos(\theta), \quad y = \sin(\theta) $$

This means \( \sin^2(\theta) + \cos^2(\theta) = 1 \) is not magic, it's just the Pythagorean Theorem.

2. Feature Engineering: Time

If you feed hour "23" and hour "0" into a Neural Net, it thinks they are far apart. But in reality, they are adjacent.

Solution: Transform the scalar feature \( h \) into two vector features:

$$ h_{sin} = \sin(\frac{2\pi h}{24}), \quad h_{cos} = \cos(\frac{2\pi h}{24}) $$

Now, the distance matches reality. This is standard practice in Time Series Forecasting.

3. Encoding Cycles

Fixing the "Midnight Discontinuity".

import numpy as np
import pandas as pd

# Hours: 0 to 23
hours = np.array([0, 6, 12, 18, 23])

# Bad: Linear
print(f"Distance 0 to 23 (Linear): {abs(0-23)}") # 23 (Huge Gap!)

# Good: Cyclic
def encode_cyclic(data, max_val):
    sin_feat = np.sin(2 * np.pi * data / max_val)
    cos_feat = np.cos(2 * np.pi * data / max_val)
    return np.column_stack([sin_feat, cos_feat])

encoded = encode_cyclic(hours, 24)

# Calculate distance between 0 (Index 0) and 23 (Index 4)
# In Unit Circle space
dist = np.linalg.norm(encoded[0] - encoded[4])
print(f"Distance 0 to 23 (Cyclic): {dist:.4f}") 
# ~0.26 (Very Close!)

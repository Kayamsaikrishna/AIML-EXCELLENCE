09. Extreme Value Theorem (EVT)

Ensuring that a global optimum exists.

1. The Theorem

If a function \(f(x)\) is Continuous on a Closed Interval \([a, b]\), then \(f\) must attain an absolute maximum and an absolute minimum at least once in that interval.

$$ \exists c, d \in [a, b] \text{ s.t. } f(c) \leq f(x) \leq f(d) \quad \forall x \in [a, b] $$

2. Why Two Conditions?

  • Closed Interval: If the interval is open (e.g., \((0, 1)\)), a function like \(1/x\) could go to \(\infty\), never reaching a "max".
  • Continuity: If there's a jump, the function might skip over its peak.

3. AI Connection: Loss Minimization

In Machine Learning, we often constrain our weights to be within a certain range (e.g., Weight Clipping or L2 Regularization). These constraints create a Closed Set of possible model states. EVT guarantees that if our Loss function is continuous, there must exist an optimal set of weights that minimizes that loss. It gives us the mathematical "green light" to start searching.

4. Python: Finding Absolute Extrema

import numpy as np

def f(x): return x**2 - 4*x + 5

# Interval [0, 5]
x_vals = np.linspace(0, 5, 1000)
y_vals = f(x_vals)

abs_min = np.min(y_vals)
abs_max = np.max(y_vals)

print(f"On [0, 5]: Abs Min = {abs_min:.2f}, Abs Max = {abs_max:.2f}")

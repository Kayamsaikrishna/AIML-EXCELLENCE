Complexity Theory The Hierarchy

Complexity Classes: P, NP & EXP

Sorting the Unsolvable. Categorizing problems based on the resources required to solve them vs. the resources required to verify a solution.

Decision Problems

Complexity theory usually deals with Decision Problems—questions with a Yes/No answer. Even complex AI tasks (like "Find the best weight") can be phrased as a decision ("Is there a weight set with loss < 0.01?").

1. The Class P (Polynomial Time)

Problems that can be solved in polynomial time \(O(n^k)\). These are considered "tractable" or "efficiently solvable."

  • Sorting an array.
  • Finding the shortest path (Dijkstra).
  • Matrix multiplication.
  • AI Inference: Running a forward pass of a fixed-size neural network.

2. The Class NP (Nondeterministic Polynomial)

Problems where a proposed solution can be verified in polynomial time, even if finding the solution is hard.

If P is the set of "Easy to Solve" problems, NP is the set of "Easy to Check" problems.

P vs NP

The greatest unsolved question in CS: Is every problem that can be verified quickly also solvable quickly? (Most believe \(P \neq NP\)).

EXP (Exponential Time)

Problems that require \(O(2^{n^k})\) to solve. Example: Brute-forcing a 256-bit encryption key or solving a perfect game of Chess.

Optimization LLM

The Computational Reality of AI

  • Global Optimization: Finding the *absolute minimum* loss for a deep neural network is generally NP-Hard. This is why we use Stochastic Gradient Descent (SGD) to find *local* minima—which is in P.
  • Hyperparameter Search: Finding the optimal set of parameters from a combinatorial space is often an EXP or NP problem. We "approximate" it with Bayesian Optimization or Random Search.
  • Constraint Satisfaction: Many AI logic puzzles are in NP. We use heuristics (A*, branching) to solve them in "reasonable" time despite the theoretical worst-case.
  • Verification of Proofs: AI agents like *AlphaProof* or *Lean-based* models operate in the realm of verification—checking if a mathematical step is valid (P) while searching for the next step (NP).

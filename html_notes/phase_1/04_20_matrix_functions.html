1. Definition

How do we compute \( e^A \) or \( \sin(A) \)? We use the Taylor Series definition.

$$ e^A = I + A + \frac{A^2}{2!} + \frac{A^3}{3!} + \dots $$

If \( A = PDP^{-1} \), this collapses to \( P e^D P^{-1} \), where \( e^D \) is just the exponential of each diagonal element.

2. Neural ODEs & Diffusion

Continuous-depth neural networks (Neural ODEs) model the hidden state as \( \frac{dh}{dt} = f(h, t) \).

Linear dynamics \( \frac{dh}{dt} = Ah \) have the closed-form solution \( h(t) = e^{At} h(0) \). Understanding matrix exponentials is key to solving and creating stable Diffusion probablistic models.

3. SciPy expm

Note: never compute \( e^A \) by simply taking the exponential of each element!

import numpy as np
from scipy.linalg import expm

# A 90 degree rotation generator
A = np.array([
    [0, -np.pi/2],
    [np.pi/2, 0]
])

# Matrix Exponential (Rotation Matrix at t=1)
Rot = expm(A)

print("Matrix Exponential:")
print(Rot.round(2))
# Expected: [[0, -1], [1, 0]]

# WRONG way (Element-wise)
Wrong = np.exp(A)
print("\nElement-wise Exp (WRONG):")
print(Wrong.round(2))

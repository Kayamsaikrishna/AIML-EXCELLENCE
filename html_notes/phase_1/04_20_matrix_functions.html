20. Matrix Functions (Exp, Log, Sqrt)

Applying calculus functions to entire matrices.

1. The Definition via Eigendecomposition

How do you compute \(e^{\mathbf{A}}\)? You can't just apply \(e\) to every entry. However, if \(\mathbf{A} = \mathbf{PDP}^{-1}\), we define:

$$ f(\mathbf{A}) = \mathbf{P} f(\mathbf{D}) \mathbf{P}^{-1} $$

Where \(f(\mathbf{D})\) is a diagonal matrix obtained by applying \(f\) to the eigenvalues along the diagonal.

2. The Matrix Exponential (\(e^{\mathbf{A}}\))

Solving Dynamic Systems

In Physics and some Continuous Neural Networks (Neural ODEs), if we have \(\frac{d\mathbf{x}}{dt} = \mathbf{Ax}\), the solution is exactly \(\mathbf{x}(t) = e^{\mathbf{A}t}\mathbf{x}(0)\). The eigenvalues of \(\mathbf{A}\) dictate whether the system decays to zero, explodes, or oscillates.

3. Matrix Square Root (\(\mathbf{A}^{1/2}\))

In Whiteing Transformations (pre-processing data to have zero mean and identity covariance), we need the inverse square root of the covariance matrix \(\mathbf{S}^{-1/2}\). This ensures all features are perfectly uncorrelated and have unit variance.

4. Python: Exponential vs Element-wise

import numpy as np
from scipy.linalg import expm

A = np.array([[1, 2], [0, 1]])

# Element-wise exp (Usually WRONG for math)
element_exp = np.exp(A)

# Proper Matrix Exponential
matrix_exp = expm(A)

print(f"Matrix Exp:\n{matrix_exp}")
# Note: expm(A) != exp(A)_ij

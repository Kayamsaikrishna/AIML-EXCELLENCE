09. Computational Graphs

The structural representation of calculus.

1. Anatomy of a Graph

A Computational Graph is a directed graph where Nodes represent operations (add, multiply, exp) or variables, and Edges represent the flow of data. This is how a computer "Sees" a mathematical equation.

2. Forward and Backward Passes

  • Forward: Compute values from inputs to outputs following the arrows.
  • Backward: Compute gradients from outputs to inputs by traversing the graph against the arrows using the chain rule.

3. AI/ML Connection: Dynamic vs. Static Graphs

Architecture Paradigms

Computational graphs define the "Logic" of your AI model.

TensorFlow 1.x used Static Graphs: you define the entire math graph first, then run data through it. This is fast but rigid. PyTorch popularized Dynamic Graphs (Imperative): the graph is built on-the-fly as code executes. This allows for complex logic like `if` statements or variable-length loops inside a neural network. Understanding the graph structure of calculus is essential for optimizing AI performance; it's what allows compilers (like XLA or TorchScript) to fuse operations and run math directly on GPU hardware at the speed of light.

4. Python: A Simple DAG

# Equation: z = (a + b) * c
# Graph:
# Node 1: d = a + b
# Node 2: z = d * c

# To calculate dz/da:
# dz/da = (dz/dd) * (dd/da) 
#       = c * 1 = c

a, b, c = 2, 3, 4
d = a + b
z = d * c

dz_dc = d
dz_dd = c
dd_da = 1

dz_da = dz_dd * dd_da
print(f"Gradient w.r.t a: {dz_da}")

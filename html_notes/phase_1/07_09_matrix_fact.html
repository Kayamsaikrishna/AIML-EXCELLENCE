1. Non-Negative Matrix Factorization (NMF)

Unlike SVD which allows negative numbers, NMF forces \( X \approx WH \) where \( W, H \ge 0 \).

This leads to "parts-based" learning. In facial recognition, NMF learns to build faces from eyes, noses, and mouths (additive parts), whereas SVD uses "Eigenfaces" which are holistic and ghostly.

2. Collaborative Filtering

We decompose the Rating Matrix \( R \) (Users \(\times\) Movies) into \( U \) (User preferences) and \( V \) (Movie attributes).

$$ \text{Rating}_{ij} \approx \mathbf{u}_i \cdot \mathbf{v}_j $$

This reduces a massive sparse problem to a low-rank k-dimensional problem, capturing "Latent" concepts like "Action vs Romance" or "Serious vs Funny".

3. NMF in Action

import numpy as np
from sklearn.decomposition import NMF

# Data: 4 Users, 5 Movies (0 = Unseen)
X = np.array([
    [5, 4, 0, 1, 0], # User 1: Likes Action
    [0, 0, 5, 4, 0], # User 2: Likes Comedy
    [4, 5, 0, 0, 1], # User 3: Likes Action
    [1, 0, 4, 5, 0]  # User 4: Likes Comedy
])

# Factorize into 2 latent components
model = NMF(n_components=2, init='random', random_state=42)
W = model.fit_transform(X) # User Matrix
H = model.components_      # Movie Matrix

print("User Factors W (Preference):\n", W.round(2))
# Users 1&3 should map to feature 0, Users 2&4 to feature 1

print("\nMovie Factors H (Attributes):\n", H.round(2))

# Reconstruct
X_hat = W @ H
print("\nPredicted Ratings:\n", X_hat.round(1))

Optimization 1.7 Loss Landscapes

Critical Points & Loss Surfaces

Navigating the high-dimensional peaks and valleys of Neural Networks.

The Foundation of Training

Training a model means finding the best parameters \(\mathbf{w}\) that minimize a **Loss Function** \(L(\mathbf{w})\). This is equivalent to finding the lowest point in a mountainous landscape.

The "flat" spots where the slope is zero are called Critical Points. \[ \nabla L(\mathbf{w}) = \mathbf{0} \]

2. AI/ML Connection: The Saddle Point Problem

Why SGD Gets Stuck

In low dimensions (1D or 2D), we worry about getting stuck in "Local Minima" (small potholes). However, in Deep Learning (billions of dimensions), Saddle Points are exponentially more common.

A saddle point curves up in some directions and down in others (like a Pringles chip). Standard Gradient Descent slows down significantly near saddle points because the gradient \(\nabla L\) becomes tiny, deceiving the optimizer into thinking it has converged.

3. Python: Visualizing the Landscape

plot_loss_surface.py
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# Define a function with a Saddle Point at (0,0)
# f(x,y) = x^2 - y^2 (The classic Monkey Saddle)
def loss_function(x, y):
    return x**2 - y**2

x = np.linspace(-2, 2, 30)
y = np.linspace(-2, 2, 30)
X, Y = np.meshgrid(x, y)
Z = loss_function(X, Y)

fig = plt.figure(figsize=(10, 7))
ax = fig.add_subplot(111, projection='3d')

# Plot surface
surf = ax.plot_surface(X, Y, Z, cmap='coolwarm', edgecolor='none', alpha=0.8)

# Mark the Critical Point (0,0,0)
ax.scatter([0], [0], [0], color='red', s=100, label='Saddle Point')

ax.set_title("Loss Landscape: Saddle Point")
ax.set_xlabel("Weight w1")
ax.set_ylabel("Weight w2")
ax.set_zlabel("Loss")
plt.legend()
plt.show()

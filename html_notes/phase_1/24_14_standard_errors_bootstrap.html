Standard Errors via Bootstrap

Using code to calculate the "wiggle room" of any algorithm, no matter how complex.

The End of Calculus?

In classic stats, to find the Standard Error of a complex estimator, you had to perform heavy calculus (Delta Method).

With Bootstrap Standard Error, you just run your algorithm 500 times on different resamples and calculate the Standard Deviation of the outputs.

1. The Formula

$$ SE_{boot} = \sqrt{\frac{1}{B-1} \sum_{b=1}^{B} (\hat{\theta}_b^* - \bar{\hat{\theta}}^*)^2} $$
  • \(B\): Number of Bootstrap resamples.
  • \(\hat{\theta}_b^*\): The statistic calculated from resample \(b\).
  • \(\bar{\hat{\theta}}^*\): The average of all bootstrap statistics.

2. ML Connection: Feature Selection Stability

Supervised Interpretability

Are these features actually important?

Imagine you run a Lasso Regression and it says Feature A's weight is 5.0. Is that 5.0 stable? If you had a different dataset, would it be 0.0?

The Bootstrap Test: 1. Generate 200 bootstrap versions of your training data. 2. Train the model on each. 3. Record the weight of Feature A for each. 4. Calculate the Bootstrap Standard Error.

If the weight is 5.0 and the SE is 0.5, the feature is highly reliable. If the weight is 5.0 and the SE is 6.0, the feature's importance is just a fluke of your specific dataset—it's not a real signal!

Model Sensitivity

This is often used for calculating the Standard Error of Hyperparameters or the stability of Cluster Centroids in K-Means.

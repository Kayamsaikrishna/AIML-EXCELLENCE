Prob 1.4 Corollaries

Properties of Probability

What follows from the Three Axioms.

Derived Rules

From the three axioms, we can derive everything else:

  • Empty Set: \(P(\emptyset) = 0\).
  • Monotonicity: If \(A \subseteq B\), then \(P(A) \le P(B)\).
  • Bound: \(0 \le P(E) \le 1\).

2. ML Connection: ROC Curves

Thresholds

In binary classification, we choose a threshold \(T\) to decide class 1 or 0. Let \(S\) be the set of samples classified as positive. If we lower the threshold, the set of positive samples grows ($S_{T=0.9} \subseteq S_{T=0.5}$). Due to Monotonicity, the Recall (True Positive Rate) can never decrease as we lower the threshold.

3. Python: Monotonicity

monotonicity.py
# Set A: Even numbers < 10 {2,4,6,8}
# Set B: All numbers < 10 {1..9}
# A is a subset of B.

P_A = 4/10
P_B = 9/10

print(f"P(A)={P_A}, P(B)={P_B}")
if P_A <= P_B:
    print("Monotonicity Holds: Subset prob is smaller.")

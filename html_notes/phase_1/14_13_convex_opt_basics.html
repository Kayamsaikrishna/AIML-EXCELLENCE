Optimization 1.7 The Holy Grail

Convex Optimization Basics

When solving the problem is guaranteed.

Reliability Engineering

In most engineering fields (Control Theory, Signal Processing), we design systems to be Convex. Why? Because Convex Problems are Solvable.

We have efficient polynomial-time algorithms (Interior Point Methods) that can find the global minimum to high precision. If you can frame your AI problem as a Convex Optimization problem (e.g., SVM is a Quadratic Program), you solve it once and solve it strictly.

2. AI/ML Connection: The Relaxation

Approximating the Hard Stuff

Many real-world AI problems are discrete (combinatorial) and Non-Convex (NP-Hard). A common strategy is Convex Relaxation:

  • Original: Find the sparsest solution (L0 Norm, NP-Hard).
  • Relaxed: Find the solution with smallest L1 Norm (Convex L1 Regularization).

This turns an impossible problem into a solvable one (Lasso Regression), often yielding almost the same answer.

3. Python: Solving with CVXPY

cvxpy_demo.py
import cvxpy as cp
import numpy as np

# Problem: Least Squares with Non-Negativity Constraints
# Minimize ||Ax - b||^2 subject to x >= 0

np.random.seed(1)
m, n = 10, 5
A = np.random.randn(m, n)
b = np.random.randn(m)

# Define variables
x = cp.Variable(n)

# Define Objective
cost = cp.sum_squares(A @ x - b)
objective = cp.Minimize(cost)

# Define Constraints
constraints = [x >= 0]

# Solve
prob = cp.Problem(objective, constraints)
prob.solve()

print(f"Optimal value: {prob.value:.4f}")
print(f"Optimal x: {x.value}")
# Notice all x values are >= 0 (or significantly close to 0)

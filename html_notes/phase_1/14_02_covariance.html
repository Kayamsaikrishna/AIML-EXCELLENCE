02. Covariance and Correlation Matrices

Capturing dependencies between features.

1. The Definition

The Covariance Matrix \(\mathbf{\Sigma}\) (Sigma) measures how each pair of features in a dataset \(\mathbf{X}\) vary together. For a mean-centered matrix \(\mathbf{X}\):

$$ \mathbf{\Sigma} = \frac{1}{m-1} \mathbf{X}^T\mathbf{X} $$
  • Diagonal Elements: Variance of each feature.
  • Off-diagonal Elements: Covariance between different features.

2. Geometry: The Uncertainty Ellipsoid

The Covariance matrix defines the shape of a multivariate Gaussian distribution. The Eigenvectors of \(\mathbf{\Sigma}\) are the principal axes of the ellipsoid, and the Eigenvalues are the lengths of those axes.

3. AI Connection: PCA

Principal Component Analysis (PCA) is simply finding the eigenvectors of the covariance matrix and projecting data onto the ones with the largest eigenvalues (most variance).

4. Python: Manual Covariance

import numpy as np

# Sample Data
X = np.array([[1, 2], [3, 4], [5, 6], [7, 8]])

# Mean Center
X_centered = X - np.mean(X, axis=0)

# Covariance Matrix (Manual)
m = X.shape[0]
cov_manual = (X_centered.T @ X_centered) / (m - 1)

# Covariance (NumPy)
cov_np = np.cov(X, rowvar=False)

print(f"Manual:\n{cov_manual}")
print(f"NumPy:\n{cov_np}")

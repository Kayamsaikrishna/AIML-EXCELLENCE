03. Probability Axioms (Kolmogorov Axioms)

The three pillars of mathematical probability.

1. The Foundation

In 1933, Andrey Kolmogorov formalized probability with three simple rules. Any function that assigns a number to an event must obey these rules to be considered a measure of "Probability".

2. The Three Axioms

  • Axiom 1 (Non-negativity): For any event \(A\), the probability is a non-negative real number: \(P(A) \geq 0\).
  • Axiom 2 (Unitarity): The probability of the entire sample space \(S\) is exactly 1: \(P(S) = 1\).
  • Axiom 3 (Sigma-Additivity): If events \(A_1, A_2, \dots\) are mutually exclusive (disjoint), then: $$ P(A_1 \cup A_2 \cup \dots) = \sum_{i} P(A_i) $$

3. AI/ML Connection: The Softmax Layer

Enforcing the Axioms

When an AI model predicts a class, it outputs "Confidence Scores". To turn these scores into valid probabilities, we use the Softmax Function.

The Softmax function is mathematically designed to enforce Axiom 1 (by exponentiating, ensuring all values are > 0) and Axiom 2 (by dividing by the sum, ensuring all output probabilities add up to exactly 1.0). If an AI model's outputs didn't obey these Kolmogorov axioms, we couldn't use them to calculate Expected Rewards in Reinforcement Learning or Risk in financial models. These axioms are the "Checklist" that every modern AI output must satisfy.

4. Python: Softmax Probability Check

import numpy as np

def softmax(logits):
    exps = np.exp(logits)
    return exps / np.sum(exps)

logits = [2.0, 1.0, 0.1]
probs = softmax(logits)

print(f"Probabilities: {probs}")
print(f"Axiom 1 (Non-negative): {np.all(probs >= 0)}")
print(f"Axiom 2 (Sum to 1): {np.isclose(np.sum(probs), 1.0)}")

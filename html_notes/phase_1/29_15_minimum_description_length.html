15. Minimum Description Length (MDL)

Learning is compression.

1. The Best Model

The Minimum Description Length (MDL)** principle states that the best model is the one leads to the shortest description of the data. This description consists of two parts:

$$ L(\text{Total}) = L(\text{Model}) + L(\text{Data} | \text{Model}) $$
  • L(Model): How complex is the program or equation?
  • L(Data | Model): How well does the model explain the data (Residuals)?

2. The Trade-off

If you have a very complex model, $L(\text{Data} | \text{Model})$ is small (near zero error), but $L(\text{Model})$ is huge. If you have a simple model, $L(\text{Model})$ is small, but $L(\text{Data} | \text{Model})$ is large. MDL finds the "Sweet Spot."

3. AI/ML Connection: Model Selection and BIC

The Rationale for Regularization

In AI, MDL is the philosophical root of AIC (Akaike Info Criterion)** and BIC (Bayesian Info Criterion)**.

When you use L1 (Lasso) or L2 (Ridge) regularization, you are essentially adding a cost to $L(\text{Model})$. You are telling the model: "Every weight you use must pay for itself in terms of error reduction." In Neural Network Pruning**, we delete neurons that don't add enough "Benefit" to justify their "Cost" (the memory they take). Recent research in **Deep Learning Theory** suggests that SGD naturally biases models towards low-MDL solutions. This is why giant neural networks can generalize despite having billions of parameters: they are effectively "Finding the simplest code" that describes the manifold of the inputs. It is the proof that Learning IS Compression.

4. Practical Logic

If you find that compressing your dataset with ZIP or LZ4 makes the file 90% smaller, that's exactly how much "Learning" a model can potentially do. If the file is 100% random, no model can learn it. MDL allows AI engineers to estimate the Predictive Limit of their datasets.

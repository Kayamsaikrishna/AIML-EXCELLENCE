04. Linear Regression Mathematical Formulation

The first bridge to machine learning.

1. The Problem Space

Given a dataset of inputs \(\mathbf{X} \in \mathbb{R}^{m \times n}\) and targets \(\mathbf{y} \in \mathbb{R}^m\), we assume a linear relationship:

$$ \mathbf{y} \approx \mathbf{X}\mathbf{w} $$

Where \(\mathbf{w}\) are the weights we need to learn.

2. The Loss Function

We define the Mean Squared Error (MSE) in vector form:

$$ L(\mathbf{w}) = \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2_2 = (\mathbf{y} - \mathbf{X}\mathbf{w})^T(\mathbf{y} - \mathbf{X}\mathbf{w}) $$

3. The Analytical Solution

To find the minimum, we set the gradient to zero:

$$ \nabla_{\mathbf{w}} L(\mathbf{w}) = -2\mathbf{X}^T(\mathbf{y} - \mathbf{X}\mathbf{w}) = \mathbf{0} $$

Rearranging gives the Normal Equation:

$$ \mathbf{w}^* = (\mathbf{X}^T\mathbf{X})^{-1}\mathbf{X}^T\mathbf{y} $$

4. Regularization (The L2 Bridge)

If \(\mathbf{X}^T\mathbf{X}\) is singular (multicollinearity), we add a small diagonal term (Tikhonov Regularization):

$$ \mathbf{w}^*_{ridge} = (\mathbf{X}^T\mathbf{X} + \lambda \mathbf{I})^{-1}\mathbf{X}^T\mathbf{y} $$

This is why Ridge Regression is always solvable!

5. Python: Implementation

import numpy as np

# Synthetic Data
X = np.array([[1, 1], [1, 2], [1, 3]]) # Augmented with bias
y = np.array([2, 4, 6])

# Solve analytically
w = np.linalg.inv(X.T @ X) @ X.T @ y

print(f"Learned Weights: {w}") # [0, 2] -> f(x) = 0 + 2*x

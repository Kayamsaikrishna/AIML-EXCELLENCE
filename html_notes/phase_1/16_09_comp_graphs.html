ML Calc 1.9 The Blueprint

Computation Graphs

Visualizing mathematical dependencies.

DAGs (Directed Acyclic Graphs)

Every calculation in a computer can be represented as a Graph. Nodes are Operations (add, mul, tanh). Edges are Tensors (data flowing between ops).

This abstraction allows Deep Learning frameworks to optimize execution (fusing operations) and run parallel streams on GPUs automatically.

2. ML Connection: Dynamic vs Static

Define-by-Run

Static Graphs (TensorFlow 1.x): You define the graph once, compile it, and run it many times. Fast but rigid. Debugging is a nightmare.

Dynamic Graphs (PyTorch): The graph is built on-the-fly as you execute code. You can use Python `if` loops and print statements. This flexibility is why researchers love PyTorch.

3. Python: Traversing the Graph

graph_inspect.py
import torch

x = torch.tensor(1.0, requires_grad=True)
y = x * 2
z = y ** 2

# We can inspect the graph attached to z
print(f"z grad_fn: {z.grad_fn}")
# PowBackward0

print(f"y grad_fn: {z.grad_fn.next_functions[0][0]}")
# MulBackward0 (The operation that created y)

# This linked list of functions IS the computation graph.
# .backward() just traverses this list.

04. Probability Density Function (PDF)

Assigning likelihood to continuous intervals.

1. What is a PDF?

For a continuous random variable $X$, the Probability Density Function (PDF), denoted as $f_X(x)$, describes the relative likelihood of $X$ taking on a value. The probability that $X$ falls in the interval $[a, b]$ is the integral of the PDF over that interval:

$$ P(a \le X \le b) = \int_a^b f_X(x) \, dx $$

2. Key Properties

  • $f_X(x) \ge 0$ for all $x$ (Densities cannot be negative).
  • The total area under the curve must be 1: $\int_{-\infty}^{\infty} f_X(x) \, dx = 1$.
  • Note: $f_X(x)$ can be greater than 1, as it is a density, not a probability.

3. AI/ML Connection: Gaussian Noise and Sampling

The Math of Distributions

The most famous PDF in AI is the **Normal (Gaussian) Distribution**.

Most AI models assume that data noise or error follows a Gaussian PDF. In Diffusion Models (like Stable Diffusion), the process of generating an image involves starting with "Pure Gaussian Noise" and iteratively refining it. Each step of this refinement is a movement through a high-dimensional PDF. Furthermore, in **Anomaly Detection**, a system might flag a data point as an outlier if its value falls in a region where the PDF is extremely low (the "tails" of the distribution). Understanding PDFs is what allows us to mathematically define what is "normal" and what is "rare" for an AI system.

4. Python: Plotting the Standard Normal PDF

import numpy as np
import matplotlib.pyplot as plt
from scipy.stats import norm

# Range of values for calculation
x = np.linspace(-4, 4, 100)

# Calculate PDF values using scipy
pdf_values = norm.pdf(x, loc=0, scale=1) # Mean=0, StdDev=1

# The value at x=0 is ~0.4, which is a density, not a prob!
print(f"Density at x=0: {norm.pdf(0, 0, 1):.4f}")

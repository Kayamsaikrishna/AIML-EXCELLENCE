1. The Spectral Theorem

If \( A \) is symmetric real (\( A = A^T \)):

  1. All eigenvalues \( \lambda \) are Real (no imaginary parts).
  2. Eigenvectors corresponding to distinct eigenvalues are Orthogonal.
  3. \( A \) is orthogonally diagonalizable: \( A = Q \Lambda Q^T \) where \( Q \) is an Orthogonal matrix (\( Q^{-1} = Q^T \)).

2. The Loss Landscape

The Hessian Matrix (matrix of second derivatives) of a loss function is always Symmetric.

Therefore, its eigenvectors form an orthogonal coordinate system describing the principal curvatures (valleys and ridges) of the loss surface. The eigenvalues tell us if we are at a minimum (all positive) or a saddle point (mixed signs).

3. eigh vs eig

Use `eigh` (Hermitian/Symmetric) for faster and more numerically stable results on symmetric matrices.

import numpy as np

# A symmetric matrix
A = np.array([
    [2, 1],
    [1, 2]
])

# Use numpy.linalg.eigh (specialized for symmetric)
vals, vecs = np.linalg.eigh(A)

print("Eigenvalues (Real):")
print(vals)
# [1, 3]

print("\nEigenvectors (Columns of Q):")
print(vecs)
# [[-0.707, 0.707], [0.707, 0.707]] approx

# Verification: Orthogonality
dot_prod = np.dot(vecs[:,0], vecs[:,1])
print(f"\nDot Product (Should be 0): {dot_prod:.2e}")

# Verification: A = Q L Q.T
reconstructed = vecs @ np.diag(vals) @ vecs.T
print("\nReconstructed:")
print(reconstructed.round(2))

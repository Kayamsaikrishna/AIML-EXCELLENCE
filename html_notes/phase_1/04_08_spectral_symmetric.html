08. Spectral Theorem (Real Symmetric)

The crown jewel of Linear Algebra for Data Science.

1. The Power of Symmetry

If \(\mathbf{A}\) is a real symmetric matrix (\(\mathbf{A} = \mathbf{A}^T\)), it possesses extraordinary properties:

  • Real Eigenvalues: All eigenvalues are guaranteed to be real.
  • Orthogonal Eigenvectors: Eigenvectors corresponding to different eigenvalues are guaranteed to be perpendicular (Orthogonal).
  • Orthogonal Diagonalization: \(\mathbf{A} = \mathbf{QDQ}^T\), where \(\mathbf{Q}\) is an orthogonal matrix (\(\mathbf{Q}^T\mathbf{Q} = \mathbf{I}\)).

2. Geometry: Pure Stretching

A symmetric matrix represents a purely "stretching" transformation along orthogonal axes. There is no rotation involved in the transformation once align with the principal axes.

Symmetric matrices transform unit balls into orthogonal ellipsoids.

3. AI Application: Covariance & PCA

Principal Components

A **Covariance Matrix** is always symmetric. The Spectral Theorem tells us we can find orthogonal directions (Principal Components) along which our data varies the most. The eigenvalues tell us the **Variance** along those directions.

4. Python: Orthogonal Check

import numpy as np

# A symmetric matrix
A = np.array([[4, 2], [2, 3]])

# Get Q (eigenvectors) and D (vals)
eigenvals, Q = np.linalg.eigh(A) # eigh is optimized for symmetric

# Check orthogonality of Q
ortho_test = Q.T @ Q
print(f"Q.T @ Q (Should be Identity):\n{np.round(ortho_test, 5)}")

# Reconstruction
D = np.diag(eigenvals)
print(f"Reconstructed A:\n{Q @ D @ Q.T}")

01. Matrix Definition & Notation

Organizing data into grids for parallel processing.

1. What is a Matrix?

A matrix is a rectangular array of numbers arranged in rows and columns. In AI, a matrix is formally known as a Rank-2 Tensor.

$$ \mathbf{A} = \begin{bmatrix} a_{11} & a_{12} & \dots & a_{1n} \\ a_{21} & a_{22} & \dots & a_{2n} \\ \vdots & \vdots & \ddots & \vdots \\ a_{m1} & a_{m2} & \dots & a_{mn} \end{bmatrix} \in \mathbb{R}^{m \times n} $$

Dimension Standards

  • m: Number of rows (usually represents samples in a batch).
  • n: Number of columns (usually represents features or dimensions).
  • Index: \( a_{ij} \) refers to the element at the \( i \)-th row and \( j \)-th column.

2. Matrices in the AI Workflow

Batching Data

Instead of passing one vector at a time to a model, we stack them into a matrix. This allows GPUs to perform SIMD (Single Instruction, Multiple Data) operations, dramatically speeding up training.

  • Batch Size: The number of rows (\( m \)) in the input matrix.
  • Weight Matrix: The parameters of a layer are stored as a matrix where each column corresponds to a single neuron.

3. Python: Creating Matrices in Numpy

import numpy as np

# Creating a 3x2 Matrix
A = np.array([
    [1, 2],
    [3, 4],
    [5, 6]
])

print(f"Matrix A:\n{A}")
print(f"Shape: {A.shape}") # (3, 2)
print(f"Element a[1,0]: {A[1,0]}") # Output: 3 (Zero-indexed)

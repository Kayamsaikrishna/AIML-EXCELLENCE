Calculus 1.3 Linearization

Geometric Interpretation

If you zoom in enough, everything looks like a line. This simple fact allows us to conquer complexity.

Local Linearity

The most profound insight of calculus is that curved functions act like straight lines locally. The line that best mimics the curve at a specific point is the Tangent Line.

1. The Tangent Line Equation

The derivative \(f'(a)\) gives us the Slope of the tangent line at \(x = a\). Using the point-slope form \(y - y_1 = m(x - x_1)\), we get the equation of the linear approximation:

\[ L(x) = f(a) + f'(a)(x - a) \]

The curve is complex; the line is simple. Near 'a', they are twins.

2. AI/ML Connection: The Manifold Hypothesis

Why Gradient Descent Works

A Neural Network's Loss Function is a wildly complex, high-dimensional surface ("Manifold"). It has hills, valleys, and twists.

However, Gradient Descent relies on the fact that at any tiny specific point, the surface looks like a tilted flat sheet (a Hyperplane).

\[ \Delta \text{Loss} \approx \nabla \text{Loss} \cdot \Delta \text{Weights} \]

Because the surface is locally linear, we can just "slide downhill" along the steepest slope. If calculus didn't imply local linearity, simple optimization algorithms would fail.

3. Python: Constructing the Tangent

tangent_line.py
import numpy as np

def f(x):
    # A simple parabola
    return x**2 - 2*x + 1

def df_analytical(x):
    # Derivative is 2x - 2
    return 2*x - 2

def get_tangent_line_func(x_point):
    # Creates the linear function L(x) = f(a) + f'(a)(x-a)
    slope = df_analytical(x_point)
    y_point = f(x_point)
    
    # Return a lambda function for the line
    return lambda x: y_point + slope * (x - x_point), slope

# Analyze at x=3
a = 3.0
tangent_line, slope = get_tangent_line_func(a)

print(f"Function f(x) = x^2 - 2x + 1")
print(f"At x={a}:")
print(f"  True value f({a}) = {f(a)}")
print(f"  Slope f'({a}) = {slope}")
print(f"  Tangent Equation: y = {f(a)} + {slope}(x - {a})")

# Test Approximation
x_near = 3.01
true_val = f(x_near)
approx_val = tangent_line(x_near)

print(f"\nChecking Approximation at x={x_near}:")
print(f"  True Value: {true_val:.6f}")
print(f"  Linear Approx: {approx_val:.6f}")
print(f"  Difference: {abs(true_val - approx_val):.8f}")
# The difference is on the order of (dx)^2, extremely small!

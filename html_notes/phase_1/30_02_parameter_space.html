02. Parameter Space ($\Theta$)

Defining the boundaries of what is possible.

1. Definition

The Parameter Space is the set of all possible values that a parameter (or vector of parameters) can take for a given statistical model. It is usually denoted by the Greek letter $\Theta$.

$$ \theta \in \Theta $$

For example, if we are modeling the probability of a coin flip, the parameter space for $p$ is the interval $[0, 1]$. If we are modeling heights (Normal distribution), the parameter space for $\sigma$ is $(0, \infty)$.

2. Constrained vs. Unconstrained

In many problems, the parameter space is limited by mathematical or physical reality. Variance cannot be negative; probabilities cannot exceed 1. Defining $\Theta$ correctly is the first step in any optimization or inference problem—it tells the "search engine" where it is allowed to look for the truth.

3. AI/ML Connection: Weights, Biases, and Hyperparameters

The Terrain of Learning

In AI, the Parameter Space is the Configuration Space of your model.

For a **Neural Network**, $\Theta$ is the massive high-dimensional space containing every possible combination of Weights ($W$) and Biases ($b$). When we train a model, we are performing a search through this "Parameter Space" to find the specific $\theta$ that minimizes our loss function. In **Automated Machine Learning (AutoML)**, we define a Hyperparameter Space (e.g., Learning Rate $\in [1e-5, 1]$, Batch Size $\in \{16, 32, 64\}$) and use search algorithms to find the best configuration. If your parameter space is too small, your AI can't learn the truth (Underfitting); if it's too large or poorly defined, your optimizer might get lost in a "featureless desert" of noise.

4. Python: Defining Bounds for Optimization

from scipy.optimize import minimize

# Objective: Find 'p' that maximizes likelihood
# Constraint: p must be in [0, 1] (The Parameter Space)

def objective(p):
    # Log-likelihood example for 7 successes in 10 flips
    return -(7 * np.log(p) + 3 * np.log(1 - p))

# Search only within the valid Parameter Space
result = minimize(objective, x0=0.5, bounds=[(1e-6, 1-1e-6)])

print(f"Optimal p within Theta: {result.x[0]:.2f}")

10. Non-parametric Bootstrap

Resampling without assumptions.

1. The Concept

The Non-parametric Bootstrap is the pure form of bootstrapping where we make no assumptions about the underlying population distribution ($F$). Instead, we resample from the Empirical Distribution Function ($F_n$) of the sample itself.

If your data is "weirdly" shaped (skewed, multimodal, or heavy-tailed), the non-parametric bootstrap will respect that shape perfectly because it only uses the data it has seen.

2. Advantages & Drawbacks

  • **Advantage:** Completely Model-Free. You don't need to guess if the data is Normal or Gamma.
  • **Advantage:** Valid for any statistic (Skewness, Median, Custom metrics).
  • **Drawback:** Performance can be poor with very small sample sizes (less than 10), as the empirical distribution is a poor proxy for the truth.

3. AI/ML Connection: Model Robustness and OOD Detection

Stress-Testing the AI

In AI, the Non-parametric Bootstrap is used to evaluate Stability across Data Shifts.

In K-Fold Cross-Validation, we are essentially doing a form of non-parametric bootstrapping. By training on different subsets of the data, we ask: "How much does my model's logic change if I slightly modify its experience?". In Out-of-Distribution (OOD) Detection, we use bootstrap resampling to build a "Profile of Normalcy." If a new data point falls outside the bootstrap range of the training set's latent features, the AI can flag it as "Never seen before." This is essential for Robustness Engineering—it ensures that an AI doesn't just give an answer, but can distinguish between a "Known known" and an "Unknown unknown."

4. Python: Bootstrapping the Median

# Imagine a skewed dataset where Mean != Median
data = np.exp(np.random.normal(0, 1, 100)) # Lognormal data

medians = []
for _ in range(5000):
    sample = np.random.choice(data, size=len(data), replace=True)
    medians.append(np.median(sample))

# Non-parametric range for the median
low, high = np.percentile(medians, [2.5, 97.5])
print(f"95% CI for Median: [{low:.2f}, {high:.2f}]")

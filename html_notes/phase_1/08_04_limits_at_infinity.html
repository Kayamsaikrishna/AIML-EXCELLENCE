Calculus 1.3 Asymptotes

Limits at Infinity

Understanding the long-term behavior of functions: What happens when inputs grow aggressively large?

End Behavior

In many physical and computational systems, we care about stability over time or inputs. Does the system explode? Does it settle down to a steady state? Limits at infinity (\(x \to \infty\)) answer this question.

1. Definition & Horizontal Asymptotes

\[ \lim_{x \to \infty} f(x) = L \]

This means as \(x\) gets arbitrarily large, \(f(x)\) settles closer and closer to the value \(L\). Geometrically, the line \(y = L\) is a Horizontal Asymptote.

Behavior of the Sigmoid Function: Bounded between 0 and 1.

2. Rational Functions: The Power Struggle

For a rational function \(f(x) = \frac{P(x)}{Q(x)}\), the limit relies entirely on the highest powers (degrees) of \(x\).

The 3 Rules

  1. Top Heavy (Degree P > Degree Q): Limit is \(\pm \infty\). (No asymptote).
  2. Bottom Heavy (Degree P < Degree Q): Limit is \(0\). (Asymptote \(y=0\)).
  3. Balanced (Degree P = Degree Q): Limit is ratio of leading coefficients.
\[ \lim_{x \to \infty} \frac{3x^2 + 5}{2x^2 - x} = \frac{3}{2} \]

3. AI/ML Application: Activation Saturation

The Vanishing Gradient Problem

Consider the Sigmoid function used in early neural networks:

\[ \sigma(x) = \frac{1}{1 + e^{-x}} \]
  • \(\lim_{x \to \infty} \sigma(x) = 1\)
  • \(\lim_{x \to -\infty} \sigma(x) = 0\)

This "squashing" behavior is useful because it maps any input to a probability range \([0, 1]\).

The Downsides: Saturation

When the input \(x\) is very large (e.g., 100), \(\sigma(x) \approx 1\). The curve becomes completely flat. Since the derivative (gradient) represents the slope, the gradient becomes almost 0. This effectively stops the network from learning ("Vanishing Gradient"). This limitation led to the adoption of ReLU, which does not saturate at positive infinity (\(\lim_{x \to \infty} x = \infty\)).

4. Python: Observing Saturation

sigmoid_limits.py
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)

test_values = [0, 2, 5, 10, 50]

print(f"{'Input x':<10} | {'Sigmoid(x)':<15} | {'Slope (Gradient)':<15}")
print("-" * 45)

for x in test_values:
    val = sigmoid(x)
    grad = sigmoid_derivative(x)
    print(f"{x:<10} | {val:<15.8f} | {grad:<15.8f}")

# Notice specifically at x=50:
# Sigmoid is effectively 1.0
# Gradient is 0.00000000 -> Vanishing Gradient!

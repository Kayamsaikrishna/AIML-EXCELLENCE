1. The Universal Loop

Mathematical "For Loop".

$$ \sum_{i=1}^{N} x_i = x_1 + x_2 + \dots + x_N $$

AI Application: MSE Loss

Mean Squared Error is just a standardized sum of squared differences.

$$ \text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2 $$

2. Einstein Summation (Einsum)

In Deep Learning code (PyTorch/TensorFlow), we often skip writing the \(\Sigma\). If an index appears twice, we sum over it.

Matrix Multiplication \( C_{ik} = \sum_j A_{ij} B_{jk} \) becomes just `ik = ij,jk`.

3. The Power of Einsum

Performing complex tensor reductions in one line.

import torch

# Batch of Data: (Batch_Size, Features)
# 3 examples, 4 features
A = torch.randn(3, 4)

# 1. Standard Sum (Reduction)
# Summing all elements
total_sig = torch.sum(A)

# 2. Einsum equivalent
# "ij ->" means sum over i and j, reducing to scalar
total_ein = torch.einsum('ij->', A)

print(f"Sigma Sum: {total_sig:.4f}")
print(f"Einsum:    {total_ein:.4f}")

# 3. Dot Product Batch Sum
# If we had reduced row-wise: 'ij->i' (Sum over columns)
row_sums = torch.einsum('ij->i', A)
print(f"Row Sums: {row_sums}")

26. Summation Notation (Sigma)

The Big E. The Loop of Mathematics.

1. The Loop

$$ \sum_{i=1}^{n} x_i = x_1 + x_2 + \dots + x_n $$

In Programming

Sigma is literally a For Loop. It iterates through an index, adds the result to an accumulator, and returns the total.

2. The Loss Function

In Deep Learning, we train on "Batches" of data (e.g., 32 images at a time). We calculate the error for each image, then Sum them up (or Average them) to get the final Loss.

$$ J(w) = \frac{1}{m} \sum_{i=1}^{m} L(\hat{y}^{(i)}, y^{(i)}) $$

Vectorization

In Python, writing a literal `for` loop to do summation is slow. We use Vectorized Operations (like `np.sum` or dot products) which do the math in parallel on the GPU/CPU.

3. Coding Sigma

The speed difference between Loops and Vectorization.

// Python: Loop vs Vector
import numpy as np
import time

# Create a large array representing errors
errors = np.random.rand(10000000)

# OPTION 1: The Sigma Loop (Slow)
start = time.time()
total_loop = 0
for e in errors:
    total_loop += e
end = time.time()
print(f"Loop Time: {end - start:.4f} sec")

# OPTION 2: Vectorized Sum (Fast)
start = time.time()
total_vec = np.sum(errors)
end = time.time()
print(f"Vector Time: {end - start:.4f} sec")

# Vectors are typically 50-100x faster!

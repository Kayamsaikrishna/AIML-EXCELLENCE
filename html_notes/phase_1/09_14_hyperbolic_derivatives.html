Hyperbolic Derivatives

Meet 'Tanh', the older, sharper cousin of Sigmoid.

The "Zero-Centered" Advantage

Both Sigmoid and Tanh are S-shaped. But Tanh goes from -1 to 1, passing through 0. This "Zero-Centering" makes optimization easier because gradients can be positive or negative, rather than always positive (as in Sigmoid outputs).

1. The Formulae

Hyperbolic Sine & Cosine:

\[ \frac{d}{dx}\sinh x = \cosh x \] \[ \frac{d}{dx}\cosh x = \sinh x \]

(Notice no negative signs, unlike regular trig!)

Hyperbolic Tangent (The Star):

\[ \frac{d}{dx}\tanh x = \text{sech}^2 x = 1 - \tanh^2 x \]

2. AI/ML Connection: Tanh Saturation

Why Gradient Descent gets stuck

In Recurrent Neural Networks (RNNs) and LSTMs, Tanh is the default activation. Look at the derivative: \(1 - \text{output}^2\).

  • If the output is near 1 (Meaning x is large positive), derivative is \(1 - 1^2 = 0\).
  • If the output is near -1 (Meaning x is large negative), derivative is \(1 - (-1)^2 = 0\).

This is Saturation. If your weights push the neuron into these flat regions, the gradient dies, and the neuron stops learning. This led to the initialization techinques like "Xavier Initialization" designed specifically to keep inputs in the "linear" range near 0 where gradients are strong.

3. Python: Tanh vs Sigmoid Gradients

activation_gradients.py
import numpy as np

def tanh_deriv(x):
    return 1 - np.tanh(x)**2

def sigmoid_deriv(x):
    s = 1 / (1 + np.exp(-x))
    return s * (1 - s)

# Peak Gradient Strength implies learning speed potential
print(f"Max Tanh Gradient (at 0):    {tanh_deriv(0):.4f}")    # 1.0!
print(f"Max Sigmoid Gradient (at 0): {sigmoid_deriv(0):.4f}") # 0.25

# Tanh allows gradients to flow 4x stronger than Sigmoid!
# This is why Tanh is historically preferred over Sigmoid in hidden layers.

x_sat = 3.0
print(f"\nSaturation Check at x={x_sat}:")
print(f"Tanh Grad:    {tanh_deriv(x_sat):.6f}")
print(f"Sigmoid Grad: {sigmoid_deriv(x_sat):.6f}")
# Both are dying, but Tanh dies faster due to steeper slope.

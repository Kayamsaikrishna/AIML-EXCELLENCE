Optimization 1.7 The Engine

Gradient Descent: The Math

Steepest Descent, Learning Rates, and Convergence.

The Update Rule

To minimize a differentiable function \(f(\mathbf{w})\), we iteratively move in the direction of the negative gradient.

$$ \mathbf{w}_{t+1} = \mathbf{w}_t - \eta \nabla f(\mathbf{w}_t) $$

Here, \(\eta\) (eta) is the Learning Rate. It determines "how big a step" we take. It is the single most important hyperparameter in Deep Learning.

2. AI/ML Connection: The Backprop Loop

Why it works

Through Taylor Expansion, we know that for a very small step \(\epsilon\), the function value decreases most rapidly in the direction of \(-\nabla f\).

In Neural Networks, we don't have the full function shape. We only know the slope at our current location. Like hiking down a mountain in thick fog, we feel with our feet which way is down, take a step, and repeat.

3. Python: Learning Rate Visualization

learning_rate_demo.py
import numpy as np

def train(learning_rate):
    w = 10.0 # Start
    path = []
    for i in range(10):
        grad = 2 * w
        w = w - learning_rate * grad
        path.append(w)
    return path

# 1. Good LR
p1 = train(0.1)
print(f"LR=0.1: {['{:.2f}'.format(x) for x in p1]} (Converges)")

# 2. Too Small LR
p2 = train(0.001)
print(f"LR=0.01: {['{:.2f}'.format(x) for x in p2]} (Too Slow)")

# 3. Too Large LR (Exploding Gradient)
p3 = train(1.1)
print(f"LR=1.1: {['{:.2f}'.format(x) for x in p3]} (Diverges!)")

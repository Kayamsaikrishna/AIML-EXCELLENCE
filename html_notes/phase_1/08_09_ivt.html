Calculus 1.3 Theorems

Intermediate Value Theorem (IVT)

If you travel from A to B without teleporting, you must cross every point in between. The rigorous proof that solutions exist.

Existence vs. Construction

In math (and AI), we often distinguish between proving a solution exists versus actually finding it. The IVT is an existence theorem. It tells us a root lies somewhere in an interval, giving us the confidence to search for it (e.g., via Binary Search).

1. The Theorem Statement

Suppose \(f\) is continuous on the closed interval \([a, b]\). Let \(N\) be any number strictly between \(f(a)\) and \(f(b)\). Then there exists a number \(c\) in \((a, b)\) such that:

\[ f(c) = N \]
graph LR A[Start Point f_a] -->|Continuous Path| B[End Point f_b] N[Target Value N] A -.-> N N -.-> B style N fill:#fefcbf,stroke:#d69e2e,stroke-width:2px
To get from f(a) to f(b) continuously, you cannot skip N.

2. The Root-Finding Application

The most common use of IVT is to show that \(f(x) = 0\) has a solution.

  • If \(f(a) < 0\) (negative)
  • And \(f(b) > 0\) (positive)
  • And \(f\) is continuous...
  • Then \(f(c) = 0\) for some \(c\) between \(a\) and \(b\). The graph must cross the x-axis.

3. AI/ML Connection: Decision Boundaries

Proving Boundaries Exist

In a Neural Network used for classification, the output is a continuous probability score \(P(y=1|x)\) ranging from 0 to 1.

Suppose for input \(x_1\) (a cat), the score is 0.9. For input \(x_2\) (a dog), the score is 0.1. If we define the "Decision Boundary" as the set of inputs where score = 0.5 (uncertainty), does such a boundary exist?

Yes, by IVT. If we can continuously morph the image of the cat into the dog (in the latent space), there must be a transitional image where the model is exactly 50/50 confused. This concept is crucial for Adversarial Examples—finding the exact perturbation that flips a prediction.

4. Python: The Bisection Method

The Bisection Method is the algorithmic implementation of IVT. It repeatedly halves the interval to trap the root.

bisection_method.py
def f(x):
    # Solves x^3 - x - 2 = 0
    return x**3 - x - 2

def bisection_search(func, a, b, tol=1e-5):
    if func(a) * func(b) >= 0:
        print("IVT conditions not met: f(a) and f(b) must have opposite signs.")
        return None
    
    mid = a
    steps = 0
    while (b - a) / 2 > tol:
        mid = (a + b) / 2
        if func(mid) == 0:
            return mid # Found exact root
        elif func(a) * func(mid) < 0:
            b = mid # Root is in left half
        else:
            a = mid # Root is in right half
        steps += 1
        
    print(f"Found root approx {mid:.5f} after {steps} steps.")
    return mid

# Check values
print(f"f(1) = {f(1)}") # -2
print(f"f(2) = {f(2)}") # +4
# Sign change detected -> Root exists between 1 and 2

bisection_search(f, 1, 2)

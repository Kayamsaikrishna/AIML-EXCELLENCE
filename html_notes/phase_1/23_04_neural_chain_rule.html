04. Chain Rule in Neural Networks

The engine of gradient flow.

1. The Nested Function Problem

A Neural Network is a massive composition of simple functions: \(f(g(h(x)))\). To find the derivative of the output with respect to the input (or weights), we must use the Chain Rule recursively.

$$ \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dv} \cdot \frac{dv}{dx} $$

2. Local Gradients

During the "Forward Pass", each node computes its output. During the "Backward Pass", each node receives the gradient from the next layer (\(\frac{\partial L}{\partial \text{out}}\)), multiplies it by its Local Gradient (\(\frac{\partial \text{out}}{\partial \text{in}}\)), and passes the result backward.

3. AI/ML Connection: Custom Layer Design

Designing Activations

When you design a new activation function (like GELU or Swish), you must ensure it has a well-behaved derivative for the Chain Rule.

If the local gradient of your function is always zero or always very large, the Chain Rule will "kill" the gradient flow or cause "Exploding Gradients". Modern AI frameworks like PyTorch and TensorFlow automate the Chain Rule (via Autograd), but the underlying calculus is what determines if a model architecture is trainable. Understanding the chain rule allows you to debug "Dead Neurons" by realizing that the product of derivatives has effectively collapsed to zero.

4. Python: Chain Rule Multiplication

# Function: y = sigmoid(relu(w * x))
def relu_grad(x): return 1 if x > 0 else 0
def sigmoid_grad(x): return sigmoid(x) * (1 - sigmoid(x))

# Grad of y w.r.t w
# dL/dw = (dL/dy) * (dy/dsigmoid_in) * (dsigmoid_in/drelu_in) * (drelu_in/dw)

local_grads = [dL_dy, sig_grad, relu_grad, x]
total_grad = 1
for g in local_grads:
    total_grad *= g

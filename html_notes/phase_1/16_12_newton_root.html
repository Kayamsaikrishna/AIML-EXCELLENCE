12. Newton's Method for Root Finding

Finding roots using tangent line intersections.

1. The Iterative Formula

To find the root of \(f(x)=0\), start with a guess \(x_n\) and improve it by finding where the tangent line at \(x_n\) hits the x-axis:

$$ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} $$

2. Convergence Speed

Newton's method converges Quadratically. This means the number of correct digits roughly doubles with every iteration. It is significantly faster than the Bisection method, provided the initial guess is reasonable.

3. AI Connection: Root vs Minimum

Optimization is just finding where the Derivative is Zero (\(f'(x)=0\)). If we apply Newton's Method to find the root of the derivative, we get the Newton Optimizer:

$$ w_{t+1} = w_t - \frac{f'(w_t)}{f''(w_t)} \quad \text{(1D case)} $$ $$ \mathbf{w}_{t+1} = \mathbf{w}_t - \mathbf{H}^{-1}\nabla f(\mathbf{w}_t) \quad \text{(Matrix case)} $$

This "Second-Order" update is the peak of classical optimization theory.

4. Python: Manual Implementation

def f(x): return x**2 - 2 # Root is sqrt(2)
def df(x): return 2*x

x = 1.0 # Initial guess
for i in range(5):
    x = x - f(x)/df(x)
    print(f"Iter {i+1}: x = {x:.10f}")

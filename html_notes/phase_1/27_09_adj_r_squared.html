Stats 1.7 Model Selection

Adjusted R-Squared

R-Squared with a "BS Filter". It penalizes you for adding features that don't add real value.

The Penalty for Greed

In a regular \(R^2\), adding features always makes the score look better (or stay the same). Adjusted \(R^2\) only increases if the new feature clarifies the target more than what's expected by chance.

1. The Formula

$$ R^2_{adj} = 1 - \left[ \frac{(1 - R^2)(n - 1)}{n - p - 1} \right] $$

Where: - \(n\): Number of data points (Samples). - \(p\): Number of predictors (Features).

As \(p\) (features) increases, the denominator \((n-p-1)\) gets smaller. This makes the fraction larger, which subtracts more from 1, lowering the final score.

2. When to use it?

Feature Competing

When you are trying to decide between Model A (5 features) and Model B (500 features). Adjusted \(R^2\) treats Model A more fairly.

Parsimony

The principle of choosing the simplest explanation. If Model A and Model B have the same \(R^2\), the one with the higher Adjusted \(R^2\) is the winner because it achieves the result with fewer moving parts.

3. ML Connection: Regularization Logic

Overfitting Model Choice

The Statistical Ancestor of L1/L2

Adjusted R-squared is the conceptual father of Regularization (Lasso/Ridge).

Both tools are designed to solve the same problem: **"How do I keep my model from getting too complex and learning noise?"**

  • Adjusted R-Squared: Punishes you for the *count* of features (\(p\)).
  • Ridge/Lasso: Punishes you for the *size* of the weights (\(\beta\)).

In deep learning, we use Akaike Information Criterion (AIC) and **Bayesian Information Criterion (BIC)**, which are essentially more advanced versions of Adjusted R-Squared.

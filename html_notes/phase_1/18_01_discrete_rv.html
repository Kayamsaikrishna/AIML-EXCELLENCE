Prob 1.4 Numeric Mapping

Discrete Random Variables

Converting outcomes to numbers.

The Mapper

A Random Variable (RV) is actually a Function! It maps outcomes from the sample space \(\Omega\) to real numbers. \[ X: \Omega \to \mathbb{R} \] If the range is countable (integers, categories), it is Discrete. Example: \(X(\text{Heads}) = 1, X(\text{Tails}) = 0\).

2. ML Connection: Label Encoding

Targets

In Classification, our target \(Y\) is a Discrete Random Variable. If we predict Spam (1) vs Not Spam (0), \(Y\) follows a Bernoulli distribution. If we predict digit classes (0-9), \(Y\) follows a Categorical distribution. We train models to approximate \(P(Y=k | X)\).

3. Python: RV Simulation

discrete_rv.py
import numpy as np

# Outcome space: ['Head', 'Tail']
outcomes = ['H', 'T']

# Define Random Variable X: H->1, T->0
def X(outcome):
    return 1 if outcome == 'H' else 0

# Simulate 10 experiments
experiments = np.random.choice(outcomes, 10)
# Apply RV function
values = [X(exp) for exp in experiments]

print(f"Experiments: {experiments}")
print(f"RV Values:   {values}")

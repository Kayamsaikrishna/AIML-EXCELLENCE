14. Median and Mode

Alternative measures of center for non-normal data.

1. Median (The 50th Percentile)

The Median is the value $m$ such that $P(X \le m) \ge 0.5$ and $P(X \ge m) \ge 0.5$. In simple terms, it is the middle value when data is sorted. Unlike the mean, the median is Robust to outliers.

2. Mode (The Peak)

The Mode is the value $x$ where the PMF/PDF reaches its maximum.

  • Unimodal: One peak (most normal distributions).
  • Bimodal: Two peaks. In ML, this often indicates that your dataset is actually composed of two different groups of users or objects.

3. AI/ML Connection: Data Imputation and Robust Loss

Handling Missing Values

Median and Mode are the "Workhorses" of **Feature Engineering**.

When you have a dataset with missing values, you must "Impute" (fill) them. If the feature is numerical (like Age) and has outliers, we use Median Imputation because the Mean would be biased by the extreme values. If the feature is categorical (like City), we use Mode Imputation (choosing the most frequent city). In **Robust Regression**, researchers often minimize the Mean Absolute Error (MAE), which is equivalent to finding the **Median**. This is safer when data is noisy. Mode is also the foundation of **Maximum A Posteriori (MAP)** estimation, where the "Best" model parameter is considered to be the Mode of the posterior distribution.

4. Python: Calculating Robust Metrics

from scipy import stats

data = [1, 1, 2, 3, 5, 8, 13, 1000] # 1000 is an outlier

print(f"Mean: {np.mean(data)}") # ~130 (Heavily skewed!)
print(f"Median: {np.median(data)}") # 4.0 (Typical value)
print(f"Mode: {stats.mode(data).mode[0]}") # 1
